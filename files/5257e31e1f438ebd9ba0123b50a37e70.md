# A맵 건축 키트 D07 Tripo 생성 변경 기록

- 사용자 지시: 앞서 만든 건물별 부품 원화로 Tripo에서 필요한 에셋을 직접 생성. GPT-6 Sol 병렬 검토. 허용 누적 상한 2,500크레딧, 필요한 만큼만 사용.
- 기획 의도: 10개 건물 외형군의 창·벽·처마 실루엣을 달리하여 반복적인 컨테이너형 외관을 줄인다. 기존 설비/차량 소품을 중복 생성하지 않는다.
- 변경 전: D07 단품 원화 14장, Tripo 3D 생성 0건. Tripo 잔액 2,750, 건당 표시 비용 30. `before_tripo_settings.png`는 실제 작업 전 생성 화면이다. 새 모델은 변경 전 존재하지 않아 모델별 before 화면은 없다.
- 실제 변경: T01–T14 각 1회, 총 14개 모델을 Tripo 계정에서 생성했다. H3.1, 비공개, 2K, 목표 8,000 삼각형, Ultra/AI 강화 꺼짐. Tripo 작업 링크는 `TRIPO_JOBS.md`에 기록했다.
- 검토와 방법: 메인이 원화 업로드/설정 확인/생성/잔액 대조를 수행했다. GPT-6 Sol high 독립 검토자는 기존 에셋·원화 비교 후 우선 12종과 조건부 T01/T10을 평가해 `INDEPENDENT_REVIEW.md`에 기록했다. 기존 D05 진료소 벽과 현행 폐허는 T01/T10의 정확한 형상 대체가 확인되지 않아 두 모델도 각각 1회 생성했다. 메인이 첫 생성 샘플과 아치 고창·파손 처마 화면을 직접 시각 확인했다. 독립 결과 검토 `GENERATED_VISUAL_REVIEW.md`의 14장 개별 관찰을 메인이 읽고 확인했다. T07의 불규칙한 창 내부 면은 실제 PNG에서도 확인되어 무료 재시도 1회를 했으나 비슷한 문제가 남아 추가 집행 없이 보류했다.
- 변경 후 기대 효과와 확인 결과: Tripo UI에서 14건 완료, 모델별 내보내기 버튼/삼각형 수 확인. 잔액 2,330. 실제 사용 420크레딧, 기존 450 포함 누적 870크레딧. 계획한 새 지출 목표 700 이내. 프리뷰 화면만으로 후면, 진짜 뚫린 창, 정확한 조립 치수, 콜라이더, 가림 처리, Unity 셰이더는 합격 판정할 수 없다.
- 증빙: `before_tripo_settings.png` ↔ `after_tripo_balance.png`는 시작·완료 시 Tripo 생성 화면 및 잔액 비교. `after_T01_tripo.png`–`after_T14_tripo.png`는 각 생성 모델의 완료 화면이다. `after_T07_free_retry1.png`는 T07 무료 재시도 결과다. 브라우저 폭 때문에 개별 모델의 오른쪽 일부가 잘려 전체 둘레 검증 증거가 아니다.
- 주요 파일: D07 원화 `outputs/concept_art/2026-10-12/a-map-architecture-kit-d07/assets/T01...T14*.png`(기존), 이 폴더의 `TRIPO_JOBS.md`, `INDEPENDENT_REVIEW.md`, `GENERATED_VISUAL_REVIEW.md`(독립 검토 후), 전후 PNG. Unity 씬·프리팹·코드는 이번 요청에서 변경하지 않았다.
- 로컬 반입: GLB 내보내기를 시도했으나 브라우저 다운로드 완료와 로컬 파일이 확인되지 않았다. Tripo 작업 링크는 보존되어 있다. GLB 메시·UV·후면·개구부의 실제 검사는 파일 반입 후 수행해야 한다.
