# 비 온 뒤 안뜰 — 첫 그래픽 샘플

2026-09-08 · 원본 프로젝트 C:/UnityProject/escape · Unity 6000.1.0f1 / URP 17.1.0

## 적용과 실행

원본 프로젝트의 `Assets/Escape/Scenes/SystemsTest.unity`에서 Play를 다시 시작하면 적용된다. 기존 StageAArtPass와 동일하게 공용 시스템 시험장 배경에 연결되므로 로비 및 같은 시험장을 공유하는 다른 구역에서도 보인다. 정식 스테이지 전체 제작은 아니다.

현재 URP를 유지했다. 새 외부 그래픽 패키지나 유료 에셋을 설치하지 않았다. 배경은 절차적으로 제작한 메시 배치와 텍스처, URP Lit 재질을 사용한다. 기존 세 단계 플랫 셰이더 파일은 보존했고, StageAArt 재질 14개를 빛과 그림자에 반응하는 재질로 교체했다. 20×20 타일 배치, 다층 벽, 파이프, 덩굴, 잔해, 따뜻한 램프를 추가했다. 주요 외벽은 원래 시험장 충돌면 ±19.5m에 맞췄고, 기존 충돌·전투 코드는 변경하지 않았다. 작은 잔해와 식물은 시각 장식이다.

약한 빗줄기, ACES 톤 매핑과 약한 블룸, 한 번 캡처하는 환경 반사 프로브를 사용한다. 프로브는 배경 레이어만 캡처해 캐릭터가 반사에 고정되는 것을 피한다. 이는 움직이는 캐릭터를 실시간으로 비추는 화면 공간 반사나 정교한 볼류메트릭 안개가 아니다. 부상 화면 효과보다 낮은 우선순위를 사용한다.

## 검증

분리한 `work/rain-courtyard-validation` 프로젝트에서 에셋 생성 및 Unity 컴파일 성공. 실제 SystemsTest에서 별도 임시 저장 경로를 사용해 출격, 원래 SD 캐릭터 생성, 재장전, 사격, 이동, 무충돌 장식, 실행 중인 빗줄기, 렌더링 후 환경 반사 텍스처 등을 12항목 확인했다. 최종 검사에 예외가 없었다. 사용 GPU는 NVIDIA GeForce RTX 4050 Laptop GPU, 플레이 캡처는 1280×720이다. 60FPS 벤치마크 및 배포용 실행 파일 빌드는 이번 범위에서 수행하지 않았다.

원본 SD 리소스 292개 파일의 SHA-256 변경 0개. 생성 StageAArt 리소스를 원본에 복사한 뒤 검증본과 해시 불일치 0개. 원본 ProjectSettings/Packages 및 캐릭터·장비·저장 파일은 배포 대상으로 복사하지 않았다.

## 한계와 다음 작업
