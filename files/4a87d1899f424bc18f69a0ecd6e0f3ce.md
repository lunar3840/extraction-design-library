# 인게임 우측 하단 초록 점선 원 수정

## 사용자 지시 및 기획 의도

- 인게임 우측 하단에 크게 나타나는 이상한 초록 원형 점선을 진단하고 조치한다.
- 스킬 UI와 실제 스킬 기능을 제거하지 않고 잘못 그려지는 잔상을 해결한다.

## 변경 전 상태 및 근거

- 수정 전에 기존 실제 Game View 캡처 `ui-kit-completion-unity/after_r06_combat_hud_1920x1080.png`를 `before_combat_hud_1920x1080.png`로 복사했다. 원본 캡처 시점은 2026-10-22 07:24:30 KST이며, 재구성 이미지가 아니다.
- 큰 민트 점선 원과 아래쪽 흩어진 흰 조각을 확인했다. 당시 렌더러와 현재 `InventoryHudVisuals.Line`의 수정 전 구현이 일치한다. 수정 전 소스도 `before_InventoryHudView.cs`에 보관했다.
- 현재 Unity는 원래 StageA_Relay_Blockout_v08 씬, Play 정지, 제목/Hierarchy에 미저장 표시 없음으로 확인했다. 전후 재검증에서는 임시 SystemsTest 프로필을 사용하고 원래 씬으로 복구한다.

## 원인

- `CompanionAbilityController.DrawAbility` → `InventoryHudVisuals.Arc` → `Line`에서 스킬 테두리 72개 조각을 그린다.
- `UiTheme.Begin`이 전체 UI에 배율을 적용한 상태에서 `GUIUtility.RotateAroundPivot`을 화면 기준으로 선행 합성해, 논리 좌표 pivot과 배율이 맞지 않았다. 1920×1080의 Scale1.2에서 작은 원호가 큰 점선 원으로 흩어졌다.
- 같은 함수를 사용하는 조준 아이콘의 흰 선 조각도 같은 좌표 오류 영향을 받는다. 월드 범위 표시나 스킬 판정 자체가 아니다.

## 실제 수정과 방식

- 수정 파일: `C:/UnityProject/escape/Assets/Escape/Runtime/Inventory/InventoryHudView.cs`의 `InventoryHudVisuals.Line` 한 메서드.
- 선을 원점에 그리면서 `부모 GUI 행렬 × 논리 위치/회전 TRS` 순서로 적용한다. `finally`에서 기존 GUI 행렬을 항상 복구한다.
- 스킬 정상 원형 테두리, 쿨타임·충전 비율, E/X 입력, 스킬 기능, HUD 배치/색상/시간/소모품 표시를 보존한다.
- 독립 코드 진단을 병렬로 수행했으며 원본 수정·Unity 조작은 메인이 맡았다. 연동 검토 탭에는 해당 한 메서드와 공유 Unity 검증 범위를 알렸다.

## 검증 진행

- 전체 runtime 정적 컴파일 exit0, 오류0/기존 경고21, 결과 `validation/runtime_compile.txt`. 열린 Unity Editor에서도 script build success를 확인했다.
- 독립 검토 보고서 `readonly_review/REVIEW.md`를 메인이 읽었다. 0.5/1/1.2/1.5 배율 및 다양한 선 방향·원호 비율에서93 PASS (`result.txt`). 원호의 선 두께까지76×76논리영역 안에 있고, Line 외 소스가 수정 전과 동일함을 확인했다.
- 연동 검토 탭의 이후 `loot-shop-tier-consistency` 변경 사항5파일을 현재 SHA-256과 대조해 모두 동일함을 확인했다. 예전 전체 소스로 덮어쓰지 않았고 기존 자연 시간 테스트 도구를 그대로 사용했다.
- 현재 증빙 도구를 수정하지 않고 격리 프로필의39단계 캡처 route를 실행했다. `loot-shop-tier-consistency/after_r02` 새 파일로 저장돼 기존 증빙을 덮어쓰지 않았으며,34장 캡처/COMPLETE/bounds0/temporary session cleared=True다. 해당 manifest를 `validation/actual_screen_manifest.txt`로 복사했다.
- `after_combat_hud_1920x1080.png`와 상태 파일을 복사하고 실제 픽셀을 직접 열어 확인했다. 큰 초록 점선 원과 흩어진 흰 조각이 없어졌고, 오른쪽 E/X 자체 아이콘 영역에 정상 작은 테두리/조준 선이 모인다. 스킬 이름·키·준비/충전 상태와 기존 HUD 배치는 유지됐다.
- 전후 동일1920×1080 및 동일격리route 전투화면을 비교했다. 런타임 프레임에 따라 캐릭터 위치/포즈와 카메라 정착은 달라 완전한 픽셀 동일 구도로 주장하지 않는다. 월드의 초록 연무는 별개 월드효과로 유지되며, 이번 제거 대상은 화면 위의 점선/흰조각이다.
- 검증 종료 후 기본 저장 경로와 Keyboard, 비활성 가상입력/interactive 상태를 확인했고 Title/noSession에서 Play정지를 요청했다. 원래 씬 복구 결과는 아래에 이어 기록한다.
