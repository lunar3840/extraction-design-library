# 퀘스트 분류 / 스토리 컷씬 시스템

날짜: 2026-10-19 (Asia/Seoul)
적용 대상: C:/UnityProject/escape/Assets/Escape
현재 상태: 실제 Unity 프로젝트에 적용 완료. 최종 실행 검증과 실제 편집기의 컴파일·리로드 완료를 확인했다.

## 사용자 지시
퀘스트 진행에 연결되는 컷씬 시스템을 구현한다. 상황에 따른 캐릭터 정면·측면·대각선 클로즈업, 하단 대사, 대사 위 화자 이름·얼굴 또는 상반신 썸네일이 필요하다.
퀘스트를 메인 / 서브 / 인연(동료 시나리오)으로 나누고, 아직 확정하지 않은 목록 대신 임시 예시를 넣는다.
파이어엠블렘 풍화설월은 대화 화면의 참고 대상이며 해당 게임의 세계관·규칙·이미지 자산은 프로젝트에 가져오지 않는다. 공식 소개 참고: https://www.nintendo.com/en-gb/Games/Nintendo-Switch-games/Fire-Emblem-Three-Houses-1175482.html

## 의도와 변경 전 문제
기존에는 작은 스크롤 패널에 지역 해금용 메인 의뢰 4개가 표시되었다. 서브·인연 분류, 퀘스트 연동 대화, 재생 대기·시청 기록, 화자별 클로즈업이 없었다.
기존 메인 의뢰와 저장 호환을 지키면서 시나리오 데이터를 교체할 수 있는 기반을 마련한다.

## 변경 내용과 방식
- 기존 4개 메인 퀘스트 ID·지역 해금 조건 유지. QuestCategory / QuestCatalog 확장.
- 메인 예시 '첫 귀환의 기록', 서브 예시 '내일을 위한 물', 세린 인연 예시 '돌아온 뒤의 약속' 추가. 제목·대사·목표·보상은 임시다.
- Q/거점 단말의 퀘스트 창을 세 분류, 목록, 목표·선행 조건·보상·수락/대화/보고·시청한 대화 다시 보기 구조로 구성.
- 성공 귀환 / 인연 대화 목표를 기존 처치·수집·제출 목표에 추가.
- 수락·목표 달성·완료 컷씬 이벤트를 프로필과 함께 저장. 저장 실패 시 진행과 보상은 유지. 시청 완료 및 건너뛰기는 같은 결과를 한 번만 저장.
- 중도 종료한 대화는 대기 상태를 유지하며 다음 재생 시 첫 문장부터 시작. 다시 보기는 진행·보상 변경 없음.
- 별도 렌더 장면에 기존 캐릭터 프리팹을 생성하고 대사별 정면·좌우 측면·좌우 대각선, 얼굴/상반신 구도를 사용. 원래 메시·재질 유지.
- 초상은 같은 모델을 별도 카메라로 촬영하거나 화자에 지정한 이미지 사용.
- 타이핑 표시, 다음 대사, 자동 진행, 대화 기록, 건너뛰기 확인, 선택 음성 클립 지원.
- 컷씬 중 월드 시간·게임 입력·HUD를 잠그고 종료/비활성화 시 복원. 퀘스트 자동 컷씬은 거점에서 재생하며 출격 중 달성은 귀환 후 확인.
- Quest / Cutscene ScriptableObject를 추가. Resources/Story/Quests, Resources/Story/Cutscenes에서 시나리오 에셋을 읽는다.
- 프로필 storyVersion=1 및 대기·시청 기록 추가. 기존 저장은 빈 이야기 기록으로 이관.

## 검증 방법
기존 companion-chip-validation의 독립 프로젝트에 현재 Runtime을 복사하고 본 작업 전용 QuestEvidence/QuestAfterEvidence 장면·실행 파일을 생성했다.
프로필은 이 폴더의 isolated_profiles 아래 매 실행 새 GUID 경로를 사용한다. 실제 사용자 저장을 편집하지 않았다.
QuestStoryChecks, 기존 BasecampChecks, SessionChecks 및 실행 중 통합 검사와 PNG 육안 확인을 수행한다.
검증 빌드의 IL post-processing 연결 대기가 반복되어 검증 프로젝트의 편집기 스크립트만 QuestEditorArchive로 임시 분리했다. 실제 프로젝트의 기존 Editor 도구는 변경하지 않았다. 중단한 검증 프로세스가 완전히 종료되기 전에 재시작한 한 번은 프로젝트 잠금 오류가 발생했으며 after_build_6.log에 남아 있다. 본 작업 전용 ILPP 연결을 정리하고 검증 프로젝트를 작업 경로로 지정해 연결을 정상화했다. Unity 설치 파일이나 보안 설정은 변경하지 않았다. 최종 검사 후 임시 분리한 편집기 파일은 원래 경로에 복원했으며 현재 검사 파일과 빌드 도구를 덮어쓰지 않았다.

## 범위
맵·적 배치, 캐릭터 외형 에셋은 수정하지 않는다. 기존 다른 작업 파일은 적용 직전 비교하여 보존한다.
실제 스토리 목록·대본, 전용 배경, 표정·제스처·립싱크·음성 자산, 선택지 분기는 이 기반 구현과 별도다.

## 기대 효과와 현재 예시 범위
실제 퀘스트 목록이 확정되면 퀘스트와 컷씬 에셋을 추가해 같은 저장·목표·보상·대화 화면에 연결할 수 있다. 현재 자동 컷씬은 거점에서 시작하며 출격 중 달성한 목표는 귀환 후 대화로 이어진다. 예시 제목·대사·목표·보상, 단색 배경과 기본 대기 자세는 확정 시나리오가 아니다. 실제 대본과 연출 자산을 후속으로 교체할 수 있다.
