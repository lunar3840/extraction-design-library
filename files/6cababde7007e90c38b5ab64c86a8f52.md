# 기획 라이브러리 연결 오류 및 실행 방식 보완

2026-10-23 KST. 사용자 제공 화면에서 ERR_CONNECTION_REFUSED 확인. 이번 진단 시점에는 기존 서버 PID 67808이 HTTP 200으로 응답하므로 오류 당시의 종료 원인을 확정하지 않는다.

기존 서버가 작업용 실행 세션에서 실행됐음을 확인했다. 해당 서버만 식별해 종료하고 숨김 백그라운드 프로세스로 다시 실행한다. 실행기는 Node 경로 대체 탐색, 시작 로그 저장, HTTP 준비 확인 후 브라우저 열기를 지원하도록 수정했다.

before_connection_error.png는 사용자가 제공한 실제 오류 화면이며 source_before/start.ps1은 수정 전 실행기다. 현재 브라우저 제어 목록이 비어 있어 변경 후 실제 화면 캡처는 확보하지 못했다. HTTP 응답과 별도 호출에서 프로세스 유지 여부를 확인하며 이를 화면 검수로 간주하지 않는다. 사용자 PC 재부팅 후에는 라이브러리 열기.cmd로 다시 실행한다.
