# 전투 HUD 참고 방향 수정 및 가독성 보강
일자: 2026-10-21
Figma: https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0/EXTRACTION-%C2%B7-Modern-Glass-UI-Kit?node-id=69-2948

## 사용자 지시
- 반복 소켓·금속 장식이 작위적이므로 니케와 스텔라 블레이드를 참조한다.
- 후속: 새 시안의 방향은 유지하되 글자 가독성을 명암으로 높이고 디자인을 조금 다듬는다.
- 후속: 아크 레이더스도 참조하되 레트로 느낌은 제외한다.
- 숫자 없는 원형 수분·에너지, 캐릭터 위 체력·스태미너, 편집 가능한 Figma 요소, 앱 종료·재시작 금지 지시는 유지한다.

## 의도와 변경 전 문제
직전 시안의 소켓/이중 아크/U 받침/금속 접점/별 문양 반복이 정보를 읽는 데 불필요했다. 장식을 걷어낸 첫 참고 시안에서는 복잡한 게임 배경이 문구와 겹쳐 대비가 약했다. 고유성은 실제 에델 초상·능력 기호·파스텔 생존 게이지에서 확보하고, 정보 위계와 명암을 중심으로 정리했다.

## 실제 변경
- 반복 금속 테두리·이중 링·받침·문양을 제거. 수분·에너지는 112px, 내부 아이콘52px, x336/y920 위치와 아래부터 차는 fill38%를 유지.
- 주 탄약48px, 보조 탄약32px, 이름/본문16px, 보조14px. Noto Sans KR + Barlow Condensed.
- 능력은 상자 대신 아이콘/충전 링/입력 키/이름으로 구성. 에델 초상과 실제 재배치·기동 가속 문구 사용.
- 글자 뒤 국소 배경52–66%와 흐림6px, 검정 그림자2겹. 제목Bold/본문Medium, 기본 문구는 밝은 중성색. 밝고 복잡한 지형에서도 문구와 배경을 분리.
- 무기·작전·상호작용·시계·중량·동료 이름·스킬 설명에 필요한 만큼의 명암 적용.
- 에델 초상은 기존 에셋을 얼굴 중심으로 잘랐다. 원래 머리색·재질은 그대로다.
- 흰 키캡/검정 글자를 F·숫자3~6·E/X에 통일. 수량은 ×1로 표시하여 입력 키와 구분.
- 주 탄약과 예비 탄약의 하단 정렬, 작전 제목의 수직 중앙 정렬을 수정.
- 작전2/4 및 탄창24/30의 밝은/어두운 구간을 복구. 색은 생존·경고·등급의 의미에 사용.
- 복고풍 표제/누런 흰색/강한 원색 배합/하프톤/인쇄 마모 효과는 적용하지 않았다.
- Figma 공유 컴포넌트·변수·텍스트·벡터·인스턴스로 작업. Unity 실행·수정 없음.

## 참고 자료와 적용 범위
타 게임은 UI 정보 위계/배치/명암/입력 안내만 참고했다. 타 게임 세계관·전투 규칙·장비 체계는 이 프로젝트에 적용하지 않았다.

## 검증
- 주 에이전트가 실제 참고 이미지와 변경 후 프로젝트 배경 미리보기를 직접 확인.
- 독립 시각 검토: 최신 after_project_backdrop.png와 before_readability_project_backdrop.png를 열어 비교, PASS.
- 주요 문구·탄수·키캡·수량이 배경에서 구분된다. 작전2/4와 탄창24/30의 명암 차이 확인. 새 겹침·잘림 없음(제공된1920×1080장면 기준).
- 초기 자동 검사에서 기준선 때문에 발생한1px 넘침2종을 발견했고, 실제 원본 컴포넌트의 하단 정렬/중앙 정렬로 수정. 수정 노드 ID는 readability-ledger.json에 기록.
- 마지막 저장 후 전체6프레임 자동 검사·추출을 시도했으나 Figma MCP 호출 한도로 실패. 실패 결과를 최종 검증 성공으로 취급하지 않았다.
- whoami 확인 시 현재 파일 소유 팀 ‘믕봉믕's team’은 Professional/View로 보고됐다. 추가 결제·좌석 변경은 수행하지 않았다.
- 최신 프로젝트 배경 이미지는 모든 수정이 저장된 뒤 호출 한도에 걸리기 전에 정상 추출한 실제 Figma 화면이다.
- 브라우저 재확인도 시도했으나 익명 뷰가 홈으로 이동하거나 접근 제한을 표시했다. 재확인에 성공했다고 주장하지 않는다.
- Codex/ChatGPT 앱을 종료·재시작하지 않았다.

## 스크린샷 증빙
작업 착수 전에 Figma 원본6프레임의 before_*.png를 저장했다. 가독성 후속 지시 직전 상태도 before_readability_*.png로6프레임 저장했다. 재구성 전 이미지 없음.

| 전체 디자인 / 프로젝트 배경 | before_project_backdrop.png | after_project_backdrop.png |

- 위기 중간 증빙은 명암 수정 후, 흰 E/X 키캡과 ×1 표기 적용 전 캡처다. 최종 위기 이미지로 위장하지 않는다.
- before_normal/critical/extraction/guide/survival_guide.png 및 before_readability_*는 실제 해당 단계 원본이다.
- 나머지5프레임의 최종 재추출은 호출 한도로 확보하지 못했다. 기존/중간 캡처를 최종 after로 대체하지 않았다.
- 프로젝트 배경은2026-10-15의 기존 게임 캡처와 에델 에셋으로 구성한 Figma 합성 디자인이다. 최신 Unity 런타임 구현 화면을 뜻하지 않는다.
