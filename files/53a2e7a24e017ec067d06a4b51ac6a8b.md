# A맵 V29 동선 유도 도면 작성 기록

## 사용자 지시와 범위

너무 자유롭게 가로질러 다니는 현재 맵에 비선형 동선 유도를 적용할 도면을 요청하셨다. 직접 수정은 금지하셨으므로 Unity 실행, 씬·프리팹·코드·에셋 배치는 하지 않았다. 건물 가림 효과는 별도 요청이며 이번 범위에 포함하지 않는다.

## 문제와 기획 의도

기존 V27의 소규모 군집만으로는 넓은 접근면 전체의 통과 위치와 목적지를 읽기 어렵다. 주 연결길, 시설 접근 마당, 우회 탐색길, 노출 지름길을 계층화하고 그 주변에 지형·외벽·적치 공간으로 이루어진 경계 후보 F1–F9를 제안한다. 중앙 시설에 들어가지 않고도 북·남으로 돌아갈 선택과 두 기존 교량을 유지한다.

## 작성한 부분과 방법

- 기존 저장 좌표를 바탕으로 520×400m 전체 동선 계획 PLAN.json과 DESIGN.md를 작성했다.
- GPT-6 Sol high 제작 에이전트가 좌표 기반 PNG/SVG 전체도와 A01–A03 확대도를 제작했다.
- 별도 GPT-6 Sol high 검토 에이전트가 건물·소품 충돌 범위와 제안 통행 폭, 교량 연결, B/R/X 보존을 검토했다. 메인이 REVIEW.md를 읽고 경로와 재배치 검토 표식을 통합했다.
- P1/P2는 열린 접근 마당, Q1–Q3는 기존 소품 이동 검토 대상이다. 기존 물체 위에 새 경계를 무조건 추가하는 지시가 아니다.
- 지형·주 통로·시설 접근·우회 폭은 모두 제안값이다. 실제 출입구·경사·메시·NavMesh·시야·플레이 시험은 하지 않았다.

## 증빙 이미지와 한계

- `before_reference_unity.png`: 이 작업에서 새로 촬영한 화면이 아니다. 같은 날 완료된 V27의 `after_overview.png` 원본을 현황 참고로 복사했다. 출처: `outputs/change_records/2026-10-01/a-map-approach-clusters-v27/after_overview.png`.
- `after_proposed_plan.png`: 새로 만든 미적용 제안 전체도이다. Unity 적용 후 스크린샷이 아니다.
- `after_proposed_details.png`: 새로 만든 미적용 제안 확대도이다. Unity 적용 후 스크린샷이 아니다.
- 실제 맵을 수정하지 않았으므로 동일 시점 Unity 전후 비교 화면은 생성하지 않았다. 현황 참고 화면과 제안 도면은 카메라·투영·축척이 달라 직접 픽셀 비교 대상이 아니다. 사후 화면을 작업 전 화면으로 위장하거나 재구성하지 않았다.

## 확인 결과 및 기대 효과

주요 시설 간 통과길의 기존 건물 AABB 관통·명목 통행 폭 간섭은 도면 좌표 조정으로 해소했다. 수로 교차는 기존 두 교량에 한정했다. 기본 진입·탈출 좌표와 위험 진입 비활성 상태는 유지한다. B4/R8 차별화 문제를 해결했다고 주장하지 않는다.

Q1–Q3 소품 간섭, 실제 문 접속, A01 급경사와 V27 개별 메시 간섭은 구현 전 확인 대상으로 남는다. 도면 검토상 연결 구조가 성립한다는 뜻이며 실제 게임에서 동선 유도가 검증됐다는 뜻은 아니다.
