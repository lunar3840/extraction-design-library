# 덩굴 잎 형태·분포 후속 조정

## 사용자 원문

> 잎의 형태나 분포 조금 더 다듬어봐.

앞선 도구의 차량 앞부분 과밀, 건물 윗선 균일, 지붕의 가느다란 선 형태를 조정한다. 대상은 덩굴 생성 도구와 별도 차량/S06외벽/지붕 시범이며 A맵 전체 배치 지시로 확대하지 않는다. 원본 맵/AI/조명/가림/캐릭터를 보존한다. 같은 D09 주제의 당일03회차로 연결하며 앞선02원문과 시범은 보존한다.

## 기획 의도와 시작 상태

기존 잎은 큰 각이 진 단일 실루엣으로 반복되고, 줄기 전 구간에 일정 간격으로 달린다. 차량 앞쪽에 여러 줄기가 집중되고 벽 꼭대기에 도달한 줄기가 윗선을 길게 따라가 장식띠처럼 보인다. 더 둥근 다엽 실루엣과 크기·방향 변화, 잎이 풍성한 군집과 줄기가 보이는 여백, 서로 다른 성장 길이로 바꾼다.

사용자 지시 후 공유 Unity 명시 인계를 확보했다. 실제 변경 전에 기존 생성 결과를 새 회차에서 같은 카메라로 렌더하고 도구/보호파일 백업과 해시를 남긴다. 메인 통합·실행, GPT-6 Sol high 생성 분포 / 잎 형태·표면 표현 / 독립 검증으로 소유 파일을 나눈다.

## 실제 변경

메인이 통합·실제 Unity 실행을 맡고 GPT-6 Sol high에 성장 분포 / 잎 형상·잎 재질 / 독립 검증을 분리 배정했다. 수정 전에 기존02시범 프리팹을 그대로 불러 실제 Unity 렌더6장을 `baseline_renders/`에 저장했다. 과거 사진을 새 전 이미지로 위장하거나 수정 후 이미지를 전 이미지로 사용하지 않았다.

- 잎을 기존7정점/6삼각형의 각진 단일 형태에서24경계+중심점/24삼각형의 완만한3엽·둥근 어린잎·5엽 혼합으로 바꿨다. 작은 좌우 비대칭과 말림, 크기·방향 차이를 준다. 불필요하게 솟은 중앙 접힘을 낮췄다.
- 새 잎 전용 URP Lit 재질은 채도가 덜한 올리브색이다. 96×96 텍스처에 부드러운 중앙 잎맥·옆 잎맥·가장자리 음영·약한 얼룩/갈변을 넣었다. 새 셰이더나 원본 건물/차량 재질을 수정하지 않았다.
- 자동 시작점의 간격을 분산하고 줄기별 성장 길이를 달리했다. 가까운 경로의 과밀을 제한하며 벽 상단에서 긴 가로 띠로 이어지는 성장을 제한한다. 군집 중간은 양쪽 짝잎을 만들고 사이에 빈 구간을 둔다. 끝으로 갈수록 줄기가 가늘어진다.
- 잎 외형의 난수열을 성장 방향 난수열에서 분리했다. 외형 조정 때문에 기존 모서리 추적이 우연히 달라지는 결합을 줄였다. 공개 Build/settings API와 실제 표면·배제·비가독 메시 읽기·취소·상한 보호를 유지했다.

수정: `Assets/Escape/Editor/Environment/SurfaceIvyGenerator.cs`, `SurfaceIvyWindow.cs`, `SurfaceIvyValidation.cs`. 추가: 같은 경로 `SurfaceIvyLeafProfile.cs`. 생성기의 최종 통합 소스는 `staging/integrated/SurfaceIvyGenerator.cs`이며 성장 담당의 중간 원본과 구별한다. `Runtime/Environment/SurfaceIvyInstance.cs`는 해시 동일이다.
