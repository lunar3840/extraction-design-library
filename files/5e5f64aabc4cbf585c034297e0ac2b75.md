# 인벤토리 분석서 페르소나·가독성 후속 수정

## 변경 이유와 범위

설계 목적에 맞는 인벤토리 형태를 제안하는 결론에, 어떤 플레이어에게 어떤 경험을 제공할지 연결할 필요가 있었다. 38·39쪽에 가상 페르소나를 넣은 뒤 사용자 피드백에 따라 배치와 문구를 다듬었다. 40쪽 구성과 기존 조사 수치는 유지했다.

사용자의 서비스디자인 프로젝트는 인물·대표 문장·행동·요구를 배치하는 방식의 참고로만 사용했다. 그 참고 원본은 이 인계에 포함하지 않는다.

## 실제 변경

- 38쪽은 공간을 정리해 더 챙기는 과정을 즐기는 플레이어, 39쪽은 필요한 물품을 챙긴 뒤 다음 탐색을 서두르는 플레이어로 구성했다. 가상 인물 이미지는 AI로 제작했다.
- 기존 네 열을 주로 하는 행동 / 불편한 순간 / 원하는 경험의 세 열로 줄이고 본문 글자를 키웠다. 하단에는 제공할 경험 → 게임 설계 목적 → 더 유리한 인벤토리 형태를 연결했다.
- 사용자가 삭제를 요청한 하단 안내 두 줄, 설문 참고 수치, 공통 상황 문구를 페르소나 페이지에서 제거했다. 다른 분석 페이지의 조사 근거를 삭제하거나 수치를 다시 계산한 작업은 아니다.
- 기능의 장점을 설명하는 대사 대신 성향이 드러나는 문장으로 고쳤다. 38쪽은 “잠깐만, 자리 좀 만들어 볼게. 이것도 챙겨 가고 싶어.”, 39쪽은 “그냥 필요한 거 빨리 챙겨. 다른 데도 빨리 가봐야 해.”다.
- 인물 아래의 설명을 대표 대사 위로 옮겨 상단을 줄였다. 확보한 공간으로 본문 문단 간격과 하단 요약 영역의 안쪽 여백을 넓혔다.
- 마지막 정렬 요청을 확인했을 때 두 색상 박스는 이미 같은 위치와 크기였다. 추가 이동을 했다고 기록하지 않고, Figma와 PDF에서 동일 좌표를 확인했다.
- 사용자가 최종 출력하도록 요청한 뒤 Figma의 고품질·sRGB 내보내기로 전체 40쪽 PDF를 다시 만들었다. 최종 용량은 20,485,445바이트(20.5MB)다.

## 의도와 해석

격자형 페르소나는 배치와 교체를 고민해 수납 구성을 완성하는 성취감에, 균일 슬롯형 페르소나는 담는 조작을 간결하게 끝내 다음 행동을 이어가는 경험에 연결했다. 이는 설계 목적을 설명하기 위한 가상 설정이다. 설문 참여자를 두 유형의 사람으로 분류한 결과나 실제 이용자의 직접 인용으로 해석하지 않는다.

## 사용자 지시와 검증

지시일은 모두 2026-11-19(KST)이며 핵심 메시지 15건의 실제 식별자는 SOURCE_MESSAGES.json에 수록했다. 개별 메시지의 정확한 작성 시각은 제공되지 않아 턴 시작일을 날짜 근거로 사용했다.

최종 PDF SHA256은 `19b8b10c4e8373ad03ab65248885e8e111fe78111818b2dfae06ea516202d00a`다. 40쪽 순서·크기와 최신 대사, 삭제 문구가 없는 것을 확인했고 전체 렌더와 두 페이지 확대 검토를 마쳤다. PDF에서 하단 박스는 양쪽 모두 x=144, y=827, 너비=1712, 높이=138이다. 기존 16.8MB PDF와 원본 이미지들은 보존했다.

## 인계 상태

이번 인계는 완료자료 문서화와 선택 이미지 변환만 수행했다. Figma·게임 편집, 영상 재조사, 설문 재수집은 하지 않았다. 전체 PDF·비공개 참고자료·설문 개별 응답·추론 및 도구 로그는 제외한다.

기존 인벤토리 주제의 다음 회차로 연결하며 기존 문서·선정 이미지·주제 메타는 덮지 않는다. 수신 측의 파일 SHA 검증과 실제 게시·열람 확인은 별도 단계다. 로컬 준비나 청크 출력만으로 게시 완료를 주장하지 않는다.
