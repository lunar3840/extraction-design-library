# 에델 S4 — Unity 테스트 지급·방어구 외형 토글

사용자 지시(2026-11-03 KST): “유니티에 임시로 기본지급 의상으로 게시해볼래? 한번 유니티서 확인해보게.” 후속: “방어구 외형 나오게끔 하는 대신 다른 방어구들은 아직 모델링 안넣었으니 얘만 넣어줘. 방어구 외형 on off 버튼도 인벤토리 열었을때 캐릭터 근처에 하나 만들어주고.”

11/2 같은 주제의 Blender 피팅 시제품 r14 이후 실제 Unity 적용 회차다. 기존 피팅 원문과 게시 회차를 덮어쓰지 않는다. 이번에는 에델용 모델 한 벌만 연결하며, 세린/리브/유이 피팅 또는 전체16종 제작으로 확대하지 않는다. 맵/전역 렌더링 정책은 수정하지 않는다.

## 의도와 변경 전

기존 게임은 플레이어 방어구 외형을 임시로 모두 숨겼고 S4 모델은 Blender/GLB 검토본으로만 존재했다. 테스트용 기본 지급과 실제 방어구 장착을 연결하되 미제작 방어구에 예전 공통 모델을 표시하지 않고, 외형 표시만 선택할 수 있게 한다.

수정 전에 실제 Unity 에델 프리팹의 정면/측면/후면과 편집기 상태를 저장했다. 첫 프리뷰는 머리 위가 잘려 `initial_preview/`에 따로 보존하고, 실제 원래 프리팹의 구운 정점 경계로 고정 카메라를 다시 잡았다. 최종 전후는 `PREVIEW_CAMERA.json`의 같은 카메라·해상도·조명·Idle 시점을 사용한다. 인벤토리 버튼 추가 이전의 실제 게임 UI 화면은 확보하지 못했으며, 사후 화면을 전 사진으로 위장하지 않는다. 변경 전 UI 소스는 `backup/Runtime/Inventory/InventoryGlassView.cs`에 보존한다. 최종 ON/OFF 화면은 현재 구현의 상태 비교이며 구버전 UI 복원본이 아니다.

## 진행 범위

- 원본 r14 native에서 의상50개·기존 골격·몸 가림 참조를 FBX로 변환하고, 현재 에델의 골격/몸 좌표계에 연결한다. 원래 캐릭터 프리팹·FBX·텍스처 원본은 보존한다.
- `TEST_EDEL_S4_MAINTENANCE` 전용 방어구와 아이템을 추가한다. 성능은 기존 S급 경량 방탄복을 복제한 테스트 값이며 정식 정비형 S4 밸런스 확정이 아니다. 판매/상점/새 드롭 테이블에는 넣지 않는다.
- 신규 테스트 슬롯은 S4 기본 지급·장착, 기존 슬롯은 최초1회 지급하고 기존 방어구를 강제로 교체하지 않는다. 가방 부족 시 창고에 지급하며 지급 여부를 저장해 재접속/분실 후 무한 재지급하지 않는다. 실제 사용자 저장을 검증에 사용하지 않는다.
- 플레이어 방어구는 에델+S4 아이템의 조합만 표시한다. 다른 플레이어 방어구와 헬멧의 예전 모델은 표시하지 않는다. NPC 외형은 이번 범위에서 변경하지 않는다.
- 캐릭터 패널 우측 위에 “방어구 외형 · 켬/끔” 버튼을 배치한다. 장착·능력치·인벤토리를 바꾸지 않고 외형만 전환하며, 선택은 별도 로컬 표시 환경값으로 유지한다. 회전/캐릭터 반응 입력과 버튼의 포인터 영역을 구별한다.

## 사용자 후속 명확화와 피부 가림 수정

사용자 원문: “방어구 숨김 옵션은 방어구 외형을 안보이고 별도의 의상을 출력하는 시스템이라 방금 작업화면처럼 단순히 의상 부분을 비워두라는 이야기가 아님. 우리 따로 의상 만든거 아직은 없으니까 이너웨어 복장으로 유지해주면 될거임.”

방어구 숨김의 기획은 장착 방어구 외형 대신 별도 의상을 표시하는 것이다. 현재 별도 의상이 없으므로 **OFF는 원래 몸 전체+이너웨어 복장**이다. 장착/방어력은 유지한다. ON은 에델이 전용 S4를 장착했을 때만 S4를 표시한다. 별도 의상 선택 기능은 이번에 새로 만들지 않았다.

초기 실제 인벤토리 OFF에서 옷은 숨었지만 피부가 일부 잘린 상태가 남았다. 라이브 캐릭터의 원본 몸 복원은 수행됐으나, 미리보기 헤어 충돌 시뮬레이션이 이전의 가림 메시 복제본을 다시 할당하는 것이 원인이었다. `InventoryPortrait`에 원본 메시 추적을 추가하고 메시 교체 시 미리보기 헤어 바인딩을 비운 뒤 새 소스로 연결한다. 미리보기 전체를 재생성하거나 카메라 크기/회전/발 위치를 초기화하지 않는다. 라이브 쪽도 몸 교체 전에 해당 바인딩을 비운다.

`before_inventory_hidden_bug.png`는 이번 작업 도중 발견한 실제 OFF 버그다. `after_inventory_off.png`는 수정 후 같은 인벤토리·정면·동일 해상도의 실제 화면이다. 대기모션 시점은 서로 다르며 완전히 동일 포즈로 가장하지 않는다.

## 실제 변경과 가져오기

원본 Blender r14의 50개 의상 메시를 FBX로 변환하고 기존 52개 골격에 이름으로 연결했다. 현재 에델의 기존 몸 정점 27,958개와 형태키·UV·스킨 데이터는 보존한다. 방어구 ON에서만 몸 복제본의 가려진 면을 제거해 45,631→31,505삼각형으로 전환한다. OFF에서는 45,631개 전체 면으로 복원한다. 원본 Unity 에델 FBX/프리팹/텍스처는 수정하지 않았다. 가림 참조와 현재 몸 사이 최대 매핑 오차는 약 0.000000123이다(`IMPORT_REPORT.json`).

의상 베이스컬러를 URP 재질로 연결했으며 Blender의 모든 절차적 미세재질이 동일하게 이식됐다는 의미는 아니다. 임시 테스트 아이템 이름은 `정비형 S4 · 에델 (테스트)`다. 기존 S급 경량 방어구 수치를 복제했고 아이콘도 기존 공통 아이콘을 사용한다. 정식 밸런스나 최종 아이콘이 아니다.

버튼은 에델 이름 오른쪽에 배치하고 동료 칩 슬롯과 겹치지 않게 조정했다. 표시 설정은 캐릭터 장착과 별도로 유지한다. 모델이 없는 플레이어 방어구와 헬멧은 예전 임시 모델을 출력하지 않는다.

- 원래 StageA 씬 복귀는 `EDITOR_RETURNED.txt` 및 `after_editor.jpg`로 남긴다. 맵/전역 렌더링 정책과 사용자의 실제 저장은 변경하지 않았다.
