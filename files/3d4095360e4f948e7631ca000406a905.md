## 공통 미술·제작 판단

- 일곱 이미지 모두 단일 물체, 중성 배경, 명확한 3/4 형태다. 사용자 v0.7 콘셉트의 침수된 산업 정비지구와 D04의 녹슨 판금·회색 벽 어휘를 크게 벗어나지 않는다. 새 건물을 통째로 추가하지 않고 도크/포털/차양으로 기존 쉘의 **기능적 입면**을 만드는 방향이 맞다. 사진처럼 세밀한 녹·볼트가 많은 편이라 Unity 카툰 렌더에서 작은 표면 정보는 약해질 수 있다. 큰 경계·원통·프레임·개방 수조의 실루엣을 우선 보존해야 한다.
- **우선 통과 원화:** 도크, 포털, 터빈, 기계 접속장치, 침전조. **조건부 원화:** 차양은 탑뷰 차폐 해결 경로가 있을 때, 물탱크는 지붕 컷어웨이 또는 지상 슬롯 교체 대상이 정해졌을 때 생성 가치가 높다. 그렇다고 생성 화면 성공만으로 배치 승인한 것은 아니다.
- 모델 생성 뒤에는 최소 정면·3/4 윗면·후면을 비교한다. 특히 포털의 실제 빈 중앙, 터빈의 열린 상단·날개, 침전조 두 칸의 실제 안쪽, 차양 하부, 물탱크 받침/배관을 확인한다. Tripo 프리뷰의 화면상 face·vertex는 **서비스 표시값**이며 원본 GLB의 triangle/실치수/텍스처 품질·프레임 비용을 증명하지 않는다. 유료 재생성/리토폴로지 여부는 결과가 이 핵심 실루엣을 잃었는지에 따라 결정한다.
- 현행 맵에서는 기존 12개 V33 게이트·건물의 실제 문·중정비동·두 교량·B4/R8/W5 및 주요 도로를 보존해야 한다. `EXPANSION_REVIEW.md`의 좌표는 모두 검사 후보이며, 이번 원화 검토로 점유면/충돌/출입 안전을 입증한 것은 아니다.

### 제작 결과의 범위와 판정

- 추가 일곱 모델은 모두 비공개 2K 원본, ultra/AI 강화 off 설정으로 생성됐고 서비스 화면상 각각 30크레딧이 차감됐다. 시작 3200에서 기존 세 모델 120, 확장 일곱 모델 210으로 **총 330크레딧 사용·표시 잔액 2870**이다. 2,000은 허용 상한이지 소비 목표가 아니며 불필요한 재생성을 권하지 않는다. 도크/차양/포털의 수치와 네 모델의 수치는 **Tripo UI triangles/vertices**로만 취급한다. 목표 1만/터빈 1.6만/기타 8천~1만과 실제 결과를 혼동하지 않는다.
- 원화 대비 일곱 모델의 핵심 큰 실루엣은 프리뷰에서 유지됐다. **생성 화면 통과**는 정면·사선·일부 후면에서 형태를 확인했다는 제한적 판정이다. 원본 GLB·텍스처·피벗·정확 치수·UV·노멀·동적/정적 콜라이더를 독립 검사하지 않았고, Unity 실행·배치·실제 플레이 캡처·프레임 성능 시험도 하지 않았다. 따라서 A맵에 써도 안전하다는 **Unity 적합 판정은 아니다.**
- 배치 전에 우선 검사할 위험 순서는 차양/포털의 플레이어 가림과 원래 문 폭, 터빈 열린 면 방향과 성능, 침전조의 빠짐/갇힘, 도크 계단·철판의 보행 높이, 탱크 후면 보강대와 받침, 커플러 바닥 점유면이다. 기존 12게이트·두 교량·중정비동·B4/R8/W5·원본 충돌을 건드리지 않는 것을 전제로 한다.
