## 핵심 확인 결과

### 1. 중앙 landmark와 외곽 순환이 분리됨

- 선택형 지름길 S-A를 닫은 상태에서도 전체 공개 그래프는 1개 연결 성분입니다.
- 중정비동 노드 `HN/HW/HE/HS/H0/HU`와 `K0`를 동시에 제거해도 외곽 그래프는 1개 연결 성분을 유지합니다. 중정비동은 방향 landmark이지만 필수 통행 절단점이 아닙니다.
- 외곽 목적지 최단경로 144개 중 중앙 parcel을 이용한 경로는 13개(9.0%)였습니다. 중앙 강제 집중 징후는 발견되지 않았습니다.
- 두 교량을 하나씩 제거한 두 사례 모두에서 고립 노드가 생기지 않았습니다.
- 공개 그래프의 절단점은 `H0` 하나입니다. 이 절단점은 상부 통로 `HU` 가지만 분리하며 외곽 통행을 절단하지 않습니다.

### 2. 12개 스폰에서 공개 목적지와 7개 탈출로가 열려 있음

- 누적 스폰 풀은 4→8→12, 탈출구는 7개입니다.
- P01–P12 각각에서 `C1/T1/P1/L1/H0/Q(E2)`와 X1–X7까지, 총 156개 조합의 잠금 없는 경로가 모두 연결됩니다.
- 스폰의 짧은 attach 발끝을 제외하면 모든 스폰 접점에 2개 이상의 공개 방향이 있습니다. 여섯 공개 목적지 접점도 모두 2개 이상의 접근 방향을 갖습니다.
- P11은 `E2–BN2` 공개 연결 추가 후 attach 방향이 2개가 되어, 단일 진입 가지 문제가 해소됐습니다.
- 대안경로는 모든 조합에 대해 완전한 edge-disjoint를 요구하지 않았습니다. 지도 밖 스폰 attach 발끝과 실내 가지는 본질적으로 공유될 수 있으므로, 대신 양단 접근 방향·중앙 parcel 제거·교량 단일 장애를 독립 검사했습니다.

### 3. G1–G4가 공개 이동을 막지 않는 독립 가지로 정의됨

- 검증기에서만 `LOCKED:G1`–`LOCKED:G4` 노드를 각 gate의 공개 노드에 붙는 leaf로 파생했습니다. `layout.json`을 변형하지 않았습니다.
- 모든 unlock/local source는 잠금 없는 공개 노드이며, 요구 조건 ID가 다른 gate에 중복되지 않습니다. 자기 잠금실이나 다른 gate를 먼저 열어야 하는 순환 의존은 검출되지 않았습니다.
- 각 gate에 unlock source, 현장 local source, 최초 cue, prototype 조작시간 G1 8초/G2 25초/G3 20초/G4 20초가 정의돼 있습니다.
- G4 상층 접근로는 `HU`에서 시작해 `coreDoor`에서 끝나며, 도중에 잠금 core를 관통하지 않습니다.
- 단, cue 문구는 최초 진입 실시야를 증명하지 않으며 상호작용 취소·사망·재접속 상태 저장 규칙도 아직 검증되지 않았습니다.

## 중심선 검사와 폭/clearance 검사

### 중심선으로 통과한 항목

- bridge가 아닌 공개 edge의 water polygon 내부 관통: 0건
- outdoor edge의 건물 polygon 내부 관통: 0건
- 공개 edge의 같은 층 gate core 관통: 0건
- spawn/exit 좌표→attach 직선의 수면·건물·gate core 관통: 0건
- 두 bridge는 water polygon 내부를 통과하고 양 끝은 water polygon 밖에 있습니다.
- 모든 건물 문의 외벽 거리는 계획 좌표상 0m이며, 허용 오차 2m 이내입니다.

### 폭/clearance까지 확인한 항목

- non-bridge edge 반폭과 water polygon 간 clearance 충돌: 0건
- 공개 edge 반폭과 gate core 간 같은 층 clearance 충돌: 0건
- 회전된 V/C 차폐 polygon과 공개 edge 반폭 buffer 충돌: 0건
- V/C polygon의 맵 밖·수면·건물 중첩: 0건
- V4와 V6는 최신 좌표 보정 후 이전 도로 buffer 충돌 후보에서 제외됐습니다.

### 폭/clearance를 확인하지 못한 항목

- spawn/exit attach 구간은 schema에 폭이 없어 중심선만 검사했습니다.
- 여기서 사용한 edge 폭은 계획 수치입니다. 장애물 collider, 회전 여유, AI와 플레이어의 교행, 경사를 포함한 실제 잔여 통행폭은 입증되지 않았습니다.
- G4는 상층 z=6으로 판정했습니다. 다른 층의 2D 중첩은 같은 층 관통으로 잘못 판정하지 않도록 1.5m 수직 오차를 적용했습니다.

## 스폰 및 시간 검토

- 모든 스폰은 water/building polygon과 기계 encounter 반경 밖에 있습니다.
- C01–C12는 각 스폰에 정확히 하나씩 연결되고, 모두 스폰 중심에서 약 11.18m 거리에 있으며 최소 6×0.8×2.4m 치수를 충족합니다.
- 좌표상 가까운 위험 후보로는 P10이 M2 encounter 반경 밖 20.21m, P06과 P11이 H2 patrol 선형까지 각각 27.62m와 27.00m입니다. 이 수치는 안전 판정이 아니며 실제 시야·감지 거리 검증 우선순위를 정하는 지표입니다.
- 최악의 공개 목적 이동 사례는 `P07→C1→X1`, 748.37m입니다. 4m/s에서 187.09초, 3m/s에서 249.46초로 30분의 13.9%입니다.
- prototype 현장 조작을 포함한 최악 사례는 `P03→P0→G3 공개 접점→X4`, 이동 766.55m+조작 20초입니다. 총시간은 4m/s에서 211.64초, 3m/s에서 275.52초로 30분의 15.3%입니다.
- 이 시간은 최단경로 이동+제안된 현장 조작만 합산합니다. 적의 감지, 전투, 숨기, 수색, 길 찾기, 회복, 실패 후 우회를 포함한 레이드 완주 시간을 보장하지 않습니다.

## 가장 중요한 잔여 위험

1. **실제 통행 가능 폭과 경사**: 중심선과 계획 반폭 충돌은 0건이지만 collider·경사·회전반경·교행을 포함한 NavMesh 가용폭은 알 수 없습니다. 특히 attach 구간은 폭 데이터도 없습니다.
2. **스폰 시야·AI 감지**: C01–C12의 좌표와 치수는 있지만 실제로 스폰에서 적을 차폐하는지는 미검증입니다. P10–M2, P06/P11–H2를 먼저 확인해야 합니다.
3. **조건 획득과 현장 조작의 실제 경험**: 획득처·cue·임시 조작시간은 정의됐으나 단서 가시성, 상호작용 취소/중단, 상태 저장, 소음에 따른 실제 노출은 입증되지 않았습니다.
4. **전투·수색을 포함한 risk traverse**: 이동시간은 레이드의 15.3% 이내였지만 이 수치로 초보자의 실제 외곽 임무 완주를 보장할 수 없습니다. 패스별 적 밀도·시야 노출·소모품 부담을 반영한 플레이테스트가 필요합니다.
