# 세린 머리·눈썹·속눈썹 텍스처 정리 (Blender 원본)

## 사용자 지시 요약

- 세린 머리카락의 흰 점, 눈썹·속눈썹 경계를 고친다.

## 기획 의도와 해결하려는 문제

- 아틀라스 한 장을 여러 파츠가 공유하면서, 일부 UV가 엉뚱한 영역(흰색·피부색)에 떨어져 얼굴 가까이서 눈에 띄는 텍스처 미스가 생겼다.

## 진행 회차

- **머리카락**: 머리 UV 일부가 아틀라스의 흰색/피부색 영역과 겹침 → 머리 전용 텍스처에서 해당 픽셀을 주변 머리색으로 채움.
- **눈썹 (v3)**: 눈썹 UV 섬이 입술·가슴 피부 영역에 가는 띠로 흩어져 있음 → 원래 UVMap을 다시 펼쳐 아틀라스 빈 공간에 놓고 눈썹 색을 칠함(약 3200px/m).
- **속눈썹 (v4)**: 모델링이 아니라 UV 문제. 삼각형 413개 중 약 104개가 피부/흰색 영역에 있음 → 정면 투영으로 다시 펼쳐 빈 곳에 배치(2600px/m).
- **확인**: 앞머리 위로 눈썹이 비친다는 의심은 광선 검사·렌더 비교로 앞머리 틈 사이 이마 그림자임을 확인. 수정 없음.

## 결과

- 머리 흰 점 제거, 눈썹·속눈썹 경계 정리.
- 메인 아틀라스 `Serin_BaseColor_v08_BrowLash`.

## 한계 / 확인하지 못한 것

- 새 눈썹·속눈썹 텍스처는 단색 계열(원래의 붉은 하이라이트 디테일 없음).
- 게임 적용·직접 플레이 확인 없음.
