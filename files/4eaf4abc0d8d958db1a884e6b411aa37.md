# 캐릭터 외형 유지 지침

- 사용자 요청(2026-09-04): 헬멧 아래로 보이는 뒷머리는 해당 캐릭터의 원래 머리색을 유지한다. 앞으로 캐릭터 모델을 교체하거나 추가할 때에도 적용한다.
- 노출되는 머리카락과 빈 두상을 보완한 헤어 메시에는 해당 캐릭터의 헤어 재질·텍스처를 사용한다. 검정·갈색·헬멧 안감 색을 공통으로 지정하지 않는다.
- 새 모델의 헤어 구조가 다르면 원래 헤어 재질과 UV 연결을 명시적으로 설정하고, 헬멧 착용 전후의 측면·후면을 확인한다.

# 작업 전후 증빙 및 기획 기록 지침

- 사용자 요청(2026-09-10): 이 규칙은 익스트랙션 프로젝트의 현재 작업과 앞으로 수행하는 모든 작업에 공통으로 적용한다.
- 사용자의 변경 지시를 받으면 실제 수정에 착수하기 전에 변경 대상의 현재 상태를 스크린샷으로 저장하고, 작업 완료 후 결과 상태도 스크린샷으로 저장한다.
- 전후 비교가 정확하도록 가능하면 동일한 화면, 카메라 위치, 캐릭터 자세, 조명, 해상도, UI 표시 상태 및 배율을 유지한다. 한 화면으로 확인이 부족하면 정면·측면·후면·상세 등 필요한 시점을 각각 남긴다.
- 스크린샷은 `outputs/change_records/YYYY-MM-DD/<작업명>/` 아래에 보관한다. 파일명은 대응 관계가 분명하도록 `before_<시점>.png`와 `after_<시점>.png` 형식을 사용한다.
- 같은 폴더의 `CHANGE_RECORD.md`에 아래 항목을 기록한다.
  - 사용자 지시 요약
  - 기획 의도와 해결하려는 문제
  - 변경 전 상태 및 문제점
  - 실제로 바꾼 부분
  - 어떤 방식으로 변경했는지
  - 변경 후 기대 효과와 확인 결과
  - 관련 스크린샷 파일명 및 서로 대응하는 비교 시점
  - 수정한 주요 파일 또는 에셋
- 작업 시작 전 상태를 확보하지 못한 경우 사후 이미지를 전 이미지로 위장하지 않는다. 원본·백업·버전 기록으로 상태를 정확히 복원할 수 있을 때만 `before_reconstructed_<시점>.png`로 저장하고, 기록에 재구성본임을 밝힌다. 복원이 불가능하면 누락 사유를 기록한다.
- 코드·설정처럼 변화가 화면에 직접 드러나지 않는 작업도 가능한 한 실제 게임/도구에서 그 효과를 보여 주는 전후 화면을 남긴다. 시각적 차이가 전혀 없는 작업은 관련 확인 화면을 저장하고 기록에 그 사실과 별도의 검증 결과를 적는다.
- 작업 완료 보고 전, 전후 스크린샷과 `CHANGE_RECORD.md`가 모두 저장되었는지 확인한다.
