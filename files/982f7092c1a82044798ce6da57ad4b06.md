# A맵 68동 Blender 후보 통합 계약

현재 상태: 현 Unity 활성 68동의 실측 원본·메타데이터·보호 체적을 결합한 저작 `.blend` 68개와 Shell/Roof/Interior FBX 204개가 생성됐다. 개별 독립 Blender 재반입 68/68 PASS, `EXPORT_INDEX.json` 집계 PASS, `DELIVERY_AUDIT.json` 파일·해시 재감사 PASS다. W10은 2026-10-26 검증된 샘플을 보존했다. 메인은 Unity 실제 68동 적용·bounds/triangle/material 검사를 수행했고, 게임 시각·문·Nav·성능 최종 검증은 계속 진행 중이다.

- `main/current_geometry/INDEX.json` + 68개 ID JSON은 실제 active D09/D10/D15/Tripo renderer의 현재 정점/normal/UV/submesh/material GUID를 담는다. 2,541 leaf/1,062,973tri가 원본 기준이며 과거 D09 저작 source의 삼각형을 기준으로 덮지 않는다.

Unity 실제 PlayerMotor/Nav/시야 검증 전까지 새 방 후보 승격 금지.

## FBX 규칙

- `blender/export/<ID>/<ID>_Shell.fbx`, `<ID>_Roof.fbx`, `<ID>_Interior.fbx`와 `<ID>_Authoring.blend`, `EXPORT_MANIFEST.json`, `ROUNDTRIP_VALIDATION.json` 생성. Unity 복사 목적지는 `Assets/Escape/Art/BlenderEnvironmentExpansion/Buildings/<ID>/<ID>_<Group>.fbx`.
- 각 FBX 원점0/회전 identity/scale1, `metresPerUnit=1`. Blender 저작 좌표는 Unity-local `(X,-Z,Y)`이고 FBX export `axis_forward=-Z`, `axis_up=Y`, global scale1. **FBX 복제 메시만 X 반사·면 순서·UV loop 반전**해 Unity의 실제 import X 반사를 상쇄한다. Unity ModelImporter `useFileScale=true`, 프리팹 추가 scale1. 음수 scale 배치 금지.
- `Shell`/`Roof`/`Interior` FBX별 자식은 `<ID>_<Group>_renderOpaque`, `<ID>_<Group>Stain_renderStain`(있을 때), `<ID>_<Group>_colliderOnly`(있을 때)로 묶는다. `renderStain`은 renderer shadow Off·collision 없음·기존 D10 stain material 유지. `colliderOnly`는 renderer Off·정적 비볼록 MeshCollider로 쓰고 재질 슬롯은 없다. 원래 Collider 없는 source leaf는 colliderOnly에 복제하지 않는다. 새 방 유리/문틀·주요 설비는 별도 role로 collisionSuggested를 기록한다.
- `EXPORT_MANIFEST.json`의 `groups[].objects[]`는 mesh 이름, role, Unity material `{name,guid,localFileId,assetPath,role}`, 실제 vertex/triangle/submesh 수, `localBoundsUnity`와 `worldBoundsUnity`, collider pair를 포함한다. `geometryRecipe`, `candidateRoomDoorWitness`, `protectedDoors`, source renderer shadow/queue도 담는다. `totals`는 render와 collider 삼각형/객체를 따로 센다.
- shell/interior는 기존 D09Facade 부모 아래 새 root로, roof는 기존 D09Roof 부모/roof cutaway 아래 새 root로 넣고, 각 새 root의 **세계 TRS는 해당 건물 `geometryFrame`**에 맞춘다. 실제 parent-local 변환은 현 Unity Transform에서 계산한다. W10과 68동 모두 기존 비D09 바닥·가구·loot·door/NPC roots는 유지한다. 랜드마크 CLINIC/HALL/PARTS/POWER/TOOLS는 Foundation 경로가 없으므로 비D09 시각 subtree를 전체 보존하고 현재 planning grid의 바닥 collider support 경로를 유지해야 한다.
