# 공통 테마의 개별 화면 적용 기록

상태: 표시 코드 패치와 독립 문법·범위 검사 완료. 메인이 실제 Unity 재컴파일 및 after_r02 캡처를 수행했으며, 이 담당자는 아래 세 화면을 실제 파일로 확인했다. 최종 실입력 검증은 메인 진행 중이다.

## 지시와 의도

사용자가 인벤토리 캐릭터 영역 확대와 남은 UI 키트 완성 및 Unity 적용을 승인한 범위에서, 기존 화면의 딱딱한 사각 카드와 가시성이 낮은 표면을 최신 Figma의 큰 라운드·잉크 글라스·밝은 글자 체계로 맞춘다. 이 담당자는 개별 화면의 표시 코드만 수정하며, UiTheme 공통 구현은 메인, Inventory 및 티어/능력 HUD는 별도 담당자가 소유한다.

## 변경 전 증빙

실제 수정 전 메인이 `before_r02_*_1920x1080.png` 34장을 캡처하고 SKIP/ERROR/bounds 위반 0을 확인한 뒤 코드 수정을 시작했다. 담당 원본 9개를 먼저 `source_before/Assets/Escape/Runtime/` 아래 상대 경로로 복사했다. 이 기록은 새 before 캡처를 직접 수행했다고 주장하지 않는다.

직접 확인한 이전 화면은 `before_r02_supply_1920x1080.png`이다. 기존 보급소의 제품 목록은 개별 제품 면 구분이 약하고 사각 외곽이 남아 있었다.

## 유지 범위와 확인

- Unity 제공 Roslyn으로 담당 9개 파일을 C# 9 구문 분석: 오류 0.
- AST 비교 결과 허용한 표시 메서드 20개만 변경. 나머지 메서드 117개와 모든 프로퍼티가 원본 그대로다.
- 모든 lambda 콜백과 실제 문자열/보간 문자열 텍스트가 원본과 동일하다.
- 유일한 필드 변경은 연구 표시용 `researchMint`를 공통 Accent로 연결한 것이다.
- SessionTestWorld의 저장·경제·출격·월드 함수는 바꾸지 않았다.
- 지도 이미지·좌표 변환·floor·zoom/pan·waypoint·표식 배치·필터 동작·입력 처리와 cutscene 진행/저장/타이밍·전체 폭 letterbox를 유지했다.
- 기존 연구 재료용 unpadded 28px 행과 현재 CompanionAbilityCatalog의 이름/설명을 보존했다.
- 네이티브 앱/Figma/Unity UI를 이 담당자가 조작하지 않았다.

검사 도구와 결과는 `presentation-audit/`, `presentation-patch-manifest.json`에 있으며, 해당 검사는 전체 런타임 컴파일 및 실제 화면 테스트를 대신하지 않는다. 수정 결과 원본은 `source_after/Assets/Escape/Runtime/`에 보존했다.

## 전후 화면 대응과 남은 확인

### 실제 확인한 after_r02

- `after_r02_lobby_1920x1080.png`: 주/보조 버튼과 카드의 읽기 순서, 초상 영역, 시계와 무기·준비 상태 텍스트를 확인했다. 하단 조작 버튼과 시계 카드 사이 새 겹침은 보이지 않는다. 작전명 상단 행의 공백은 before_r02에도 같은 상태이며 이번 패치로 생긴 누락으로 분류하지 않았다. 작전명은 시계 오른쪽에 표시된다.
- `after_r02_supply_1920x1080.png`: 보이는 상품 이름·가격·구매 버튼은 읽히며 개별 카드와 목록 영역이 구별된다. 9-slice 수정 후 검색/분류/구매 버튼의 테두리 겹침이 줄어든 것을 확인했다. 목록 맨 아래의 일부 노출 상품은 스크롤 뷰포트 경계다. 통화 칩은 메인이 추가 교정 후 재캡처할 예정이므로 해당 최종 상태는 별도 확인 대상이다.
- `after_r02_story_dialogue_1920x1080.png`: 화자 이름·대사·진행 안내·하단 버튼이 읽히고, 새 텍스트 겹침이나 잘림은 보이지 않는다. 대사 원문과 초상 배치를 유지한다.

위 판정은 보이는 정적 상태의 시각 검토다. 이 담당자가 실제 구매/저장/출격/대화 진행 버튼을 조작하거나 전체 34개 상태를 독립 검증했다고 주장하지 않는다. 최초 after 이미지도 덮어쓰지 않고 보존하며, after_r02가 새 비교 실행이다.

나머지 담당 화면과 실제 입력은 메인 통합 검증에서 확인한다. 동일한 1920×1080 상태의 before 대응은 다음과 같다.

- 로비: `before_r02_lobby_1920x1080.png`
- 출격/보급/저장: `before_r02_departure_1920x1080.png`, `before_r02_supply_1920x1080.png`, `before_r02_save_records_1920x1080.png`
- 연구/능력/복원/의뢰: `before_r02_research_1920x1080.png`, `before_r02_companion_abilities_1920x1080.png`, `before_r02_chip_recovery_1920x1080.png`, `before_r02_quests_1920x1080.png`
- 보관함: `before_r02_storage_1920x1080.png`, `before_r02_storage_details_1920x1080.png`
- 프론트엔드: `before_r02_title_1920x1080.png`, `before_r02_new_slot_confirmation_1920x1080.png` 등 슬롯/전환 상태
- 대사: `before_r02_story_dialogue_1920x1080.png`, `before_r02_story_history_1920x1080.png`, `before_r02_story_skip_confirmation_1920x1080.png`
- 지도/작전 메타: `before_r02_tactical_map_1920x1080.png`, `before_r02_combat_hud_1920x1080.png`

전체 작업의 사용자 지시·실제 실행·최종 전후 증빙은 메인이 소유한 같은 폴더 `CHANGE_RECORD.md`에서 통합한다. 이 파일은 개별 표시 패치 담당 기록이며 전체 UI 키트 완료 선언이 아니다.
