# 에델 눈 라인·얼굴 분리 자료 압축 기록

## 사용자 지시 요약

최근 ChatGPT 대화에서 요청된 에델 눈 라인·얼굴 분리 작업에 사용할 `.blend`, 관련 텍스처, 이전 수정 자료를 ZIP으로 묶어 전달한다.

## 기획 의도와 해결하려는 문제

전체 작업 폴더는 211개 파일, 약 2.1GB로 중복 백업과 여러 중간 산출물이 포함되어 있어 채팅 업로드에 비효율적이다. 실제 분리 작업에 필요한 기준본과 비교 자료만 선별해 하나의 업로드용 패키지로 구성한다.

## 변경 전 상태 및 문제점

- 기준본 `edel_parts_baseline.blend`, v8~v10 참고본, 텍스처와 검증 자료가 여러 경로에 분산되어 있었다.
- 업로드용 ZIP은 존재하지 않았다.
- 원본 작업 폴더 전체를 압축하면 약 2.1GB라 전송과 확인이 불편했다.
