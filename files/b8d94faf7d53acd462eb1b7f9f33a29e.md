# 델타포스 참조 인벤토리 배치·크기 조정

## 사용자 지시와 기획 의도
2026-10-12 사용자가 첨부한 델타포스 인벤토리 화면을 참조하여 현재 익스트랙션 게임의 인벤토리 레이아웃과 화면상 크기를 비슷하게 수정하도록 요청했다. 첨부 이미지는 `reference_deltaforce.png`에 보관했다.

참조 적용 범위는 화면 배치, 패널 비율, 칸의 표시 크기와 정보 밀도다. 기존 게임의 가방·퀵슬롯·장비·전리품·창고 기능을 사용하며, 참고 게임의 체스트 리그나 금고 등 별도 수납 시스템을 새로 도입하는 작업은 아니다.

## 변경 전 상태
왼쪽 캐릭터는 작은 초상으로 표시되고 장비는 넓은 가로 버튼으로 나열되어 있었다. 1600×900 기준 가방 패널 폭은 524, 격자 한 칸은 최대 76픽셀이었다. 오른쪽의 빈 전리품과 상세 패널이 화면의 넓은 영역을 계속 차지했다. 큰 둥근 카드와 제목 때문에 참조 화면보다 정보 밀도가 낮았다.

실제 원본 Unity에서 수정 전에 `before_field_inventory.png`, `before_field_detail.png`를 촬영했다. `before_source/`와 `before_source_hashes.csv`에 4,846개 관련 파일을 보관했다. 사용자 저장은 별도로 복사하고 해시를 기록했다.

## 변경 방식
실제 프로젝트는 `C:\UnityProject\escape`다. GPT-6.1 Sol extra high 구현 에이전트와 별도의 동일 모델·추론 수준 검토 에이전트로 작업을 분리했다. 메인이 기획, 통합, 실행 검증 및 전후 화면 비교를 맡는다.

큰 캐릭터 영역, 분리된 장비 슬롯, 중앙의 폭이 좁은 수납 패널, 상황에 따라 표시되는 오른쪽 정보 패널을 구성한다. 현재 가방 용량과 개별 아이템의 점유 칸 수는 그대로 두고 화면에서 차지하는 픽셀 크기를 조정한다. 가방의 기준 칸 크기는 1600×900에서 60픽셀로 설정한다. 많은 열을 가진 창고는 전체 열을 볼 수 있도록 패널 폭에 맞춰 칸을 줄인다.

## 실제 변경
- 캐릭터의 표시 영역을 406×690 기준으로 넓히고, 122×122 방어구 슬롯을 오른쪽에 세로 배치했다. 무기 두 개는 아래쪽 238×84 카드로 배치했다.
- 중앙 가방 패널 폭을 524에서 412로 줄이고, 퀵슬롯 3개를 가방 위의 한 줄로 옮겼다. 가방 한 칸은 76에서 60픽셀로 약 21% 작아졌다.
- 전리품 6열은 약 56.67픽셀, 창고 10열은 49.8픽셀 칸으로 모든 열이 보이도록 조정했다. 가방·전리품·창고가 같은 좌표 계산으로 표시와 드롭을 처리한다.
- 인벤토리 전용 사각 패널, 얇은 테두리, 작은 제목과 글꼴을 적용했다. 기존 로비와 일반 HUD 스타일은 별도로 유지한다.
- 빈 전리품 창은 높이 112픽셀의 안내만 표시한다. 상세 정보는 선택했을 때 표시하고, 열린 전리품·창고가 있으면 높이를 조절하여 아래에 상세 창을 배치한다.
- 캐릭터 회전 입력이 겹쳐 보이는 무기 카드를 가로채지 않도록 제외했다. 새 방어구 슬롯의 장착 부위 판정을 맞췄다.
- 독립 검토에서 발견한 상단 도움말과 닫기 버튼의 겹침을 해결하고, 공통 제목 글꼴 변경이 로비에 영향을 주지 않도록 복원했다.

## 검증 결과
- `EscapeGlassLayoutChecks.txt`: 실제 Play Mode의 101개 UI 검사 통과. 새 패널 비율, 칸 크기, 해상도별 영역, 캐릭터/무기 클릭 구분, 실제 방어구 장착, 아이템 이동, 퀵슬롯, 패널 전환과 기존 세션 흐름을 검사했다.
- 위 검사 이후 마지막 도움말 표시 조건과 공통 제목 글꼴 복원은 독립 검토를 거쳐 `after_final_build.log`의 Windows 빌드에서 최종 컴파일했다. 빌드 성공, 컴파일 오류 없음.
- `after_visual_results.txt`: 1600×900, 1280×720, 2400×1440 화면 촬영 및 렌더링 중 런타임 오류 없음. 2560×1440 요청은 화면 한계로 2400×1440에 적용됐다.
- 메인이 원본 Unity에서 정상 재질의 실제 캐릭터·배경, 줄어든 격자, CAT 지혈대 상세 창을 확인했다.
- 원본 Unity에서 가방의 2×2 헬멧을 새 헬멧 슬롯으로 드래그하여 장착 성공을 확인했다. 가방 사용량은 27칸에서 23칸으로 줄고 장비 내구도 40/40이 표시됐다. 이후 상단 닫기 버튼으로 정상 게임 화면 복귀를 확인했다.
- `INDEPENDENT_REVIEW.md`: 별도 GPT-6.1 Sol extra high 검토 후 남은 조치 필요 코드 문제 없음.
- `changed_source_hashes.csv`: 기존 파일 8개 수정. 게임 규칙·아이템 카탈로그·저장 로직·맵·씬·모델·재질은 변경하지 않았다.
- `original_saves_preservation.csv`: 사용자 저장 3개와 잠금 파일 2개의 해시가 작업 전과 동일함을 확인했다.

## 주요 수정 파일
실제 프로젝트 `C:\UnityProject\escape\Assets\Escape` 기준:

- `Runtime/Inventory/InventoryTestWorld.cs`: 선택 상세 창의 크기와 버튼 배치

- `Runtime/Stage/SessionInventoryPresentation.cs`: 창고 검색·필터·정리·회수 버튼 배치
- `Runtime/Loot/LootInteractor.cs`: 전리품 창과 조작 버튼 배치
