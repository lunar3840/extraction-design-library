# 네임드 체력바 이름표 독립 검토

- 실제 A맵 Play 화면의 `before_nameplate_N1.png`와 `after_nameplate_N1.png`를 같은 카메라에서 비교했다. 일반 체력바 위에 빨간색 굵은 한글 이름 **볼트**가 또렷하게 나타난다.
- `before_nameplate_N5.png`와 `after_nameplate_N5.png`도 같은 카메라에서 비교했다. 높이 3.6m의 중장비형 **감독관**에 맞춰 체력바와 이름을 위로 올렸고, 벽이 본체 일부를 가리는 화면에서도 글자를 읽을 수 있다. 두 장면 모두 이름이 체력바 바로 위에 표시된다.
- 출격 생성 코드는 네임드 후보에만 `ConfigureNamedIdentity`를 호출한다. 일반 적은 이름 문자열이 비어 있으므로 기존 체력바만 그린다. 카탈로그의 N1~N5 대응은 볼트·롤백·차단기·봉인자·감독관으로 기획 명단과 일치한다.
- 이름과 체력바는 같은 `OnGUI` 입구를 사용한다. 시야에서 숨김, 인벤토리 열림, 카메라 뒤, 사망 시 둘 다 표시하지 않는 조건을 코드에서 확인했다. 이 네 조건은 별도 화면 캡처로 직접 검증하지 않았다.
- `after_nameplate_capture.txt`는 두 변경 후 화면 저장을 통과로 기록했다. `ELITE_REPLACEMENT_CHECK.txt`는 같은 프레임의 출격 교체에서 이전 58개와 새 58개가 잠시 등록되어도 실제 활성 적이 새 58개뿐임을 확인했다.
- `ELITE_DAMAGE_CHECK.txt`는 실제 `TryAttack`의 몸통 적중으로 기본 피해 10과 배율 0.8 피해 8을 기록했다. 이는 UI와 별개의 전투 완화 연결 검증이다.

검토 한계: N5의 몸체 일부는 카메라와 구조물 사이의 벽에 가려져 있다. 이름과 체력바는 뚜렷하게 보이지만, 이 화면만으로 본체 전체 외형을 평가하지는 않는다. N2~N4의 이름 철자는 카탈로그와 생성 호출을 확인했으며, 개별 Play 화면을 찍지는 않았다.
