# 인간형 적 4면도 — 기존 캐릭터 인체 비율에 맞춘 수정

- 사용자 지적: 기존 게임 캐릭터에 비해 제작한 적의 인체 비율이 다르게 보인다.
- 확인: outputs/Serin_TPose_front_compact.png, outputs/Serin_front_separate_v2.png, 기존 세린 3D 렌더, 2026-09-21 캐릭터 기록에서 참조한 에델 자료를 직접 열람했다. 실제 캐릭터는 머리가 크고 몸통과 팔다리가 짧은 반면, v01 적은 머리가 상대적으로 작고 몸통·팔다리가 길다.
- 원인: 최초 적 콘셉트에서 실제 세린·에델 이미지를 직접 참조하지 않고 글로만 3.5~4등신 SD를 지시했다. 이후 잘못된 적 디자인을 기준으로 4면도를 확장했다. 기존 캐릭터와 비율 검증을 했다는 표현은 부정확했다.
- 수정 의도: 세린의 T포즈 원본을 직접 비율 참조로 사용해 머리 비중과 어깨·골반·손·발 위치를 맞춘다. 적 클래스의 차이는 의상, 장비, 몸통 너비로 표현한다. 기계형 적이나 Unity 장면은 범위 밖이다.
- 변경 전 자료: before_*_tpose_front/back/left/right.png 총 12장. 변경 대상 원본의 복사본이며 실제 화면 캡처가 아니다. reference_serin_tpose.png와 reference_serin_front.png는 비교 기준 원본 복사본이다.
- 화면 증빙 한계: 이전에 브라우저/컴퓨터 화면 접근이 차단되었고 이번 수정 대상은 독립 이미지 파일이다. 원본 복사본을 스크린샷이나 동일 카메라의 3D 렌더라고 표현하지 않는다.
- 제작 방식: 내장 image_gen으로 v02 별도 폴더에 제작한다. 기존 v01은 전 상태 자료로 보존한다. 정면을 먼저 세린 참조에 맞춘 뒤 각 정면으로 후면·좌우를 맞춘다. T포즈, 빈손, 흰 배경, 방향별 개별 PNG를 유지한다.
- 작업 상태: 3종의 정면·후면·좌측·우측 PNG 총 12장 수정 완료.

## 실제 변경과 검토

- 머리/마스크 비중을 키우고, 몸통과 상·하완, 허벅지·종아리를 함께 짧게 재구성했다. 머리만 크게 붙이고 기존 긴 몸을 남기는 방식은 사용하지 않았다. 짧아진 몸에 맞춰 배낭과 세로로 겹친 파우치도 줄였다.
- 수색병의 청회색 후드와 비대칭 어깨 장비, 돌파병의 헬멧·갈색 재킷·산탄 띠, 중화기병의 두꺼운 목 보호대·넓은 흉갑·큰 배낭은 구분되게 유지했다.
- 정면과 후면은 세린의 해당 T포즈 이미지를, 왼쪽 측면은 세린의 측면 T포즈 이미지를 실제 참조로 넣었다. 오른쪽은 수정된 해당 캐릭터의 정면·후면·왼쪽을 참조했다.
- 신규 이미지 12장을 생성 결과로 직접 확인했다. 모두 전신·빈손·T포즈·불투명 흰 배경이며 손끝과 발바닥이 프레임 안에 있다. 후면에 얼굴이 없고 측면은 인물 본인의 좌우에 대응한다. 돌파병과 수색병의 큰 왼쪽 어깨판/작은 오른쪽 패드도 구분했다.
- 정면 근사 검증: 세린의 모자 위~턱 / 전신 높이가 약 40%, 기존 적의 머리 덮개 위~마스크 아래 / 전신 높이는 약 19%, 수정 정면은 수색병 약 39%, 돌파병 약 41%, 중화기병 약 41%다. 육안으로 고른 이미지 픽셀 기준점의 계산이며 실제 모델 두개골·리그 치수 또는 엄밀한 등신 측정은 아니다.
- COMPARISON.html에 세린, v01, v02를 같은 전신 높이로 표시했다. 원본을 내장한 HTML 비교 문서로서 래스터 원본을 변형하지 않았다. PROPORTION_CHECK.json에 근사 기준점과 계산을 남겼다.
- 시점별 머리 깊이, 장비 위치, 손가락과 주름에는 생성 이미지의 작은 차이가 남는다. 3D 회전 렌더와 동일한 정확도라고 주장하지 않는다. 실제 모델 생성·리깅 검증은 수행하지 않았다.
- PNG 12장은 모두 1254×1254이고, 각 캐릭터 폴더에 최종 PROMPTS.md를 저장했다. MANIFEST.json에 파일 크기·해상도·해시를 기록했다.
- 후 증빙은 after_*_tpose_front/back/left/right.png 총 12장으로, 같은 이름의 before_*와 대응한다. 원본 파일 복사본이며 화면 캡처가 아니다.
