# 로컬 기획 라이브러리 및 Chat 날짜 정정

작성일: 2026-10-23 KST.

## 사용자 지시와 기획 의도

날짜 오류를 수정하고, 제안한 카테고리로 Codex·시나리오 Chat 작업의 기획/수정 이력/전후 스크린샷/원문을 연결하는 로컬 웹 라이브러리를 구현한다. 분산된 기록을 분야별로 찾아 변경 이유와 근거를 확인할 수 있도록 한다.

## 변경 전 상태

새 웹 라이브러리는 없었다. Chat 대조표와 날짜순 보존문서의 startedAt 초 값을 밀리초로 처리해 1970년으로 표시했다. 원본 JSON의 숫자 시각은 정상이며 변경하지 않았다. 수정 전 CSV와 8개 TRANSCRIPT는 source_before에 보존했다.

## 실제 변경과 방식

- 원본 startedAt에서 UTC 날짜를 재계산해 지시 54행과 대화 8개 문서의 날짜를 apply_patch로 정정했다.
- planning-library에 별도 설치가 필요 없는 Node 로컬 서버와 웹 UI를 추가했다. 원문은 읽기 전용으로 제공하고, 분야·출처·증빙·내용 검색과 페이지 단위 추가 표시를 지원한다.
- 날짜 정렬, 문서별 상세, 원문·관련 파일 링크, 같은 파일명 시점의 before/after 비교 및 이미지 목록을 연결했다. 제안·중단·미확보 설명은 원문 그대로 유지했다.
- ‘최신 기록 읽기’로 로컬 색인을 갱신한다. 원격 대화 자동 수집은 아니다. 통계는 문서/지시 행 수이며 독립 구현 개수는 아니다.

## 검증과 화면 증빙

문법 검사와 실제 HTTP 응답, Chat 원본 시각 대조, 대표 미니맵 전후 파일과 원문 링크, 허용 범위 밖 파일 접근 차단을 검증한다. 결과는 VERIFICATION.json에 보존한다.

현재 도구에 연결된 브라우저가 없었다(iab unavailable, browser inventory empty). 따라서 실제 브라우저 화면의 육안 확인과 전후 스크린샷을 확보하지 못했다. 신규 사이트의 과거 화면을 만들어 before로 제시하지 않는다. 날짜 수정 전 원문은 source_before로 보존했으나 이는 스크린샷이 아니다. 기능 검증 통과를 화면 품질 검증 완료로 확대하지 않는다.
