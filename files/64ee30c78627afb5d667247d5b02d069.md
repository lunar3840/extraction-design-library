# A맵 광원·표면 그래픽 V31

2026-10-07. 광원·재질 변경을 저장하고 재로드한 뒤 실제 플레이 재검사를 완료한 기록입니다. 대규모 아트 교체가 아닌 기존 표현의 점진적 개선입니다.

## 사용자 지시와 의도

추가 그래픽 개선을 찾아 실제 반영하고 광원을 현실적으로 개선합니다. 실제 제작은 GPT-6 Sol high 병렬 담당자에게 분리하고 메인은 방향·통합·최종 검증을 담당합니다.

## 기준 상태와 보호 범위

같은 날 D03 최종 기록의 씬·프리팹 SHA256과 현재 파일이 일치합니다. 공유 Unity는 편집 모드이며 D03 최종 저장/재로드 완료 기록을 확인했습니다. 새 배치 101개 및 기존 건물·소품·동선·콜라이더·진입/탈출은 유지합니다. B맵과 캐릭터 원래 머리 재질은 수정하지 않습니다. 과거 기록·증빙을 덮어쓰지 않습니다.

변경 전 Unity 화면은 before_editor.png로 저장했습니다. 전후 같은 고정 카메라 및 실제 게임 시점은 별도로 확보합니다. backup에는 변경 대상 소스와 V16/V23 재질·셰이더 원본을 보존합니다.

## 발견한 개선점과 계획

- V16/V23의 일부 콘크리트 재질은 노멀 텍스처를 참조하지만 실제 노멀 키워드가 꺼져 있습니다. 매핑 방향을 확인해 요철에 대한 빛 반응을 활성화합니다.
- 금속 작업면·계단의 반사 거칠기가 균일합니다. 기존 형태와 도색 범위를 유지한 채 표면 반응을 구분합니다.
- A맵 기본 환경광과 중심 공장 지역 환경광을 조율합니다. 단순히 노출을 올리는 대신 햇빛과 하늘빛의 면별 차이를 살립니다.
- V25의 밝기 경계 수정(지역 톤매핑 상속)은 유지하고 네 방향 경계를 별도 재검사합니다. 공용 렌더 파이프라인 설정은 바꾸지 않습니다.

## 실제 변경

1. A맵 햇빛을 약간 따뜻한 색으로 조정하고 세기를 1.4에서 1.5로 변경했습니다. 하늘·수평선·지면 주변광을 각각 조율하여 햇빛을 받는 면과 그늘의 방향 차이를 살렸습니다. 중앙 공장 지역 조명도 이 기본 조명에 가깝게 맞췄습니다. 구체적 수치는 LIGHTING_IMPLEMENTATION.md에 있습니다.
2. 기존 노멀 텍스처가 있는 콘크리트·공장 외벽·앞마당 재질 14개에서 실제 요철 조명 반응을 활성화했습니다. 강도를 .48/.55로 제한하고 원래 UV 방향을 유지했습니다. 금속 계단·안전벽·작업대는 색과 무늬를 유지하며 반사 거칠기에 미세한 공간 차이를 더했습니다. 목록은 MATERIAL_IMPLEMENTATION.md에 있습니다.
3. 재질 생성 코드를 다시 사용할 때 개선된 설정이 사라지지 않도록 보존 코드를 추가했습니다. 이번에는 기존 배치 생성 도구를 실행하지 않았습니다.

태양 방향·그림자 거리·공용 URP 설정·지역 톤매핑·노출·블룸·반사 프로브는 그대로입니다. 임의의 추가 점광원, 새로운 소품, 새 메시·텍스처는 넣지 않았습니다. B맵 조명은 변경하지 않습니다.

## 검증과 반복 과정

- 적용 전 백업 및 실제 편집기 고정 시점 7장, 게임 시점 16장을 확보했습니다. 컴퓨터 사용 스킬로 Unity 편집 상태를 확인하고 편집기 UI 전후 화면도 별도 보존했습니다.
- 첫 사후 외부 전체 화면에서 건물·지붕 일부가 누락되어 해당 화면은 비교 근거에서 제외했습니다. 첫 실제 Play 동쪽 경계도 지붕/층판 표시가 달라 휘도차 .028582로 실패했습니다. 원본 실패 결과는 iteration01/에 보존했습니다.
- 촬영 도구에서 기존 가시성 캐시를 재구성하고 편집기 각 시점의 예열 렌더 후 본 화면을 촬영하도록 보강했습니다. **실제 게임의 가시성 코드는 수정하지 않았습니다.** 첫 Play 이상 원인은 확정하지 않았으며 초기 렌더 상태의 영향으로 추정합니다. 문턱값을 완화해 통과시킨 것은 아닙니다.
- 2차 실제 Play 검사에서 네 경계 모두 휘도차 약 .000001, 오류 0으로 통과했습니다. 해당 결과는 validation02/에 보존했습니다.
- 18:23 A씬 저장·재열기 후, 18:23:59 새 Play 검사를 다시 시작했습니다. 최종 after_PLAY_VALIDATION.txt는 4방향 경계와 28m 보간 구간, 1F/2F 층별 표시, 지역 외부 원복, B맵 환경광·태양색/세기·안개 복원을 통과했습니다. 최종 네 경계의 평균 절대 휘도차는 각각 약 .000001, defects=0입니다. 고정 플레이어·카메라 상태에서 실제 분위기 평가 위치를 바꾼 분리 시험이며, 이번에 캐릭터가 전 맵을 걸어서 통과한 시험으로 주장하지 않습니다.
- after_DISTRICT_VALIDATION.txt: 실제 D02/SC 게임 시점과 지역 볼륨 Weight=0, B맵 조명 복원 모두 통과했습니다. 건물 가까이 촬영되어 지붕이 화면의 큰 비중을 차지하는 시점이라는 한계가 있습니다.

## 전후 화면과 판독

before_ ↔ after_ 대응 **24쌍/48장**의 존재를 확인했습니다. 고정 편집기 7쌍 + 실제 게임 16쌍 + 편집기 UI 1쌍입니다.

- 편집기: outdoor_factory, factory_metal_close, west_d02, sc, factory_1f, factory_2f, factory_stairs.
- 게임: play_boundary_{east,west,north,south}_{outside,inside,reverse_outside} 12쌍, play_factory_1f/2f 2쌍, play_west_d02/sc 2쌍.
- editor 1쌍은 저장/편집 모드 확인용이며 그래픽 품질의 주 증거가 아닙니다.
- 이름이 factory_2f인 **편집기** 시점은 전체 컷어웨이를 다른 각도에서 본 보조 사진입니다. 실제 2층 검증은 play_factory_2f와 floor=1 기록을 사용합니다.
- 최종 outdoor_factory는 같은 건물·지붕 상태로 재촬영됐음을 메인과 독립 검토자가 직접 열어 확인했습니다. 고고도 전체 사진은 일부 그림자가 렌더 거리 밖이므로 게임 조명 평가는 실제 게임 시점으로 했습니다.
- 메인의 시각 판독: 플레이 바닥의 미세 요철과 균열 반응이 늘고 직사광/하늘빛 균형이 정리됐습니다. 기존 어두운 면의 가독성을 유지했습니다. 변화는 보수적이며 극적인 아트 교체나 완전한 물리 기반 간접광을 구현했다고 주장하지 않습니다.
