# R04 아이콘 및 안내문 보완 — 이후 슬롯 단순화는 별도 기록

## 변경 전과 의도

- 실제 `after_r03_inventory_1920x1080.png`의 카드 간격은 개선됐지만 의료 아이콘 자체의 투명 여백 때문에 작은 병·수술 키트의 식별성이 약했다. 독립 검토 의견과 실제 이미지를 읽고 보완했다.
- 실제 `after_r03_camp_hud_1920x1080.png`에서 캠프 상시 안내문이 중앙 무기 카드와 겹쳤다. 다른 UI 배치 채팅과의 허가된 조율 과정에서도 확인됐다.
- 두 이미지는 이 마지막 보완의 진짜 before이며, 기존 초기 before를 덮거나 after를 before로 위장하지 않는다.

## 변경 내용

- `MedicalIcons.TryDrawItemTight`: 격자에서만 texture별 알파 bounds를 한 번 캐시하고 2px 여유를 남겨 기존 그림 영역을 채운다. 실제 texture/에셋은 변경하지 않는다. 읽을 수 없으면 기존 아이콘 경로로 복귀한다. 의료 휠·HUD·퀵슬롯의 원래 framing은 유지한다.
- `UiTheme.Hint`: 폭580/높이28을 유지하고 무기+퀵슬롯 위쪽으로 이동한다. 캠프 시설 상호작용 프롬프트와도 간격을 남긴다. 짧은 안내문 배경은 `Pill`을 사용한다.
- 캐릭터 영역, 초상 크기/카메라/모델, 가방 칸 수/논리 좌표, 장비 효과, 저장과 경제 규칙은 그대로다.

## 검증 상태

- 의료 아이콘 전체 runtime 정적 컴파일 오류0/기존 경고21. 소스 변경 및 검토 근거는 `INVENTORY_SPACING_RECORD.md`와 해당 compile log에 있다.
- 기존 앱을 종료하지 않고 Unity에서 새로고침했다. 실제 새 Assembly-CSharp.dll 06:55:56, Editor DLL 06:56:11을 확인했다.
- 실제 r04 검토와 대응 이미지를 CHANGE_RECORD.md 및 VISUAL_AUDIT_R04_FINAL.md에 기록했고 이후 r06까지 검증했다.
- 후속 사용자 지시의 큰 아이콘/개수 전용 슬롯에서는 이 tight-fit을 퀵슬롯에도 재사용했다. 현재 호출 범위와 최종 색/표시 계약은 SLOT_SIMPLIFICATION_RECORD.md를 따른다. 위의 ‘격자에서만’은 이 R04 단계 당시 범위를 설명한다.
