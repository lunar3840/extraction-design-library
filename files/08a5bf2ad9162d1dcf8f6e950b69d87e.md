## 사용자 지시와 기획 의도

무게의 긴 문구 때문에 네 항목 사이의 간격이 달라 보이므로, 실제로 보이는 간격을 더 좁고 고르게 맞추고 아이콘과 수치를 확대한다. 기존 Figma UI kit을 수정하고 실제 Unity 게임에도 적용한다.

## 변경 전 상태와 증빙

기존 네 항목은 136px 셀을 152px 간격으로 배치했다. 아이콘20px, 현재 수치26px, 보조 수치12px였으며, 무게 문구 길이와 SVG별 투명 여백 때문에 눈에 보이는 간격이 달랐다.

- Figma 수정 전: before_figma.png, before-components.json.
- 실제 게임 수정 전: before_inventory.png / before_inventory_state.txt. 1920×1080, SystemsTest 거점 인벤토리, 정상 테스트 프로필.
- 실제 전후 비교: before_inventory.png ↔ after_inventory.png. 같은 장면·해상도·UI 상태를 유지했다. 캐릭터의 기존 idle/표정 동작은 동결하지 않아 자세/시선은 약간 다를 수 있다.
- before_inventory는 기존 guarded 캡처 도구가 먼저 저장한 inventory-figma-kit-alignment/before_spacing_20261023.png와 상태 파일을 그대로 복사했다. 실제 Assets 변경 전에 확보한 원본이며 재구성본이 아니다.
- 동일 영역 원본 크롭: before_inventory_footer.png ↔ after_inventory_footer.png. 크기 변경/합성/후보정 없음.

## 실제 변경

- 아이콘20→26px, 현재 수치26→30px Bold, 최대/변화 수치12→13px.
- 전체 영역은 (56,972,592,40), 기존 하단 끝1012를 유지했다.
- 항목별 내용 폭을158/116/146/146으로 구분하고, 시작점0/167.675/289.45/440.575로 배치했다.
- 현재 수치는 고정 숫자 열에서 좌측 정렬, 최대/변화 수치는 고정 보조 열에서 우측 정렬한다. 자릿수가 변해도 이후 항목의 시작점이 움직이지 않는다.
- Figma 원본 아이콘의 투명 여백을 고려한 시각 간격은 약10.425/10.275/10.125px이다(104px PNG alpha>16 기준). 현재 영역 뒤의 여유는 긴 수치와 변화량을 수용하도록 예약한다.
- Figma Metric에 Kind=Weight/Health/Needs 변형을 추가해 서로 다른 열 폭을 원본 컴포넌트에서 관리한다. 기존5개 텍스트/아이콘 속성을 공유하고, 기존 여섯Needs 변형 ID를 보존했다. Raid/Camp/Recovery/Critical 및 배낭 없는 화면에도 같은 공유 구조를 적용했다.
- 네 아이콘을 최신 Figma의 순수26×26 SVG로 다시 내보내고4배104×104 PNG로 적용했다. 기존 meta/GUID를 보존했다. 특정 아이콘에만 구워졌던 그림자를 제거하고 Figma Header wrapper 효과로 통일했다.
- 런타임의 기존 텍스트/아이콘 그림자는 IMGUI의 근사 표현을 유지한다. Figma blur와 픽셀 단위로 동일한 효과라고 주장하지 않는다.
- 백플레이트 없는 구성, 소모/회복 파스텔 색, 숫자 포맷, 실제 상태 연결과 체력 상세 클릭은 유지했다.
