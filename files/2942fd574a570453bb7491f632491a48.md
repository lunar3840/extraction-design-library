# SCAR 위치·회전 연결 개선 시안

손이 공중 경유점에서 멈췄다가 다시 움직이는 부분을14개 위치·회전 연결로 조정했다. 잡기·놓기·삽입의 기준 자세와 손가락 열림/닫힘 시간은 유지하고, 잡힌 탄창은 실제 손에 강체 고정한다. 기본3초/현재 부품 구성 가정3.53초 및 같은 속도의 이전/수정 비교 영상을 만들었다.

기존 시간 압축만의 결과와 달리 실제 저장된 손의 이동/회전 속도가 중간 지점에서도 이어진다. 새 공간 경로는 수정 창의 실제 기하로 별도 검증했다. 정확한 범위/표본/잔여 팔꿈치 안쪽 접힘은 MAIN_FINAL_ACCEPTANCE와 독립QA에 따른다. 완전한 수학C2·전체 피부 무교차·실시간 연속영상 관찰이나 실게임 자연스러움 승인을 주장하지 않는다.

비교영상의 왼쪽은Flow02,오른쪽은Spatial01이며 둘다3.533초다. 영상은로컬전달이며공개사이트에는정지이미지/문서만게시한다. 원본 모델·Unity는 수정하지 않았다.
