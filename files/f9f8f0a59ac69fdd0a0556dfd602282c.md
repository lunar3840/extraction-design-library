## 북벽·지붕 가림/복귀 실제 Game 4장

`rev03_clinic_north_reveal.png`, `rev03_clinic_north_reveal_restored.png`, `rr03_clinic_roof_reveal.png`, `rr03_clinic_roof_restored.png`를 각각 직접 열었다. 함께 생성된 `play_rev03/PLAY_REPORT.json`, `play_rr03/PLAY_REPORT.json`의 실제 렌더러 상태와 촬영 명령 완료를 대조했다. 두 쌍은 서로 다른 카메라의 **각 쌍 내부 비교**이며, 북벽 쌍을 지붕 가림의 증거로 바꾸어 쓰지 않는다.

- 북벽 가림: 플레이어를 따라 북벽 원벽이 V33 국소 reveal로 열릴 때 해당 성장 Renderer 3개가 0개로 숨고, 뿌리·흙·젖음 등 지면 Renderer 3개는 유지된다. 사진에서도 벽 잎은 사라지고 지면 발·토사가 남는다. 복귀 사진에서 원벽과 북벽 아이비가 다시 보이며 raw는 성장 3, 지면 3으로 돌아왔다고 기록한다. 이 국소 동기화는 PASS다.
- 지붕 가림: reveal 사진에서 지붕 자체와 그 위 아이비가 함께 사라져 실내가 열리고, 복귀 사진에서 원래 지붕·입체 아이비가 함께 돌아온다. raw에서는 지붕 source가 꺼진 동안 기존 roof Leaves/Stems의 `enabled=False`, roof visible renderer 0이고, 복귀 후 두 renderer 모두 `enabled=True`, visible 2다. 숨김 원인은 `SOURCE_RENDERER_DISABLED`로 기록되어 있으며, 이 촬영을 지붕 source의 V33 shader 전환으로 잘못 설명하지 않는다. 기존 marker/binding과 새 clone mesh 참조가 유지된 상태의 가림/복귀로 판정한다. **지붕 국소 기능 PASS.**

**독립 최종 결론:** 현재 `rounds/finished`의 12개 Game 시점은 CLINIC 국소 아트 기준 PASS, 북벽·지붕 가림/복귀 네 Game 화면도 PASS다. 원경의 아주 작은 젖음과 기존 A33 지붕 방사형 경로, 밤 조명에서 어두운 하부 잎은 관찰되는 한계다. 화면 검토는 전체 A맵의 다른 가림 상황이나 모든 날씨·조명에서의 보증이 아니다. 원본 8,497자산·씬/prefab/참조의 전수 보존과 최종 compare의 PASS는 별도 validator 결과를 확인해야 하며, 이 리뷰가 대신 선언하지 않는다.
