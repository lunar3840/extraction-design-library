# 세린 이너웨어 경계 정리 v5 확정 — 전용 텍스처·새 UV, v6 폐기

## 사용자 지시 요약

- 이너웨어 경계가 지저분한 문제를 정리한다.
- "원래처럼 좁은 라인도 가능해?" → v6 시도.
- "난 선정적인걸 원하는게 아니라 면적을 줄임으로서 의상교체시 발생하는 이너웨어 노출을 줄이고 싶은건데" → v6 문제 지적 후 "그럼 v5로 가자".

## 기획 의도와 해결하려는 문제

- 의상 교체 시 이너웨어가 겉옷 밖으로 비치거나 경계가 지글거리는 문제를 줄인다. 이 주제의 2026-10-22 v21 회차에서 남았던 이너웨어 잔선의 후속이다.

## 진행 회차

- **원인**: ① 상의·하의 UV 섬이 아틀라스의 피부·다른 파츠 영역에 흩어져 있음 ② 옷 가장자리 일부를 피부색으로 칠해 몸 구멍 테두리를 흉내 냄.
- **v5**: 전용 텍스처 `Serin_Innerwear_v02`(2048×1024)와 새 UV. 전부 천 색(정점별 음영) + 열린 가장자리 3mm 짙은 테두리. 상의 정면 아래 접힌 메움면 4개를 지우고 틈을 이음.
- **v6 (폐기)**: 하의 뒤 다리 라인을 원래 좁은 라인으로 잘라 복원 시도. 피부로 칠한 면도 몸에서 떠 있어 겉옷 관통 면적은 그대로였고, 옛 밑단이 피부 위 돌출선으로 보여 v5로 되돌림.

## 결과

- 유령 쐐기·피부색 띠 제거.
- 하의 뒤를 덮는 범위가 최대 약 1cm 넓어 보임(메시 면적 자체는 원본과 같음).
- 이너웨어 재질에 새 텍스처 + 새 UV 메시.

## 한계 / 확인하지 못한 것

- 노출을 실제로 줄이려면 겉옷 착용 시 이너웨어를 끄거나 몸에 더 밀착시키는 방식이 효과적(이번 범위 밖).
- 직접 플레이 확인 없음.
