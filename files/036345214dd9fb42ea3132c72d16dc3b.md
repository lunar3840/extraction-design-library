## 실제 변경 / 결과

- POWER·PARTS의 추가 전폭 칸막이 외형 4개와 대응 충돌 4개를 제거했다. 기존 핵심실 3개의 벽·문·바닥은 유지했다. 삭제한 칸막이는 백업 씬/프리팹에서 복구할 수 있다.
- 실제 외형의 회전된 경계와 핵심실 벽을 교차 검사한 뒤 CLINIC `SupplyCabinet_5`를 서쪽 0.50m, POWER `ControlPanel_6`를 남쪽 0.80m 이동했다. 외형과 정확히 대응하는 충돌을 같은 거리만큼 옮겼다. 임의의 모든 소품 이동은 하지 않았다.
- CLINIC·POWER·PARTS 외형 프리팹 3개를 백업한 뒤 수정했다. 씬만 고친 것이 아니라 시각물 재생성에 쓰이는 원본에도 반영했다. V12 제작 규칙에서도 POWER/PARTS 전폭 칸막이를 제외하고 핵심실 벽과 짧은 문 진입 통로를 침범하는 새 소품 후보를 제외하도록 했다.
- 첫 적용: `visualPartitions=4 collisionPartitions=4 prefabPartitions=4 movedProps=2` (`APPLY.txt`). 재적용은 모두 0으로 추가 삭제·이동이 없었다(`IDEMPOTENCE.txt`).
- 독립 검사: **67 통과 / 0 실패**. 활성 Factory 건물 53동(별도 V13으로 교체된 비활성 옛 HALL 제외), 추가 충돌 185개, 구조 충돌 585개, 외형 경계 검사 228건, 외형/충돌 짝 위치 185건을 점검했다. 검사 대상 추가 소품과 핵심실/해당 건물 외벽 간 부적절한 관통은 0건이다. 맵의 모든 메시 삼각형 쌍을 전수 검사했다는 뜻은 아니다.
- 초기 검사는 다른 건물에서 칸막이 끝이 외벽에 정상 접합한 부분도 실패로 분류했다. 직교 여부·끝부분 위치·관입 깊이를 확인하는 좁은 접합 판별로 보완했으며 기존 핵심실 관통이나 일반 소품 간섭을 제외하지 않았다. 초기 결과는 `VALIDATION_INITIAL_JOINS.txt`, 수정 전 검사들은 `VALIDATION_BEFORE*.txt`에 보존했다.
- 출입구의 정적 검사는 1.6m 문에 대한 경계상자 여유 검사이며 실제 이동을 대신하지 않는다. 추가로 실제 `PlayerMotor`/`CharacterController`를 사용해 G1·G2·G3 핵심실 진입/퇴장 총 6회 모두 통과했다(`PLAY_VALIDATION.txt`, 각 31 step). 테스트 중에만 자동 입력·적 이동을 중지했고 종료 후 플레이 모드를 종료했다.
- 이전 V14 수정 회귀 검사도 **123 통과 / 0 실패 / 기존 경고 1**. B1→X6 일반 경로 검색 한도 경고는 그대로이나 16,384-node 추가 검사에서 완전 연결이다. 이전 투명벽 수정의 빈 통로·보이는 벽 검사 및 식생 충돌 없음 조건을 유지했다(`V14_REGRESSION.txt`).
- 핵심실 충돌·문·진입/탈출·스폰 단계·중정비동·식생 비교 일치(`PRESERVATION.txt`). 씬과 Resources 프리팹 저장 후 재로드하여 미저장 변경 없음 확인(`SAVED_RELOAD.txt`, `sceneDirty=False`).
- 메인이 전후 CORE_G2/G3 및 실제 G3 입장 화면을 직접 확인했고, 제작 담당이 프리팹 변경 범위(칸막이 4개 및 소품 위치 2개)와 백업을 독립 재검토했다.
- 독립 검증 담당도 전후 G2/G3 화면, 최종 67/0 검사, 실제 6회 보행, 재적용 0건, 저장·재로드 및 V14 회귀 결과를 읽고 최종 통과로 판정했다. 메인이 해당 판정을 확인한 뒤 기록을 마감했다.
