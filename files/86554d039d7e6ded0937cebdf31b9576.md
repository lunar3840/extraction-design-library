# 에셋 표면 덩굴 도구 사용법

현재 상태: Unity 6000.1에서 실제 생성·재생성·굽기·재열기 검증과 차량/건물 외벽/파손 지붕 시범을 완료했습니다. 실제 A맵 대량 배치와 플레이 성능 검사는 이번 결과에 포함되지 않습니다.

## 기본 사용

1. Unity 메뉴 `Escape → Environment → Surface Ivy Tool`을 연다.
2. `대상 / 프리팹`에 건물·차량·소품 GameObject 또는 정적 모델 프리팹을 넣는다. 씬에서 선택한 오브젝트를 대상으로 사용할 수도 있다.
3. 차량·벽·지붕 프리셋 중 하나를 선택하고 `프리뷰 생성 / 다시 생성`을 누른다. 생성기는 실제 메시 표면을 읽어 줄기와 잎을 만든다.
4. 시작 줄기 수·성장 단계·잎 크기와 간격·위쪽 성장·퍼짐을 바꿔 다시 생성한다. 무늬 씨앗이 같고 원본이 같으면 같은 형태를 재현한다.
5. 결과가 맞으면 `굽기 · 새 프리팹 사본 저장`으로 메시·재질·잎 표면 텍스처와 새 프리팹을 저장한다. 결과 프리팹 경로는 창 아래에 표시된다.

원본 프리팹 에셋을 넣으면 작업 사본에서 진행한다. 원본의 메시·재질·임포트 설정을 직접 바꾸지 않는다. 씬 오브젝트를 넣은 경우 생성한 덩굴은 그 대상 아래 별도 자식으로 붙으며 원본 충돌을 바꾸지 않는다. 프리뷰는 임시 상태이고 굽기 전에는 저장 결과가 아니다.

## 원하는 곳에서 자라게 하기

`수동 시작점` 목록이 비어 있으면 대상 표면에 자동으로 시작점을 잡는다. 시작점을 추가하면 대상의 로컬 좌표로 위치를 지정하고 Scene 뷰의 원형 핸들로 이동할 수 있다. 목표 표면에서 너무 멀리 떨어진 시작점은 추적 한계에 따라 건너뛴다.

`성장 제외 상자`에 문·창문·파밍 설비·표지처럼 덮지 않을 영역을 추가한다. 상자의 중심·크기·회전은 대상 로컬 좌표다. Scene 뷰에 제외 상자가 표시된다. 도구가 출입구의 게임 의미까지 자동으로 이해하는 것은 아니므로 중요한 통로는 직접 제외하고 실제 화면을 확인한다.

`표면 간격`은 원본과 덩굴 사이의 작은 여유다. 너무 작으면 겹침이, 너무 크면 떠 보이는 문제가 생길 수 있다. `표면 추적 한계`를 크게 올리는 것으로 구멍이나 분리된 부품을 억지로 이어 붙이지 않는다.

## 저장한 결과 수정과 삭제

굽기 후에는 저장된 새 프리팹을 일반 에셋처럼 배치할 수 있다. 저장된 프리팹 에셋 내부의 덩굴을 창에서 직접 삭제하거나 덮어쓰지 않는다. 이를 다시 대상으로 넣으면 새 작업 사본에서 편집한다.

이미 구운 덩굴이 붙은 씬 대상을 다시 생성하려면 해당 도구 결과를 선택해 명시적으로 지운 뒤 새 프리뷰를 만든다. 정리 기능은 도구가 만든 결과만 제거하며 저장된 메시·재질 에셋 파일을 삭제하지 않는다. 일반 씬 편집에는 Undo를 연결했으나 Undo/Redo 동작 자체는 이번 검증에서 직접 시험하지 않았다. 격리된 프리뷰 씬에서는 원본 씬의 수정 표시에 영향을 주지 않도록 Undo 등록을 생략한다.

`Assets/Escape/Art/SurfaceIvy/Generated/` 아래에는 매번 고유한 저장 폴더가 생긴다. 원본 모델·재질을 보존하므로 새 프리팹도 그 원본 에셋 의존성을 계속 갖는다.

## 가림과 성능 기준

생성은 편집기에서만 실행된다. 게임을 실행할 때 매 프레임 덩굴이 자라거나 대상 전체 메시를 다시 탐색하지 않는다. 줄기·잎은 각각 합쳐진 메시로 생성되며 장식용 콜라이더를 추가하지 않는다.

가시성 연결은 미리 지정한 원본 렌더러들이 숨겨지는지를 따라간다. 지붕만 숨기는 건물은 지붕용 덩굴을 따로 생성하고 `따를 원본 렌더러`를 정확히 지정하는 것이 좋다. 플레이어 주변 국소 투명화·카메라 가림과 완벽히 연동된다고 설정만으로 가정하지 말고 실제 출입/이탈 화면에서 확인한다.

기본 대상은 정적 MeshFilter/MeshRenderer다. Terrain·애니메이션 중 변형하는 SkinnedMeshRenderer를 같은 방식으로 지원한다고 주장하지 않는다. 사용자가 따로 제공한 잎 메시도 사용할 수 있으나 크기·방향·UV와 생성량을 확인해야 한다.

건물의 파손 형상, 무너진 부위 아래의 잔해, 흙·이끼·누수와의 연결은 별도 아트 작업이다. 이 도구는 표면에 붙어 성장하는 덩굴을 담당하며, 공중으로 길게 늘어지는 덩굴 시뮬레이션까지 자동 완성하는 기능은 아니다.

## 저장된 시범

`DEMO_PREFABS.txt`에 실제 저장된 차량·S06 외벽·S06 지붕의 정확한 프리팹 경로가 있다. `demo_attempt_01/`의 iso와 top은 같은 조건의 전후 비교다. 단순 생성 결과를 보여주는 시범이므로 차량 앞부분의 덩어리감, 외벽 윗선의 균일함, 탑뷰 지붕 잎의 크기는 실제 배치 전 조정한다. 원본의 낡은 재질은 보존하고 새 잎은 URP Lit, 간단한 접힌 잎 형상과 96×96 잎맥 텍스처를 사용한다. 제공받은 정적 잎 메시를 연결해 형태를 바꿀 수도 있다.
