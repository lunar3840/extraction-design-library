# 전술 미니맵 및 M키 전체 지도

- 작업일: 2026-10-13 (한국 시간)
- 대상: `C:/UnityProject/escape` Unity 익스트랙션 프로젝트
- 상태: 구현 완료, 실제 A맵 실행 검증 49항목 통과 및 전후 증빙 저장 완료

## 사용자 지시와 기획 의도

기존 Roblox 미니맵 형식을 조사하고 델타포스의 주요 파밍 시설 안내 방식과 조합한 설계를 실제 게임에 구현한다. M키로 전 맵을 한눈에 볼 수 있어야 하며 내 위치와 주요 파밍 요소를 표시한다. 서브에이전트는 사용자 최신 지시에 따라 GPT-6.1 Sol / Extra High로 배정했다.

이전 Roblox 조사 근거는 `outputs/reference/2026-10-12/roblox-minimap-history/`에 보존되어 있다. 실제 지형을 평면화하고 플레이어를 중심으로 보여주는 표현 방식을 참고했으며, 다른 게임의 스폰·적·파밍 규칙은 가져오지 않았다.

## 변경 전

- 기존 A맵 실행 화면에는 좌측 상단 작전 시간 카드가 있었으며 미니맵과 M키 전체 지도는 없었다.
- 현재 맵에는 주요 시설과 탈출 위치가 있지만 시설별 실제 파밍 컨테이너 배치는 아직 완성되지 않았다. 출격 위치 근처 테스트 보급함과 실제 드롭·회수 보관함만 존재한다.
- 신규 지도에서 비활성 R 진입점을 위험 지역 또는 적 위치로 오인해 표시하면 안 된다.

## 실제 변경

- 주변 지도: 북쪽 고정, 플레이어 중심, 정사각형 반경 70m, 진행 방향 표시, M키 또는 미니맵 클릭으로 확대.
- 전체 지도: 열 때마다 A맵 520×400m 전체 맞춤. 내 위치·방향, 주요 시설 5곳, 실제 탈출 지점 7곳 표시.
- 휠 확대·축소, 드래그 이동, 전 맵 복귀, 내 위치 중심, 시설 선택·직선거리·목적지 표시, 표시 종류 필터.
- 파밍 안내: 진료소/공구점/전력 제어소/정밀 부품 창고/중정비동의 시설 용도를 표시한다. 보관함이나 내용물의 실제 배치를 보장하지 않는다는 설명을 구분해 제공한다.
- 실제 보관함: 가까운 거리, 같은 층, 시야 조건으로 발견한 뒤 표시한다. 내용물은 읽거나 공개하지 않는다. 수색 후 비워진 보관함은 회색으로 표시한다.
- 층 표시: 중정비동의 실제 층 판정 범위에 맞춰 B1/1F/2F 구분. 야외 고지대를 2층으로 오인하지 않는다. 다른 층의 발견한 보관함은 흐리게 표시한다.
- 작전 시간 카드를 미니맵 아래로 옮겼으며 전체 지도에도 시간과 작전 진행 중 안내를 표시한다.
- 전체 지도는 이동·회피·조준·사격·재장전·퀵슬롯·의료 메뉴·수색 입력을 차단한다. 게임 시간은 정지하지 않는다.
- M/ESC로 닫은 프레임과 마우스 버튼을 놓기 전까지 입력을 보호한다. 드래그 중 지도 닫기/비활성화 시 마우스 점유도 해제한다.

## 구현 방식

`SessionTestWorld` 초기화 시 지도 컨트롤러와 화면을 자동으로 연결한다. 현재 작전의 맵 구조와 충돌 형상을 읽어 평면 안내도를 한 번 생성하고 캐시한다. 실제 씬의 렌더러·충돌체·지도 위치는 변경하지 않는다. 최종 실행의 지도 형상은 1,278개이며 이 중 최신 D06 추가 구조의 충돌 형상 10개도 포함된다. 현행 지형의 도로 서브메시 16개·수면 1개와 연결 건물 64동의 활성 충돌 구조를 읽는다. 비활성화된 예전 도로 슬래브와 충돌체는 제외한다.

주요 시설은 현재 맵의 의미 앵커에서 찾고 탈출 지점은 실제 `ExitPoints`에서 읽는다. 스폰 후보·비활성 R 진입점·적·보스·미구현 릴레이 목표를 공개하지 않는다. 발견 정보와 목적지는 작전 범위의 메모리 상태이며 저장 파일 형식을 바꾸지 않는다.

## 검증

- Unity의 실제 A맵 분리 미리보기에서 컴파일 및 실행.
- `LIVE_CHECKS.txt`: 좌표 왕복, 전체 맞춤, 실제 시설과 탈출 수, 최신 형상 포함, 층 구분, UI 겹침, 지도 중 입력 차단, 실제 타이머 진행, 닫기 직후 오발 보호, 재열기 초기화, 캐시 재사용을 검증한다.
- 최종 실행 결과: 2026-10-13 01:39:03, 49개 PASS / ALL CHECKS PASSED. 인벤토리·캐릭터 미리보기 드래그 중 M 전환 후 실제 OnGUI에서 점유가 해제되는 회귀 검증도 포함한다. 단축키는 실제 처리 함수 호출, 마우스 유지·해제는 Input System 시험 장치 이벤트로 검증했다. 최종 이미지의 이후 소스 수정은 인벤토리 입력 점유 해제이며 화면 외형은 변하지 않았다.
- 검증 저장 위치는 `StageMapPreview/<임의 ID>` 임시 폴더다. 일반 저장 슬롯을 사용하지 않았다.
- 독립 검토: 데이터·입력·화면을 별도 GPT-6.1 Sol / Extra High 에이전트에 배정했다. 서버 혼잡으로 초기 호출은 실패했고 같은 모델로 재시도했다. 구현은 메인이 진행했다. 전달받은 화면 검토 3건(내 위치와 시설 라벨 겹침, 미니맵 가장자리 목적지 거리 잘림, 가로·세로 축척 불일치)과 입력 검토의 지도 드래그 점유 해제 문제를 읽고 반영했다. 화면 에이전트의 최종 재검토는 서버 혼잡으로 완료되지 않아 최종 화면은 메인이 직접 확인했다.
- 메인 통합 검토에서 비활성 예전 맵 형상 혼입, 작은 지도 축척 막대와 목적지 거리 겹침, 인벤토리 드래그 중 M 전환의 마우스 점유 잔류를 추가로 수정했다.
- 데이터 독립 검토 결과를 읽었다. 퇴역 충돌체 표시와 최신 루트 누락을 필수 문제로 확인했고 현행 지형 서브메시·수면·연결 건물·중정비동 충돌 구조를 직접 읽는 수정 방향이 타당하다고 판단했다. R/B/T·적 공개 없음, 실제 보관함만 발견 조건으로 추가, 실제 시설 앵커 사용을 확인했다. 최종 1,278/17/64/10 수치와 최신 소스의 독립 재실행은 완료하지 않았으므로 해당 수치는 메인의 실제 실행 결과다. D06 충돌 10개는 전체 시각 배치 수를 뜻하지 않는다.
- 입력 독립 검토의 최종 답변을 읽었다. 이동·조준·회피·사격·재장전·퀵슬롯·의료·수색 차단 경로와 시간 정지·저장 호출이 없음을 확인했고, 추가 필수 결함은 보고하지 않았다. 해당 에이전트가 직접 읽은 실행 결과는 중간 38개 항목이며 최종 49개 결과는 메인이 확인했다. 실제 키보드 장치부터 화면까지의 물리 입력 전달 및 마우스 제스처 전체의 자동 검증은 수행하지 않았다. 확대·이동·선택은 실제 처리 함수와 좌표·상태 변화로 확인했다.
- 증빙 명령 파일을 읽는 순간 외부 쓰기와 충돌한 일시적인 편집기 IOException이 있었다. 증빙 도구에서 재시도하도록 처리하고 요청을 임시 파일에서 원자적으로 교체했다. `after_editor.png` 하단은 이 이전 오류 알림을 포함하며 게임 런타임 오류를 의미하지 않는다.
- 빌드 파일 배포는 하지 않았고 Unity 프로젝트 소스에 적용했다.
- 확인 범위는 현재 A맵의 Unity 편집기 실행이다. B맵의 일반 좌표 기반 지도 분기는 이번 실행 검증 범위가 아니다. 정상 출격·귀환·사망의 지도 해제 경로는 소스 검토를 거쳤으며 전체 플레이 사이클을 별도로 완주하지는 않았다.
