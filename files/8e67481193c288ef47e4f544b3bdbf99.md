# Blender 5.2.1 Linux 실행 파일 준비 기록

## 사용자 지시 요약

일반 Chat의 Linux 작업공간에서 에델 `.blend`를 수정할 수 있도록 Blender 5.2 계열 Linux x64 실행 압축본을 추가로 준비한다.

## 기획 의도와 해결하려는 문제

기존 에델 모델 패키지는 정상적으로 전달됐지만, 대상 Chat 작업공간에 Blender 실행 환경이 없어 메시 수정과 렌더 검증을 시작하지 못했다. 모델 파일과 같은 5.2 계열의 공식 Linux x64 배포본을 별도로 제공한다.

## 변경 전 상태 및 문제점

- 에델 모델 ZIP은 이미 생성되어 있었다.
- `blender-5.2.1-linux-x64.tar.xz`는 로컬 다운로드 폴더에 없었다.
- Chat 작업공간은 Windows 설치 파일이 아니라 Linux x64용 독립 실행 압축본을 요구했다.

## 실제로 바꾼 부분

- Blender Foundation 공식 배포 서버에서 `blender-5.2.1-linux-x64.tar.xz`를 다운로드했다.
- 공식 `blender-5.2.1.sha256` 체크섬 파일도 함께 저장했다.
- 기존 `.blend`, 텍스처와 모델 ZIP은 변경하지 않았다.

## 변경 방식

- 공식 배포 위치: `https://download.blender.org/release/Blender5.2/`
- Linux x64 `.tar.xz`를 압축 해제하거나 재압축하지 않고 원본 그대로 보관했다.
- 내려받은 파일의 SHA-256을 공식 체크섬과 대조했다.

## 변경 후 기대 효과와 확인 결과

- 파일 크기: 383,688,088 bytes (약 365.9 MiB)
- SHA-256: `a31f524fa99a527d3d52b7f5aaa68c34e1a19d5a1c9473f79c5cc610fd5b10e9`
- 공식 SHA-256과 일치함을 확인했다.
- 모델 ZIP과 합치면 업로드 한도를 초과할 가능성이 있어 별도 파일로 유지했다.
