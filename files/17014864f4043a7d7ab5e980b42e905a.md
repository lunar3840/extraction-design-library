# A맵 기계 사냥 · 인간 선인지 회피 및 방어 사격

작성일: 2026-10-15. 상태: Unity 행동 적용, 실제 A맵 회피 및 기존 전투 회귀 검증 완료.

## 사용자 지시와 의도

기계형은 순찰 중 살아있는 인간을 발견하면 적극적으로 공격한다. 인간형 NPC는 기계보다 넓은 인식 범위로 먼저 발견하여 전투를 피하고, 안전한 방향으로 동선을 바꾼다. 사용자의 후속 정정에 따라 **첫 발사나 피격을 기다리지 않는다.** 인간 입장에서 기계가 자신이나 가까운 동료를 식별했다는 외부 단서(지속적인 정면 접근, 자신들 방향의 조준 자세)가 관측되면 방어 사격을 허용한다.

## 변경 전과 증빙

직전 배치 작업의 적 수·거점·일반 위치 후보를 유지한다. 기존 로직은 인간 NPC도 기계를 발견하면 즉시 공격 대상으로 삼았고 탐지거리는 일반 18m, 네임드 23m로 진영 구별이 없었다.

런타임 변경 전 Unity 편집 창을 `before_editor.png`로 저장하고 대상 코드 원본을 `source_before/`에 복사했다. 기존 모델과 배치의 이미지는 이전 작업 `../a-map-enemy-placement-unity/`에 보존되어 있다. 이번 작업의 변경 전 교전 영상을 새로 촬영한 것은 아니므로 기존 이미지나 사후 화면을 변경 전 행동 증거로 제시하지 않는다. 코드 동작의 전후 차이는 원본 코드와 실제 Play 검사로 확인한다.

## 실제 변경

- 탐지거리: 일반 인간 27m, 인간 네임드 30m / 일반 기계 18m, 기계 네임드 21m. 시야각은 인간 200도, 일반 기계 120도, 네임드 기계 140도다. 벽을 통과해 감지하지 않는다.
- 인간의 일반 순찰 속도를 1.35m/s로 낮추고 기계는 기존 속도와 공격적 성향을 사용한다. 인간은 조심스러운 성향을 사용한다. 인간의 방어 준비 지연은 반응 0.25초·조준 0.35초다.
- 인간의 위험 관측과 공격 대상을 분리한다. 기계를 보았다는 사실만으로 공격 대상에 등록하지 않는다.
- 기계가 인간 또는 12m 안의 보이는 동료 방향으로 조준 상태를 0.35초 이상 유지하거나, 같은 방향으로 0.6초 이상 지속 접근한 것이 보이면 방어 허용을 기억한다. 접근은 실제 관측 위치의 시간별 변화로 계산한다. 기계의 숨겨진 표적 ID만으로 인간에게 탐지 사실을 알려주지 않는다.
- 직접 공격·피격도 긴급 방어 단서다. 방어 허용은 최근 단서에서 8초 유지하며 보이는 공격 단서로 갱신한다. 시야가 끊긴 기계를 끝까지 추격하지 않는다.
- 미발각 상태에서는 거리를 벌리는 후보와 엄폐 후보를 찾는다. 후보마다 실제 NavMesh 경로 완성, 몸체 충돌, 활동 반경, 다른 관측 기계에 더 가까워지는 경로 여부를 확인한다. 안전한 경로가 없으면 무리하게 전진하지 않는다.
- 회피 중에는 마지막으로 본 위협 방향을 보며 물러나므로 조준·추격 단서를 피격 전에 확인할 수 있다. 마지막 관측 위치는 4초간 회피에 이용하고, 보이지 않는 적의 새 위치를 계속 추적하지 않는다.
- 플레이어와 동진영에 대한 기존 관계, 직접 공격자 우선순위, 표적 유지, 처치 기여도는 유지한다. 인간의 기계 회피가 플레이어와의 동맹을 뜻하지 않는다.
- 인간은 체력이 낮아져도 기계를 향한 자살 돌격으로 전환하지 않도록 전용 설정을 껐다. 기존 테스트 적의 기본 행동은 유지한다.

## 배치·진입 보호

H1 서측 작업장과 H2 동측 작업 구역은 기존 위치를 유지하고, H3 단독 수색자도 기존 안전한 포켓에 둔다. H1의 북/서측, H2의 서측 회피 가능성을 배치 담당이 독립 검토했다. 구체 회피 목적지는 실제 지형의 경로 검사로 매번 선택한다. 기계 사냥·인간 회피 모두 기존 활동 반경을 지키며 B1~B4 초입 및 탈출 동선으로 무제한 확장하지 않는다. R8은 계속 비활성 플레이어 진입점이며 적 배치 표시가 아니다. 반입가치 문턱이나 진입점 선택은 변경하지 않는다.

## 검사

`play_Checks_103123/` 1차 실제 Unity Play RESULT PASS. 기존 EnemyChecks/CombatChecks와 새 행동 검사 22개 확인이 통과했다. 인간의 선인지·무사격 회피·도달 가능한 원거리 회피 목표, 측면 통과 기계에 대한 선제공격 억제, 조준·지속 접근 인지 후 무피해 상태의 방어 표적 획득 및 실제 인간 발사, 등 뒤/벽 너머 단서 배제, 피격 시 방어, 위험 소멸 뒤 복귀, 플레이어 적대 유지가 포함된다. 일부 테스트는 수동으로 검사 배우의 시간과 위치를 제어한 통제 환경이며 실제 맵의 모든 조우를 대표하지 않는다.

`play_Checks_103527/` 저체력 보완 후 실제 Play RESULT PASS. 새 행동 검사 26개 확인과 기존 EnemyChecks/CombatChecks가 통과했다. 생산 설정의 인간 일반·네임드가 자살 돌격을 사용하지 않고 기계·기존 테스트 기본 설정은 유지됨을 확인했다. 인간 체력을 실제 기계 출처 피해로 낮춘 상태에서도 기계에 일반 조준 사격으로 방어하며 Rush 모드로 가지 않았다.

`play_A_103646/` 실제 A맵 Play RESULT PASS. 일반 무작위 출격 47기와 기존 접촉 후보를 선택한 출격 48기를 각각 60초 관찰했다. 일반 표본은 47기 생존, 46기 이동, 인간 6발·기계 3발이었다. 접촉 표본은 48기 모두 이동·생존, 양 진영 0발로 인간이 먼저 피한 채 교전 없이 유지되었다. 이는 인간이 항상 안전하다는 뜻이나 전체 출격의 조우 확률을 측정한 결과는 아니다.

두 출격 합산 회피 관측은 출격별 배우 키 기준 6건, 그중 회피 중 0.5m 이상 실제 이동은 5건이다(동일 NPC 슬롯의 다른 출격은 별도 키이므로 서로 다른 인간 6명을 뜻하지 않는다). 회피 목적지 2,603개 시간 샘플에서 NavMesh 완전 경로·활동 반경·기계 몸체와의 간격 검사를 통과했다. 이는 같은 목표를 여러 번 확인한 표본을 포함하며 2,603개의 독립 경로가 아니다. 종료 시 생존 배우의 NavMesh·활동 반경, 두 차례 귀환과 등록 정리도 통과했다. 첫 일반 표본 H1_02는 최초 회피 목표가 현재 위치여서 제자리 경계였고, 해당 출격의 회피 중 이동 성공에는 집계되지 않았다. 일반 출격 종료 시 전체 이동 기준에 못 미친 1개체와 동일한지까지는 별도 확인하지 않았다.

실제 경로와 첫 회피 관측 위치는 `play_A_103646/AVOIDANCE_EVENTS.csv`에 남겼다. `after_avoidance_H1_02_Scavenger.png`는 최초 경계 상태 화면이며 이후 실제 이동의 단독 시각 증거로 쓰지 않는다. `after_patrol_human.png`, `after_patrol_machine.png`, `after_contact_human.png`, `after_contact_machine.png`는 각 관찰 종료 화면이다. 이동과 방어 허용의 시간적 검증은 로그와 코드 검사를 함께 참조한다.

독립 검토에서 선인지와 방어 허용 분리, 시야 없는 표적 지정 정보 배제, 기존 플레이어 위협 평가와 legacy 동작 보존을 확인했다. 플레이어와 이미 교전 중인 인간은 그 교전을 유지하므로 기계 회피가 다른 실제 위협을 무조건 덮어쓰지는 않는다. 경사지·복합 잔해에서의 엄폐 선택 품질과 장시간 프레임 비용은 후속 플레이 튜닝 대상이며 이번 짧은 관찰로 모든 배치/성능을 보증하지 않는다.

`play_Checks_104100/` 최종 실제 Play RESULT PASS. 기존 EnemyChecks·CombatChecks, 정책 변경에 맞춘 EncounterCombatChecks 14개 확인, 새 FactionBehaviorChecks 26개 확인을 함께 통과했다. 인간의 무피격 방어 발사와 저체력 조준 사격 외에도, 기계의 인간 표적 선택·NPC 상호 실제 사격 피해·플레이어 직접 공격에 대한 표적 전환·동진영 배제·NPC/플레이어 처치 기여도·활동 반경 밖 대응 사격·기존 테스트 적 동작을 재검증했다. 모든 결과 로그를 메인이 직접 읽었고 독립 담당도 최종 PASS를 확인했다.

## 완료 증빙

`before_editor.png`와 `after_editor.png`는 동일 Unity 창·같은 Scene 뷰의 전후 기록이다. 맵 배치나 외형 변경은 없으므로 편집 화면상 차이가 거의 없으며, 행동 변화는 실제 Play 로그와 해당 실행의 회피·순찰 화면으로 확인한다. 맵 씬과 Resources 프리팹의 최종 수정 시각은 각각 09:49:39와 09:48:57로 이 행동 변경 전이며 이번 작업에서 저장하거나 이동시키지 않았다. 사용자 프로필을 사용하지 않았고 Unity는 저장된 A맵의 Edit 상태로 돌려놓았다. 전후 PNG·실행 PNG·검증 로그·본 CHANGE_RECORD 존재를 최종 확인했다.
