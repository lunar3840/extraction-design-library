# Surface Ruin Tool 사용 가이드

Unity 메뉴 **Escape → Environment → Surface Ruin Tool**에서 엽니다. 선택한 **정적 환경 에셋**의 파손 형상·파편, 표면 노후화, 덩굴을 편집기에서 미리 만든 뒤 **새 프리팹**으로 저장하는 도구입니다. 게임 실행 중 자동 생성하거나 A맵 전체에 일괄 적용하는 기능은 아닙니다.

## 사용 순서

1. Project 또는 Hierarchy에서 에셋을 하나 이상 선택하고 **현재 선택 목록에 추가**를 누릅니다. 대상 칸으로 개별 추가·삭제도 가능합니다. 목록의 각 대상은 따로 처리되며, 실패한 대상은 아래 상태와 Console에서 확인합니다.
2. **구조 종류**는 우선 `자동`으로 둡니다. 분류가 맞지 않으면 `건물 / 차량 / 소품`을 직접 고릅니다. **실제 형상 파손·파편**, **표면 노후화**, **덩굴**을 필요한 만큼 켜고 강도·파편 양·덩굴 풍성함을 조정합니다. 세부 설정에서 파편·삼각형 상한 등을 바꿀 수 있습니다.
3. 문, 창, 내부가 보이는 파손 단면을 남겨야 하면 **덩굴 보호 영역**에 대상의 **로컬 좌표**로 중심·크기·회전을 입력합니다. 기본 **출입구 주변 보호**도 켜 둡니다. 재질·오브젝트 이름으로 출입구 의미를 추정하므로, 이름이 없거나 유리와 벽이 한 재질로 합쳐진 모델은 직접 보호 영역을 지정하고 결과를 눈으로 확인해야 합니다.
4. 같은 배치를 다시 만들려면 **현재 무늬 시드** 값을 기록하고 **현재 무늬 고정 · 재현**을 누릅니다. **생성할 때 새 무늬**가 켜져 있으면 미리보기마다 새 시드를 사용합니다. 미리보기 결과의 **사용 시드**와 **상세 적용 기록**도 확인합니다.
5. **목록 전체 미리보기**를 누르고 `보기`에서 각 결과를 확인합니다. 창의 미리보기는 고정된 비스듬한 시점입니다. 파손 구멍·단면, 파편 위치, 문·창, 차량 실루엣을 보고, 설정을 바꿨다면 다시 미리보기를 만듭니다.
6. 만족한 결과에 **결과 전체 새 프리팹 저장**을 누릅니다. 새 사본은 `Assets/Escape/Art/SurfaceRuin/Generated/` 아래 고유 폴더에 저장됩니다. 기존 모델·프리팹은 수정하지 않습니다. 저장한 프리팹을 Scene 뷰에서 위·비스듬한 시점으로 열어 덩굴과 파손면을 다시 확인합니다. 반복 사용할 설정은 **현재 설정 새 프로필 저장**으로 별도 `.asset`에 저장하고, 다음 작업에서 **프로필 불러오기**를 사용합니다. 필요 없어진 임시 결과는 **미리보기 지우기**로 정리합니다.

## 적용 범위와 확인할 점

- 기본 **정적 메시 충돌 생성**은 꺼져 있습니다. 저장한 시안을 게임에 배치하기 전 충돌, 이동·길찾기, 가림, 실제 카메라 시점은 별도 검증해야 합니다. 켜서 생성한 충돌도 플레이용으로 적합한지 확인합니다.
- `SkinnedMeshRenderer`가 있는 캐릭터·변형 메시는 지원하지 않습니다. `MeshFilter`가 없는 대상도 처리할 수 없습니다. 노후화는 지원 재질과 shader에 적용되고, 특수 shader·투명 유리·보호 재질은 건너뛸 수 있습니다. **상세 적용 기록**의 적용·건너뜀 사유를 확인합니다.
- 자동 종류 판별과 출입구 보호는 모델 이름·크기·재질 이름에 영향을 받습니다. 창문과 파손면의 의미를 완전히 이해하는 기능이 아니므로, 중요한 개구부는 수동 보호 영역과 전후 화면 확인이 필요합니다.
- 이번 폐차·건물 격리 시안에서는 형상 변경, 덩굴 생성, 새 프리팹 저장·재읽기를 확인했습니다. 이것은 **전체 맵 적용이나 게임 플레이 검증 결과가 아닙니다.** 다른 에셋은 미리보기와 저장 후 외관을 각각 확인하세요.
