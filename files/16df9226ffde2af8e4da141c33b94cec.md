# A맵 v0.5 — 침수 정비지구 / 접근 단계·비정형 동선 검토안

## 범위와 근거
- 사용자 요청: 덕코프식 경로·시설 접근 단계를 도면에 적용하되 Unity는 수정하지 않는다. 도시처럼 규칙적인 사각 구획과 반복되는 탐험 감각을 줄인다.
- 기존 v0.3 도면 및 v0.4 실제 Unity 조감 기록을 참고했다. 이번 이미지는 기존 좌표를 그대로 유지한 시공도면이 아닌 공간 재구성 제안이다. 이미지의 표식·치수가 어긋나면 이 문서의 설계 의도가 우선한다.
- 계획 범위 520×400m와 중앙 중정비동 약80×56m를 기준으로 한다. 모든 외곽 건물·도로의 정확한 좌표 확정, 충돌·경사·AI 이동 검증은 아직 하지 않았다.

## 공간 구성
부분 침수된 옛 도시 기반시설 정비지구. 기계 점령 지상이며 인간 상주 정착지는 아니다. 개별 건물은 원래 용도에 맞는 직선 벽과 구조를 유지하고, 건물군의 방향·간격·증축·지형을 비대칭으로 구성한다. 임의로 구불거리는 길을 넣는 것이 목적이 아니다.

- 북서: 경사지의 직원 진료소와 작은 부속동. 좁은 잔해 틈에서 의료시설 앞마당으로 시야가 열린다.
- 서부: 서로 어긋난 공구 정비점 세 동과 작업 마당. 근거리 엄폐와 여러 짧은 선택 경로를 만든다.
- 남서: 생활 폐허가 붕괴 토사·식생으로 흐트러지는 구간. 건물군과 자연 지형의 경계가 연속적으로 이어진다.
- 중앙: 높은 정비 홀과 크레인이 방향 기준이 되는 중정비동. 건물의 모든 일반 출입구와 작업 홀은 기본 접근 가능. 중앙이 모든 여행의 필수 경유지나 최고 보상의 독점 장소가 되지 않는다.
- 북동: 경사진 지형의 전력·전장시설과 케이블 도랑. 옛 도로와 건물 방향이 다르고, 고저차가 접근 시야를 바꾼다.
- 동부: 비스듬한 옛 운반 선형을 따르는 정밀부품 창고와 부속 차양. 외부 긴 시야와 내부 좁은 측면 복도를 대비한다.
- 남부: 차량과 폐기계가 불균등하게 놓인 초승달 모양 야적장. 수색 경로가 직선으로 반복되지 않게 군집의 틈을 배치한다.
- 남동: 국소 침수 저지대와 건조한 회수 작업 둔덕. 두 교량은 기본 통행 가능하다. 맵 외곽 전체가 물로 둘러싸인 섬이 아니다.

## 동선과 탐험 리듬
규칙적인 외곽 순환도로와 중앙 동심원 도로를 해체한다. 서부의 짧은 수색 순환, 중앙 남·북측 우회, 동부의 긴 고저차 순환이 불균등한 위치에서 연결된다. 같은 폭과 각도의 사거리 반복을 피한다. 북측 사면길과 남측 야적장·수변길은 잠긴 시설을 통과하지 않고 동서 이동이 가능해야 한다.

설계 리듬은 ‘좁은 폐허 틈 → 개방 작업 마당 → 짧은 실내 탐색 → 가려진 굽이 → 랜드마크 재발견’이다. 지형과 건물이 긴 시야를 간헐적으로 끊되, 방향을 잃지 않도록 크레인·전력 구조물·수변을 보조 기준으로 삼는다. 기존 도로의 일부 직선 구간은 남겨 변화의 대비를 만든다.

장거리 우회는 무조건 안전한 길이 아니다. 외곽 퀘스트 목표까지 잠금 없이 도달 가능하도록 설계하되, 교전·우회 시간과 소모품 부담은 추후 검증한다. 실제 제한 시간 안에 도착할 수 있다는 보장은 아직 하지 않는다.

## 접근 제한: 지도상의 순서가 아닌 독립적인 가지
| 구분 | 기본 접근 | 제한 대상 | 제안 조건 | 자원 정체성 |
|---|---|---|---|---|
| G1 진료소 | 로비·일반 진료실 | 약품 보관실 | 보관실 열쇠 획득 | 희귀 의료품·기록 |
| G2 정밀부품 창고 | 하역장·일반 재고 통로 | 정밀부품 금고/보안 케이지 | 절단 도구 확보·현장 사용 | 광학·정밀 부품 |
| G3 전력·전장시설 | 외부 작업장·일반 정비실 | 전력 코어실 | 인증 수단 확보 + 현장 전력 복구 | 전력·전장 부품 |
| G4 중정비동 | 정비 홀·피트·일반 상부 통로 | 폐쇄된 상부 제어실 | 정비 권한 확보 + 현장 재가동 | 기계 제어·정비 자료 |

G1→G2→G3→G4를 반드시 순서대로 도는 구조가 아니다. 네 시설은 독립 분기이며 특정 외곽 금고를 열기 위해 중앙을 강제로 거치지 않는다. 권한·도구 획득처는 후속 퀘스트 설계에서 별도 확정한다. 획득해야 할 물건을 그것으로 여는 방 안에만 배치하는 순환 의존은 금지한다.

영구 진행과 매 출격 행동을 구분한다. 권한·도구 접근 능력은 성장 축, 현장 전력 복구·재가동은 출격 내 행동 축으로 제안한다. 열쇠의 소모 여부, 절단 시간·소음, 재가동 비용과 보상은 미확정이다. 값비싼 무장을 갖췄다는 이유만으로 잠긴 방의 권한을 자동 지급하지 않는다.

잠금은 붉은 해칭의 작은 실내 영역에만 둔다. 복도·일반실·도로·교량은 잠그지 않는다. 잠긴 방은 벽·천장·모든 출입문이 동일한 조건을 적용받아야 한다. 이미지의 지붕 생략은 실내를 보여주는 표현이며 실제로 점프로 들어갈 수 있는 개방 지붕이라는 뜻이 아니다. 경로 개방형 지름길은 추후 추가할 수 있으나 필수 횡단로의 유일한 통로에 배치하지 않는다.

## 진입·탈출·적
- 기존 후보 수를 유지한 검토용 표식: P01–04 → P01–08 → P01–12 누적 스폰 풀. 실제 금액 기준은 이번에 확정하지 않는다.
- 저무장 후보는 서·남서부 쪽, 추가 후보는 북·동·남동의 외부 접근로로 확장한다. 고무장도 저무장 후보에서 출발할 수 있다. 모든 스폰은 잠긴 실내 밖에 두며 보스와 즉시 교전하지 않는 가림·완충 공간이 필요하다.
- E1–E7은 플레이어용 탈출 후보. 별도의 최종 탈출 조건은 이번 범위가 아니다. 고가치 시설 잠금 때문에 유일한 귀환로가 막히면 안 된다.
- 인간 H1 서부 / H2 동부 / H3 남부는 일정 영역 내 파밍·탐험·순찰 루프를 유지한다. 철수·탈출구 도착·상주 요새를 전제로 하지 않는다. H1·H2의 별 표식은 이동형 인간 보스의 후보일 뿐 동시 고정 출현 확정이 아니다.
- 기계 M1 중앙 작업장 / M2 북동 작업장 / M3 남동 건조 둔덕은 조우 후보. M1이 중앙 일반실 진입을 항상 강제로 막는 구성은 피한다. 보스 활성 조건·감지 거리·조우 빈도는 미확정이다.

## 도면 검토 항목
- 중앙 랜드마크 유지, 의료·정밀·전력·기계 보상 분산.
- 잠금 없이 가능한 동서 우회 경로와 기본 교량 2개.
- 4개 독립 잠금실과 열린 일반 작업 공간 구분.
- 지형으로 설명되는 비대칭 구획, 건물 자체의 구조적 합리성.
- 인간의 제한 구역 순환 유지, 철수 동선 배제.
- 스폰 풀 확대와 접근 권한을 분리.
- 후속 공간 확정 시 보행 폭: 주 접근로 6m 이상, 보조 연결 3m 이상을 초기 목표로 사용. 경사와 회전 반경은 실제 캐릭터·AI로 확인할 때 확정한다.

## 산출 방식과 한계
built-in image_gen으로 검토용 비트맵 도면을 제작했다. IMAGE_PROMPT.md에 최종 생성 지시를 보존한다. 좌표 기반 CAD, Unity 내 배치 결과, 내비게이션 검증도라고 주장하지 않는다. 기존 Unity 씬·프리팹·스크립트·저장 데이터를 수정하지 않는다.
