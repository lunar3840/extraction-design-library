# 성장 / 동료 능력 1차 개편

날짜: 2026-10-19
적용 프로젝트: C:/UnityProject/escape
사용자 지시: 기존 스킬창을 공용 기본 능력 성장과 캐릭터별 특성/스킬로 나누고, 제안한 방향에 맞춰 구현 시작.

## 의도와 범위
기본 스태미너·하중·생존·무기 운용의 영구 성장과 캐릭터의 전투 방식을 구별한다.
공용 성장은 회수 자재의 사용처, 개별 능력은 출격 전 선택과 전투 중 행동으로 연결한다.
이번은 실제 조작 가능한 첫 구현이다. 기존 동료 칩 2종(세린, 테스트 동료)에 관측/기동 역할을 시험 적용했다.
새 캐릭터, 외형·헤어·재질, 맵·적 배치, 원본 시설 건설 시스템은 이번에 추가하거나 수정하지 않았다.
이름·수치·비용은 시험값이며 최종 확정 기획으로 취급하지 않는다.

## 변경 전
12개 성장 노드가 생존/기동/숙련 트리에 섞였고 선행 노드 최대 강화를 요구했다.
캐릭터의 고유 능력 화면과 출격 중 E/X 능력이 없었다.
AmmoManagement는 계산기만 있고 실제 플레이 소비처 연결이 없어 효과를 확인하기 어려웠다.
QuickBreathing은 회복 계열과 통합 가능한 항목이었다.

## 실제 변경
- K 화면을 공용 연구 / 동료 능력 두 탭으로 교체.
- 공용 연구 10종, 4분류. 선행 최대 강화 조건 제거. 현재/다음 효과, 재료, 비용, 추적 목표 표시.
- 연구 비용은 단계별 자재와 블랭크. 보관함을 우선 소비하고 보호된 물품은 제외.
- 기존 포인트/촉매는 연구권으로 호환. 연구권은 자재·블랭크 비용을 대체.
- 이전 QuickBreathing(최대 5), AmmoManagement(최대 3) 투자분 환불. 나머지 랭크 유지.
- 최대 지구력 +10%, 질주 소모 -10%, 회복 +15%, 회복 대기 -0.30초. 기본 질주 지속 약 6.67→8.15초.
- 세린: 전방 관측 E, 집중 추적 X, 표적 조준 보정, 물자 용기 위치 식별.
- 테스트 동료: 재배치 E, 기동 가속 X, 이동 후 사격/장전 보정, 비전투 보행 스태미너 보조.
- 각 동료 3쌍 A/B 특성. 동조 1~3에서 B 순차 개방, A 기본 제공. 거점 변경 무료.
- 연구·동조·특성·추적 목표는 거점에서 저장. 출격 중 열람만 가능, 죽어도 영구 성장 유지.
- 필살기는 명중/기여 처치/새 물자 종류/세린의 최초 표적 발견으로 충전. 대기 충전 없음, 출격마다 초기화.
- 같은 적의 명중 피해 충전은 최대 30, 관측 충전은 한 번. 자원/지속시간은 저장 데이터와 분리.
- 관측은 발동 프레임의 범위·각도·벽 차단을 검사. 표식은 마지막 관측 위치이며 벽 뒤 현재 위치를 갱신하지 않는다.
- 스킬의 m 단위는 Unity 월드 거리 기준. 기존 무기/이동의 원본 공간 배율을 바꾸지 않았다.
- 이동 가속은 전술/필살기의 큰 배율만 적용. 회피 거리와 CharacterController 충돌 유지.
- 선택한 특성에 맞춰 설명을 갱신. 전투 HUD에 E/X 준비·쿨다운·충전·지속시간 표시.

## 방식과 저장 보호
기존 ProfileSession의 저장 트랜잭션을 재사용했다. 새 growthVersion 및 companionTraining 필드와 구형 성장 이관을 추가.
재료 연구/동조는 저장 실패 시 돈·가방·보관함·랭크가 함께 유지된다.
기존 연구권 경로는 라이브 무기 객체와 장전 시간 축을 보존한다.
실제 사용자 저장을 시험용으로 편집하지 않았다. 별도 검증 프로젝트와 새 임시 프로필을 사용했다.
전체 원본 Runtime은 source_before/Runtime에 보관. 변경 20개 파일과 적용 SHA-256은 applied_files.json.
동시에 바뀐 SessionGlassView/UiTheme의 조작 안내 버튼 제거를 발견하여 보존했다. 적용 직전 두 파일은 source_at_apply에 보관.

## 검증
- 최종 Windows 실행 파일 빌드 성공: after_build_5.log.
- GrowthRework 24, Basecamp 52, Session 43, CompanionChip 42 = 161개 PASS.
- 실행 상태 검사 20개 PASS: runtime_checks.txt. 최종 실행에서 runtime_errors.txt 없음.
- 실제 검사: 차폐/가시 표적, 반복 관측 충전 방지, 인벤토리 사용 차단, 필살기 소모, 동료 변경, 출격 초기화, 기동 배율/비중첩/만료, 가속 중 벽 충돌.
- 1600×900 원본 및 수정 후 공용/개별 화면을 캡처하고 글자·수치·버튼·인물 배치를 육안 확인.
- 초기 검증용 저장 revision 누락과 복사본의 오래된 A맵 데이터 문제를 수정. 능력 검증은 기존 실험실 바닥으로 분리.
- 관측 검사 중 이전 프레임 PlayerVisionVisible을 참조하는 지연을 발견해 현재 발동 시점의 직접 검사로 수정.
- 초기 실패 기록은 harness_setup_errors_attempt1.txt, attempt2_*, attempt3_* 및 초기 build 로그에 별도 보존.
- 적용 전 실제 편집기 Play 종료 시 기존 InventoryGlassView/SdCharacterVisual NullReference가 관찰되었다. 해당 기존 종료 경로는 본 개편의 수정 범위 밖이며 최종 분리 실행 검사에서는 재현되지 않았다.
