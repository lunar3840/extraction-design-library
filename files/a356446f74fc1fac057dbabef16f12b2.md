# Existing kit → native Unity bindings

Source: https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0?node-id=105-2987

The existing project uses IMGUI. The accepted editable Figma components are translated to reusable native renderers and geometry; this does not add or claim a Unity Figma Connector/UXML pipeline. The reference PNG is a preserved earlier 1× export whose layout/content was freshly confirmed using official MCP context and screenshot on 2026-10-23. It is for review only, never a runtime asset. The user's subsequent operator-backplate/empty-icon revision is applied to both editable Figma instances and Unity, as described below.

Dynamic player models and items remain driven by current game data. Thus the real Serin/medical/ammunition inventory differs from the illustrative Edel/example-item content in Figma. Demo cursor/warehouse illustration is not inserted into the game. Runtime-only equipped weapons and physical chip controls are fitted within the operator panel using the same card family. Actual loot grid remains6×6 rather than changing gameplay to the sample's four-across loot arrangement.

The translucent panels use the exact existing #647080 at44%, white6% tiles, white16% boundaries and mint18% selection. Scene-camera-only blur supplies the live world backdrop, avoiding capture of the HUD itself. The shared HUD coordinate scale is preserved.

Latest Figma edit: `105:3012` has no fills/strokes/effects, with all child positions and editable instances preserved. Only nested `Image` instances in `105:3018`, `105:3019`, `105:3020` are30% opacity. Their vector fills/strokes use the same neutral luminance mapping as `create_placeholder_assets.mjs`: gray=.55+.4*(.2126r+.7152g+.0722b). Original asset masters and inventory item tier tokens are not changed. `before_figma_operator.png` is the genuine previously exported pre-edit source, copied from reference_figma_inventory.png; `after_figma_operator.png` is the official MCP post-edit screenshot at1024×576. Their pixel dimensions differ; use as composition evidence, not a pixel-perfect diff.
