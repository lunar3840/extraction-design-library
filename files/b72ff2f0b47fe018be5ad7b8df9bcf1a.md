# SCAR 장전 연결 개선 미리보기

전체 장전 길이는 유지하면서, 동작 사이 멈춤을 줄이고 빠른 이동에 시간을 더 주었다. 탄창을 잡고 놓고 끼우는 순서와 기존 파지·공간 경로는 유지했다. 기본 3초와 현재 외형의 부품 구성 가정 3.53초 영상을 만들었다. Unity에는 적용하지 않았다.

삽입 전 연결은 약0.105초에서0.006초, 복귀 중 연결은 약0.072초에서0.004초로 줄였다. 새 탄창 잡기와 마지막 삽입은 각각 약0.10초·0.12초를 유지했다. 명목3.528초 조건의 시간 배분값이며 60fps 영상은3.533초다. 기본 SCAR은3초이고 부품·성장·상태·개체 보너스에 따라 실제 장전 시간은 달라진다.

모든 채널의 공통 시간 재배분으로 공간 경로를 보존했다. 첫 시안에서 너무 빨랐던 초기 손가락 열림도 시간을 다시 확보했다. 독립 검증의 정확한 판정 범위는 QA_FLOW02.md에 따른다. 새 전 표면 충돌 검사나 실게임 연속 재생을 주장하지 않는다. 경유점의 원래 끝속도0과 낙하 경로도 유지하므로 완전히 새로운 공간 곡선 수정은 아니다.
