# A맵 D05 이미지 콘셉트 독립 시각 검토

검토 대상은 `concepts/`의 `YardWall_3m_reference_v01.png`, `ServiceFacade_3m_reference_v01.png`, `DrainHeadwall_5m_reference_v01.png` 세 장이다. 세 이미지를 원본 크기로 직접 열고, `outputs/map_design/2026-09-15/stage-a-relay-v07/StageA_Relay_Map_v07_final.png`, `outputs/map_design/2026-09-22/a-map-asset-production/ASSET_BRIEF.md`, 2026-10-02 V33 시설 경계 적용 기록과 2026-10-07 건물·실외 최종 화면을 비교했다. 검토 대상은 **2D 콘셉트 이미지**다. Tripo 3D 메시, 실제 치수, 후면, 최종 Unity 재질·충돌·배치 결과는 아직 확인하지 않았다.

## 총평

세 형상이 각각 작업장 경계, 건물 서비스면, 침수 수로 시설로 분명히 구분된다. 낡은 도시 기반시설을 재사용한다는 v0.7 A맵의 방향과 맞고, 과장된 SF·군사 요새 표현도 없다. 재질의 녹과 물때는 현실감이 있지만 작은 화면에서 세밀한 스크래치보다 프레임·파이프·수문 같은 큰 실루엣이 읽히도록 Unity 카메라에서 확인해야 한다. 세 이미지의 실측 기준 물체나 치수 표기가 없어 3m/5m 규격 달성 여부는 판정할 수 없다.

## 권장 시범 범위와 검수 기준

1. `YardWall`을 먼저 Tripo로 1회 생성해 모델의 후면·양 끝·바닥 접촉·UV를 확인한다. 기존 V33 연결 담장의 실제 좌표와 길이를 기준으로 직선 구간 일부만 외형 교체한다. 원본 출입구 12개와 기존 충돌·실외 우회는 그대로 둔다. 6~10개 반복 가능 여부는 **1개 모델의 실제 플레이 카메라와 결합 상태를 본 뒤** 판단한다.
2. `ServiceFacade`는 POWER/E03 또는 TOOLS/W02의 문·창 없는 외벽 한 면에 임시 크기 시험을 한다. 건물 바깥 접근 폭, 창·문·지붕 가림 계층, V33 국소 반투명 표현을 확인한 후 5~7곳 확장을 결정한다. 의료동 CLINIC은 이미 별도 재질·조명 개선이 있어 첫 시범 대상에서 제외한다.
3. `DrainHeadwall`은 남동 수로의 실제 수위·호안 경사와 두 교량 접근을 재측정한 뒤 1곳만 시험한다. 닫힌 문에 맞는 막힌/사용 중지된 시설 맥락을 준다. 기계 장치의 개폐나 물리적 배수 기능은 현재 이미지에서 입증되지 않는다.
4. 세 모델 모두 Unity 1 unit=1m, Y-up, 바닥 중심 피벗, 실제 폭×깊이×높이, 후면·측면·상단, 삼각형 수와 재질 수를 **생성된 GLB를 받은 뒤** 확인한다. 자동 생성본의 세밀한 볼트·철선은 시야거리에서 사라질 수 있으므로 큰 형태와 적당한 표면 마모를 우선한다. 원래 경계·문·교량·진입점의 충돌과 실제 보행 검증 없이 이미지 승인만으로 배치 완료로 보지 않는다.

## 자료의 적용 범위

`StageA_Relay_Map_v07_final.png`는 현재 세계관·구역 성격의 콘셉트이며 현재 Unity 좌표를 정밀하게 확정하는 도면은 아니다. V31 열린 동선 도면과 V33 연결 경계 도면은 이후 승인되어 Unity에 적용됐고, 당시 적용 기록의 실측 보정·비활성 보존까지 현행 근거로 읽어야 한다. 반면 `outputs/map_design/2026-09-11/stage-a-flooded-gate/StageA_Flooded_Gate_Blueprint_v01.png`는 맵 전반이 침수된 초기 구상으로, 남동 국소 수로인 현재 A맵의 시설 배치 기준으로 사용하지 않는다. B4/R8은 약 62m 간격에 W5 초반 접근이 겹치고 R8은 비활성이다. 새 벽이 이 주변의 노출·엄폐·접근을 우연히 변경하지 않도록 별도 확인한다.
