# A맵 건물 Blender 전수 제작 결과

2026-10-28 현재 Unity 활성 D09/D10/D15/Tripo 형상을 기준으로 W10을 제외한 68동을 별도 Blender 원본 68개와 Shell/Roof/Interior FBX 204개로 제작했다. W10은 기존 검증 샘플을 보존했다. `EXPORT_INDEX.json`과 독립 `DELIVERY_AUDIT.json`이 모두 PASS이며, 68개 `ROUNDTRIP_VALIDATION.json`도 PASS다. 파일 해시·Blender 외부 이미지 누락·세 그룹 구성·메시 수·재질 슬롯·변환 후 경계 비교에서 감사 오류는 0개다. 원본 Unity material asset은 GUID+localFileID로 식별하며 수정하지 않았다.

출력은 렌더 객체 271개, 충돌 전용 객체 135개, 렌더 submesh 1,267개, 충돌 삼각형 133,924개다. 각 건물의 원래 렌더 삼각형보다 출력 렌더 삼각형이 48~672개 많다. 같은 역할·재질 메시를 묶어 건물당 렌더 객체 3~4개로 제한했다. 추가 실내방은 C01, C04, E02, E04, E07, HALL, N02, N04, N07, N17의 10동이다. 나머지 58동은 새 밀폐방을 만들지 않고 기존 형상과 역할별 상세를 개선했다. 이 중 폐허 11동(S01~S10, S12)은 열린 파손 형태를 유지한 `detailRecipe`에 해당한다. 계약의 `reuseExistingCompartments` 라벨은 비신규방의 포괄 표기로만 해석해야 하며 폐허에 밀폐 구획이 있다는 뜻은 아니다.

현재 문 100곳의 Shell 중심 ray는 원본 개구 100/100을 확인했다. 이 측정만으로 플레이어 캡슐 통과나 Nav 연결을 최종 승인하지 않는다. 신규 방은 계획 grid와 가구·loot·문·NPC 보호 체적을 피해 후보로 제작됐으며 실제 Unity 게임에서 양면 문 통과와 동선 검증이 남는다.

대표 Blender 미리보기는 C01, CLINIC, E05, F01, HALL, N03, N07, PARTS, POWER, S05, TOOLS, W08에 있다. C01/N07의 새 방 개구, S05의 손상된 벽·지붕, PARTS의 벽돌·철 지붕, POWER의 설비동, TOOLS/W08의 다른 지붕 형태를 확인했다. 지붕 제거 미리보기는 기존 Unity 바닥·가구를 포함하지 않아 넓은 흰 영역이 보인다. HALL은 개방형 건물이라 지붕 제거 원경에서 작은 새 방이 잘 보이지 않는다. 실제 Unity 게임 카메라의 전후 캡처를 시각 수용 근거로 사용해야 한다.

Blender 저작 원점은 해당 D09 geometry frame local, 미터 단위, scale 1이다. FBX 복제 메시에서 X 반사와 면 winding을 보정했고 Unity `useFileScale=true`/추가 scale 1을 전제로 했다. `EXPORT_MANIFEST.json`의 geometry frame, 실제 local/world bounds, 객체별 재질 슬롯, collider pair와 SHA256이 Unity 연결 계약이다. 부모 Unity 통합 결과와 최종 게임 검증은 별도 통합 기록에서 판정한다.
