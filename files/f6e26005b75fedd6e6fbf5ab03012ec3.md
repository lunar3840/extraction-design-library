## 변환 증빙

네 JPG를 크롭·리사이즈·보정 없이 PNG로 변환했다. 각각 1085×1025이며 원본 JPG를 디코딩한 RGB 픽셀과 저장한 PNG를 다시 읽은 RGB 픽셀이 동일하다. JPG에서 이미 발생한 압축 손실을 복구했다는 뜻은 아니다. 앱 전체 스크린샷이며 304×260 컴포넌트의 1× 내보내기 파일이 아니다.

## 검증하지 않은 항목

- 포인터 hover로 실제 팝업이 나타나는 Figma 프로토타입 동작은 연결되지 않았다.
- Unity에서의 hover·드래그·클릭 동작, 툴팁 배치·화면 가장자리 회피와 실제 게임 배경 대비는 검증하지 않았다.
- 개별 색상의 정확한 RGBA, 본문 13.5/21과 폰트 속성, 숨긴 레이어 수·원본 미변경은 편집자 보고와 구별한다.
- Figma 상태 variant 6개를 만들지 않았다. 게임 코드의 6개 상태 지원은 별도 작업·검증 범위다.
- 현재 페이지 ID 0:1은 기존 기록에서 가져왔고 페이지 이름은 새 스크린샷에서 확인했다.
