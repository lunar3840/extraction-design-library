# 적 탄도·출혈 생존 하한·V키 자동 의료 변경 기록

## 사용자 지시 요약

- 적이 발사한 총알의 궤적이 보이게 한다.
- 출혈 피해로 체력이 1까지 감소할 수는 있지만 출혈만으로 사망하지 않게 한다.
- V키를 짧게 눌렀을 때 현재 상태에서 가장 필요한 의료품을 자동 판별해 사용한다.
- 의료 관련 변경 내용은 완료 후 Codex의 `탑뷰 의료 시스템 설계 구현` 작업에도 전달한다.

## 기획 의도와 해결하려는 문제

- 플레이어가 피격 원인과 적의 사격 방향을 즉시 파악할 수 있도록 전투 가독성을 높인다.
- 출혈을 즉시 치료해야 하는 강한 압박으로 유지하되, 출혈 틱 하나만으로 플레이가 갑자기 종료되는 상황을 막는다.
- 의료 휠을 열 여유가 없는 전투 중에는 짧은 V 입력만으로 출혈, 위급한 체력 손실, 외상 순서에 맞는 치료를 시작하게 한다.

## 변경 전 상태 및 문제점

- 적의 히트스캔 판정과 피해 처리는 있었지만 화면에 표시하는 탄도 렌더러가 생성되지 않았다.
- 출혈 틱이 일반 피해 함수에 들어가 체력이 0이 되고 사망 이벤트까지 발생했다.
- 짧은 V 입력 및 상태별 추천 로직은 현재 소스에 이미 구현되어 있었으나, 이번 요청 기준으로 다시 확인할 증빙이 필요했다.

## 실제로 바꾼 부분

- 적 총기 발사마다 실제 히트스캔의 시작점과 충돌점(미충돌 시 최대 사거리)을 잇는 밝은 탄도를 생성한다.
- 탄도는 적의 시야 공개 여부와 관계없이 보이며 0.15초 뒤 사라진다. 근접 공격에는 생성하지 않는다.
- 출혈 전용 피해 경로를 분리해 생존 중인 플레이어의 체력이 출혈 때문에 1 아래로 내려가지 않게 했다. 직접 피해 등 기존 치명 피해는 그대로 사망시킬 수 있다.
- V키 짧은 입력은 기존 구현대로 0.25초 전에 놓으면 추천 의료품을 즉시 사용하고, 오래 누르면 의료 휠을 여는 동작을 유지했다.
- 적 탄도 생성·종료와 출혈 생존 하한에 대한 회귀 검사를 추가했다.

## 어떤 방식으로 변경했는지

- 적 공격 판정에서 모든 펠릿의 최종 광선 끝점을 얻은 뒤 재사용 가능한 `LineRenderer`를 표시한다.
- 프레임 단위로 표시 종료 시각을 확인해 탄도를 숨기며, 비활성화 시에도 즉시 정리한다.
- 출혈 피해는 현재 체력이 1 이상일 때 1을 하한으로 감산한다. 이미 다른 피해로 1 미만이지만 생존 중인 상태라면 체력을 역으로 회복시키지 않고 현재값을 하한으로 삼는다.
- 의료 추천 우선순위는 출혈 지혈 → 체력 40% 이하의 효율적 회복 → 진통이 필요한 외상 → 일반 체력 회복 순서임을 실제 인벤토리 데이터로 확인했다.

## 변경 후 기대 효과와 확인 결과

- 적 사격 1회에서 활성 탄도 렌더러 1개가 생성되는 것을 확인했다.
- 적 전투 전체 자동 검사에서 발사, 탄도 표시, 표시 시간 종료, 사망 후 공격 차단을 포함한 모든 항목이 통과했다 (`enemy_checks_after_3.log`).
- 체력 1인 출혈 상태에서 2초가 지나도 체력 1, 사망 `False`, 출혈 유지 상태임을 확인했다.
- 출혈 상태의 V키 추천 결과가 `med_tourniquet_b / StopBleeding`임을 확인했다.
- 격리 프로젝트의 스크립트 컴파일은 성공했다. 전체 신체·의료 검사 묶음은 이번 변경과 별개인 `automatic surgery target prioritizes torso before leg and arm` 항목에서 중단되어 해당 로그를 `body_hit_checks_after.log`에 남겼다. 이번 범위의 출혈 하한은 별도 결정론적 검사와 화면 증빙으로 통과를 확인했다.

## 관련 스크린샷 및 비교 시점

- 적 탄도: `before_enemy_trajectory.png` ↔ `after_enemy_trajectory.png`
  - 동일한 1600×900 결정론적 Unity 검사 화면에서 발사 1회 후 활성 탄도 렌더러 수를 비교했다(0 → 1).
- 출혈 생존 하한: `before_bleeding_floor.png` ↔ `after_bleeding_floor.png`
  - 동일한 조건에서 체력 1, 출혈 상태로 2초 경과 후 결과를 비교했다(체력 0·사망 → 체력 1·생존).
- V키 자동 의료: `before_v_auto_medical.png` ↔ `after_v_auto_medical.png`
  - 동일한 출혈 및 인벤토리 조건에서 지혈대 추천 결과가 유지됨을 확인했다. 이 기능은 변경 착수 시점에 이미 구현되어 있어 전후 모두 통과한다.
