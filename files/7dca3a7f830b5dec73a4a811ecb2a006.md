# A맵 적 배치 · 인간형 증원 및 Unity 적용

작성일: 2026-10-15. 상태: Unity 배치 적용 및 실제 Play 검증 완료.

## 사용자 지시와 기획 의도

인간형을 조금 늘리고 기존 배치안을 Unity에 적용한다. 외곽을 포함하여 기계가 주적이며, 중정비동은 기계 영역이다. 구역 난이도는 고정하고 반입가치로 적 능력치를 자동 조절하지 않는다. 인간형과 기계형은 상호 적대하며 플레이어가 교전에 개입할 때 직접 피해, 거리, 시야, 현재 표적 유지에 따라 반응한다. 네임드 홈은 고정하고 출격마다 후보 일부만 선택한다.

일반 인간형을 기존 제안 4명에서 7명(서측 Scavenger 3명, 동측 Scavenger 2명+Suppressor 1명, 외곽 Scavenger 1명)으로 늘렸다. 일반 기계 37기, 네임드 3~4기로 출격당 47~48개체다. N1 Breacher가 선택되면 인간형 총수는 8명이다. 이 수치는 첫 실제 배치의 조정값이며 영구적으로 고정할 사용자 요구로 취급하지 않는다.

## 변경 전 상태

09:28의 실제 A맵 편집 씬은 저장된 깨끗한 상태였고 전투 적은 0개였다. 다운로드한 인간형 GLB 3종은 텍스처와 65본 스킨을 포함하지만 원본 애니메이션 클립은 없었다. 구매한 Mech Constructor 패키지는 캐시에 있었고 프로젝트 내 적용이 필요했다. 기존 적 전투는 플레이어 단일 표적을 가정했다.

`backup/A.unity`, `backup/A.prefab`, `source_before/`에 원본을 보존했다. `BASELINE.txt`, `BEFORE_PROTECTED.txt`, `before_editor.png` 및 7개 실제 맵 카메라 렌더는 수정 전에 저장했다. 사후 이미지를 전 이미지로 대체하지 않았다.

## 실제 변경

- Unity 패키지를 가져오고 인간형 3종과 기계 5종의 전투용 외형 프리팹을 새 경로에 구성했다. 원본 다운로드와 패키지 원본을 덮어쓰지 않는다.
- A맵에 일반 적 44개 슬롯(각각 A/B/C 위치 후보)과 네임드 5개 고정 홈을 직렬화했다. 출격 때 구역별 후보 하나를 선택하고 네임드 명단을 한번 추첨한다. 귀환 때 해당 출격의 적을 정리한다.
- 네임드는 N1/N2 중 1명, N3/N4/N5 중 2명, 20% 확률로 미선정 후보 1명을 추가한다.
- N1 볼트: 서측 해체 작업장 (150.06,195.28). 원안의 엔진 충돌체를 피해 1m 이동.
- N2 롤백: 남측 적치장 (260,312).
- N3 차단기: 전력시설 외부 (455.20,107.00). 원안의 변압기·전선 충돌체를 피해 6m 이동.
- N4 봉인자: 부품창고 서측 검사 동선 (393,190).
- N5 감독관: 중정비동 내부 (260,218).
- 위 좌표는 맵 좌상단 기준 동쪽 X, 남쪽 Y이며 월드 좌표는 별도 기록한다.
- 표적 선정은 양 진영과 플레이어를 동일한 위협 평가에 넣는다. 현재 표적을 유지하는 가중치와 전환 지연을 두고, 직접 피격은 신속한 전환 조건이다. 동진영은 의도적 공격 대상으로 선택하지 않는다.
- NPC의 치명타는 플레이어 개인 처치 퀘스트로 처리하지 않는다. 발사체·근접 피해에 실제 공격자 출처를 전달한다.
- 각 적의 이동 활동 반경과 몸체 폭 검사를 추가했다. 반경 밖의 상대에게도 시야·사거리 내 대응 사격은 가능하지만 추격 이동은 활동 반경에 제한된다.
- 배치 생성 오류는 거점 저장 상태로 복구한다. 이 복구는 탈출 보상이나 상점 주기를 증가시키지 않는다.
