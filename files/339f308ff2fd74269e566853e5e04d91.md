## 사용자 지시와 기획 의도
앞선 자료 순차 업로드를 완료한 뒤 기획 라이브러리 UI를 데이터 편집기와 동일한 스타일로 변경한다. 두 도구를 오갈 때 시각적 연속성을 확보한다.

## 변경 전과 실제 변경
기존 크림색 본문/녹색 사이드바를 편집기 기준 슬레이트 배경, 반투명 패널, 민트 강조, 둥근 탭·버튼으로 변경했다. Noto Sans KR 글꼴을 기존 편집기 원본에서 라이브러리 전체 본문 문자 기준으로 서브셋했다. 검색, 분류, 원문 연결, 이미지 비교와 색인 데이터는 유지했다. 편집기 소스는 읽기만 했으며 수정하지 않았다.

## 방법과 주요 파일
planning-library-web/glass-theme.css, apply-glass-theme.mjs, worker/shell.js, worker/index.js, .gitignore, preview-worker.mjs. CSS 덧씌우기 및 WOFF2 자산 응답을 추가하고 기존 Worker/R2 저장소 연결을 유지했다. 원본 프로젝트 자료 및 이미지에는 변경 없음.

## 검증 결과
- 자료 업로드 완료 후 UI 작업 착수: 문서 1,358/1,358, 웹 이미지 7,398/7,398. 현재 게시 이미지는 최대 1440px 웹 열람용이며 원본 그대로가 아니다.
- Worker 테스트 통과: 셸 응답, 인증 없는 쓰기 차단, 이미지 대기 표시, 해시 검증 및 읽기, 경로 검증.
- 로컬 검색 ‘흰자’ 11개 결과 확인. 390px 작은 화면에서 문서 가로 넘침 없음(clientWidth/scrollWidth 모두 383).
- 공개 배포 후 1,043개 항목과 업로드 완료 표시, 상세 원문/전후 이미지 실제 로딩 확인. 첫 비교 이미지 2개 모두 complete=true, naturalWidth=1440.
- 변경 전후 메인 및 상세 스크린샷 저장. 같은 기본 브라우저 뷰포트로 비교하며 상세는 체스트리그 기록의 편집기 전후 화면이다.
