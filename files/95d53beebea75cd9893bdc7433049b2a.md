# after05 렌더 실패와 수정 후보

- 실제 오류: `outputs/change_records/2026-10-29/edel-shading-first-pass/UNITY_SESSION.log` 112978–112986행. Unity 6 RenderGraph가 `Invalid imported texture. Both a color and a depthStencil format are provided`를 보고했고, 호출 지점은 production `ToonOutlineFeature.cs:229`의 `renderGraph.ImportTexture(frontHandle)`이다. 그 뒤의 `ZBinningJob` 예외는 렌더 실패 후속 오류다.
- 원인: V33 전면 깊이 마스크는 `RenderTextureFormat.RGFloat` 색상과 24비트 깊이 버퍼를 함께 가진다. 이 RT를 RenderGraph의 읽기 전용 색상 텍스처로 import하면 해당 Unity 버전의 형식 검사를 통과하지 못한다.
- 증빙 영향: `after05/MANIFEST.json`은 18/18 완료이나 모든 PNG가 동일한 해시 `5E76E0ACC1D23C037B99CAA4F7F9CE98A41568CAC3C3C5473E2468228CF0A9C3`와 W03 화면이다. 플레이어/카메라 위치 로그는 달라 렌더 결과가 갱신되지 않은 것으로 판단한다. after05 화면으로 효과를 판정할 수 없다.
- 최소 수정 후보: staging `outline_guard/ToonOutlineFeature.cs`는 `ImportTexture`, `UseTexture(front)`, 비소유 `RTHandle` 래퍼를 제거한다. 카메라별 material의 마스크 텍스처와 유효 플래그, 프레임·카메라·해상도 보호는 유지한다. V33은 `beginCameraRendering`에서 마스크 명령을 실행한 뒤 URP RenderGraph가 이 패스를 기록한다. 외부 마스크는 RenderGraph가 생성하거나 갱신하지 않는다.
- 후보 검증: Unity Bee Runtime 응답 파일로 전체 C# 외부 컴파일 `EXIT=0`, 오류 0, staging 변경 파일 경고 0. Feature SHA256 `4D00B3127654C41F602CF8C6ED1A0E49BCC18B95A67442E02A238DE85F644252`. HLSL 및 실제 화면은 다음 Unity 실행에서 확인해야 한다.
