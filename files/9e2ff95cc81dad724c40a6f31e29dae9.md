# Figma HUD 배치·타이포그래피 정리

- 날짜: 2026-10-21
- 대상: EXTRACTION · Modern Glass UI Kit / Gameplay · HUD & Overlays
- 사용자 지시: 배치·크기·폰트·문구 정렬을 더 고민하여 개선.
- 범위: 일반 HUD(13:708), 위급 HUD(13:855), 탈출 진행 HUD(13:1423)와 관련 재사용 컴포넌트. Unity 프로젝트는 수정하지 않음.

## 기획 의도와 변경 전 문제

메뉴용 큰 카드와 글자 위계를 게임 HUD에도 사용해 미니맵/시간, 무기/스킬이 과도한 공간을 차지했다. 무기와 빠른 사용 아이템의 정렬 폭이 다르고, 상호작용 대상·거리·수색 동작이 분리되어 정보가 반복되었다. 탈출 진행 화면에는 진행 중 메시지와 완료 메시지가 동시에 표시되었다.

## 실제 변경과 방법

- Figma 네이티브 프레임·텍스트·컴포넌트 인스턴스로 편집. 기존 색상/유리 효과/여백 변수 재사용.
- 화면 바깥 여백 48px, 하단 그룹 종료선 y=1032로 통일.
- 미니맵 264×224 → 208×176.48. 시간 카드 264×114 → 208×48. 구역명은 미니맵 헤더에 배치.
- 목표 카드 344×128 → 296×104. 항목은 좌측, 진행 수치는 우측에 배치하고 문구를 축약.
- 무기·빠른 사용 그룹 600×176 → 460×156. 무기 224×88, 아이템 슬롯 80×56. 빠른 사용 줄은 무기 그룹 중앙에 정렬.
- 스킬 그룹 480×100 → 340×72. 항목명과 입력키/상태를 2행으로 배치. 키는 고정 크기 상자의 중앙에 정렬.
- 상호작용 대상·거리·동작을 264×80 패널로 통합. 대상명은 왼쪽, 거리는 오른쪽, 입력과 동작은 다음 행.
- 상태 이상 180×52 → 112×36. 위급 화면의 가방 중량 초과 문구를 실제 상태에 맞게 정리.
- Noto Sans KR 유지. HUD 스타일 6종 추가: 12/18, 14/20 Regular, 14/20 Medium, 16/24 Medium, 20/28 Medium, 28/36 Medium.
- 탄창 수와 예비 탄약은 기준선 정렬. 수치의 중요도에 따라 크기를 구분.
- 캐릭터 위 HP/스태미너는 유지하고 위젯과 캐릭터 에셋 사이 간격 20 → 12. 기존 캐릭터 위치·모델·머리색 유지.
- 숫자 없는 58px 수분·에너지 원형과 아래부터 차는 반투명 채움은 유지.
- 탈출 진행 패널 400×100을 상단 중앙에 배치. 진행 중에는 상호작용과 완료 토스트를 숨겨 상태 메시지 충돌 해소. 숨긴 노드는 편집 가능 상태로 보존.
- HUD/WeaponCompact(4), AbilityCompact(4), QuickSlotCompact(1), InteractionCompact(3), ConditionCompact(3) 생성. 문구·키·아이템은 컴포넌트 속성에서 편집 가능.
- 새 가이드 57:1158 ‘12 · HUD layout & typography’에 실제 크기 샘플과 정렬 규칙 추가.

## 검증과 확인 결과

- 일반·위급·탈출 전체 화면 및 새 가이드의 Figma 렌더를 육안 검토.
- 1차 검토에서 기존 텍스트의 검정 폴백 색과 변형별 기본값 중복을 발견하여 색 변수의 실제 색값 및 명시적 인스턴스 문구로 수정.
- 최종 텍스트 컨테이너 이탈 0건(4개 화면/가이드 각각). 폰트 모두 Noto Sans KR.
- 일반/위급/탈출의 가시 자손 수 145/157/144, 가이드 193. 각각 실제 텍스트·벡터·컴포넌트로 구성.
- 이미지 채움은 작은 개별 아이템/무기 에셋과 캐릭터만 사용. UI 전체 스크린샷을 디자인 레이어로 넣지 않음.
- 최종 위급 상태에서 00 / 120, 보조 무기 12 / 48, 출혈/다리 외상/탈진 표시 확인.
- 1920×1080 Figma 시안 검증이며 실제 Unity 배경·다른 해상도에서의 가독성 검증은 아직 하지 않음.
