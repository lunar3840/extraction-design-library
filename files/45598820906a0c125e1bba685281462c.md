# 헬멧 돔 비율 복원·상의 제거 착용 테스트

2026-09-04. 대상 `C:/UnityProject/escape`, 검증 `C:/tmp/EscapeHelmetRefit`.

## 문제와 변경

원본 Battle Royale Props 헬멧을 변형 없이 렌더링해 비교했다. 원본은 둥근 돔이며, 이전 피팅의 비균일 축소가 앞뒤 길이를 과하게 줄였다. 눈가의 검은 사각형은 이전 작업에서 추가한 고글 가림판이었다.

- 돔을 원본 비율 그대로 균일 확대했다. 플레이어 헬멧의 앞뒤 깊이는 이전 약 .58에서 원본 비율 기준 약 .77로 복원했다. 얼굴·눈·본 스케일은 변경하지 않았다.
- 원본 렌즈와 프레임을 별도 고글 메시로 분리해 얼굴별 폭·위치와 측면 아래 테두리를 조정했다. 돔을 함께 찌그러뜨리지 않는다. 검은 `Goggle side padding` 오브젝트를 제거했다.
- 방탄복 상단의 어깨끈 높이를 조정했다. 기존 여섯 본에 연결된 몸통 스키닝은 유지한다.
- 플레이어 UnityChan의 상의·큰 소매를 착용 중 제거했다. 하의와 손은 남긴다. 패키지의 의상 Skin 메시에는 완전한 몸통/팔이 없으므로 얇은 이너와 테스트용 팔 보완 메시를 추가했다. 원래 팔의 겹치는 부분을 착용 사본에서 교체한다. 원본 FBX를 수정하거나 완성된 기본 몸체가 있는 것처럼 취급하지 않았다.
- `SdArmorRig`가 자식 이너/팔의 뼈까지 연결하도록 확장했다. 해제하면 모든 추가 부품이 사라지고 원래 상의·소매·피부 메시가 돌아온다.
- Misaki/Yuko는 기존 의상을 유지하며 헬멧과 어깨끈 피팅만 수정했다. 적에게 장비 자동 지급은 추가하지 않았다.

## 확인

Unity Play Mode 연동 검사 **63 PASS**, 최종 검사 로그에 컴파일 오류/Exception/FAIL 없음. 실제 가방 장착·해제·파손·비활성화·가방 교체, 원래 메시 복원, 방탄복/이너 뼈 연결, 실제 고글 메시 존재, 검은 눈가 패딩 부재를 확인했다. 원본 돔 위쪽 정점의 상대 위치가 균일 배율을 유지하는 것도 검사했다.

총을 든 Idle/Walk/Run 각 네 시점의 양손 그립, 현재 InventoryPortrait의 장비 스키닝 복사도 통과했다. 동작별 세 방향과 인벤토리 렌더를 실제 카메라로 확인했다. 검사 후 적 캐릭터의 이마와 고글 간격만 추가 조정하고 세 캐릭터 정면/측면/후면을 다시 렌더링했다.

이미지:

- `Original-Helmet-Shape.png`: 변형 없는 원본 헬멧.
- `Dome-Detail.png`: 현재 플레이어 정면·측면·후면, 헬멧과 어깨 확대.
- `Dome-Player_UnityChan.png`, `Dome-Ranged_Misaki.png`, `Dome-Melee_Yuko.png`: 왼쪽 원래 모습, 오른쪽 세 방향 착용 모습.
- `Dome-Gun-Idle.png`, `Dome-Gun-Walk.png`, `Dome-Gun-Run.png`, `Dome-InventoryPortrait.png`: 최신 플레이어 동작/인물 뷰.

보완한 팔/이너는 현재 장착 테스트를 위한 기본 형상이다. 패키지 제작자가 제공한 완전한 기본 몸체나 최종 수작업 캐릭터 모델은 아니다. 새 동작이나 체형에는 추가 보정이 필요하다. 검증은 별도 에디터에서 했으며 사용자가 열어 둔 원본 Unity 씬을 직접 조작한 검증은 아니다.
