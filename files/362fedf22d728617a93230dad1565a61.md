# UI 시안 v03 — 모던 반투명 스타일

- 사용자 지시: Apple SwiftUI와 같은 모던하고 깔끔한 스타일을 참고해 시안을 개선한다.
- 의도: 기존 반투명 UI의 소재감을 유지하면서 여백, 둥근 형태, 명확한 글자 위계로 정돈한다.
- 변경 전: v02의 직선 패널, 다수의 테두리, 각진 선택 표시가 전술 단말 느낌을 강하게 냈다.
- 실제 변경: 큰 연속 곡률 모서리, 중성 회색 프로스트 유리 패널, 캡슐형 버튼과 상태 표시, 부드러운 선택 영역, 넓은 간격을 적용한 콘셉트 이미지를 생성했다.
- 방식: 기본 이미지 생성 도구로 v02 참조 편집. Apple HIG Materials 공식 자료(https://developer.apple.com/design/human-interface-guidelines/materials)를 참고했다. Swift 코드를 작성하거나 Apple UI를 그대로 이식한 작업은 아니다.
- 확인: 3열 구조, 은보라 머리 SD 캐릭터, 동료 칩, 민트 선택/행동 강조가 유지되고 대형 둥근 유리 패널과 여백으로 인상이 바뀐 것을 육안 확인했다.
- 한계: 생성된 콘셉트로 실제 게임 구현 화면이 아니다. 6×6 표시와 실제 생성 격자, 수치, 일부 레이아웃은 구현 단계에서 정합성 조정이 필요하다.
