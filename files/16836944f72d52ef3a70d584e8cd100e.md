# 신규 총기 34정 실총 외형 대조·SD 체형 보정 (Blender 원본)

## 사용자 지시 요약

- 모딩을 건드리기 전에 총부터 웹의 실총 외형과 대조해 제대로 구현됐는지 확인하고, 미흡한 곳은 고친다. 단, 게임 캐릭터 체형(SD)에 맞게 수정할 것.
- 종류별 대표 1정씩 먼저 분석 → 수정 → 나머지 27정.
- MP5 상단 레일은 실물엔 없지만 모딩용으로 남긴다.

## 기획 의도와 해결하려는 문제

- 11-15 GPT 단계에서 34정을 만들 때 사진 대조는 했지만, 캐릭터 손이 닿는 거리(개머리판 길이·앞손 위치)는 총마다 제각각이었다. 모딩 부품을 붙이기 전에 총 자체의 실루엣과 손 위치 기준을 맞춰 두어야 이후 파지·장전 모션이 총마다 깨지지 않는다.

## 판정 기준

- 실물 치수(전장·총열)는 웹 자료로 확인. 긴 총은 실물보다 더 줄여 둔 상태(AR 기준 0.76~0.94배)라 SD 체형용 의도로 보고 유지.
- SD 기준은 에델 장착이 검증된 기본 AR: 개머리판 길이(방아쇠~개머리판 끝) 1.27, 앞손 거리(방아쇠~앞손잡이 중앙) 0.90.
- 개머리판 길이 1.36 초과 → 1.27로 단축 / 펌프식 앞손 거리 1.1 초과 → 리시버 바로 앞으로.
- 권총은 손잡이가 두껍고 키가 약간 큰 것을 SD 손 크기용으로 보고 유지.

## 보정한 10정

- AK47·RPK: 윗면 레일 돌기 9개 삭제, 목재 윗덮개 추가, 가스블록을 45° 경사 형태로 교체.
- MP5: 장전손잡이를 실총처럼 왼쪽으로 옮김. 상단 레일은 모딩용으로 유지.
- Remington 870·회수 산탄총: 펌프 앞손잡이를 리시버 바로 앞으로(앞손 거리 1.20 → 1.00), 손잡이 소켓도 같이 이동.
- M16(1.42)·SR-25(1.37)·M249(1.45)·분대 지원 기관총(1.45): 개머리판을 1.27로 단축.
- M249: 총열 열차폐판 추가. M14: 금속 앞 밴드 추가.
