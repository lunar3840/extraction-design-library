# Serin / Edel 컨셉아트 수정 기록

## 사용자 지시 요약
기존 결과에 게임의 실제 캐릭터가 없음을 지적하고 Serin과 Edel로 제작하도록 수정 지시.

## 기획 의도와 해결하려는 문제
임의의 은발 캐릭터를 만든 오류를 바로잡고, 두 기존 캐릭터의 얼굴·머리색·헤어 구조·SD 표현을 실제 참조에 맞춘다. 니어 오토마타와 니케는 폐허 분위기와 그림 표현의 방향으로만 사용한다.

## 변경 전 상태
v01 두 장은 임의의 은발 포니테일 여성이 주인공이었다. 제작 시작 전에 해당 원본을 before_keyvisual.png / before_character_sheet.png로 복사해 보관했다. 신규 생성 결과를 이전 상태로 위장하지 않았다.

## 실제 변경 및 방식
- Serin 정면 원본과 Edel 정면 모델링 참조를 직접 확인하고 이미지 생성 도구에 입력했다.
- Serin의 갈색 옆묶음, 분홍 모자, 장밋빛 갈색 눈, 검은 재킷과 흰 후드, 반바지·타이츠·부츠를 반영했다.
- Edel의 옅은 청보라색 머리, 푸른 눈, 굵은 옆 땋은 머리, 정수리 고리형 잔머리를 반영했다.
- Edel은 찾은 자료가 기본 바디 자료라 슬레이트 블루 전술복을 새 시안으로 제안했다. 기존 확정 의상으로 주장하지 않는다.
- 두 사람의 SD 표현을 유지한 폐허 회수 작전 키비주얼과 캐릭터 시트를 각각 제작했다. 시트에는 새 키비주얼도 추가 참조해 일관성을 높였다.

## 확인 결과 및 한계
두 결과를 육안으로 확인했다. Serin과 Edel이 각각 구분되며 머리색, 모자/땋은 머리, 눈 색, 핵심 의상 특징이 반영되었다. 시트는 두 전신과 얼굴 확대, 키비주얼은 두 인물과 침수된 산업 폐허를 보여준다. 두 그림 모두 발끝까지 포함한다. 생성 일러스트로 세부 장비·패치·비율이 원본 모델과 정밀하게 일치하는 모델링 도면은 아니다. Edel 전술복은 검토용 제안이다.
