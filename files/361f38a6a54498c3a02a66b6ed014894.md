# 니어풍 룩 04 — 그늘 속 지붕, 홀 쪽 땅, 풀 솎기 후보 (2026-11-25)

## 사용자 지시 요약

- 2026-11-25 09:42 KST "03 pilot 괜찮네. 너가 말한 문제들도 해결 시도 부탁함. 기획 라이브러리 게시도 해주고."
- 지시 1회, 구현 1회차(촬영 2번).

## 기획 의도와 해결하려는 문제

03 회차 끝에 남긴 문제 가운데 룩 쪽에서 풀 수 있는 것을 처리한다.

1. 나무 그늘에 든 차량 지붕이 다시 거의 검게 보인다.
2. 풀밭에 초록 얼룩이 남는다.
3. 풀이 화면을 덮는다(색으로는 못 푼다고 적었던 것).

## 실제로 바꾼 부분과 방법

전부 룩 테스트 전용이다. 전역 키워드가 꺼져 있으면 수정 전과 같은 화면이다.

1. 그늘 올림(`darkLiftShade` 0.06): 거의 검은 환경 색이 그늘에 있을 때만 하늘빛을 조금 돌려준다. 지금 게임에서 하늘 반사가 하던 일이다.
2. 홀 쪽 땅: 남은 초록 얼룩의 원인은 `Escape/LookV16/GroundSlice`(홀 주변 땅) 셰이더에 룩 훅이 없던 것이었다. 훅을 넣어 다른 땅과 같은 조명·색조를 따르게 했다. (03 회차에서 "다른 색 값을 가진 풀 카드로 보인다"고 적은 추정은 틀렸다.)
3. 풀 솎기 후보(`grassThin`): 룩이 켜져 있을 때 풀 카드를 몇 미터 크기의 불규칙한 섬 모양으로 잘라 내 땅이 드러나게 한다. 풀 재질을 쓰는 렌더러 1,693개에만 값을 주고, 나뭇잎은 건드리지 않는다. 맵·프리팹·풀 배치는 그대로다.
   - 드러난 땅이 어두운 갈색이라 땅 밝기 값(`groundGain`)을 추가했다.
   - `nier04_thin`: 풀 약 45% 솎음, 땅 색조 올리브 모래. `nier04_thin_sand`: 약 55% 솎음, 모래색 땅.

## 확인 결과

- 그늘 속 차량 지붕: 검은 덩어리에서 어두운 청회색 면으로 읽힌다(`close_car`).
- 홀 쪽 초록 얼룩: 사라졌다(`tree_1`).
- 풀 솎기: 풀이 섬처럼 남고 사이로 땅이 드러난다. `thin_sand`는 "모래 바탕에 풀이 드문드문"에 가깝다(`close_open`, `prop_2`).
- 끄면 수정 전과 같은 화면: `CONTROL_VS_PREVIOUS.txt`(tree_3 차이 0, 나머지는 연기·잎 흔들림 잡음 범위).
- 컴파일 오류 0, 셰이더 오류 0.

## 한계 / 확인하지 못한 것

- **풀 솎기는 색을 그리는 단계에서만 잘라 낸다.** 깊이·노멀을 미리 그리는 단계에는 풀이 그대로 있어서, 잘라 낸 자리에 옅은 그림자(AO)나 외곽선 흔적이 남을 수 있다. 확대해서 재 보지 않았다. 제대로 하려면 풀 배치 자체를 줄여야 하고 그건 맵 쪽 땅 작업이다.
- 풀을 솎으면 맨땅 위 나무 그림자가 풀 위보다 훨씬 어둡게 보인다.
- 솎는 무늬는 위치로만 정해지고 길·건물·담 같은 맥락을 모른다. 건물 벽 밑에 풀이 모이거나 길가가 비는 식의 배치는 못 한다.
- 맵 쪽 작업장 거리 후보 위에서 같이 찍지 못했다. 그쪽 도구에 밖에서 부를 수 있는 진입점이 없고 지금도 수정 중이라 건드리지 않았다. 맵 쪽 후보용 `WorkshopPaveDetail.shader`에도 훅을 넣지 않았다.
- 건물 얼룩 셰이더(`StainOverlay`)가 조명을 안 받는 점은 그대로 두었다. 최종 화면에서 어긋나 보이지 않아 뒤로 미뤘다.
- 직접 플레이, 빌드, 성능은 확인하지 않았다. 건물 낡음은 시범 블록 3동, Play 중에만.
