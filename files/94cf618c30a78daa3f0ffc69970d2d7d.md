# 익스트랙션 사용자 지시별 변경 기록 감사

감사일: 2026-10-21, 한국 시간. 실행 중인 다른 작업은 계속 변하므로 아래 집계는 감사 스냅샷 기준이다.

## 결과

에델 눈 흰자 정리의 누락 `CHANGE_RECORD.md`를 보완했다. 실제 사용자 중단 요청과 마지막 경계 수정의 검증 미완료 상태를 확인했으며, 완료 작업으로 소급 변경하지 않았다.

파일 폴더 수만 세던 이전 확인보다 범위를 넓혀 Codex 대화 36개와 시나리오 관련 ChatGPT 대화 7개를 조사했다. Codex 메시지 대조표는 550행(자동화 전달 1행 포함), ChatGPT 사용자 메시지 대조표는 34행이다. 한 지시에 여러 후속 메시지가 붙거나 한 변경 기록에 여러 지시가 통합된 경우가 있으므로 이 수치는 독립 구현 작업 수가 아니다.

추가로 2026-09-10의 **11개 사용자 지시**에서 당일 작업별 정식 변경 기록 대응을 찾지 못했다. 에델 경계 관련 2건과 UI·로비 관련 9건이다. 이것은 각각 별도 작업 11개가 유실됐다는 뜻이 아니며, 이어진 지시를 한 작업으로 묶을 수 있다. 결과 응답과 일부 모델/보고 자료는 남아 있어 원본 작업 자체가 전부 소실됐다는 결론도 아니다.

## 대조 범위와 방법

- 로컬의 익스트랙션·Unity escape 관련 세션 17개 파일, 고유 대화 15개에서 사용자/assistant 메시지를 추출했다. 서브 에이전트의 작업 프롬프트는 인간 지시로 중복 집계하지 않았다.
- 로컬 세션 파일이 없던 과거 Codex 대화 21개는 앱 읽기 도구로 보충했고, 페이지가 있는 경우 마지막 페이지까지 조회했다. 원문은 `codex_sources/`에 보존했다.
- 로컬 작업 목록은 읽기 전용 메타데이터 조회와 앱 목록을 함께 대조했다. `THREAD_COVERAGE.json`은 실제 파일 유무를 포함한다. 로컬 원문이 없는 것만으로 대화가 삭제됐다고 추정하지 않았다.
- ‘익스트랙션 시나리오’ 사이드바에는 세계관/메인부관/게임 에셋/맵 구조 ChatGPT 대화 4개가 있었다. 같은 게임의 주인공·히로인(2)/(3) 대화 3개도 포함했다. 같은 섹션에 있는 `hojin29`는 별도 게임 프로젝트이므로 포함하지 않았다. 프리미어 작업·C드라이브 정리·단순 영상 확인도 게임 변경 감사에서 제외했다.
- ChatGPT 응답은 사용자가 요청한 Chat Pro 작업의 출처로 조사했으나 반환 자료에 실제 모델 등급이 없으므로 모두 Pro로 확인됐다고 쓰지 않는다.
- `CODEX_INSTRUCTION_LEDGER.csv`: 사용자 원문, 메시지 ID, 대화, 시각, 해당 CHANGE_RECORD 경로와 판정 근거를 기록했다. 시각 열은 UTC이며 한국 시각은 +9시간이다.
- `CHAT_INSTRUCTION_LEDGER.csv`: 시나리오 관련 사용자 지시 원문, 응답 결과 링크, 확인 상태, 출처 JSON을 기록했다.
- `EVIDENCE_INVENTORY.csv`: 당시 136개 증빙 폴더의 기록 문서·전후 이미지 존재와 파일 크기를 점검했다. 0바이트 이미지는 0개였다. 반복 촬영·iterations 사본도 이미지 수에 포함되므로 독립 전후 쌍 수로 읽으면 안 된다.
- 대표 이미지 직접 열람과 전체 파일 존재 점검은 구별했다. 모든 과거 이미지의 디코딩·육안 검토를 완료하지 않았다. OneDrive 원격 이미지의 일괄 읽기가 지연되어 해당 읽기만 중단하고 파일 메타데이터 점검으로 마무리했다.

## 전체 대조 상태와 남은 확인 범위

Codex 550행 중 기록 대응 확인 194행, 지침 도입 전 소급 참고 227행, 추가 기록 누락 확인 11행이다. 나머지는 질문·분석·승인·자동화 또는 아래의 미확정 항목이다. 구체 분류는 `AUDIT_SUMMARY.json`과 CSV를 따른다.

- 인계 자료 관련 지시 3행은 `MAP_THREAD_REVIEW` 등 산출물은 확인되지만 독립 CHANGE_RECORD 대응은 확인되지 않았다. 실제 게임 변경 누락 3건으로 세지 않는다.
- 응답 원문이 없는 Codex 지시 2행은 완료/기록 누락을 확정하지 못했다.
- 단순 질문·검토 77행은 파일 변경 증거가 없는 참고 질의로 유지했다. 키워드만으로 변경 작업에 포함하지 않았다.
- 현재 Figma 연결 작업은 감사 중 시작돼 `before_user_mention_list.png`가 저장된 상태를 확인했다. 계속 진행 중이므로 after/CHANGE_RECORD 미완료를 과거 완료 작업의 누락으로 세지 않았다.
- 전체 디스크의 모든 파일 변경을 사용자 지시에 일대일로 역추적한 결과는 아니다. 현재 접근 가능한 사용자 대화·보존된 기록 전체를 대상으로 대조했고, 접근 도구가 반환하지 않은 이력은 미확정 범위로 남겼다.

## 지속 사용

앞으로 기록 감사에는 익스트랙션 Codex 작업과 익스트랙션 시나리오의 ChatGPT 작업을 함께 포함한다. ChatGPT 결과에는 대화 ID·사용자 지시·결과 버전·로컬 파일 경로/해시·전후 이미지·제안/확정/구현 상태를 연결한다. 로컬 AGENTS.md가 다른 ChatGPT 대화의 지침까지 자동 설정하거나 원격 파일을 자동 내려받는 기능은 이번 감사로 생기지 않는다.

- `CODEX_INSTRUCTION_LEDGER.csv`, `CHAT_INSTRUCTION_LEDGER.csv`: 지시별 대조표
