# UI 스타일 예시 v01

- 사용자 지시: Figma 또는 이미지 생성으로 게임 UI 스타일 예시를 먼저 보여 달라.
- 의도: SD 캐릭터·동료 칩·격자 인벤토리에 맞는 청회색/민트 전술 단말 스타일을 검토한다.
- 변경 전 자료: 기존 실제 게임 인벤토리 스크린샷을 before_reference_inventory.png로 복사했다. 과거 화면을 참고로 사용한 것이며 이번 작업 직전의 실시간 캡처는 아니다.
- 제작 내용: 이미지 생성 기본 도구로 인벤토리 + 루팅 시안을 새로 제작했다. 어두운 패널, 읽기 쉬운 한글, 정돈된 아이템 썸네일, 동료 칩 소켓, 장비 카드와 선택 강조를 표현했다.
- 방법: 실제 인벤토리 이미지를 참고해 시각적 재설계. 은보라색 머리·보라색 눈·SD 비율을 참고하고 캐릭터 의상은 시안용 전술복으로 표현했다. 실제 캐릭터 모델을 수정하지 않았다.
- 결과: after_concept_inventory_loot.png는 생성된 콘셉트 이미지이며 Unity 실행 결과나 구현 후 스크린샷이 아니다. 격자 칸 수, 수치, 장비 규칙은 구현 검증 전의 예시다.
- 검토: 전술 단말과 SD 캐릭터의 조합, 세 구역의 정보 구분, 민트 선택 표시와 황색 수색 표시를 육안으로 확인했다. 생성 이미지의 그리드/수치 일관성은 실제 구현 때 재설계가 필요하다.
- 전후 대응: before_reference_inventory.png → after_concept_inventory_loot.png. 카메라 일치 비교가 아닌 기존 UI와 제안 스타일의 비교다.
- 주요 산출물: after_concept_inventory_loot.png, GENERATION_PROMPT.txt.
- Unity/Figma 게임 파일 및 에셋 변경 없음. 앱 종료 없음.
