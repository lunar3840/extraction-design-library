# Figma Modern Glass UI Kit — 변경 기록

- 사용자 지시: 승인한 Apple SwiftUI 참고 모던 반투명 시안을 기반으로 Figma 새 작업 페이지에 직접 수정 가능한 UI 키트를 제작한다.
- 저장 위치: 사용자가 선택한 믕봉믕's team의 새 Design 파일 EXTRACTION · Modern Glass UI Kit.
- 링크: https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0
- 페이지: Modern Glass · UI Kit (0:1).

## 기획 의도
반투명 소재, 큰 둥근 모서리, 민트 강조, 한글 글자 위계를 재사용 가능한 편집 구조로 제공한다. 전체 화면을 이미지로 고정하지 않고 네이티브 텍스트·벡터·오토레이아웃·컴포넌트 인스턴스로 구성한다.

## 변경 전
신규 파일에 빈 Page 1만 있었다. Figma에서 빈 페이지를 캡처한 before_empty_page.png는 실제 빈 페이지의 1×1 투명 캡처다. 기존 파일이나 게임 화면을 수정한 것이 아니다. 스타일 기준은 outputs/change_records/2026-10-21/ui-style-example-v03-modern/after_concept_inventory_loot.png.

## 실제 제작
- 01 Foundations & editing guide: 기본 스타일·사용법.
- 02 Components & states: 버튼, 인벤토리 슬롯, 아이템, 배지, 키캡, 상태 바, 장비 카드, 동료 칩, 유리 패널, 탐색 필.
- 03 Inventory + Loot: 1920×1080, 3열 예시, 실제 6×6 가방, 27칸 점유/19아이템.
- 04 Replaceable image assets: 개별 교체 가능한 콘텐츠 이미지와 벡터 에셋.
- 2개 변수 컬렉션/변수 48개(의미색 별칭18개), Noto Sans KR 글자 스타일7개, 효과 스타일2개.
- 컴포넌트 세트10개, 상태44개. 예시 화면에 네이티브 텍스트68개와 인스턴스122개.

## 제작 방식
Figma use_figma / generate-library / generate-design / create-new-file 지침에 따라 제작했다. 기존 파일은 빈 상태이고 Unity C# IMGUI에 Code Connect 매핑은 없음을 확인했다. iOS26 라이브러리에서 버튼/스타일/변수를 조사했으나 게임 전용 격자·키보드 상태와 한글 글꼴, 선택 시안의 색을 편집하기 위해 자체 네이티브 컴포넌트와 로컬 변수를 만들었다. 의미색은 원시색에 별칭 연결하고 색·간격·모서리를 변수에 연결했다.

캐릭터는 승인 시안에서 이미지 생성 기본 도구로 분리한 투명 배경 예시 에셋이며, 실제 게임 캐릭터 모델 변경이 아니다. 은보라색 원래 머리색을 유지했다. 물/탄약/공구/에너지/부품/소총은 프로젝트의 기존 개별 PNG를 사용했다. 의료품·헬멧·방탄복·배낭·조작 아이콘은 편집 가능한 SVG 벡터다. 전체 시안 스크린샷은 Figma에 업로드하지 않았다.

## 검증·수정 결과
기본판의 자동 높이, 상태별 예시 문구, 의료품 벡터의 크기 상속, 다중 칸 아래의 격자선 문제를 시각 검토 후 수정했다. 최종 원본 크기로 화면을 렌더링해 텍스트·배치·격자·반투명 배경을 확인했다. 구조 검사에서 빈 코드 문법 변수0개, ALL_SCOPES 변수0개, 잘못된 폰트/접힌 텍스트0개, 예시 프레임의 이미지 통째 채움 없음으로 확인했다.

## 범위와 편집 방법
UI 구조·문구·색상·간격·반투명도·상태는 Figma에서 직접 수정할 수 있다. PNG 캐릭터/아이템은 개별 이미지 채움으로 교체 가능하며, 3D 모델 자체를 편집하는 기능은 아니다. 목업의 수치·콘텐츠는 디자인 검토용이다. 게임 동작·드래그 프로토타입·Unity 적용·Code Connect 연동은 수행하지 않았다. ChatGPT/Figma/Unity 앱 종료와 기존 작업 탭 종료 없음.
