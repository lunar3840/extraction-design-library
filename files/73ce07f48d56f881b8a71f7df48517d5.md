# 니어풍 룩 03 — 색 되살리기와 남은 문제 처리 (2026-11-25)

## 사용자 지시 요약

- 2026-11-25 09:10 KST "나쁘진 않은데... 너무 색감이 옅다는 문제는 있긴하네. 중간을 잡아야 할 것 같은데 어렵다. 나머지 너가 말해줬던 문제점도 해결해보고, 색감도 조금 건드려봐야 할 것 같아. 어쨌든 툰셰이더 적용하는 카툰형태인데 너무 칙칙하긴하네..."
- 지시 1회, 구현 1회차(촬영 2번: 후보 4개 → 최종 3개).

## 기획 의도

- 니어풍 02는 환경 채도를 절반으로 낮추고 풀을 마른 색으로 당겨서, 밝긴 하지만 색이 빠진 화면이 됐다. 카툰 화면에 필요한 건 "색 면이 또렷하고 빛과 그늘의 색이 다른 것"이다.
- 그래서 채도를 되돌리되(0.5 → 0.85) 지금 게임의 짙은 초록으로 돌아가지는 않게, 햇빛은 따뜻하게 그늘은 푸르게 갈랐다. 안개는 더 옅게, 후처리는 색을 빼는 쪽에서 조금 더하는 쪽으로.

## 실제로 바꾼 부분과 방법

1. 색 (설정만): `settings/StylizedLook_override_nier03.json`.
   - 환경 채도 0.5 → 0.85, 그늘 색 (0.85, 0.88, 0.95) → (0.70, 0.80, 1.00), 주변광 하늘색을 푸르게 (0.58, 0.64, 0.74), 해 (1, 0.95, 0.84).
   - 안개 색을 중립 회색 (0.78, 0.80, 0.80), 시작 14 범위 260(02는 10 / 190).
   - 후처리 채도 -6 → +4, 대비 2 → 8, 노출 0.28, 블룸 0.30.
   - 풀 색조는 마른 짚색 대신 올리브 초록 (0.52, 0.58, 0.34)으로 25%.
   - 대안 둘: `…_nier03_soft.json`(채도 0.70, 02 쪽에 가까움), `…_nier03_vivid.json`(채도 0.98, 후처리 채도 +8).
2. 풀밭 초록 얼룩: 땅 메시용 색조(`groundTint`)를 룩에 추가. 지면 셰이더 2종이 `EscapeStylizedGroundLit`을 부른다. 값 (0.50, 0.55, 0.34) 75%.
3. 포장 셰이더 3종(`D12RoadFinish`, `D11Pavement`, `V34HallApproachPavement`)에 룩 훅.
   - 첫 시도(after_11)는 **실패: 길이 검푸르게 나왔다.** 이 셰이더들은 원래 해의 `distanceAttenuation`을 곱하지 않는데 이 길 메시들에서는 그 값이 0이라, 훅이 햇빛을 0으로 계산했다. 훅 안에서 원래 식처럼 1로 두어 고쳤다(after_12).
4. 건물 낡음 강한 단계(`StageALookBuildingAging.Level = 2`, 촬영 옵션 `agingstrong`).
   - 얼룩 재질을 실행 중 사본으로 진하게(불투명도 0.34/0.30 → 0.62/0.58, 에셋은 그대로), 장 수 117 → 254, 벽 밑에서 올라오는 때 추가.
   - 풍화 세기 0.72 → 0.92(빗물 자국 0.88, 이끼 0.32), 지붕 0.42 → 0.62.
   - 담쟁이 건물당 2곳 → 3곳, 잎 1,002 → 2,524장.
5. `StylizedLook.Rescan()` 추가: 룩을 켠 뒤에 생긴 물체를 다시 훑는다(아직 호출하는 곳 없음, 맵 후보와 같이 찍을 때 쓸 것).

## 확인 결과

- 색: 외벽의 노랑, 자갈의 붉은 갈색, 지붕의 청록, 풀의 올리브 초록이 돌아왔다. 02보다 덜 바랬고 지금 게임보다 밝다. 그늘이 푸르게 갈려 빛·그늘 구분이 더 분명하다.
- 풀밭 초록 얼룩: 줄었다(`n03_ground.jpg`). 완전히 없어지지는 않았다 — 남은 것은 다른 색 값을 가진 풀 카드로 보인다(재질 조사에서 땅 메시는 크기 제한에 걸려 목록에 안 나와 직접 확인은 못 했다).
- 포장 길: 룩을 켠 화면에서 다른 면과 같은 조명 규칙으로 밝게 나온다(`pilot_S01`, `pilot_block`).
- 건물 낡음: 벽의 빗물 줄, 벽 밑 때, 지붕 얼룩, 담쟁이가 게임 카메라 거리에서도 보인다.
- 끄면 수정 전과 같은 화면: `CONTROL_VS_PREVIOUS.txt`. tree_3 차이 0, 나머지는 같은 셰이더끼리 찍어도 나오는 잡음(연기·잎 흔들림) 범위.
- 컴파일 오류 0, 셰이더 오류 0.

## 한계 / 확인하지 못한 것

- 나무 그늘에 든 차량 지붕은 다시 거의 검게 보인다(`close_car` 왼쪽 차). 햇빛 받는 지붕은 갈색으로 읽힌다. 그늘 색을 푸르고 어둡게 한 영향이다.
- 풀이 화면을 덮는 문제는 그대로다. 색만 바꿨다.
- 얼룩 재질(`StainOverlay`)은 조명을 안 받는 셰이더라 룩을 켜도 색이 그대로다.
- 맵 쪽 후보용 `WorkshopPaveDetail.shader`에는 훅을 넣지 않았다(그쪽 파일).
- 맵 후보(작업장 거리) 위 촬영, 직접 플레이, 빌드, 성능은 하지 않았다.
