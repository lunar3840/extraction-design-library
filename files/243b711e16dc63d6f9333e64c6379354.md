# 중간보고 워드 시각 자료 보강

## 사용자 지시 요약
- 워드 문서만 수정한다. PPT는 수정하지 않는다.
- 세린 소녀형 바디와 에델 성인형 바디의 재사용 계획을 이미지로 비교한다.
- 에델의 정면·좌측·후면·우측 참조 이미지 네 장을 모두 싣는다.
- 사용자가 첨부한 Tripo 에델 작업 화면을 포함한다.

## 기획 의도와 해결하려는 문제
기존 보고서는 바디 재사용을 문장으로만 설명했고 에델 참조 이미지도 정면 한 장뿐이었다. 제작 의도와 모델링 과정을 화면으로 바로 확인할 수 있도록 비교·참조 자료를 보강했다.

## 변경 전 상태
- 5쪽 워드 문서의 2쪽에 체형 재사용 계획이 글로 적혀 있었다.
- 5쪽 화면 자료에는 에델 정면 참조 한 장과 UV·텍스처 결과가 있었다.
- Tripo 실제 작업 화면은 없었다.

## 실제 변경 내용과 방식
- 기존 문서의 시스템·기획 요약은 유지하고 캐릭터 설명 문구를 비교 자료와 일치하도록 정리했다.
- 에델 정면 참조를 갤러리에서 빼고, 사용자가 제공한 Tripo 에델 모델·텍스처 작업 화면을 삽입했다.
- 세린·에델의 정면 모델 화면을 같은 크기로 배치해 소녀형/성인형 바디를 비교했다. 재사용은 계획 단계임을 명시했다.
- 에델의 정면·좌측·후면·우측 참조 이미지를 별도 2×2 배열로 배치했다.
- 원본 워드 파일이 열려 있어 별도의 `_수정본.docx` 파일로 저장했다. PPT 파일은 변경하지 않았다.

## 변경 후 확인 결과
- 수정본 7쪽을 Word에서 PDF로 내보내 전 페이지를 이미지로 확인했다. 이미지 누락, 페이지 넘침, 캡션 잘림이 없다.
- Tripo 화면, 바디 비교, 에델 4면 참조가 각각 워드에 표시된다.
