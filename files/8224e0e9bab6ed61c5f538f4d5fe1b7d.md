## Remaining risk and decision

The normal-path original mirror outputs agree for the tested 300 frames and the combined worker paths were exercised. The mirror does not directly compare Part points/tree/epoch/cache arrays or final hair vertices. More importantly, this run had zero fallbacks and no injected worker failure. Refit failure is designed to discard scratch and run serial, while Distance failure may leave exclusive Part/cache worker state changed before `Apply` returns false with `UNVERIFIED`; recovery requires a fresh Bind. The separate V17 fault QA and moving/contact acceptance must examine those paths before adoption. A clean single-implementation inventory A/B is also required for the user's actual lag. At the final read, the owned Editor scene restoration marker existed while temporary V16 source and original mirror were still installed; final cleanup/recompile is root-owned.
