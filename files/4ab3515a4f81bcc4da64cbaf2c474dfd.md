# V33 독립 검증 기록

2026-10-07 최종 Play 재검증 기준. 제작 코드는 수정하지 않고, 별도의 `StageABuildingV33Workflow` 및 `StageABuildingV33Play` 검사로 확인했다. Unity 실행·에셋 저장은 메인 담당자가 수행했다.

## 판정

- `PRESERVATION_VALIDATION.txt`: PASS. 기존 트랜스폼·메시·콜라이더 및 원본 재질 파일 바이트가 유지됐고, 기존 조명 기록도 동일하다. 추가 콜라이더 없음.
- `after_PLAY_VALIDATION.txt`: PASS, 실패 0. 같은 발/카메라 좌표의 실제 Play 전후 14쌍 중 W03·W04·E08·PARTS의 지붕/외벽 가림은 청록 실루엣 대신 플레이어와 바닥을 보여 주는 국소 투명화가 작동했다. W03 접근→가림→실내→재접근 4단계 전환도 기대한 상태와 일치했다.
- 68개 건물의 실제 입구 인근 및 실내 중심, 총 136개 Play 시점 확인: 불투명한 실제 건물 메시의 삼각형이 카메라→플레이어 선분을 가리는 29개 시점에서 국소 투명화 누락 0개. 실패 전용 캡처 0개.
- TOOLS 실내는 기존 충돌 프록시가 가림으로 오판해 청록 표시를 냈지만, 실제 보이는 불투명 메시 삼각형은 플레이어를 가리지 않았다. 새 동작은 투명화를 억지로 켜지 않고 원래 캐릭터를 그대로 표시한다. `before_play_TOOLS_inside.png`와 `after_play_TOOLS_inside.png`를 직접 대조했다.
- HALL 2층 보조 시점 `(38.5, 8.04, 20.5)`에서 실제 `Factory2Wall04` 벽 삼각형 가림과 국소 투명화가 함께 확인됐다. `after_play_HALL_2F_positive.png`는 보조 후 화면이며 별도 동일 좌표 전 사진은 없다.
- B맵 복귀 때 A 비활성화와 주변광·안개·태양 복원이 PASS. 13,525개 맵 렌더러의 원본 재질 참조 불일치 0개, 남은 투명화 렌더러 0개.
- 최종 저장·재로드 검사 `SETTLED_SAVE_RELOAD_VALIDATION.txt`: PASS. 첫 저장 직후 엄격한 appearance 해시 비교는 신규 V33 재질의 의존성 해시 178개가 저장 시 확정되며 실패했다. 그때도 재질 경로·이름·렌더러 상태 차이는 0개였다. 저장 상태에서 같은 14쌍 Play와 136시점 검사를 다시 통과한 뒤, 다음 재로드에서 확정된 해시를 포함한 appearance, 원본 재질 바이트, 기하·조명·컴포넌트 상태가 모두 일치했다. 최초 실패 기록은 삭제하거나 성공으로 위장하지 않고 보관했다.

## 화면 확인

`before_play_W03_outside.png` / `after_play_W03_outside.png`: 불투명 지붕 위 청록 복제 캐릭터가 사라지고, 작은 지붕 창을 통해 원래 분홍 캐릭터와 바로 아래 바닥이 보인다. 창 바깥의 지붕은 유지된다.

`before_play_TOOLS_inside.png` / `after_play_TOOLS_inside.png`: 잘못 더해졌던 청록 표시가 제거되고, 지붕이 열린 실내에서 기존 캐릭터가 자연스럽게 보인다. 새 불필요한 원형 투명화는 없다.

`before_inside_POWER.png` / `after_inside_POWER.png` 및 `before_inside_E04.png` / `after_inside_E04.png`: 전후 카메라 위치가 일치하며, 새 바닥·벽 마감이 기존 배치와 장비를 바꾸지 않고 적용됐다. 정적 건물 증빙은 실내 68쌍, 접근 9쌍 모두 저장돼 있다.

## 성능과 범위 한계

최종 저장·재로드 후 Editor Play에서 예열된 `RefreshForDiagnostics` 100회 평균은 W03 가림 시점 1.1802 ms/호출, 실내 비가림 시점 0.1126 ms/호출이다. 관리 스레드 할당 측정값은 양쪽 0.0 B/호출이었다. 이는 CPU 갱신만의 진단이며 GPU 렌더링·네이티브 할당·배포 빌드 프레임 시간은 포함하지 않는다.

68개 전체를 전 동선·전 카메라각으로 주행한 것은 아니다. 검사는 각 건물의 실제 출입구 인근에서 가능한 샘플과 실내 중심, 선택된 14개 완전 대응 Play 시점, W03 전환 경로 및 HALL 2층 근벽 시점에 한정된다. 동일 프레임에 여러 진단 포즈를 전환해 기록한 지붕 렌더러 개수에는 삭제 예약된 임시 오버레이가 포함될 수 있으므로 물리 메시 수 증가로 해석하지 않는다. 저장 전 `iterations/03-before-saved-replay`와 저장 후 루트의 W03·POWER·HALL 2F 화면을 직접 대조했으며 외형과 국소 가림 동작은 유지됐다. 런타임 프레임 변화로 PNG 파일 바이트가 같지는 않으므로 픽셀 단위 완전 동일성은 주장하지 않는다.
