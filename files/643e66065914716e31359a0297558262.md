# 자연 잠식 폐허 시안 도구

사용자 요구는 낡은 건물·파손된 구조물·덩굴이 함께 보이는 지상 폐허다. 이번 회차는 그중 덩굴 생성과 재료별 노후화 도구를 만들고 별도 사본에 결합하는 단계다. 전체 A맵 배치, 파손 형상 자동 생성, 전역 조명 변경은 이번 결과에 포함하지 않는다.

## 덩굴

Unity 상단 `Escape → Environment → Surface Ivy Tool`에서 원본 대상 또는 프리팹을 선택한다. 차량·벽·지붕 사전 설정과 시작점·제외 영역을 조절할 수 있다.

- `생성 때 새 무늬`를 켜면 생성 버튼을 누를 때마다 새 씨앗값으로 줄기와 잎 분포를 다시 만든다. 씬을 열거나 플레이를 시작할 때 자동으로 바뀌는 방식이 아니다.
- 결과의 `현재 무늬 시드`를 기록하고 `현재 시드 고정 · 같은 무늬 재현`을 누르면 같은 원본·시작점·제외 영역·설정에서 동일한 결과를 재생성한다. 씨앗값이 달라도 모든 결과가 예술적으로 적절하다는 보장은 없으므로 가림·입구·군집 편중은 검토한다.
- 잎은 이전의 군집 사이 여백을 유지하면서 한 군집의 연속 잎을 소폭 늘렸다. 시작 줄기와 가지의 기존 성장 난수 흐름을 밀도 변화로 뒤섞지 않는다.
- 마음에 드는 결과는 새 프리팹으로 굽는다. 새 생성물은 `Assets/Escape/Art/SurfaceIvy/Generated/` 아래 고유 폴더에 저장된다. 원본 에셋 파일을 덮어쓰지 않는다.

## 표면 노후화

`Escape → Environment → Weathering Tool`에서 건물·폐차·소품을 선택하고 `미리보기 / 다시 생성`을 누른다. 원본을 읽어 별도의 미리보기 씬에 작업 사본을 만든다. `차량 / 석재·벽돌 / 도장면`은 조정 시작점이다.

전체 강도, 녹·도장 벗겨짐, 분진·오염, 빗물 흔적, 낮은 부분 이끼, 퇴색, 무늬 크기와 씨앗값을 조절한다. 자동 재료 분류는 회반죽·도장면, 벽돌·콘크리트·석재, 금속을 구별한다. 벽돌이나 회반죽을 단순히 metallic 값만 보고 금속으로 바꾸지 않는다.

`새 프리팹 저장`은 생성 재질의 별도 복사본과 원본 텍스처 연결·노후화 값을 저장하고 재읽기까지 확인한다. 결과는 `Assets/Escape/Art/SurfaceWeathering/Generated/` 아래 고유 폴더다. `미리보기 지우기`는 미리보기 사본을 정리한다.

## 두 효과 함께 사용

먼저 노후화 사본을 새 프리팹으로 저장하고, 그 사본에 덩굴을 생성한 뒤 다시 별도 프리팹으로 굽는다. 그러면 두 도구의 설정과 결과를 함께 가진 프리팹이 된다. 이번 실제 폐차·S06 외벽·지붕 시안과 조합 프리팹의 정확한 경로는 채택된 `study_*/SAVED_PREFABS.txt` 및 CHANGE_RECORD.md에 기록한다.

기존 덩굴이 있는 작업 사본에서 다시 생성하려면 기존 도구 소유 덩굴을 지운 뒤 재생성한다. 이미 노후화된 프리팹에 노후화를 겹쳐 누적하지 않는다. 사본에서 원본 재질 복원 후 새 Preview를 만든다. 원본 재질과 도구가 만든 재질은 marker에 별도로 기록된다.

## 보호와 현재 한계

- 기존 URP Lit과 정확한 `Escape/BuildingD09/WeatheredLit`의 색·기본 텍스처·노멀·금속·AO·발광·UV와 D09 노후화 값을 유지한 위에 추가 효과를 적용한다. Standard 원본은 대응 필드를 변환한다. 지원하지 않는 커스텀 shader는 임의 교체하지 않고 적용 결과에 SKIP 이유를 적는다.
- 별도 유리·타이어·목재·식생·overlay 재질과 충돌 전용·비활성·그림자 전용 renderer는 보호한다. 하나의 텍스처/재질로 차체·유리·좌석이 합쳐진 모델은 자동으로 부분을 의미 구분하지 못한다. 그런 모델은 material slot 또는 별도 마스크 준비가 필요하다.
- 노후화는 표면 색·거칠기·재료 반응을 다룬다. 벽 구멍·철근·깨진 창·실루엣 파손을 새로 모델링하는 기능은 아니다. 참고 이미지의 최종 완성도에는 그런 형상과 지면·잔해·조명 구성이 함께 필요하다.
- 현재 높이 기준은 생성 시 renderer의 월드 수직 높이에 맞춘다. 저장 후 크기를 크게 바꾸거나 회전/비균일 스케일을 바꾸면 높이별 습기 흔적을 다시 생성해 확인한다.
- 이 시안의 직접 렌더·pass 검사는 실제 게임의 가림 처리, 모든 렌더러 경로와 모든 shader 조합, 전체 맵 FPS를 검증한 결과가 아니다. 전체 적용 전에 실제 게임 화면과 예산을 별도로 확인해야 한다.
- 기존 A맵 씬·맵 프리팹·AI·가림·캐릭터·전역 조명·renderer·기존 D09 shader/재질 원본은 이번 시안 때문에 수정하지 않는다.
