# 사용자 지시 원문과 적용 범위

지시일: 2026-10-26 (KST)

> 샘플로 한번 해봐

직전 논의: 맵의 게임 규칙·배치는 Unity에서 관리하고 건물의 외벽·실내·지붕·세부 모델은 Blender에서 제작한 뒤 분리해 가져오는 방식. 첫 시험으로 기존 A맵 중형 창고 한 동을 선택해 현행 치수와 문 위치, 파밍 동선을 유지하며 전후 비교한다.

범위 판단: 기존 D09 건물 제작 주제의 후속 구현이며, W10 반출 검수창고 한 동을 대상으로 한다. 전체 맵 변경, 새 게임 규칙이나 적/전리품 수치 변경으로 해석하지 않는다. 모델 제작·Unity 삽입·검증·기획 라이브러리 게시까지 이번 기록에 연결한다.

모든 전후 증빙은 해당 시점 실제 Unity 화면을 저장한다. Blender 렌더와 첫 제작 후보는 별도 표시하며 변경 전 화면으로 사용하지 않는다.
