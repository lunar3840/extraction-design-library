# UI Kit Unity 공통 스타일 계약

상태: **런타임 적용 완료, 최종 실화면·입력 검증 중.** 아래는 초기 계약이며 최종 소스/증빙 상태는 CHANGE_RECORD.md를 따른다.

## 기준과 단위

- 최신 전투 HUD: Figma103:2538 / DMZ 반투명·하단 중앙 무기·오른쪽 소모품3개(2×2 자리 중 하나 비움)·확대 스킬.
- 인벤토리/캐릭터/Hover는 별도 담당자가 소유하며 기존 Figma 검토본105:2987과 Tooltip105:2984를 이어 간다.
- UI Kit의 semantic 색과 V1–V6/T 구분을 유지한다. 메뉴 가독성을 위해 HUD의 낮은 배경 alpha를 모든 메뉴에 일괄 적용하지 않는다.
- 런타임 좌표는 UiTheme의1600×900 logical 좌표다.1920에서Scale1.2이므로 Figma32px은 약26.7 logical이다. 텍스트/슬롯을 화면 전체와 함께 임의 축소하지 않는다.

## 메인이 제공할 API

```csharp
UiTheme.Surface(Rect rect, Color fill, Color edge, float radius = 20f);
UiTheme.Pill(Rect rect, Color fill, Color edge);
```

Surface는 edge1px, 안쪽 top light, 하단 shade, soft shadow를 그린다. Pill은 height/2 곡률이다. UI 입력이나 상태는 소유하지 않는다. 기존 Text/Press/Begin/Panel/GUILayout skin 사용 계약은 유지한다.

| 역할 | 계약 |
| --- | --- |
| Accent | #72EBD1 |
| TextPrimary | #F5F7FB |
| Muted | #C5CDD7 |
| PanelFill | #283340 / alpha0.79 |
| HudFill | #060D14 / alpha0.42 |
| Border | white / alpha0.16 |
| Major panel | radius26–28 logical |
| Card / small surface | radius16–20 logical |
| Pill / compact button backing | height/2 |

최종 런타임 조정: 작은9-slice 버튼의 상하 border 합계가 실제 높이를 넘지 않도록 공통 버튼/HudGlass/HudCard는 radius/border12, InventoryButton10, Primary20으로 맞췄다. Surface/Pill은 실제 높이에 맞춰 곡률을 계산한다. 큰 패널26 및 인벤토리 카드16은 유지한다. 검색 입력란은 radius10과 민트 포커스 테두리를 사용한다. 비활성 주요 버튼은 별도 회색 표면으로 구분한다.

토큰 이름은 메인이 UiTheme에서 제공하는 실제 필드를 따른다. 서로 다른 파일에서 같은 색의 임의 사본을 만들지 않는다. 기존 경고/위험/등급/지도종류 색은 의미를 유지한다.

## 적용 원칙

- 개별 사각 카드·행·배지·이름표의 배경만 Surface/Pill로 교체한다.
- 기존 GUI.Button/Press의 이벤트·enabled·Queue 및 hit rectangle을 유지한다. 새 Surface는 그리기만 하며 입력 영역을 추가하지 않는다.
- GUI.Button/GUI.Box의 shared skin으로 이미 둥글게 그려지는 면은 불필요하게 배경을 중복해서 덧그리지 않는다.
- 글자와 아이콘은100% opacity를 유지한다. 배경을 밝게/투명하게 만들기 위해 부모 전체 alpha를 낮추지 않는다.
- 기존 실제 카탈로그 문구·숫자·조건을 유지한다. Figma의 옛 자리표시자/수치를 런타임에 복사하지 않는다.
- 한국어·긴 설명·재료 목록·오류 문구가 잘리지 않도록 기존 줄바꿈·스크롤·행 높이를 보존한다. 필요시 표시 여백만 조정한다.
- Fill을 모두 둥근 면으로 바꾸지 않는다. 전체 화면 dim/letterbox,1px 구분선, 지도 grid/경계/스케일 바/루트·마커 좌표용 선은 현재 의미를 유지한다.
- 렌더 순서, GUI.depth, 그룹/스크롤 좌표계와 내부 pointer 변환을 보존한다.
- 맵 데이터·월드 배치·스폰·경로·저장/경제/성장/대화 진행 상태는 변경하지 않는다.

## 최종 아이템 슬롯 계약

최종 아이템 슬롯 계약(후속 사용자 지시 우선): 시각 카드 간격6logical을 유지하고, 큰 아이콘과 우하단 개수만 표시한다. V/T·이름·의료 잔량/보호/손상 글자는 hover와 상세에서 읽는다. 슬롯 배경과 외곽선에 등급색을 반영하며 탄약은 실제 관통 T, 나머지 물품은 기존 가치 V 색을 쓴다. 퀵슬롯은 의료 잔량 대신 실제 보유 개수와3/4/5 키를 표시한다. Figma의6개 기존 tint 변수 알파24%, runtime의 normal/selected 색 혼합24%/32%는 각각의 배경 합성 방식에 맞춘 값이다. 카드 표시/hover/click은3px inset을 쓰되 원래 grid pitch·칸수·drag grab 원점은 유지한다.
