# 세린에 C01 바디 모션·감정표현 적용 — 82액션, 왼팔 관통 보정 (Blender 원본)

## 사용자 지시 요약

- 에델과 같은 모션 세트(총기별 모션 + 감정표현)를 세린에도 적용한다.
- 무기 대기 시 팔이 몸을 뚫는 문제를 고친다.

## 기획 의도와 해결하려는 문제

- 캐릭터마다 모션을 따로 만들지 않고 한 세트를 공유하려면, 체형이 다른 캐릭터로 옮겼을 때 파지와 관통이 깨지지 않아야 한다.

## 진행 회차

- **리타깃**: 본 매핑 + 월드 회전 차이 전달, 골반·발 이동량 0.92배. 팔·다리는 2본 IK, 무기는 가슴 기준. 얼굴은 에델 값을 세린 셰이프키로 환산(드라이버 54개).
- **왼팔 관통 (v2)**: 에델의 팔꿈치를 모은 파지를 가슴·배 볼륨이 큰 세린에 그대로 옮기자 왼팔이 최대 4.1cm 들어감. 프레임마다 총·양손 위치와 팔꿈치 회전을 탐색해 줄임.

## 결과

- 액션 82개 `SER_C01_*`.
- 왼팔 관통 최대 4.1cm → 대부분 1.2~1.5cm.

## 한계 / 확인하지 못한 것

- 소총 대기 시 총이 에델보다 약 9cm 앞으로 나옴(관통을 피한 결과).
- 세린에는 일부 눈 기울기 키가 없어 LidClose·LidArc 조합으로만 표현.
- 게임 적용·직접 플레이 확인 없음.
