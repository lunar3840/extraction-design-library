# A맵 공장 내부 표면 V23 독립 검토

검토 결론: 요청 범위인 기존 공장 내부의 재질 개선으로 승인한다. 새로운 배치·형상·충돌체 변경은 확인되지 않았다.

- 원본 스크린샷과 적용 후 스크린샷의 외관·홀·작업 구역·동서 계단·작업대·지하 계단을 같은 시점에서 비교했다. 실제 플레이의 서쪽 계단과 주출입구 전후 화면도 비교했다. 바닥 작업 구역 경계, 어두운 금속 계단·안전벽, 얇은 황색 모서리가 보이며 지붕·창·벽·기존 설비의 누락이나 분홍색 오류 재질은 보이지 않았다.
- 원본 기준에서 선택된 렌더러 169개의 단일 재질 슬롯만 7개의 V23 재질로 교체됐다. 대상 외 모든 재질 슬롯, 기존에 참조되던 재질 에셋 파일 207개, 계층·위치·메시·충돌체·조명 설정은 독립 검사에서 불변이었다. 저장 및 씬·프리팹 재열기 후 엄격한 V23 검사는 20개 통과, 0개 실패했다.
- 원본 기준 검사의 참조 번호 오탐은 백업 씬의 SHA-256 일치, 계층·기존 슬롯·기존 재질 파일 일치, 정규화된 컴포넌트·전역 설정 대조로 해결했다. 원래 기준 JSON을 덮어쓰지 않았다. 상세 증거는 `VALIDATION_COMPONENT_REFERENCE.txt`, `VALIDATION_GLOBAL_REFERENCE.txt`, `VALIDATION.txt`에 있다.
- 회귀 검사는 V14 123/123, V15 67/67 통과했다. V16 원 검사는 의도적으로 바꾼 재질 경로가 전체 시각 상태 해시에 포함되어 390 통과·2 실패했다. 승인된 169개 슬롯만 검사 중 원래 참조로 잠시 되돌린 호환성 검사는 392/392 통과했고, 이후 V23 참조를 복원해 실제 상태를 재검증했다. 원 V16 결과를 무조건 통과로 해석하지 않는다.
- 저장 후 실제 플레이 검사는 `after_PLAY_VALIDATION.txt`에서 `RESULT PASS`이며, 시작·도착 스크린샷과 지붕 아래 시점도 기록됐다. 이 검토는 재질 작업과 해당 플레이 경로를 대상으로 하며 독립 실행 빌드의 GPU 성능 측정은 포함하지 않는다.
