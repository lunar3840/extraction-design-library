# 카툰 렌더링 적용 결과

2026-09-08. 적용 프로젝트: C:/UnityProject/escape (Unity 6000.1.0f1 / URP 17.1).

기존 안뜰 배치와 게임 카메라를 유지하고 배경 14개 재질을 Hybrid Toon 셰이더로 전환했다. 3단계 명암, 차가운 그림자 색, 약한 반사와 하이라이트를 적용했다. 기존 조명·비·반사 프로브·톤매핑과 함께 동작한다. URP RenderGraph 외곽선은 명시적으로 표시한 게임 카메라에만 적용한다. 별도 유료 에셋이나 엔진 교체는 없다.

캐릭터에는 실행 중 복제한 재질을 사용한다. 얼굴·머리카락의 원래 텍스처, 색, UV, 알파 컷아웃, 양면 설정을 보존하고 장비 교체 시 새 재질도 처리한다. 기능을 끄면 원본 재질을 복원한다. 공유 테스트 환경과 캐릭터 표현에도 적용되므로 Stage A에만 국한된 설정은 아니다.

- PlayChecks.txt: 최종 통합 검사 27개 PASS.

## 검증 범위와 제한

별도 복제 프로젝트에서 출격, 재장전, 사격, 이동, 비, 실제 반사 텍스처, 캐릭터 재질 복원과 재적용, 원래 텍스처 연결을 검사했다. 외곽선 켜기/끄기 실제 렌더 결과에서 19,152픽셀의 차이를 확인했다. 두 셰이더 컴파일과 전경 생성이 성공했다. 검증된 재질과 렌더러 설정, 참조 메타 파일을 본 프로젝트에 반영했다.

캐릭터 원본 SD 리소스 292개와 기존 맵 프리팹/생성 코드 2개의 SHA256이 모두 이전과 동일하다. 적 테스트 객체의 근접 화면은 가시성 설정 때문에 외형 검증 자료로 채택하지 않았다. 헬멧별 실제 착용 화면 전체 검증, 실행파일 빌드 및 60FPS 성능 측정은 수행하지 않았다. 이미지에는 IMGUI HUD가 포함되지 않는다.

Unity에서 스크립트 가져오기가 끝난 후 SystemsTest의 Play를 다시 시작하면 적용된다. 명시적 재적용 메뉴는 Escape > Toon > Apply Hybrid Toon Style. 백업은 work/toon-rendering-backup에 있다.
