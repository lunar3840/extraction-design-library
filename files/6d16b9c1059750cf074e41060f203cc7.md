# 정보창 하단 조작 안내 제거

사용자 후속 지시: 상세 페이지 밑의 클릭 상세·드래그 이동 안내는 표시하지 않아도 된다.

- `InventoryHoverTooltip.cs`의 공용 hover 카드 하단 조작 안내 렌더와 구분선을 제거했다. 따라서 가방·루팅·상점·퀵슬롯이 같은 표시 규칙을 따른다.
- 기존 하단 안내용 높이도 제거했다. 설명이 있으면 설명 끝, 설명이 없으면 잔량/상태 끝, 둘 다 없으면 아이콘 영역 끝을 기준으로 14px 논리 여백을 남긴다.
- 제목·가치·가격·수량·무게·관통 티어·실제 의료 잔량·설명·티어색은 보존했다.
- 기존 hover 등록 API의 hint 인자와 내부 상태는 인터페이스 호환성을 위해 유지한다. 클릭·드래그·거래 콜백은 수정하지 않았다.

변경 직전 실제 화면은 `after_loot_t3_hover_1920x1080.png`, `after_loot_t6_hover_1920x1080.png`, `after_shop_food_hover_1920x1080.png`, `after_shop_purple_hover_1920x1080.png`, `after_shop_scrolled_hover_1920x1080.png`에 보존되어 있다. 이들은 최초 티어색 변경 후, 이번 하단 안내 제거 전 화면이다. 최종 대응 화면과 실제 마우스 검증은 메인 변경 기록에서 구분한다.

단계별 코드는 `source_before_footer/`와 `source_after_footer/`, 해시는 `source-footer-before-manifest.json`과 `source-footer-after-manifest.json`에 있다. 최종 통합 `source_after/`와 `source-after-manifest.json`의 해당 파일도 갱신했다. 이전 색상 변경 전 `source_before/`는 보존했다.

`footer-preservation-audit.json`은 이번 단계의 변경이 정확히 footer 렌더 삭제와 높이 계산뿐이며 다른 3개 색상 변경 파일이 그대로임을 확인한다. 전체 runtime C# 재컴파일은 종료 코드 0, 오류 0, 기존 경고 21이며 `compile/footer_runtime_compile.txt`에 저장했다. 이전 `compile/runtime_compile.txt`는 덮어쓰지 않았다.
