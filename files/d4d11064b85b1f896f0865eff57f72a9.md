# DMZ 참고 반투명 HUD 조정 기록

## 사용자 지시와 기획 의도

사용자가 제공한 DMZ 화면의 반투명 표현을 참고해 HUD 배경을 가볍게 조정한다. 이전에 확정한 무기 중앙 하단, 소모품 우측 2×2, 확대 스킬의 배치를 유지하면서, 짙은 배경 판의 존재감을 낮추고 글자·아이콘의 가독성을 보존하는 것이 목적이다. 참고 게임의 규칙이나 체력 배치를 도입하는 작업은 아니다.

## 대상과 변경 전 상태

- Figma 파일: `KUD4t84BL1S77c3cnb8co0`
- 페이지: `11:711` — Gameplay · HUD & Overlays
- 비교 프레임: `103:2538` — 14 · Field HUD · Compact combat · Project backdrop
- 프레임 크기: 1920×1080
- 이전 기록: `../figma-consumables-right-larger-skills/CHANGE_RECORD.md`

변경 전에는 목표·탈출, 지역명·시간·무게, 상호작용과 스킬 뒤의 어두운 배경이 상대적으로 강했다. 텍스트는 구별됐지만, 사용자가 원한 반투명 느낌보다 배경 판이 두드러졌다.

## 실제 변경

아래 수치는 작업 담당자가 보고한 Figma 속성 변경 내역이다. 그라디언트의 페인트 불투명도와 배경 노드 자체의 불투명도를 구분한다.

| 대상 | 변경한 속성 | 변경 전 → 후 | 보존한 요소 |
| --- | --- | --- | --- |
| Objective body, Extraction availability | 그라디언트 페인트 불투명도 | 100% → 50% | 텍스트·아이콘·노드 불투명도 |
| HUD/InteractionCompact | 해당 인스턴스의 로컬 Fill `#060D14` 알파 | 62% → 42% | 글자·키·크기·배치 |
| Skill caption · contrast backing 두 개 | 그라디언트 페인트 불투명도 | 100% → 50% | 설명 글자 |
| Area label · contrast backing | 배경 노드 불투명도 | 100% → 55% | 별도 형제 텍스트 100% |
| Carry weight · contrast backing | 배경 노드 불투명도 | 100% → 55% | 별도 형제 텍스트 100% |
| Operation clock | 그라디언트 페인트 불투명도 | 100% → 55% | 노드·텍스트 100% |
| Skill disc · local contrast 두 개 | 배경 전용 노드 불투명도 | 100% → 55% | 별도 아이콘·링 100% |

상호작용 인스턴스의 Fill만 공유 변수에서 분리해 로컬 값으로 조정했다. 공유 변수와 컴포넌트 원본은 변경하지 않았다. 배경 노드의 불투명도를 바꾼 항목은 그 노드의 효과에도 적용되지만, 분리된 글자·아이콘·링의 불투명도는 유지된다.

## 보존한 배치와 범위

- 무기: 좌상단 `(720, 928)`, 480×104, 중앙축 x960.
- 소모품: 좌상단 `(1224, 866)`, 166×166의 2×2 배치, 슬롯 80×80, 키 3·4·5·6.
- 스킬: 좌상단 `(1497, 872)`, 375×160, 이전 125% 확대 유지.
- 112px 수분·에너지, 캐릭터 위 체력·스태미너, 라운드·폰트·아이콘 유지.
- 원본 프레임 `69:2948`, 컴포넌트 원본, 다른 화면은 변경하지 않은 범위다.
- 코드·Unity·게임 규칙은 변경하지 않았다. 전체 UI 키트나 모든 런타임 상태의 완료를 의미하지 않는다.

## 변경 방법

Figma MCP의 조회 호출 한도로 인해 작업 담당자가 열려 있는 네이티브 Figma 화면에서 해당 HUD의 배경 속성을 편집했다. 앱이나 기존 탭을 종료·재시작하지 않았다. 결과는 실제 Figma 프레임 내보내기와 네이티브 화면 캡처로 보존했다.

이 폴더의 `before_project_export.png`는 변경 전 상태의 실제 Figma 내보내기이며, 재구성 이미지가 아니다. `after_project_export.png`는 변경 후 실제 내보내기다. 네이티브 JPG 원본은 그대로 보존하고, 같은 픽셀의 PNG 확인본을 추가했다. PNG 변환은 원본 JPG의 압축 손실을 복원하는 작업이 아니다.

## 결과와 검증

독립 검토에서 배경 판이 옅어지고 게임 배경이 더 잘 비치는 것이 확인됐다. 현재 주간 1920×1080 화면에서는 글자·아이콘·키·수량이 유지됐으며, 새 겹침이나 잘림은 보이지 않는다. 무기·소모품·스킬의 배치 변화도 보이지 않는다.

정확한 내부 속성 수치는 작업 담당자의 보고를 기록한 것이며, 독립 검토는 PNG의 외형·가독성·배치를 확인했다. 야간·역광·다른 해상도·긴 문구·경고 상태·Unity 런타임 검증은 수행하지 않았다. 자세한 독립 시각 검토는 `visual-audit.md`에 기록했다.
