# D14 A맵 자연물 교체 — 독립 검토

## 판정과 범위

**저장·재열기 후 구조 검증 35/35 통과, 실제 플레이 이동 검증 32/32 통과.** 이 판정은 최신 V35 A맵을 기준으로 한 원본 보존, 지정 Polytope 자연물의 출처와 배치, 시각 전용 50m 외곽, 표본 카메라 화면과 테스트한 이동 경로에 한정한다. 모든 카메라·시간대의 시야, 전투 시인성, 프레임타임, 실제 탈출 저장 처리는 입증하지 않았다.

독립 검증기는 `Assets/Escape/Editor/StageANatureD14Validation.cs`다. Unity 실행·저장·캡처와 제작 코드는 메인이 담당했고, 이 검토는 동결된 원본 스냅샷·검증 출력·실제 Play 기록·전후 이미지를 따로 대조했다.

## 중간 실패와 독립 검증기 보정

- candidate01은 잘못된 LOD 합산으로 삼각형 예산 검사에서 중단되었고, 원본 자연물을 숨기기 전에 롤백되었다. 미사용 생성 메시 1,131개는 삭제하지 않고 `failed_candidate_meshes/`에 복구 가능하게 옮겼으며 `ARCHIVED_UNUSED.txt`에 기록했다. candidate02~05는 밝기·외곽 과확장·풀 밀도 때문에 최종안이 아니다.
- candidate06 첫 검증은 34 PASS / 1 FAIL. 외곽 L자형 풀 청크 한 개의 *바운딩 박스 중심*이 원래 맵 안에 있는 듯 보였으나 `CENTER_DIAGNOSTIC.txt`에서 실제 13,816정점은 모두 바깥임을 확인했다. 단순 예외 처리 대신 해당 풀 청크의 모든 투영 삼각형이 원래 플레이 사각형과 교차하지 않는지 검사하도록 보완했다. 개별 나무·관목·바위 중심, 전체 정점 및 CSV 검사는 유지했다.
- 재열기 직후 첫 검증도 34 PASS / 1 FAIL이었다. 즉시 prefab source가 저장된 A맵 프리팹을 가리켜 외곽 766개를 오판했다. `SOURCE_DIAGNOSTIC.txt`는 766개 모두의 최종 원본이 Polytope, 최근접 프리팹이 해당 Polytope 5종, 첫 메시 참조가 원본과 동일함을 확인한다. 이에 검증기를 원본 source 체인·정확한 경로/GUID·최근접 경로·메시 참조를 모두 요구하도록 고쳤다. 맵·프리팹 배치는 수정하지 않았으며 최종 재검증은 35 PASS / 0 FAIL이다.

## 플레이·시각 증빙과 남은 한계

변경 전과 저장 후 `PlayerMotor`/`CharacterController` 실제 이동 시험은 각각 32/32 통과했다. 저장 후 기록 `after_play_01/OUTER_PLAY.txt`에는 울타리 변·모서리 23시도, 탈출 접근 7곳, B4→W5 335스텝, R8→W5 504스텝이 있다. 탈출은 `InsideExit`까지만 확인했고 실제 탈출 저장 거래는 실행하지 않았다. R8은 여전히 비활성 위험 진입점으로 무작위 스폰 대상이 아니다.

변경 전후 대응 인덱스는 각각 53행, 누락 파일과 카메라·표적·FOV 불일치가 0이다. 실제 Play의 32시도는 시작·끝 각 1장씩 64장으로 남았고 기록 좌표와 이미지 인덱스의 차이가 0이다. 독립 표본으로 `after_overview.png`, `after_pavers_west_close.png`, `after_grass_west_close.png`와 실제 Play 북·동·남·서 경계 및 북서 모서리 화면을 살폈다. 내부는 낮은 풀이 연속적으로 늘고 보도 잡초는 드물게 남으며, 실제 탑다운 경계 표본에서는 울타리 뒤 지형·식생이 이어져 딱 잘린 맵 끝이 보이지 않는다. 단, 건물·진입점·소품 주변에 안전 여유로 드러난 지면이 있고, 사용자 참고 상점 이미지와 동일한 품질·전 화면 완전 피복을 주장하지 않는다.

캡처 PNG는 1600×1000(16:10)이다. 50m 범위의 16:9/21:9 탑다운 프러스텀 계산은 별도 설계 근거이며 PNG의 실제 화면비와 혼동하지 않는다. 기존 `edge_*_player` 진단 카메라는 실제 런타임보다 수평을 향한 별도 시점이므로, 그 화면의 바깥 검은 영역만으로 탑다운 플레이 실패를 판정하지 않았다. 표본 밖 모든 시점, 야간/전투 시인성, 기기별 프레임타임은 미검증이다.

B4와 R8은 약 62m 떨어졌고 둘 다 W5에 이어진다. 두 경로의 실제 도달은 통과했으나 W5 종료 화면은 같은 건물 지붕에 가려 초반 적 노출·엄폐·보상 차이를 증명하지 못한다. 따라서 R8이 B4와 구별되는 위험 진입 경험이라는 주장은 보류하며 비활성을 유지한다.
