# 건축 가림 표현 구현 및 검증 상태 — iteration06 (실제 함수 CPU 분리 확인)

실제 캐릭터의 원래 색과 근방을 보이게 한다는 10/7 V33 지시를 유지했다. 청록색 인체 오버레이로 되돌리지 않았다. source actor·머리 재질·C15b/skin·조명·글로벌 outline·renderer asset·적 시야는 이 구현에서 수정하지 않는다. 하위 담당자는 production을 직접 설치하거나 Unity를 실행하지 않았고, Root가 원본 백업/전후 촬영 후 각 staging 버전을 설치·검증했다.

## 최종 구현

- 실제 활성 actor/머리/장비/무기의 Mesh/SkinnedMesh를 컴포넌트 소유 RGFloat depth×coverage/coverage 마스크로 그린다. bone·blendshape·원본 source renderer/material을 바꾸지 않고 원본 alpha cutoff/색 alpha/culling을 따른다.
- 3m×2.5m 화면 타원은 제거했다. 실제 인체·무기 모양과 작은 0.22m 투영 여백(시험 상한8~22pixel), bilinear coverage와 Gaussian 가중 fringe로 국소 건물 opacity를 전환한다. 색상 silhouette나 넓은 바닥 창을 그리지 않는다.
- opaque/veil/DepthOnly/DepthNormals가 같은 형태·깊이 함수를 공유하고 원래 ShadowCaster를 유지한다. 실제 Transparent/AlphaClip 건축 슬롯은 원본을 유지한다. D09_GlassMuted처럼 실제 Opaque인 슬롯은 원래 색·광택·normal을 보존하며 mask 안에서만 fade한다.
- imported Shell/Roof가 예전 VisualRoot/RoofCutawayRoot 밖 sibling에 있어도 명시된 건물 신원으로 찾는다. 68개 Expansion과 별도 보존 W10_BlenderSample_Shell/Roof를 합쳐69동이다. HALL 및 retained POWER/PARTS/TOOLS/CLINIC도 포함한다.
- FBX의 작은 native vertex 좌표와 큰 object scale에서도 정확한 삼각 교차를 유지하도록 절대 determinant epsilon을 제거했다. shared double 연산과 scale-relative angular guard로 world-ray t와 finite segment 범위를 보존한다. AABB는 broadphase이며 실제 삼각 검사를 대신하지 않는다.
- 실제 actor renderer world bounds의8꼭짓점을 마스크와 동일한 GPU VP/플랫폼 UV 규칙으로 투영한다. fringe+1texel을 보수적으로 더한 rectangle 밖에서는 **25개 texture read 전에 반환**한다. 카메라를 가로지르거나 잘못된 bounds는 full rectangle으로 돌아가 실제 actor를 자르지 않는다.
- 중첩된 벽·지붕의 veil이 누적돼 body가 벽색으로 덮이지 않도록 core opacity를 .01로 낮췄다. 주변의 작은 soft fringe는 유지한다. 추가 occluder RT나 전역 RenderFeature는 없다.
- iteration06은 map-owned mesh/submesh별 lazy balanced triangle BVH(leaf8)를 추가한다. 보수적 local bounds로만 가지를 제외하고 최종 hit는 동일한 double exact triangle 함수만 승인한다. 비정규화 local ray의 world t/finite segment/material slot/static-batch owned range를 유지하며, cache는 ReleaseAll에서 해제한다. 첫 mesh 진입 시 트리 생성 비용은 존재하고 warmed 시험이 이 초기 비용까지 해소한 것으로 주장하지 않는다.
- mask 준비 실패 시 원래 불투명 건물로 유지한다. 비활성/퇴장 시 원래 material 참조와 runtime resources를 정리한다.

## 실제 발견과 수정 근거

1. 첫18뷰의 전체 cyan은 shader supported/error 검사와 별개인 URP FallbackLoading의 정확한 색과 일치했다. shader-local `editor_sync_compilation`을 모든 관련4 program에 추가한 후 W03/HALL의 원래 색이 회복됐다. 전역 async 설정은 바꾸지 않았다. 첫 실패 사진과 소스는 보존한다.
2. S11은 초기 sibling 탐색 보강 뒤에도 roof가 보이지 않는 body를 덮었다. 실제 cache/renderer/material은 정상이었고, native 및 독립 world-double triangle은 세 광선 모두 hit인데 생산 함수만 miss였다. native mesh bounds가 약0.11×0.13×0.02이고 transform이 약100배여서 절대1e-6 determinant 검사가 정상 면을 버렸다. 상대 기준으로 고친 뒤 실제 roof 선택과 body 색이 회복됐다. static batching은 False였으며 관측 원인으로 주장하지 않는다.
3. POWER outside는 roof/shell 둘 다 실제 선택·삼각 hit인데 몸이 벽색의 ghost처럼 남았다. raw roof4/shell8 교차면이 있어 .20 veil 여러 층의 누적이 원래 body 색을 가렸다. .01 core로 바꾼 `power_diagnostic_639288572408510870/actual_POWER.png`를 직접 열었고 갈색 머리와 몸/복장 원래 색이 보이는 것을 확인했다.
