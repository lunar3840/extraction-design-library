# 1차 전맵 적용 독립 검증 — 후속 큰 건물 밀도 조정 이전 상태

검토 기준: 사용자 승인 2026-10-29 전맵 노후화·파손·덩굴. 이 문서는 전맵 1차 적용(잎 157,099개)의 검증 경계를 고정한다. 사용자의 이후 큰 건물 덩굴 밀도 강화 요청은 같은 주제의 다음 회차이며 이 수치에 섞지 않는다. 최종 변경 기록과 라이브러리 게시 판정은 메인 담당이다.

## 전수 분류와 저장

- `ROLLOUT_MANIFEST_REVIEW.json`: 원본 renderer 23,659개 key와 정책/Unity 결과가 1:1로 맞고 중복·미처리·실패 0. 처리 7,628개, 보호 16,031개(그중 비활성 10,328개). 활성 보호 5,703개를 처리 수에 넣지 않는다.
- 처리 7,628개 전부 실제 aged slot 1개 이상, 총 8,959개 slot. 덩굴 대표 226/226개 모두 path/stem/leaf 양수, 총 잎 157,099개. 지붕 69/69, 외벽 69/69 포함. 이것은 ledger 전수 일치이지 각 방향에서 보이는 품질의 보증이 아니다.
- 파손 후보 456개 중 실제 컷 115개, 높이 제한 295개, 저층 표면 감사 거절 46개. `CUT_BASELINE_REVIEW.json`은 115/115 원본 mesh GUID가 before 기준과 동일하며 각 컷의 허용 audit 경로 기록을 확인한다. 115건 중 9건은 저층 표면 동치 판정이므로 모든 새 정점이 바닥+2.1m 위라고 표현하지 않는다. 차량 floor+0.2m 예외에는 내부 backing을 적용했다.
- `PERSISTED_PREFAB_REVIEW.json`: 저장된 Stage A 리소스 prefab의 115개 컷 mesh·20개 backing mesh 참조와 실제 asset/meta 존재를 확인, 문제 0. 메인의 `SAVED_RELOAD_VERIFICATION.json`은 재로드된 scene/resource prefab 모두 덩굴 226, 잎 157,099, backing 20, 오류 0으로 기록한다.
- `FINAL_INVENTORY_REVIEW.json`: ivy refine·저장·재로드 후 새로 촬영한 `AFTER_INVENTORY.json`으로 검산했다. 원본 renderer key 23,659개 모두 유지; 보호 16,031개의 mesh/material/shader/component/활성/collider/tri 필드 변경 0. 신규 renderer 472개는 잎 226, 줄기 226, 차량 backing 20으로만 구성된다. 풍화 처리 원본 renderer shader binding 7,189개 변경은 의도한 새 풍화 shader 배정 결과이며 원본 shader 파일 수정과 구별한다.

## 실제 Game 화면

- `play_before/`와 `play_after/`의 동일한 player/camera 위치 10쌍, 각 150 Editor 프레임; `play_before_supplement_retry02/`와 `play_after_supplement/`의 Clinic 진짜 외부/차량 근접 2쌍을 확인했다. 초기 `CLINIC_outside`는 플레이어가 지붕 위에 있었던 것이 아니다. 플레이어 Y≈4m, 지붕 AABB Y≈9.47–14.48m이며 투영 가림 때문에 외벽 증거로 부적합했다. `CORRECTION_CLINIC_BEFORE.md` 참조.
- HALL·CLINIC·S06 실내의 플레이어와 주요 문/공간은 보이고 지붕 cutaway가 이를 가리지 않는다. B4 비교 화면과 남측 다리의 노면·통로도 보이며, R8 화면은 비활성 위험점 비교 용도다. SW 근접 화면에서는 sedan/van의 새 녹색 덩굴과 풍화가 보인다.
- Clinic 북측 외벽 Game 화면의 벽면 덩굴은 매우 약하거나 보이지 않는다. 수량 ledger에 외벽 잎이 양수라도 모든 외벽에서 실제 육안 가시성이 확보됐다고 판정하지 않는다. 차량 구멍의 내부 철판이 전 면을 막는지도 현재 높은 시점만으로는 육안 확정할 수 없다. 별도 저각도 before/after 캡처를 준비했다.

## 성능 신호와 한계

- `PLAY_COMPARISON.json`: Editor 프레임 median이 10뷰 중 9뷰에서 증가(비율 1.12–1.78), GPU FrameTiming median도 9뷰에서 증가(1.10–1.26). UnityStats draw triangle은 10뷰 모두 증가(약 5–44%)하고 draw call은 10뷰 모두 감소. 일관된 비용 증가 신호이므로 후속 밀도 강화에서는 예산을 재측정해야 한다. 이것은 Editor 단기 표본이며 빌드 FPS나 목표 기기 성능 판정이 아니다.
- 현재 1차 판정은 **전수 ledger·원본 보호·Nav·대표 Game 시야 검증 완료, 전맵 가시성·차량 라이닝·빌드 성능은 미확정**이다. 높은 시점의 풍화/덩굴 식별성이 부족한 외벽은 다음 밀도 회차에서 재검한다.

## 남은 1차 증빙

- 차량 sedan/van의 저각도 Game 6뷰를 확인했다(`VEHICLE_LINING_AFTER_REVIEW.md`). 보이는 면에서 차체를 통과해 배경이 통째로 비치는 명백한 새 ghost hole은 보이지 않지만, 원본과 같은 각도 before가 없고 모든 cut 위치/20대를 직접 본 것은 아니다. 큰 건물 외벽 덩굴 밀도는 후속 회차다.

따라서 현재 문서의 상태는 **1차 전수 분류·원본 보호·물리·기능 검증 확인 / 대표 차량 저각도 시각은 보이는 면에 한정**이며 20대 전체 및 모든 벽·지붕의 시각 PASS가 아니다.
