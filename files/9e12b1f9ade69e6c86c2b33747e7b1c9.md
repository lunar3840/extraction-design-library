# A맵 밝기 경계 V25 독립 검토

검토일: 2026-09-24  
판정: **경계의 톤매핑 스냅 제거 및 실제 보행 통합 검증 통과.**

## 원인과 수정 범위

- A맵 기본 URP 프로필 `SampleSceneProfile.asset`의 톤매핑은 Neutral이다. 기존 `LookV16Volume.asset`은 ACES를 override했고, Unity Volume의 enum 값은 가중치가 0보다 커지는 순간 전환된다. 따라서 A맵 분위기 경계에서 극히 작은 양의 가중치만으로 화면이 급격히 어두워졌다.
- 현재 `LookV16Volume.asset`의 `Tonemapping.mode.m_OverrideState`는 `0`이다. `StageALookV16Lighting.Apply`도 재적용할 때 `tone.mode.overrideState=false`로 유지하고 `EditorUtility.SetDirty(tone)`으로 해당 서브에셋의 저장을 요청한다. 노출·대비·채도·Bloom의 연속 값은 기존 가중치에 따라 보간된다. 저장된 `m_Value: 2`는 override가 꺼져 실제 렌더링 모드를 결정하지 않는다.
- 변경 전 백업과 SHA-256을 대조한 결과 `StageALookV16Atmosphere.cs`, `StageA_Relay_Blockout_v08.prefab`, `StageA_Relay_Blockout_v08.unity`는 동일했다. 이 비교는 해당 세 파일의 불변만 증명한다.

## 실제 보행 및 실내 보조 검증

- `WALK_VALIDATION.txt`와 `StageABrightnessV25Walk.cs`를 확인했다. 검사는 실제 CharacterController를 움직이고 정상 `StageMapRouter.LateUpdate`와 추적 카메라를 사용한다. 검사 코드가 `Evaluate` 또는 Volume stack 갱신을 수동 호출하지 않는다. 동·서·북·남 각 경계를 바깥 1.2m에서 안쪽 1.2m까지 걷고 다시 돌아왔다. 156개 프레임과 8회 횡단에서 실제 가중치가 좌표 기반 예상값과 일치하고, 톤매핑 Neutral과 ambient mode Trilight가 유지됐다. `failures=0`, `RESULT PASS`다.
- `walk_{east,west,north,south}_{outside,inside}.png`를 직접 열어 확인했다. 서·북·남은 추적 카메라가 움직이는 동안 주변 지형 노출이 자연스럽게 유지된다. 동쪽 외부 사진은 가까운 홀 외벽이 대부분을 차지하고 내부 사진은 지형을 보므로, 이 두 장의 밝기를 직접 비교할 수 없다. 동쪽 밝기의 전후 판정은 같은 구도의 고정 카메라 쌍과 보행 프레임 로그에 근거한다.
- 보행 후 `Leave`는 A look과 V24 외부 차폐값을 초기화하고 B맵을 다시 활성화했다. B맵 복귀 뒤 `tone=ACES`는 기존 B 전용 분위기 프로필에 따른 정상 결과다.
- 최신 `INTERIOR_VALIDATION.txt`와 `after_interior_1f.png`, `after_interior_2f.png`를 직접 확인했다. 1F/2F 모두 가중치 1, Neutral, 해당 층 표시와 외부 차폐 상태 검사가 통과했다. 순간이동 후 기존 게임 카메라 구도로 수렴시켜 촬영한 두 화면에서 플레이어, 벽·입구·바닥 및 보이는 소품을 식별할 수 있다. 이 사진은 수정 후 보조 검사이며 같은 구도의 수정 전 사진과 비교한 V24 전체 회귀 검사는 아니다.
- `FINAL_STATE.txt`에 2026-09-24 15:10:30 기준 `playing=False`, `sceneDirty=False`가 기록됐다. 검증 종료 시 Play가 꺼져 있고 씬의 미저장 변경이 없음을 확인했다.

## 범위와 남은 확인

- 고정 카메라 테스트 자체는 **실제 캐릭터 보행이 아니다**. `Evaluate`의 발 위치만 바꾸어 렌더링 원인을 분리한 것이고, 실제 이동은 별도 `WALK_VALIDATION.txt`로 확인했다.
- 분위기 영역 전체에서 ACES override를 끈 만큼, 가중치가 큰 홀·마당의 최종 색감도 달라진다. 1F/2F의 수정 후 가독성은 확인했지만 모든 V24 구도·소품의 기존 색감 보존까지 증명하지는 않는다. 씬과 프리팹의 해시가 동일하므로 배치·지형 데이터는 변경되지 않았다.
- 원격 A 및 B 복귀는 검증 로그의 상태 확인과 변경되지 않은 씬·프리팹으로 뒷받침된다. B맵의 실제 화면 전후 비교와 재진입 후 상태 확인은 이 검토의 범위 밖이다.
- `StageALookV16Atmosphere.Evaluate`는 가중치가 0보다 크면 fog와 ambient mode를 조건부로 전환한다. 이번 실제 A맵 경로에서는 시작 ambient mode가 Trilight였고, 경계 이미지에서 남은 밝기 스냅이 관찰되지 않았다. 다른 진입 경로가 Skybox/Flat으로 시작하는 경우는 이 검증의 범위 밖이다.

결론적으로 보고된 네 경계의 급격한 톤매핑·휘도 변화는 제거됐고 실제 보행에서도 재현되지 않았다. 배치·씬 보존과 1F/2F 가독성 보조 검증도 통과했다. V24 전체 외관 및 B맵 화면의 전후 동일성까지 주장하지 않는다.
