# 명중·피격 효과 강도 강화 — 2026-10-30 후속

## 사용자 지시 원문

> 타격 / 피격효과 더 강화하길 바람. 예를 들어 현재 피격 방향을 알려주는 UX / UI가 존재하는데 매우 약함. 더 강화해야 함. 타격 효과도 마찬가지.

지시일은 KST 2026-10-30이다. 기존 2026-10-21 타격 피드백 첫 묶음과 같은 대상·같은 인지성 개선 목적의 후속이므로 기존 주제 ID를 유지한다. 라이브러리 담당 채팅이 기존 주제·분류 및 10-30-01 회차 사용 가능 상태를 확인했다. 새 대표 항목이나 별도 자동화를 만들지 않는다.

## 의도와 변경 전 문제

기존 일반 명중/머리/처치 표시는 각각 0.12/0.16/0.22초의 작은 마커였다. 피격 방향은 3~5px 기준의 가는 호와 빠른 제곱 감쇠, 0.35~0.65초 지속이어서 주변을 살피는 동안 놓치기 쉬웠다. 실제 화면 크기에서는 두께가 해상도 비율로 더 줄었다.

명중의 즉각적인 보상과 피격 방향의 읽기 쉬운 경고를 강화한다. 조준 중심과 실제 적 탐지·피해 규칙을 유지하면서 주변부에 강한 신호를 배치한다.

## 작업 전 확보 및 소유 범위

- 수정 전 본 Unity의 clean Edit 화면을 `before_editor.png`로 저장했다.
- 현재 CombatFeedbackHud.cs, CombatFeedbackAudio.cs, CombatFeedbackController.cs를 `source_before/`에 보존했다. 이전 회차 코드로 교체하지 않는다.
- 공유 Unity 담당 채팅과 실행 순서를 조율하고 명시적 사용권 반환/인계를 받았다. 맵·적 AI·진영·귀속 규칙·렌더러·씬은 변경하지 않는다.
- 별도 검증 사본에 현재 Runtime과 Resources를 동기화해 현행 표현의 실제 플레이 화면을 먼저 촬영한다. 초기 화면을 사후 상태로 대신하지 않는다.

## 실제 변경

- 일반/머리/처치 표시 시간을 0.22/0.30/0.42초로 늘렸다. 기본 크기 1.5배, 선의 바깥 길이와 두께를 함께 키웠다. 시작 순간 32% 확대 후 빠르게 안정되는 반응을 넣었다. 머리는 금색 마름모, 처치는 더 큰 적색 코너로 구별하고 새 발의 명중은 이전 처치 표시를 교체한다.
- 피격 호의 각도를 넓히고 선을 굵게 하며, 반투명 가장자리 강조와 공격이 들어오는 쪽을 가리키는 쐐기를 더했다. 강도별 지속시간은 0.80~1.15초로 늘리고 초기 22% 동안 강도를 유지한 다음 부드럽게 줄인다. 출처 없는 피해는 네 방향의 균형 표시만 사용해 가짜 방향을 만들지 않는다.
- 후방 피격 경고는 하단 무기·퀵슬롯 패널 위쪽으로 올려 강조가 숫자/문구를 가리지 않게 했다. 원래 공격 방향을 바꾸지 않으며 경고 반경만 화면 하단 여백에 맞춘다.
- 피격 강조의 부드러운 마스크 두 장을 512×512로 한 번 생성한다. 방향 회전을 타원 비율로 보정하고 화면 픽셀 좌표에서 그린다. 매 프레임 텍스처를 만들지 않으며 종료 시 해제한다. 검증 과정에서 발견한 겹친 사각형의 이음새와 작은 좌표 사각형의 표시 누락을 수정했다.
- 확인음 재생 gain을 일반 .72/머리 .78/처치 .84로 구별하고 피격음은 .32~.78로 높였다. 강한 피격은 음높이도 조금 낮춰 무게를 준다.
- 확인음/피격음이 발생하는 0.14초 동안 로컬 총성을 원래 gain의 .78, 원거리 총성을 .25로 낮춰 전면 효과음의 여유를 만든다. 해당 시간이 지나면 각 음원의 원래 거리별 gain으로 돌아간다. 증폭을 반복 곱하지 않으며 시간정지·정리 시 잔여 상태를 해제한다. AI가 듣는 총성 신호와 거리는 변경하지 않는다.

## 검증 과정 및 한계

기존 검사의 피해 분류·산탄 중복 방지·좌우전후 방향·카메라 회전·무출처·방어구 흡수·가방·일시정지·재바인딩·치명 피격 검사를 유지한다. 늘어난 지속시간을 고려해 사례 간 대기만 1.30초로 조정했다. 별도 사본은 피드백 검사에 필요한 실제 발사/피해 경로를 사용하지만 플레이어 프리팹 연결이 없으면 대체 캡슐로 표시되므로 캐릭터 아트 검증으로 확대하지 않는다. 실제 본 A맵의 소유 소총 경로도 따로 검사한다.

초기 증폭안은 연속 사격·명중·피격·동시 원거리 총성 세 개를 겹친 실제 출력에서 peak 1.331546으로 실패했다. 이를 통과로 처리하지 않고 `iterations/segment-bands-overlap-clipping/`에 보존했으며 전면 효과음 우선의 짧은 음량 조정으로 보완했다. 두 번째 시각 후보의 마스크 표시 누락은 코드/상태 검사로 잡히지 않아 직접 이미지 검토로 발견했고 `iterations/unit-rectangle-culling/`에 따로 보존했다. 최종 통과는 최신 소스의 화면·실행·음향 증빙을 다시 확인한 뒤 기록한다.

최종 실행 결과·화면 검토·원본 동일성 검사 및 게시 영수증은 아래에 추가한다. 전체 전투의 주관적 청감이나 무제한 동시 음원의 무클리핑을 보증하는 범위는 아니다.
