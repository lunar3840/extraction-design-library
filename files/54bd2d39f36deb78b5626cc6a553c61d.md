# A맵 기계 타입별 외형·도장 다양화 v2

2026-10-16. Unity 적용·실행 검증·독립 검토와 전후 증빙 저장 완료.

후속 사용자 지시에 따라 이 기록의 강한 색 도장은 같은 날 더 절제된 도장으로 교체했다. 현재 최종 색상과 새 전후 증빙은 `../a-map-machine-muted-palette/CHANGE_RECORD.md`를 따른다. 이 기록은 외형 조립·주행 수정·전투 검증의 당시 근거로 보존한다.

## 사용자 지시와 기획 의도

“에셋에 기계 외형이 한두개가 아닐텐데.. 타입이 달라지면 좀 다양한 외형들에 다양한 색들 사용해서 차별화했으면 좋겠는데.”

기존 7역할은 공격 패턴은 구별됐지만 경량 다리/Gunbot, 중형 다리, 주황·청록 도장이 반복되어 실제 A맵에서 비슷하게 보였다. 보유 Mech Constructor: Spiders and Tanks의 다리·버기·궤도·캐리어·전차와 상체·무기를 조합해 타입별 윤곽을 나누고, 풀·건물·실내 배경에서도 역할의 색이 읽히도록 조정했다.

메인이 기획·통합·Unity 실행을 담당했다. GPT-6 Sol high 에이전트에 원본 인벤토리/카탈로그 도구, 외형/재질 빌더, 독립 검토를 분담했다. 제작자는 외부 staging만 수정했고 메인이 읽고 통합했다. 독립 리뷰가 지적한 미약한 색상과 롤러 과축소를 그대로 통과시키지 않았다.

## 변경 전후 증빙

모델 수정 전에 일반7종·네임드4종의 실제 Play 상세11장과 A맵 전경9장을 새로 촬영했다. 원본/백업을 대신 찍은 전 화면이 아니다. `baseline/`은 원래 씬/맵·일반/네임드 리소스·관련 코드이며 `BASELINE_HASHES.txt`에 해시를 남겼다. 별도 V1 비교 리소스는 AssetDatabase.CopyAsset로 새로운 GUID를 부여해 보존했다.

- 실제 맵 비교: 루트 `before_<지역>.png` ↔ `after_<지역>.png` 9쌍.
- 일반 상세: 루트 `before_detail_<슬롯>.png` ↔ `after_detail_<슬롯>.png` 7쌍.
- 네임드 상세: `named/before_detail_N2~N5.png` ↔ `named/after_detail_N2~N5.png` 4쌍.
- 동일 카메라/공통 배율의 모델 비교: `catalog/before_<역할>.png` ↔ `catalog/after_<역할>.png` 7쌍, `before_silhouette_<역할>.png` ↔ `after_silhouette_<역할>.png` 7쌍과 각 CONTACT_SHEET. 무채색 뷰는 형태만 비교하는 진열이며 실제 게임 색/조명의 증거가 아니다.
- 최종 후 상태 추가 확인: `clearance/after_*.png` 6장(실내3·N5 3시점), `after_pattern_<역할>_{telegraph,fire}.png` 14장. 이 추가 확인은 후 화면만 있으며 전 이미지를 꾸미지 않았다.

대상·좌표·카메라·해상도는 before 카메라 기록을 다시 사용했다. 시작 부하에 따라 HUD 타이머가 약1~2초 다르고 플레이어 무작위 진입으로 미니맵 표시는 달라질 수 있다. 변경 대상 몹과 배경의 비교 구도는 유지했다.

원본 패키지 `Materials/MC_Spiders_Diffuse_{색}.png`, `Camouflage_Diffuse/MC_Spiders_Camo_Diffuse_{색}.png`를 프로젝트 소유 공유 URP/Lit 재질에 연결했다. Green `(0.62,1.25,0.62)`, Blue `(0.42,0.85,1.75)`, Teal `(0.50,1.35,1.40)`는 BaseColor를 보강해 실전 조명에서 갈색으로 묻히는 문제를 해소했다. 이 세 색은 바디/무기 도장 전체에 영향을 주며 원래 금속의 색조도 일부 변한다. 원본 마모·표면 결·법선/금속성 맵과 별도 트랙 재질은 유지했다. 원본 FBX·텍스처·공용 재질은 수정하지 않았다. 추가한 도장 기능은 역할별 공유 재질을 사용한다. 패키지의 기존 트랙 UV 스크롤 등 별도 동작은 그대로이며 이 진술은 기존 패키지 내부의 material instance 사용까지 없앴다는 뜻이 아니다.

## 조립·이동 방식

패키지의 -Z 전방을 모델 내부에서 180도 돌리고 모든 실제 총구를 게임 +Z로 맞췄다. 원본 부품 collider를 제거해 기존 에이전트/피격 판정을 사용하며, 에이전트 반경·높이 안에 몸체와 무기를 맞췄다. 총구/포신은 실제 사격 때만 반동·발사 애니메이션을 재생한다. Root motion은 껐다.

Sniper/Discharger의 바퀴형, ArcRifle의 캐리어형은 기존 Grenadier/GuardTank와 같은 횡이동 금지 분기에 추가했다. 바퀴/궤도가 옆으로 미끄러지지 않도록 선회·전진·후진 상태를 사용한다. 버기는 패키지 Lvl1 Idle/Forward/Turn/Death 바퀴 클립을 기존 공통 뼈대에 연결했고 실제 Lvl1/Lvl3의 바퀴 회전을 검사했다. Tracks Lvl2는 해당 레벨의 Roll/Idle/Death를 사용한다. 물리 차량이나 새 공격 로직을 추가한 것은 아니다.

실제 Play에서 차체 고정점이 1~2m 벗어나는 문제도 수정했다. 원본 TankRig Forward의 ROOT.z는 한 클립에서 0→30m, 회전 주행은 x±12m/z약6m였다. Buggy에도 ROOT 위치·회전 곡선이 있었다. Animator.applyRootMotion=false만으로 내부 ROOT 곡선이 남아 차체가 이동·회전했다. 프로젝트 소유 `Controllers/InPlace/*.anim` 11개에 원본 곡선을 복사한 뒤 ROOT 위치·회전을 고정하고 Body의 흔들림/기울기·바퀴 곡선·사망의 비루프 설정을 유지했다. ArcRifle/GuardTank는 새 MachineTankInPlaceV2 controller, Sniper/Discharger는 제자리 클립을 연결한 Buggy controller를 사용한다. N3에도 TankRig controller만 별도 적용했다.

N3 변경은 원래 전체 서명과 무조건 동일하다고 처리하지 않았다. `0:ForwardAligned/0:TankRig`라는 보존 V1 원본의 정확한 Animator 경로 한 곳에서 controller가 새 MachineTankInPlaceV2일 때만 원본 controller GUID로 정규화하고, 나머지 Transform/Mesh/Avatar/applyRootMotion/Animator 요소를 원본 서명과 비교한다. 별도 검사에서 실제 N3 controller 교체가 정확히1곳이고 state 이름·속도·transition·parameter 구조가 원본과 같음을 확인한다. `N3 controller-only allowlisted delta`를 명시한 예외이며 몸체/배치 보존 검사를 일반적으로 완화하지 않았다.

## 보존한 맵·전투 상태

73슬롯(일반 기계54/인간14/네임드 후보5), 출격당 네임드3~4, Kind/역할/위치/변동 후보/동선/홈/leash/실내/에이전트 크기/공격 프로필/피해/사거리를 보존했다. 인간 HP70·피해0.65, N1 HP200·피해0.8, 인간의 선발견·기계 회피·접근/조준을 관찰한 방어 사격도 그대로다. 이번 색은 전투 속성/약점/상태이상을 새로 구현했다는 의미가 아니다.

기본 B1~B4와 R 비활성, 반입가치별 후보 원칙을 변경하지 않았다. B4/R8 약62m 및 W5 공유의 기존 비교 사유도 유효하며 이번 외형 수정으로 해결됐다고 보지 않는다. G1~G4/G8/W5의 기존 Scout 중심 구성을 유지했다. 씬·맵 프리팹 파일 해시가 같으므로 건물/CQB 내부/진입점/장애물/적의 좌표와 경로는 이번 작업에서 바뀌지 않았다.

## 중간 실패와 처리

원본 부품 카탈로그 첫 시도는 Preview 카메라가 A맵을 그려 무효였다. `staging/inventory/source_catalog/`는 최종 근거에서 제외했다. scene/culling mask를 명시한 `source_catalog_v2/`로 부품을 다시 확인했다. 일부 리그 전용/빈 타일은 완성 모델 검증으로 세지 않았다.

첫 Realistic 도장은 어두워 `intermediate_v2_realistic_dull/`로 분리했다. 접힌 Roller 방전기 실험은 렌더 경계/샘플 포즈의 일관성과 가독 크기 검사에 실패했다. `intermediate_v2_roller_*`에 실패 근거를 보존했고 최종에서는 안정적인 Lvl3 버기로 교체했다. 초기 rig 불일치 가능성만으로 해결됐다고 판단하지 않았고 추가 검사 실패 후 사용을 중단했다. 최종 리소스에는 Roller 차체/컨트롤러를 연결하지 않는다.

Diffuse만 쓴 시안도 초록·파랑·청록이 실전에서 갈색처럼 보여 `intermediate_v2_muted_diffuse/`로 분리하고 색을 보강했다. 애니메이션 샘플링 뒤 남은 임시 scene dirty flag는 live 보호 상태/73슬롯/저장 파일 해시를 원본과 대조한 뒤 저장 없이 원래 A씬을 다시 열어 해소했다.

첫 주행 검사는 회전 차체의 월드 AABB 합집합을 고정 중심처럼 비교하는 오류가 있었다(`PLAY_actual_144511.txt`, `145529`, `145905`, `150118`). 렌더 경계·회전하는 관절 중심은 실제 차체 이탈의 확정 근거로 쓰지 않았다. 검사를 actor 로컬의 고정 visual root/ForwardAligned/Chassis/TankRig와 Weapon 아래가 아닌 skinned rootBone으로 바꿨다. 1m 문턱은 유지하고 바퀴 회전은 별도로 검사한다.

고정점 검사에서도 `PLAY_actual_150442`의 Arc Chassis 2.219m가 남아 실제 클립 ROOT 이동을 조사했고, 원본 곡선을 확인해 제자리 클립으로 수정했다. `PLAY_probe_151417`에서 Tank 계열은 0.02m로 개선됐지만 버기1.315~1.415m와 N3 1.409m가 남았다. 추가 수정 뒤 `PLAY_probe_152021`에서 최대 고정점 변화0.03664m, Sniper0.01422m/Discharger0.01198m/Arc0.02160m/Guard0.02015m/N3 0.03093m로 통과했다. 이 로그는 variant0의 8초 진단이며 30초×3변형 최종 검사와 구별한다. 실패·중간 로그를 삭제하지 않았다.
