# ARC 참고 — 큰 라운드 HUD 적용안

작성일: 2026-10-22. 본 문서는 적용 전 제안이며 완료 기록이 아니다. Figma·Unity·앱을 조작하지 않았다.

## 참고 범위와 출처

사용자가 ARC Raiders를 참고해 현재보다 훨씬 큰 라운드와 컴팩트한 인상을 요청했다. 복고 색·장식은 도입하지 않고 현재 흑백 대비, 반투명 배경, 파스텔 생존 fill과 게임 고유 아이콘을 유지하는 범위다.

- [ARC Raiders 공식 사이트](https://arcraiders.com/)와 [공식 Steam 상품 페이지](https://store.steampowered.com/app/1808500/ARC_Raiders/)를 확인했다.
- 실제 HUD가 포함된 비교 자료로 [PC Gamer의 Power Out 게임 화면](https://www.pcgamer.com/games/third-person-shooter/arc-raiders-power-out/) 및 [Game Informer의 게임 화면](https://gameinformer.com/review-in-progress/2025/10/31/arc-raiders-review-in-progress)을 웹 검색에서 찾았다.
- 웹 도구가 해당 원본 이미지의 픽셀을 검토 가능한 형태로 반환하지 않아, 이번 조사에서는 ARC UI의 실제 corner radius를 직접 관찰·계측했다고 주장하지 않는다. 아래 값은 ARC의 공식 수치를 복제한 것이 아니라 사용자 의도에 맞춰 현재 HUD의 크기·정보 배치를 기준으로 산정한 제안이다.

## 권장값

| 요소 | 크기 | 제안 radius | 의도 |
| --- | --- | --- | --- |
| 퀵슬롯 | 80×80 | **32** | 현재 18보다 분명히 둥근 모듈. 36은 하단 키·수량에 배경 여유가 부족해질 수 있어 32를 우선한다. |
| 숫자 및 E/X 키캡 | 24×24 | **12** | 완전 원형 키. 한 글자의 식별성을 유지한다. |
| F 키캡 | 28×28 | **14** | 완전 원형 키. |
| 상호작용 | 296×80 | **40** | 완전 캡슐. 현재 14와 확연한 차이가 난다. |
| 주무기 | 264×136 | **28** | 넓은 패널도 라운드 방향을 공유하되 콘텐츠 공간은 유지한다. |
| 보조무기 | 200×104 | **24** | 주무기와 비슷한 비율의 라운드. |
| 목표 패널 | 현재 크기 유지 | **32** | 작은 모서리 처리에서 명확한 둥근 패널로 변경한다. |
| 작전 시간 | 높이 44 | **22** | 완전 캡슐. |

폰트·아이콘 크기, 수분/에너지 112px, 충전링, 현재 퀵슬롯 간격과 중앙 정렬은 유지한다. 정보량을 줄이거나 텍스트를 작게 만들어 컴팩트함을 연출하지 않는다.

## 큰 라운드에서 확인할 접점

1. **퀵슬롯 수량·키:** radius 32는 기존 하단 행에 비교적 안전하다. 36을 선택하면 키캡과 ×1의 좌우 여백을 12px 정도로 늘려 곡선 가장자리와 붙지 않게 해야 한다.
2. **상호작용 첫 글자와 F 키:** radius 40에서 기존 왼쪽 12px 여백을 유지할 수 있는지 PNG로 확인한다. 곡선과 가까워 보이면 가로 여백만 16px로 조정한다. 글자나 키 크기는 줄이지 않는다.
3. **주무기 선택 표시:** 기존 상단 선택 선의 시작점이 x12/y0이면 radius 28의 곡선 바깥에 떠 보일 수 있다. 선의 x를 28로 옮기거나 이 선만 생략한다.
4. 큰 라운드로 잘린 배경 밖에 글자·수량이 노출되지 않는지, 키캡과 슬롯 외곽 곡선이 겹치지 않는지 최종 동일 장면 PNG로 다시 확인한다.

물방울·번개의 추가 경로 곡률과 초상 변경을 이 패널 라운드 적용과 혼동하지 않는다. 실제 적용 후 검토는 별도 visual-audit.md에 기록한다.
