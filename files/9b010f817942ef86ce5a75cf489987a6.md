# 헬멧·고글 착용 외형 수정

헬멧의 고글을 눈 높이로 내리고, 캐릭터 머리의 비율을 바꾸지 않은 상태에서 윗부분과 뒤쪽 외형을 다시 맞췄습니다.

## 수정 내용

- 렌더러의 넉넉한 표시 범위 대신 실제 얼굴 메시의 범위와 방향을 기준으로 피팅합니다.
- 고글을 눈 앞에 배치하고, 측면에서 눈이 드러나는 틈에는 별도 안쪽 패딩을 추가했습니다. 원래 얼굴·눈 메시를 지우지 않습니다.
- 고글을 내리면서 이마가 헬멧을 관통하지 않도록 윗부분은 별도 복제 메시로 조정했습니다. 패키지의 원본 모델은 유지합니다.
- 큰 검은 구형 캡을 작은 목덜미 덮개로 줄이고, 원래 헤어의 두피 부분을 축약한 메시를 함께 사용합니다. 긴 머리와 장식은 착용 중에만 숨깁니다.
- UnityChan / Misaki / Yuko 세 캐릭터에 적용합니다. 장착 슬롯과 능력치 규칙, 캐릭터 머리 크기는 변경하지 않습니다.

## 검증 자료

전용 `C:/tmp/EscapeHelmetRefit` Unity 6000.1 URP 프로젝트에서 실제 카메라로 확인했습니다. 기존 공유 검증 프로젝트에서 다른 작업의 빌드와 충돌해 이후 검증 공간을 분리했습니다. 최종 수정본의 Play Mode 검사 44개가 통과했고 런타임 예외는 없었습니다. 원본 에디터 창을 직접 조작한 검증과는 구분됩니다.

- `Helmet-Refit-Detail.png`: 원래 모습 / 착용 정면 / 측면 / 후면.
- `Helmet-Refit-Characters.png`: 세 캐릭터 착용 모습.
- `Helmet-Refit-Gun.png`: Play Mode에서 총과 헬멧을 함께 착용한 모습.
- `Helmet-Refit-Checks.txt`: 실제 인벤토리 장착·해제·파손·가방 교체·머리/옷 복원과 총 손잡이 유지 검사.

자산 27개 파일을 수정/추가하고 의존 파일 100개의 내용·SHA-256 일치를 확인했습니다. 런타임 스크립트는 변경하지 않았습니다. 내역은 `Helmet-Refit-ImportedFiles.json`, 이전 자산 백업은 `work/helmet-refit-backup`에 있습니다. 생성기와 검사 코드는 `work/helmet-refit-tooling`에 보관했습니다.

원본 에디터에서 Play를 중지했다가 다시 실행하면 변경된 프리팹을 사용합니다. InventoryTest의 기존 방어구 장착 흐름으로 확인할 수 있습니다.
