# V35 HALL 2층 조명 독립 검증

## 판정

**D13/V34 원본 보존과 V35의 제한된 시각 개선은 합격.** 실제 게임 카메라의 동일 위치 전후 8쌍에서 남서·남동 2층 바닥 및 서·동 계단 **상단 접근로**의 플레이어 주변 명암이 회복됐다. 후보01은 작은 원형 밝기 집중과 넓은 암부 때문에 시각 판정을 보류했고, 범위·각도를 넓힌 후보02에서 주변 바닥과 계단 입구가 더 빠르게 읽히는 것을 확인했다. 이 결과를 2층 전체나 계단 아래쪽의 조명 완성으로 확대 해석하지 않는다.

## 변경 전과 시각 비교

- 작업 전 `before_editor.png`, `before_PLAY.txt`, `before_play_south_west.png`, `before_play_south_east.png`, `before_play_stair_west.png`, `before_play_stair_east.png`, `before_play_north.png`, `before_play_first_floor.png`, `before_play_outside.png`, `before_play_remote.png` 및 `backup/A.unity`, `backup/A.prefab`가 먼저 저장됐다. 변경 전 D13 기준 서명은 `BASELINE.txt`와 `V35_D13_ORIGINAL_SNAPSHOT.json`에 있다.
- 동일 실제 게임 카메라·캐릭터 위치·Neutral 톤의 `before_play_*.png`와 `candidate02_play_*.png`, 저장·재로드 뒤 `after_play_*.png`를 8시점 비교했다. 남서·남동의 캐릭터와 주변 바닥, 서·동 계단 상단의 진입 경계가 이전보다 넓고 부드럽게 밝아졌다. 창 그림자 패턴은 유지됐다. 최종 `after_play_*.png`는 후보02 결과를 유지한다.
- 북측 2층, HALL 1층, 외부, 원격 지점의 대응 화면은 실질적인 밝기/외관 변화가 보이지 않는다. 1층에서는 V35 등기구 renderer가 0/4로 숨는다. 실제 Play 로그에서 외부·원격의 renderer는 4/4 `enabled`이나, 대응 화면에서 지붕/거리 뒤 뚜렷한 외관 누출은 찾지 못했다. 외부에서 자동 비활성화된다고 주장하지 않는다.
- 남측에서도 새 조명 주변을 벗어난 2층 바닥은 어둡고, 계단 아래쪽/나머지 실내 전역은 이번 화면만으로 밝아졌다고 할 수 없다. 신규 등기구의 둥근 상단은 탑뷰에서 보이지만 기존 2층 등기구와 같은 메시·재질이다. GF2급 전체 실내 조명 완성 판정이 아니라 사용자가 지적한 구역의 **국소 암부 완화** 판정이다.

## 원본 보존과 저장 지속성

- 변경 전 snapshot은 D13 원본 오브젝트 33,892개, 참조 의존 자산 4,485개, 기존 scene Light/Volume 16개를 기록했다. `VALIDATION_candidate02.txt`와 저장·재로드 후 `VALIDATION_reloaded.txt`를 직접 읽었다. 두 결과 모두 **16 PASS, 0 FAIL**이다.
- 33,892개 원본의 누락/구조/외관 변경은 각각 0이다. 따라서 원래 2층 등 5개, V34 조명과 shadow-only 81개, 원래 메시·충돌·재질 결합·게임플레이 직렬화 필드는 유지됐다. 참조 자산 변경 0, 기존 Light/Volume 변경 0, 전역 RenderSettings/렌더 파이프라인 변경 0이다.
- 신규 객체는 `V13_HallRoot/Floor_2F/V35_2FLighting` 아래 9개뿐이다. 남측 2등과 계단 상부 2등의 Spotlight 4개 및 기존 등기구와 메시·재질이 같은 fixture renderer 4개이며, 추가 Collider 0, 범위 밖 위치 0, shader 오류 0이다. B4 기본 진입·R8 비활성 위험 진입 구분도 유지됐다. 이것은 기존 B4/R8 간격 문제를 해결했다는 뜻은 아니다.
- `SAVED.txt`, 재로드 검증, `after_PLAY.txt`, 최종 8개 `after_play_*.png`를 확인했다. 저장 후 효과가 사라지거나 기술 보존 조건이 바뀐 흔적은 없다.

## 실제 이동 검사의 범위

- `candidate02_PLAY.txt`와 최종 `after_PLAY.txt`는 둘 다 `RESULT PASS`다. 켜진 `CharacterController`에 대해 `PlayerMotor`가 서·동 계단 각각 오르내림 4경로와 각 계단 상단↔남측 2층 왕복 4경로, 총 **8/8**을 통과했다. 층별 표시와 지역 톤매핑 연속성도 PASS다.
- 이 검사는 시작점을 정해 실행한 실제 이동 시뮬레이션이며 물리 키보드·마우스 수동 조작 시험은 아니다. V34의 원래 102개 문 양방향 전수 검사와도 별개의 V35 국소 경로 검사다.
