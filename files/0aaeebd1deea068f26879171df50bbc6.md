# 변경 기록 — Figma 인벤토리 Hover Tooltip

## 사용자 지시 요약

인벤토리 아이템에 커서를 올렸을 때 활용할 간결한 정보 카드를 기존 UI 키트에 추가한다. 기존 아이템 상세 디자인과 에셋을 재사용하고 사용자가 Figma에서 편집할 수 있는 네이티브 컴포넌트로 저장한다.

## 기획 의도와 문제

기존 아이템 상세 화면은 상태 정보와 세 개 행동 버튼을 포함한 큰 화면이다. Hover 정보에는 이름·등급·수량·용량·무게·판매가·짧은 설명을 모아 빠르게 읽을 수 있는 별도 컴포넌트가 필요했다. 이번 범위는 Figma 컴포넌트 추가이며 인벤토리 전체 리뉴얼이나 Unity 런타임 검증이 아니다.

## 변경 전 상태

- 파일: KUD4t84BL1S77c3cnb8co0.
- UI 키트: Modern Glass · UI Kit, page 0:1. 페이지 ID는 기존 `../../2026-10-21/figma-modern-glass-ui-kit/design-system-state.json`의 foundations.pageId와 CHANGE_RECORD.md에서 확인했다.
- 기존 상세 화면 13:1612 및 Medical 상세 패널 13:1633을 재사용 대상으로 삼았다.
- 변경 전 키트 9% 화면과 원본 상세 화면 24%를 별도로 보존했다. 사후 이미지를 변경 전으로 재구성하지 않았다.

## 실제로 바꾼 부분

- 새 네이티브 컴포넌트 `Inventory/ItemHoverTooltip`, ID **105:2984**, UI 키트 페이지 x2575/y2760.
- 크기 304×260, 세로 Auto Layout, gap8, padding16, radius21.
- 기존 Medical field-kit 인스턴스 76×76 재사용.
- 카탈로그 예시: `med_field_kit_b`, 야전 응급키트, V2, 1개, 남은 용량120/120, 0.8kg, 판매가300블랭크.
- 설명: “교전 직후 사용하는 B등급 주력 회복 키트.”
- 안내: “클릭 상세 · 드래그 이동”.
- 배경 기존 color/bg/dense(#283340, alpha78.82%), 본문 color/text/secondary(#C5CDD7), 제목 color/text/primary, 등급 color/tier/2 및 위쪽3px 강조를 사용.
- 편집자 보고: 제목 Noto Sans KR Bold16/24, subtitle12, body13.5/21. 색상·티어 의미 바인딩을 유지하고 spacing/radius는 로컬 값으로 조정했다.
- 복제본 내부에서 기존 상태 행2개와 버튼3개를 숨겼다. 원본 패널은 보존했다고 편집자가 보고했다.

## 변경 방식

Figma MCP View 요청 한도 초과로 네이티브 Figma UI에서 작업했다. 원본13:1633을 복제하고 임시 복제본을 원본 화면에서 잘라 UI 키트 페이지로 이동한 다음 새 컴포넌트로 정리했다. 원본 상세 화면 변경 후 재캡처는 없어 원본 미변경은 편집자 보고로 구분한다.

추가된 기본형은 하나다. 전체 여섯 상태의 Figma variant는 생성하지 않았으며 Figma prototype hover wiring도 하지 않았다. 게임 코드의 여섯 상태 지원 및 Unity hover·클릭·드래그 연결은 별도 작업 범위다.

## 확인 결과와 기대 효과

133% 컴포넌트 화면에서 모든 표시 문구가 읽히고 새 잘림·겹침은 보이지 않는다. 키트9%의 같은 범위 전후에서 컴포넌트 추가 위치가 기존 보드와 겹치지 않는다. Figma 오른쪽 패널에서 새 컴포넌트의 크기·Auto Layout·주요 토큰 이름이 보인다. 상세 결과와 검증 한계는 `visual-audit.md`에 기록했다.

실제 게임에서 hover가 작동하거나 모든 상태·배경·해상도에서 검증됐다는 의미는 아니다.

## 후속 실제 게임 검증 — 메인 작업자

Figma 기본 컴포넌트와 별도로 같은 정보 구조·반투명 스타일을 사용하는 Unity IMGUI hover를 구현하고 InventoryTest에서 직접 hover·클릭·드래그를 검증했다. 실제 게임의 구현은 Figma 레이어를 그대로 내보낸 결과가 아니며, Figma 프로토타입 hover 연결은 여전히 없다.

런타임/Editor 컴파일 오류 0, 실제 Editor 검사 33개 PASS, 최종 시각 QA PASS를 확인했다. 실제 V1 탄약과 V2 의료품을 확인했으며 여섯 등급 전체·모든 조명·해상도·게임 상태를 시각 검증한 것은 아니다. 상세 기록과 실제 전후 화면은 `../dmz-inventory-hover-tooltip/CHANGE_RECORD.md` 및 `runtime_visual_audit.md`에 보관했다. 원래 Unity 작업 씬으로 돌아왔으며 앱을 종료하거나 재시작하지 않았다.
