# UI 시안 v02 — 반투명 강화

- 사용자 지시: 기존 시안의 반투명한 느낌을 더 살린다.
- 기획 의도: 공업시설 배경이 패널 뒤로 은은하게 비쳐 유리 같은 재질감을 느끼게 한다.
- 변경 전: v01 패널과 슬롯이 짙고 불투명해 배경 투과가 약했다.
- 실제 변경: 큰 패널과 슬롯의 시각적 불투명도를 낮추고, 배경 투과·흐림·유리 가장자리 하이라이트를 강화했다. 글자·아이템·주요 행동 버튼은 선명하게 유지하도록 요청했다.
- 방법: 기본 이미지 생성 도구로 v01을 참조 편집했다. 최종 프롬프트는 GENERATION_PROMPT.txt에 저장했다.
- 확인: 중앙 가방과 오른쪽 전리품 패널 뒤의 기둥·조명이 식별되며, 기존 주요 배치와 캐릭터 은보라색 머리·민트 강조가 유지됨을 육안 확인했다. 수치/격자 일치 여부는 게임 구현 검증 대상이 아니다.
- 비교: before_concept_inventory_loot.png → after_concept_inventory_loot.png. 양쪽 모두 콘셉트 이미지이며 실제 게임 전후 스크린샷이 아니다.
- 변경 파일: after_concept_inventory_loot.png. Unity/Figma 실작업 파일·게임 모델 변경 없음.
