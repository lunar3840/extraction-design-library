# A맵 수몰 관문지구 도면 제작 기록

## 사용자 지시 요약

기존에 논의한 대형 A맵 구조, 다수 탈출구, 인간형·기계형 적 생태, 덕코프식 다중 보스를 반영한 맵 이미지 또는 도면을 제작한다.

## 기획 의도와 해결하려는 문제

현재 A 구역은 시스템과 비주얼을 확인하는 작은 시험장만 있어 전체 출격 맵의 구역 관계, 이동 선택, 보스 영역, 적 형태별 이동권, 탈출구 분산을 판단하기 어렵다. 시나리오의 첫 메인 의뢰인 `폐허의 통로`와 `외곽 통행 인증패`를 공간 구조로 연결하는 첫 기획 도면을 만든다.

## 변경 전 상태 및 문제점

- 젖은 돌바닥과 폐허 벽으로 구성된 소규모 광장형 시험장만 존재했다.
- 전체 A맵의 도로·건물·수로·지하 경로 도면은 없었다.
- 인간형 적과 기계형 적의 영역, 다중 보스 슬롯, 다수 탈출구가 정의되지 않았다.
- 넓은 개방 공간 하나이므로 실제 익스트랙션 맵의 우회·위험 선택을 표현하지 못했다.

## 실제로 바꾼 부분

- 약 420×320m를 가정한 `A · 수몰 관문지구` 탑다운 기획 도면 v0.1을 추가했다.
- 남북 중앙 간선, 서부 외곽 순환, 동부 산업 경로, 지하 배수망을 시각화했다.
- 인간형 보스 H1~H3, 기계형 보스 M1~M3의 영역과 순찰로를 배치했다.
- 물리적 탈출구 E1~E7을 맵 외곽과 주요 경로 끝에 분산했다.
- 행정청사와 동부 전력·화물 권역을 두 개의 고가치 중심지로 표시했다.
- 정확한 코드 해석과 시나리오 연결을 별도 범례 문서에 기록했다.

## 어떤 방식으로 변경했는지

- 현재 시험장 전경을 재질·분위기 참고 이미지로 사용했다.
- 이미지 생성 도구를 사용해 직교 탑다운 전술 도면을 생성했다.
- 긴 장소명 대신 H/M/E 코드를 사용해 이미지 내 텍스트 오류 가능성을 줄였다.
- 생성 결과를 육안 확인해 H1~H3, M1~M3, E1~E7이 각각 한 번씩 표시되고 인간 영역, 기계 순찰, 지하 배수망, 고가치 지점이 구분되는지 확인했다.
- 실제 Unity 씬·게임 코드·스폰·내비메시는 변경하지 않았다.

## 변경 후 기대 효과와 확인 결과

- A맵의 전체 방향성과 규모를 한 화면에서 검토할 수 있다.
- 인간은 건물, 기계는 도로·상공·수로를 지배한다는 핵심 규칙이 시각적으로 드러난다.
- 중앙 보행포대 순찰을 피하는 외곽 순환로와 동서 횡단로가 확인된다.
- 일곱 탈출구가 서로 다른 방향과 적 위협에 분산되어 단일 보스나 병목이 모든 철수를 차단하지 않는다.
- 현재 결과는 기획 이미지이며 플레이 시간, 실제 이동 거리, 전투 밀도, 카메라 가림은 Unity 블록아웃에서 별도 검증해야 한다.
