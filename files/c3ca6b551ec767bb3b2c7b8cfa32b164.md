# 시나리오 Chat 매일 동기화 · 포트폴리오 제외

## 사용자 지시와 기획 의도

로컬 변경파일만 점검하면 Chat에서 진행한 기획과 수정 지시가 빠지므로, 지정10개 Chat을 직접 조회해 기존 주제의 후속으로 연결하고 중복 수집을 막는다. 두 포트폴리오 리터칭 채팅은 제외한다. 기존 automation-2를 사용자에게 이해되는 이름으로 갱신하며 중복 예약은 만들지 않았다.

## 변경 전

기존 시나리오8개 보존은10/23 고정수집본이며 블렌더 애니메이션과 새 장비plan이 빠져 있었다. 일1회 프롬프트는 새로컬파일이 없으면 Chat조회 전에 종료할 여지가 있었다. 기존1109항목/307주제와 과거원문·이미지·게시ledger는 보존한다.

## 실제 변경

- 10개Chat에서 반환한 45턴을 새 스냅샷으로 보존하고 미수집13대화(블렌더5/메인부관5/장비plan3)를 기존 EDEL/무기기획 주제로 연결한다. 기존 32대화의 공개본문은 덮어쓰지 않는다. 과거시각은 실제 원문KST를 유지하며 이번 수집일과 구별한다.
- 사용자첨부 참고이미지5장만 실물을 확보·해시대조하여 보존했다. 전후0쌍이며 사후 제작이미지로 표시하지 않는다. 생성모델/영상의 원격sandbox참조와 로컬장비ZIP은 바이너리 공개업로드하지 않았다.
- 답변본문 미반환14턴·참조전용8턴·본문잘림3턴을 명시했다. Chat이 r8/r9/r10/r11 또는v23을 만들었다고 한 내용은 응답주장으로 보존하고 실제파일·움직임검증을 완료로 승격하지 않는다. 최신 샷건/기관총 지향자세 수정 지시와 장비plan의 답변은 아직 미확보다.
- 웹원문 직접접근은 로그인되지 않은 상태여서 추가본문·원격파일을 확보하지 못했다. 연결도구의 최근캐시 hasMore:false를 전체장기대화복구로 해석하지 않는다. 가능한 원문을 동기화하고 미확보 결과는 체크포인트에서 pending으로 추적한다.
- planning-library/SCENARIO_SYNC_CONFIG.json·SCENARIO_SYNC.md·SCENARIO_SYNC_LEDGER.json을 통해 대상ID/제외ID·메시지SHA/원문보관·게시검증단계를 관리한다. AGENTS.md와 웹README에 절차를 연결했다.

## 예약과 적용 범위

예약 이름: 익스트랙션 라이브러리 — Codex·시나리오 채팅 매일 동기화. 기존automation-2 ACTIVE/하루1회/이 채팅 대상을 유지했다. Figma 자기 PR 포트폴리오 리터칭과 Figma 기획서 포트폴리오 리터칭은 읽기·신규수집·게시에서 제외한다. 다른게임·자기PR·개인대화를 자동으로 섞지 않는다. 예약등록은 미래실행 또는 게시성공의 보증이 아니다.

## 검증·누락·증빙

SOURCE_SCOPE/CONFIG_SNAPSHOT/PROCEDURE_SNAPSHOT,10개 원문JSON/TRANSCRIPT, SYNC_REPORT·메시지해시·ATTACHMENT_STATUS·ARTIFACT_REFERENCES로 추적한다. 원문보존/목록연결 작업의 완료와 Chat 제작물의 미검증 상태를 구별한다. 실제 사이트의 새 대화/기존주제·분류·원문/이미지 조회 전까지 게시pending이다. 게시전후 웹스크린샷과 별도영수증은 이 폴더에 저장한다. Unity/Assets/Figma/Blender/게임코드·대화원본은 수정하지 않았다.


## 실제 게시·예약 확인 (2026-10-30 KST)

- 대상10개Chat의 반환45턴, 미수집13대화를 기존EDEL/무기주제에 연결했다. 기존32대화·전체1109원문을 덮어쓰지 않았고, 새13대화와 이수집기록1개로1123원문/307주제를 유지한다. 게임구현검증0이며 지시/실패/응답주장·미검증모델을 구별한다.
- 허용39문서·사용자참고이미지5장/전후0쌍을 게시하고 49고유공개경로를 비인증200/SHA일치로 재조회했다. 비인증쓰기401을 유지한다. 5장모두 실제브라우저로딩과 참고캡션을 확인했다. 생성모델/영상 실물은미확보이며 공개다운로드완료로 표시하지 않았다.
- 기존automation-2의명확한제목/ACTIVE/하루1회/이채팅대상을 도구반환과저장파일에서확인했다. 포트폴리오리터칭2개는제외하며새예약생성0이다. 앞으로원문과실물접근한계는SCENARIO_SYNC_LEDGER의pending으로추적한다. 현재SYNC_REPORT의pending은동결당시상태이며 최종게시검증은별도영수증으로구별한다.
- 공개쓰기연결자격을 안전하게 갱신해 기존저장화면v18·동일commit을 환경revision10으로 재배포했다. 공개대상/쓰기보호/화면소스는 그대로 유지하고 비밀값은파일/원문에저장하지않았다. 실제게시최종원문·13대화열람·주제/분류·대표썸네일의최종검증후체크포인트를전진한다.
- 기존64게시행·307주제·과거대응표/고정ledger스냅샷과원문/이미지를보존한다. 최종수집기록추가로65게시행이며 원문지시13건을게임구현완료65건으로해석하지않는다. Unity/Figma/Assets/대화원본은수정하지않았다.
