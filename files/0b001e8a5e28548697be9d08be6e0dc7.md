# 젖은 바닥과 조명 — URP 구현

적용 프로젝트: C:/UnityProject/escape. 기존 맵 프리팹, 배치 생성 코드, 게임 카메라 구도를 유지했다. HDRP 전환, 그래픽 드라이버 패치, 유료 에셋 설치 없이 URP 17에서 구현했다.

## 변경

- Ground, WetGround, Concrete, DarkStone 재질에 전용 Wet Stone 셰이더를 사용한다. 월드 좌표로 이어지는 불규칙한 물웅덩이, 젖은 부분의 어두워짐/매끈함, 마른 돌의 작은 요철을 처리한다.
- 빗방울은 물웅덩이의 표면 방향을 시간에 따라 변화시켜 실제 조명과 환경 반사에 파문을 만든다. 고정된 밝은 원을 덧그리는 방식이 아니다.
- 물의 반사는 주변 배경을 한 번 촬영하는 256 해상도 반사 프로브와 조명의 하이라이트다. SSR·평면 반사·레이 트레이싱은 추가하지 않았으므로 움직이는 캐릭터를 정확히 반사하지 않는다.
- 조명은 중성에 가까운 차가운 주광과 따뜻한 기존 벽등을 조합한다. 물의 반짝임을 유지하면서 과도한 청색과 강한 대비를 줄였다.
- 바닥의 카툰 윤곽선을 억제하고 나머지 배경의 질감을 복원했다. 캐릭터의 기존 카툰 셰이더와 원래 머리색/텍스처는 유지한다.

## 확인 자료

Before_Overview.png / After_Overview.png는 같은 검토 카메라의 Unity 전경이다. Before_Gameplay.png / After_Gameplay.png는 기존 플레이 카메라의 이동 후 화면이다. Comparison.png는 전경을 나란히 배치한 비교본(왼쪽 이전, 오른쪽 이후)이다.

Motion.gif는 실제 플레이 렌더 요청에서 수집한 이동 표본이다. Wet_Dry_Control.png는 같은 카메라에서 Ground/WetGround의 젖음만 끈 대조 화면이고, Wet_Ripple_Later.png는 파문 시간만 바꾼 대조 화면이다. 검사 결과는 PlayChecks.txt에 기록했다.

원본 SD 캐릭터 파일과 기존 맵 파일 해시 보존, 실제 출격/이동/사격, 반사 텍스처, 카툰 재질 보존/복원, 물의 켜기/끄기 및 파문 시간에 따른 실제 픽셀 차이를 검사한다. 캡처에는 IMGUI HUD가 포함되지 않는다. 실행파일 빌드 및 FPS 벤치마크는 수행하지 않았다.

Unity의 파일 가져오기가 끝난 후 SystemsTest에서 Play를 다시 시작하면 적용된다. 적용 메뉴는 Escape > Toon > Apply Hybrid Toon Style이며 이후 아트 재생성도 새 재질 설정을 유지한다. 이전 재질/조명 백업은 work/wet-rendering-backup에 있다.
