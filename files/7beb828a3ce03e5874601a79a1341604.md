# 에델 C01 감정표현 34클립 — 맨손 17 · 소총 17 (Blender 원본)

## 사용자 지시 요약

- 걷기·달리기·장전 등 총기 모션 다음으로 감정 표현을 추가한다.
- 얼굴 피드백: "입은 이전이 낫다".

## 기획 의도와 해결하려는 문제

- 로비·인벤토리·상호작용에서 쓸 감정 표현이 없었다. 총을 든 상태와 맨손 상태 모두에서 쓸 수 있어야 하고, 어떤 대기 자세에서든 끊김 없이 들어가고 나와야 한다.

## 진행 회차

- **감정 목록**: 기쁨, 미소, 부드러운 미소, 코믹 웃음, 화남, 슬픔, 부끄러움, 놀람, 궁금, 결의, 실망, 인사, 졸림, 의심, 생각, 윙크(왼눈/오른눈). 각 120프레임(4초).
- **얼굴 v1→v3**: 눈 컨트롤 최대값이 0.65로 막혀 ^^ 눈이 안 나와 리그 범위를 넓힘. v2에서 입을 크게 키웠으나 피드백대로 v3에서 입은 v1 수준, 눈 감기만 유지.
- **팔 동작 방식**: 맨손은 볼·턱·허리·만세·브이 같은 목표점 기반 팔 계산(관절 한계 + 팔꿈치 연속성 + 몸통 관통 회피). 소총판은 끼운 대기 자세 위에 상체만 얹고 왼손만 떼서 제스처.

## 결과

- `C01_Emotion_U_*` 17개 + `C01_Emotion_A_*` 17개.

## 한계 / 확인하지 못한 것

- 눈썹 움직임은 앞머리에 가려 거의 보이지 않음.
- 소총판 관통: 기본 약 2cm, 일부 감정 최대 약 3cm.
- 게임 적용·직접 플레이 확인 없음.
