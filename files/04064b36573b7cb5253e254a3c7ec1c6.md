# 선택한 에셋 표면의 덩굴 자동 생성 도구

## 사용자 원문과 범위

> 너가 말한 방식도 적용하되... 넝쿨의 경우 너가 아예 건축물이든 구조물이든 물건이든 에셋에 넝쿨 디자인을 감싸는 일종의 로직? 하나의 툴?을 만들어 줄 수는 없나? 예를 들면 폐자동차 에셋이 있다면 그걸 넣으면 자동으로 넝쿨이 감싸지게끔..

직전 자연 잠식 폐허 방향을 실제 도구로 구체화한다. 선택한 건물/구조물/폐차의 실제 표면을 따라 생성하고 밀도·시작점·성장 방향과 제외 영역을 조정하는 편집기 도구를 우선 제작한다. 원본 재질을 초록색으로 칠하는 방식으로 대체하지 않는다. 우선 별도 시범에서 복제 대상과 결과를 검증한 뒤 적용 범위를 구분한다. 전체 맵 자동 대량 배치나 앞선 모든 아트 항목의 완료를 이 한 도구로 주장하지 않는다.

## 시작 상태와 소유

`before_editor_shared_state.png`는 도구 소스 변경 전에 읽기 전용으로 확보한 공유 Unity 화면이다. 다른 채팅의 검증 중 상태이므로 실제 시범 대상의 변경 전 컷과 구별한다. 대상별 고정 전후는 Unity 사용권 반환 후 촬영한다. 원본 A맵/AI/가림·조명 파일은 보호한다.

공유 Unity/Assets 임포트/요청 파일은 A맵 적 배치와 동선 계획 담당이 사용 중이며 명시 반환 전에는 변경하지 않는다. 소스는 이 기록의 staging/ 밖으로 반입하지 않고 병렬 준비한다. 메인이 기획·통합·Unity 실행을 맡고 GPT-6 Sol high에 생성 로직, 편집 도구/시각 자산, 독립 검증을 분리 배정한다.

## 실제 변경과 방법

2026-10-29 17:23 KST에 공유 Unity 사용권이 명시 반환된 뒤 새 전용 경로에 반입했다. GPT-6 Sol high 생성기/편집도구/독립검증 담당의 결과를 메인이 검토·통합했다. 기존 건물·차량·AI·조명·가림 파일을 덮어쓰지 않았다.

- `Assets/Escape/Editor/Environment/SurfaceIvyGenerator.cs`: 정적 메시의 실제 삼각형을 읽고 가까운 표면을 따라 줄기와 잎을 성장시킨다. 내부 BVH 검색, 모서리 추적, 중간 경로 지지 확인, 제외 상자, 비균일 배율, 임포트된 비가독 메시 읽기를 지원한다. 박스 테두리를 초록색으로 덮는 방식이 아니다.
- `Assets/Escape/Runtime/Environment/SurfaceIvyInstance.cs`: 생성된 전용 자식의 설정·소유 자원·가시성 연결만 보관한다. 런타임에는 성장 계산을 하지 않는다. 지정한 원본 렌더러들이 전부 숨으면 결과도 숨기는 기본 연결이며 국소 컷어웨이와의 완전한 통합은 별도 확인 대상이다.
- `Assets/Escape/Editor/Environment/SurfaceIvyWindow.cs`: 메뉴 `Escape → Environment → Surface Ivy Tool`. 차량/벽/지붕 프리셋, 시작점, 밀도·성장 길이·잎 크기·퍼짐·표면 간격, 문/창문 제외 상자, 재생성, 새 프리팹 굽기를 제공한다.
- `Assets/Escape/Editor/Environment/SurfaceIvyValidation.cs`: 자동 실행하지 않는 독립 검증 진입점. 실제 검증 보고는 아래 파일에 보존한다.

새 잎은 URP Lit 재질, 접힌 간단한 잎 형상, 96×96 잎맥 텍스처를 쓴다. 외부 서비스나 Tripo 크레딧은 사용하지 않았다. 원본 재질·메시·콜라이더·임포트 설정은 읽기 대상으로 유지한다. 프리뷰는 임시 상태이고 굽기는 고유 폴더의 새 메시·재질·텍스처·프리팹을 만든다. 결과는 줄기와 잎 각각 합쳐진 메시이며 새 장식 콜라이더가 없다.

## 기대 효과와 남은 한계

차량·건물·구조물마다 별도의 덩굴 모델을 수동 배치하는 반복 작업을 줄이고, 원본을 바꾸지 않고 설정을 재현하며 새 에셋으로 저장할 수 있다. 정적 MeshFilter/MeshRenderer를 우선 지원한다. Terrain, 변형 애니메이션 메시, 공중으로 늘어지는 물리 덩굴, 의미를 이해한 자동 출입구 식별은 완성 기능이 아니다. 투명 유리 등은 기본적으로 성장 표면에서 제외한다.

실제 시범에서 차량 앞부분이 과밀하고, 외벽 윗선을 따라가는 형상이 다소 균일하며, 탑뷰 지붕의 잎은 작게 보인다. 도구 기능 완성과 최종 아트 배치 승인을 구별한다. 이전의 파손·같은 재료의 잔해·누수·이끼·자연 잠식 방향을 이 도구로 전부 완료했다고 보고하지 않는다. A맵에 대량 배치하지 않았고, Play/FPS/실제 출입 시 컷어웨이·가림·그림자 검사는 하지 않았다. 문·파밍 지점은 수동 제외 후 실제 게임 화면 검증이 필요하다.
