## 증빙 비교의 정확한 범위

- before_review_composition_native와 after_review_composition_native는 모두1085×1025 앱 창,24% 배율의 같은 복제 보드 전후다. 왼쪽 sidebar 폭이 약2px 달라 보드의 화면상 위치도 조금 달라진다. 완전히 동일한 픽셀 정렬의 전후라고 주장하지 않는다.
- after_review_export.png는 제공된 **실제 Figma1×1920×1080 내보내기 원본**이다. 검토자가 재생성·크롭·보정하지 않았으며 변환 작업 전후 해시가 동일하다.
- after_tooltip_context_native는133%의 카드 상세 확인용이다.24%전후와 같은 배율의 직접 비교 쌍으로 취급하지 않는다.
- after_review_clean_maximized는1600×1043 앱 창의44% 전체 검토 보조 자료다.
- 나머지 before_inventory_native, before_review_page_native, after_review_composition_maximized는 보조 증빙으로만 보관·PNG변환했다.

## 한계

- 1개의 의료품 Hover를 보이는 **정적 디자인 시안**이다. Prototype Hover는 아직 연결하지 않았다.
- 실제 게임 Hover·클릭·드래그·화면 가장자리 회피·상태 전환은 시험하지 않았다.
- 다른 원본 페이지·컴포넌트 미변경 및 Screenshot-as-UI import가 없다는 내용은 편집자 보고다. 현재 앱 계층은 네이티브 편집 구조를 뒷받침하지만 파일 전체를 독립 감리하지는 않았다.
- 페이지 이름은 확인되지만 새 page ID는 확인되지 않아 상태 기록에 null로 남긴다.
- 모든 등급·아이템·조명·해상도의 검증이 아니다. 이전 Unity 코드 작업을 되돌렸다는 판정도 하지 않는다.

현재 이미지에서 추가 시각 수정 권고는 없다. 이 판정은 사용자에게 보여 줄 Figma 디자인 검토 시안이 구도·가독성 측면에서 준비됐다는 의미다.
