# 덩굴 조정판 사용

메뉴는 `Escape → Environment → Surface Ivy Tool` 그대로다. 차량/벽/지붕을 선택하고 프리뷰 생성 후 밀도·성장 길이·잎 크기·퍼짐과 출입구 제외 영역을 조정해 새 프리팹으로 저장한다.

이제 기본 잎에 어린잎/3엽/5엽이 섞이며 잎 사이의 간격과 군집, 줄기 길이가 달라진다. 이전에 이미 구운 프리팹은 그대로 보존한다. 새 표현을 쓰려면 원본이나 새 작업 사본에서 다시 생성한다. 기존 씬의 구운 덩굴을 바꾸려면 도구가 만든 결과만 명시 제거한 뒤 재생성한다.

최종 비교는 baseline_renders/와 candidate_03/이다. candidate_03/DEMO_PREFABS.txt의3개가 이번 최종 시범이다. candidate_01/02는 중간 검토 상태이므로 최종과 구분한다. 현재 A맵에 대량 배치한 결과가 아니며 실제 게임의 가림·성능은 배치 후 별도 확인한다.
