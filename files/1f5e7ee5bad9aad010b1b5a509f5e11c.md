# A맵 v0.8 — 교체 가능한 기본 블록 구조

## 이번 구현 범위

520×400m 침수 정비지구의 주요 구조를 Unity에 배치합니다. 건물 5곳의 바닥·벽·출입구, G1~G4 핵심실의 개방된 골격, 중앙 상부 통로와 계단, 수로와 교량 2개, 중계 장치 3곳의 공터/임시 단말, 기본·위험 진입 및 탈출 기준점을 포함합니다.

엄폐물, 잔해, 차량, 소형 배경 폐허, 식생, 장식 오브젝트, 기계/인간 적과 전리품은 새 맵 프리팹에 배치하지 않습니다. 건물 벽과 기초, 교량 바닥은 통행 구조이므로 포함합니다. 기존 게임 출격 시스템이 생성하는 보급 상자 등은 새 맵의 배경 배치와 별개입니다.

지형은 최종 자연 지형 메시가 아니라 평면 지반·수로 절단·높이 차가 있는 연결면·구조 기초를 나눈 블록아웃입니다. 주변 지형을 완만하게 잇는 조형, 정비 피트, 최종 난간/지붕 외형과 배경 구성은 완료된 것으로 보지 않습니다.

## 열기

- 새 씬: `Assets/Escape/Scenes/StageA_Relay_Blockout_v08.unity`
- 새 맵 프리팹: `Assets/Escape/Resources/StageMaps/StageA_Relay_Blockout_v08.prefab`
- Unity 메뉴: `Escape > Stage Maps > v08 > Open Basic Structure`
- 씬의 Play 미리보기는 기존처럼 별도 임시 저장 경로를 사용합니다. 일반 A 출격도 새 프리팹에 연결합니다.
- 구형 `StageA_Blockout.unity/.prefab`와 `StageB_Legacy.unity/.prefab`는 보존합니다.

## 에셋 교체 구조

새 루트에는 세 역할을 분리했습니다.

| 계층 | 역할 | 외형 교체 시 |
|---|---|---|
| `00_Structural_Anchors_Preserved` | 건물/문/진입/탈출/중계 등 이름과 기준 좌표 | 보존 |
| `01_Collision_Replaceable_Separately` | 바닥, 벽, 경사로 등 실제 충돌 | 보존 |
| `02_Visual_Replaceable` | 현재 블록 외형과 이후 외형용 프리팹 | 해당 슬롯만 교체 |

건물·지붕·통로·교량·수면·기초 등을 별도 슬롯으로 관리하므로 전체 맵을 하나의 메시로 합치지 않습니다. 에셋 교체가 자동으로 건물 크기나 출입구 위치를 바꾸지는 않습니다.

1. 프리팹 편집 모드에서 해당 구조의 `StageABlockoutSemanticAnchor`를 선택합니다.
2. `Override Prefab`에 외형용 프리팹을 지정합니다.
3. 필요한 경우 `Visual Override Local Position / Euler Angles / Scale`로 피벗·고도·배율을 맞춥니다.
4. `Rebuild This Visual Slot`을 누르고 저장합니다. 원래 블록으로 되돌리려면 Override를 비운 뒤 같은 버튼을 누릅니다.

교체 프리팹의 Collider/Rigidbody는 제거하여 이중 충돌이나 외형의 낙하를 방지합니다. 구조 슬롯의 충돌체와 기준점은 그대로 남습니다. 충돌 형상도 바꾸고 싶다면 별도 단계에서 `CollisionRoot`를 수정하고 통행 검증을 다시 해야 합니다. 임의 게임플레이 스크립트까지 포함한 복합 프리팹의 동작을 보장하는 기능은 아닙니다.

교체 외형의 벽과 문은 기존 통행 공간에 맞춰야 합니다. 외형이 문을 시각적으로 가리거나 바닥과 어긋나는 문제까지 자동 교정하지는 않습니다. 지붕은 별도 슬롯을 유지해야 기존 실내 지붕 숨김이 정상 작동합니다. 일반 A 출격에 반영하려면 프리팹 자체를 저장해야 하며, 씬 인스턴스만의 변경은 Unity의 일반적인 override 규칙을 따릅니다.

전체 신규 생성 메뉴는 기존 v08 씬/프리팹이 있으면 재생성을 거부합니다. 외형을 바꾸려고 전체 맵을 재생성할 필요가 없습니다. 테스트 프로젝트 전용 일괄 생성은 원본 프로젝트에서 실행되지 않도록 제한했습니다.

## 도면에서 조정한 부분

- 수로 남단을 y=397에서 맵 경계 y=400까지 3m 연장하여 가장자리 우회 틈을 닫았습니다. 교량은 원래 위치/폭을 유지합니다.
- 중앙 계단은 24단 외형을 유지하되 실제 충돌/내비게이션에는 동일 폭 2.4m, 상승 4m/진행 6m의 연속 경사면을 사용합니다.
- 상부 5×5m 발판 중심을 (272,193)에서 (272,190.5)로 옮겼습니다. 계단 끝 y=193의 앞쪽에 붙여 발판이 계단 위를 덮는 낮은 천장 문제를 제거했습니다.
- 고도가 있는 통로와 건물 아래에 분리된 기초를 채워 의도하지 않은 밑길이 생기지 않게 했습니다.
- G1~G4는 구조 확인용으로 출입구가 열려 있습니다. 핵심실의 실제 잠금·열쇠·전원·진행도 시스템을 구현한 것은 아닙니다.

## 진입 시스템의 현재 상태

이번 요청은 기본 구조 구현이므로 중계 해금/지도 공개/출격 옵션/영구 저장은 구현하지 않습니다. B1~B4와 R1~R8은 배치 기준점으로 남기되, 새 A 출격은 무장 가치와 관계없이 B1~B4 중에서만 시작합니다. T를 조작해 R을 해금하는 게임플레이는 후속 시스템 단계입니다. 해당 미구현 상태를 `RiskUnlockSystemImplemented=false`로 명시합니다.

## 검증

독립 검증의 최종 결과는 `STRUCTURE_VALIDATION.json`, `PLAY_VALIDATION.json`, `INDEPENDENT_REVIEW.md`를 따릅니다. 실제 Unity NavMesh 경로, 출입구/계단/교량 통행, 외형 교체 후 기준점·충돌체 보존, 구형 A/B 보존과 원본 파일 설치 확인을 구분해서 기록합니다. 도면의 추상 경로 검사 결과를 실제 통행 검사로 대체하지 않습니다.

최종 결과는 정적/Play 모두 PASS입니다. 정적 검사 11,245개 항목·198 NavMesh 경로, Play 검사 209 NavMesh 경로·실제 PlayerMotor 통행 15건을 통과했습니다. 모든 외형 슬롯의 프리팹 교체 후 기준점과 충돌체가 유지됐으며, Play에서는 2프레임을 기다려 지연 삭제 후에도 확인했습니다.

`C:/UnityProject/escape`에 새 파일 57개(메타 포함)를 설치했습니다. 검증본과 설치본 해시는 일치하며 기존 파일 903개 중 A 연결을 변경한 `StageMapRouter.cs` 외 902개가 보존됐습니다. 기존 A/B 씬·프리팹은 그대로입니다. 자세한 목록은 `INSTALLATION.json`을 참조하십시오.

테스트는 원본의 별도 사본에서 수행했습니다. 사용자가 열어 두신 원본 씬은 강제로 전환하거나 저장하지 않았으며, 원본에서 Play를 자동 시작하지도 않았습니다. Unity가 파일을 새로 불러온 후 위 메뉴 또는 새 씬으로 확인할 수 있습니다.
