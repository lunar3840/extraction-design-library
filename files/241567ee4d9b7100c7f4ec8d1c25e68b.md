# HUD 생존 아이콘 확대 및 가독성 보강

- 날짜: 2026-10-21
- 사용자 지시: 수분/에너지 UI를 크게 하여 식별성을 높이고, 기존 반투명 UI의 명암·글자 가시성을 개선.
- 선행 작업: ../CHANGE_RECORD.md의 전술 유리 HUD 개편.

## 기획 의도와 변경 전 문제

58px 원형 아이콘과 12–14px 글자가 게임 지형·밝은 바닥 위에서 작거나 옅게 보였다. 낮은 불투명도 16%를 적용한 글자 패널은 배경의 명암 변화와 충분히 분리되지 않았다. 반투명한 성격을 유지하면서 아이콘의 실루엣과 글자의 대비를 확보하는 것이 목적이다.

## 실제 변경

- 수분·에너지: 58 → 76px, 내부 아이콘 28 → 36px, 경고 점 6 → 8px. 숫자 없는 아래부터 차는 방식 유지. 8개 상태 모두 갱신.
- 수분/에너지 잔량 채움 불투명도 28%, 원형 바탕 24%, 더 밝은 경계와 그림자 적용.
- 본문·항목 16px, 보조 문구·키·스택 수량 최소 14px. 본문 행간 24px, 보조 행간 20px. 핵심 탄창 44px 유지.
- 글자 패널에 어두운 32% 받침, 28% 경계, 흐림 10px, 부드러운 내부 하이라이트와 외부 그림자 적용. 지도 등 비문자 영역은 더 옅은 재질을 유지.
- 밝은 보조 글자 색과 검정 글자 그림자로 배경의 지형·밝은 바닥과 분리.
- 키 상자 24px, 빠른 사용 슬롯 80×80, 스킬 144×128, 주 무기 264×136, 보조 무기 200×104. 글자가 커진 만큼 컨테이너와 여백을 조정.
- 생존 그룹 168×76을 하단 48px 기준선에 정렬. 가방 중량과 상태 이상 위치를 올려 겹침 방지.
- 체력 136×9, 스태미너 136×5 및 어두운 트랙·테두리. 캐릭터 위 배치와 숫자 없는 표현 유지.
- 일반·위급·탈출 HUD 및 두 편집 가이드에 동일 기준 적용.
- UI 없는 기존 프로젝트 캡처 배경을 사용한 새 네이티브 미리보기(69:2948) 제작. 캐릭터·체력바·UI는 독립 레이어다. 이전 미리보기는 숨김 보존.

## 변경 방법

기존 재사용 컴포넌트와 속성 API, 색·재질 변수와 텍스트/효과 스타일을 갱신했다. 각 화면은 갱신된 소스의 새 인스턴스로 조립하여 크기·폰트·상태 값이 일치하도록 했다. Figma에서 편집 가능하며 Unity 파일 및 실행 중 앱은 종료·변경하지 않았다.

## 확인 결과와 한계

실제 프로젝트 배경 위에서 확대된 생존 아이콘과 밝아진 글자를 확인했다. 1920×1080 일반·위급·탈출·배경 미리보기와 두 가이드의 폰트 및 텍스트 컨테이너 이탈을 검사했다. 모두 이탈 0건, 14px 미만 가시 텍스트 0건이다. Noto Sans KR와 Barlow Condensed만 사용했다. 구조와 재질 값은 validation.json에 저장했다.

Figma 정지 시안 검증이다. 별도 배경은 2026-10-15의 실제 프로젝트 캡처이며 최신 Unity 실행 화면으로 가장하지 않는다. 지도·방위·거리와 잔량 예시는 실시간 게임 데이터가 아니다. 최종 미리보기 캐릭터 위치는 지형 위 표시 확인용으로 조정했다.
