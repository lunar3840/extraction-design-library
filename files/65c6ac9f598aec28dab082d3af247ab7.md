# 익스트랙션 기획서 초안 — 핵심 구성과 현재 상태

이 자료는 제작 진행 중인 개인 게임의 기획·제작 과정을 정리한 초안이다. 이번 공개 범위는 자체요약과 선택 화면3장이다.

## 핵심 내용을 고른 기준

전체 시스템을 나열하기보다 어떤 재미를 의도했고, 무엇을 선택·수정했으며, 실제 화면에서 어디까지 확인했는지를 보여 주도록 구성했다. 긴 문장은 나누고, 플로차트는 필요한 순서와 분기의 이해를 돕는 데 사용했다. 세부 규칙과 전체 수치표·목록은 별첨 경로로 보존했다.

## 전체 흐름

|범위|담은 내용|
|---|---|
|게임 소개|게임 정체성·추구하는 재미·출격에서 귀환 후 성장까지의 흐름|
|Discover|서브컬처·익스트랙션의 경험 비교와 실제 제작에서 발견한 문제|
|Define|핵심 경험·조작과 정보·공간과 전투·AI 자산의 품질 기준|
|Develop|AI 협업 방법과 다섯 대표 사례의 판단·구현·수정|
|Deliver|기록으로 확인된 결과, 검증의 범위, 미완료와 다음 작업|
|별첨 안내|상세 규칙·UI 상태·도면·제작 버전·검증 근거를 더 읽을 경로|

본편은58쪽, 별첨 안내는8쪽이다. 기존 인벤토리 UX 분석40쪽의 전문을 이8쪽에 복제한 것은 아니다. 사례 비교를 이번 초안에서 추가 정리한 부분과 과거 실제 구현 기록도 구분했다.

## AI 활용과 사람의 판단

기존 프로젝트 작업을 설명할 때 GPT/Codex로 대안과 지시를 구체화한 과정, 이미지 생성·Tripo의 후보와 입력, Blender 피팅·리깅·모션·렌더, Figma와 실제 게임의 대응을 연결했다. 도구 사용 이력 자체보다 목표·유지 조건을 정하고 결과의 오류를 지적하며 다시 검토한 판단을 중심에 두었다.

생성 형상이 보이는 것, 게임에 적용한 것, 특정 동작을 검사한 것은 서로 다른 상태다. 예를 들어 Tripo 한 벌의 입력·형상·텍스처 확인은 이후 모든 장비의 피팅·리깅·게임 연결이 완료됐다는 근거로 사용하지 않았다.
