# 시범 블록 디테일 소품 (Tripo 12종)

## 사용자 지시 요약

- 원문은 [SOURCE_REQUEST.md](SOURCE_REQUEST.md). 외형 A안(03회차) 뒤 "벽이 밋밋하다"는 남은 문제에 대해 Tripo 소품 12개 생성을 제안했고, **"한번 생성해서 써봐"**로 승인받았다.

## 기획 의도와 해결하려는 문제

- 03회차로 윤곽과 지붕은 달라졌지만 벽과 지붕 면이 비어 있어 "사람이 살고 일하던 곳"으로 읽히지 않았다.
- 소품을 세 종류로 나눴다: 작업 흔적(배관, 계량기·분전함, 환풍기와 덕트, 옥상 환기구, 손수레), 생활 흔적(방범창, 평상, 자전거 거치대, 게시판과 우편함, 빨래 건조대), 세계관 흔적(기계 케이블 다발, 붉은 표시등의 기계 중계 상자).

## 변경 전 상태 (실제 화면)

- `before_01/` 6장 = 03회차 최종 상태(sw-ruins-block-pilot/after_06).

## 실제로 바꾼 부분과 방법

- Tripo로 12개 생성(비공개, 모델당 30 크레딧, 합계 360, 잔액 2,945 → 2,585). 면 수 상한 6,000. 프롬프트와 출력은 `tripo_details_01/run_log.txt`, 미리보기는 [preview_details_01.jpg](tripo_details_01/preview_details_01.jpg).
- GLB를 OBJ + 기본색 JPG로 변환해 `Assets/Escape/Art/BlockPilotSW/Props/d_*.obj`로 추가(기존 에셋 수정 없음).
- `StageASwBlockPilot.cs`에 배치 코드 추가: 세 동에 31곳. 벽걸이 소품은 벽면에서 모델 두께의 절반만큼 띄워 붙이고, 옥상 소품은 실내에 들어가면 지붕과 함께 숨긴다. 평상·손수레·자전거 거치대·게시판·중계 상자는 충돌이 있다.
- 모델마다 앞면 방향이 달라 축 미리보기로 판단해 회전값을 정했다(계량기함·게시판·환풍기·방범창).

## 변경 후 결과 (같은 카메라)

- `after_01/` 6장 = sw-ruins-block-pilot/after_07.
- 건물 가까이(exterior, yard)에서는 창의 방범창, 문 옆 계량기함, 평상, 게시판, 자전거, 손수레, 옥상 환기구가 보인다. 원경에서는 작아서 차이가 크지 않다.

## 확인한 것과 확인하지 못한 것

확인함: 12개 모두 생성·변환·불러오기 성공(누락 0), 촬영 18/18, 컴파일 오류 없음, 화면에서 벽걸이 소품이 벽에 붙어 있고 방범창이 창 위치와 맞음.

확인하지 못함: 계량기함·환풍기의 앞뒤가 실제로 맞는지(작게 보여 화면으로 확정 못 함), 직접 걸어 다니며 소품에 걸리는지, 성능(소품 31개 약 17만 삼각형 추가), 환경 툰 룩과 함께 켠 화면.

## 남은 문제

- 방범창이 밝은 회색이라 창보다 튄다. 케이블 다발은 위아래에 벽돌 덩어리가 붙은 모양으로 나와 의도(벽을 뚫고 나온 케이블)와 다르다.
- 원경에서 보이는 차이는 작다. 벽 자체의 얼룩·물때·담쟁이·간판 글씨는 여전히 없다.
- 소품 재질은 기본 URP Lit이라 건물 재질의 낡음 표현과 방식이 다르다.
