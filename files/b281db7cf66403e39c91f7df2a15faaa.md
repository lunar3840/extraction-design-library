# A맵 투명벽 수정 및 전반 식생 보강 V14

## 사용자 지시와 기획 의도

- 외형이 없는 곳에서 막히는 투명벽 수정.
- 추가 요청: 맵 전반이 비어 보이므로 식생 추가.
- 보이는 구조물과 충돌을 일치시키고, 무너진 틈·실내 통행은 열어 두며 실제 벽은 막히도록 한다.
- 자연스러운 군락 분포를 넓히되 도로·문·진입/탈출·중정비동 비밀 통로는 보존한다. 위험 진입 활성화나 적/퀘스트 변경은 범위 밖이다.
- 메인이 기획·실행·통합 검토, Sol high가 충돌 수정 / 독립 검증 / 식생 보강을 분담. 파일 소유 범위를 분리한다.

## 변경 전 상태 및 증빙

- V11 폐허 14동의 동서 파손 벽 28개는 이전 충돌과 V12 외형의 길이·위치 규칙이 달랐다.
- 건물 25동에는 대체 외형에서 사라진 실내 칸막이 충돌 50개가 남아 있었다.
- V13 식생은 2690개, 20구역·40 결합 그룹. 특정 군락 외에는 넓은 빈 녹지가 남았다.
- 02:48 편집 모드 확인. 사용자 플레이를 강제로 실행 중이라고 간주하지 않음.
- 실제 변경 전 `backup/`에 현재 씬과 Resources 프리팹을 보관.
- `before_overview`, `before_west`, `before_south`, `before_east_bank`, `before_SWR_02`, `before_SWR_04` 및 두 건물의 `_collision` 캡처 확보.
- `_collision` 화면의 빨간 박스는 검사용 임시 충돌 표시다. 실제 게임 외형이 아니며 캡처 직후 삭제했다. 대응 후 화면에도 같은 방식 사용.

## 변경 계획

- V11 건물의 현재 외형을 기준으로 별도 교체 가능한 구조 충돌을 구성. 옛 충돌은 추적 가능하게 비활성화하고 임의의 전체 충돌 삭제는 피한다.
- 중정비동의 의도된 층별/카메라 가림 기능, 지형, 소품, 출입 및 스폰 기준점은 보존.
- 식생은 기존 원본을 재사용해 분포를 확대. 충돌체는 추가하지 않으며 원래 나무 128개는 유지.
- B4/R8은 여전히 약 62m에 W5 접근이 겹친다. 이번 식생으로 독립적인 위험 진입 경험이 완성됐다고 간주하지 않으며 R 비활성 유지. 해당 지점과 연결 도로 주변의 통행·시야 여유를 검토한다.

## 결과

- 식생 적용: 5465개(낮은 풀 4337 / 큰 잡초 1128), 기존보다 2775개 추가. broad 신규 분포 2369개, 북서/북동/남서/남동 1073/959/2082/1351. 20구역·40 결합 그룹, 2041385정점·1571939삼각형. 실제 FPS 성능 측정 완료를 뜻하지 않음.
- 원래 나무 128개 유지, 풀용 충돌체 0. 도로·문·다리·진입/탈출·중정비동 비밀 진입부를 피하도록 필터링. 메인과 식생 담당이 4개 동일 시점 전후 화면을 각각 검토.
- 충돌 적용: V11 건물 39동의 외벽 모듈 226개·기둥 156개로부터 메시별 충돌체 532개 생성. 옛 구조 충돌 362개 비활성(외벽 252 / 칸막이 50 / 지붕 지지대 60). 삭제하지 않아 추적 가능. 기존 지붕 충돌은 0개였으며 새로 추가하지 않음.
- 외형·지형·기존 소품 배치와 중정비동은 변경하지 않음. 중정비동 전체 계층/충돌 서명 및 진입·탈출·출입문 좌표·스폰 단계의 전후 비교 일치(`PRESERVATION.txt`).
- 수정 전 대표 6개 경로 모두 옛 측벽/칸막이에 캡슐 충돌하는 증거 확보(`BEFORE_PASSAGES.txt`).
- 1차 검사에서 전체 후보 265개 중 33개가 주변의 보이는 캐비닛·드럼통·잔해를 통과하도록 잡힌 검사 경로임을 발견. 구조 수정은 유지하고 검사 경로 선정 기준을 ‘중심점’에서 ‘캐릭터 폭을 포함한 전체 이동 구간의 보이는 물체’로 보완 완료. 보이는 소품 충돌은 제거하지 않았다. 실패 결과는 보존했다(`VALIDATION_INITIAL_PROP_FILTER.txt`).
- 최종 독립 검증 PASS: 123개 항목 통과, 실패 0, 기존 경로 검색 한도 경고 1. 실제 빈 외벽 통로 44개와 실내 통로 157개, 합계 201개 모두 반경 0.4m·높이 2m 캡슐 검사 통과. 보이는 벽 방향 376개 충돌 검사 모두 차단 확인(`VALIDATION.txt`). 보이는 장애물과 겹치는 후보 경로는 이름을 기록하고 빈 통로 검사에서 제외했다.
- 4개 기본 진입점 × 7개 탈출점 연결 검사: 일반 검색 27/28 완전 연결. 기존 B1→X6 검색 한도 경고는 16,384-node 재검사에서 완전 연결 확인. AI 경로 검색 예산 문제 자체를 이번 작업에서 수정한 것은 아니다.
- 재적용 검사에서도 기존 충돌 362개는 이미 비활성 상태이며, 새 충돌체 532개와 건물별 루트 39개가 중복 없이 유지됐다(`IDEMPOTENCE.txt`).
- 씬과 Resources 프리팹 저장 후 다시 열어 씬 미저장 변경 없음(`sceneDirty=False`) 및 V14 루트 39개 확인(`SAVED.txt`, `RELOAD.txt`). 중정비동 서명과 진입·탈출·출입문 좌표 및 스폰 단계 동일 확인(`PRESERVATION.txt`).
- 실제 플레이의 PlayerMotor/CharacterController로 폐허 외벽 틈 4곳·기존 칸막이 자리 2곳, 총 6곳 보행 PASS. 기본 진입 B1 선택 확인. 검사 중에만 자동 입력·적 이동을 멈췄으며 테스트 종료 후 플레이 모드를 종료했다(`PLAY_VALIDATION.txt`). 전투·전체 맵 수동 플레이 또는 FPS 프로파일링까지 검증했다는 의미는 아니다.
- 메인이 실제 보행 후 외벽/실내 화면을 직접 확인했고, Sol high 독립 검증 담당도 최종 검사·실제 보행·재로드 결과를 확인했다.

## 전후 화면 대응 및 확인 범위

- 동일 시점 8쌍: `before_` / `after_` 접두사에 각각 `overview.png`, `west.png`, `south.png`, `east_bank.png`, `SWR_02.png`, `SWR_04.png`, `SWR_02_collision.png`, `SWR_04_collision.png` 대응.
- 추가 실제 보행 증빙: `after_play_0_start.png` / `after_play_0_end.png`부터 `after_play_5_start.png` / `after_play_5_end.png`까지 6개 구간의 시작·종료. 이는 수정 후 보행 증빙이며 변경 전 화면으로 취급하지 않는다. 전체 경로 필터 보완에 따라 SWR_04 보행은 변경 전 동측 경로 대신 서측의 빈 통로를 사용했다.
- 건물 벽과 기존 소품은 유지하면서 보이지 않는 옛 벽만 막지 않도록 개선. 빈 녹지와 나무 아래의 불규칙한 풀·잡초 군락이 늘었다. 신규 나무·꽃·관목 에셋을 추가한 작업은 아니다.
- B4/R8 주변의 길과 진입 여유는 보존했지만 거리 및 목적지 중복 문제는 그대로다. R 위험 진입점 비활성 유지. 식생 보강만으로 위험 진입점의 기능적 차별화가 해결됐다고 간주하지 않는다.
