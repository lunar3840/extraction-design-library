# A맵 Look V16 독립 검토

## 판정

**첫 현실감 시험 구역 범위에서 통과. 차단 회귀 없음.**

이 판정은 중정비동과 인접 남측 야드에 한정한다. A맵 전체가 최종 현실적 그래픽 품질에 도달했다는 뜻은 아니다. 제작 보고만으로 판단하지 않고, 저장·재로드 후 검증 로그와 고정 편집 카메라 5시점, 실제 플레이 카메라 14시점의 전후 화면을 직접 비교했다.

## 검토한 증거

- 변경 전 보호 기준: `BASELINE_VALIDATION.txt`
- 저장·재로드: `SAVED.txt`, `RELOAD.txt`
- 독립 정적·회귀 검증: `VALIDATION.txt`
- 셰이더 검사: `SHADERS.txt`
- 실제 플레이 이동·카메라·복원 검사: `after_PLAY_VALIDATION.txt`
- 편집 카메라 비교: `before_/after_overview.png`, `hall_exterior`, `hall_close`, `south_yard`, `hall_interior`
- 실제 플레이 비교: `before_/after_game_*.png` 14시점

## 확인 결과

### 보호 대상과 게임 기능

- 변경 전 기존 충돌체 4,576개, 진입·탈출·문 보호 앵커 46개, 원격 지구 33개와 렌더러 864개의 서명을 확보했다.
- 최종 `VALIDATION.txt`는 **32 PASS / 0 FAIL**이다.
- 기존 충돌체, B/R·탈출·문 앵커, V13 홀의 비소유 구조, CORE_G1~G3, 원격 지구 형상·재질 연결이 기준 서명과 일치한다.
- R1~R8은 계속 기본 무작위 스폰에서 제외되며 B4/R8 위치와 정책은 변경되지 않았다.
- V14 충돌 회귀와 V15 건물 겹침 회귀 검증이 모두 통과했다. 기존 B1→X6 공개 질의 경고는 고예산 위상 검사에서 연결이 확인된 종전의 알려진 경고이며 V16 신규 실패가 아니다.
- 신규 대형 프롭 2개는 활성 비트리거 충돌체를 가지며 진입·탈출·문 캡슐을 침범하지 않는다.
- 실제 플레이에서 정문, 좌우 2층, 좌우 지하, 비밀 경사로, 남측 야드 이동이 모두 통과했다. 지붕 가림 상태, 시험 구역 이탈 시 A 기본 룩 복원, 라우터 종료 시 B 상태 복원도 통과했다.

### 재질·셰이더와 적용 범위

- LookV16 재질 15개에서 오류 셰이더와 미지원 셰이더가 발견되지 않았다.
- GroundSlice의 직렬화된 world-to-map 행은 유효하며 저장·재로드 후에도 실제 맵 변환과 일치한다.
- 승인된 70m 반경, 홀·야드 경계와 7m 페더가 유지되고, 보수적으로 계산한 마스크도 원격 지구 렌더러 경계와 만나지 않는다.
- GroundSlice는 정상 메시를 가진 StageALandformV09 렌더러에만 연결되어 있다.
- 원본 재질을 직접 덮어쓰지 않고 LookV16 소유 재질과 자식 루트로 분리되어 후속 교체와 되돌리기가 가능하다.

### 실제 화면

- 변경 전의 밝고 균일한 초록 지면과 평평한 주변광보다, 홀 주변의 흙·자갈·콘크리트 기능 구분과 접촉 그림자가 명확해졌다.
- 홀 내부 바닥은 반복 타일이 전면에 튀던 상태에서 저주파 얼룩과 마모가 섞인 콘크리트로 안정되었다. 캐릭터, 문, 계단과 벽은 최종 플레이 화면에서 암부에 묻히지 않는다.
- 남측 야드는 잔디 공터보다 산업 작업장에 가까운 표면으로 바뀌었고, 처음 발생했던 회색 판 조각, 패드 위 풀 관통과 강한 체커형 apron 반복은 최종 화면에서 해소되었다.
- 최종 apron은 큰 단일 작업면으로 읽히며 캐릭터와 경계가 구분된다. 다만 가장자리 상세와 배수·파손 표현은 후속 개선 대상이다.
- `game_secret_descent_end`의 넓은 청회색 공백과 검은 구조는 변경 전에도 같은 시점에 존재하므로 V16 회귀로 판정하지 않았다.
- `overview`의 극원거리 건물 누락은 변경 전 동일 화면에도 존재하는 기존 LOD/컬링 상태로, 이번 시험 구역의 신규 회귀 근거로 사용하지 않았다.

## 남은 스타일 한계

다음은 이번 첫 슬라이스의 통과를 막는 회귀는 아니지만, 맵 전체 현실감 작업에서 계속 해결해야 한다.

1. 건물 외장에 같은 창·벽·골판 지붕 패턴이 반복되어 원거리 구역 정체성이 약하다.
2. 남측 야드는 지면은 개선됐지만 중간 규모 설비와 기능적 군집이 아직 성기다. 배수, 적재, 차량 정비 흐름을 설명하는 구조가 더 필요하다.
3. 일부 검은 상자 군집과 평판형 가구는 근거리에서 임시 프롭처럼 보인다.
4. 주황색 계단 난간과 안전 바는 가독성은 좋지만 채도와 균일성이 높아 재질 현실감과 충돌한다.
5. apron은 단일 작업면으로 정리됐으나 가장자리 파손, 줄눈, 배수 홈, 타이어·기름 흔적이 부족하다.
6. 수변, 다른 지구, 건물 외장 변화, 식생 종·그림자, 전역 대기 원근은 이번 범위 밖이라 그대로 남아 있다.
7. 반사 프로브는 런타임 1회 캡처 방식이므로 이후 동적 표식이나 캐릭터 레이어 구성이 바뀌면 반사 혼입을 다시 확인해야 한다. 현재 증거 화면에서는 눈에 띄는 혼입을 찾지 못했다.
8. 전역 확장 전에는 목표 장비의 GPU 시간, 드로콜, 오버드로우, 프로브 갱신 비용을 별도로 측정해야 한다.

## 후속 권고

- 이번 홀·야드의 조명, GroundSlice 경계, 재질 소유 방식을 다음 구역의 기준으로 사용하되 수치만 전역 복사하지 않는다.
- 다음 우선순위는 남측 야드의 중간 규모 산업 설비와 배수 서사, 건물 외장 변형, 수변 전용 표면이다.
- B4/R8은 이번처럼 그대로 유지한다. R8은 첫 30~45초 위험·엄폐·보상 경험이 B4와 실질적으로 달라지는 별도 설계와 검증 전까지 비활성 상태를 유지해야 한다.

## 최종 결론

V16은 전체 그래픽 완성이 아니라, 제한 구역에서 현실감 방향을 시험하는 첫 단계로서 목적을 달성했다. 지면 기능 구분, 바닥 재질, 조명 깊이와 접촉감은 전보다 좋아졌고, 기존 통행·앵커·원격 지구·위험 스폰 정책을 보존했다. 현재 증거에서 출시를 막는 신규 기능 회귀나 셰이더 오류는 없으며, 위에 분리한 항목들은 다음 현실감 패스의 작업 목록으로 넘기는 것이 타당하다.
