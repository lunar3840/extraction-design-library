# V36b — 건물별 실내 벽 마감 일관성

## 사용자 지시와 의도

- 사용자가 TOOLS 내부의 중앙 회색 창문 칸막이가 황토색 건물 콘셉트와 맞지 않는다고 지적했다. 건물별 일관성을 유지한다.
- 앞선 V36 바닥·역할별 마감·소품 변경에서 누락된 V12 창문 칸막이의 벽 몸체를 수정한다. 건물 전체를 하나의 공통 색으로 통일하지 않는다.
- 창틀, 유리, 건물 외곽 벽돌 하부, 출입구, 충돌, 구조, 동선, 적 배치는 유지한다. 칸막이 양면의 기존 콘크리트·벽돌 표현만 해당 건물의 주마감으로 맞춘다.

## 변경 전 확인 및 범위

- 최종 대상은 32개 건물의 Factory2Wall05 불투명 렌더러 64개, 양면 재질 슬롯 0·1(총128개)이다. 처음의 slot0-only 가정은 아래 시험 기록과 같이 정정했다.
- 기존 슬롯 0은 CommonConcreteWall03 계열의 회색·하단 녹색 띠를 가진 한쪽 면, 슬롯 1은 CommonBricks01 반대면이다. 슬롯 2 금속, 별도 Factory2Wall05Glass는 유지한다.
- 건물의 실제 D09 외벽 주재질을 면적 기준으로 판정하고, 해당 색과 텍스처를 건물별 독립 복제 재질에 적용한다. 원본 공유 재질은 수정하지 않는다.
- D09 전용 WeatheredLit 셰이더 자체는 복사하지 않는다. URP Lit 재질에서 기본색·노멀·금속/거칠기와 약 2m 물리 반복 크기를 대응하며 최종 일관성은 실제 화면으로 검수한다.
- 세 가지 시험 대상: TOOLS(황토 미장), N03(크림 미장), E01(밝은 콘크리트).

## 공유 편집 조율

- V36 완료 저장본을 UI 배치 적용 분석에 인계했다. UI는 맵 변경 없이 소스 통합·컴파일·의료 규칙 검사 후 A맵 적 배치와 동선 계획에 인계했다.
- UI·인간형 증원 패스가 종료돼 명시적 인계를 받았다. FINAL_STATUS에서 Play=false/dirty=false, 디스크 해시와 해당 변경 기록을 직접 읽고 확인했다.
- 인계 최신 저장본(65개 적 후보 슬롯)을 별도 백업·스냅샷·before 실제 게임 화면으로 확보했다. V36의 이전 스냅샷으로 최신 적 배치를 덮어쓰지 않는다.

## 검증 계획과 현재 상태

- GPT-6 Sol high 제작과 독립 검증 분담. 메인이 통합·실제 화면 판정을 맡는다.
- 시험 3곳/12슬롯 → 실제 화면 6장과 독립 보존 검사 → 전체 32곳/128슬롯 순서.
- 전체 원본 객체/구조/재질 슬롯/소스 에셋/광원/진입·탈출점 보존 검사를 수행한다. 이번 작업에서 새 오브젝트는 추가하지 않는다.
- 플레이어 이동 경로 172개 기하 검사는 동적 NPC와의 충돌만 시험 중 제외한다. 실제 전투 혼잡이나 추격 AI 검증으로 해석하지 않는다.
- 적용 전후 대상 32동 room + 3동 game + 중정비동 1/2층, 총37개 동일 카메라 비교 및 저장·재로드 후 실제 Play 재확인 예정이다.
