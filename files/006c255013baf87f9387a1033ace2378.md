# 통합 시험 UI 개선 · 2026-09-04

## 적용 내용

- 한국어 메뉴·안내·성장 이름·상태·적 표시. 저장/아이템/목표 ID와 원작 데이터는 그대로 유지.
- 어두운 공통 패널, 한국어 OS 폰트, 큰 버튼, 밝은 설명 글씨, 화면 비율 조정.
- 상단 생존 게이지/무기/실제 예비 탄약/중량, 하단 퀵슬롯.
- 왼쪽 4열 가방: 슬롯 목록과 선택 상세를 별도 스크롤로 분리. 종류에 맞는 장착·사용·수리 버튼만 표시.
- 오른쪽 출격/상점/창고/성장/의뢰/저장 탭. 상점 검색/종류 분류, 구매 조건 안내, 창고 실제 이름 표시.
- 전리품은 오른쪽 패널을 단독 사용. 순차 수색과 1개/묶음/전체 획득, 선택 묶음 보관.
- 저장 슬롯 전환 확인, 개발용 목표 지급 버튼 접기, 저장 진단 원문 보존.
- 검색 중 게임 단축키 차단. 클릭 동작은 다음 LateUpdate로 지연하며 가방·프로필·위치·전리품이 교체되면 이전 클릭은 폐기.

## 검증

- Unity 배치 6개 모두 exit 0: Systems16 + Session42 + Basecamp50 + Inventory50 + Equipment63 + Loot58 + Player67 + Enemy98 = **444 PASS**.
- 독립 좌표 검사 200 PASS, 지연 동작/텍스트 포커스 검사 14 PASS. 이는 관리형 검사이며 실제 키보드/IME 이벤트를 실행한 것은 아님.
- 별도 Windows 게임 실행 파일로 한국어 IMGUI 4개 화면 캡처, 런타임 오류 0. 시작 시 숨김 창의 검은 캡처는 렌더링 갱신 후 재캡처해 대체.
- UI-Inventory-Shop.png, UI-Growth.png, UI-Compact-Storage.png, UI-Loot.png.
- 마지막 보조 글씨 대비/크기 조정은 동일 소스의 재빌드·렌더 검사로 확인. 기존 자동 회귀의 데이터/행동 코드는 바뀌지 않음.

## 범위와 한계

- 대상은 Assets/Escape/Scenes/SystemsTest.unity 및 해당 인벤토리·전리품 시험 UI. 이전 Player/Combat/Weapon 전용 디버그 화면 전체를 새 디자인으로 바꾼 것은 아님.
- 캡처는 격리된 검증 프로젝트의 Built-in 렌더러에서 실행한 동일 UI 코드. 사용자 URP 씬의 최종 조명·아트 품질을 확인했다는 뜻은 아님.
- 1280×800 이상 권장. 더 작은 Game 창에서는 전체 UI와 글자도 축소됨. 960×600 화면도 확인했으나 작은 화면용 별도 모바일 레이아웃은 아님.
- 한국어 표시는 캡처로 확인. 실제 한국어 IME 조합 입력과 사람의 빠른 연속 조작은 사용자 Play 확인이 남아 있음.
- 저장 규칙/소스 ID/Roblox 원본/SampleScene/대상 프로젝트 Packages·ProjectSettings는 변경하지 않음.
- UI는 나중에 교체 가능한 IMGUI 표시 계층이며, 최종 아트·모델·애니메이션·맵·몹 구성 이식은 포함하지 않음.

## 사용자 확인

진행 중인 플레이는 먼저 귀환/저장한 뒤 Play를 중지하고 다시 시작. 상점·창고 탭에서 가방이 열리며 Tab으로도 여닫을 수 있음.
