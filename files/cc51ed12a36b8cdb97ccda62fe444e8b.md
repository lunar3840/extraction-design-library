# 회수소총 공통 기준: 생존·퇴각 여유

2026-10-22. 원본 Unity와 사용자 저장을 실행·수정하지 않은 코드/설정 감사다. 미래 캐릭터 능력·개별 스탯을 생존성의 보충재로 가정하지 않았다.

## 실행 근거

실제 `PlayerRules.cs`, `DamageRules.cs`, `InjuryState.cs`의 복사본을 PowerShell Add-Type로 그대로 컴파일하여 실행했다. 플레이어 상태 계산을 별도 모형으로 다시 작성하지 않았다. `run_survival.ps1`와 `SurvivalProbe.cs`는 통제 입력을 제공하는 진단 도구다. A 씬은 PlayerDefaults 설정을 참조하며 직렬화된22개 생존 규칙 값이 실행한 기본 규칙과 일치함을 별도로 검사했다. 직렬화되지 않은 부상 필드는 해당 타입의 초기값을 근거로 추적한다. 실제 씬/게임 화면에서 부상 동작을 새로 재현한 것은 아니다.

`SOURCE_MANIFEST.csv`에 원본 경로·SHA256·수정시각, `source/`에 읽은 소스/설정을 보존했다. 검사15개 PASS/0FAIL. 필요량 시간선은0.05초 간격 통제 실험이며 명중률·생존율·실제 이동거리의 실측 통계가 아니다.

## 물과 음식이 정하는 출격 길이

기본 최대 체력/허기/수분/스태미너100, 연구0·부상 없음·의료/음식/물 미사용을 기준으로 했다.

| 통제 행동 | 수분0 도달 | 그때 의미 | 무전투 허기 사망 |
|---|---:|---|---:|
| 계속 정지 | 약11분07초 | 질주·구르기 불가, 보행 가능 | 30분 실험 안에서 생존 |
| 계속 보행 | 약8분20초 | 질주·구르기 불가, 직접 갈증 피해 없음 | 약17분30초 |
| 10초 주기 중 정지2초·보행7초·질주1초 요청 | 약8분20초 | 이후 갈증 때문에 질주 요청이 보행으로 바뀜 | 약17분58초 |
| 110%하중 계속 보행 | 약6분57초 | 보급 없이 철수할 여유가 줄어듦 | 약14분44초 |
| 125%하중 계속 보행 | 약5분33초 | 처음부터 질주·구르기 불가 | 약11분57초 |

음식/물을 전혀 쓰지 않는 극단 시나리오다. 현재 수치가 반드시 이 시간에 출격을 끝내라고 강제한다는 뜻은 아니다. 보급을 갖춘 뒤 더 오래 머무를 수 있으며 사용 전 허기/수분이100보다 낮으면 압박이 더 빠르다. 혼합 실험은 실제 인간 플레이 행동을 측정한 분포가 아니다.

부분 파밍 기준에서는 **무보급5분은 활동 여유가 있고,8분 무렵은 물과 철수 결정을 요구하는 구조**다. 기본 보행5분 후 수분 약40,8분 후 약4가 남았다. 새 슬롯 지급품에는 물/식량이 없으므로 초보에게는 적의 수보다 이 숨은 회피 불능 시점이 먼저 체감될 수 있다. 30분 작전 제한을30분 무보급 활동 가능 시간으로 해석하면 안 된다. A맵에는 StageD 전용 침식 상태가 생성되지 않는다.

## 피격 후 전투를 지속할 여유

- 기준 체력100에서 방어구를 통과한 총탄 피해 누적28은 출혈 조건이다. 시험에서30피해 뒤 출혈이 생겼고100초 방치 후 체력1에 남았다. **출혈 자체는 죽이지 않지만 다음 공격에 취약하게 만든다.** 음식 고갈 피해나 다른 직접 피해는 별도로 치명적이다.
- 총탄 외상 누적 기준은42이고 총탄 계수는0.65다. 시험에서 몸통65피해 후 몸통 외상과 최대 체력90이 생겼다. 평범한 체력 회복은90까지만 적용됐다. 방어구에 흡수된 양을 그대로 출혈/외상 누적으로 더하지 않는다.
- 약한 피격은6초 피격 공백 이후 초당기본최대체력의12%만큼 누적치가 감소한다. 20피해를7초 간격으로2번 받는 실험에서는 출혈이 발생하지 않았다. 이미 발생한 출혈/외상이 자동 치료된다는 뜻은 아니다.
- 부상 치료·회복에는 실제 아이템 사용 시간과 행동 제약이 있다. 가방을 열거나 약을 사용해도 모든 적이 멈춘다고 가정하지 않는다. 수술 등의 피격 중단·치료 용량·진통과 외상 치료의 차이는 기존 ItemUseState를 따른다.

## 하중과 회피

- 기본 스태미너100/질주 소모15로 연속 질주 약6.67초다. 기본 재생은초당20, 지연1초다. 기본 보행4m/s·질주7.2m/s는 월드 배율0.4 적용 전후를 구별해야 하며 방어구/무기/부상으로 더 변한다.
- 구르기는스태미너25, 이동0.30초, 보호 꼬리0.15초, 재사용0.65초다. 실제 상태 실험에서0.44초에는 보호가 남고0.47초에는 종료됐다. 연속 무한 무적이라고 평가하지 않는다.
- 하중100%초과부터 구르기 불가·보행속도70%,120%부터 질주도 불가,150%부터 이동 불가다. **파밍 중 조금 넘친 무게가 회피 능력과 퇴각을 동시에 바꾸는 점**을 고려해야 한다. 가방 격자에 들어간다는 사실과 안전하게 운반할 수 있다는 것은 다르다.
- 101%하중은 질주가 가능해도 구르기는 불가능하고 필요 소모는102%다.125%하중 실험에서는 필요 소모150%가 적용됐다. 이 임계점들은 서서히 어려워지는 보정과 달리 즉시 행동을 잠근다.

## 판정과 우선순위

전 지역 적 수/체력을 함께 낮추는 근거는 아니다. 한두 시설을 수색하고 보급을 확인해 철수하는5~8분 기준을 먼저 잡는 편이 현재 구조와 맞는다. 다음 실제 플레이 점검에서는 장전·방어구 착용·물1개·최소 의료·하중100%이하를 동일하게 맞추고, 짧은 루트 후 수분/탄약/방어구 내구도를 기록해야 한다. 아직 수행하지 않은 반복 플레이의 생존율을 추정치로 보고하지 않는다.

우선 확인할 것은 새 슬롯의 빈 탄창/미착용 방어구/물 미지급으로 인한 준비 상태 차이, 짧은 파밍 루트의 물 접근성, 하중 초과 후 회피 불가 안내다. 필요 소모나 적 스탯의 일괄 완화는 이 확인 뒤 결정한다. 현재 감사에서는 생산 수치를 변경하지 않았다.
