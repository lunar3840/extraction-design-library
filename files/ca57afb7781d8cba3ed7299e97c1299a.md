# Time Ghost 적용 결과

원본 `C:/UnityProject/escape`의 기존 A맵에 적용했다. 기존 프리팹 이름 `StageA_Relay_Blockout_v08`은 연결 보존을 위해 유지했다. 에디터의 에셋 가져오기가 끝난 뒤 Play를 다시 시작하면 새 인스턴스로 확인할 수 있다.

## 적용 범위

- grass ground + rubble 길 재질과 부드러운 도로 경계
- 나무 128곳: Cedar/Dogwood 다방향 이미지 기반 표시
- 바위 80곳: Kullaberg 모델 2종
- 잔디 640곳 + 기존 덤불 위치 192곳의 높은 풀: Standard/Meadow Grass 총 6종

기존 지형, 충돌체, 동선과 건물 실내 구조는 유지한다. 건물·차량·산업 소품·수면은 기존 임시 형태로 남겼다. 나무는 일반 3D 모델이 아니라 원본 샘플의 impostor 자료를 URP로 적응시킨 것이므로 근접 표현 한계가 있다. HDRP/DOTS 샘플 전체의 조명·바람·ECS 기능까지 이식한 것은 아니다.

아트는 `Assets/Escape/Art/TimeGhostV10/`에 모았다. 기존 환경 슬롯의 VisualOverridePrefab 연결을 통해 외형을 다시 바꿀 수 있다. 큰 크기나 피벗·충돌 형태가 다른 에셋으로 교체할 때는 배치와 이동을 재검증해야 한다.

## 검증

분리 Unity 프로젝트에서 정적 3,577개 확인, 이동 경로 233건, 실제 캐릭터 이동 39건, 호안 차단 17건을 통과했다. 원본에는 파일 해시를 대조하여 설치했다. 원본 에디터의 씬이나 Play 상태는 강제로 변경하지 않았다.
