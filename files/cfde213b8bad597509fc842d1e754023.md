# A맵 v1.1 구역 건물군 — 독립 검증

## 현재 판정

**분리 Unity 검증 프로젝트의 최종 prefab은 기술 검증과 이번 단계의 수치화된 구역 밀도 검증을 모두 PASS했다.** 기존 주요 건물 5동과 v0.9 보조 건물 10동에 새 건물 39동이 추가되어 총 54동이 됐고, 새 건물 점유 면적은 4,369.38㎡다.

다만 이것은 **승인한 v1.1 건물군 블록아웃 목표의 PASS**다. v0.7 콘셉트 이미지와 같은 최종 도시·산업 아트 밀도, 골목의 생활감, 울타리·배관·잔해·설비까지 완성됐다는 판정은 아니다. 기술 PASS와 콘셉트 최종 충실도를 구분한다.

Unity 배치·검사 실행은 메인 통합 담당이 수행했고, 본 검토에서는 제작 완료 보고만 신뢰하지 않고 `V11_LAYOUT.json`, `V11_VALIDATION.json`과 원본 크기의 전후·보충 화면을 직접 대조했다. 이후 원본 설치 영수증도 별도로 판독했다.

## 구역별 밀도

최종 배치 수와 실제 footprint 합계는 다음과 같다.

| 구역 | 새 건물 | footprint 합계 |
|---|---:|---:|
| NW_CLINIC | 4 | 374.14㎡ |
| W_MAINT | 9 | 1,198.59㎡ |
| SW_RUINS | 14 | 1,508.21㎡ |

각 구역은 목표 4/9/14/6/6을 정확히 채웠고 배치 shortfall은 0이다. stable ID는 39개 모두 서로 다르며, 각 구역의 건물 중심 범위와 점유 면적도 기록됐다. 기존 15동을 포함한 최종 건물 수는 54동이다.

## 기술 검증

`V11_VALIDATION.json` 최종 결과는 `PASS`, technical 2,185 assertions / 0 failures, density 21 assertions / 0 failures, Unity Error·Exception·Assert 0건이다.

- 기준본 `Assets/Escape/Editor/V11Baseline.prefab`과 비교해 기존 활성 collider 945개의 경로·pose·shape fingerprint가 일치했다.
- `StageA_Landform_v09`의 계층·transform·mesh·collider fingerprint와 기존 semantic anchor 143개의 ID·종류·pose fingerprint가 일치했다.
- 기존 진입 12곳, 탈출 7곳, 중계 3곳, 주요 건물 5곳, 보조 건물 10곳과 교량 2개가 유지됐다.
- 기준본에서 성립한 entry→exit/relay 기존 경로 120개가 최종본에서도 120/120 유지됐다.
- 새 건물 39동의 문은 2개씩 총 78개다. 문 폭, 외부·내부 standing capsule clearance와 양방향 local NavMesh를 모두 검사해 156/156 경로가 통과했다. B1에서 각 건물 내부로 가는 전역 경로도 39/39 통과했다.
- 새 collider 362개에서 새 건물끼리 penetration 0건, 기존 collider와 penetration 0건, 서로 다른 건물 또는 기존 collider와 겹치는 box coplanar face 0건이었다.
- 새 건물은 landform을 바닥으로 사용한다. 별도 floor collider 0개, floor renderer 0개이며 지형 접지 실패도 0건이다.
- missing script 0개, active renderer의 missing mesh/material 0개다.
- replaceable visual 하위 gameplay collider 0개, 별도 collision root 하위 enabled renderer 0개다. collider를 가진 임시 override를 실제 적용·복구한 뒤에도 collision fingerprint가 같았다.

`StageV11Checks`는 v1.0처럼 전체 collider 불변을 요구하지 않는다. 새 건물 collider는 추가돼야 하므로 기존 collider만 기준본과 비교하고, 새 362개는 접지·관통·공면·참조·교체 분리 대상으로 별도 검사했다.

## Play 회귀 확인

별도 담당이 생성한 `V11_PLAY_VALIDATION.json`도 직접 읽어 `PASS`와 실패 없는 최종 집계를 확인했다. SystemsTest의 정상 Stage A 출발 흐름에서 NavMesh 467건, 실제 `PlayerMotor` 이동 273건, 수로 호안 차단 17건이 통과했다.

새 건물은 문 78개의 안팎 양방향 156건과 39동의 반대편 문 관통 양방향 78건, 합계 234건에서 NavMesh 234/234와 `PlayerMotor` 234/234가 통과했다. 이 가운데 건물 관통 경로와 실제 이동은 78/78이다. 39개 visual replacement를 적용하고 두 프레임을 기다린 뒤에도 runtime identity·collision 분리가 유지됐다. 높은 장비값을 흉내 낸 선택 24회도 기존 기본 진입 정책을 유지했다.

## 중간 실패와 수정 확인

첫 생성은 33/39로 NW_CLINIC 3, S_SCRAP 5, E_UTILITY 2에 그쳐 density FAIL이었다. 동시에 일부 문 A의 NavMesh 연결과 긴 우회가 검출됐다. 문 상부 lintel 여유를 보강한 다음 검사에서는 35동의 모든 기술 항목이 PASS했고, East shortfall 4동만 남았다.

최종 생성은 기존 35동을 보존한 채 E_UTILITY의 엄격한 지형·도로·기존 환경 회피 조건을 통과한 후보 4동만 추가했다. 최종 39동에서 모든 문과 기존 경로를 다시 검사해 기술·밀도 모두 PASS했다. 검사기의 footprint 회전 변환도 runtime 좌표계와 독립 대조해 초기 오탐 가능성을 제거했다.

## 화면 직접 판독

동일 정사영 `before_plan.png` / `after_plan.png`에서 서부 정비골목, 남서 생활폐허, 남부 야적장, 동부 전력·창고 부속, 북서 진료소 부속의 건물 점유가 명확히 증가했다. 특히 남서부는 이전 세 동 수준의 고립된 폐허에서 다수의 소형 주거·파손 건물이 이어지는 구역으로 바뀌었고, 서부와 남부도 단일 거점 사이에 중간 규모 목적지가 생겼다.

`after_workshop_interior_supplement.png`에서는 지형 바닥을 유지한 개방 실내, 내부 칸막이와 출입구가 확인된다. `after_residential_supplement.png`에서는 파손 지붕 패널과 지지 구조가 함께 보이며, 대량 부유 지붕으로 읽히는 상태는 보이지 않는다. `after_repair_alley_supplement.png`에서는 건물 사이를 지나는 공간이 확보돼 있다.

## 남은 시각적 한계

- 정사영에서 건물 수 증가는 분명하지만 중앙·북부에는 의도적으로 큰 비건축 공간이 남고, 동부 6동도 넓게 분산돼 있다.
- 서부·남서부는 이전보다 구역성이 강해졌지만 콘셉트 이미지의 촘촘한 연속 골목이나 거의 맞닿은 도시 블록까지는 아니다.
- 건물은 교체 가능한 회색 블록아웃이며 재질·창호·문·간판·배관·울타리·옹벽·마당 포장과 산업 장식이 부족하다. 동일 폭으로 읽히는 길의 위계 문제도 이번 건물군 pass에서 바꾸지 않았다.
- `after_play_entry_district_supplement.png`에는 지표를 가로지르는 큰 직선·다각형 명암 경계가 남아 있다. v1.0의 `after_play_entry_timeghost_supplement.png`에서도 같은 유형을 직접 확인했으므로 새 건물 공면이나 v1.1 배치가 새로 만든 현상으로 보이지는 않지만, 정확한 원인은 아직 진단되지 않았다. 이번 건물 추가 범위를 넘어 셰이더를 임의 수정하지 않았으며 후속 지표 렌더링 점검 대상으로 남긴다.
- 따라서 이번 결과는 “너무 적었던 건물 수와 주요 구역의 비어 있음”을 실질적으로 보강한 단계다. v0.7 콘셉트의 최종 화면 밀도를 100% 재현한 결과로 표현해서는 안 된다.
