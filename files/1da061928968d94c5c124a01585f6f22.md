# Chat Pro 전달 첨부 가이드

이 폴더의 CHAT_PRO_HANDOFF_PROMPT.md를 첨부하고 COPY_PASTE_PROMPT.md를 복사해 새 대화에 붙인다. 또는 CHAT_PRO_HANDOFF_PROMPT.md 전체를 직접 붙여도 된다. 아래 자료를 함께 전달한다. 이 채팅에서는 모델 파일을 복사·수정·업로드하거나 아트를 생성하지 않았다.

1. 최신 사용/승인 버전 Edel 원본과 Serin 원본. .blend가 있으면 원본을 우선하고, FBX/GLB라면 연결된 텍스처·재질 파일을 함께 ZIP으로 묶는다. 파일명에 캐릭터/버전을 표시한다. 단순 스크린샷만으로 실제 피팅 완료를 요구하지 않는다.
2. 각 캐릭터의 정면·측면·후면 및 실제 탑다운 게임 화면/인벤토리 화면. 원본과 같은 버전의 이미지인지 밝힌다. 다른 시점·실험 버전을 최신 승인본으로 섞지 않는다.
3. 제공 가능한 기존 애니메이션이나 대표 포즈. 없는 경우 실제 애니메이션 검증 불가라는 한계를 기록한다.
4. 별도 아트 지침이 있으면 그 원문. 전달문 자체에는 총기24·방탄복16·헬멧14의 목록과 최신 무기 원칙을 포함했으므로01~06의 충돌하는 과거 초안을 전부 무정리로 붙일 필요는 없다.

폴더를 단순히 Edel/Serin으로 나눠 원본 이름과 상대 텍스처 경로를 유지한다. 원본 수정 대신 복제본으로 작업한다. 현재 진행 중인 캐릭터 수정본이 있다면 어떤 버전을 기준으로 삼는지 명시한다. 첨부가 실제로 읽혔는지는 받는 대화에서 파일 목록/구조로 확인해야 한다.

대표4종부터 시작하는 것은 전달 효율을 위한 이번 작업 순서 제안이며, 사용자가 기존에 확정한 제작 수량은 아니다. 전체54종 목록도 검토용 후보다. 콘셉트 이미지 제작과 실제3D 파일 생성·피팅·엔진 적용은 서로 다른 완료 단계다. Chat Pro에서 쓸 수 있는 도구 범위는 여기서 확인하지 않았으며, 실제3D 파일 생성 가능 여부를 단정하지 않는다.
