# 지붕 위 시야 경계 표시 수정

## 사용자 지시 요약

캐릭터가 지붕에 가려졌을 때 원형 시야 경계가 지붕을 뚫고 그려지는 화면 표현을 점검하고 수정한다.

## 기획 의도와 해결하려는 문제

플레이어 시야 효과는 플레이 공간에 적용되어야 한다. 지붕처럼 플레이어보다 위에 있고 화면에서 플레이어를 가리는 표면에는 시야 경계가 떠 보이지 않게 한다. 지붕 밖의 전방 시야 표현과 적 표시 규칙은 유지한다.

## 변경 전 상태 및 문제점

- 사용자 제공 실제 Game 화면 `before_user_game_view.png`에서 지붕을 가로질러 시야 밝기 경계가 표시됐다.
- 동일한 카메라와 지붕 배치를 사용한 검증 장면 `before_roof_scene.png`에서도 원형 경계가 지붕 표면에 보였다.
- 원인은 화면 앞에 그리는 시야 오버레이가 `ZTest Always`로 작동하면서, 표면의 깊이와 높이를 확인하지 않았기 때문이다.

## 실제로 바꾼 부분과 방식

- 시야 오버레이가 현재 화면의 깊이 텍스처를 읽고, 표면의 월드 높이를 복원하게 했다.
- 화면 표면이 플레이어 발 높이보다 1.8m 이상 높으면 그 픽셀의 시야 오버레이를 투명하게 처리한다. 지붕 같은 상부 가림면이 시야 경계보다 앞에 보이도록 하는 처리다.
- 플레이어 카메라가 깊이 텍스처를 생성하도록 요청해 파이프라인 기본 설정과 관계없이 이 판정에 필요한 깊이 정보를 확보했다.
- 맵 지붕 에셋, 지붕 충돌, 적 가시성 판정과 전방·근접 시야 범위는 변경하지 않았다.

## 변경 후 기대 효과와 확인 결과

- `after_roof_scene.png`에서 지붕 위 원형 시야 경계가 사라졌고 지붕 밖의 어두운 전방 시야 구분은 남아 있다.
- 별도 Unity 검증 프로젝트에서 변경된 셰이더와 C# 코드가 컴파일되고 동일 카메라·장면의 전후 화면이 생성됐다.
- 기존 플레이어 시야 검사 4개가 모두 통과했다: 근접 후방 적 표시, 반경 밖 후방 적 숨김, 벽 뒤 적 숨김, 원거리 전방 적 표시. `vision_checks.log` 및 검증 프로젝트의 `Library/EscapePlayerVisionChecks.txt`에 결과가 있다.
- 실제 메인 맵의 게임 화면을 자동으로 다시 촬영하지는 못했다. 첨부 Game 화면은 변경 전 실제 상황이며, 전후 비교 이미지는 같은 깊이 처리를 적용한 격리된 Unity 지붕 장면이다.

## 관련 스크린샷 파일명 및 서로 대응하는 비교 시점

- `before_user_game_view.png`: 사용자가 첨부한 실제 메인 게임 화면의 변경 전 모습.
- `before_roof_scene.png` ↔ `after_roof_scene.png`: 1600×900, 같은 카메라, 플레이어와 지붕 위치, 조명 및 UI 상태의 검증 장면.
