# 헬멧 부피 조정 및 캐릭터 머리색 유지

2026-09-04. 대상 `C:/UnityProject/escape`, 검증 사본 `C:/tmp/EscapeHelmetRefit`.

이전 헬멧의 사람 두상용 긴 타원 비율 때문에 SD 캐릭터에서 앞뒤가 과도하게 커 보였다. 돔의 폭은 4%, 깊이는 16%, 높이는 2% 줄이고 위치를 앞으로 조금 옮겼다. 플레이어의 소스 경계 기준 크기는 약 (.62, .54, .77)에서 (.59, .53, .65)로 바뀌었다. 얼굴·눈·본은 수정하지 않았다. 고글은 별도로 폭 약 2.5%, 높이 10%를 줄이고 위쪽 측면의 피부 노출을 보정했다.

노출되는 뒷머리를 채우던 공통 HelmetCap 재질을 제거했다. 각 캐릭터의 원래 Hair/Base 렌더러의 헤어 재질과 텍스처를 사용하는 보완 헤어로 교체했다. 하나의 원래 UV 삼각형 안에서 연결해 텍스처 이음새를 피하고, 기존 두피 사본을 함께 표시하지 않아 표면 겹침도 피한다. 금발/갈색/밝은 회색 캐릭터별 색을 확인했다. 보완 헤어는 매끈하게 단순화한 형상이며 원래 머리카락 가닥 전체를 재현한 것은 아니다.

사용자 요청인 **향후 캐릭터 모델을 바꿔도 원래 머리색 유지**를 작업 폴더와 Unity `Assets/Escape`의 AGENTS.md 및 방어구 README에 기록했다. 다른 모델은 헤어 이름·서브메시·재질·UV 연결을 명시적으로 새로 설정해야 하며, 현재 Haon 연결 방식만으로 임의의 모델을 자동 지원한다고 가정하지 않는다.

## 검증과 반영

- 최종 세 캐릭터 정면·측면·후면과 플레이어 총 대기/이동/달리기를 Unity 카메라로 렌더링했다. 고글 모서리의 피부 관통과 뒷머리 표면 겹침을 발견한 중간안은 수정 후 재렌더링했다.
- 최종 Play Mode 검사 66 PASS. 장착/해제/비활성화/가방 교체 시 복원, 실제 고글 메시, 둥근 돔 경계 비율, 각 캐릭터 원래 헤어 재질 연결, 겹치는 이전 두피/안감 부재, 장비 스키닝, 총 12시점 그립, 인벤토리 인물 뷰를 확인했다. 최종 로그에 FAIL/컴파일 오류/Exception 없음.
- 의존 파일 96개 확인, 헬멧 관련 12개만 변경·복사 후 SHA256 일치. 방탄복과 런타임 소스는 변경되지 않았다. `Armor-Compact-ImportedFiles.json`에 기록하고 이전 파일은 `work/armor-compact-backup`에 보관했다. README/AGENTS 문서는 별도 반영했다.
