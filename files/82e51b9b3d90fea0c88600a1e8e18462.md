4. **국소 가림**: 큰 가슴 중심 타원을 실제 플레이어·머리·장비·무기의 현재 GPU 형태와 깊이를 담는 전용 마스크로 교체했다. 약 .22m의 좁고 부드러운 여백, .18초 전환을 사용하며 앞을 가리는 건물 픽셀만 연다. 신규 Shell/Roof와 별도 보존 W10 샘플을 포함한다. 원본 유리·alpha cutout·금속틀·그림자는 구분해 유지한다.
5. **새 모델의 크기 단위와 중첩면 처리**: 작은 로컬 좌표의 FBX가 큰 배율로 배치되면 절대 오차 기준이 실제 지붕 삼각형을 누락했다. 크기에 독립적인 정확한 교차 판정으로 고쳤다. POWER는 여러 벽·지붕 면의20% veil이 누적돼 벽색 윤곽만 남았으므로 몸체 중심부 opacity를1%로 낮춰 실제 머리·복장·다리 색을 보이게 했다.
6. **처리량과 복구**: 실제 캐릭터의 보수적인 화면 범위 밖은25회 마스크 읽기를 건너뛴다. 정확한 삼각형 판정은 mesh/submesh별 BVH 캐시를 공유한다. 경계 상자만으로 가림을 확정하지 않는다. 맵/컴포넌트 비활성화 시 원래 재질 참조를 돌리고 전용 RT·veil·이벤트를 정리한다.
