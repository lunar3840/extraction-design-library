# 안뜰 복합 광원 적용

2026-09-10. Unity 6000.1.0f1 / URP 17 프로젝트 `C:/UnityProject/escape`에 적용했다. 맵 프리팹, 배치, 카메라 구도와 캐릭터 원본 리소스는 변경하지 않았다.

벽등 6개 모두 전구 주변의 약한 Point Light와 바닥을 향하는 Spot Light를 함께 사용한다. Spot Light에는 절차적으로 만든 불규칙 Cookie가 들어가며, 성능과 화면 복잡도를 제한하기 위해 서로 떨어진 3개만 부드러운 실시간 그림자를 만든다. 기존 발광 재질과 Bloom은 유지하고 강도를 소폭 높였다.

벽등 주변 3구역에는 128 해상도 지역 반사 프로브를 추가했다. 기존 256 해상도 안뜰 프로브와 함께 젖은 바닥에 따뜻한 광원과 가까운 벽의 색을 반영한다. 캐릭터를 반사 캡처에서 제외하는 기존 정책을 유지한다. 플레이 시작 시 네 개의 반사 캡처는 여러 프레임으로 나누어 실행한다.

캐릭터 Hybrid Toon 셰이더, 3단 명암, 외곽선 및 원래 얼굴·머리카락 텍스처 연결은 유지된다. 새 광원은 국소 범위로 제한해 캐릭터의 명암 단계가 전체적으로 밝아지지 않도록 했다.

실제 SystemsTest 플레이에서 37개 검사가 통과했다. 출격, 이동, 사격, 비, 젖은 바닥과 파문, 카툰 재질 복원, 원래 헤어 연결에 더해 벽등 6개의 Spot/Fill, Cookie, 선택 그림자 3개, 지역 반사 프로브 3개의 캡처 완료를 검사했다. 광원을 끈 대조 화면과 비교해 16,142개의 실제 렌더 픽셀이 달라졌다.

`Before_Overview.png`/`After_Overview.png`와 `Before_Gameplay.png`/`After_Gameplay.png`가 전후 자료다. `Lamp_On.png`/`Lamp_Off.png`는 같은 실제 플레이 카메라에서 복합 벽등만 켜고 끈 대조 화면이다. `PlayChecks.txt`에 검사 결과가 있다.

실행파일 빌드와 FPS 벤치마크는 수행하지 않았다. 지역 프로브는 시작 시 한 번만 촬영하며 움직이는 캐릭터를 거울처럼 반사하지 않는다. 이전 상태는 `work/courtyard-lighting-backup`에 보관했다.
