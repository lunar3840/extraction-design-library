# 에델 Pro 원본 모션 적용과 실제 재생 검증

에델의 보존된 Pro 제작 원본에서 평가된 모션을 추출해 Unity 실제 플레이와 인벤토리에 연결했다. 기존 구르기용 모델 전체 회전과 임시 팔·손가락 보정이 원본을 덮어쓰지 않도록 적용 순서를 분리했다. 실제 입력 재생, 원본 DQ 표면 대조, 인벤토리 수동/자동 표정·몸짓 및 다른 세 캐릭터의 기존 경로를 확인했다.

새로 재발급된 Unity 패키지/ZIP의 다운로드는 여전히 확보되지 않았다. 실제 검증 기반은 이미 로컬에 보존된 `EDEL_ShoulderConnection_r18.blend`이며, 원본 출처와 파일 확보 범위를 `SOURCE_PROVENANCE.md`에 구분했다. 세린·리브·유이까지 새 Pro 모션으로 교체했다는 뜻이 아니다.

## 사용자 지시와 기획 의도

사용자는 “chat pro 대화에서 원본 파일 다시 확보해서 실제 제작했던 모션들 유니티에 적용”, “기존 임시 모션 말고 원본이 제대로 재생되는지까지 확인”하도록 지시했다. 피곤해 별도 조작 없이 진행하도록 했고, 공간 부족은 원본을 보존하며 자체 정리하도록 승인했다. `USER_REQUEST.md`에 원문과 기존 유효 조건을 보존했다.

같은 캐릭터 모션 동기화 목적의 후속 구현이므로 기존 주제 ID와 캐릭터/리깅·애니메이션 분류를 유지했다. 같은 날01회차는 미완료 원인 분석이고, 이 기록은 실제 구현·검증02회차다. 진행 확인과 원격 파일 재발급만으로 구현 회차를 추가하지 않았다.

## 변경 전 상태와 원인

- Unity는 기존 Humanoid 컨트롤러와 절차적 팔·손가락 보정 및 구르기용 전체 모델 회전을 사용했다. Pro 원본의 실제 뼈대·표정·보정 키를 그대로 재생하는 경로가 아니었다.
- 원본52본의 평가 행렬, DQ 스키닝과77개 네이티브 보정 키가 필요했다. 기본 LBS 재생 또는 단순 FBX 교체만으로는 극단적인 구르기 표면이 달라졌다.
- 실제 변경 전에 동일한 시험 장면에서 기본 입력33화면을 촬영했다. `before/`와 `before_RUNTIME_REVIEW.json`이 실제 사전 기록이다.
- 인벤토리 사전 화면은 미리 촬영하지 못했다. 보존된 원래 프리팹·기존 재생 경로로 재구성한 두 화면만 `before_reconstructed_inventory_*`로 표시했다. 사후 촬영본을 사전 실촬영으로 표시하지 않았다.

## 실제 변경

1. 보존 원본의 비시연 모션134개 카탈로그에서 원래30fps의 평가 본 행렬과 모프 값을 추출했다. 원본·바이너리 해시, 축 변환과 정지 자세 보정을 명시했다. 과거 액션도 포함되어 있어134개 전부를 최신 채택 모션으로 간주하지 않는다.
2. 별도 `SD/ProMotion/Edel/Player_Edel` 프리팹과 네이티브 보정 메시를 추가했다. 실제 칩 ID인 `CompanionChipCatalog.EdelId`(`prototype`)로만 연결하며 기존 칩/저장 ID는 변경하지 않았다. 기존 공용 프리팹·컨트롤러를 덮어쓰지 않았다.
3. `EdelOriginalMotion`이 실제 플레이어의 이동·조준·발사·재장전·구르기·피격·사망 및 기존 감정표현 스케줄러를 읽어 원본 액션을 선택한다. 이동 중 상체 동작은 원본 상체 본을 기존 원본 보행 위에 정렬해 재생한다. 액션 전환에는0.12초 혼합을 사용한다.
4. `OriginalMotionDataset`이 검증된 본 축/위치와 네이티브 모프를 적용한다. 원본 DQ 스키닝을 `OriginalDqSkin`과 에델 전용 셰이더로 재현했다. 정점의 원래 영향 본 순서 및 누적 부호 규칙도 보존했다. 공용 `HybridToon.shader`는 변경하지 않았다.
5. 에델 원본 경로가 활성일 때 기존 절차적 팔·손가락 IK와 모델 전체 회전이 덮어쓰지 않도록 했다. 실제 게임의 탄약·피해·이동·무적/쿨다운 규칙은 유지한다. 원본 구르기2.4초는 현행 게임 구르기0.3초에 맞춰8배속 재생하며, 재장전은 현행 무기 재장전 진행률에 맞춘다. 원본 동작을 같은 실시간 길이로 무조건 재생하는 방식은 아니다.
6. 현재 게임 총기 모델은 원본 Weapon 본의 방향을 유지하면서 오른손 파지 기준점에 부착한다. 원본 팔을 총기에 맞추려고 다시 꺾지 않는다. 비활성 임시 총기 프리팹의 표시 누락을 고쳤고, 기존 정책대로 구르기/사망 중 숨김과 종료 후 복귀를 유지했다. 원본 Magazine 본 상대 변환 연결도 추가했으나 이번 표본에서 유의한 탄창 이동은 관측하지 못해 탄창 교체 실물 검증 완료로 주장하지 않는다.
7. 인벤토리 복제 모델은 원본 자세·표정을 별도 시간으로 재생한다. 기존 수동 클릭과 캐릭터 무입력 자동 감정표현을 유지했다. 카메라/크기/발 위치의 설정값과 UI 배치를 바꾸지 않았다. 방어구 숨김 시 완성된 이너웨어가 표시된다.
8. 원본 드라이버를 끄거나 네이티브 근접 공격이 없는 칼을 들면 기존 애니메이터로 복귀하고 원본 전용 몸 보정 키를 지운다. 다시 총기를 들거나 드라이버를 켜면 원본 경로를 재개한다. HIGH READY 취소는 유지한다.

## 실패 시험·오류 복구·공간 정리

중간 조사와 실패 기록은 `HISTORY_WORK_LOG.md`와 `trials/`에 보존했다. PCA/LBS 근사 후보는 전체 구르기 오차 약0.278338 단위로 불합격 처리했고 생산 적용하지 않았다. DQ의 최댓가중치 기준 부호 선택도 전체292프레임 중 일부5.52mm 차이로 폐기한 뒤 원래 누적 순서로 교체했다. 두 기준점을 맞추려고 총을 회전·축소한 시험은 총구 방향을 바꿔 폐기했다. 문자열 ID 오류와 비활성 임시 총기 누락 시험도 최종 합격 사진으로 사용하지 않는다.

임시 후보 저장 도구가 전역 직렬화 모드를 바꿔 프로젝트 전체 재직렬화를 유발한 구현 오류가 있었다. 디스크 부족 중단 후 기존 ForceText(2)로 복귀하고, 원래 씬을 디스크에서 다시 열어 검사했다. 이후에는 파일 하나만 별도 형식으로 저장하는 API로 변경했다. 복구 검사에서 루트4개, Renderer24,171개, MeshFilter25,927개 및 현재 의존8,787개를 검사해 누락/빈 메시와 누락 재질0건이었다. 사전 개별 해시가 없는 의존8,787개 전체까지 사전 사후 동일하다고 증명한 것은 아니다. 기존 보호 파일의 정확한 해시 대조와 현재 의존 상태 검사는 구별한다. `SERIALIZATION_RECOVERY_AUDIT.json` 전체와 `RECOVERY_SUMMARY.json`을 보존했다. 이전 원본으로 맵/에셋을 일괄 롤백하지 않았다.

공간은 사용자에게 추가 요청하지 않고 정리했다. 이 작업 소유의 세린 r18~r31 중간 blend/FBX19개는 압축 후 전 멤버 SHA를 대조해 약484MB를 확보했다. 에델 의상 r2~r13 중간본12개도 각각 복원 SHA를 대조해 압축 보관했다. 현재본·기준본·원본 모션은 보존했다. `SPACE_RECOVERY*.json`에 복원 경로와 해시를 남겼다. 로컬 Unity Assets/Library에는 내용이 바뀌지 않는 NTFS 투명 압축을 적용했다. OneDrive 캐시 압축은 수화에 따른 공간 증가를 확인해 중단했다. 오래된 검증 프로젝트 캐시 삭제는 자동 승인 검토에서 차단돼 실행하지 않았고 같은 삭제를 우회하지 않았다.

## 남은 제한과 다음 작업

- 새 Pro Unity 패키지/ZIP 다운로드는 미확보다. 로컬 보존 원본에서 검증된 에델 모션만 실제 적용했다.
- 세린·리브·유이용 새 네이티브 원본이나 최종 공통 모션은 확보하지 않았다. 기존 동작 유지 여부만 검사했다.
- S4 의상의 일부 표면 깨짐/들뜸은 사전·사후 화면에 모두 보이는 별도 기존 문제다. 이 모션 작업에서 의상 메시·텍스처 정리가 완료됐다고 보고하지 않는다.
- 무기별 외형은 기존 임시 모델이다. 원본 손가락/팔 자세를 보존한 상태에서 실제 최종 총기 형상과의 양손 피팅은 별도 검수가 필요하다.
- 네이티브 칼 공격을 확보하지 못해 기존 경로로 복귀한다. 사망·피격·비무장 등의 연결은 코드와 원본 표면 표본에 포함되지만 이번 실제 플레이96화면이 모든 입력 조합을 전수 검증한 것은 아니다.
- 헤어 충돌 시스템은 유지하고 그 이후 DQ 렌더를 갱신한다. 모든 머리카락/몸/총기의 절대 비관통을 새로 보증하는 작업은 아니다.
- 검증 환경은 Unity6000.1.0f1 Windows DX12 편집기다. 독립 실행 빌드 및 다른 플랫폼 검증은 수행하지 않았다. 영상 촬영은 기존 유보 지시를 유지한다.
