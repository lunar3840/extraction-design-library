# 실제 Unity HUD·파밍 화면 검수

- 검수일: 2026-10-23 KST
- 범위: `unified-figma-ui/`의 실제 Game View 1920×1080 전후 PNG 11쌍, 총 22장.
- 방법: 각 원본을 `view_image`로 직접 열어 한국어 문구, 수치, 경계, 겹침을 읽었다. Figma 시안만 보고 판정하지 않았다.
- 권한: 읽기 전용 검수. Unity, Assets, Library, Editor, 요청 파일, Figma 및 웹은 수정하지 않았다. 이 보고서만 작성했다.

## 결론

새 공통 스타일 때문에 발생한 텍스트 잘림이나 컨트롤 간 겹침은 이번 11개 상태에서 발견하지 못했다. 인벤토리의 청회색 반투명 면, 둥근 경계, 민트색 강조, 한글 글꼴과 HUD·지도·파밍 패널이 일관되게 연결된다. 30분 작전 시간, 무기 탄 수, 의료 행동과 상태 이름이 각 박스 안에 들어간다.

단, 파밍 상자 3개가 모인 상태에서는 기존의 동료 탐색 월드 표식 세 개가 새 세로 선택 목록의 두 번째 행 위에 중복 표시된다. **변경 전에도 존재하는 문제지만 이번 공통 UI 검수에서 해결할 필요가 있는 미해결 항목**이다. 메인에 즉시 전달했으며, 아래 표시 전용 최소 조정을 제안했다. 수정 후 재검수 전까지 해당 항목을 통과로 세지 않는다.

## 파밍 목록의 중복 표식 상세

- 대상: `after_loot_prompt_group_1920x1080.png`
- 위치: 대략 x=900~1010, y=805~841. 세로 목록의 중간 행 텍스트 위에 금색 `◇ 물자 용기`가 여러 번 포개진다.
- 비교: `before_loot_prompt_group_1920x1080.png`에도 같은 중복이 있어 스타일 변경이 만든 회귀로 분류하지 않는다.
- 원인: `CompanionAbilityController.OnGUI()`의 Scout 용기 탐색 표식이 `LootInteractor.DrawPromptStack()`의 세로 목록과 동시에 표시된다. `LootContainer` 자신의 GUI가 아니다.
- 실제 경로: `CompanionAbilityController.cs`의 `foreach (var container in LootContainer.All)`가 12m 이내·시야 조건으로 `DrawMarker(p, "물자 용기", gold)`를 호출하고, `DrawMarker`가 `◇ ` 접두사를 붙인다.
- 최소 표시 전용 제안: `LootInteractor`에 상태를 바꾸지 않는 `IsPromptVisibleFor(container)`를 두고, 실제 세로 목록에 표시 중인 동일 용기에 한해서만 동료의 금색 텍스트 표식을 생략한다. 목록 표시 가드와 앞면 투영 조건을 동일하게 검사하고 `visible=min(8,count)`, `first=Clamp(selected-visible+1,0,count-visible)`의 실제 표시 구간만 포함해야 한다. 전체 `PromptCandidates`를 무조건 생략하면 8개 초과의 숨긴 행에 대응하는 원거리 표식까지 사라질 수 있다.
- 보존 사항: 범위·시야 판정, 후보 정렬, 현재 선택, 휠 순환, F 단일 입력, 수색·아이템 이동, 동료 능력의 실제 탐지 효과를 변경하지 않는다.

## 한계와 비차단 관찰

- 모든 PNG는 동일한 1920×1080이지만 전후 월드 카메라/캐릭터의 투영 위치가 일치하지 않는 장면이 있다. 예를 들어 변경 전 전투의 캐릭터는 x≈620, 변경 후는 x≈964에 있다. 따라서 월드 캐릭터와 화면 고정 UI 간 거리 변화는 새 스타일의 배치 회귀라고 단정하지 않았다.
- 밝은 기지 바닥 위에서는 반투명 V 카드의 회색 보조 문구와 테두리 대비가 전투의 어두운 바닥보다 약하다. 문구는 읽히며 변경 전에도 같은 성격이 있다. 차후 밝은 배경을 많이 사용할 경우 공통 HUD 패널 불투명도에 대한 별도 대비 튜닝을 검토할 수 있다. 이번 검수에서 기능 추가나 임의 색상 수정은 요구하지 않았다.
- 치료 진행 카드의 좌측 글자 여백이 좁지만 변경 전과 같은 영역이며 잘리지 않는다.
- 이 검수는 정지 이미지의 시각 검수이다. 마우스 클릭·드래그·휠·장착·수색 트랜잭션 동작을 검증한 것으로 대체하지 않는다.
- 현행 정책인 체스트리그 의료품 자동 V 선택은 유지되어 보인다. 의료 휠 또는 숫자 소모품 퀵슬롯의 복귀를 요구하지 않았다.

## 후속 확인

1. 메인의 중복 월드 표식 표시 전용 패치가 적용되면 같은 3상자 상태의 새 실제 PNG를 다시 확인한다.
2. 해당 새 PNG에서 두 번째 행이 온전히 읽히고, 다른 원거리 표식이 필요한 상태의 정책이 보존됨을 확인한 뒤 위 미해결 항목을 갱신한다.

최종 시각 판정: **요청 범위에서 신규 텍스트 잘림·겹침 없음. 발견했던 기존 파밍 목록 중복 표식도 실제 r02 화면에서 해소됨.** 총 28장(초기 22장 + 보완 6장)을 직접 열어 검수했다. 검수자는 보고서 외 파일이나 Unity 실행 상태를 변경하지 않았다.
