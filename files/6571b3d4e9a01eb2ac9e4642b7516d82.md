# 플레이어 상태 인지 기반 전투 판단

## 사용자 지시 요약

적이 플레이어의 실제 스탯을 무조건 조회하지 않고, 자신이 플레이어에게 준 피해와 육안으로 확인 가능한 상태를 근거로 플레이어의 상태를 추정하여 전투 의사 결정에 활용하도록 한다.

## 기획 의도와 해결하려는 문제

기존 AI가 플레이어의 현재 HP와 최대 HP를 직접 읽으면 플레이어가 얻을 수 없는 정보를 정확히 아는 이른바 치팅 AI가 된다. 적마다 관찰 기억과 확신도를 따로 두어, 같은 전투에서도 직접 확보한 정보의 양에 따라 다른 결정을 내리게 만드는 것이 목표다.

## 변경 전 상태 및 문제점

- `EnemyController`가 매 판단 시점에 `Target.State.Health / Target.State.EffectiveMaxHealth`를 직접 계산했다.
- 적이 실제로 플레이어에게 얼마나 피해를 줬는지 기억하지 않았다.
- 플레이어의 치료 행동처럼 눈으로 확인 가능한 약점 노출을 전투 판단에 활용하지 않았다.
- 변경 전 검증 화면에서는 개인별 인지 기억, 피해 기반 추정 HP, 판단 확신도가 모두 `UNAVAILABLE`이었다.

## 실제로 바꾼 부분

- 적마다 독립적인 `EnemyTargetPerception` 기억을 생성한다.
- 자신이 명중시켜 방어구 처리 후 실제 적용된 피해만 누적한다.
- 누적 피해로 플레이어의 남은 내구도를 추정하고, 증거가 쌓일수록 확신도를 높인다.
- 시야 안에서 플레이어가 의료 아이템을 사용 중인 경우만 치료 행동을 관찰한다.
- 치료량은 알 수 없으므로 치료 목격 후 추정 HP를 보수적으로 올리고 확신도를 낮춘다.
- 플레이어가 약하다는 추정은 확신도 45% 이상일 때만 판단에 사용한다.
- 공격형은 확실히 약해진 대상 또는 치료 중인 대상을 압박하고, 균형형은 충분한 피해 증거가 있을 때 마무리하며, 불확실한 정보만으로는 돌격하지 않는다.
- 자신의 HP가 낮을 때에도 상대 상태 증거와 치료 행동을 생존·돌격 판단의 보조 입력으로 사용한다.

## 변경 방식

전투 판단과 플레이어 객체 사이에 순수한 인지 기억 모델을 추가했다. 컨트롤러는 적이 직접 발생시킨 최종 피해 결과와 현재 시야 내 치료 행동만 이 모델에 전달하며, 브레인은 실제 플레이어 HP 대신 `추정 HP + 확신도 + 관찰된 치료 여부`를 입력으로 받는다. 일반 적의 예상 내구도 기본값은 100이며 이는 런타임 스탯 조회가 아닌 프리셋 지식이다.

## 변경 후 기대 효과와 확인 결과

- 적은 플레이어의 실제 HP 및 최대 HP를 직접 조회하지 않는다. 정적 검색 결과 `Target.State.Health`와 `Target.State.EffectiveMaxHealth` 참조는 적 런타임 코드에서 0건이다.
- 적 A가 준 피해는 적 B의 기억에 공유되지 않는다.
- 100 내구도를 예상한 적이 실제 적용 피해 35를 직접 확인하면 추정 HP는 0.65, 확신도는 0.43이 된다.
- 확신도가 낮은 HP 추정은 마무리 돌격을 유발하지 않는다.
- 공격형 적은 시야 안의 치료 행동을 약점 노출로 판단해 압박할 수 있다.
- 적 AI 자동 검사 119개 통과, 실패 0개.
- 전투 피해·히트스캔 핵심 검사 40개 통과, 실패 0개.
- 현재 Unity 편집기 로그에서 최근 C# 컴파일 오류 없음.
