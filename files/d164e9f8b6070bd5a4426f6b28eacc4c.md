# A 구역 v0.3 Unity 블록아웃

## 컨셉과 구조

부분 침수된 구 도시 기반시설 정비지구입니다. 환승역이나 인간 상주 기지가 아닙니다. 기계가 점유한 지상에 인간 수색조가 자원을 찾으러 들어와 정해진 탐색 범위를 순환합니다. 인간 수색조에는 탈출구 사용·철수 동작을 연결하지 않았습니다.

- 전체 배치: 520 × 400 Unity 단위. 평면도 북서 원점을 Unity `(x - 260, 높이, 200 - y)`로 변환합니다.
- 중앙: 80 × 56 규모의 중정비동. 과거 도시 유지보수용 중장비·작업차량과 설비 부품을 정비하던 시설입니다. 동서 차량 출입구, 남북 보행 출입구, 부품실·전기실, 높이 4m 상부 작업 통로, 깊이 2.4m 정비 피트를 배치했습니다.
- 외곽: 북서 직원 진료소, 북동 전력·전기동, 동쪽 정밀부품 창고, 서쪽 공구 정비점, 남쪽 차량 야적장과 남서 폐허. 네 실내 외곽 시설은 서로 반대쪽 출입구를 갖습니다.
- 침수: 남동쪽 국소 수로와 두 교량. 맵 전체를 물로 채우지 않았습니다. 수로 바닥은 AI 보행 경로 생성에서 제외했습니다. 수영·익사 시스템은 이번 범위가 아닙니다.
- 중앙 우회: 중앙 건물을 통과하지 않아도 외곽 시설·탈출구로 이동할 수 있는 외곽 순환로와 중앙 우회로를 배치했습니다.

## 실제 연결된 기능

- A 출격은 새 블록아웃을, B 출격은 보존한 옛 A 프리팹을 활성화합니다. 일반 저장 슬롯의 B 해금 조건은 그대로입니다.
- 진입점 12개, 플레이어 탈출구 7개. 탈출 지점에는 녹색 바닥·게이트 표식이 있고 4초 연속 대기 귀환이 연결돼 있습니다. 현재는 7곳 모두 사용할 수 있는 검증용 설정입니다.
- 무장 가치에 따른 누적 스폰 풀: 티어 0 네 곳 → 티어 0+1 여덟 곳 → 전체 열두 곳. 임시 경계값은 10,000 / 30,000이며, 장착 무기·방어구의 현재 카탈로그 가격을 사용합니다. 최종 경제 밸런스 수치가 아닙니다.
- 인간 수색조: 3개 순환 경로에 기존 인간 AI를 2명씩 배치했습니다. 기존 전투·수색 반응을 재사용한 기능 검증용이며, 파티 협동 전술이나 별도 인간 보스 AI까지 구현한 것은 아닙니다.
- 기계 조우: 중앙·북동·남동 세 배치 슬롯을 보존했습니다. 기계 적 모델·전용 AI·보스 전투는 아직 연결하지 않았습니다.
- 지붕: 해당 실내에 진입하면 지붕 표시를 숨깁니다. 이번 블록아웃의 지붕은 보행 대상이 아니며 조준을 막지 않도록 비충돌입니다. 계단·상부 바닥·정비 피트·벽에는 실제 충돌이 있습니다.
- 기존 저장된 A 유품 좌표가 새 구조물과 충돌할 경우 표시 위치를 근처 보행면으로 보정합니다. 원래 저장된 유품 내용과 퀘스트 키는 변경하지 않습니다.

## 씬과 편집

원본 프로젝트: `C:/UnityProject/escape`

- `Assets/Escape/Scenes/StageA_Blockout.unity`: 새 A 편집/플레이 씬. Play 시 현재 씬의 실제 블록 geometry를 사용합니다.
- `Assets/Escape/Scenes/StageB_Legacy.unity`: 옛 A 보존본. Play 시 임시 격리 슬롯으로 B에 들어갑니다.
- `Assets/Escape/Resources/StageMaps/StageA_Blockout.prefab`: 일반 SystemsTest 출격에 쓰이는 A 원본.
- `Assets/Escape/Resources/StageMaps/StageB_Legacy.prefab`: B에서 실제로 사용하는 옛 A 보존본.
- Unity 메뉴 `Escape > Stage Maps > Open Retained A` / `Open Preserved B`로 열 수 있습니다.
- 씬 미리보기는 고유 임시 저장 폴더를 사용하며 사용자 일반 세이브 슬롯을 덮어쓰지 않습니다. B 해금 우회도 이 격리 B 미리보기 슬롯에서만 적용합니다.
- 편집용 씬 자체를 바꾼 내용과 일반 출격용 프리팹은 별도 에셋입니다. 일반 출격에도 수정 사항을 반영하려면 해당 프리팹도 갱신해야 합니다.
- 기존 프로젝트의 빌드 씬 목록과 시작 씬은 변경하지 않습니다.

## 검증 범위

`PLAY_VALIDATION.json`에는 실제 Unity Play mode의 경로 검사와 PlayerMotor 통과 결과를 기록합니다. 저장·귀환 회귀 검사는 기존 SessionChecks도 실행했습니다.

경로 통과는 지형이 연결돼 있다는 증거입니다. 실제 적 압박 아래의 난이도, 장거리 퀘스트의 시간적 여유, 보상 분포와 30분 레이드의 완성도까지 검증한 것은 아닙니다. 전리품은 기능 검사용 컨테이너만 연결되어 있으며, 랜드마크별 최종 고가치 보상표는 후속 배치 대상입니다. 이번 결과는 아트 완성 맵이 아니라 실제 충돌·이동·진입·귀환이 가능한 첫 공간 검증본입니다.
