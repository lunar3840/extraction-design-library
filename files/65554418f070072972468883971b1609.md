# A맵 공장 남측 외벽 반복 완화 V19

## 사용자 지시와 의도

그래픽을 더 현실적으로 개선하는 후속 작업으로, 제안한 남측 공장 외벽의 창·보수판 반복 완화 작업을 실행하라는 지시(“한번 해봐”). 동일한 창과 하부 보수판이 균일하게 반복되는 인상을 줄이고, 부분 수리와 물때의 흔적을 더한다. 전체 맵 재배치나 충돌·진입점 변경은 범위 밖이다.

## 변경 전 상태와 증빙

2026-09-23 01:58의 실제 Unity 상태에서 먼저 촬영했다. 이전 단계 이미지를 재사용하거나 사후 재구성하지 않았다. 남측 상부 창 14개가 7개 모듈로 반복되고, 서측 하부 보수판 3개의 폭·높이가 동일했다. 기존 벽 자체의 얼룩 텍스처가 강했다.

`backup/StageA_Relay_Blockout_v08.unity`와 `backup/StageA_Relay_Blockout_v08.prefab`에 변경 전 장면과 프리팹을 보관했다. `BASELINE_VALIDATION.txt`에서 기존 렌더러 5,990개, 충돌체 4,665개, 게임플레이 위치 참조 46개를 기록했다.

## 실제 변경과 방법

- 상부 창 14곳 중 4곳에 폭 2.8–3.1m의 부분 금속 보수판과 상·하단 접힘을 추가했다. 창 전체를 폐쇄하지 않는다. 합산 폭 11.65m로 외벽 80m 중 14.6%다.
- 기존 서측 하부 보수판을 서로 다른 폭 7.00/9.20/9.45m, 높이 2.77/3.12/2.84m로 조정했다. 해당 판·캡·하단·이음부의 명시된 11개 시각 요소 위치와 크기만 변경했다. 기존 재질과 메시 및 충돌체는 그대로다.
- 빗물 흘러내림 10곳, 낮은 벽면의 흙 튐 6곳을 시각 전용 표면으로 추가했다. 개구부와 환기구를 피하고 물때를 동일 간격으로 반복 배치하지 않았다.
- 기존 금속 텍스처를 별도 V19 재질에 연결하고, 물때는 가장자리와 끝부분이 불규칙하게 사라지는 조명 반응 셰이더로 만들었다. 기존 벽 무늬에 묻히는 현상을 줄이기 위해 최종 투명도 계수는 1.6, 상한은 0.58로 제한했다.
- 추가 요소는 기존 외벽 숨김 그룹 아래에 두어 실내 및 하역 차양 아래에서 기존 시야 확보 규칙을 따르게 했다.

통합 중 보수판이 벽 앞에 뜨지 않도록 실제 벽면 깊이를 기준으로 수정했다. 초기 물때 배치 검사가 두 흙 튐의 하단 제한 위반을 발견하여 중심 높이를 2.65m/2.64m로 올리고 재검사했다. 검사 기준을 완화하지 않았다.
