# A맵 파밍 용기·칩 배치 조사 및 통합 제안

2026-10-21. 이 문서는 읽기 전용 조사와 배치 명세 제작 결과다. 실제 Unity 씬·프리팹·런타임 에셋을 수정하거나 Unity를 실행하지 않았다. 새 배치점의 물리·동선 검증 완료를 의미하지 않는다.

## 참조 범위와 공식 근거

사용자가 말한 ‘비콘 에어리어’라는 한국어 명칭은 델타포스 공식 한국어 업데이트의 모드별 항목에 등장한다. 별도 맵 이름으로 오해하지 않고 해당 익스트랙션 모드의 파밍 용기 구분을 참조한다.

- 공식 한국어 모드명 근거: [델타포스 2025-03-13 업데이트](https://www.playdeltaforce.com/ko/detail.html?content_id=3bca5758aa9e8a4a21ab9fea96ec26d315e4&father_content_id=a4df1595acb72a4705a8a87ab2cc66a7ac01).
- 실제 용기 종류 근거: [델타포스 공식 맵 도구](https://www.playdeltaforce.com/act/mapswiki/). 금고·소형 금고, 무기/탄약 상자, 의료함, 공구 수납장, 컴퓨터/본체, 여행 가방, 서랍, 사물함 등 서로 다른 수색 대상이 표시되어 있다.
- 모드 구조 근거: [Garena 공식 Operations 입문 가이드](https://deltaforce.garena.com/en/news/system/RMDWVM). 진입, 물자 확보, 생존, 철수로 물자를 보존하는 구조를 설명한다.

익스트랙션에 가져오는 범위는 용도에 맞는 용기 구분과 장소별 수색 동기다. 델타포스의 정확한 아이템 풀, 금고 개수, 좌표, 드롭 확률, 해킹 방식, 안전 보관함 사망 보존 규칙은 복제하거나 본 프로젝트 확정 규칙으로 간주하지 않는다. 아래 칩 구역·보스 배정은 본 프로젝트의 첫 조정값이다. 캐릭터의 공식 속성을 증명하는 근거로 쓰지 않는다.

## 실제 수정 전 구현 상태

조사 대상은 `C:/UnityProject/escape`의 현재 소스와 Resources 명세다. 작업공간 및 프로젝트/Assets/Escape의 AGENTS.md를 모두 읽었다.

- StageALootSpawner는 출격마다 42개 물리 수색 용기를 `A_Loot_Raid` 아래 생성한다. 기존 파밍 용기가 없어서 처음 만드는 상황이 아니다.
- 42개는 실제 건물 33곳에 흩어져 있으며, HALL·POWER·PARTS·CLINIC 각 3개, TOOLS 2개, 그 외 28곳에 1개씩 있다.
- 기존 위험 단계 0/1/2는 9/20/13개다. 외곽 POWER·E01·E03·PARTS·N11·N12·N14·E06에도 2단계 보상이 있어 ‘중앙만 위험, 외곽은 전부 쉬움’ 구조가 아니다.
- 기존 명세의 표시 스타일 7종은 ammo 1, electronics 11, industrial 8, medical 3, rations 8, toolbox 5, valuables 6이다. industrial은 toolbox 모형의 별칭이므로 실제 시각적 형태는 더 적다. 금고/서랍/컴퓨터/무기 케이스 고유 모양은 없다. valuables는 휴대용 잠금 케이스 모형이며 고정 금고가 아니다.
- 기존 ammo 풀은 총기와 탄약을 함께 확률 생성한다. 새 무기 케이스는 이 풀을 사용해 기존 총기 등급·개체 옵션·탄약 구조와 연결한다. 용기 모형과 내용물 풀은 별도다.
- 현재 일반 적은 기계 54·인간 14, 고정 홈 네임드 후보 5종이다. 출격당 네임드는 3~4종이다. 오래된 문서의 기계 37·인간 7을 현재 배치로 사용하지 않았다.
- 현재 CompanionChipCatalog에 등록된 정식 동료는 Serin과 Edel이며 Edel의 저장 키는 `prototype`이다. Liv/Uui와 탐사 화물용 완전 칩·조각은 게임플레이 담당의 확장 범위다. 기존 저장 키를 임의로 바꾸면 안 된다.

기존 42개 배치의 실제 바닥·동선 검증은 2026-10-19 `loot-production/StageALootChecks.txt`의 1,588개 검사 통과 기록에 있다. 현재 작업의 새 8개 위치까지 검증된 것으로 해석하지 않는다.

칩 담당과 합의한 초기 연결은 Edel=HALL/PARTS/N11/E06, Liv=POWER/N08/N12/N14/E01/E03, Uui=CLINIC/N03/N05다. 그 외 건물을 이 배치 문서가 임의로 특정 동료 구역에 편입하지 않는다. 중앙 게임플레이 정책이 실제 비매핑 구역의 희귀 칩 처리 여부와 확률을 명시해야 한다. Serin은 탐사 칩 풀에서 제외한다.

선택된 보스 원천은 N2→Edel, N3→Liv, N4→Uui다. 고정 홈은 각각 도면 약 (260,312), (455.20,107), (393,190)이며 실제 출격에 선택되어 등장한 해당 보스를 처치했을 때만 조각/완전 칩 드롭을 계산한다. N1/N5를 이 작업에서 추가 칩 보스로 확대하지 않는다. 고정 조각과 확률 완전 칩은 보스 출현 확률과 별도다.

B4/R8의 기존 실제 수평 거리는 62.17m이며 W5 접근을 공유한다. R8은 계속 비활성 위험 진입점이다. 기존 측정에서 B4의 가장 가까운 낮은 단계 용기는 실제 경로 33.91m, 1단계 이상 용기는 89.64m였다. R8 비교값 97.28m/51.04m는 비활성 지점을 가정한 기하 비교다. 새 금고는 HALL/POWER/PARTS/N11/CLINIC의 기존 바닥 안에만 후보를 두고 W5나 B 진입을 바꾸지 않는다. 무기 케이스는 물리 엄폐를 추가하지 않는다. 보상 배치만으로 B4/R8의 중복 경험이 해결되었다고 판정하지 않는다.

## 메인 통합 시 필수 확인

1. StageALootSpawner.ExpectedCount와 42를 고정한 편집기/생명주기 검사를 50에 맞춰 갱신한다. schema는 기존 1을 유지했다.
2. 새 8개를 현재 실제 건물의 바닥, 벽/가구 간섭, 문 간격, 상자 간격, 실제 상호작용 시야, 기본 진입에서 이어지는 완주 가능한 동선으로 검사한다. 같은 건물/같은 층을 벗어나는 보정은 허용하지 않는다.
3. 5개 금고와 새 모형의 실제 렌더 외피가 예약된 약 1.2×0.8×0.9m 범위 안인지 확인한다. 원거리만으로 크기·가독성을 통과 처리하지 않는다.
4. 금고군의 고가품 확률이 일반 파밍 용기보다 높고 100%가 아님을 별도 다중 시드 수치로 확인한다. 사용자 요구는 금고와 일반 용기의 상대적인 차이다. HALL 금고를 외곽의 다른 금고보다 더 높게 만드는 내부 서열은 사용자 요구가 아니며 이 제안의 통과 조건으로 삼지 않는다.
5. 각각의 캐릭터 구역에 해당하는 금고가 실제로 1개 이상 존재하고 Serin이 파밍에서 나오지 않는지, 선택되지 않은 보스가 조각을 선지급하지 않는지 확인한다.
6. 실제 출격의 전후 화면과 변경 기록은 메인이 확보한다. 이 단계의 명세/정적 조사 결과를 최종 Unity 검증이나 완료 보고로 대신하지 않는다.
