# Pilot11 / candidate23 독립 실제 화면 검토

## 판정

**PASS_FOR_BASE_ROLLOUT — 대표 8시점 미감 게이트 통과.** `rounds/pilot11/PILOT_REPORT.json`의 Game 8/8, 실제 플레이어 이동 PASS, 씬 clean 및 원본·임시 참조 복원을 확인했다. `rounds/pilot11/after_<id>.png` 여덟 장을 직접 열고 진짜 before 여덟 장(`before_<id>.png` 여섯 장과 `rounds/extra_before02/before_{hall,c01}_close.png` 두 장), Pilot09·10, 수용된 CLINIC22 Game과 비교했다. 이 판정은 **base224 실제 저장을 진행할 대표 미감 근거**이며 전체 226그룹 전수 Game 미감 확인 또는 최종 보존·기능 검증을 대신하지 않는다.

| 시점 | 관찰과 판정 |
| --- | --- |
| `building_hall` | 큰 산업 건물의 여러 위치에 분리된 녹색 성장 군집이 보이고, 군집 사이를 가는 굽은 팔이 잇는다. Pilot09의 거의 빈 지붕 및 Pilot10의 선형 점열보다 잎이 몇 거점에 모여 있다. 원래 A33 방사형·평행 카드 패턴은 되풀이되지 않는다. 전체 지붕을 카펫처럼 채우지 않은 빈 면은 의도된 밀도 대비로 수용 가능하다. |
| `hall_close` | 처마 가까운 연결 줄기에 잎 묶음이 겹쳐 보여 Pilot10의 한 줄 잎보다 입체적이다. 창과 외벽 형상은 유지된다. 이 한 시점에서 처마 전체 분포를 보장할 수는 없으나 식물이 없거나 부유한 상태는 아니다. |
| `building_c01` | 지붕 중앙의 교차 줄기에서 오른쪽으로 잎이 모이고 왼쪽은 성긴 팔과 작은 군집으로 남는다. 지붕 색·형태를 가리지 않으면서 덩굴의 방향성과 밀도 차이가 보인다. |
| `c01_close` | 우측 교차점의 잎이 높낮이와 방향을 달리한 겹층 mound로 읽힌다. 검은 잎 뒷면 카드 띠가 없고, 맨 곡선 팔이 녹색 중심부와 대비된다. 길고 어두운 나뭇가지가 여전히 눈에 띄지만 식물의 연결 구조로 읽히며 이 단계의 탈락 사유는 아니다. |
| `vehicle_truck`, `container` | 폐밴 정면과 지붕 일부, 실제 낡은 승용차의 앞 유리 주변에 소규모 성장이 보인다. 유리·차체·출입 공간을 가리지 않는다. `container`는 기존 정책 이름이며 화면 속 대상은 승용차다. 두 차량에 건물과 같은 잎 밀도를 요구하지 않는다. |
| `boundary_pier_sc`, `equipment_en1` | 담장 가장자리에 붙은 잎과 작은 설비 측면의 국소 성장을 확인한다. 경로·설비 본체의 인식은 유지되며 이 화면에서 큰 부유 덩굴이나 기능 침범은 보이지 않는다. |

수용 CLINIC22와 동일한 잎 위치·사진 밀도를 복제하지 않아도, **연결된 곡선 주가지, 국소 3D 잎 군집, 사이의 성긴 팔, 표면과 처마의 접점**이라는 성장 언어가 이번 대표 화면에서 읽힌다. 따라서 추가 미감 반복 없이 base224 적용과 이후 전수 진단·대표/추가 Game 검증으로 진행해도 된다.

잔여 한계: HALL 원경의 군집은 지붕 규모에 비해 작고, C01의 어두운 맨줄기는 가까이서 보인다. 추가 57 Game 및 243 진단에서 **다른 건물·차량·담장·설비에 검은 뒷면, 부유, 출입·통행 가림, 원 개념 손상**이 발견되면 해당 대상에 좁혀 재검토해야 한다. 이번 PASS로 전수 미감 합격을 미리 선언하지 않는다. Pilot01·02·03·05·07·09·10의 실패/보류 기록은 보존한다.
