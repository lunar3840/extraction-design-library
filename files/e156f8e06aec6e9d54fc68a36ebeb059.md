## 사용자 지시

공용 연구와 개별 캐릭터 성장 구조에 맞는 파밍 아이템의 종류와 필요량을 분석하고, 잡동사니·아이콘·실제 Unity 배치까지 자율적으로 완성한다. 사용자가 자리를 비운 동안에도 계속 작업하며 GPT-6.1 Sol ultra 하위 에이전트를 사용한다.

메인은 구성·통합·실행 검증을 맡고, 같은 모델/추론 수준의 에이전트 3명이 경제와 연구, 맵과 드롭, 아이템 외형을 분담했다. 각 담당자의 제작 보고와 실제 Unity 검증 결과를 구별한다.

## 변경 전 상태와 기획 의도

기존 카탈로그에는 아이템 165종과 잡동사니 74종이 정의되어 있었지만, A맵의 시설별 유한 파밍 배치·용도·아이템 외형이 일관된 순환으로 연결되어 있지 않았다. 일반 적의 총기 중심 드롭과 진입 시 고정 보급 상자는 기계 부품을 찾아 연구한다는 목표를 충분히 지원하지 못했다.

초기 활성 파밍 목록을 잡동사니/연구 자재 32종, 식량·의료·수리 보급품 12종, 탄약 4종으로 제한했다. 자재 20종은 성장에 쓰고 판매용 품목 12종은 수익과 발견의 다양성을 담당한다. 총기와 별도 장비 드롭은 이 48종 집계에 포함하지 않는다. 기존 저장 ID와 인벤토리 점유 크기를 보존하고, 기존 스택 한도를 낮추지 않았다.

- 공용 연구 10개 항목, 총 46단계의 비용은 자재 132개와 블랭크 198,000을 유지한다. 동료 훈련 3단계는 동료당 자재 12개와 블랭크 18,000이다. 단계가 높아질수록 여러 재료를 요구한다. 보관함 우선, 보호 물품 제외, 전체 재료와 비용의 원자적 소비를 적용했다.
- 아이템 상세에 용도, 주요 획득처, 추적 중인 연구의 소지/필요 수량을 표시한다. 상점에 기본 의료품 3종의 보충 경로를 연결했다.
- A맵 33개 시설에 출격당 42개 유한 수색 상자를 생성한다. 의료·전력·전자·공구·산업·식량·탄약·생활·사무·귀중품·일반의 11개 표를 쓴다. 일반 상자는 2~3묶음, 고위험 상자는 3~4묶음이다.
- 출격별 추첨 결과를 유지하며 상자 닫기·재활성화·중복 생성 호출로 재고가 회복되지 않게 한다. 기존 진입점 고정 무료 보급 상자는 A맵에서 제거했다.
- 기계는 역할에 맞는 부품, 인간은 실제 휴대 무기와 해당 탄약 및 보급품을 남긴다. 네임드 기계는 제어 코어를 보장한다. 전역 사망 통지를 현재 월드/플레이어 소유로 제한하고 중복 처리를 차단했다.
- 상자 배치는 실제 바닥, 전체 몸체, 출입문, 기본 진입점에서 연결된 내비게이션 경로, 접근 시야로 검증한다. 적의 전리품은 벽·바닥·경사면을 검사하고 필요할 때 작은 잔해 형태를 사용한다.
- 잡동사니 32종·식량 5종·탄약 4종의 개별 모델과 같은 모델에서 렌더링한 투명 아이콘 41개를 제작해 실제 프로젝트에 설치했다. 기존 의료/수리품 7종의 전용 아이콘은 유지한다. 상자 외형은 7종이다.
- 후속 요청에 따라 로봇 팔·발전기 부품·폐탄피 주머니·향수 4종은 Tripo에서 실제 생성하고 Blender에서 최적화한 모델로 교체했다. 금괴/장갑 조각의 공유 메시 오류도 수정했다. 원본, 프롬프트, 최적화 전후, Unity 재질/실제 화면은 `tripo_refinement/CHANGE_RECORD.md`에 기록한다. 잡템 전용 재생성 명령을 추가해 별도 총기 작업의 탄약 외형을 보존한다.
- 바닥 버리기는 실제 모델 크기로 빈 공간·이동 경로·큰 물건의 네 모서리 바닥을 검사한 다음 소유권을 이전한다.

품목별 역할이 겹치는 이름만 늘리기보다 처음부터 획득처와 용도가 드러나는 32종으로 시작한다. 캐릭터마다 별도의 수십 가지 재료 ID를 만들지 않고 기본 자재·정밀 부품·기계 부품을 조합한다.

### 후속: 총기 확장 후 공용 회귀 검사 충돌 해결

같은 날 총기 담당이 기존 검사 계약 갱신을 완료했고, 메인이 실제 `../weapon-ammo-tiers/legacy_checks_final_summary.txt`와 해당 `CHANGE_RECORD.md`의 후속 절을 읽어 확인했다. Basecamp/Weapon/Arsenal/LootEconomy/Inventory/Enemy/LootEquipment/InventoryRegionSwap/GrowthRework/Session/Equipment의 **11개 규칙 그룹, 2,241개 PASS**다. Equipment의 오래된 공급품 무게 fixture는 카탈로그 기반 무게 보존 검사로 수정한 뒤 별도 실행하여 통과했다. 32총기의 모델·앵커·아이콘 카탈로그 검사도 통과했다.

기존 32재료/12소모품과 새 24탄약/32총기 도달성, 퀘스트 제외, 거래·연구·그리드 검증을 유지한 갱신이다. 이 후속은 Editor 검사 10파일만 배포했으며 Runtime/가격/무게/밸런스를 변경하지 않았다. 검사 입력은 `../weapon-ammo-tiers/regression_source_manifest.json`, 세부 결과는 같은 폴더의 `legacy_results/`와 `equipment_recheck.txt`다. 앞선 파밍 전용 실행 결과와 이 최신 통합 규칙 검사 결과는 각각의 입력 버전으로 구별한다. 전체 Serin 씬 애니메이션 검사는 이 후속 범위에 포함되지 않는다.

후속 확인 시 메인이 해당 회귀 입력 매니페스트의 Runtime/Resources **191개 파일**을 실제 프로젝트와 직접 해시 대조했고 불일치 **0개**였다. 지정한 공용 5개 파일도 이 대조에 포함된다.
