# A맵 V31 Unity 반영 — 독립 인수 검토

## 판정

**요청된 V31 물리 동선 반영과 확인 범위는 통과.** 4개 독립 지형 덩어리 A–D가 실제 메시와 충돌체로 배치됐고, A의 5m 안부 S는 빈 통로로 남았다. 북·남/동·서 양 끝 우회와 기존 두 교량을 포함한 PlayerMotor 실제 이동 11구간이 모두 완료됐다. 이것은 맵의 모든 지점·모든 카메라 각도·AI 전투 경험에 대한 보증은 아니다.

## 독립 확인 근거

- `V31_PLAY_VALIDATION.txt`에서 A 북끝·남끝·S, B 북·남, C 북·남, D 서·동 접근, 서교·동교의 **11/11 실제 PlayerMotor 이동**을 확인했다. S 중간 실제 좌표는 (218.17, 92.83), 화면 내 플레이어 중심은 (0.500, 0.705)였으며 카메라에서 머리·가슴·발로 향하는 세 광선 모두 신규 지형에 막히지 않았다. `after_play_S_saddle_mid.png`에서도 플레이어 전신과 양쪽 암반 사이 열린 바닥이 보인다.

## 해석과 남은 한계

- 첫 플레이 도구 실행의 null 예외는 Play 진입 시 정적 보고서가 도메인 재로드로 사라진 **검증 도구 결함**이었다. 이를 복구한 뒤 이동은 11/11 통과했다. 첫 S 중간 사진의 플레이어가 화면 밖으로 밀린 현상도 프레임당 8회 가속 이동을 카메라의 실제 프레임시간 추종이 따라가지 못한 **검증 속도 차이**였다. 테스트에서 플레이어를 2초 정지시키고 카메라 중심을 확인한 재촬영은 플레이어를 정상 표시했다. 실제 게임의 모든 속도·시점에서 가려짐이 없다는 일반화는 하지 않는다.
- A의 렌더 전용 기존 `Combined_LowGrass` 중심 (211.11, 53.28)이 새 암반 표면 아래에 들어갈 수 있다는 시각 후보 1건이 남는다. 물리 충돌은 아니며, 정확한 삼각형 교차나 플레이 시 가시성은 별도 미확인이다. 아트 외형은 기능 배치 단계로서 최종 완성 품질로 판정하지 않는다.
- 적 `EnemyController`의 신규 우회 실제 플레이는 수행하지 않았다. B4와 비활성 위험 진입점 R8의 약 62m 간격 및 W5 합류로 인한 경험 차별화 문제도 이번 V31 배치만으로 해결됐다고 보지 않는다. R1–R8은 계속 기본 무작위 진입 후보에서 제외된다.
