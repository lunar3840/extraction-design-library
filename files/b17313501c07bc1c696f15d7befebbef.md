## HALL target migration safeguard

Use `StageARuinRolloutBuilder.ExteriorCandidateV2Fix.cs` instead of the earlier V2 builder; its `V2-to-V2Fix.diff` contains the delta. When a selected policy changes `ivyTargetPath` from the representative renderer to a parent (HALL facade), it validates the newly generated positive-leaf parent marker and unchanged source mesh/material first. Only then does it remove the old renderer-local `__A33_Ivy`. It leaves any damage/backing siblings under the renderer's OwnedRoot. A failed attempt removes the new parent marker and retains the old renderer-local one. It counts every actual A33 marker on the map; a count other than 226 aborts before committing the result JSON. The separate V2 generator and runtime setting files are unchanged.
