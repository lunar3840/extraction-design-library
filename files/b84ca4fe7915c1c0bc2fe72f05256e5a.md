# Tripo 모델 후처리 결과

2026-10-19. 원본 GLB 4개를 Blender 5.2.2 LTS의 독립 factory-empty background 프로세스에서 처리했다. 이 작업은 Unity 프로젝트와 기존 Blender 장면을 열거나 수정하지 않았다.

| 아이템 | 원본 삼각형 | FBX 삼각형 | 감축 후 Blender 정점 |
| --- | ---: | ---: | ---: |
| trade_a_006 로봇팔 | 7,685 | 7,685 | 6,359 |
| trade_b_023 발전기 | 7,480 | 5,000 | 5,100 |
| trade_c_018 폐탄피 주머니 | 7,810 | 4,999 | 4,122 |
| trade_b_009 향수 | 7,376 | 5,000 | 3,654 |

로봇팔은 8,000 상한 이하여서 감축하지 않았다. 나머지는 UV를 유지하는 collapse decimation으로 5,000 상한에 맞췄다. 원본 GLB와 embedded JPEG 12개는 각 아이템의 `original/` 아래 바이트 그대로 보관했다. 실제 원본은 모두 1024×1024 JPEG이며 2K 원본으로 표기하지 않았다.

각 아이템의 출력은 `<id>.fbx`, `textures/<id>_mat00_basecolor_1024.png`, `_normal_1024.png`, `_metallicroughness_1024.png`이다. PNG는 Pillow로 원본 JPEG를 디코딩해 저장했으며 12장 모두 원본 디코딩 픽셀과 완전히 일치함을 확인했다. Basecolor는 sRGB, normal과 metallicroughness는 선형 데이터다. MR은 G=roughness/B=metallic이며 R은 사용하지 않는다. Normal의 녹색 채널을 뒤집지 않았다. 재질 계수를 텍스처에 굽지 않았다.

모델마다 단일 재질이다. 모든 재질은 baseColorFactor=[1,1,1,1], metallicFactor=1, roughnessFactor=1, normalScale=1, OPAQUE, doubleSided=false다. 상세한 소스 채널·재질 원문·파일 해시·처리 전후 UV/행렬/AABB는 아이템별 `manifest.json`에 기록했다.

축은 glTF +Y up → Blender +Z up → FBX +Y up/-Z forward다. 수동 앞 방향 보정, 바닥 이동, 물리 크기 조정은 하지 않았다. glTF 부모 변환은 월드 정점 위치를 유지하며 메시로 적용했다. FBX에는 메시만 포함되며 카메라·조명·애니메이션이 없다. Unity의 최종 크기, 바닥, 배치 방향과 게임 화면은 별도 통합 검증 대상이다. 발전기는 감축 후 바닥 최솟값이 Blender Z=-.001283이므로 배치할 때 실제 메시 바닥을 기준으로 맞춘다.

동일한 카메라·조명·해상도·색 변환으로 원본 형상과 감축 형상을 각각 4방향 렌더했다. `renders/before_*.png`와 `renders/after_*.png`가 대응하며 `matched_review.png`가 8장 비교다. 여기의 before는 다운로드한 Tripo GLB의 감축 전 상태이고 기존 Unity 모델의 변경 전 화면이 아니다. 정면/오른쪽/후면/사선이라는 이름은 고정 Blender 축 기준이며 아티스트가 지정한 앞 방향을 주장하지 않는다.

네 비교 시트를 직접 열어 관절·집게·배선, 발전기 방열구·받침, 주머니 끈·탄피 입구, 향수병 캡·라벨이 유지되는지 확인했다. 동일 카메라의 알파 마스크 IoU 최저값은 팔100%, 발전기99.15%, 주머니99.60%, 향수99.90%다. 발전기 AABB 최대 변화는 .01339(원본 폭 약1 대비1.34%)이며 다른 세 모델은 .000107 이하다. 이 수치는 실루엣 비교이며 화면 품질 전체를 보장하는 척도는 아니다.

내보낸 FBX 4개를 다시 별도의 빈 Blender 장면에 읽어 실제 파일의 삼각형 수, 메시만 포함, UV, 재질 슬롯, 유한 좌표 및 월드 범위를 확인했다. 모두 PASS이며 최대 왕복 범위 오차는 1.64e-7이다. 결과는 `fbx_roundtrip_summary.json`과 아이템별 `fbx_roundtrip_checks.json`에 있다. Unity에서 imported normals와 명시적인 URP 재질 연결을 우선 보존한다.

처리 스크립트는 상위 폴더의 `preprocess_tripo.py`, `preprocess_tripo_blender.py`, `preprocess_review.py`, `preprocess_verify_fbx.py`다. `processing_summary.json`, `review_summary.json`에 전체 결과가 있다.
