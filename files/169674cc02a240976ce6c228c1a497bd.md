# 세린·에델 S4 적용 및 검수 결과

세린의 가슴 양옆이 과하게 벌어진 후보는 제외했다. 원래 체형을 유지하면서 가슴 아래·겨드랑이·복부 천을 연결하고 소매·허리·쇼츠·바지·부츠를 현재 몸과 관절에 맞춰 보완했다. 세린 기본 외형의 상체 음영도 정리했다.

에델에서도 팔과 허리를 잘못 연결한71면을 제거했다. 원본에서 몸 표면에만 천 재질로 표시했던2,349면은 실제 의상 패널로 분리했다. 두 모델 모두 파일 가져오기 이후의 실제 재질 이름으로 연결을 대조했다. 같은 재질 슬롯 개수만으로 순서를 추정하던 오류를 제거했다.

기존 S4 테스트 아이템은 세린과 에델의 각 전용 외형을 선택한다. 인벤토리의 기존 외형 버튼을 끄면 원래 이너웨어를 복원하며 장비·성능·소지품을 바꾸지 않는다. 모델이 없는 다른 방어구는 S4 외형을 대신 표시하지 않는다. 저장 ID·테스트 지급 규칙과 HIGH READY 폐기 상태는 유지했다.

- 실제 Play: 두 캐릭터 각각26상태·3시점, 총156화면. 걷기·달리기·조준·사격·재장전·근접공격·구르기·피격·사망·자동 대기 몸짓3종과 무작위 표정/몸짓2종씩 확인.
- 실제 인벤토리: 기존 버튼 켬/끔/복원과 직접 좌우 회전, 총8화면. 크기와 발 기준이 유지되고 장비 데이터가 같음을 확인.
- 추가 클립 검수: 세린 idle/aim/walk/run/attack 각각3시점·3방향,45화면.
- 원래 StageA Edit 상태 복귀, 검수 도구30파일 보관·제거 후 새 컴파일/실행 오류0. 기존 UI·헤어·성능·맵과 원본 모델 보호13항목은 모두 기준 해시 일치.

검수한 포즈와 화면에서 이전의 큰 관통·연결면 늘어남을 정리했다. 모든 시간·장비 조합의 무관통이나 실행 파일 빌드 성능을 보증하는 결과는 아니다. 실제 실행·정리 근거는 FINAL_VALIDATION.json과 CLEANUP_VALIDATION.json, 전체 경과·전후 대응은 CHANGE_RECORD.md에 보관했다. 기존 실패02는 별도 이력으로 유지한다.

독립 시험 장면과 시험 인벤토리를 사용했으며 실제 저장 프로필은 바꾸지 않았다. 정식 영상 검증은 이전 보류 요청을 유지한다. 공개 반영은 개별 게시 영수증으로 별도 확인한다.
