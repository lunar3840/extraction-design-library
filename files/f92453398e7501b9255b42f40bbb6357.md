# ChatGPT Pro 검토용 현재 배치 인계 자료

## 지시 및 의도

사용자는 실제 장애물 배치 전에 숲·폐차로 자연스럽게 동선을 유도하는 방안을 분석하고 도면으로 검토하려 했다. 이어 현재 배치 자료만 ChatGPT Pro로 옮겨 설계할 수 있는지 물었고, 전달용 자료 제작을 승인했다.

이번 결과물은 **현재 배치 현황 인계 패키지**이며 신규 장애물 제안, Unity 적용 또는 ChatGPT 전송 완료 결과가 아니다.

## 변경 전 상태 / 문제

현재 맵은 여러 버전의 건물·환경·사용자 에셋과 수정을 포함한다. 과거 v0.8 도면만 전달하면 최근 배치, 변경된 실제 위치, 비활성 옛 충돌 형태를 잘못 해석할 수 있다.

## 작업 내용과 방식

- Unity 실행·조작·저장 없이 씬 참조 프리팹과 저장된 Transform 계층을 읽었다.
- 누적 4×4 TRS 변환으로 위치를 추출하고 원시 충돌 도형의 평면 외접 범위를 계산했다. 수면의 저장 메시 정점 13개를 해석했다.
- 환경/지구 semantic 객체 332개, 별도 신규 사용자 에셋 53개, 기존 슬롯 교체 21개, 진입·탈출 앵커 19개를 구분했다. 교체 21개를 신규 물체로 중복 계산하지 않았다.
- 실제 배치 현황 전체도와 4개 구역 확대도, JSON/CSV 좌표, 출처·한계 감사, 보존 조건, Pro 요청문을 작성했다.
- 과거 경로 생성 정의 67개는 참고 중심선으로만 제공한다. 현재 도로 표면이나 실행 중 NavMesh 검사로 표현하지 않는다.
- 제작과 독립 검토를 GPT-6 Sol high 에이전트에 분담하고 메인이 데이터 해석·도면 가독성을 검토했다.

## 증빙 및 전후 화면의 범위

실제 맵을 변경하지 않았으므로 게임 내 수정 전/후 비교 대상은 없다. 분석·도면만 요청한 범위를 지키기 위해 Unity를 열거나 새 게임 스크린샷을 찍지 않았다. 생성된 `CURRENT_OVERVIEW.png`, `CURRENT_DETAILS.png`는 저장 데이터 투영도이지 게임 스크린샷이 아니다. 이를 변경 후 게임 화면 또는 재구성 전 화면으로 위장하지 않는다.

도면은 메인이 이미지로 열어 확인했다. 초기본의 누락된 주요 구조, 확대창 밖 표시, 낮은 라벨 대비를 지적해 수정하도록 했다. 최종 독립 검토는 전달 폴더의 `INDEPENDENT_REVIEW.md`를 따른다.

## 출력 위치 및 주요 파일

`outputs/map_design/2026-09-28/a-map-current-handoff/`

- CURRENT_OVERVIEW.png / .svg
- CURRENT_DETAILS.png / .svg
- CURRENT_FACTS.json / CURRENT_OBJECTS.csv
- CURRENT_AUDIT.md / INDEPENDENT_REVIEW.md
- START_HERE.md / CONSTRAINTS.md / PROMPT_FOR_PRO.md
- extract_current.py / render_current.py: 읽기 전용 추출 및 도면 생성 절차. Unity Assets 폴더에 쓰지 않는다.

Unity 프로젝트의 파일 수정은 없다. 출처 파일 해시는 CURRENT_FACTS.json에 기록했다. 생성 스크립트와 임시 캐시는 Pro 첨부용 ZIP에서 제외한다.

메인이 작업 전후 씬·프리팹·StageMapRouter.cs의 SHA-256을 다시 대조해 세 파일 모두 동일함을 확인했다. 도면 생성 결과는 PNG 로드와 SVG XML 구조 검사, 직접 시각 검토를 거쳤다.

## 한계

열려 있는 Unity 편집기의 미저장 변경, 런타임 생성물, 상세 실내 도면, 정확한 메시 충돌 외곽과 새 보행 가능성 검증은 포함하지 않는다. MeshCollider만 가진 신규 에셋 18개는 중심 위치만 제공한다. 건물·교량 AABB는 열린 공간과 출입구까지 모두 막혀 있다는 뜻이 아니다.

ChatGPT Pro용 새 대화를 생성하거나 자동 업로드하지 않았다. 사용자는 ZIP을 풀어 자료를 첨부하고 요청문을 사용하면 된다.
