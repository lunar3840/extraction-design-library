# A맵 건물 가림·재질 개선 V33

## 사용자 지시와 기획 의도

- 건물 뒤 캐릭터를 청록색 실루엣으로 표시하지 말고, 가리는 건물 부분을 반투명하게 하여 실제 캐릭터와 근방을 보이게 한다.
- 유사 구현을 검색하고, 중정비동에서 적용한 재질 개선 원칙을 다른 건물에도 확장한다.
- 기존 배치·동선·충돌·창문·출입구·캐릭터 외형은 보존한다. 중정비동 및 의료동의 기존 개선을 덮어쓰지 않는다.

## 참고 사례와 설계 선택

- [Shader Crew의 See-through Shader](https://www.shadercrew.com/): 카메라와 플레이어 사이 장애물에 국소적인 영역을 열고 범위·가장자리를 조절하는 사례. 제품을 구매하거나 외부 코드를 복사하지 않고 현재 URP 구조에 맞게 별도 구현했다.
- [Unity 포럼의 URP 장애물 페이드 튜토리얼 — 제작자 게시물](https://discussions.unity.com/t/tutorial-opaque-objects-making-it-hard-to-see-fade-them-out-with-the-standard-urp-shaders/888353): 가리는 물체의 표면을 전환하는 접근을 비교했다.
- [Unity 6.1 URP Lit 공식 문서](https://docs.unity3d.com/6000.1/Documentation/Manual/urp/lit-shader.html): 불투명/투명 표면의 렌더링 순서와 블렌딩을 참고했다.
- 건물 전체를 숨기지 않고 캐릭터 중심의 부드러운 타원 범위만 반투명하게 처리한다. 카메라보다 먼 벽까지 열리지 않도록 깊이를 제한한다. 실제 지붕 그림자와 광원은 유지하여 이동 중 조명 급변을 새로 만들지 않는다.

## 변경 전 증빙·백업

- 현재 저장된 A맵으로 신규 촬영: 내부 68동 + 접근 9시점 = 77장. 실제 Play 카메라·캐릭터 위치 14시점 추가.
- `before_PLAY_POSES.json`에 실제 캐릭터 좌표·카메라 위치·회전·화각 저장. W03/W04/E08/PARTS 외부 및 TOOLS 내부에서 기존 실루엣 확인.
- `backup/A_saved.unity`, `backup/A.prefab`, `backup/materials/`에 원본 보존.
- `before_GEOMETRY.txt`, `before_APPEARANCE.txt`, `before_LIGHTING.txt`, `before_MATERIAL_ASSETS.txt` 및 `BASELINE.txt`에 원본 상태·해시 기록.
- 작업 전 화면은 실제 전 상태이며 재구성 이미지가 아니다. Unity 렌더 요청으로 동일 해상도 1600×1000, HUD 없이 비교한다.

## 실제 변경

### 국소 반투명 가림 처리

- `StageABuildingV33Reveal`이 플레이 중 건물 가림을 검사하고, 가리는 건물 메시의 런타임 복제 재질로 국소 투명 영역을 만든다.
- 불투명 표면에서 해당 영역의 깊이 기록을 비우고 동일 메시의 투명 표면을 나중에 그려 실제 캐릭터·지면이 보이게 한다. 중심 표면 불투명도 16%, 전환 0.18초, 가장자리는 완만하게 연결한다.
- 원본 건물 재질·메시·충돌은 변경하지 않는다. 투명/알파 컷아웃 슬롯과 그림자 전용 메시를 보호한다. 해제·맵 퇴장 시 원래 재질 참조를 복구한다.
- 기존 청록색 실루엣 구성요소 2개를 비활성화한다. 캐릭터 메시·머리색은 수정하지 않는다.

### 다른 건물의 재질 개선

- 중정비동 HALL, 의료동 CLINIC을 제외한 67동(보조동 64 + POWER/PARTS/TOOLS)에 적용.
- 기초 바닥 64개, 기존 공장 바닥 45개, 코어 바닥 2개·벽 10개, 건축 표면 슬롯 670개, 공장 외벽 슬롯 808개에 전용 복제 재질 적용.
- 기존 공장 바닥의 얼룩·줄눈·UV·색을 유지하고 법선 강도와 거칠기를 절제한다. 무늬 없는 코어 벽·바닥을 보완한다.
- D04 지붕·파사드의 원래 형태와 유리 슬롯 보존. 탄젠트가 없는 생성 메시에 법선맵을 억지로 적용하지 않는다.
- 조명 추가·노출 변경은 하지 않는다. 실내 개별 광원은 실제 등기구 및 차광 구조 검토가 필요하므로 전 건물에 일괄 복제하지 않았다.
- 외관 변화는 섬세한 재질 개선이며 대규모 리모델링이나 새로운 배치가 아니다.

## 검증 및 반복 수정

- 작업 전 Play: 14시점 및 B맵 복귀 환경 복원 PASS.
- 정적 보존 검사: 원래 모든 Transform/활성 상태/메시/충돌 동일, 원본 재질 파일 바이트 불변, 광원 불변 PASS (`PRESERVATION_VALIDATION.txt`).
- 최초 적용은 보조동 D04 파사드가 Visual의 자식이 아니라 형제인 구조를 사전 검사에서 감지해 중단했다. 재질 변경 전 정확한 경로로 수정 후 적용했다.
- 독립 검토에서 투명 슬롯 원본 재질에 런타임 속성을 쓰는 위험을 발견해 제외 처리했다. 빌드에서 런타임 키워드 변형이 누락되지 않도록 셰이더 포함 참조와 변형을 유지한다.
- 최초 적용 후 Play의 공구동 내부 검사가 실패했다. 전후 화면을 메인과 제작자가 직접 대조한 결과, 실제 캐릭터는 이미 보이는데 구형 충돌 대리체가 실루엣을 잘못 켜던 **기존 판정의 오탐**이었다. 이 검사는 실제로 활성 건물 메시 삼각형이 시야를 가리는지를 확인하도록 보완했다. 동시에 보존 건물의 충돌 대리체와 실제 벽의 연결, D04 지붕·파사드 중복 가림을 보강했다. 최초 결과 14장과 실패 보고서는 `iterations/01-tools-wall-gap/`에 보존한다(폴더명은 최초 의심 원인). 전 상태 증빙을 덮어쓰지 않았다.
- 두 번째 확대 검사 결과는 `iterations/02-expanded-sweep-pass/`에 보존했다. 중정비동 2층의 기존 V24 검증 좌표까지 추가하여 최종 검사를 다시 수행했다.
