# 니어풍 룩 05 — 풀 솎기 채택, 건물 낡음을 전 건물로 (2026-11-25)

## 사용자 지시 요약

- 2026-11-25 17:33 KST "1,2번 모두 시행 바람" — 앞 보고의 두 질문(① 풀 솎기 후보를 쓸지 ② 건물 낡음을 전 건물로 넓힐지)에 대한 답.
- 풀 솎기를 어느 쪽으로 할지는 지정이 없어, 앞서 정해진 방향("콘크리트·모래 바탕에 풀이 드문드문")에 가까운 55% + 모래색 땅을 기준으로 잡았다. 45% 쪽 설정도 남아 있다(`nier_04/settings/…_nier04_thin.json`).
- 지시 1회, 구현 1회차(촬영 1번).

## 실제로 바꾼 부분과 방법

1. 풀 솎기를 제대로
   - 04에서는 색을 그리는 단계에서만 풀을 잘라서, 맨땅에 풀잎 모양 외곽선과 옅은 그림자가 남았다(`sheets/n05_remnant_crop.jpg` 오른쪽).
   - 잘라 내는 계산을 공용 조각 래퍼(`EscapeOccluderCutPasses.hlsl`)로 옮겨 색·깊이·노멀 패스가 같은 픽셀을 자른다. 풀 깊이 패스 둘(`D14MutedFoliage`, `EscapeOccluderCutLit`)에 룩 키워드를 추가. 키워드가 꺼져 있으면 매크로가 비어 수정 전과 같은 코드다.
   - 새 파일 `Art/Look/EscapeStylizedGrassThin.hlsl`(솎기 값과 무늬).
2. 맨땅 그림자: 땅 메시의 그림자 속 밝기 바닥 값(`groundShadeFloor`) 추가. 0.18.
3. 니어풍 05 값(`settings/StylizedLook_override_nier05.json`) = 04 + 풀 솎기 0.55 + 모래색 땅(색조 0.9, 밝기 1.4) + 그림자 바닥 0.18. 꺼 둔 사본 `C:\UnityProject\escape\Library\StylizedLook.nier05.json.off`.
4. 건물 낡음을 전 건물로(`StageALookBuildingAging.Level = 3`, 촬영 옵션 `agingall`)
   - 대상: 맵의 `StageAEnclosuresV33Building` 가운데 기존 외벽(`<ID>_Shell_renderOpaque`)이 켜져 있는 60동. 시범 블록 3동(S01·S02·S06)은 새 외벽 쪽 규칙(2단계)을 그대로 받고, W10은 기존 외벽이 없어 빠졌다.
   - 풍화: 외벽·지붕 재질 772칸을 실행 중 사본으로 바꿔 세기를 올림(풍화 +0.22, 빗물 자국 +0.20, 때 +0.15, 이끼 +0.10). 렌더러의 높이·시드 값은 기존 것을 그대로 둔다.
   - 얼룩: 외벽 메시를 0.2m 격자로 읽어 벽·창 위치를 구한 뒤 5,545장을 놓음 — 벽 머리에서 흘러내린 물때, 벽 밑에서 올라온 때, 창 아래 녹물, 일부 창 위 그을음. 창과 문 자리는 피한다. 그을음은 물때 재질의 어두운 실행 중 사본이다(새 에셋 없음).
   - 담쟁이는 기존 건물에 이미 있어 더하지 않았다.

- 전 건물 낡음: 기존 건물 벽에 세로 물때와 벽 밑 때가 게임 카메라 거리에서 보인다(`bld_S05_close`, `bld_tree3_close`, `tree_1`의 노란 집).

## 한계 / 확인하지 못한 것

- 풀 솎기 무늬는 위치로만 정해진다. 길가·건물 벽 밑 같은 맥락은 모른다. 풀 덤불(둥근 덤불 메시)과 나무는 그대로다.
- 풀 솎기는 화면에서만 풀을 없앤다. 풀 메시와 배치는 그대로라 성능 이득은 없다.
- 얼룩 5,545장은 한 건물에 평균 90장쯤이다. 벽 한 면이 꽤 얼룩져 보이는 곳이 있다(`tree_1`의 노란 집 윗부분). 양과 진하기는 값 하나씩으로 줄일 수 있다.
- 얼룩 위치는 격자로 확인했지만 60동을 한 동씩 눈으로 보지는 않았다. 찍은 건 3동이다. 창살·차양 같은 돌출물 위에 뜬 얼룩이 있을 수 있다.
- 플레이어가 건물 안에 들어가 지붕·벽이 걷히는 동안 얼룩이 어떻게 보이는지 확인하지 않았다. 걷힘 처리 중이던 건물은 이번 실행에 없었다(0건).
- 기존 외벽이 아닌 다섯 동(CLINIC, POWER, PARTS, TOOLS, HALL)과 W10은 대상이 아니다.
- 전 건물 낡음도 Play 중에만 얹힌다. 씬·프리팹·재질 에셋은 그대로다. 실제 적용은 저장되는 변경이라 따로 승인이 필요하다.
- 맵 쪽 작업장 거리 후보 위 촬영, 직접 플레이, 빌드, 성능은 하지 않았다.
