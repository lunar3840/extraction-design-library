# A맵 Time Ghost 환경 에셋 v1.0 — 독립 검증 기록

## 현재 판정

**PASS — 정적 검증, Play 회귀 및 최종 시각 증빙을 모두 직접 확인했다.** `V10_VALIDATION.json`은 3,577개 assertion, 실패 0개, Unity Error/Exception/Assert 0개로 PASS했고, `V10_PLAY_VALIDATION.json`도 PASS했다. 제작 완료 신고만으로 통과 처리하지 않고 두 JSON의 최종 출력과 전후·보충 화면을 대조했다.

- 정적·참조·렌더 검증: `Escape.EditorTools.StageV10Checks.RunBatch`
- 실제 Play 회귀: `Escape.EditorTools.StageV10PlayChecks.RunBatch`

Unity 실행은 메인 통합 담당이 수행했고, 이 문서에서는 그 생성물을 독립적으로 판독했다.

## 검증 기준

이번 작업은 v0.9의 지형, 충돌, 이동 경로 및 의미 기준점을 유지한 채 환경 외형만 교체하는 작업이다. 변경 전 기준 프리팹은 `Assets/Escape/Editor/V10CollisionBaseline.prefab`, 최종 대상은 `Assets/Escape/Resources/StageMaps/StageA_Relay_Blockout_v08.prefab`이다.

정적 검증기는 다음 항목을 독립적으로 확인한다.

- 활성 Collider의 상대 경로, 레이어, trigger 상태, world pose와 Box/Sphere/Capsule/Mesh/Terrain 형상을 기준 프리팹과 전수 fingerprint 비교
- `StageA_Landform_v09` 계층, transform, mesh 및 MeshCollider 참조 fingerprint 비교
- 모든 semantic anchor의 ID, kind, 계층 경로 및 pose fingerprint 비교
- 진입 12곳, 탈출 7곳, 중계 3곳, 주요 건물 5곳, 보조 건물 10곳 및 전체 환경 slot 수 보존
- 최종 프리팹이 새로 참조한 에셋과 visual override prefab이 모두 `Assets/Escape/Art/TimeGhostV10/` 아래에 있는지 확인
- 모든 활성 Renderer의 mesh/material 참조, 모든 활성 Material의 shader 지원 여부, URP subshader, HDRP 참조 부재 및 깨진 serialized texture 참조 확인
- 실제 사용 중인 Time Ghost 재질의 texture가 소유 폴더 아래에 있는지, importer max size가 2048 이하인지, `_BumpMap`/`_NormalMap`/`_GroundNormal`/`_RubbleNormal`과 albedo/base-color slot의 NormalMap·sRGB 역할이 맞는지 확인. 별도 normal+depth impostor atlas는 일반 NormalMap slot으로 오판하지 않음
- 절차적으로 생성된 `V10Dress_RouteBlendMask_1024.asset`만 Native Texture2D 예외로 한정하고, 실제 크기 2048 이하와 R8 형식을 확인. 나머지 `.tif`/`.png`는 TextureImporter가 없으면 실패
- 16개 LandSurface Renderer의 두 material slot이 동일 `V10Dress_GroundBlend`를 참조하는지, `Escape/V10GroundBlend` shader·route mask·65×50/130×100 tiling 계약이 맞는지 확인
- 모든 활성 LODGroup의 유효 bounds, 내림차순 threshold, renderer 참조 및 한 renderer의 중복 LOD 등록 방지
- 환경 visual hierarchy의 동일 mesh·동일 pose·동일 scale 인스턴스가 기준보다 증가하지 않았는지 확인
- 종류별 slot/override/unique prefab/renderer/LOD 수, rendered bounds, 지표 기준 min-Y offset 및 footprint 대비 크기 요약
- 활성 renderer·material·mesh 수, all-LOD instance triangle, unique mesh triangle 및 Unity runtime mesh memory 요약

Time Ghost 원본은 고밀도 HDRP·DOTS/ECS 환경 샘플이므로 고폴리 메시 삼각형을 전수 펼쳐 공면 검사를 수행하지 않는다. 실제 겹쳐 만든 vegetation cross-card도 정상 표현으로 본다. 대신 기준 충돌·지형·anchor 불변, 신규 참조 범위, LOD 및 정확히 중복된 visual instance를 합격 기준으로 사용한다.

종류별 bounds와 접지 수치는 진단 정보이며 그 값만으로 PASS/FAIL을 정하지 않는다. 특히 Time Ghost 나무 어댑터는 12×12 hemi-octahedral atlas를 GPU에서 회전시키는 4-vertex impostor라, Renderer bounds에 투명 여백과 모든 시야 방향의 보수적 범위가 포함될 수 있다. 따라서 큰 ground offset·footprint ratio를 곧바로 부유나 매몰로 판정하지 않고 실제 근거리·탑다운·오버헤드 화면에서 실루엣, 접지, 그림자 및 카메라 방향 전환을 확인해야 한다. 이 시각 확인은 정적 수치 검사를 대체하지 않으며, 반대로 수치 요약도 해당 화면 확인을 대체하지 않는다.

## Play 회귀

`StageV10PlayChecks`는 검증 내용 자체를 바꾸지 않고 v0.9 독립 Play 검사를 v1.0 전용 출력으로 복제한 것이다. SystemsTest의 정상 Stage A 출발을 거쳐 다음을 다시 확인한다.

- visual replacement의 지연 파괴 이후 semantic object identity 및 gameplay collision 보존
- entry-to-exit/interior/relay 및 계단·교량·core·보조건물 NavMesh 경로
- 실제 `PlayerMotor` 건물 출입, 계단, 교량, core 및 사면 이동
- 수로 호안에서 실제 이동·구르기 차단
- 높은 장비값을 흉내 낸 선택에서도 기본 진입 정책 유지

출력과 로그는 기존 v0.9 증빙을 덮어쓰지 않도록 `outputs/map_design/2026-09-15/timeghost-v10/V10_PLAY_VALIDATION.json`, `V10_TIMEGHOST_PLAY_VALIDATION_*` 접두어 및 `outputs/change_records/2026-09-15/timeghost-v10/after_play_entry_timeghost_supplement.png`로 분리했다.

## 시각 판독

최종 `after_*` 6개와 tree 3방향·vegetation·Play 보충 화면을 원본 크기로 확인했다. 초기 결과의 도로 침목 무늬·톱니 경계는 절차 mask blend 후 사라졌고, 나무 폭이 늘어나 원거리에서도 수관으로 읽힌다. Side·reverse·high 시점에서 사각 billboard frame, atlas cell bleed, 실루엣 붕괴는 보이지 않았고, 초기 수관을 가르던 직선 self-shadow 분할도 최종 화면에서 제거됐다. Rock은 대체로 접지하고 mass floating은 보이지 않았으며, vegetation도 지면과 연결된다.

Bounds 진단에서 tree 128개가 모두 deeply-sunken으로 계산되고 vegetation zone에도 floating/sunken 요약이 남았지만, 이는 투명 atlas 여백과 54×54m 경사 구역의 aggregate combined bounds를 프록시 지면과 비교한 진단값이다. 실제 보충 화면에서 대량 매롤·부유를 확인할 수 없어 이 수치만으로 불합격하지 않았다.

## 알려진 한계

- Tree는 2048 atlas 기반 impostor라 매우 가까운 거리에서 텍스처가 부드럽게 보이고 깊이가 근사된다. 자체 그림자 수신은 직선 분할을 막기 위해 제거했지만 지면에 그림자를 던지는 기능은 유지한다.
- Vegetation 분포는 기존 v0.9 slot을 유지했기 때문에 가까이서 얇고 성긴 구간이 있다. 밝은 알파 가장자리가 어두운 지반에서 두드러지는 개체도 있다.
- 이 pass는 자연환경 에셋 교체다. 건축물, 물, 차량은 기존 임시 표현이 남아 있으므로 전체 장면의 완성도는 해당 자산의 후속 패스에 의존한다.
- 이번 검증은 구조·메모리·triangle 수를 기록했지만 실제 기기에서의 FPS·GPU frame time 벤치마크는 수행하지 않았다.
- Play 회귀는 분리 검증 프로젝트에서 완료했고 원본 프로젝트에서는 설치 후 Play를 다시 실행하지 않았다. 원본 적용 일치는 `INSTALLATION.json`의 파일 보존·추가·갱신 수와 prefab hash로 확인했다.
