# 에델·세린 방어구 — 같은 유형 내 티어 구조 재설계

## 지시와 기존 주제 연결

사용자는 직전 전체16종 시안에 대해 “솔직히.. 같은 종류 내에서 등급 차이가 별로 느껴지지 않는데?”라고 지적했다. USER_REQUEST.md에 원문과 지속 조건을 보존했다. 앞선 시안의 승인이 아니며 같은 장비 주제의 11-02-04 후속 수정으로 기록한다. C/B/A/S × 기동/균형/중장/정비의16제품, 에델·세린 각각16착용안이라는 범위를 유지한다. 새16단계 성장 시스템이나 성능·드롭 변경 지시로 확대하지 않는다.

## 변경 전 상태와 문제

11-02-03은 각 유형의 크기·파우치·색 차이가 있었지만 동일 유형을 세로로 비교할 때 짧은 상의·어깨 보호대·허리판의 유사한 구성이 반복됐다. 색을 제외한 제작 방식의 차이가 부족했다. 수정 전 기존 최종 에델·세린 시트를 before_edel16.png, before_serin16.png로 그대로 보존했다. 이전 공개 원문·시안·게시 증빙은 덮어쓰지 않는다.

## 실제 수정

먼저 장비를 회색으로 표현한 에델16칸 구조 검토안을 생성하고 눈으로 검토했다. 그 구조를 채색한 에델16종, 해당 제품과 세린의 캐릭터 참조를 연결한 세린16종을 생성했다. 내장 image_gen을 사용했고 전체 프롬프트·실제 입력·원본 경로는 IMAGE_PROMPTS.json에 남겼다.

| 티어 | 몸통·결속 구조 | 허리·사지 실루엣 | 재료와 색 방향 |
|---|---|---|---|
| C | 거친 캔버스 사선 감싸기, 노출 끈과 회수 철판 | 불규칙 천단, 느슨한 가방, 납작한 조각 판 | 올리브·갈색 천, 녹슨 철판 |
| B | 둥근 U형 순찰용 셸, 큰 측면 결속 | 초승달형 둥근 허리 앞가리개, 원형 무릎 셸 | 회청 피복, 크림색 산업용 폴리머 |
| A | 각진 군용 분할판, 직선 결속과 모듈식 수납 | 분리된 사각 허리판, 상자 파우치, 사다리꼴/각진 사지판 | 올리브·차콜, 벽돌색 서비스 표식 |
| S | 비대칭 일체형 곡면 복합재, 오프셋 여밈 | 잎 모양 허리판과 한쪽 긴 판, 곡면 정강이 셸 | 네이비·백색·실버, 절제된 시안 접속부 |

동일 중장형 C3/B3/A3/S3에서는 거친 단일 철판 → 둥근 진압 셸/앞가리개 → 각진 군용 판/허리판 → 비대칭 곡면 셸/잎형 허리판이 비교된다. 기동형은 장비량과 수납을 줄이고, 균형형은 표준 조합, 중장형은 보호 면적과 사지판을 늘리며, 정비형은 공구·예비판·서비스 접속부를 남겼다. 모든 부품이 티어마다 완전히 다른 독립 메시라는 뜻은 아니다. 제품 후보 이름과 코드16개는 DESIGN_ROSTER.json의 기존 목록을 유지한다.

## 생성 경로와 참조의 한계

첫 구조 검토 요청은 실제 에델 게임 렌더를 입력했으나 이미지 도구에서 input 단계 category other로 거절되어 결과 이미지가 생기지 않았다. 별도 API/CLI 우회는 사용하지 않았다. 다음 요청은 앞선 **완전히 착의한 에델16종 시트**를 정체성·배치 참조로 사용하고 기존 장비를 새 구조로 교체하는 중립적인 장비 검토로 바꾸어 생성했다. 따라서 성공 시안을 실제 게임 원본만 직접 입력한 새 렌더라고 설명하지 않는다.

채색 에델은 새 회색 구조 검토안을 참조했다. 세린은 새 에델 제품 시트와 앞선 착의 세린 시트의 얼굴·갈색 포니테일·SD 방향을 참조했다. 이전 세린 장비 구조는 재사용 지시에서 제외했다. 원래 캐릭터의 머리색과 실루엣을 참고하며 남성형 마네킹 입력은 사용하지 않았다. 두 캐릭터의 실제 메시 치수·UV·스키닝에 맞춘 결과라는 주장은 하지 않는다.

불투명한 몸통 의상과 반바지를 유지하면서 팔·허리·허벅지 일부가 드러나는 의상 방향을 유지했다. 실제 피팅에서 원본 체형·관절·헤어 재질을 다시 확인해야 한다.

## 검토와 결과

각 최종 시트에서16인, C1~S4 코드와4행×4열 배치, 발끝 포함, 에델 연보라 땋은 머리/세린 갈색 포니테일, 같은 코드의 두 캐릭터 제품 대응을 눈으로 확인했다. 특히 둥근 B 몸통/허리판, 직선 A 판/상자 파우치, 비대칭 S 곡면/허리 지느러미의 구분과 C의 거친 감싸기 구성을 검토했다. 정비형의 공구/예비판 및 중장형의 넓은 보호 구성을 확인했다. 생성 이미지 특성상 작은 고정부나 패널 곡선은 두 캐릭터 사이에 차이가 있으며 제작 명세로 확정하지 않는다.

structure_study_edel16.png는 색 차이에 의존하는지 살피기 위한 **회색 장비 시각 검토안**이다. 동일 재질 수치나 픽셀 밝기의 수학적 동등성·실게임 식별률을 측정한 자료는 아니다. 피부와 머리색은 남아 있다. FILE_CHECK.json은 이미지 디코딩·해상도·크기·SHA와 이전 시트 복사 일치, 제품 코드 수를 검사한다. 사용자 승인 여부나 실게임 가독성을 자동 통과 처리하지 않는다.

## 증빙과 비교 조건

|---|---|---|

전후는 실제 게임 스크린샷이 아닌 **디자인 시안 간 비교**다. 같은4×4 배치를 유지했지만 생성 결과의 카메라·조명·포즈·축척이 픽셀 단위로 동일하지 않다. 체형이나 장비의 정확한 치수 변경을 전후 이미지로 측정하지 않는다. 회색 검토안은 별도 참고 이미지로 연결한다. 생성 원본은 원래 위치에 남겼고 프로젝트 사본만 추가했다.

## 적용 상태와 다음 단계

사용자 검토용 전체16제품/32착용안과 보조 회색16칸을 완료했다. 디자인 승인은 대기 중이다. Blender 장비 제작·피팅, Unity Assets 변경·삽입, 장비 성능·드롭 변경은 수행하지 않았다. 기존 r18 Unity 보정 패키지/별도 내보내기 자료 미확보에 따른 캐릭터 동기화 보류도 이 이미지 작업으로 해결된 것으로 취급하지 않는다. 승인 후 실제 모델에서 각 캐릭터 비율·관절 여유·헤어·장비 간섭을 검증해야 한다.

주요 파일: USER_REQUEST.md, DESIGN_ROSTER.json, IMAGE_PROMPTS.json, FILE_CHECK.json, LIBRARY_EVIDENCE.json, 전후 시안4장, 회색 구조 검토안1장. 라이브러리 게시·공개 열람 결과는 담당의 검증 영수증과 게시 상태를 연결하여 후속 기록한다.
