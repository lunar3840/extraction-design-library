# A맵 현재 배치 — ChatGPT Pro 전달 자료

작성일: 2026-09-28 / 대상: 익스트랙션 게임의 A맵(침수 정비지구)

## 이 자료의 목적

현재 맵이 지나치게 개방되어 구역 진입 방향이 잘 읽히지 않는다는 사용자 의견을 검토하기 위한 현황 자료다. **이번 패키지에는 새로운 숲·폐차·장애물 배치 제안을 넣지 않는다.** ChatGPT에서 현재 배치를 먼저 이해한 다음 개선안을 설계하기 위한 인계 자료다.

Unity는 실행하거나 수정하지 않았다. 저장된 맵 데이터에서 읽어 만든 평면 투영도이며 게임 화면 캡처, NavMesh 검사 결과 또는 실측 통행 가능 지도는 아니다. 저장하지 않은 편집기 변경이나 Play 중 임시 상태는 포함되지 않는다.

## 권장 전달 순서

1. `CURRENT_OVERVIEW.png`와 `CURRENT_DETAILS.png`를 이미지로 첨부한다.
2. `CURRENT_FACTS.json`, `CURRENT_AUDIT.md`, `CONSTRAINTS.md`도 첨부한다. 상세 좌표 CSV가 함께 제공되면 추가 참조 자료로 사용한다.
3. `PROMPT_FOR_PRO.md` 내용을 메시지에 붙여 넣는다.
4. 사용하려는 Pro 모드는 ChatGPT 쪽에서 선택한다. 이 패키지 제작 자체는 새 채팅 생성·업로드·모드 선택·분석 실행을 뜻하지 않는다.

전체 ZIP은 보관·전달용이다. ZIP 내부 읽기가 지원되지 않는 환경이면 압축을 풀고 위 파일을 직접 첨부한다. 이미지가 첨부되지 않은 경우 JSON만으로 실제 외관을 보았다고 가정하지 않도록 한다.

## 읽는 법

- 도면 좌표: 북서 모서리 (0,0), 동쪽으로 x 증가, 남쪽으로 y 증가. 단위 m, 전체 520×400m.
- Unity 변환: `(worldX, worldY, worldZ) = (mapX−260, 높이, 200−mapY)`.
- B: 기본 진입점. R: 현재 비활성 위험 진입 후보. X: 탈출 지점. R을 적·보스나 위험 구역 경계로 해석하지 않는다.
- 평면의 빈 곳이 곧 통행 가능 공간이라는 뜻은 아니다. 높이, 사면, 충돌체, 문, 교량 난간, 실시간 표시 상태는 추가 확인이 필요하다.
- 데이터별 출처, 포함·생략한 객체, 개수와 오차는 `CURRENT_AUDIT.md` 및 JSON의 설명을 우선한다.
- 수면은 현재 저장된 활성 수면 메시의 13개 정점에서 얻은 다각형이다. 반면 67개 경로 중심선은 저장 경로 이름과 생성 코드 정의를 대응시킨 참고선이며, 현재 도로 표면이나 실제 통행 가능 폭을 측정한 것이 아니다.
- 전체도의 작은 객체 표식은 가독성을 위한 기호다. 표시 크기를 실제 차단 폭으로 해석하지 않는다.
- 도면은 외부 구역 간 동선 검토용 요약이다. 저장된 14,153개 GameObject를 전부 그린 상세 시공도가 아니다. 장식 부품·실내 벽체·모든 문과 계단의 개별 외곽선은 생략될 수 있다.
- 332개 환경/지구 배치와 별도의 신규 사용자 에셋 53개를 구분한다. 교체 21개는 기존 산업소품 슬롯의 교체이므로 또 다른 신규 21개로 합산하지 않는다.
- 원시 충돌 도형으로 범위를 읽을 수 없는 MeshCollider 전용 신규 에셋 18개는 중심 위치만 알려져 있다. 주변에 무엇을 추가할지 결정할 때는 실제 크기와 충돌 간섭을 나중에 별도로 확인해야 한다.
- `CURRENT_OBJECTS.csv`는 332개 환경/지구 객체의 Unity 좌표 표이며 모든 에셋의 통합 목록은 아니다. 신규 53개/교체 21개와 주요 구조는 JSON의 별도 배열을 읽는다.

## 원본과 구현의 구분

2026-09-15의 v0.8 설계도는 과거 계획이다. 그 뒤 지형, 건물, 실내, 소품 배치와 가시성이 여러 차례 변경됐다. 이번 자료는 최신 저장 프리팹과 씬을 우선하며, 과거 설계의 경로/구역 정보가 필요하면 참고 정보로 분리한다. 과거 도면에 나온 시스템이나 잠금·보상 계획을 현재 구현 완료 기능으로 취급하지 않는다.

Pro가 돌려줄 결과는 분석과 제안 도면이며 실제 Unity 반영 완료가 아니다. 반영 전에는 사용자 승인과 별도 충돌·통행·AI·시야 검증이 필요하다.
