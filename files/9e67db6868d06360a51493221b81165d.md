# AweSun 설치 및 원격 연결 시도 기록

## 사용자 지시 요약

- 사진 속 원격 제어 앱이 현재 노트북에 설치되어 있는지 확인한다.
- 미설치 상태이면 설치하고 실행한다.
- 사진의 대상 PC 식별 코드와 확인 코드를 사용해 원격 데스크톱 연결까지 시도한다.

## 기획 의도와 해결하려는 문제

현재 노트북을 제어 측으로 구성하고, 사진 속 PC를 AweSun(AweRay Remote의 최신 명칭)으로 조작할 수 있게 준비한다.

## 변경 전 상태 및 문제점

- Windows 제거 프로그램 레지스트리와 실행 프로세스를 조회한 결과 AweSun/AweRay가 설치되어 있지 않았다.
- 설치 전에는 대상 앱 창 자체가 존재하지 않았고, 이 환경의 Windows 화면 캡처용 신뢰 RPC가 구성되어 있지 않아 설치 전 앱 화면을 캡처할 수 없었다.
- 사후 화면을 설치 전 화면으로 위장하지 않았으며 `before_*.png`는 만들지 않았다.
- 사용자가 제공한 사진은 대상 PC의 참고 화면이며 이 노트북의 설치 전 상태 증빙으로 취급하지 않는다.

## 실제로 바꾼 부분

- AweSun Windows 64비트 버전 `16.6.0.32198`을 설치했다.
- AweSun을 실행하고 기존 사용자 계정 로그인 상태를 확인했다.
- 대상 식별 코드 `081 494 135`와 사용자가 제공한 확인 코드가 입력된 상태에서 원격 데스크톱 연결을 시도했다.

## 어떤 방식으로 변경했는지

- AweSun 공식 다운로드 페이지에서 64비트 설치 파일을 내려받았다.
- 파일 MD5 `B65AE299C7AE1E004582C618937A3DD9`가 공식 배포 정보와 일치하는지 확인했다.
- Windows Authenticode 서명이 유효하며 서명자가 `Shanghai Best Oray Information Technology Co., Ltd.` 계열 법인임을 확인했다.
- 무인 설치 옵션으로 설치한 뒤 설치 레지스트리, 버전, 실행 프로세스를 재확인했다.

## 변경 후 기대 효과와 확인 결과

- 현재 노트북에서 AweSun이 정상 실행되고 있으며 원격 제어 측으로 사용할 준비가 완료됐다.
- 대상 연결은 여러 차례 요청됐으나 서버가 `access/remote_host_offline` 및 `fastcode_not_exists` 오류 코드 `150626313`을 반환했다.
- 따라서 대상 PC가 현재 AweSun 서버에 온라인 상태로 등록되지 않았거나, 사진의 일회용 확인 정보가 더 이상 유효하지 않은 상태로 판단된다.

## 관련 스크린샷

- `after_app_running.png`: 설치·실행·로그인 후, 대상 식별 코드와 확인 코드가 입력된 AweSun 원격 지원 화면.
- 설치 전 화면은 위 사유로 누락되었으며 재구성본을 만들지 않았다.
