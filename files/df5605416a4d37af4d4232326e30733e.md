# A맵 공장 창 깊이·반사 V22 독립 검토

## 판정

**제한 범위 승인.** V21에서 기능은 있었지만 화면상 거의 확인되지 않았던 창 깊이·반사가 V22의 근거리 정면·좌·우 사선 화면에서는 실제로 읽힌다. 파손창이 검은 평면 구멍처럼 보이던 상태에서 어두운 내부 기둥·후벽 계층, 유리 표면 톤, 제한된 반사가 분리되며, 사선 시점에서 가장 설득력이 높다. 작업 범위를 막는 시각적 또는 기능적 회귀는 발견하지 못했다.

## 독립 시각 검토

- `before_glass_frontal/left/right.png`와 대응 `after_*.png`를 원본 해상도로 비교했다. 변경 전에는 파손 영역과 내부가 큰 검은 덩어리로 합쳐졌지만, 변경 후에는 창틀 뒤의 희미한 세로 구조와 후면 명암이 남아 한 겹 안쪽 공간으로 읽힌다.
- 정면에서도 개선이 보이지만 좌·우 사선에서 내부층과 유리층의 분리가 더 분명하다. 과도한 거울 반사, 밝은 플라스틱 광택, 창틀 밖 UV 번짐, 창별 축 뒤틀림은 보이지 않았다.
- 동일 카메라의 효과 분리 화면에서 시차를 끄면 내부 단서의 위치 변화가 사라지고, 반사를 끄면 유리 표면의 완만한 명암이 평평해진다. 최종 수치는 시차가 각 시점에서 36,837~43,743픽셀(`delta >= 3`, 최대 채널 차이 20~22), 반사가 93,243~121,516픽셀(최대 24~26)에 기여했다. 수치만으로 승인한 것이 아니라 세 각도의 실제 이미지에서 해당 차이를 다시 확인했다.
- 20개 실제 플레이 후 화면도 확인했다. 이번 작업으로 캐릭터 식별, 차양 아래 시야, 지붕 가림/복원, 원격 구역 복원에 새 문제가 생기지 않았다. 플레이 카메라 대부분은 창 효과를 평가하기보다 회귀 확인용이므로, 깊이 판정의 주 증거는 고정 근접 3시점과 효과 분리 화면이다.

## 범위·회귀 검증

- 적용 전 기준선은 `9 PASS / 0 FAIL`, 적용·재열기 후 검증은 `19 PASS / 0 FAIL`이다.
- 대상은 기존 V21 창 슬롯 정확히 38개(외벽 24, 지붕/채광창 14)이며, 38개 모두 V22 재질로 교체됐다. 셰이더 오류와 미지원 셰이더는 0개다.
- 창별 파손 패턴 이동·반전·시드와 원본 BaseMap 텍스처/UV는 기준선과 동일하다.
- 렌더러 6,018개, 충돌체 4,665개, 변환 14,032개, 기준점 46개가 보존됐다. 대상 밖 모든 재질 슬롯, V21 벽 재질, V16/V17 설정, 반사 프로브와 전역 환경 설정도 기준선과 동일하다.
- V14 충돌 및 V15 중첩 회귀 검사가 통과했다. 저장 후 재열기도 통과했고, 최종 Play 검증은 `RESULT PASS`였다.
- 전후 PNG는 41쌍이며 누락은 없다. 최종 점검 시 장면은 `sceneDirty=False`, 렌더러 6,018개, 충돌체 4,665개였다.
- B4/R8의 거리, 동선, 엄폐, 보상과 스폰 정책은 변경하지 않았다. R8을 포함한 위험 진입점은 계속 기본 스폰에서 제외되며, 이번 결과를 B4/R8 공간 경험 개선으로 해석하지 않는다.

## 남은 한계

- 실제 투명 유리나 실내 지오메트리가 아니라 단일 표면의 가상 깊이 표현이다. 창에 아주 가까이 붙거나 큰 시점 이동을 하면 실제 공간과 같은 정확한 폐색은 기대할 수 없다.
- 반사는 한 지점에서 얻은 정적 큐브맵이므로 창마다 주변 구조를 정확히 반영하지 않는다. 정면보다 사선에서 효과가 잘 읽히며, 어두운 조명에서는 다시 약해질 수 있다.
- 현재 강도는 현실감을 해치지 않는 절제된 수준이다. 더 강한 시차나 반사를 추가하면 즉시 효과는 커지지만 가짜 깊이, 반복, 거울 같은 표면이 드러날 위험이 있으므로 이번 범위에서는 추가 증폭을 권하지 않는다.

## 결론

V22는 V21에서 남았던 “깊이·반사가 구현됐지만 보이지 않는다”는 핵심 시각 문제를 근거리에서 확인 가능한 수준으로 보완했다. 실제 유리/실내 구조를 대체하는 해법은 아니지만, 정해진 38개 창 재질만 바꾸고 기존 장면·게임 기능을 보존한다는 범위 안에서는 완료로 승인한다.
