# 에델 LOW READY 최종 검증

최신 실제 정지 외형과 동적 수치 검증을 확인했다. 메인은 LOW READY 어깨·양손 파지의 정지 상태와 전환의 매끄러움을 수용했다. 이동 중간의 왼손 접점 한계는 아래에 별도로 명시한다. 영상은 사용자 지시대로 보류한다. `library_ready: true`는 이 한정된 완료 범위의 수집 허용이며 게시 성공이 아니다. 게시 상태는 pending이다.

## 실제 전후

정상 비교는 `before_shoulder_anchor_edel_90_valid_portrait.png` → `after_edel_low_90_portrait.png` 한 쌍이다. 둘 다 768×1152, ortho 1.040429다. 현재 0/270°는 보조 후 시점이다. 호흡·헤어 상태가 달라 완전한 픽셀 정합을 주장하지 않는다. 초기화에 실패한 before90과 철회된 High 이미지는 제외했다. 앞선 before_edel_live 0/270°는 실제 옛 상태지만 다른 라이브 리그 카메라·조명·배율이라 직접 초상화 짝으로 만들지 않았다. 이미지 4장은 원래 파일명 그대로 복사했고 양쪽 SHA256을 요약에 보존했다.

## 정지 외형과 방법

실제 0/90/270°에서 앞쪽으로 꺾여 보이던 어깨 시작점이 개선됐다. 상완은 어깨 둥근 부분에서 아래로 내려오며 약간 앞을 향하고 전완이 총으로 굽는다. 총과 지지 손이 읽히지만 방아쇠 손가락 일부는 가려져 모든 손가락 접촉을 이미지로 증명했다고 하지 않는다.

에델 어깨는 부모 상대 bindpose 회전을 사용하고 위치·본 길이는 직접 바꾸지 않는다. 이전 왼쪽 상완 시작점 모델 z≈0.12055m에 비해 현재 왼쪽≈0.01128m, 오른쪽≈0.01127m다. 호흡 상태가 다른 실제 측정이며 월드 위치를 고정한 것이 아니다. 총 전체와 양손 목표에 기존 10mm와 추가 7mm의 전방 여유를 적용했다. 무기 점검은 총 회전 3°, 위 0.01m·앞 0.015m로 완화했다. High와 자동 교대는 수동·이전 설정·타이머로 다시 켜지지 않는다.

실제 총/몸 삼각형 교차는 Low와 점검 모두 0이며 최소 근접 거리는 6.473mm/10.385mm다. 팔 표면 최소 간격은 오른쪽 13.573mm, 왼쪽 2.896mm였다. 왼쪽의 근접 REVIEW 신호는 실제 정지 실루엣 검토와 함께 수용했다. 열린 몸 표면의 포함 레이는 모호한 표본이 많아 모든 애니메이션·모든 입체의 완전 무관통을 일반화하지 않는다.

## 동적 전환 — 최신 실제 통과와 접점 한계

첫 low_only_edel_final.json은 위치 튐 1·회전 튐 1, 후속 recovery는 1·2여서 수용하지 않았다. 실패 원본 두 개와 당시 기록·요약을 보존했다. 에델의 기존 장애물 회피 팔꿈치 탐색이 Ready 가중치 0에서도 다른 굽힘 분지를 선택하던 경로를 보완했다. 선택된 굽힘 평면이 모델 공간에서 연속되도록 하고 정확한 두 본 길이는 유지한다.

최신 low_only_edel_continuous.json은 13구간 624표본에서 실패 0·위치 튐 0·회전 튐 0·예상치 않은 High 0·비정상 수치 0이다. 본 길이 최대 상대 오차는 약 0.000261%다. 수동 High·자동 활성 시도·High 프로필 인수가 모두 차단됐고 이동·조준·재장전 동작을 관측했다. 장비 원본·장비 참조·입력·위치·선택 상태·허기/갈증·체력/스태미나 복원 표시도 모두 true다. 세린의 현재 같은 수치 검사도 실패 0·위치 튐 0·회전 튐 0이다.

손바닥 최대 오차 1.735mm는 거의 완전한 Ready의 접점 검사에만 해당한다. 전체 전환에서 총 접점을 유지했다는 뜻이 아니다. 실제 모든 표본을 따로 확인하면 이동 중간 왼손은 총의 원래 지지 소켓에서 최대 59.303mm 떨어진다. 그때 Ready 가중치는 약 0.605다. 이전 실패 후보의 최대 차이는 각각 73.229mm/63.047mm였다. 정지 Ready와 조준 끝 상태는 0.001mm 미만이다. 이는 기존 carry 도달 제한이 남은 구간이며, 동일 조건의 앵커 수정 전 대조가 없어 이번 어깨 수정이 원인이라고 단정하지 않는다. 이동 중간까지 완벽한 양손 접촉이 완성됐다고 보고하지 않는다.

수치 판정은 기록된 구간·표본 간격과 명시된 전환 선별 기준에 한정한다. 인체의 의학적 속도 한계가 아니며 희소 자동 표본으로 모든 프레임의 연속성을 증명하지 않는다. 실제 현재 소스 컴파일 오류 0은 메인이 확인했다. SdWeaponPose.cs·InventoryPortrait.cs·SdIdlePresentation.cs의 현재 SHA256과 크기를 JSON 요약에 보존했다. 기록 작성자는 Unity를 실행하거나 제작 소스를 수정하지 않았다.
