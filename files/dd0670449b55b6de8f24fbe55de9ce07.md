# 인간형 적 콘셉트 v01 작업 기록

- 작업일: 2026-10-14 (Asia/Seoul).
- 사용자 지시: 인간형·기계형 적 분류에 맞춰, 방독면으로 표정 제작 부담을 줄이는 인간형 적을 디자인하고 콘셉트 아트를 제작한다. 소녀전선 2 바랴그단은 얼굴을 가리는 방향의 참고이며 기계형은 사용자 지정 Mech Constructor 에셋 구매 예정.
- 작업 범위: 새 인간형 적 외형 시안. 기존 모델·게임 코드·맵·스폰을 변경하는 작업이 아니다.
- 변경 전 상태: 이번 인간형 적 디자인에 대응하는 기존 원본 이미지가 없다. 신규 시안이므로 before 스크린샷은 해당 없음. 이후 이미지를 이전 상태로 위장하거나 임의 재구성하지 않는다. 기존 플레이 화면은 이번 디자인의 전후 비교 화면이 될 수 없어 별도 실행하지 않았다.
- 기획 근거: ‘세계관 설정 작성’ 대화(6a9aa012-2568-83ee-b24a-38588f3e743a)의 통합 설정안 v1.0 중 기계군집·침식·인간 세력과 상시 적대 집단. 약탈자·코어 밀매단은 기본 적 후보이며 정착지 연합·계승군·회수조합 전체를 상시 적으로 재분류하지 않는다.
- 중요 설정 구분: 침식은 기계군집의 신경 규격/신체 제어 간섭이다. 방독면이 침식을 정화하거나 막는다는 설정을 추가하지 않는다. 분진 차단·신원 은폐는 이번 의상 제안의 용도다.
- 시각 근거: 기존 세린·에델 콘셉트의 큰 머리와 짧은 팔다리, A맵 폐정비지구의 낡은 산업 재료. 건물 자료는 환경 분위기만 참고하며 배치·진입점·지도 지침을 인간형 외형 작업으로 확장하지 않는다.
- 기획 의도: 얼굴·눈을 모두 가리되 천과 인간 관절이 드러나는 실루엣으로 기계형 적과 구별한다. 소총 일반병·산탄총 돌격병·기관총 중장병은 무기 길이, 어깨 폭, 배낭 크기로 구분한다. 역할·이름·장비는 이번 디자인 제안이며 확정된 전투 로스터가 아니다.
- 방식: 내장 image_gen으로 신규 콘셉트 생성. 생성 후 원본과 최종 프롬프트를 프로젝트에 보관하고 육안 검토한다.
- 실제 산출물: 3종 라인업 1장과 기본 소총수의 전면·후면·방독면 확대·탑뷰 인상 시트 1장을 추가했다. 각각 1536×1024 PNG다.

## 디자인 제안

가칭 ‘폐허 약탈자’. 기존 상시 적대 집단 중 약탈자의 한 외형군으로 제안하며, 새 공식 세력명이나 기존 세력의 분파를 확정하지 않는다. 코어 밀매단·계승군의 전용 외형은 이번에 만들지 않았다.

| 시안 | 주된 외형 | 제안한 역할 |
|---|---|---|
| 01 SCAVENGER / 수색병 | 작은 후드, 좁은 어깨, 소형 회수 배낭, 소총 | 기본 원거리 인간형 적 |
| 02 BREACHER / 돌격병 | 낮은 헬멧, 크게 덧댄 어깨판, 짧은 외투, 산탄총 | 근거리 압박 |
| 03 SUPPRESSOR / 제압병 | 넓은 흉부·어깨 방탄판, 큰 사각 배낭, 기관총 | 중장비 화력 제압 |

- 공통: 검은 고무 마스크, 두 개의 어두운 호박색 렌즈, 볼 옆 납작한 사각 필터, 청회색/먹색 직물, 퇴색한 회백색 방탄판, 짧은 녹슨 주황색 목천, 작은 황토색 식별 테이프.
- 렌즈는 반사하는 불투명 표현이다. 눈·입·표정을 드러내지 않으며 발광 센서로 만들지 않는 방향이다.
- 제작 우선순위 제안: 수색병의 바디·기본 복장·방독면을 먼저 제작한 뒤 헬멧·어깨판·흉부판·배낭·무기를 별도 부품으로 교체한다. 중장병의 과도한 체형 확대보다 방탄판과 장비 부피로 차이를 낸다. 실제 리그·메시 호환성은 후속 모델 작업에서 확인해야 한다.
- 작은 탑뷰에서는 미세한 흠집보다 후드/헬멧 외곽, 어깨 폭, 등 위의 표식이 우선이다. 생성 시안의 잔무늬·파우치는 모델 제작 때 단순화하는 편이 좋다.
- 소속 확정·능력치·전리품·스폰·AI는 이번 외형 제안으로 결정하지 않는다. 방독면을 모든 인간의 공통 의상으로 확장하지 않는다.

## 육안 검토와 한계

- 두 생성 결과를 직접 열람했다. 세 병종 모두 전신과 발끝이 보이고, 눈·입은 가려져 있으며, 천과 사람의 팔·다리 관절로 인간형임을 읽을 수 있다.
- 라인업의 소총·산탄총·기관총, 좁음→중간→넓음의 어깨/흉부 실루엣을 확인했다. 공용 마스크 형태와 복장 재료가 이어진다.
- 상세 시트의 전면·후면 크기와 발 기준선이 대체로 정렬되고, 마스크 확대 및 높은 시점의 소형 전신이 포함되어 있다. 후드는 머리카락을 완전히 가리는 신규 디자인이다. 기존 캐릭터의 머리색·재질을 바꾸지 않았다.
- 생성 시안이므로 파우치·어깨판 흠집·끈의 미세한 위치는 시점 간 차이가 있다. 정확한 정투상 제작도나 검증된 리깅 도면으로 보지 않는다. GAME VIEW는 게임 카메라를 상상한 그림이며 Unity 실제 플레이 화면이 아니다.
- 현재 게임의 픽셀 크기에서 식별성, 총기 견착 시 필터 간섭, 손가락/무기 메시 구조, 충돌, 애니메이션은 검증하지 않았다. 일러스트만으로 제작 완료 또는 게임 성능 통과로 판정하지 않는다.
