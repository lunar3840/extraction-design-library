# 반드시 보존하거나 구분할 조건

## 사용자 의도

- 현재처럼 여러 방향으로 접근할 수 있는 개방성은 어느 정도 의도됐다.
- 그렇지만 각 구역의 진입에 아무 제약도 없는 느낌은 줄이고 싶다.
- 숲, 폐차 등의 장애물로 최소한의 자연스러운 동선 유도를 원한다.
- 지금 단계의 요청은 **분석 후 도면 제안**이다. 실제 에셋 배치·Unity 수정·스폰 로직 변경은 요청하지 않았다.

## 기존 작업 보존

- 사용자 제공 에셋의 신규 배치 53개와 산업 소품 교체 21개가 반영된 상태를 기준으로 한다. 실제 추출 개수와 좌표는 현황 데이터 및 감사 기록을 우선한다.
- 기존 소품을 빈 공간으로 오인해 겹치게 배치하지 않는다. 이동이나 삭제가 필요하다고 판단하면 제안 도면에서 별도 표시하고 이유를 설명한다.
- 중정비동 내부·층별 연결·벽·입구·계단, 기존 충돌과 진입/탈출 경로를 임의로 변경하지 않는다.
- 최근 작업에는 중정비동 지붕/벽 가시성, 2층 외부 시야 제한, 벽 교차부 통로, 실내 재질과 밝기 경계 수정이 포함된다. 이 패키지 작업에서는 어느 것도 변경하지 않는다.
- 캐릭터, 머리색, 무기, 전투/파밍/적 규칙은 이번 분석의 변경 대상이 아니다.

## 진입·탈출 및 연결성

- 현재 A맵은 기본 진입 B1~B4를 사용하며 R1~R8은 무작위 진입 후보에서 제외된다. R 활성화나 이동을 현재 확정안으로 넣지 않는다.
- B4=(141,329), R8=(202,341)의 기존 기록상 직선 거리는 약 62m이며 둘 다 W5=(168,293)로 연결된다. 두 점을 서로 독립적인 위험 경험으로 단정하지 않는다. 최신 추출 좌표가 다르면 차이를 먼저 밝힌다.
- B4/R8 주변 제안은 거리뿐 아니라 초반 이동, 적 노출, 엄폐, 목적지 접근, 탈출 위험과 보상 차이를 검토한다. 현재 적 위치/AI 시야나 보상 자료가 없으면 미확인으로 표시한다. R8 비활성 상태를 유지한 채 검토한다.
- 중앙 건물을 반드시 통과해야만 동서 이동할 수 있는 구조로 바꾸지 않는다. 북측·남측 우회 골격을 보존하는 방향으로 검토한다.
- 기존 두 교량과 교량 진입부, 진입점·탈출점의 접근을 막지 않는다. 수로를 건너는 새 지름길을 임의로 추가하지 않는다.
- 주 통로와 우회 통로의 폭은 제안 값/저장된 설계 값/실제 유효 통행 폭을 구분한다. 도면만으로 NavMesh·플레이어·적 모두 통행 가능하다고 보장하지 않는다.

## Pro 분석 시 주의

- 나무 수관·덤불의 시각적 차폐와 나무 줄기·차량의 물리적 차단은 서로 다르다. 작은 표식을 연속된 막힌 숲으로 해석하지 않는다.
- 기존 도로 중심선이 있다고 해서 그 선 밖은 통행 불가가 아니다. 반대로 장애물 데이터가 없는 곳도 자유 통행이 검증된 것은 아니다.
- 건물 외곽을 폐차·숲으로 완전히 감싸 하나의 문으로만 유도하는 안은 사용자 개방성 의도와 충돌할 수 있으므로 근거 없이 기본안으로 삼지 않는다.
- 기존/제안/추가 확인 필요를 도면에서 명확하게 구분한다. 단순 예쁜 그림보다 좌표·출입 폭·우회 연결이 검토 가능한 설계가 필요하다.
