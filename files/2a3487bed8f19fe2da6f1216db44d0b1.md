## 지시·기획 의도

사용자는 편집기의 각 수치가 어떤 게임 요소와 스탯에 영향을 주는지 표기해 달라고 요청했다. 기존 CSV·웹 편집기의 수치 해석 개선이므로 기존 주제 ID의 후속 회차로 잇는다. 새 대표 주제를 만들지 않는다. 원문은 SOURCE_TRANSCRIPT.md에 보존한다.

## 변경 전 상태

게시 v6에서 EnemyTargetPerception은 estimatedHealthFraction·confidence 같은 코드 이름과 수치·코드 문장만 보여 주었다. 동일 confidence 행이 초기값인지 상한인지 증가량인지 구분하기 어려웠다. 사용자가 플레이어 실제 체력과 적의 체력 추정을 혼동할 수 있었다.

수정 전에 실제 공개 사이트의 같은 카테고리·첫 행을 1280×720에서 촬영했다. before_white.png와 before_black.png는 당시 공개 v6 원본 화면이다. 사후 재구성하지 않았다.

## 실제 변경·방법

- 표의 한글 항목명 아래에 영향 스탯·값의 역할을 표시했다. 상세에는 영향 대상, 설명, 변경 효과, 주의점, 근거 수준과 사용 맥락을 추가했다. 설명도 검색 대상이다.
- EnemyTargetPerception.cs 및 소비 코드 EnemyController/EnemyBrain을 읽고 10개 상수를 구분했다. 초기 추정 체력, 초기 확신도, 미관측 시각 표식, 피해 후 추정 체력 하한, 피해 관측 확신도 상한·고정 증가·피해 비율 계수, 치료 관측 체력 하한·확신도 하한·유지 배율이다. 전부 실제 플레이어 체력·최대 체력을 변경하지 않는다고 명시했다.
- 플레이어 실제 설정·무기·탄약·아이템·의료·경제의 공통 필드 설명을 추가했다. 상점 수량 제한과 표시 순서, 탄약 관통력과 등급, 재장전 시간과 발사 간격 등을 구별한다. 조준 보조 반경 선언값은 소비 지점을 확인하지 못했다고 표시한다.
- 임의 코드 상수는 이름만으로 직접 스탯 효과를 단정하지 않는다. 확인되지 않은 값은 세부 영향 확인 필요, 이전/비활성 설정은 적용 제외, 구조/ID는 참조 정보로 구분한다.
- 설명은 impact-guide.js의 조회 전용 표시 정보다. D1의 기존 카탈로그에서도 동작하며 ID·실제 값·권한·CSV·게임 적용 로직은 변경하지 않는다. 로컬 서버 정적 허용목록과 웹 번들에 해당 파일을 포함했다.
- 공통 White/Black 테마와 shared-web은 변경하지 않았다. 추가 설명 영역은 기존 테마 변수를 사용한다. 원본 필드 키·파일·행·코드 문장은 그대로 열람할 수 있다.
