## 다운로드

최신 추가 4종 다운로드 링크는 이 문서 마지막 “2차 보강” 절을 참조한다.

- 각 모델에서 **내보내기 → GLB → 위 표의 텍스처 해상도**를 권장한다. 반복형·탑뷰 배치용은 1K, 드물게 쓰는 터빈은 2K를 우선한다. 1K 변환이 서비스에서 실패하면 2K 원본으로 내려받아 이후 Unity에서 제한할 수 있다. 추가 생성·리토폴로지·유료 업스케일은 현재 필요하다고 확인되지 않았다.
- 담장은 **10,000면 경량화 결과**를 선택한다. 1,897,800면 원본이나 9월의 비슷한 이름 에셋과 혼동하지 않는다.
- 기존 외벽 설비·배수문 및 추가 7종의 생성 원본은 2K이고 Ultra OFF다. 목표 면수와 서비스에 실제 표시된 면/정점 수는 다를 수 있으므로 위 표 수치를 확인한다.
- 생성과 경량화가 끝난 결과이며, 버튼의 `생성 30` 또는 `리토폴로지 35`는 추가 작업 버튼이지 이미 생성된 모델을 받는 버튼이 아니다.

## 사용 의도와 제한

- 담장: 기존 연결 경계의 시각 외형 대체. 문·출입구·원래 충돌체 보존. 실제 끝단 연결은 파일 실측 후 확인한다.
- 외벽 설비: 환기함과 배관이 앞으로 돌출된 모듈. 후면 프레임과 배관도 생성됐다. 실제 무창 외벽 면적을 측정한 뒤 설치하며, 창과 문을 덮거나 통로에 돌출시키지 않는다.
- 배수문: 후면이 콘크리트로 막힌 **정적 폐쇄시설**이다. 열리는 문이나 물이 관통하는 기능성 수문이 아니다. 기존 제방에 연결되는 위치만 후보로 검토한다.
- 하역 도크: `PARTS` 긴 외벽을 첫 실측 후보로 삼되 실제 문·SC 경계·차량 접근·기존 3m 통로를 침범하면 쓰지 않는다. 레벨러와 짧은 계단은 **정적 외형**이며 움직임이나 보행 가능성을 주장하지 않는다.
- 캔틸레버 차양: 도크와 별개로 선택 설치한다. 기존 문·처마·창과 간섭하거나 불투명 상판이 탑뷰 캐릭터·도크를 가리면 생략한다. D04 가림 체계와 연동되기 전에는 반복 배치하지 않는다.
- 정비 포털: `W02`·`W04`·`E05`의 **실제 열린 문**과 중앙 빈 부분이 정확히 맞는 자리만 후보이다. 새로운 출입문, 자동문 또는 거짓 통로로 취급하지 않는다. 양 지주 발판과 상부 빔의 보행폭·가림을 검사한다.
- 물탱크: 지붕의 둥근 실루엣 또는 기존 지상 탱크 슬롯의 외형 교체 후보이다. 지붕에 놓는 경우 D04 컷어웨이·캐릭터 가림에 함께 등록되어야 한다. 사다리는 등반 기능이 없고 배출관은 연결 기능이 없다.
- 터빈 크래들: `Y01` 작업 대상 첫 후보이며 기존 소형 산업 엔진과 역할을 구분한다. 열린 상단의 날개·축, 크래들 접지와 진입/관통축을 확인한 뒤 한 곳 또는 드문 두 곳에만 고려한다. 회전·상호작용 기능은 없다.
- 기계 전력 접속물: PC 전력 야드의 사람 설비 가까이에 둘 **고정된 점령 흔적** 후보이다. T2·PC 게이트·도로·스폰/위험 표시처럼 읽히는 위치는 제외한다. 적·포탑·전력 기능은 없다.
- 회수·침전조: E08/E10과 물가 사이의 건조지 후보에서 지형·접근을 실측한다. 열린 수조에 캐릭터가 갇히거나 BankGuard·교량·T3 접근을 침범하면 배치하지 않는다. 물 흐름·작동하는 배수관·침전 시뮬레이션은 없다.
- 앞·사선 위·뒤의 Tripo 미리보기로 시각 검사했다. 실제 치수·피벗·메시 연결성·UV·Unity 재질·콜라이더·가림·프레임 성능은 파일 수령 후 검증 대상이다.
- 추가 7종도 설정·생성·정면/사선/후면 화면을 기록했지만 이는 서비스 프리뷰다. 특히 포털 중앙 관통, 차양 하부, 터빈 열린 상단, 침전조 내부, 물탱크 받침/배관을 GLB로 다시 확인해야 한다. 후보 좌표는 설치 확정값이 아니다. 기존 건물 문, 12개 V33 게이트, 두 교량, B4/R8/W5 동선·가림과 원래 충돌체를 보존한다.
- 같은 녹·보수판 무늬를 너무 많이 반복하면 새로운 획일성이 생기므로 연속 복제 수량과 구역별 사용을 제한한다.

- 4종 모두 비공개, H3.1 HD, Ultra OFF, AI 강화 OFF, 2K 원본, PBR·조명 제거 ON, triangles. 기본 GLB 1K 내보내기를 권장하며, 1K 내보내기가 안 되면 2K 원본을 받아 Unity에서 제한한다. 이번에는 유료 후처리·업스케일·리토폴로지·재시도를 실행하지 않았다.
- 접합기둥: 각도가 다른 경계 접속용 **소재**다. 자동 범용 스냅 부품이 아니다. 기존 벽 끝단의 길이·캡을 가공하여 접속하고 면을 중첩시키지 않는다. 기단이 보행 공간을 침범하지 않게 한다.
- 게이트 어깨: 문짝이 아닌 **한쪽 경계 끝단**이다. 이름이 metal gate라고 나와도 길을 가로질러 닫는 게이트로 쓰지 않는다. 기존 열린 게이트 폭을 유지하도록 벽 쪽으로만 넣고, 실제 길이가 크면 끝단을 줄인다. 불투명 경계용이며 PC/YC 철망 시야를 불투명하게 바꾸지 않는다.
- 진료소 코너: 기존 회색 공장 외벽과 다른 미장·벽돌·청록 타일 및 깊은 창틀. 기존 직사각형 진료소의 실제 벽을 교체/분할해 접속할 수 있는 경우만 사용한다. 원래 창·문 위에 중첩 배치 금지. 실제 메시에서 창은 불투명이며 문/통행구가 아니다.
- 산업 벽 베이: 콘크리트 기둥·기단·인방과 들어간 벽돌면. 기존 무창 외벽의 **대체/접속** 후보이지 길을 막는 독립 장벽이 아니다. 같은 모듈을 모든 건물에 규칙적으로 반복하지 않는다.
- 치수명 2m/3m는 설계 의도이지 실제 GLB 실측값이 아니다. 앞·사선·뒤 프리뷰는 확인했으나 실제 크기·피벗·UV·콜라이더·가림·접합·Unity 성능은 다운로드 후 검증 대상이다.
- 고정 90° 담장 코너는 시안만 보관하고 모델링 제외했다. V33의 실제 경계 꺾임 대부분이 직각이 아니기 때문이다. 추가 폐허 저벽은 기존 재고와 중복되어 제외, 철망 끝단은 기존 에셋 대체 가능성부터 확인하도록 보류했다.
