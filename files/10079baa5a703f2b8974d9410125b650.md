# A맵 v0.8.1 중복 렌더 표면 정리 — 독립 검토

## 최종 판정

**요청 1의 보이는 동일 방향 공면 중복 제거는 PASS입니다.** 변경 전 208쌍, 3,321.0042㎡였던 동일 방향 공면 렌더 중복이 변경 후 0쌍, 0㎡가 되었습니다. 기준점, 충돌체, 배치 원천 데이터, 지면 높이와 도로 높이는 바뀌지 않았습니다.

**요청 2의 도로·지형 고도는 조사만 했습니다.** 현재 구현은 전체 지형이 올라가는 구조가 아니라 Y=0 평지 위에 0~12m 도로판과 건물 바닥을 올리고 그 아래를 기초로 채운 구조라는 사용자 지적이 맞습니다. 이번 변경에서는 지형과 도로 고도를 수정하지 않았습니다. 별도 조사 문서는 `TERRAIN_DIAGNOSIS.md`입니다.

## 검토 범위와 독립성

- 제작 전 저장된 prefab을 기준으로 별도 Unity 검증 프로젝트에서 수치를 확보했습니다.
- 수정본도 원본 프로젝트가 아닌 같은 검증 프로젝트에서 검사했습니다.
- 독립 검사는 논리 기준점, 충돌체와 외형 배치 원천 데이터를 해시로 비교하고, 실제 renderer triangle의 공면 교차 면적을 별도로 계산했습니다.
- `Generated_v08` 재질은 `_Surface: 0`, `_Cull: 2`인 불투명·뒷면 제거 재질입니다. 따라서 같은 방향으로 같은 위치를 차지하는 면은 Z-fighting 위험으로 실패 처리하고, 서로 반대 방향인 닫힌 박스의 접합면은 별도 정보로 분리했습니다.

- 반대 방향 닫힌 접합면: 386쌍 / 16,455.4121㎡ — 정보 항목, 실패 아님
- semantic anchor: 143개

- 도로 충돌 보행면 범위: 약 0m / 12m

주요 실제 중복에는 Y=0 지면과 남부 평면 도로·진입 연결로, 주요 건물 바닥과 내부 핵심실 바닥, 상부 landing과 상부 통로, 중계 공터와 진입 도로, 같은 높이의 도로 교차부가 포함됐습니다. 예를 들어 `GROUND_BASE`–`ROUTE_S0_S1`은 약 390.05㎡, `PARTS`–`CORE_G2`는 196㎡, `POWER`–`CORE_G3`는 168㎡, `CLINIC`–`CORE_G1`은 약 120㎡, `UpperLanding`–`UpperWalk_North`는 12㎡가 같은 방향·같은 평면에 겹쳤습니다.

## 실패 이력과 수치 오차 검증

중간 실패를 경고로 낮추거나 임계값을 올려 통과시키지 않았습니다.

1. 첫 전면 검사에서는 서로 반대 방향인 정상 박스 접합면까지 중복으로 합산했습니다. 실제 재질이 불투명·뒷면 제거임을 확인한 뒤, 동일 방향 공면과 반대 방향 접합면을 분리했습니다.
2. `OVERLAP_AFTER_ATTEMPT02.json`은 지면 band 경계 두 곳에 0.002461㎡가 남았다고 실패했습니다.
3. `OVERLAP_AFTER_ATTEMPT03.json`도 같은 두 경계에 0.002464㎡를 보고했습니다. 두 band의 원래 경계는 정확히 맞닿아 실제 면적 중복이 없으므로, 큰 월드 좌표에 float shoelace 공식을 적용할 때 생기는 상쇄 오차를 의심했습니다.
4. 교차 다각형을 pair-local 원점으로 옮기고 double 정밀도로 다시 계산했습니다. 임계값 0.001㎡는 바꾸지 않았으며, 최종 결과는 0쌍 / 0㎡였습니다.
5. 재삼각분할 뒤 strict 1mm 양자화 표면 해시는 달라졌습니다. 이를 그대로 무시하지 않고 `COVERAGE_DIAGNOSTIC.json`에서 변경 전 전용 prefab과 최종 prefab dependency hash를 기록한 뒤 연속 삼각면 검사를 수행했습니다.
6. strict hash상 변경 전 전용 sample 516개가 달랐지만, 516개 모두 같은 방향의 최종 삼각면에 1mm 이내로 실제 피복됐습니다. 미피복은 0개였고 최대 거리는 **0.00001706m, 약 0.017mm**였습니다. 따라서 이는 회전 벽과 재삼각분할의 양자화 경계 이동이며 실제 hole이 아닙니다. 최종 validator는 이 진단이 동일한 최종 prefab dependency state를 검사했는지도 함께 확인했습니다.

## 검사 한계와 후속 범위

- 독립 공면 scanner는 카메라에 노출될 수 있는 generated 외형을 대상으로 하며, 도로·건물 아래에 묻힌 이름상 `Foundation_` 지지대 renderer는 중복 수치에서 제외했습니다. 수정기는 이 지지대도 포함한 generated box 전체에 적용됐지만, 지지대 내부 공면 0개를 독립 수치로 주장하지 않습니다. 해당 지지대의 collider와 배치는 해시로 보존됐습니다.
- 반대 방향 접합면은 불투명·뒷면 제거 재질에서 두 표면이 같은 시야를 다투는 Z-fighting 조건이 아니므로 364쌍을 최종 정보로 남기고 실패 처리하지 않았습니다.
- 향후 외부 asset override prefab을 넣으면 그 새 메시의 중복은 자동으로 잘라내지 않습니다. 배치 후 같은 공면 검사를 다시 해야 합니다.
- 이번 PASS는 도로·건물·표식의 현재 높이를 승인한다는 뜻이 아닙니다. 지형 고도 개편, 빈 공간의 건물·식생 배치, 자연 사면과 옹벽 설계는 사용자 확인 뒤 별도 작업이어야 합니다.
