# SCAR 게임 장전 속도 미리보기

기존 9.033초 검토 영상을 현행 SCAR의 장전 시간에 맞춰 두 가지 속도로 만들었다. 기본 SCAR은 **3초**, 현재 외형과 같은 부품 구성을 가정하면 **약 3.53초**다. Unity에는 적용하지 않았다.

| 미리보기 | 게임 시간 근거 | 실제 영상 | 속도 |
| --- | ---: | ---: | ---: |
| 기본 SCAR | 3.000초 | 180프레임 / 60fps = 3.000초 | 원 영상의 약 3.01배 |
| 모델 A의 부품 구성 가정 | 3.528초 | 212프레임 / 60fps = 3.533초 | 원 영상의 약 2.56배 |

부품 구성 가정은 전술 개머리판 1.05배와 확장 탄창 1.12배를 적용하고, 나머지 7개 부품·성장·상태·개체 보너스는 장전 시간에 영향을 주지 않는 조건이다. 현재 플레이어 장비를 실측한 값은 아니다. 3.528초와 출력 3.533초의 차이는 60fps 출력에서 생기는 5.33ms다.

모든 포즈는 검증20의 실제 렌더 PNG에서 순서대로 선택했다. 메인과 독립 서브에이전트가 두 MP4의 전체 디코딩, 프레임 수, 기간, 선택 PNG 392개의 원본 일치와 순서를 확인했다. 독립 판정은 시간 미리보기 범위에서 PASS다. 동일한 포즈를 빠르게 보여 주며 새로운 공간 검증을 수행한 것은 아니다.

같은 8개 포즈의 전후 이미지와 비교·동작 순서 보드를 보존하고 실제 열람했다. 팔 동작과 기존 대기·탄창 낙하도 함께 빨라지는 영상이다. 모델·원키·Unity 코드와 실제 게임 장전 수치는 변경하지 않았다. 실게임 재생이나 탄창 물리 구현 검증으로 보지 않는다.

로컬 전달 영상: `Edel_SCAR_Reload_Base_3p00s.mp4`, `Edel_SCAR_Reload_ModA_3p53s.mp4`.
