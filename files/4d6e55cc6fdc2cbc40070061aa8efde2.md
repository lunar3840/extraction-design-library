# A 스테이지 Factory / Rusty 에셋 교체 v12

## 사용자 지시와 범위

- Abandoned Factory (Lite)로 A 스테이지 기존 건물의 외형과 내부를 교체합니다.
- Abandoned Rusty Vehicles and Props - 3d Game Ready Mini Set로 기존 차량을 교체합니다.
- Rusty Barricade - with PBR materials (2K/4K)를 중간 구간에 배치합니다.
- 기존 맵 구조·진입/탈출·중계·잠금 의미를 유지하고, 새 시각 에셋도 별도 프리팹으로 교체 가능하게 만듭니다. B 스테이지, 전투/퀘스트/파밍 보상 규칙은 변경하지 않습니다.

## 기획 의도와 변경 전 상태

기존 54개 건물은 기본 형태의 벽·지붕으로 구성되어 산업 정비지구의 재질 및 실내 작업 공간을 읽기 어려웠습니다. 차량도 임시 형태였습니다. 기계 점령 후 방치된 산업 시설의 외관과 작업·적재·설비 구역을 시각적으로 구분하는 것이 목적입니다. 인간 거점 상주/철수 시스템을 새로 추가하지 않습니다.

변경 전 전체 A 씬과 프리팹을 backup 폴더에 보관하고, 원본 상태에서 아래 6개 고정 시점을 촬영했습니다. 사후 재구성 이미지가 아닙니다.

## 변경 내용과 방식

- 건물 54개: 기존 v08 랜드마크 5개, v09 부속 건물 10개, v11 밀도 보강 건물 39개에 Factory 모듈을 적용합니다.
- 건물 외벽·창·바닥·지붕과 실내 캐비닛·배럴·설비·잔해를 구성합니다. 시각 프리팹과 단순 충돌은 분리하며 기존 출입구·의미 앵커·지붕 가림 계약을 유지합니다.
- 중정비동 내부는 모터 정비, 부품 분류, 전기 설비의 세 작업 구역으로 구성합니다. 낮은 L자 벽, 캐비닛, 다리 있는 조립대, 모터, 설비함을 묶되 출입구-중앙 십자축과 북동쪽 상부 코어 계단 접근을 비웁니다. 작업 구역 전체를 막는 큰 투명 충돌은 사용하지 않고 실제 벽/가구 면적에 맞춘 15개 충돌로 구성합니다.
- 차량 16개: 8개 승용차, 4개 밴, 4개 기존 트럭 슬롯. 제공 에셋의 실제 차종은 승용차/밴이므로 트럭 슬롯은 밴 모델을 확대하여 대체했습니다. 독립적인 트럭 모델을 만들었다는 의미가 아닙니다.
- 바리케이드 12개를 6개 쌍으로 배치합니다. 중앙 통행 간격 기준은 3.5m이며 출입구/스폰/탈출·기존 고형물 간섭을 검사합니다.
- Standard 계열 소스 재질은 프로젝트 URP용 복사 재질로 변환합니다. 공급자 원본을 덮어쓰지 않습니다.
- G1~G4 및 S-A의 보라색 개발용 바닥 표시는 빈 시각 프리팹으로 교체합니다. 해당 면은 셰이더 오류가 아닌 MarkerGate 표시였습니다. 논리 앵커/진행 규칙은 남깁니다.
- 기존 R 진입점은 여전히 비활성입니다. B4–R8의 약 62m 간격과 W5 공유 문제는 배치만으로 해결되었다고 간주하지 않습니다.
- 추가된 내부 충돌로 길찾기 탐색 노드가 소진되는 현상을 진단했습니다(저수준 query OutOfNodes 확인). 현재 A의 NavigationTileSize를 128→512로 조정해 타일 경계 세분화를 줄였습니다. 0.12m voxel과 에이전트 반경·높이·등반·경사 기준은 동일하며 문 정밀도는 낮추지 않았습니다. 다른 기존 맵은 기본값 128을 유지합니다. 타일 진단에서 4기본 진입×7탈출 경로는 128일 때 26/28, 256일 때 27/28, 512일 때 28/28 완주했습니다.
- 실내 가구는 현재 배경/충돌 구성입니다. 새 파밍 상호작용이나 보상 테이블을 추가한 것은 아닙니다.

## 검증 상태

최종 배치 독립 검증은 PASS 1472 / FAIL 0입니다. 기본 219개 + 중정비동 작업구역 접근 3개의 총 222개 경로가 완주했고, 0.8×2m 플레이어 캡슐 96개 경로, 지붕 표시·숨김·복원 58개 사례가 통과했습니다. 원문 보고서를 메인과 독립 검증 에이전트가 각각 검토했습니다.

실제 Play에서도 서측 부품 보관 건물 외부→내부→외부로 CharacterController를 이동하여 왕복했습니다(진입 78, 복귀 77회 이동 시뮬레이션). 입구 바깥에서 지붕 1/1, 안에서 0/1, 다시 밖에서 1/1로 복원되어 PASS했습니다. 이는 대표 건물 한 곳의 실제 이동 보완 검사이며 54개 건물 전체를 수동으로 장시간 플레이한 것은 아닙니다. 프레임 속도/전체 성능 벤치마크는 별도로 수행하지 않았습니다.

A 씬과 리소스 맵 프리팹을 저장했고, 테스트 종료 후 편집 모드로 복귀합니다. 원래 지형/도로/앵커와 R 비활성 정책은 유지합니다.

- `VALIDATION_BEFORE.txt`: 변경 전 219개 경로, 93개 플레이어 캡슐 경로, 58개 지붕 가림 검사 통과.
- `VALIDATION_AFTER.txt`: 최종 적용 후 독립 검사 결과.
- `NAVIGATION_DIAGNOSIS.txt`, `NODE_POOL_DIAGNOSIS.txt`: 추가 구조물 이후 B1→X6/X7의 경로 탐색 예산 소진 원인 분석. 큰 노드 풀에서는 연결됨을 확인.
- `PLAY_VALIDATION.txt`: 실제 Play 모드 출입 이동 및 지붕 표시 상태·복원 PASS.
- `after_game_outside.png`, `after_game_inside.png`, `after_game_outside_restored.png`: 실제 플레이 카메라의 상태별 추가 렌더. HUD 오버레이를 포함하지 않는 카메라 출력입니다. 전후 비교 6쌍을 대체하지 않습니다.
- 첫 Play 자동 검사는 대기 시간 초과했습니다(`PLAY_INITIAL_TIMEOUT.txt`). 후속 검사에서는 테스트 중에만 백그라운드 실행을 켜고 일시정지를 해제하여 완료했으며, 테스트 종료 때 백그라운드 실행값을 복원합니다.
- `SAVED.txt`: A 씬/프리팹 저장 완료 기록.
