# A맵 v0.9 연속 지형·임시 환경 — 독립 검토

## 현재 판정

**분리된 Unity 검증 프로젝트의 최종 승인본은 정적·물리·NavMesh·Play 검사를 PASS했고, 같은 승인본의 원본 프로젝트 파일 설치도 PASS했습니다.** 기존처럼 평지 위에서 도로판만 올라가는 구조를 퇴역시키고, 도로 높이를 주변 지반으로 이어 주는 520×400m 연속 지형으로 교체됐습니다. 기존 주요 거점의 위치와 수량은 유지됐으며, 보조 건물·폐차와 산업 오브젝트·나무·바위·식생 구역이 교체 가능한 임시 슬롯으로 추가됐습니다.

검증 프로젝트 실행 결과와 원본 설치 결과는 서로 다른 범위입니다. 아래 정적·NavMesh·`PlayerMotor` 수치는 검증 프로젝트의 최종 prefab을 대상으로 한 결과입니다. 원본 프로젝트에서는 승인 파일을 설치하고 해시·씬 보존만 확인했으며 Unity Play를 실행하지 않았습니다.

## 사용자 요청과 구현 방식

- 기존 `GROUND_BASE`, `GROUND_FOUNDATIONS`, `WATER_CHANNEL`, 일반 Route와 0m 기준 `MAP_BOUNDARY`의 외형·충돌을 비활성화했습니다.
- 진입·탈출 표식과 중계 공터의 기존 바닥 충돌도 비활성화하고, 새 연속 지형을 해당 구간의 단일 보행 충돌 소유자로 사용했습니다.
- 새 지형은 2m 격자에서 생성한 연속 메시입니다. 일반 도로는 별도 높이 슬래브가 아니라 같은 지형 메시의 재질 구역이므로, 도로의 0~12m 계획 높이가 주변 사면으로 이어집니다.
- 기존 주요 건물 5곳과 보조 건물 10곳에는 평탄 제약과 완충 사면을 적용했습니다. 기존 건물 바닥 아래로 지형을 내려 노출 중복면을 피하고, 문밖 접근부는 보행 높이에 맞췄습니다.
- 수로 바닥은 -2m, 물 시각면은 -0.825m로 분리했습니다. 수로 바닥은 NavMesh 수집에서 제외했고, 교량 개구부를 제외한 양안에는 지형 높이를 따르는 물리 bank guard를 배치했습니다.
- 임시 환경은 semantic slot, collision root, replaceable visual root를 분리했습니다. 최종 에셋 교체 전 단계이므로 실제 파밍 보상, 적 생성, 은폐 판정은 추가하지 않았습니다.

## 중간 실패와 수정 이력

1. 첫 검사에서 도로·건물 제약 주변의 10m 표본 단차가 기준을 넘었습니다. route shoulder와 주요 건물·중계 완충 반경을 확대했고, 최종 최대 변화는 5.167m로 통과했습니다.
2. 물 메시가 아래쪽 winding으로 보이는 문제가 발견됐습니다. 최종 실제 mesh에서 첫 삼각형 cross Y와 모든 normal Y가 양수임을 확인했습니다.
3. 보조 건물 `E_MAINT_GARAGE` 문밖 capsule이 벽에 걸렸습니다. 문밖 anchor 위치를 바로잡고 실제 NavMesh·PlayerMotor 출입을 다시 통과했습니다.
4. 보조 건물 바닥·벽과 bank·boundary 모서리의 같은 방향 공면 63쌍을 수정해 0쌍으로 만들었습니다.
5. 시각 교체 검사 자체가 override root의 강제 이름 변경을 고려하지 않아 6건을 잘못 실패 처리했습니다. 루트 이름 대신 복제된 marker child와 renderer mesh를 검사하도록 교정했습니다.
6. bank 중심점 생략 방식이 교량 rail 바깥에 물리 틈을 남겼습니다. bank 선분을 rail 경계에 맞춰 절단하고 8개 양안 접합을 모두 gap 0m로 확인했습니다.
7. 재생성 중 persistent 식생 mesh 파괴 시도를 Unity 오류 수집으로 발견했습니다. 제작 코드의 asset 수명 처리를 수정하고 최종 오류 0건을 확인했습니다.

## 제한과 후속 범위

- 지형은 최종 조형 에셋이 아니라 2m grid 기반의 임시 연속 메시입니다. 지형 전체가 도로 높이를 따르는 구조와 통행을 검증하기 위한 단계이며, 최종 절벽·토질·배수로·옹벽 아트는 별도입니다.
- 위험 진입 8곳은 물리 위치만 보존된 비활성 후보입니다. 합의한 지역 해금 기반의 진입 후보 확장·저장 로직은 이번 환경 작업에 포함되지 않으며, 장비 가치 기반 해금으로 변경하지 않았습니다.
- 보조 건물의 loot anchor는 교체 가능한 파밍 위치 표식입니다. 아이템 테이블, 적 배치, 엄폐·은폐 시스템을 구현했다는 뜻이 아닙니다.
- 임시 환경의 개별 visual prefab을 최종 에셋으로 교체하면 새 모델의 피벗·크기·문 위치가 달라질 수 있습니다. 교체 뒤 도로 배제, collider penetration, 문턱, 시야와 공면 중복 검사를 다시 해야 합니다.
- 반대 방향 접합면 622쌍은 현 불투명·뒷면 제거 재질 조건에서만 비깜빡임 정보 항목입니다. 양면·투명 재질로 바꾸면 재검사가 필요합니다.
- 원본 씬을 강제로 열거나 저장하지 않는 파일 설치 방식을 사용합니다. 원본 프로젝트에서의 import·compile·Play 실행 여부는 설치 영수증의 실제 값으로만 기록합니다.
