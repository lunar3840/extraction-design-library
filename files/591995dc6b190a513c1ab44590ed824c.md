# 총기 모딩 참고 조사

- 조사일·접근일: **2026-10-20 (KST)**. 아래 모든 링크의 접근일은 동일하다.
- 범위: 델타포스의 부품 분류와 선택 구조, Escape from Duckov(덕코프)의 실제 부품 데이터와 성능 축을 참조하여 **현재 익스트랙션 게임**의 모딩 설계에 적용할 근거를 정리한다.
- 이 문서는 조사와 제안이다. 다른 게임의 규칙을 이 프로젝트의 확정 규칙으로 가져오지 않으며, 외형·런타임·에셋을 수정하지 않았다.
- 아래의 **공식 확인**, **커뮤니티 추출/관찰값**, **우리 게임 제안**은 서로 다르다. 제안 수치는 델타포스나 덕코프의 실제 수치로 인용하면 안 된다.

## 1. 출처 신뢰도와 현 버전 확인 한계

델타포스는 공식 Weapon Assembly 페이지와 공식 배포사 Garena의 패치를 우선 확인했다. 이벤트 페이지의 개별 수치는 과거 이벤트 당시 자료이며, 2026년 현행 전체 부품 목록·밸런스의 보증으로 사용하지 않는다. 공식 Garena 패치는 해당 지역·해당 모드의 변경 이력이다. PC/모바일, Operations/Warfare, 지역별 수치가 항상 같다고 가정하지 않는다.

덕코프는 공식 Steam 공지에서 무기 밸런스 축과 최근 슬롯 변경을 확인했다. 세부 부품은 게임 파일을 조사했다고 밝힌 커뮤니티 데이터베이스의 관찰/추출 결과를 참고했다. 이 조사에서 현재 덕코프 실행 파일이나 게임 내 툴팁을 직접 대조하지 않았으므로, 커뮤니티 수치를 **현 버전 공식 검증치**라고 부르지 않는다. 사이트의 `v1.27.0` 표시는 게임 데이터 빌드라고 확인되지 않았다.

확인된 불일치:

- [공식 Steam 공지](https://steamcommunity.com/app/3167020/announcements/)의 2026-07-01 Update 2.3.30은 VSS를 20발·대미지16.5로 변경했다. 일부 팬 자료는 여전히 15발·대미지14를 표시한다. 따라서 팬 자료의 크롤링 날짜가 최근이어도 내용은 오래됐을 수 있다.
- Rifle Quick Magazine II #544는 [커뮤니티 추출 DB](https://escapefromduckov.net/items/magazine-ar-ads-2)에서 재장전시간 -30%, 이동계수 +5%, ADS 분산 회복 +8%를 표시하지만, [별도 raw-data 재게시 사이트](https://www.duckescapefromduckov.com/en/items/attachments/magazine_ar_ads_2)는 재장전 -20%와 ADS시간 -20%만 표시한다. 어느 값을 현행 정답이라고 확정하지 않았다.
- Rifle 4x Scope #568의 [추출 DB](https://escapefromduckov.net/items/scope-ar-4x-1)는 Aiming Range를 **Add +1.36**으로 표시한다. [팬 아카이브](https://www.escapefromduckov.com/archive/items/568)는 같은 항목을 +136%로 표시한다. 고정 가산과 비율 가산의 구분을 잃으면 완전히 다른 결과가 된다.

## 4. 우리 게임용 설계 제안 — 첫 튜닝안

아래 숫자는 모두 **우리 프로젝트용 제안**이며 검증·튜닝 대상이다. 현 게임 기본 수치가 유지된 상태에서 의미 있는 선택을 만들기 위한 상대량이다. 외형을 바꾸지 않는 이번 범위에서는 부품 장착 메시 생성·총기 프리팹 교체 없이 데이터·슬롯·UI·실제 계산을 우선 구성할 수 있다.

킬플래시의 반사광 억제, 열상·야시장치, 바이포드의 자세 조건, 대형 탄창의 외형 변화는 해당 게임 기능과 외형 작업이 실제로 존재할 때 후속 단계로 연결한다. 이름만 갖춘 부품에 실제로 없는 기능을 설명하지 않는다. 대미지·관통력 증가는 탄약 선택과 중복되는 만큼 첫 모딩 단계의 보편적 보너스로 부여하지 않는 것을 제안한다.

## 5. 실효 수치와 검증 제안

델타포스의 추상 점수를 그대로 복제하기보다, UI에는 비조준/조준 분산, 수직/수평 반동, 조준시간, 이동속도, 장탄수, 재장전시간, 사거리, 탄속, 총성 감지거리, 중량을 현재값 → 장착 후 값으로 보여 준다. 유리한 방향이 서로 다르므로, 시간·분산·반동은 감소가 이득이고 장탄·사거리 등은 증가가 이득이라는 표시를 일관되게 처리한다.

권장 산식은 기본값과 부품 보정의 합성 방법을 데이터 타입으로 구분하고, 실효값을 별도 계산하는 것이다. 예를 들어 비율 보정은 `base × (1 + sum(percentModifiers))`, 고정 보정은 그 뒤 더하는 식으로 프로젝트에서 한 번 정의할 수 있다. 이는 **우리 제안 산식**이며 덕코프의 공식 산식이 아니다. 최저 조준시간·최저 분산·이속 상한은 현 게임 기본값/플레이테스트를 보고 정한다. 탄창 변경은 이미 든 탄약을 생성하거나 버리지 않으며 초과분의 보관/이전 정책을 먼저 정한다.

확인해야 할 결과:

1. 같은 총과 탄약으로 기본/제어/기동/비조준/소음 구성을 비교하여 실제 탄착·조준 전환·이동·재장전·청음이 UI 수치와 일치하는지 본다.
2. 소음기는 사거리 안의 청각 감지를 줄이되, 이미 시야로 발견한 적이나 탄착/피격 반응까지 지우지 않는다.
3. 플래시·레이저는 꺼짐/켜짐의 계산과 표시가 일치해야 한다. 노출 불이익을 설명한다면 적이 실제 보이는 광선/점/조명 원인을 인식하는 기능도 함께 있어야 한다.
4. 저장·재접속·무기 교체·부품 해제 후에도 총별 장착 상태와 계산이 유지되고, 중복 보정/누적 오염이 없어야 한다.
5. 단일 부품 또는 모든 슬롯을 채운 구성이 모든 지표에서 최고가 되지 않는지, 확장탄창과 퀵탄창 및 안정/경량 개머리판의 선택이 실제로 갈리는지 비교한다.

## 6. 조사에서 확정하지 않은 것

- 델타포스 전 부품의 현행 수치, 레이저 중첩·활성 조건의 정확한 최신 배율.
- 덕코프 현 실행 파일과 커뮤니티 DB 사이의 정확한 버전 대응, 자료 간 수치 불일치의 원인.
- 우리 프로젝트의 부품 희귀도·가격·드롭률·해금 문턱·경제 밸런스. 다른 게임 가격을 현재 게임 가격으로 가져오지 않는다.
- Unity 적용 완료 여부와 성능/플레이 검증 결과. 이 조사 문서만으로 구현 완료를 주장하지 않는다.
