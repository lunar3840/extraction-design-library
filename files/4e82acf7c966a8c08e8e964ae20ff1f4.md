# A맵 V33 — 시설 울타리·출입구 기반 도면 재설계

## 사용자 지시와 범위

V32의 짧고 띄엄띄엄 놓인 담장은 시설 울타리로서 의미가 약하므로, 연결된 경계에 맞춰 다시 설계한다. 이번 작업은 도면 변경만이며 Unity 실행·변경·배치를 하지 않는다.

## 변경 전 상태와 보존

실제 수정 시작 전에 V32 최종 총괄도와 서측 상세도를 `before_overview.png`, `before_west_detail.png`로 복사했다. 대화 내 도면 검토 화면도 `before_visual_overview.png`로 보관했다. 원본 V32 폴더와 HTML은 수정하지 않는다. 이것은 기존 도면의 보존본이며 현재 게임 캡처나 사후 재구성본으로 가장하지 않는다.

기존 V32의 21개 벽은 시설 경계보다 독립 장애물로 읽히는 부분이 많았다. 특히 야적장 일부 벽은 4m, 북측 일부 벽은 약 5m로 줄어 있었다. 도면 경로선을 유지하는 데 치우쳐 담장의 기능이 약해진 문제다.

## 메인 기획

- 시설의 소유 범위와 연속 경계를 먼저 정하고, 출입구를 정한 뒤 안팎 접근로를 다시 설계한다.
- 진료소 후정, 공구 분해·반출 작업마당, 전력 동측 설비마당, 부품창고 반입마당, 차량 분해 야적장에 시설 단위의 경계를 둔다.
- 건물 외벽을 경계 일부로 쓰며 담장 끝을 외벽에 연결한다. 외벽이 아닌 곳의 틈은 정문·서비스 출입·파손 구간으로 명시한다.
- 문은 도면에서 상시 열린 공간이다. 새 해금 조건·잠긴 게이트·퀘스트 잠금을 추가하는 안이 아니다.
- 철망과 불투명 담장의 표현·시야 기능을 구분한다. 실제 시야 차단과 전투 효과는 Unity 단계의 검증 대상이다.
- 시설끼리 담장을 이어 맵을 아홉 방으로 나누지 않는다. 시설 바깥 대로·샛길과 여러 접근을 남긴다.
- 생활 폐허의 잔존 담장은 파괴된 구조물이므로 분절 형태를 허용한다.
- B/X/T 좌표, 수로, 교량, 주요 랜드마크와 R 비활성 정책은 유지한다. B4/R8의 플레이 경험 차별화 완료를 주장하지 않는다.

## 최종 변경 및 확인 결과

- 69개 건물의 군집 구성을 바탕으로 5개 시설의 연속 경계를 작성했다. 건물 외벽·32개 담장/철망 구간과 12개 상시 열린 문·파손 틈으로 연결하며, 생활 폐허의 독립 잔존 담장 3개는 별도로 유지했다.
- 정문은 9~10m, 측문은 4~5m, 파손 틈은 3~4m로 계획했다. 문 잠금이나 새로운 해금 조건은 추가하지 않았다.
- 담장을 먼저 연결한 뒤 대표 경로 27개를 수정했다. 시설 외부 우회와 내부 마당 진입을 분리했으며, 구역 전체를 격자로 폐쇄하지 않았다. 이 안은 모든 비도로 이동을 막는 설계가 아니다.
- 후정 경계에 맞춰 N04/N08/N07, 차량 진입부 C02 등 소형 건물 및 설비 위치를 조정했다. 기존 V32 건물을 추가 중복 설치하는 안이 아니라 재배치안이다. 상세 변경 목록은 PLAN.json의 adjustments_v33에 있다.
- 메인 확대도 검토에서 EW4/EW6 설비 중복을 발견했다. EW6을 분리 이동하고 검증기에 고체 상호 겹침 검사를 추가하여 재검증했다. 초기 통과 결과를 최종 판정으로 사용하지 않았다.
- 독립 검사 최종 결과: 5개 경계의 연속성과 실제 외벽 접속, 12개 출입구의 내외부 접근, 문 전체 가상 봉합 시 내외 분리 12/12, 문 하나 가상 봉합 시 대체 접근 12/12 통과. 가상 봉합은 검사용이며 게임의 문 잠금 기능이 아니다.
- 0.5m 캐릭터 반경을 가정한 각 출입구 전후 직결 접근 충돌 0, 대표 경로 전폭 간섭 0, 자가교차/반복교차 0, 고체 상호 중복 0. 고체 상호 중복 검사는 0.1m 국소 래스터로 수행했다. B/X/T 14개와 두 교량 양끝의 2D 연결 유지.
