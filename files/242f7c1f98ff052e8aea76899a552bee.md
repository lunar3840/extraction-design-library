# 잡동사니 모델 품질 보강 및 실제 썸네일

작업일: 2026-10-19. 대상: `C:/UnityProject/escape`.
상태: Tripo 4종 생성·게임용 후처리·원본 Unity 적용·아이콘·실제 바닥 드롭/회수 검증 및 최종 사진 확인 완료.

## 사용자 지시와 의도

아이템의 실제 아이콘 썸네일과 잡템 모델을 제작하고, 직접 만든 모델의 품질이 부족하면 Tripo를 사용한다. 이미 만든 41개 아이템 모델/썸네일 중 품질 보강이 필요한 품목을 선별하고, 최종 3D 모델을 게임과 아이콘에 함께 사용한다.

## 변경 전과 문제점

32개 잡템의 기본 모델은 각기 구별되는 형태를 갖췄으나 로봇 팔은 관절/구동부가 단순하고, 향수는 각진 상자처럼 보였다. 폐탄피 주머니의 천 형태도 충분하지 않았다. 발전기 부품은 코일과 축으로 인식 가능했지만 표면과 하우징의 상세 표현을 보강하기로 했다. 금괴와 장갑판에는 공유 Ingot 메시의 면 순서 오류가 확인되었다.

`before/before_models_sheet.png`와 `before/before_<아이템ID>.png` 6장은 교체 전에 저장한 실제 기존 모델 렌더다. 사후 재구성본이 아니다. `before/LootItemVisuals.cs`에 해당 시점 소스도 보존했다.

## 실제 제작 방법

- Tripo Studio의 로그인된 계정에서 H3.1 모델, 비공개 설정으로 로봇 팔·발전기 부품·폐탄피 주머니·향수병 4개를 텍스트로 생성했다. 프로젝트 파일이나 사용자 자료를 업로드하지 않았다.
- 각 30크레딧, 총 120크레딧을 사용했다. 생성 전 1,180, 생성 후 1,060크레딧이며 추가 결제는 하지 않았다. 정확한 프롬프트와 생성 페이지는 `GENERATION_MANIFEST.json`에 기록했다.
- 실제 내보낸 GLB는 1K 텍스처를 포함한다. 이를 2K 이상 원본으로 표현하지 않는다. 원본 파일을 `source/`에 보존하고 후처리 결과를 `processed/`로 구분한다.
- Blender에서 UV와 재질 연결을 유지하며 게임용 메시를 정리했다. 로봇 팔은 7,685삼각형을 유지했고 발전기 7,480→5,000, 주머니 7,810→4,999, 향수 7,376→5,000삼각형으로 줄였다. 같은 조명/카메라에서 축소 전후 정면·측면·후면·사선 4방향을 비교했다.
- glTF의 노멀, 기본색, 금속/거칠기 지도를 확인한 뒤 Unity URP 재질에 연결한다. 금속 B 채널은 R로, 거칠기 G 채널은 반전하여 매끄러움 A로 변환하며 원본 계수를 적용한다.
- 외부 모델은 `Resources/LootArt/Overrides/<ID>.prefab`으로 연결한다. 아이콘과 바닥 드롭은 같은 모델을 사용하고, 해당 외부 에셋이 없을 때는 기존 직접 만든 모델을 사용한다.
- 금괴/장갑판은 면 방향을 고치는 과정에서 공유 꼭짓점 배열이 뒤집히던 오류를 수정했다. 캡용 배열을 복제하고 메시의 GPU 데이터를 명시적으로 갱신해 저장된 메시와 렌더가 함께 바뀌게 했다. 이 두 품목은 외부 생성 모델로 교체하지 않았다.

## 후처리 및 Unity 통합 결과

- 4개 FBX 재가져오기에서 UV·노멀·재질 수·유효 좌표·삼각형 수 검사를 모두 통과했다. 경계 오차는 최대 1.64×10⁻⁷이다. 원본 JPEG를 PNG로 추출한 12개 텍스처는 디코딩 후 픽셀이 일치했다.
- 최적화 전후 실루엣 교집합 비율의 최솟값은 로봇 팔 100%, 발전기 99.15%, 주머니 99.60%, 향수 99.90%였다. 실제 4방향 렌더를 열어 확인했으며 `processed/PROCESSING_NOTE.md`, `review_summary.json`, `fbx_roundtrip_summary.json`에 근거를 보관했다.
- 주머니는 사선에서 열린 입구와 실제 속이 빈 탄피가 보인다. 정면 Tripo 화면만 보면 닫힌 주머니처럼 보이지만 원본 모델에 탄피가 있다. 추가 탄피 장식은 최종 모델에 넣지 않았다.
- 최초 Unity 가져오기는 기술 검사만 통과했으나 FBX의 원래 축 회전을 제거해 물건이 누워 보였고, 금괴 아이콘은 이전 GPU 메시를 보여 주었다. 해당 실패 화면은 `initial_unity_import/`에 보존했다. FBX의 원래 변환을 보존하는 바깥 정규화 객체와 메시 업로드 수정 후 다시 가져왔다.
- 14:54:31의 최종 Unity 통합에서 4개 외부 Resources 프리팹, URP 기본색/노멀/금속·매끄러움 연결, 방향·크기, 충돌체 없음, 삼각형 제한을 모두 통과했다. `UNITY_INTEGRATION.txt` 참조. 로봇 팔 최대 크기 0.73m, 발전기 0.46m, 주머니 0.22m, 향수 0.18m다.
- 최종 6개 아이콘과 전체 41개 접촉 시트를 직접 열어 확인했다. 금괴의 닫힌 옆면과 장갑 조각의 층, 똑바로 선 외부 모델이 정상이다. 금괴 메시의 12삼각형은 모두 바깥 방향/볼록성 검사를 통과하고 체적은 0.81333332다.
- 검토한 에셋 101개 파일(메타 포함)만 설치 대조했고 그중 88개가 추가/변경됐다. 설치 전 파일은 `before/installed_assets/`, 전후 해시는 `INSTALLED_ASSET_HASHES.json`에 보관했다. 이번 설치 범위에는 `item_017`~`item_020` 탄약 파일이 없다.

외부 생성 4종은 직접 만든 나머지 모델보다 표면 표현이 사실적이다. 현 단계에서 사물 식별력과 바닥 드롭 용도를 충족하지만, 전 품목이 동일한 미술 완성도/표면 양식에 도달했다고 주장하지 않는다. 원본과 제작 경로를 보관해 후속 미술 조정을 할 수 있다.

## 독립 검토

`FINAL_ART_AUDIT.txt/json`: 실제 production의 41개 512px 투명 아이콘, 32개 잡템, 4개 외부 모델, 프리팹·재질·텍스처 참조, 설치 해시와 금괴 토폴로지를 별도 담당자가 재검사해 23,375개 항목, 실패 0을 확인했다. 6개 최종 아이콘과 `FINAL_ART_COMPARISON.png`도 직접 열어 검토했다.

최초 검사의 `Runtime icon lookup mismatch` 1개는 게임 오류가 아닌 검사식의 변수명 가정 오류였다. 별도 총기 작업이 Ammo에만 적용되는 `iconId` 별칭을 도입했는데 옛 `item.ItemId` 표기만 허용한 검사였다. 실제 카탈로그의 잡템 32개는 모두 Other이며 Ammo 분기에 들어가지 않고 원래 ID와 같은 Resources 경로를 사용한다. 게임 소스는 수정하지 않았다. 실패 보고서는 `FINAL_ART_AUDIT_initial_false_positive.txt/json`으로 보존했다.

4개 외부 모델의 금속 반사는 강하며 작은 세부는 32px에서 사라진다. 주머니 안 일부 금색 형상은 완성 탄약처럼 보일 수 있고, 향수병은 투명 유리 셰이더가 아닌 불투명 보라색 PBR 재질이다. 이 한계와 나머지 단순화 모델과의 표면 표현 차이를 검토 기록에 남겼다.

## 실제 실행 검증

15:05:58의 최종 Unity 9개 검사 그룹은 모두 통과했고 A맵 배치 검사는 1,588개 항목, 실패 0이었다. 최종 아트를 포함한 실행본의 15:10:35 검사에서 네 모델 모두 실제 Resources 메시로 생성되어 버리기·회수·원래 UID/수량 복원을 통과했으며 이후 탈출·저장·판매·구입·연구 소비도 통과했다.

첫 상세 사진 중 발전기는 카메라가 캐릭터 몸 안에 들어가 모델이 가려졌다. 단일 물리 광선 검사만으로 가림이 없다고 판정한 결과를 시각 승인으로 취급하지 않았다. 첫 사진은 `initial_ground_capture/`에 보존했다. 촬영 동안만 플레이어/동료의 외형·갑옷·무기 렌더러를 숨기고, 카메라를 전체 캐릭터 메시 경계 밖에서 선택하도록 바꾼 뒤 재촬영했다. 바닥·드롭 물건·조명은 그대로이며 원래 렌더러/카메라/인벤토리 상태의 복원도 검사했다. 이 처리는 검증용 하네스에만 있고 게임 소스에는 없다.

15:20:52 최종 실행에서 위 상세 촬영/상태 복원, Tripo 네 모델의 실제 버리기·동일 메시·UID/수량 회수, 기존 수색→탈출→저장/로드→판매·구입→연구 소비가 모두 통과했다. 상위 폴더의 `after_ground_trade_a_006_model.png`, `after_ground_trade_b_023_model.png`, `after_ground_trade_c_018_model.png`, `after_ground_trade_b_009_model.png`를 직접 열어 모두 가림 없이 보이는지 확인했다. 녹색 바닥은 버리기 검사 전용 임시 바닥이다. 최종 `after_<ID>.png` 6장과 `before/before_<ID>.png` 6장의 대응 및 매니페스트를 확인했다.

## 증빙과 확인 범위

`after_tripo_generated.png`는 Tripo에서 생성된 향수병과 네 후보의 실제 화면이다. `after_tripo_pouch_raw.png`는 주머니 원본 화면이다. 화면에 남아 있는 입력창 문장은 마지막 입력값이며, 선택한 이전 생성물의 원래 프롬프트로 간주하지 않는다. 개별 프롬프트/생성 ID 대응은 매니페스트로 확인한다.

게임 소스의 문법 검사, 파일 존재, 투명도 검사만으로 모델 품질을 승인하지 않는다. Unity 재질/크기/바닥 접지, 실제 게임의 버리기·회수와 작은 썸네일을 육안으로 확인한 뒤 최종 결과를 기록한다.

전체 파밍 구현의 수색·탈출·경제·연구 검증은 상위 `CHANGE_RECORD.md`와 구별해 읽는다. 이 보강은 잡템 외형에 한정하며, 동시 진행 중인 총기/탄약의 카탈로그와 아이콘을 덮어쓰지 않는다.
