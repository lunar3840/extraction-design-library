# A맵 중정비동·남측 야드 현실감 개선 시험 구역 (V16)

## 사용자 지시와 범위

그래픽을 더 현실적으로 만들기 위한 분석 후 사용자가 “한번 해보겠어?”라고 구현을 승인했다. 중정비동과 인접 남측 야드를 첫 시험 구역으로 삼는다. 맵 전체 재제작, 캐릭터 비율·외형 변경, B맵 변경, 진입점 이동은 포함하지 않는다.

## 기획 의도와 변경 전 문제

현재 벽의 높은 명암 대비와 반복 무늬, 건물 앞의 균일한 잔디, 큰 빈 공간과 성긴 소품, 표면 재질의 구분 부족을 줄인다. 실제 플레이 카메라의 가독성과 기존 통행·층별 가림 기능을 유지한다.

## 변경 전 확보

- 현재 편집 장면 5시점 및 실제 플레이 14시점, 1600×1000.
- 실제 플레이 이동 검사 7곳 통과: 정문, 좌우 2층 계단, 좌우 지하 계단, 비밀 경사로, 남측 야드.
- `before_PLAY_VALIDATION.txt`에 카메라·플레이어 위치와 검사 결과 저장.
- 원본 장면·리소스 프리팹·라우터 소스는 `backup/`에 보존. 변경 전 화면은 실제 현재 상태이며 재구성본이 아니다.

## 구현 방식

제작은 재질·지면 / 소품 배치로 분리하고, 독립 에이전트가 보호 대상 비교 및 회귀 검증을 작성한다. 메인이 조명·색보정·구역 전환, 통합, 실제 화면과 검사 결과를 검토한다. 원본 재질을 직접 덮어쓰지 않고 LookV16 복사본을 사용한다.

## 대응 화면

`before_`와 `after_`의 동일 접미사가 같은 시점이다.

- `overview`, `hall_exterior`, `hall_close`, `south_yard`, `hall_interior`: 편집 장면 고정 카메라.
- `game_main_entrance_start/end`, `game_west_up_to_2F_start/end`, `game_east_up_to_2F_start/end`, `game_west_from_B1_start/end`, `game_east_from_B1_start/end`, `game_secret_descent_start/end`, `game_south_yard_start/end`: 실제 플레이 카메라. 마우스 시선 이동을 0으로 고정.
- 조명·재질은 변경 대상이므로 전후의 차이에 포함된다. 시점·해상도·캐릭터 외형은 고정한다.

## 실제 변경

- 홀 바닥 184개 재질 슬롯과 외벽 524개 슬롯에 원본을 보존한 복사 재질 적용. 바닥의 높은 얼룩 대비를 압축하고 별도 월드 기준 색 무늬를 혼합해 반복성을 줄였다. 원래 노멀 방향은 유지했다.
- 홀·남측 야드 반경 70m 안에서 잔디 위주의 바닥을 흙·자갈·콘크리트 접경으로 전환. 새 메시로 지형을 덮지 않고 기존 지형 재질에서 부드럽게 혼합하며 구역 밖에서는 기존 계산을 유지한다. 젖음·표면 반사 차이는 작게 적용했다.
- 홀 각 층의 기존 가림 그룹 아래 벽면 배관과 정리된 보관 소품을 추가. 남측에는 기존 라이브러리의 발전기·이동식 조명·보관물 등을 제한적으로 배치했다. 배치 안전 검사에서 부적합 후보 1개는 생략했다.
- 큐브 포장판 초안은 시각 검토에서 탈락시켰다. 최종판은 기존 지형 높이를 따라가는 연속 콘크리트 메시와 동일 충돌 메시이며, 높이 차이는 약 4.5cm다. 풀과 관통하던 장비 패드는 제거했고 소품은 지면에 직접 배치했다. 입구 포장의 강한 반복 무늬도 다시 완화했다.
- 신규 제작 계수: Factory 프리팹 4개, Rusted 프리팹 8개, 추가 제작 요소 44개, 새 충돌체 49개. 대형 프롭 2개 모두 충돌체와 진입점 여유 공간을 확인했다.
- 중정비동 주변에만 완만하게 적용되는 조명·색보정·원경 안개와 반사 프로브 2개를 추가했다. 암부 가독성 검토 후 밝기를 재조정했다. 다른 A 구역에서는 효과 강도 0, B로 떠날 때와 라우터 종료 시 원래 환경으로 복원한다.
- 캐릭터 모델·머리색·장비·카메라 설정·전투·진입점·스폰 정책·다른 지구는 바꾸지 않았다.

## 확인 결과

- `VALIDATION.txt`: 저장 장면 재로딩 후 **32 PASS / 0 FAIL**. 기존 충돌체 4,576개, 앵커 참조 46개, 원격 33개 지구의 렌더러 864개 및 홀 기존 구조의 서명 일치.
- B4/R8의 위치·참조 불변. R8을 포함한 R1~R8은 여전히 실제 기본 무작위 스폰에서 제외된다. 이번 배치는 해당 진입점 간 경험을 바꾸는 작업이 아니다.
- V14 충돌 회귀 123 PASS / 0 FAIL. 기존 B1→X6 일반 경로 질의의 예산 경고 1개는 남아 있으나, 큰 탐색 예산으로 완전 연결을 재확인했다. 새로운 단절이 아니다. V15 겹침 회귀도 PASS.
- `SHADERS.txt`: 사용 중 LookV16 재질 15개, 컴파일 오류·미지원 셰이더 0. 지면의 월드→맵 좌표를 직렬화 가능한 두 벡터로 저장하고 재로딩 후 검증했다.
- 최종 `after_PLAY_VALIDATION.txt`: 실제 플레이 이동 7곳 PASS, 각 촬영 위치의 지붕 가림/복원 14회 PASS, 원격 A 효과 해제와 실제 Router.Leave 시 B 복원 PASS.
- `SAVED.txt`, `RELOAD.txt`: 실제 유지 장면과 리소스 프리팹 저장, 장면 다시 열기, 검증 재실행 완료.
- 최초 플레이 재촬영에서 무기 제어기가 마우스 시선 이동값을 다시 쓰는 것을 발견했다. 최종 촬영은 동일한 실제 게임 카메라 설정으로 중앙 시점을 명시해 변경 전 좌표와 맞췄다. 포장면 위의 약 4.5cm 높이 차이는 의도된 실제 변경이다.
- `overview`는 변경 전부터 극원거리에서 건물의 거리별 생략이 발생하는 지형 비교 화면이다. 건물 품질 판단은 `hall_close`, `south_yard`, 실제 플레이 화면으로 했다.
- 반복 적용 시 소유 루트만 재생성하며 원본 지형·기존 충돌체는 보존한다. 최종 독립 시각 검토는 `INDEPENDENT_REVIEW.md`에 별도 기록한다.

## 남은 한계

이는 첫 시험 구역의 재질·조명 개선이며 실사 스타일 완성이 아니다. 반복되는 건물 외장, 단순한 계단·안전바, 넓게 빈 야드, SD 캐릭터와 환경의 비율·양식 차이는 후속 과제다. 이번 작업에서는 큰 구조물 교체나 게임플레이 동선을 재설계하지 않았다. 실시간 반사에는 동적 물체가 소량 포함될 수 있고, 빌드 기준 FPS/GPU 비용은 별도 측정하지 않았다. 기존 비밀 경사로의 가림 단면도 이번 범위 밖이다.
