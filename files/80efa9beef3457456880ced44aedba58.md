# Modern Glass UI Kit · 파스텔 티어와 게임 전체 화면 확장

## 사용자 지시와 의도
6단계 티어 색을 적당한 파스텔로 표현하고 UI에 약간의 명암을 더한다. 인벤토리 외에도 인게임의 체력·에너지 등 전체 UI를 같은 스타일로 제작한다. 직접 수정 가능한 Figma 구조를 유지한다.

## 변경 전
Figma에는 기본 스타일, 10개 컴포넌트 패밀리 44개 상태, 인벤토리+루팅 화면 1개와 교체 가능한 이미지가 있었다. 티어 색과 전투·생존 HUD 및 거점 전체 화면이 빠져 있었다.
실제 수정 전에 현재 Figma 렌더를 before_inventory.png, before_foundations.png, before_components.png로 저장했다.

## 실제 변경과 방법
- 기존 파일 KUD4t84BL1S77c3cnb8co0에 2페이지 추가: Gameplay · HUD & Overlays / Basecamp · Screens.
- V1–V6 흰색/초록/파랑/보라/금색/빨강 순서를 보존하며 페일 그레이, 세이지, 파우더 블루, 라일락, 샌드 골드, 더스티 로즈로 구성.
- V는 개당 판매가, T는 탄약 관통 기준. 판매가 경계는 100 / 500 / 2,000 / 10,000 / 30,000 블랭크로 기존 소스와 일치한다. 화면의 예시 물품 등급을 실제 게임 데이터 확정으로 간주하지 않는다.
- 38개 변수를 추가해 총 86개. 원시값 → 의미별 별칭, 범위 지정, 코드 표기 유지.
- 유리 패널에 1px 상단 하이라이트, 하단 음영, 부드러운 외곽 그림자. 컨트롤/오목한 면에 별도 효과 스타일.
- Tier/Badge, Tier/Item 2패밀리 24개 상태 추가. 인벤토리의 아이템 25개를 연결된 티어 인스턴스로 교체.
- 생존 수치, 부상, 스킬, 탄약, 상호작용, 알림, 행동 진행, 지도 마커, 전투 피드백, 입력/토글/체크, 빈 상태: 13패밀리 63개 상태 추가.
- 총 25개 컴포넌트 패밀리 131개 상태. 원본 컴포넌트는 리뷰 프레임 오른쪽 별도 영역에 유지.
- 게임플레이 10개, 거점/메뉴 12개 화면 추가. 기존 인벤토리를 포함하면 23개 화면. 전체 목록·노드 ID는 screen-inventory.json, FINAL_STATE.json 참조.
- 텍스트, 프레임, 벡터 아이콘, 연결된 인스턴스로 제작. 전체 화면을 래스터 이미지로 붙이지 않았다. 캐릭터·게임 아이템 이미지만 교체 가능한 이미지 요소.

## 확인과 수정
구조 검사에서 실제 수치명 반복, 아이템 여러 칸 크기, 작은 글자의 행 높이, 의료 휠 카드와 능력 탭/저장 버튼의 경계 문제를 찾아 수정했다. 수치명은 Kind에 맞춰 따로 지정하고, 여러 칸 아이템은 292×92 / 192×192로 복구했다. 효과와 색은 공통 스타일·변수로 연결했다.
Figma Starter MCP 호출 한도에 도달해 후반 자동 렌더 호출이 막혔다. 이미 저장된 결과를 브라우저에서 추가 확인했다. 새로운 검수 탭만 사용했고 기존 사용자 탭과 앱은 닫지 않았다. 전체 UI는 시각적 설계이며 실제 Unity 동작/데이터 연결은 이번 작업에 포함하지 않는다.

## 전후 증빙
- before_inventory.png ↔ after_inventory_browser.jpg: 같은 인벤토리 프레임. 전 이미지는 1920px Figma 렌더, 후 이미지는 브라우저 43% 보기라 배율이 다르다.
- after_inventory.png는 티어 적용 직후의 중간 렌더이며 여러 칸 크기 복구 전이다. 최종 상태는 after_inventory_browser.jpg를 기준으로 한다.
- before_foundations.png / before_components.png: 변경 전 기존 키트.
- after_hud_normal.png, after_hud_critical.png, after_lobby.png, after_abilities.png: 수정 후 실제 Figma 렌더.
- after_*_browser.jpg: MCP 호출 한도 이후 브라우저에서 확인한 실제 화면. 신규 화면에는 대응되는 변경 전 화면이 존재하지 않으며 기존 화면으로 위장하지 않았다.
- 새 페이지의 빈 상태 별도 캡처는 확보하지 못했다. 생성 전 파일의 기존 1페이지 구조는 원본 조회 결과 및 기존 화면 캡처로 기록했다.

브라우저 캡처의 원본은 JPEG이며 같은 픽셀을 PNG 형식으로도 저장했다. before_foundations.png ↔ after_foundations_browser.png, before_components.png ↔ after_components_browser.png도 비교할 수 있다. 자동 렌더와 브라우저 보기의 배율 차이를 포함한다.

22개 추가 화면과 기존 인벤토리를 각각 실제 렌더로 확인했다. HUD·로비·동료 능력은 큰 크기의 Figma 렌더, 나머지 화면은 브라우저의 프레임 전체 보기로 확인해 배치·구획·경계를 검토했다. 긴 컴포넌트 가이드는 전체 배치와 기존 구조 검사 결과를 함께 확인했다. 후반 MCP 정밀 재검사는 플랜 한도로 제한되었으므로 브라우저 확대율에서 보이지 않는 세부 픽셀까지 자동 통과했다고 주장하지 않는다. Unity에서의 가독성·해상도 대응·동작 검증은 별도다. 현재 C# IMGUI 화면에는 웹 Code Connect 연결을 작성하지 않았다.
