# S3 중장형 실루엣·심미성 정리

## 지시와 목적

사용자는 직전11-02-04 시안의 S3가 껴입기만 해서 S4보다 단단해 보이지만 심미성이 좋지 않다고 지적했다. 정확한 원문은 USER_REQUEST.md에 보존했다. 같은 장비 주제·같은 S3 제품의 후속 수정이므로 기존 주제 ID와 후보 명칭 S3 저거넛 방탄복을 유지한다. 다른 티어·유형 전체를 재설계하거나 방어력·드롭·역할 수치를 변경하지 않는다. “보호 면적을 유지하면서 더 매끈한 구조로 정리”는 피드백에 따른 이번 제안 방향이며 사용자가 이 설계를 확정했다는 뜻은 아니다.

## 수정 전 증빙

실제 생성 전에 11-02-04의 최종 after_edel16.png와 after_serin16.png를 각각 before_edel16.png, before_serin16.png로 그대로 복사했다. 해당 이미지의 맨 아래 행 세 번째 S3가 수정 대상이고 네 번째 S4는 참고다. 기존03/04 공개 원문·이미지를 덮어쓰지 않았다. 전 이미지는 실제 게임 스크린샷이 아닌 기존 이미지 시안이다.

## 실제 제안과 제작 방식

imagegen 스킬의 내장 image_gen을 사용해 착의한 에델·세린16종 시트를 참조하는 새2×2 장비 제안 이미지를 생성했다. 입력1은 에델 정체성/기존 S계열, 입력2는 세린 정체성/기존 S계열 참조다. 전체 프롬프트와 원본 생성 경로는 IMAGE_PROMPTS.json에 남겼다. 남성 마네킹 입력이나 실제3D 메시 편집은 사용하지 않았다.

after_s3_refinement.png는 위 행 에델, 아래 행 세린, 왼쪽 수정 S3, 오른쪽 S4 비교 참고다. 두 캐릭터에서 S3의 같은 설계·재료 방향을 유지했다.

- 덧댄 흉갑을 한 장으로 읽히는 매끈한 백색 곡면 흉갑으로 정리하고, 네이비 사선 이음부로 비대칭 방향을 남겼다.
- 어깨판의 바깥 돌출과 층을 줄여 자연스러운 어깨 경사를 따라가는 낮은 한 쌍의 셸로 정리했다.
- 큰 다층 허리 보호판을 짧고 간결한 측면판 두 장으로 줄이고 벨트·짙은 반바지와 연결했다.
- 가늘게 모아지는 정강이판과 제한된 시안 접속부를 유지해 넓은 몸통 보호와 간결한 하지 실루엣을 조합했다.
- 기존 연보라 에델 땋은 머리·갈색 세린 포니테일, SD 얼굴/체형 방향, 불투명한 상의·반바지와 일부 팔·허리·허벅지 관절 공간을 유지했다.

오른쪽 S4는 기존 비대칭 몸통/한쪽 긴 잎형 허리판/원형 서비스 접속부를 큰 크기로 **재표현한 참고**다. 기존 원본과 동일 픽셀 또는 확정된 새 S4 설계가 아니다. 새 S3와 대비해 S4의 공구/서비스 특징을 보여 주려는 구성이다. 기존 S4 원본은 수정하지 않았다.

## 시각 검토와 한계

생성 이미지를 직접 열어4명·2×2 배치·S3/S4 표기·두 캐릭터 머리색·발끝 포함을 확인했다. 왼쪽 S3의 연속 흉갑·낮은 어깨판·짧은 측면판 두 장, 오른쪽 S4의 원형 서비스 모듈과 긴 한쪽 허리판이 구별되는지 검토했다. 두 캐릭터의 작은 판 곡선·이음부는 생성 과정에서 차이가 있으며 정확한 공통 메시 명세로 확정하지 않는다. 심미성 개선 여부는 사용자 판단 대기다.

FILE_CHECK.json은 원본 복사 SHA 일치,3개 이미지의 디코딩·해상도·크기·SHA,JSON 유효성을 검증한다. 새 보드는 S3 두 착용안과 S4 비교 재표현 두 착용안으로, 새4제품이 아니다. 전체16종 시트와 새2×2 보드는 비교 범위·배치·축척·카메라·조명이 달라 강제 전후 비교쌍으로 연결하지 않는다. 수정 전 두 이미지는 보조 갤러리 참고로 보존한다. 실제 게임/Blender 스크린샷 전후라고 주장하지 않는다.

## 결과와 적용 상태

두 캐릭터의 S3 수정 이미지 제안과 S4 비교 참고를 저장했다. 디자인 승인은 대기 중이다. 실제 장비 제작·Blender 피팅·Unity Assets 변경·수치/드롭 변경은 하지 않았다. 기존 별도 r18 Unity 보정 자료 미확보에 따른 동기화 보류도 해결된 것으로 취급하지 않는다. 사용자 승인 시 실제 두 모델에서 판 두께·관절·헤어/무기/장비 간섭을 검증하는 제작 단계로 이어간다.

주요 파일: USER_REQUEST.md, IMAGE_PROMPTS.json, FILE_CHECK.json, LIBRARY_EVIDENCE.json, before_edel16.png, before_serin16.png, after_s3_refinement.png. 원본 생성 파일은 기본 저장 위치에 남기고 프로젝트 사본만 추가했다. 게시 상태와 공개 검증은 별도 영수증을 연결한다.
