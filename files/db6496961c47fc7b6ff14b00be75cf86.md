# A맵 건축 키트 D07 — 단품 원화와 후속 제작 계획

상태: **건축 부품 아트 기획만**. 이 문서의 `T01`–`T14`는 `ASSET_MANIFEST.json`·`PROMPTS.md`에 정의된 단일 부품 **이미지/Tripo 후보**이며, 현재 3D 모델·Unity 에셋이나 검증된 치수라는 뜻이 아니다. `B1`–`B6`은 별도 **비교 구조 아트 시트 1장에 함께 담는** 향후 Blender 정밀 제작 작업군이다. 14개 후보 + 6개 작업군은 실제 신규 메시 20개나 건물 완성품 20개를 뜻하지 않는다.

## 범위와 선택 원칙

- 이전 건물 콘셉트의 01–10 외형군은 현행 V33의 69개 건물 ID에 대응한다. 이 키트는 **10종 대표 외형 언어**의 반복 가능한 부분을 설계하기 위한 것이지 69개별 건물 이미지·완성형 실내 또는 새 평면도 설계가 아니다. 대상 ID·용도 매핑은 `../a-map-building-identities-v01/BUILDING_DESIGN.md`를 따른다.
- 01 중정비동 HALL은 이미 랜드마크인 **현행 역할**을 보존한다. 그러나 콘셉트에 그려진 채광 지붕·철골 포털이 현행 모델에 전부 구현됐다고 단정하지 않는다. 그 차이는 `B1`의 별도 정밀 조립 대상으로 남긴다.
- 새 Tripo 후보는 구별되는 외벽·창·처마의 **외형 모듈**에 한정한다. 통짜 건물, 색상만 다른 동형 모델, 기존 변압기·펌프·파이프·차량·작업 소품의 중복 생성은 계획하지 않는다. 벽 두께·실제 문/창 구멍, 지붕 스팬·컷어웨이, 접합과 통행 폭은 이후 실측을 기반으로 Blender/Unity 단계에서 처리해야 한다.
- 이 문서의 크기는 `ASSET_MANIFEST.json`의 **후속 모델링 목표치**다. 콘셉트 이미지에서 측정한 실제 크기, 기존 건물 슬롯 치수, 검증된 게임 배치 간격이 아니다. 이미지가 구멍처럼 보이더라도 3D에서 실제 열린 토폴로지·통과 가능한 문을 보장하지 않는다.

## 원화와 3D 제작의 구분 / 비용 경계

`PROMPTS.md`·`ASSET_MANIFEST.json`은 **14개 단품 원화**의 저장 경로와 이미지 프롬프트를 지정한다. `B1`–`B6` 비교 구조 아트 시트 **1장**도 원화 참고다. 이미지의 멋진 후면·빈 창 공간·평평한 절단면이 실제 GLB 토폴로지/UV/피벗/치수/접합 품질을 보증하지 않는다. 원화 시각 검토와 3D 생성·반입·Unity 문/시야/보행 검증은 별도 단계다.

메인이 확인한 현 UI의 기본 생성 조건은 **H3.1, private 2K, Ultra/Enhance OFF, 8,000 triangles, 30크레딧/회**다. 동일 조건이 유지된다는 전제의 단순 산술은 우선 12종 **360**, 조건부 2종 추가 시 14종 **420크레딧**이며 재시도·옵션은 제외한다. 잔액/상한/집행 기록은 메인 별도 파일이 관리한다. **이번 문서 작성에서는 Tripo를 실행하거나 크레딧을 소비하지 않았다.** Unity 씬·코드·프리팹도 변경하지 않았다.
