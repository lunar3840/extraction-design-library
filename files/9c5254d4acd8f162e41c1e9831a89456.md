# 파지·재장전 검토 파일 안내

대상은 **에델의 SCAR형 AR_013_A 한 종**이다. GR_ 접두사의 정지·조준·사격·걷기·달리기·재장전 여섯 동작을 확인하는 Unity 적용 전 사본이다. 다른15개 저장 프리셋이나19개 미저장 무기의 수정 완료를 뜻하지 않는다.

ZIP을 푼 뒤 preview/AR_013_A_Reload_Review.mp4에서 재장전 전체를 볼 수 있다.271프레임·30fps의 약9.03초 검토 영상이며 실제 게임의 재장전 시간이나 탄 수를 변경한 결과가 아니다. AR_013_A_EmptyMagazine_Detail.mp4는 빈 탄창을 놓아 바닥에 안착시키는 부분을0.5배속으로 보여 준다. 두 영상 모두 같은 동결 저장본의 실제 동작을 렌더한 것이며 Unity 화면은 아니다.

native/Edel_AR_013_A_ContactRepair.blend는 Blender5.3에서 열 수 있다. 텍스처는 파일 안에 포함했다. 처음 선택된 재장전은 Space로 재생하고 Numpad0으로 검토 카메라를 볼 수 있다. 자동 Python 실행을 켤 필요가 없다. GR_AR_013_A_*가 수정 동작이며 원래 EF_* 액션은 비교 이력으로 남아 있다. 열기만으로 Unity에 적용되지 않는다.

총을 몸 앞쪽에 둔 상태로 빈 탄창을 놓고, 허리의 열린 탄창 홀더에서 새 탄창을 꺼내 삽입한 뒤 보조 손잡이를 다시 잡는다. 탄창 홀더는 이 검토 사본에 추가한 소품이다. 한 번의 재장전에서 여분 재고1개를 소비하므로 끝 상태의 홀더는 비어 있고, 빈 탄창은 바닥에 남는다. 반복 재생의 끝과 시작에서 소모 재고가 같아야 하는 동작으로 만들지 않았다.

별도 qa-independent/pass_17/의 보고서와 verification/FINAL_REVIEW_ACCEPTANCE.json이 이 사본의 판정 근거다. 기존 플레이어4명의 감정·이동·전투 애니메이션 전체 검사는 다른 기록에 보존한 **불합격 결과**이며, 이 무기 사본의 통과가 기존 게임의 결함을 고쳤다는 뜻은 아니다.

원본 모델·텍스처·원래106개 액션 곡선과 캐릭터 기본 데이터의 보존 여부는 검증 기록을 따른다. Unity 신규 적용은0이다.
