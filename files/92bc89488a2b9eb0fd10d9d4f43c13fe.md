# V33 연결형 시설 경계 독립 검증

검증 범위: 승인 도면 `PLAN.json`을 실제 Stage A 씬에 적용한 결과의 물리 형상, 출입구, 대표 동선, 기존 기능 보존. 배치 제작과 별도로 검증 코드를 작성했고, Unity 적용·저장·실행 및 캡처는 메인이 수행했다. 이 문서는 실제 Unity 산출물을 판독한 결과이며 소스 검사만으로 성공을 추정하지 않는다.

## 전후 화면 직접 확인

- `before_overview.png` ↔ `after_overview.png`: 같은 전경에서 기존의 넓고 흩어진 도로·소형 구조물이, 건물군·마당·우회 통로와 5개 시설 경계로 바뀐 것을 확인했다. 기존 HALL, 진료소, 전력시설, 부품창고, 공구시설과 물·두 교량은 남아 있다.
- `before_WC_detail.png` ↔ `after_WC_detail.png`: 서측 분해·반출마당에서 건물 외벽을 경계 일부로 쓰는 연속 담장과 야적물, 열린 진입부가 실제 화면에 나타난다.
- `after_CN_detail.png`, `after_PC_detail.png`, `after_SC_detail.png`, `after_YC_detail.png`: 후정·전력 동측·부품 반입마당·차량 야적장의 담장/철망이 각각 소속 건물과 마당을 구성한다. 단순한 구역 색칠이나 떨어진 벽 조각으로 보이지 않는다. 전력시설 철망은 원경에서 가늘어 보이므로 상세 화면과 물리 검사 결과를 함께 봐야 한다.

## 실제 검사 결과

## 도면 대비 현장 보정

- 기존 주요 시설의 회전된 실제 외벽에 담장 말단을 맞췄다. `V33_AS_BUILT.csv`에 29개 접점 보정을 기록했고 최대 이동은 20.14m다. 전력 PC_W6은 굴절시켜 기존 시설 외벽에 접속했다.
- 지형은 보조 건물 19개 부지만 국소 평탄화했다(`GROUND_GRADING.txt`). 원본 지형 메시를 복제해 보존하고, B/R/X/T·교량·물·기존 주요 시설 주변을 보호했다. 일부 비보행 사면의 최대 변화 경사는 57.72°이나, 실제 대표 경로 최대는 33.3°였다.
- 공구시설 원본 출입문 확보를 위해 서측 WC_W7과 인접 연결 말단을 x=106m로 2m 이동했다. W10은 실제 양면 문이 있는 V11 셸로 교체했고 128개 양면 출입 검사를 통과했다.
- 기존 벽·건물·기초에 맞춘 도로 선형과 계획 폭의 국소 변경은 `V33_ROUTE_AS_BUILT.csv`에 기록했다. 원 PLAN은 불변이다. S 차도와 접한 `Curb_EastEdge_Tile_01` 단일 조각은 플레이어 단차 한계에 걸쳐, 차도 개방부에서 시각·충돌을 함께 비활성화했다. 다른 턱은 유지했다.

## 남은 범위와 판단

- R1–R8은 계속 비활성 위험 진입 후보이며, R8은 위험 지역 표시가 아니다. B4–R8 직선거리는 약 62.17m이고 초반 접근 경험의 차별성은 이번 검증으로 해결되지 않았다. 위험 진입 재활성화 전 동선·적 노출·엄폐·보상과 함께 재설계해야 한다.
- `map.HumanRoutes` 등록 경로가 0개여서 기존 인간 AI 경유점의 물리 검사는 적용 불가다. 순찰·철수 행동, 적 반응과 실제 전투 흐름은 실행하지 않았다. NavMesh 연결성이 그런 행동의 성공을 보장하지 않는다.
- 이번 결과는 배치·충돌·이동 가능한 블록아웃 검증이지, 최종 아트 품질·조명·게임플레이 밸런스 승인으로 확대하지 않는다.
