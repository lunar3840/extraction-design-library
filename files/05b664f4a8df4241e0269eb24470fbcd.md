- 검토일: 2026-10-22
- 전후 자료: `before_project_export.png` / `after_project_export.png`
- 방법: 동일한 게임 장면의 1920×1080 실제 Figma 내보내기 두 장을 직접 열어 비교했다. Figma·Unity·앱은 조작하지 않았다.
- 범위: 새 HUD 비교 시안 `103:2538`의 무기·퀵슬롯과 스킬 위치 변경만 검토했다. 기존 원본, 다른 화면, Unity 런타임의 완료 판정이 아니다.
- 판정: **PASS — 무기·퀵슬롯은 중앙 하단, 스킬은 우측 하단으로 분리됐으며 새 겹침이나 정보 손실은 발견하지 못했다.**

## 확인 결과

| 항목 | 결과 |
| --- | --- |
| 무기 중앙 배치 | 주·보조 무기와 그 아래 네 개 퀵슬롯이 화면 중앙 하단에 모여 있다. 작업자가 보고한 x720, 폭480의 중심은 x960으로 1920 화면 중앙과 일치하며 실제 이미지도 중앙 배치로 읽힌다. |
| 스킬 우측 배치 | E/X 스킬이 우측 하단으로 이동해 중앙 무기 묶음과 충분히 분리됐다. 충전 링, 키, 이름과 준비/72%가 서로 겹치지 않는다. |
| 하단 정렬 | 작업자가 보고한 무기 y836+196과 스킬 y904+128은 모두 y1032이며, 실제 이미지에서도 같은 하단 기준선과 48px 여백이 유지된다. 정확한 소스 좌표와 PNG 시각 관찰은 구별한다. |
| 정보 보존 | 주 탄수 24/120, 보조 탄수 12/48, 총기 실루엣, 주무기 장탄 표기·T3 관통, 아이템 네 개, 3~6 원형 키 및 ×1 수량이 유지된다. 주·보조 탄수의 높이 정렬도 유지된다. |
| 다른 HUD와의 관계 | 좌측 수분·에너지 및 중량 표시와 무기 묶음이 겹치지 않는다. 캐릭터·캐릭터 위 HP/스태미너·상호작용 캡슐과도 분리돼 있다. 미니맵·시계·목표·탈출 안내는 전후 동일하게 보인다. |
| 가독성 | 새 중앙 위치의 벽·지면 위에서도 현재 장면의 탄수와 수량을 읽을 수 있다. 새 문자 잘림이나 아이콘 잘림은 발견하지 못했다. |

현재 장면에 대한 추가 시각 수정 권고는 없다. 다른 조명·밝은 바닥 및 장전/탄약 고갈/긴 스킬명 등의 상태까지 검증한 것은 아니다. 정확한 네이티브 편집 구조와 좌표는 작업자의 소스 확인 사항이다.
