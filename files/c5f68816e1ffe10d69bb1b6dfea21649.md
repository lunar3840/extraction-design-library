- 침수 정비지구의 정비·하역·전력·배수 시설에 각각 맞는 설비와 외관을 배치합니다.

- 독립 장애물은 보이는 메시와 일치하는 충돌을 사용합니다. 구멍이나 계단이 통과 가능한지는 별도로 확인합니다.

- B4/R8의 비슷한 초기 접근 경험 문제는 기존 검토 사항입니다. 이번 작업이 위험 진입점 활성화나 문제 해결을 의미하지 않습니다.

## 구현 및 검증 상태

**최종 A씬과 리소스 프리팹에 저장 완료. 14종 반입 / 11종 사용 / 14개 배치 인스턴스입니다.**

- GLB 원본 14개를 `Assets/Escape/Art/TripoD05/SourceGLB`에 복사했으며 원본과 해시 14/14 일치를 확인했습니다. Unity 메시·재질·텍스처와 전체 프리뷰 14개가 준비되어 있습니다.
- glTF 생략 기본값과 없는 sparse 필드의 임포터 호환 문제를 수정했습니다. 실패 시도는 롤백 후 재실행했고 실제 반입 결과를 확인했습니다. 최초 프리뷰가 잘린 문제는 원본을 보존하고 `import_preview_full_*`로 재촬영했습니다.
- 텍스처는 탑뷰 용도를 고려하여 Unity 임포트 최대 1K로 제한했습니다. 원본 해상도와 파일은 보존됩니다.
- 원본 렌더러 8개만 명시적 목록에 따라 숨겼습니다. 원본 객체는 삭제하지 않았고, 원본 Transform·Collider·SpawnTiers는 변경 전 서명과 일치합니다. 새 시각 프리팹과 충돌 트리는 분리되어 이후 교체할 수 있습니다.
- 플레이어 가림의 정확한 삼각형 검사 캐시에 `TripoD06_Placements`를 연결했습니다. 최종 실제 플레이에서 차양·문틀·탱크·전력 장치 각각이 카메라 선을 막는 지점과 국소 표시/실루엣 작동을 확인했습니다.

1. 첫 Apply에서 하역대가 E05 문과 D03 대체 동선을 막아 304 PASS / 3 FAIL이었습니다. 실패 씬 `failed_preview_202337.unity`와 `attempt_01` 기록을 보존하고 원본 씬을 다시 열었습니다. 이 실패 배치는 A씬/프리팹에 저장하지 않았습니다.

4. D06 홀더 2개만 교정했습니다. 전력 장치는 야외 `(470,120)`, 문틀은 실제 열린 B 입구로 이동했습니다. `REFINEMENT.txt` 및 `before_refinement_backup`에 수정 내용과 직전 상태를 보존했습니다.
5. 초기 플레이의 16 PASS에는 실제 가림이 없는 시점과 문틀 반대쪽 W02 문 통과가 포함되어 있었습니다. 그 결과는 `play_initial/D06_PLAY_VALIDATION.txt`에 보존했습니다. 보강 검사는 배치된 문틀의 실제 대응 출입구를 명시하며, 가림이 발생하지 않은 테스트는 PASS가 아닌 NOT_EXERCISED로 구분합니다.

7. 간격 교정 후 첫 재플레이는 검사 도구가 준비 단계에서 승인한 NavMesh 위치 대신 원래 희망 위치를 실제 시작점으로 써 커플러 측면 1건이 준비 단계에서 실패했습니다(19 PASS / 1 FAIL). 동일한 승인 좌표를 실제 보행 시작·끝점으로 사용하도록 수정했고, 기존 0.8m 허용 판정은 완화하지 않았습니다. 다시 실행하여 **최종 20 PASS / 0 FAIL**을 확인했습니다. 실패 보고서도 prior 파일로 보존했습니다.
