# 2차 계획 독립 코드 검토

GPT-6 Sol high 코드 담당의 읽기 검토 결과를 메인이 통합했다. 검토자는 이번 요청에서 Unity/프로덕션/기록 파일을 변경하지 않았다.

최종 Current-only fixed240행에서 CurrentApply17.290ms, BraidSurface17.324ms, CurrentRefresh11.365ms가 관찰됐다. BodyQuery8.307ms는 중첩값이다. 1차 Hair 캐시는 반려됐으므로 재제안하지 않는다.

우선 CurrentSource 거리 커널의 반복 불변항을 분리 계측하고, 다음으로 Braid Adaptive/Score의 모든 witness를 유지한 순차 데이터 경로를 검토한다. 과거 한 프레임의 BraidSkinMatrix1.128ms/PoseValidation0.473ms는 현행 평균이 아니며, source 방향/분류 snapshot만을 주력으로 삼을 근거는 부족하다.

Transform을 순서대로 바꾸는 후보 탐색과 nearest seed/cache 상태 때문에 곧바로 Jobs/Burst로 옮기기보다 입력 분리와 결정적 결과 검증을 먼저 한다. 각 후보를 독립 A/B하고 결과 동일성·CPU·GC 개선이 입증되지 않으면 반려한다. 예상 개선률이나 전체 게임 FPS 개선을 제시할 근거는 없다.
