# 플레이어 중심 원형 근접 시야 변경 기록

## 사용자 지시 요약

- 현재 전방 시야각은 유지한다.
- 덕코프 사례를 참고해 플레이어 주변 일정 반경은 방향과 무관하게 원형으로 보이게 한다.
- 적이 플레이어에게 근접했을 때 뒤쪽에 있더라도 확인할 수 있게 한다.

## 기획 의도와 해결하려는 문제

- 탑뷰에서 플레이어 바로 뒤까지 전방 부채꼴만 적용되면 근접한 적을 시각적으로 확인하지 못하고 피격되는 문제가 생긴다.
- 장거리 정보는 기존 전방 시야각으로 제한하면서, 즉각적인 근접 위험만 최소 반경 안에서 인지할 수 있게 한다.
- 참고 이미지는 다른 게임의 표현 사례로만 사용하고 현재 익스트랙션 게임의 거리 단위, 적 표시, 벽 시야선 규칙에 맞춰 적용한다.

## 변경 전 상태 및 문제점

- 플레이어 전방 115도 부채꼴은 정상 표시됐다.
- 5.5m 근접 보조 감지는 근접 무기를 든 적에게만 적용됐고, 적 중심의 작은 공개 영역을 만들었다.
- 따라서 플레이어 뒤 4m에 원거리 무기 적이 있어도 화면과 적 모델이 숨겨졌다.

## 실제로 바꾼 부분

- 근접 보조 감지를 적 무기 종류와 무관한 플레이어 중심 원형 최소 시야로 변경했다.
- 기본 원형 시야 반경은 5.5m이며 경계는 1.1m 구간에서 부드럽게 어두워진다.
- 원형 시야 안의 적은 전후좌우 어느 방향에 있어도 표시한다.
- 벽이나 장애물이 시야선을 차단하면 원형 반경 안이어도 적은 표시하지 않는다.
- 기존 전방 115도 장거리 시야는 유지했다.
- 기존 설정 이름은 직렬화 이전 이름으로 등록해 이미 저장된 설정과의 호환성을 유지했다.

## 어떤 방식으로 변경했는지

- 셰이더에 플레이어 위치를 중심으로 하는 두 개의 화면 투영 축을 전달해 월드 공간 원이 탑뷰 화면에서 자연스러운 타원 형태로 투영되게 했다.
- 전방 부채꼴 공개값과 원형 근접 공개값 중 더 큰 값을 최종 공개 영역으로 사용한다.
- 적 표시 판정은 `전방 부채꼴 내부 또는 5.5m 원형 반경 내부`인 경우에만 시야선 검사를 통과해야 보이도록 구성했다.
- 원형 반경, 경계 흐림 값을 플레이어 기본 설정에서 조절할 수 있게 이름을 명확히 정리했다.

## 변경 후 기대 효과와 확인 결과

- 플레이어 뒤 4m에 있는 원거리 적이 표시되는 것을 확인했다.
- 플레이어 뒤 7m의 적은 원형 반경 밖이므로 숨겨지는 것을 확인했다.
- 플레이어 뒤 4m라도 벽이 사이에 있으면 숨겨지는 것을 확인했다.
- 전방 9m의 적은 기존 부채꼴 시야로 계속 표시되는 것을 확인했다.
- 격리된 Unity 프로젝트에서 스크립트와 셰이더가 컴파일됐으며 전용 자동 검사 4개가 모두 통과했다. 결과는 `vision_checks.log`와 검증 프로젝트의 `Library/EscapePlayerVisionChecks.txt`에 기록했다.

## 관련 스크린샷 파일명 및 대응 비교 시점

- `before_vision.png` ↔ `after_vision.png`
  - 동일한 1600×900 해상도, 카메라 위치, 플레이어 자세, 조명, 적 위치를 사용했다.
  - 플레이어는 화면 중앙에서 위쪽을 바라보고, 원거리 적은 플레이어 뒤 4m에 배치했다.
  - 변경 전에는 뒤쪽 원거리 적이 숨겨지고, 변경 후에는 플레이어 중심 원형 시야 안에서 표시된다.
- 수치 판정은 `before_result.txt` ↔ `after_result.txt`에 대응시켰다.
  - `nearRangedVisible=False` → `nearRangedVisible=True`
  - 반경 밖의 뒤쪽 적은 양쪽 모두 숨겨진다.
