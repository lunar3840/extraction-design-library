# 예방 진통제 사용 변경

- 사용자 추가 지시: 진통제는 부상 전에도 미리 사용할 수 있다. 수술과 힐킷의 치료 필요 조건은 유지한다.
- 메인 에이전트가 변경 전 화면과 원본 소스 백업을 확보한 뒤 수정 승인을 전달했다.

## 변경 파일

- `Assets/Escape/Runtime/Inventory/Core/ItemUseState.cs`: 진통 사용의 시작·완료 단계에서 외상 필수 조건을 제거. 소유 UID, 자원, 배치, 사용 시간, 완료 재검증, 중복 효과, 거점 제한은 유지한다.
- `Assets/Escape/Runtime/Combat/Core/InjuryState.cs`: 유효한 지속시간이라면 외상이 없어도 진통 효과를 적용한다. 기존 10초 초과 중복 제한과 만료·부상 억제 방식은 유지한다.
- `Assets/Escape/Runtime/Inventory/InventoryMedicalDetails.cs`: 무부상 진통 버튼 비활성 조건을 제거. 기존 퀵슬롯 등록 및 의료휠 우선 표시 UI를 삭제하고 체스트리그 V 자동 치료, 배낭 직접 사용, 예방 복용 안내로 교체한다.
- `Assets/Escape/Editor/AnalgesicProphylaxisChecks.cs`: 실제 프로필·씬·편집기 실행 상태를 변경하지 않는 독립 도메인 검증.

## 검증

- 신규 Editor 검증 파일은 현재 Unity의 실제 Editor 컴파일 응답 파일에 있는 참조·정의를 재사용하여 별도 DLL로 컴파일했다. 종료 코드 0, 오류 0, 경고 0. `compile-summary.json` 참조.
- 검증 API: `Escape.Tests.AnalgesicProphylaxisChecks.RunChecks()`는 보고 문자열을 반환한다. `RunRules()`는 동일 검증 후 `Library/AnalgesicProphylaxisChecks.txt`에 저장한다.
- 검사 범위: 정상 상태에서 일반·고급·전술 의료품의 진통 직접 사용, 사용 시간과 지속시간, 정확한 자원 소비, 중복 완료·중복 효과 차단, 취소·거점·입력·소유권 조건, 나중에 발생한 외상 억제 및 만료 후 페널티 복귀, 정상 상태 힐·수술·지혈 거부.
- 이 하위 작업에서는 Unity를 조작하거나 검증 함수를 실행하지 않았다. 메인 에이전트가 통합 컴파일 및 편집기 실행 결과를 기록한다.
- V의 자동 추천 필요 판정은 다른 소유 범위인 `InventoryController`에 있다. 외상 없는 V 입력에서 진통제가 자동 소비되지 않는 통합 검증이 별도로 필요하다.

## 통합 리뷰 후 자원 소비 재진입 보호

- V 자동 수술의 마지막 사용 횟수를 소모하면 `Bag.Changed`가 즉시 `Controller.Refresh`를 호출한다. 이 시점에 자동 사용 위치 검증이 아이템 소멸을 이동으로 오인하여 사용을 취소하면, 아직 적용 전인 수술 대상이 초기화되어 키트만 소모될 수 있는 경로를 발견했다.
- 메인 승인 후 `ItemUseState.Tick`의 기존 로직을 `TickCore`로 옮기고 공개 `IsTicking` 속성을 `try/finally`로 관리하는 래퍼를 추가했다. 중첩 Tick은 거절한다. 직접 `Complete`도 원래대로 Tick을 거쳐 동일 보호를 받는다.
- Controller 담당이 `ValidateAutomaticMedicalLocation`에서 `Use.IsTicking` 동안 검증을 보류하도록 연결했다. 실제 이동·삭제는 Tick 시작의 기존 `OriginalPlacement` 검사와 다음 프레임 검사에서 검증한다.
- 변경된 core 파일의 별도 컴파일은 종료 코드 0, 오류 0, 경고 0. 기존 도메인 참조에 대해 변경 파일만 확인한 컴파일이며 실제 통합 실행 결과와 구분한다. `core-commit-guard-summary.json` 참조.
- Controller 담당이 마지막 1회 수술·진통의 실제 효과, 정확한 자원 소모, `IsTicking` 복귀 검증을 통합 체크에 추가했다. 실행은 메인 에이전트가 수행한다.

스크린샷 및 최종 통합 검증 기록은 상위 `CHANGE_RECORD.md`에 연결한다.
