# 대표 총기·방어구 명단 독립 검토

## 무기 로스터 검토

기존 무기 검토 에이전트가 현행32총기 카탈로그와01/02회차를 대조하고24종 역할표를 제안했다. 작성 후 ROSTER_PROPOSAL.md·SELECTION_MAPPING.md를 읽어 다음을 검증했다.

- 7+3+3+3+3+3+2=24, 기존21+신규 기관단총3이다.
- 기존21+예비11=32이며 선택ID에 중복·누락이 없다. 예비2권총+4산탄+4저격+1기관총을 보존했다.
- 무기 티어가 없고 모델별 역할·장단점·가격을 구분했다.
- M16 점사는 현재 자동에서의 신규 후보, 기관단총은 신규 분류다.
- 탄약4계열과 기관단총의 권총탄 공유 후보를 현실 구경 분리와 구별했다.
- 실총 제원 인용이나 실제 카탈로그 변경·상점/드랍 삭제·Unity 검증 완료로 표현하지 않았다.

최종 문서 정합성 통과, 필수 수정 없음으로 보고받았다.

## 방어구 로스터 검토

별도 방어구 검토 에이전트가 C/B/A/S별4스타일의 지배적 선택 위험과 소재·정비·외형 차이, 헬멧10종을 검토했다. 작성 후 문서를 다시 읽고 다음을 지적했다.

1. 균형형은 한 번의 출격을 안정적으로, 정비형은 반복 출격 유지비에 유리하게 구분한다. 정비형에 낮은 최대 내구를 남기고 최저 가격·경량·빠른 수리까지 모두 주지 않는다.
2. 중장형의 높은 내구를 기본 차이로 두고 제품별 넓은 방호 범위는 확장 후보로만 설명한다.
3. 현재 헬멧의 머리 공통 방호와 충돌하지 않도록 ‘얼굴 보호 없음’을 ‘안면 덮개 없는 외형’으로 바꾸고 범위 차등은 미구현 후보임을 명시한다.
4. B 훈련형은 실방호판을 쓴 훈련·경계용이며, ‘복’은 별도 착용 몸통 방탄복임을 밝힌다. 외형 파우치에 리그/V 치료 보너스를 자동으로 붙이지 않는다.
5. 기존 수리키트를 유지하는 방향을 우선하고 새 티어별 수리 재료 체계는 필수 요구로 추가하지 않는다. 이는 메인의 복잡도 판단이며 절대 수리비는 미확정이다.

메인은 지적 문장과 수정 결과를 직접 대조해 모두 반영했다.16방탄복·10헬멧 목록, 소재/실루엣 차이, 기존 리그·원래 헤어 보존은 확인됐다.
