## 기획 의도와 변경 전 문제

기존 민트색 강조와 회색 유리 패널을 사용하던 두 웹 화면을, 사용자가 역설계한 짙은 남청색·아이보리·캡슐 탭·원형 분류 버튼의 표현으로 맞춘다. 두 도구는 한 워크스페이스의 기능 화면으로 취급하며 공통 배치를 유지한다. 모바일에서는 기존 좌측 패널 높이와 하단 영역의 차이도 함께 검토한다.

## 실제 변경과 방법

- Figma `36:289` 탭: 기본/선택 대비, 아이보리 외곽선 캡슐.
- `36:297` 분류 버튼: 원형 배경, 실제 원본 아이콘 `36:253` 및 선택용 `40:689`를 로컬 저장하여 연결.
- `36:298` 드롭다운: 원본 정렬 아이콘 `36:299`와 외곽선.
- `95:1466` 백플레이트: #0B0C1A / 60% 단색 면. 웹의 고정 하단은 겹친 내용이 비치지 않도록 모바일에서 불투명 면으로 적용.
- `shared-web/arc-workspace.css`를 공통 원본으로 두고 동기화 스크립트로 두 웹 및 로컬 데이터 편집기에 같은 테마 사본을 적용.
- 한국어는 기존 번들 Noto Sans KR을 유지. Figma 원본 2560px 치수를 웹에 그대로 붙이지 않고 기존 웹 크기와 반응형에 맞춰 번역.
- 편집기는 보관된 게시 카탈로그를 재사용. 인증·비밀번호·DB·CSV·Unity 연결 코드와 게임 원본을 변경하지 않는다.

## 주제 연결과 조율

기존 두 웹의 스타일·배치 통일 작업을 잇는 후속으로 기존 hosted-planning-library 주제 ID를 유지한다. 같은 변경을 편집기 주제에 별도 구현 회차로 중복 생성하지 않는다. `스탯 데이터 편집기 추가` 담당 탭은 진행 중 UI 수정이 없음을 확인했고, 이번 양쪽 웹 UI 변경은 MD 탭 단독 소유로 조율했다.

## 검증 및 게시 상태

양쪽 실제 공개 사이트 배포 완료: 라이브러리 v16, 편집기 v5. 라이브러리 조직·Worker 검사 통과. 편집기 임시 테스트 29/29 통과, 실제 Unity 파일 열기 0. 게시 카탈로그는 103개 분류 / 12,931개 값, 지문 `7dae3ef2c6cfcc501fd08cdacdaba5ce0cddde4710f4ae120bdbf41d8d773f8e` 유지. backend·transport·app·CSV·catalog 소스가 이전 커밋과 동일함을 해시로 대조했다. 로컬 편집기 서버는 새 CSS/아이콘의 정적 파일 허용목록과 MIME만 추가했고 실행·게임 원본 수집은 하지 않았다.

- 1280×720: 두 도구 모두 헤더 x14/y0/1252×76, 좌측 패널 x14/y132/236×496, 하단 x14/y640/1252×68. 브랜드 제목 20px/29px, 위치와 탭 경계 일치.
- 390×844(스크롤바를 제외한 내용 폭383px): 두 도구 모두 헤더 높이125, 탭 x14/y70/215.58×40, 좌측 x10/y189/363.33×250, 하단 x10/y678/363.33×156. 가로 넘침0. 실제 기능 영역의 정보량 차이는 유지.
- 라이브러리 검색·날짜 정렬·대표 이미지 3장 로딩·상세 열기 확인. 편집기 검색 결과1행, 쓰기 잠금 유지, 로그인/CSV 이동 안내 모달 확인. 실제 공개 편집기의 카테고리 CSV 14,797bytes 내려받기 성공. 웹 값 저장이나 Unity 반영 요청은 하지 않았다.
- 공개 사이트의 공통 CSS와 아이콘 총8개 요청이 모두 HTTP200이며 로컬 SHA256과 일치.
- 별도 게시용 쓰기 인증값을 새 실행에서 읽을 수 없어 실제 신규 자료 게시를 위해 라이브러리의 기존 업로드 비밀키만 갱신하고 같은 v16 소스를 환경 revision7로 배포했다. 읽기 공개 범위·쓰기 보호는 유지했고 편집기 인증·비밀번호·환경 revision1은 변경하지 않았다. 비밀값은 파일·로그·원문에 저장하지 않았다.

이 기록의 기획 라이브러리 원문/이미지 반영은 아래 게시 확인 절차를 이어 진행한다. UI 배포 완료와 기록 색인 게시 완료는 별개다.

## 증빙

- 실제 수정 전에 기존 공개 두 사이트를 동일 1280×720에서 저장: `before_library_desktop.jpg`, `before_editor_desktop.jpg`.
- 기존 공개 사이트의 모바일 기준도 별도로 저장했다. 각 after는 실제 새 공개 사이트에서 촬영했다. JPEG 원본을 보존하고 PNG는 포맷 변환만 수행했다.
- `before_library_desktop.png` ↔ `after_library_desktop.png`: 라이브러리 첫 화면,1280×720.
- `before_editor_desktop.png` ↔ `after_editor_desktop.png`: 편집기 플레이어 실제 설정,1280×720.
- `before_library_mobile.png` ↔ `after_library_mobile.png`: 라이브러리 모바일,390×844.
- `before_editor_mobile.png` ↔ `after_editor_mobile.png`: 편집기 로딩 완료 모바일,390×844.
- `after_library_cards.png`: 카드와 썸네일 보조 화면. 첫 화면과 다른 스크롤 위치이므로 전후 짝에 넣지 않는다.
- `LAYOUT_VERIFICATION.json`, `PUBLIC_ASSET_CHECKS.json`, `DESIGN_PROVENANCE.json`, `IMPLEMENTATION_VERIFICATION.json`에 실제 경계·출처·배포·검증 근거를 기록한다.
- `source_before/`는 수정 전 소스 보관본이며 공개 라이브러리 업로드 허용목록에서 제외한다.
