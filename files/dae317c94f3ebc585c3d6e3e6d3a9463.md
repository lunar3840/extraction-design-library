# A맵 구역 정체성용 Tripo 추가 제작 변경 기록

날짜: 2026-10-13

## 사용자 지시와 기획 의도

사용자는 앞서 제작한 건축 에셋만으로는 새로 정한 구역별 콘셉트를 표현하기에 부족하다고 보고, 추가 생성과 필요한 만큼의 크레딧 사용을 허용했습니다. 이전 대화의 2,500크레딧은 **누적 상한**이지 사용 목표가 아닙니다. 이번 작업은 A맵 아홉 구역의 차이를 중형 설비·작업 흔적으로 보강할 Tripo 모델을 만들되, 기존 콘셉트의 기계 점령 지상/순회하는 인간형 적/개방되지만 길이 읽히는 맵과 충돌할 모형을 피하는 것입니다. Unity 씬·프리팹·코드 변경 요청으로 해석하지 않았습니다.

## 변경 전 상태와 문제

- D05 중형 Tripo 모델 14종, D07 건물 외형 부품 14종은 생성 기록이 있으나, 그것만으로 V33 69동/아홉 구역의 각 작업 기능과 실루엣이 다르게 보이는지는 입증되지 않았습니다. D07 14종은 GLB/Unity 반입도 아직 확인되지 않습니다.
- 이전 잔액 기록 및 이번 시작 UI에서 Tripo **2,330크레딧**을 확인했습니다. D05 450 + D07 420 = **870크레딧**을 사용자 상한에 이미 사용한 상태로 계산했습니다.
- `before_tripo_balance.png`는 첫 신규 모델 생성 전 같은 Tripo 작업 화면을 저장한 것입니다. 브라우저 뷰포트 폭 때문에 상단 실제 잔액 숫자는 캡처에 들어오지 않았고, 잔액은 당시 UI 접근성 텍스트에서 확인했습니다. 캡처의 이전 건축 창 모델은 이번 수정 대상 자체가 아니라 비교 화면 배경입니다.

## 실제 변경 내용과 방법

1. GPT-6 Sol high 서브 에이전트의 구역별 갭 조사 `ZONE_ASSET_AUDIT.md`와 보유품 중복/동선 위험 조사 `REUSE_AND_RISK_REVIEW.md`를 메인이 읽고 통합했습니다. 작업 파일은 구분했고, 서브 에이전트는 Tripo/Unity를 조작하지 않았습니다.
2. 기존 D05/D07/MAV16 품목과 겹치지 않도록 `ASSET_PLAN.md`의 **20개 용도**를 선정했습니다. 각 단품 원화 PNG를 만들고, Tripo에 H3.1·비공개·일반 2K 텍스처·8K OFF·추가 강화 OFF 설정으로 올렸습니다. 화면에 표시된 가격 **건당 30크레딧**을 확인하고 20회 생성했습니다. `TRIPO_JOBS.md`에 실제 작업 URL과 완료 표시/삼각형 수를 기록했습니다. `Z10` 롤러 원화는 `Z11`과 너무 유사하여 과금 전 제외하고 `Z10b` 봉인 프레스로 교체했습니다.
3. 별도 GPT-6 Sol high 독립 검토 `INDEPENDENT_VISUAL_QA.md`에서 원화의 톱뷰 가독성·기존 품목 중복·동선/지형 연결 위험을 검토했습니다. 이 검토는 **20종 과금 후** 완료되었으므로, 그 시점에 Z07/Z09/Z12/Z17/Z19 원안의 비용을 사전에 막았다고 주장하지 않습니다.
4. 메인은 Z07의 ㄴ자 차광벽, Z09의 큰 램프/도크 판, Z19의 앞면에만 있는 패치잭을 문제로 보고 세 개의 수정 원화 `Z07r`·`Z09r`·`Z19r`을 제작했습니다. 서브 에이전트가 `REVISION_QA.md`에서 수정 방향을 **유료 재생성 전에** 독립 검토했습니다. 이어 세 수정안을 각 30크레딧 1회만 Tripo 생성하고 완료·삼각형 수를 확인했습니다. 원안 3종은 삭제하지 않았지만 배치 후보에서는 제외합니다.
5. `Z12` 파손 외부 계단과 `Z17` 점검 챔버는 생성 완료 기록과 별개로 **배치 보류**합니다. 벽/지형 접합, 실제 이동 가능성, 충돌 및 컷어웨이를 정밀하게 정해야 하기 때문입니다. Z02/Z05/Z13/Z14/Z16/Z18도 설치 슬롯과 톱뷰/동선 조건을 통과해야 합니다.

이번 **23회 유료 생성**은 690크레딧을 썼습니다. UI 잔액은 2,330→20회 뒤 1,730→3회 뒤 **1,640**으로 확인했고, 이전 작업 포함 누적은 **1,560/2,500크레딧**, 남은 상한 여유는 **940크레딧**입니다. 실제 모델은 Tripo의 `내보내기`가 표시될 때까지 확인했습니다. 단, 미리보기 오른쪽이 잘리는 화면이고 GLB를 내려받지 않았으므로 뒤·밑면/비어 있는 공간/치수/LOD/UV/재질/콜라이더/플레이어 시야/건물 실내는 확인되지 않았습니다. **생성 23개 = Unity에 바로 배치 가능한 23개**로 보지 않습니다.

## 수정 파일·에셋과 미해결 사항

- 이 폴더: `ASSET_PLAN.md`, `ART_BRIEFS.md`, `TRIPO_JOBS.md`, `ZONE_ASSET_AUDIT.md`, `REUSE_AND_RISK_REVIEW.md`, `INDEPENDENT_VISUAL_QA.md`, `REVISION_QA.md`, 단품 원화 PNG 24장(미선정 Z10 포함), 전후/결과 PNG.
- 클라우드: `TRIPO_JOBS.md`의 Tripo 생성 작업 23개. 원안은 보존하고 수정본을 후보로 표기했으며, 공유 범위는 작업 UI의 **비공개** 설정입니다.
- 미해결: GLB 수령 및 메시·후면·치수 검사, Unity 실제 설치 슬롯·컷어웨이·충돌·AI 길찾기, V33의 12개 열린 출입 틈/두 교량과 27개 대표 경로 보존, B4와 비활성 R8 간 약 62m·W5 합류 경험 비교. R8은 위험 진입 후보이지 적 위치/위험 구역 경계가 아니며 스폰 로직은 변경하지 않았습니다.
- Unity 씬·프리팹·코드, 기존 맵 지형·건물·진입점에는 **변경 없음**. 이 폴더의 문서/이미지와 Tripo 계정의 새 생성 작업만 변경됐습니다.
