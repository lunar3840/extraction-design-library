## 사용자 지시 요약
1. 좌측 수분·에너지 UI를 오른쪽으로 이동하고 더 크게 만들어 식별성을 높인다.
2. 어디서나 볼 법한 UI에서 벗어나 현재 익스트랙션 게임의 특색을 살린다.
3. 기존 지시 유지: 숫자 없는 원형 반투명 fill, 캐릭터 위 체력·스태미너, 직접 편집 가능한 Figma 요소. 앱 종료·재시작 금지.

## 기획 의도와 근거
현재 프로젝트의 사람과 아니마가 하나의 몸을 공유하는 ‘현현’, ‘현현 소켓’, ‘크래들 거점’에서 형태를 도출했다. 열린 이중 아크·받침·짝을 이루는 접점은 UI 디자인 해석이다. 새 공식 문장, 새 능력치, 확정 세계관 문양으로 간주하지 않는다.

## 변경 전 상태 및 문제
- 생존 원형 76px / 내부 아이콘 36px / 화면 x48,y956. 복잡한 지형에서 작게 보임.
- 동일한 검은 사각 유리 패널과 민트 포인트가 반복돼 고유성이 약함.
- 에델이 표시된 화면에 세린의 ‘전방 관측 / 집중 추적’ 문구가 섞여 있었음.

## 실제 변경과 방법
- 원형 112px, 내부 챔버 96px, 아이콘 52px. 쌍의 시작점을 x336,y920으로 이동; 간격20px; 전체244×112; 하단1032px 유지.
- 중량 표기는 x336,y884, 위기 상태 이상은 x336,y832로 정렬.
- 원형 잔량은 바닥부터 채움, fill 불투명도38% 변수 연결. 숫자 추가 없음. 부족·고갈 경고점10px.
- 잉크색 유리42%, 은백색 열린 테두리, 옅은 금색 접점. 동일한 형태를 무기·스킬·작전·상호작용·퀵슬롯에 적용.
- 스킬 문구를 에델의 ‘재배치 / 기동 가속’으로 정정. 재배치·가속·현현 기호를 각각 native component로 만들고 Symbol 교체 속성 제공.
- HUD 숫자를 Rajdhani SemiBold로 변경, 한글 Noto Sans KR 유지. 본문16px / 보조14px.
- 체력·스태미너는 기존 위치·크기·색을 유지하면서 작은 결합부 추가.
- 시각 검토에서 퀵슬롯 키와 간섭하던 작은 접점은 제거하고 나침반 별 장식을 덜어냄.
- 기존 공유 컴포넌트 ID를 유지하고 네 화면의 HUD 인스턴스를 갱신. 모든 UI 텍스트·벡터·변수·인스턴스는 편집 가능. 배경과 프로젝트 에셋 이미지는 이미지로 유지.

## 확인 결과
- 1920×1080에서 일반/위기/탈출/프로젝트 배경 4개 화면을 직접 확인.
- 가이드2개 포함 총6프레임: 자동 배치 컨테이너의 텍스트 넘침0건. HUD 최소 글자 크기14px. 생존 원형 내부 텍스트0개.
- 부족 상태는 낮은 fill과 경고점, 고갈은 비어 있는 챔버로 구별.
- 독립 시각 검토: 최종 미리보기·위기 화면 PASS. 장식 문자 간섭 해소, 새 겹침·잘림 없음.
- 현재 편집 범위는 Figma HUD다. Unity 런타임 연동이나 다른 모든 메뉴 화면의 재작업 완료를 의미하지 않는다.
- 프로젝트 배경은 기존 2026-10-15 캡처를 사용한 합성 디자인 미리보기다. 최신 실행 화면이나 실제 HUD 구현 증빙으로 취급하지 않는다.
- Unity를 실행·수정하지 않았으며 Codex/ChatGPT 앱을 종료·재시작하지 않았다.
