# 익스트랙션 시나리오 문구 반영

2026-09-04 · 대상 C:/UnityProject/escape

가제를 **아니마: 대단절의 잔향**으로 적용했다. 기준은 ‘세계관 설정 작성’의 통합 세계관·시나리오 설정안 v1.0이다.

- 메인 카피: 거점에서는 서로의 얼굴을, 전장에서는 하나의 몸을.
- 크래들 거점 / 작전 침식률 / 블랭크 / 현현 신체 / 작전 실패·긴급 회수로 표시 용어 통일.
- 메뉴, 슬롯, 출격, 보급소, 보관함, 인벤토리, 의뢰, 실패·귀환 안내 수정.
- A~D에 임시 탐사 지역명, 기존 네 의뢰에 새 탐사 제목 적용. 정식 시나리오 챕터 구현은 아님.
- 아이템 37종의 이름 또는 설명 수정. 기본 무기·방어구, 신경 적응 촉매, 침식 억제제와 연구 시료, 출입 카드, 구문명 유물 포함.
- 별도 무기/방어구 카탈로그의 표시 이름도 일치시킴. 블랭크 표시 폭 확장, 새 한글 글리프 사전 로딩, 진단 원문 접기.

검증: Unity 컴파일과 Windows 실행본 빌드 성공. 최종 소스 및 카탈로그를 별도 검증 프로젝트에 동기화한 뒤 기존 FrontEnd 검사 **44 PASS**. 155개 아이템과 전체 무기/방어구의 표시명·설명 외 필드가 이전과 동일함을 대조했고, 세 카탈로그 간 표시명 일치도 확인했다. 기존 저장 파일은 사용하지 않았다.

화면 캡처 제한: 숨김 실행으로 생성된 Scenario-01~05 PNG는 검은 화면이므로 시각 검증 자료로 사용하지 않는다. 캡처용 임시 코드의 D 구역 준비는 저장 revision 오류로 중단됐다. 이 오류는 사용자 프로젝트 코드나 FrontEnd 검사에서 발생한 것이 아니다. 작동 중이던 해당 미리보기 프로세스는 종료했다. 이번 결과를 실제 화면의 육안 검증 완료로 해석하면 안 된다.

맵·캐릭터·헤어·장비 외형, 저장 경로/스키마, 내부 식별자, 가격·효과·보상·침식 동작은 변경하지 않았다. 아니마 선택·구조·크래들 생활·잔류 침식·세력 평판 등 미구현 기능을 이번 문구 수정으로 구현했다고 주장하지 않는다.

최종 동시 작업 확인: 검증 후 별도 작업에서 SessionTestWorld의 부상 상태 복원, InventoryGlassView의 부상 표시, ItemCatalog의 SURGERY_KIT를 추가하고 있다. 해당 변경들은 보존했고 이번 44개 검사 범위에 포함하지 않는다. 검증사본은 이번 문구 수정 시점의 버전이다. 따라서 현재 계속 변경 중인 원본 전체와 검증사본의 해시 일치를 주장하지 않는다.
