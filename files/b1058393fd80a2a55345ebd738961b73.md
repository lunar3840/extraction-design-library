# 큰 건물 덩굴 제작 후보 독립 코드 검토

기준: 최종 적용 전 `StageARuinRolloutBuilder.ExteriorCandidateV2Fix.cs`, V2 facade/roof generator, runtime settings, `LARGE_IVY_PROBES_V1.txt`·`LARGE_IVY_PROBES_V2.txt`, 정책 `ACTUAL_RENDERER_POLICY_LARGE_IVY.json`. 이 문서는 정적/6대표 probe 검토이며 실제 62그룹 적용·Game 시야·성능 PASS가 아니다.

- 선택 리파인 API는 ivy 대표 226개 중 정책상 roots/cluster plan이 있는 정확히 62 key만 재생성한다. 출력 root `StageALargeIvy20261030`과 원래 baseline `StageARollout/A33Baseline.asset`를 분리한다. 기존 164개는 결과 재계수에만 참여한다. 기존 생성 자산 전체 3,580파일의 사전 SHA-256을 `PHASE1_GENERATED_ASSET_HASHES.json`에 동결했다. 후 적용 `--verify`에서 0변경을 요구한다.
- HALL 외벽 target을 `V13_HallRoot/Exterior/Facade`로 넓히며 기존 renderer 아래 marker와 새 parent marker가 중복될 수 있었으나 V2Fix는 새 marker 양수·원본 renderer mesh/material 불변을 확인한 뒤 기존 ivy child만 제거하고, 실패 시 새 parent ivy를 지운다. 완료 전 맵의 실제 `__A33_Ivy` marker 수 226을 hard gate한다. HALL 이관 결과는 실제 씬 audit의 marker 수/경로로 재검한다.
- 새 sampler는 정책 survey frame의 center/yaw/footprint를 읽고, roof `u/v` 및 facade `side/along` 패치를 실제 opaque 삼각면에 투영한다. Cluster sampling RNG와 성장 RNG를 구분한다. 외벽 후보/성장점은 수직 법선과 target mesh BVH의 양면 첫-hit를 검사하고, 지붕은 상부 첫-hit와 unpaired rim 가중치를 쓴다. 문/창 제외 박스는 기존 값 그대로이며 root, stem contact/연결 경로, leaf vertex에서 검사한다. Collider/physics/파손 로직은 선택 적용 경로에서 호출하지 않는다.
- V2 probe의 6대표 잎은 모두 1차 실제 ledger보다 증가했다: HALL 외벽 1,222→4,150·지붕 1,350→11,200; S06 외벽 671→1,202·지붕 750→2,153; CLINIC 외벽 1,016→1,574·지붕 1,350→6,045. HALL 외벽은 단일 좁은 shell(376tri)의 V1 698잎 실패를 상위 visual parent(30,364tri)로 넓혀 회복했다. Patch acceptance는 6대표 모두 planned 전량이며, roof 중 HALL은 leaf budget 11,200에 도달했다. 이 수치는 새 62그룹 전체 결과가 아니다.
- 외부 노출 검사는 **해당 target mesh 내부**의 BVH를 사용한다. 다른 건물·별도 장식·게임 카메라/그림자 가림까지 판정하지 않으므로 정책의 `ivyVisibleShellAudit` 62건은 아직 pending이다. HALL parent의 source renderer 74개는 V2Fix의 `Take(largePlan ? 256 : 64)`에 모두 들어가지만 runtime `SurfaceIvyInstance.RefreshVisibility()`의 첫64개 검사와 V33 별도 binding 상태는 실제 HALL 실내 Game으로 확인한다.
- 계획 잎 예산 218,300→358,500은 실제 생성량이 아니다. 1차 Editor 10뷰에서 GPU median이 9뷰 증가하고 scene active instance triangle이 약24% 늘어난 근거가 있으므로, 62그룹 적용 후 동일 Game 카메라/150프레임과 실제 drawn triangle·GPU timing을 재비교한다. 목표 빌드 FPS는 측정하지 않았다.

필수 적용 후 게이트: 새 정책 62 key만 변경, 총 물리 marker 226 및 226그룹 모두 양수 잎, 기존164 marker/asset 유지, source renderer mesh/material/collider/기능 참조 동일, HALL/S06/CLINIC과 나머지 큰 외벽의 실제 camera visible ivy 증가, 문·창/실내 cutaway 시야 유지, Nav 1,205경로와 성능 실측. 하나라도 불확실하면 숫자 ledger만으로 시각 PASS를 주지 않는다.
