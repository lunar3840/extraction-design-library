# Z07r·Z09r·Z19r 원화 수정 독립 검토

2026-10-13. 수정 원화 3장을 각각 열어 이전 `Z07`·`Z09`·`Z19`와 비교했다. **세 수정본 모두 30크레딧 1회 시험 생성 가치가 있다.** 이는 원화 기준 판단이며 Tripo 3D 품질이나 Unity 배치 합격은 아니다. 기존 원본 3장은 이 검토보다 먼저 유료 생성됐으므로, 이미 쓴 비용을 되돌릴 수 없으며 **향후 배치 후보에서 제외**하고 `r` 수정본으로 연결한다.

| 수정본 | 이전 지적 해결 여부 | 과금 판단과 남은 검사 |
|---|---|---|
| **Z07r** 열린 용접 스테이션 | 이전 L자 높은 차광판 두 장이 **뒤쪽 한 장**으로 줄고 앞·양옆이 열린 작업대가 됐다. 벽/반폐실처럼 통로를 자르는 위험은 크게 낮아졌다. 후드와 책상은 공구 공방의 작업 기능을 유지한다. | **1회 시험 권고.** 실제 탑뷰에서 큰 후드가 작업면을 전부 가리는지 확인하고, WC 문·열린 게이트가 아닌 벽 옆 작업 슬롯에 배치한다. 후드 기둥/판 충돌은 단순화한다. |
| **Z09r** 소형 화물 저울 | 긴 차량용 램프와 넓은 바닥판이 없어졌다. 네 다리의 독립 테이블과 크게 보이는 원형 계기로 D05 `IndustrialPlatform` 도크보다 분명히 작은 검수 설비다. 도크/도로의 시각·점유 중복 지적은 원화상 해소됐다. | **1회 시험 권고.** 원형 계기가 카메라에서 보이는 방향에 놓고 하역 통로를 비운다. 판이 실제 통과 바닥이나 차량용 램프로 오해되지 않게 3D 치수를 확인한다. |
| **Z19r** 상부 패치 아일랜드 | 앞문 속에만 있던 잭을 **기울어진 상부 전면 8개 원형 소켓**으로 옮기고, 아래에 큰 케이블 코일 3개를 노출했다. 탑뷰에서 일반 회색 캐비닛보다 통신 접속 설비로 읽힐 가능성이 높고, 열린 문 충돌도 사라졌다. | **1회 시험 권고.** 실제 게임 카메라에서 소켓/코일이 보이는지, Tripo가 코일·잭을 서로 붙여 평판으로 만들지 않는지 앞·위·뒤와 GLB에서 확인한다. 실내 컷어웨이/배치 슬롯 검사는 별도다. |

총 3회가 현재 표시가 유지된다는 **30크레딧/회 가정**이면 90크레딧이다. 실행 직전 가격·잔액과 생성 옵션을 다시 확인하고, 실패 시 유료 재시도를 자동 진행하지 않는다. `Z12`·`Z17`의 지형/건물 정밀 접합 보류 판정은 이 세 수정본으로 바뀌지 않는다.
