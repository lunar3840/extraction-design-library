# Figma 슬롯 정보 간소화 · 추가 작업

사용자 후속 지시: 슬롯 위의 V/T 티어 문자와 상시 이름·내구도·의료 잔량을 숨기고, 기존 파스텔 외곽선·슬롯 면색으로 티어를 구분한다. 아이콘을 키우고 수량은 우하단 숫자만 보인다. 수량 1도 표시하며 × 접두사는 쓰지 않는다. 툴팁과 상세 정보의 티어·내구·잔량은 유지한다.

## 실제 변경 전 보존

- 직전 저장한 `after_figma_inventory_final.png` / `after_figma_hud_final.png`는 이번 후속 수정 직전의 실제 Figma 1× 상태다. 파일명을 바꾸거나 덮어쓰지 않는다.
- `before_slot_simplification_figma_master_native.jpg`: UI Kit에서 실제 Tier/Item 12개 variant가 보이는 1085×1025 창, 96% 배율의 수정 전 캡처.
- Unity before와 코드 변경은 메인 담당이며 이 문서에 Figma 작업만 기록한다.

## 실제 저장된 변경

1. `Tier/Item` 11:429의 12개 variant(6등급 × Default/Selected)를 보존하고, 각 `Value tier row` 12개를 숨겼다. 삭제나 래스터 교체 없이 기존 Image Fill 레이아웃이 공간을 차지하도록 했다. 이미지 영역은 Default 74×52, Selected 72×50이며 Quantity 행은 유지된다. 원본 컴포넌트가 연결된 가방/전리품 슬롯에도 변경이 전파된다.
2. 기존 원색 변수 `pastel/tier/1/tint`부터 `/6/tint`의 알파를 13% → 24%로 바꿨다. RGB는 각각 `#DCE2EC`, `#ADE4BE`, `#A9CEF5`, `#CCB8EC`, `#EDD29A`, `#EEB3B7`를 유지했다. semantic `color/tier/n/tint`의 기존 alias와 슬롯의 변수 결합을 보존했다. 신규 변수는 추가하지 않았다. Default/Selected의 기존 stroke 강도 차이를 유지한다. 이 공통 tint 변수에 연결된 작은 티어 배지의 바탕에도 농도 변경이 전파된다.
3. 검토 인벤토리 105:2987의 무기 Quantity 텍스트 105:3192는 `0 / 100` → `1`, 방어구 105:3255는 `80 / 100` → `1`, 배낭 105:3263은 `44 / 100` → `1`로 바꿨다. 실제 스택 수량은 유지한다. hover 304×260 카드의 V2, 남은 용량 120/120, 설명은 보존했다. 왼쪽 캐릭터 크기, 열 배치, 92px 셀/8px 간격은 수정하지 않았다.
4. 최신 HUD 103:2538의 소모품 수량 텍스트 103:2830, 103:2836, 103:2848을 각각 `×1` → `1`로 바꿨다. 기존 64×24 입력/수량 행의 양끝 정렬이 유지되어 8px 숫자는 local X58, Y2로 우측에 놓인다. 키3/4/5 좌하 키캡과 3칸 가로 배치, 무기의 탄약·관통 정보는 보존했다.
5. 구 UI Kit의 원본 03 Inventory 화면 4:149도 같은 슬롯 규칙으로 정리했다. 무기 인스턴스 4:272의 Quantity 97:283 (`0 / 100`), 방어구 4:322의 Quantity 97:272 (`80 / 100`), 배낭 4:329의 Quantity 97:120 (`44 / 100`)만 각각 `1`로 바꿨다. 원본의 캐릭터/배치/다른 텍스트는 수정하지 않았다. 세 값이 함께 보이는 실제 96% 화면을 편집 전에 저장했으며 동일 뷰의 after도 저장했다.

- `after_slot_simplification_figma_master_native.jpg`: 12개 슬롯에서 V행이 사라지고 아이콘과 우하단 숫자가 남은 실제 네이티브 화면. 우측 선택된 6/Selected의 `color/tier/6/tint` 결합도 보인다.
- `after_slot_simplification_figma_tint_variables_native.jpg`: 기존 원색 6개 모두 24%로 저장된 실제 Variables 화면.
- `after_slot_simplification_figma_inventory_native.jpg`: 검토 인벤토리 전체 24% 네이티브 화면. 캐릭터/열/툴팁 구조를 보존했다.
- `after_slot_simplification_figma_hud_counts_native.jpg`: HUD 세 수량이 모두 1인 레이어 목록과 실제 캔버스. 편집 편의를 위해 좌측 패널만 일시적으로 418px로 넓혔다.
- `before_slot_simplification_figma_original_inventory_native.jpg` / `after_slot_simplification_figma_original_inventory_native.jpg`: 원본 세 Quantity의 실제 수정 전후. 창 1085×1025, 96% 배율과 viewport를 유지했다. 선택 대상은 무기에서 배낭으로 바뀌었다.
- 검토 배낭의 추가 변경 전후는 `before_slot_simplification_figma_review_backpack_native.jpg` / `after_slot_simplification_figma_review_backpack_native.jpg`와 대응 `*_ax.txt`에 남겼다. 해당 Quantity는 툴팁과 viewport에 가려져 있으므로 이미지만으로 수치를 확인했다고 주장하지 않는다. 실제 Figma 접근성 트리에서 105:3263의 문자열 `44 / 100` → `1`을 확인했다.
- 모든 네이티브 JPG 증빙은 크기 변경·자르기 없이 PNG로도 변환했다.
- 최종 1× PNG는 네이티브 Figma Export로 저장 완료했다. `after_slot_simplification_figma_inventory_final.png` (1920×1080, 1,677,155 bytes)와 `after_slot_simplification_figma_hud.png` (1920×1080, 3,838,408 bytes)가 최종이다. 배낭 정리 직전의 `after_slot_simplification_figma_inventory.png`도 중간 기록으로 보존한다. 세 파일 모두 크기 변경·자르기·후처리 없는 실제 export다.
- 독립 검토자는 위 네이티브 5장과 1× 인벤토리/HUD 전후를 직접 열어 PASS로 판정했다. V행 제거, 약 1.7~2배로 커진 병 아이콘, 우하단 plain 수량, 6색/24%, HUD 수량 1 세 개와 인벤토리 구조 보존을 확인했다. 툴팁 V2·120/120 및 캐릭터/3열/그리드/HUD 배치를 유지하고 새 잘림·겹침이 없음을 1×에서 재확인했다.
- 배낭까지 정리한 `after_slot_simplification_figma_inventory_final.png`도 독립 검토자가 다시 직접 열어 PASS로 판정했다. 원본 96% 전후에서 세 값이 모두 1인 것을 확인했으며, 툴팁에 가려진 검토 배낭은 같은 노드 ID 105:3263의 저장된 전후 접근성 기록에서 `44 / 100` → `1`, 텍스트 폭 51 → 8 Hug를 확인했다.
