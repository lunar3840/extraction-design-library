# Delta Force 참고 컴팩트 전투 HUD

- 작업일: 2026-10-22
- 사용자 지시: 첨부한 델타 포스 화면처럼 UI를 더 컴팩트하게 제작.
- 대상: Figma `EXTRACTION · Modern Glass UI Kit` / `Gameplay · HUD & Overlays` 페이지.
- 결과 프레임: `103:2538` — `14 · Field HUD · Compact combat · Project backdrop`.
- 링크: https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0?node-id=103-2538

## 기획 의도와 변경 전 문제

기존 HUD는 무기 카드가 중앙 하단에 있고, 동료 이름 패널과 스킬이 우측에 별도로 쌓여 전투 화면을 넓게 차지했다. 반복되는 무기 종류·발사 방식·목표 설명도 상시 노출됐다. 첨부 참고 화면의 작은 하단 정보 묶음과 가벼운 배경 처리를 현재 게임의 둥근 아이콘·파스텔 생존 게이지에 적용했다. 전체 폰트를 일괄 축소하는 방식은 사용하지 않았다.

## 실제 변경

기존 `69:2948` 프레임을 보존하고 복제한 별도 비교 시안을 x4400/y9500에 배치했다. 크기는 동일한 1920×1080이다.

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 목표 본문 | 300×144, 카테고리·상태·설명 상시 표시 | 300×80, 제목·진행 수량·진행선 중심 |
| 목표+탈출 전체 | 300×200 | 300×136 |
| 주무기 | 264×136, 배경 카드와 식별 행 | 264×104, 배경 fill 및 식별 행 숨김 |
| 보조무기 | 200×104, 배경 카드와 식별 행 | 200×80, 배경 fill 및 식별 행 숨김 |
| 무기/퀵슬롯 묶음 | 480×228, x720/y804 | 480×196, x1392/y836 |
| 무기 정렬 | 하단 정렬 | 상단 정렬, 탄수 기준선 일치 |
| 퀵슬롯 | 어두운 배경 fill | 배경 fill 숨김, 에셋·키·수량·가느다란 윤곽 유지 |
| 동료 헤더 | 300×56 상시 표시 | 이 전투 비교 시안에서 숨김 |
| 스킬 묶음 | x1572/y904 | x1056/y904, 무기 왼쪽 하단에 정렬 |
| 선택 장식 | 주무기 상단 흰 선 | 배경이 사라진 상태에서 떠 보여 숨김 |

수분·에너지는 이전 사용자 요청의 식별성을 유지하기 위해 112px 원형과 숫자 없는 아래에서 차오르는 fill 표현을 유지했다. 체력·스태미너는 캐릭터 위에 유지했다. 핵심 글자 크기, 탄수 위계, 명암, 둥근 키캡도 유지했다.

## 변경 방법과 편집 가능성

Figma 데스크톱의 일반 편집 기능으로 변경했다. 새 비교 프레임 안의 목표 인스턴스와 무기 2개·퀵슬롯 4개 인스턴스는 고정된 내부 레이아웃의 높이를 조정하기 위해 분리했다. 텍스트·프레임·아이콘·에셋 레이어를 유지했으며 UI를 이미지로 평면화하지 않았다. 일부 분리한 레이아웃은 원본 컴포넌트의 후속 구조 변경을 자동 상속하지 않는다.

원본 컴포넌트와 기존 시안을 이번 압축안으로 일괄 변경하지 않았다. 이번 결과는 전투 HUD 한 장의 편집 가능한 비교 시안이다. 전체 UI 키트의 모든 상태·해상도 적용이나 Unity 런타임 구현 완료를 의미하지 않는다.

## 확인 결과

- 같은 게임 배경·캐릭터 자세·1920×1080 해상도의 실제 Figma PNG를 전후 비교했다.
- 중앙 하단의 큰 카드가 없어져 캐릭터 아래 공간이 열렸다.
- 목표 제목과 수량, 무기 탄수, 퀵슬롯 키·수량, 스킬 이름·준비/충전 정보에 새 잘림이 보이지 않는다.
- 독립 검토의 보완 권고였던 무기 기준선과 떠 있는 선택선을 수정했다.
- 일반 전투 시안의 시각 검토만 수행했다. 긴 현지화 문자열, 재장전·경고 등 모든 상태, 다른 화면비의 런타임 검증은 이번 범위에 포함하지 않았다.
- Unity·게임 에셋·맵은 수정하지 않았고 앱이나 작업 탭을 종료·재시작하지 않았다.
