# 컨셉아트 신규 제작 기록

- 사용자 지시: 우리 익스트랙션 게임 컨셉아트를 니어 오토마타와 니케 느낌으로 제작.
- 기획 의도: 폐허의 고독한 분위기와 선명한 서브컬처 전술 캐릭터 표현을 조합해 시각적 방향을 탐색한다.
- 참고한 현재 프로젝트 설정: outputs/SCENARIO_COPY_REPORT.md의 가제와 시료·회수 용어, outputs/map_design/2026-09-15/stage-a-relay-v07/MAP_CONCEPT.md의 부분 침수 도시 정비지구 배경. 지도 배치나 로직을 변경하는 작업이 아닌 홍보용 분위기 일러스트이다.
- 변경 전 상태 및 증빙: 기존 에셋 수정이 아닌 신규 이미지 2장 제작으로 대응하는 이전 이미지가 존재하지 않는다. before 스크린샷은 해당 없음이며 생성 후 이미지를 이전 상태로 재구성하지 않았다. 실제 게임의 변경 전후 화면으로 주장하지 않는다.
- 실제 추가 내용: 은빛 라벤더 머리, 아이보리 코트, 어두운 전술복, 회수 시료통을 조합한 새 캐릭터 제안과 폐허 속 회수 작전 키비주얼.
- 방식: 내장 image_gen으로 서로 독립적인 이미지 2장을 생성했다. 각 최종 프롬프트는 outputs/concept_art/2026-09-21/anima-v01/PROMPTS.md에 보관했다.
- 확인 결과: 두 이미지를 육안 검토했다. 키비주얼에서 인물과 침수 산업 폐허가 명확하고, 캐릭터 시트에서 얼굴·앞모습·뒷모습 및 머리색을 확인했다. 문자와 로고가 없다. 독립 생성으로 두 이미지의 코트 구조·총기·시료통 위치에 세부 차이가 있어 동일 모델 제작용 확정 도면으로는 사용하지 않는다. 키비주얼의 하체는 화면 아래에서 잘리고 시트는 발끝까지 보인다.
- 결과 증빙: after_keyvisual.png / after_character_sheet.png는 생성 결과 원본의 복사본이다. 게임/도구 스크린샷이 아니며 신규 산출물 기록용이다. 동일 시점 전후 비교는 해당 없음.
- 주요 추가 파일: outputs/concept_art/2026-09-21/anima-v01/anima-extraction-keyvisual-v01.png, anima-operative-sheet-v01.png, PROMPTS.md.
- 범위: 탐색 시안만 추가. 세계관 확정이나 캐릭터 교체, 지도 설계·배치 변경, Unity 실행·수정은 수행하지 않음.
