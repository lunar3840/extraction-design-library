# 맵 작업 서브 에이전트 모델 지정 변경

- 사용자 지시: 앞으로 맵 관련 작업의 서브 에이전트를 GPT-5.6 Sol high에서 GPT-6 Sol high로 변경.
- 의도: 이후 맵 기획·제작·검증을 병렬로 수행할 때 최신 요청의 모델을 일관되게 적용.
- 변경 전: 프로젝트 `AGENTS.md`의 맵 병렬 지침은 모델 세대를 지정하지 않은 `Sol high`라고 적혀 있었다.
- 변경: 해당 역할에 `GPT-6 Sol high`를 명시하고 2026-09-23 요청을 같은 절에 기록했다.
- 방식: 기존 맵 작업 분담·파일 소유·통합 검토 규칙은 그대로 두고 모델 지정 문장만 수정했다.
- 확인 결과: 변경 전후 `AGENTS.md`의 같은 절을 대조해 새 모델 지정이 기록된 것을 확인했다. 실제 서브 에이전트를 시작하는 다음 맵 작업부터 적용된다.
- 전후 화면: `before_instruction.png` ↔ `after_instruction.png`. 설정 파일의 해당 절을 동일한 글꼴·크기·화면 범위로 렌더링한 비교 이미지다. 게임 화면의 변화는 없다.
- 수정 파일: `AGENTS.md`.
