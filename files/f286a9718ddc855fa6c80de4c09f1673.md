# 공통 테마 최종 코드 검토

Inventory 담당의 읽기 검토. UiTheme 런타임 코드는 이 담당자가 수정하지 않았다. 메인이 저장한 최종 소스를 `source_after/Assets/Escape/Runtime/UI/UiTheme.cs`에 복사했고, 변경 전 `source_before`는 보존했다. 정확한 SHA256/저장 시각은 `FINAL_THEME_COMPILE_STATE.txt`에 있다.

- 최종 전체 runtime 정적 컴파일을1회 수행해 오류0/기존 경고21을 확인했다. 기록 폴더의 `compile_inventory_hud/runtime_compile_final_theme.txt`에 결과를 저장했다. Editor 최종 컴파일은 다른 helper 담당이 수행하므로 여기서는 반복하지 않았다.
- Surface는 실제 높이의 절반 이하 radius를 계산하고9-slice border를 rounded와 동일하게 사용한다. 이전 radius+1 때문에 작은 캡슐 상하 border가2px 넘던 문제를 해소한다. Fill/edge/radius 캐시와 Repaint 전용 draw를 유지한다.
- compact shared button/HudGlass/HudCard는 texture radius12와 border12가 일치한다. InventoryButton은 별도10px texture/border를 사용해22~24px 높이에서도 상하가 겹치지 않는다. InventoryCard16/major panel26은 큰 면에 유지한다. LobbyPrimary radius20/border20은 사용처의 최소42px 높이에 들어간다.
- disabled LobbyPrimary는 기존 GUI.enabled 및 요청 enabled의 결합이 false일 때만 별도 dark style로 선택한다. 원본 LobbyPrimary의 state를 변조하지 않고 fontSize와 GUI.enabled를 finally에서 복원한다. 스타일을 직접 지정하는 FrontEnd의 GUILayout primary2개는 기존enabled 상태에서 쓰이며, 비활성인 연구/복원/동조 버튼들은 UiTheme.Press 경로를 사용한다.
- 글자 shadow는 배경 없는 label만 그린다. 버튼/키캡 backing이 중복되지 않으며 GUI.contentColor와 fontSize 복원, BeginScope의 skin/matrix/depth/color/GUI.enabled 복원은 유지된다.
- Malgun Gothic 우선 경로와 기존 glyph preload를 사용한다. Hover는 기존 별도 GUIStyle/흑연 배경/폰트 측정 경로를 유지하고 파일 변경이 없다. 새로운 실제 hover의 글자 표시 여부는 별도 화면에서 확인해야 한다.
- Bolt는 최초1회 생성한96px antialias texture를 지정 rect 크기로 그리며 textures 및 Reset의 bolt=null 경로로 관리한다. 수치 변화에 따른 icon texture 재생성은 없다.

정적 검토에서 중대한 GUI 상태·tooltip glyph·입력 회귀를 발견하지 못했다. 최종 실제 코너/비활성 버튼/개조 caption/hover 화면 검증을 대신하는 결과로 취급하지 않는다. 앱 조작·실행·종료는 하지 않았다.
