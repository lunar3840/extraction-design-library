## 적용과 검증의 구분

- runtime20개 파일의 표시 코드와 공통 스킨을 적용했다(그중 HUD 전용2개 파일은 신규). Editor 전용 검증 도구는 별도1개이며 최종21개 소스 스냅샷·SHA는 final-source-manifest.json에 있다. 저장·경제·성장·전투·맵 배치 규칙을 Figma 예시값으로 바꾸지 않았다.
- 실제1920×1080 before34장과 각 단계 after/after_r02~r06의34장·manifest·상태 파일을 모두 보존했다. 최종 r06은 큰 아이콘·우하단 수량·등급별 배경색과 탄약6색을 확인한 판본이며, VISUAL_AUDIT_SLOT_SIMPLIFICATION.md의 독립 검토를 읽어 통합했다. 화면 캡처 경로는 임시 프로필로 격리하고 완료 후 원래 경로를 복구했다.
- API fixture 캡처는 실제 렌더링 증거이며 키보드/마우스 조작 통과를 대신하지 않는다. 입력 결과는 별도 INPUT_VALIDATION.md에 실제 수행분만 남긴다.
- 의료 휠의 최초 before는 휠이 열리지 않았던 누락이다. after의 실제 열린 휠과 가짜 대응 before로 비교하지 않는다.
- 공통 테마는 현재 프로젝트의 IMGUI에 적용했다. 프로젝트 UI 시스템을 uGUI/UI Toolkit으로 갈아엎지 않았다.
- 네트워크/지원되지 않는 새 메뉴나 게임 기능까지 구현한 것으로 확대하지 않는다.
