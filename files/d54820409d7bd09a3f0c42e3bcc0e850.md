# CLINIC 실제 적용 결과

2026-10-30. 동일 D09 주제의 당일 회차04. 최신 지붕 요구는 개별 잎의 작은 불규칙한 Y 높낮이이며, 식생 덩어리 전체를 지붕에서 띄우는 방식은 폐기했다.

최종 Game 이미지는 `rounds/finished/after_<시점>.png`다. 북벽 아래에 넓은 비대칭 가지와 여러 뿌리 발이 생겼고, 회백색으로 튀던 뿌리·파편은 젖은 갈색 흙과 국소 물고임에 이어지도록 낮췄다. 지붕은 기존 줄기와 잎자루를 고정한 채 잎판의 높이·기울기·굽힘을 달리해 작은 그림자가 생긴다.

## 검토와 기능

독립 검토자는 최종 12장을 직접 열어 이번 국소 목표의 미감을 합격으로 판정했다. 메인이 결과를 읽고 지붕·벽/지면·출입·통제 화면을 직접 재확인했다. 상세 관찰과 기존 A33 경로·짙은 하부 잎·근접에서 가장 잘 읽히는 젖음의 한계는 `staging/review/CANDIDATE03_VISUAL_REVIEW.md`를 따른다.

`aft06`의 실제 PlayerMotor 출입 이동 21걸음과 원 before의 동일 조건 대조를 통과했다. `rev03_clinic_north_reveal.png` / `rev03_clinic_north_reveal_restored.png`는 벽 가림과 성장 장식의 연동, `rr03_clinic_roof_reveal.png` / `rr03_clinic_roof_restored.png`는 원지붕 renderer 가시성과 잎·줄기 연동을 각각 실제 Game에서 확인한 기능 증빙이다. 전후 아트 비교 사진을 대신하지 않는다.

각 원시 보고서는 `staging/validation/play_bef03`, `play_aft06`, `play_rev03`, `play_rr03`의 `PLAY_REPORT.json`이며, 최종 조건 대조는 `PLAY_PAIR_COMPARISON_finished.txt`다. 원본 보존·저장/재열기·도구 정리와 공개 게시의 최종 결과는 `CHANGE_RECORD.md` 및 `staging/validation/FINAL_VALIDATION.md`에 연결한다.

## 적용 범위와 남는 차이

CLINIC 한 곳의 북벽·기초·지붕만 적용했다. 다른 건물의 그래픽 일괄 변경이나 전맵 식생 재생성을 하지 않았다. 원지붕의 기존 방사형 성장 경로와 상부 군집은 남는다. 잎별 높낮이를 바꾸어 평면감을 줄인 것이 이번 지붕 결과다.

새 A34 벽/지면 root는 6 renderer와 collider/light 0을 유지하고 4,735→7,996삼각형이다. 기존 roof ivy의 186,920삼각형과 줄기 41,840정점 위치는 유지했다. 제작·검증 도구는 작업 후 프로젝트 밖에 보관한다. 실제 빌드 성능을 합격 처리하지 않았으며, 일부 Editor P95 상승이 원격 통제 화면에서도 관찰되어 이번 국소 변경의 영향으로 분리하지 못했다.

## 중간 결과를 읽을 때

루트 `after_*.png`는 후보03, `rounds/final`은 최초 후보04 화면, `rounds/display_refresh`는 표시 갱신 실험, `rounds/verified`는 재가져오기·재열기 후 마감05 이전 결과다. 모두 당시 원시 파일과 함께 보존했으며 최신 결과로 덮어쓰지 않았다. 최종 비교는 반드시 `rounds/finished`를 사용한다. 초기 사전검사 실패와 표시 갱신 조사, 최초 gpu04 촬영 실패는 `CANDIDATE03_REJECTED.md`와 `failed_attempts/`에 남긴다.
