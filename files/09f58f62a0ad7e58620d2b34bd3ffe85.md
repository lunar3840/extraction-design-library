## 실제 게임 화면과 수정 재검증

- 전 회차 `play_after/`와 이번 회차 최종 10시점은 player/camera 좌표가 전부 동일하고 시점마다 Editor 150프레임을 측정했다. 실제 Game 스크린샷 10쌍과 별도 camera 스크린샷이 존재한다. HALL 2시점은 아래 수정 뒤 `play_hall_final/`을 **최종본**으로 사용하고, 다른 8시점은 `play_after/`를 사용했다. [최종 Play 비교](FINAL_PLAY_COMPARISON.json)
- 최초 `play_after/after_play_game_HALL_inside.png`에는 실내 캐릭터 옆에 큰 덩굴 다발이 허공에 매달린 결함이 보인다. 이 중간 증빙은 보존했다. 맵 전용 `AMapRuinIvyRevealBinding.cs`는 소스가 정확히 HALL `Exterior/Facade` aggregate일 때 `StageAHallV13LayerVisibility.VisibleFloor != 99`인 실내에서만 그 aggregate의 생성 renderer를 숨기도록 보완됐다. 다른 164그룹, 공통 V33/HallVisibility, collider는 이 보완의 수정 대상이 아니다. 최종 `play_hall_final/hall_final_play_game_HALL_inside.png`에서 대형 전경 덩굴이 사라져 캐릭터·실내 바닥·벽이 다시 보이고, `hall_final_play_game_HALL_outside.png`에서는 외벽 상부 덩굴이 유지된다. 이 두 지정 화면에 대한 시각 문제는 해결됐다.
- `S06_outside`와 `S06_inside` 실제 Game은 지붕·상단 외벽 덩굴 증가와 캐릭터·출입구 가독성을 보여준다. `CLINIC_inside`도 캐릭터를 가리지 않는다. 기존 `CLINIC_outside`는 지붕 투영 탓에 북측 외벽 판정에 부적합하다. 보조 실제 Game `play_after_supplement/after_play_game_CLINIC_true_exterior.png`에서 지면 플레이어 뒤 북측 외벽 수직 덩굴과 지붕 패턴이 전 회차 같은 시점보다 분명하고, 창·캐릭터는 보인다. 보조 화면은 2/2 촬영 완료, 엄격 지면 Nav 수평 차 0·수직 차 0.077m/0.047m다. `SW_vehicle_close`의 차량 두 대 외형은 전후 사진에서 유지되며 이번 회차 변경 대상은 아니다.
- `W05_vehicle`라는 기존 ID는 실제로 W05 **실내** 시점이다. 이를 차량 근접 검증으로 취급하지 않았다. B4와 비활성 위험 진입점 R8은 별도 비교 시점이다.

- 최종 실제 Game HALL 실외 `UnityStats` 중앙 삼각 수는 4,573,896→8,697,590, draw calls 2,749→2,775이다. HALL 실내는 수정 뒤 2,836,241→2,802,238이다. 다른 8시점 중 `CLINIC_outside`만 삼각 수가 거의 동일하고 나머지 7개는 증가했다. 화면별 Editor frame 시간은 외부 조건과 에디터 상태 영향을 받으므로 빌드 FPS 또는 목표 성능 통과로 판정하지 않는다.
