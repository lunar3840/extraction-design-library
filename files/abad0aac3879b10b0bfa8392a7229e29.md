# A맵 V31 — 9분할을 없앤 연속 지형 동선 도면

## 사용자 지시 및 범위

사용자가 V30의 9분할 구조를 지적했고, 구역을 둘러싸는 방 형태 대신 하나의 지형 안에서 이동이 분기·합류하는 도면을 요청했다. Unity는 수정하지 않고 도면만 작성했다.

## 변경 전 문제와 기획 의도

V30의 연속 경계는 직선 횡단을 강하게 제어했지만 맵을 격자형 방으로 분리했다. V31은 구역 색칠·외곽까지 이어진 경계·22개 게이트를 계승하지 않는다. 네 개의 독립 지형·시설 덩어리로 필요한 직선 횡단만 제어하고, 주변의 열린 끝과 마당을 연결 상태로 둔다.

## 작성한 부분과 방법

- A 비스듬한 북측 능선, B 작업장 한쪽 적치 기단, C 창고 앞 비스듬한 설비 단차, D 제방의 국소 돌출부를 다각형 점유안으로 설계했다.
- A의 낮은 안부 S는 선택 통로이며 이를 닫아도 양 끝으로 돌아갈 수 있게 했다.
- 대표 이동 흐름을 표시하고 북측 흐름은 전력시설 서쪽, 동측 흐름은 창고 앞에서 합류하도록 그렸다. 길 밖 탐색도 허용되는 도면이다.
- 메인이 PLAN.json 생성 원본과 DESIGN.md를 작성하고 GPT-6 Sol high 제작 에이전트가 전체·확대 PNG/SVG를 제작했다. 별도 GPT-6 Sol high 검토 에이전트가 평면 연결·간섭·우회를 검사했다.
- 기존 건물, 기본 진입·탈출 좌표, 수면·두 교량을 참조로 유지했다. 인간형 적 상주 기지나 신규 해금 조건은 추가하지 않았다. R은 비활성 유지다.

## 증빙 이미지

- `before_plan.png`: 작업 착수 전에 복사한 V30 전체 설계도 원본.
- `after_plan.png`: V31 전체 제안 도면.
- `after_details.png`: V31 북측·작업장·동측 확대도.
- 위 이미지는 실제 게임 적용 전후 화면이 아니다. 도면 변경 전후이며 동일한 지도 좌표계 520×400m를 사용한다. 도면 레이아웃이 달라 픽셀 단위 비교는 아니다.
- Unity 실행이나 변경을 하지 않았으므로 새 게임 스크린샷은 생성하지 않았다. 제안 도면을 실제 적용 결과로 표시하지 않는다.

평면 검사는 S 열림·닫힘 모두 연결된 육지 1개, 새 지형과 저장 건물 겹침 0, 대표 흐름 중심선 및 제안 폭의 지형·건물 간섭 0을 확인했다. 작업장 샘플은 기존 기준 35.00m에서 61.25m, 창고 방향은 81.07m에서 112.74m로 우회가 늘었다. 임의 횡단 전체를 막은 결과가 아니라 선택적 제어다.

교량 연결 띠 가장자리에는 0.5m 격자 외곽 불일치가 있어 실제 교량 유효 폭 확보를 확정하지 않는다. 상세 한계는 REVIEW.md에 보존했다. 전후 설계도 이미지와 이 기록을 같은 폴더에 저장했다.
