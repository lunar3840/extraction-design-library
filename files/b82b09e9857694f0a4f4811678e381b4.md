# Figma UI kit v2 scope

사용자 요청: 6단계 파스텔 티어 색, 은은한 명암, 현재 게임의 전체 UI 요소를 편집 가능한 Figma로 제작.

현재 소스 기준: C:/UnityProject/escape/Assets/Escape/Runtime.
Unity 파일은 이번 작업에서 변경하지 않는다. 새 기능/밸런스 확정이 아닌 화면과 상태 디자인이다.

- 티어: ItemValueTier 및 ItemTierPresentation의 V1–V6 순서와 판매가 문턱 유지. T는 탄약 관통 등급으로 별도 표시.
- 공통 부품: 티어 배지/슬롯, 생존 수치, 부상/버프, 스킬, 탄약, 상호작용, 진행 표시, 알림, 지도 마커, 입력/선택/스크롤/모달 상태.
- 인게임: 일반/위험 HUD, 의료품 휠, 지도 UI, 무기 개조/탄약/의료품 상세, 동료 칩 선택, 대화/기록, 탈출/작전 실패/손실 저장.
- 거점: 로비/출격 준비, 보관함, 상점, 공용 연구, 동료 능력, 칩 복원, 탐사 의뢰, 타이틀, 새게임/불러오기, 저장/대기/확인/오류.
- 검수: 네이티브 텍스트 및 연결된 컴포넌트, 변형/텍스트/이미지 속성, 변수 별칭/범위, 프레임 경계 및 실제 Figma 렌더 확인.

지도 UI의 지도 영역은 표시 체계 설명용 도식이며 실제 A맵 지형·배치 변경이 아니다. 화면의 수치·티어는 디자인 예시이며 게임 데이터 구현과 구별한다.
