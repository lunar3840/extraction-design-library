# 차량 안쪽 면 보강 사용

Unity의 **Escape → Environment → Surface Ruin Tool**에서 차량 에셋을 추가하고 구조 종류를 `차량` 또는 `자동`으로 지정합니다. **실제 형상 파손·파편**을 켜서 미리보기를 생성하면, 새로 잘린 외판 영역에 안쪽 금속면과 절단 연결 면이 함께 생성됩니다. 별도 차량 한 개에만 수작업으로 붙인 모델이 아닙니다.

파손 강도·파편·노후화·덩굴과 시드 조작, 새 프리팹·재사용 프로필 저장 절차는 기존 도구와 같습니다. 이전 프리팹을 입력해 다시 생성하면 원래 외형을 복원한 작업 사본에서 새 설정으로 처리합니다. 원본 파일은 보존됩니다. 기존 건물 처리에는 차량 보강을 적용하지 않습니다.

덩굴을 잠시 끈 미리보기에서도 내부면·창·좌석 공간과 절단면을 확인한 뒤 새 프리팹으로 저장해 주세요. 기본 충돌 생성은 꺼져 있으며 맵에 배치할 때 이동·충돌·가림은 별도로 확인합니다. 외판 선별은 형태를 이용한 추정이므로 차종별로 외관 확인이 필요합니다.
