# A맵 v0.2 변경 기록
날짜: 2026-09-11
상태: 도면 검토 완료, 독립 Unity 블록아웃 최종 경로 검증 중

## 사용자 지시 요약
존댓말을 사용한다. 지상은 기계가 점령하고 인간형 적은 소수 무리로 자원을 찾아 돌아다닌다. 중앙 고가치 집중을 없애고 들어갈 수 있는 고가치 랜드마크를 분산한다. 진입 구역도 다수로 만들고 무장 가치에 따라 기존 후보를 유지하며 랜덤 진입 풀을 넓힌다. 저가 무장도 먼 퀘스트에 도전할 수 있어야 한다. 메인이 설계하고 Sol high가 도면을 작성한 뒤 메인이 검증한다.
후속 정정: 인간형 적은 실제 철수/맵 이탈을 하지 않는다. 한정된 범위 안에서 순찰·탐험·수색한다.

## 기획 의도와 해결하려는 문제
v0.1의 인간 요새/고정 거점은 최신 세계관과 충돌했다. 중앙 행정청사·환승광장 집중과 단일 남부 진입은 여러 탐험 경로를 만들기 어려웠다. 기계 지배 아래 떠도는 인간 탐색 무리를 표현하고 시작점·필요 자원·위험 감수에 따라 다른 경로가 성립하도록 구조를 수정한다.

## 변경 전 상태 및 문제점
기존 이미지 v0.1의 북부 인간 요새, 중앙 H2 고가치와 M3 왕복 순찰, E1/E7 남부 집중 구조를 확인했다. 인간 H1~H3는 고정 점유 영역으로 표시되어 있었다. 다수 플레이어 진입 구역과 무장 가치 누적 스폰풀이 표시되어 있지 않았다.

## 실제 변경 내용
- 약520×400m를 가정한 비대칭 도시 외곽 골격, 동남부 국지 침수.
- 중앙 저보상 C1/C2와 외곽 순환·다중 가로 연결.
- L1 북서 기록진료원, L2 북동 중계관제소, L3 동부 화물정비고. 모두 실내 탐험·복수 진입 및 지상 우회.
- 인간 H1~H3 한정 범위 수색망, 기계 M1~M3 활동권. 인간 상주 요새와 철수 화살표 삭제.
- 플레이어 P01~P12 진입 구역과 무장 가치에 따른4→8→12 누적 후보.
- E01~E07 분산 탈출. 보스 드롭 없이 일반/조건부/비상 대안.
- 이전 인간 고정 차단대장·영구 관문 점유는 폐기된 제안으로 명시.
- 요구사항 대조표, 경로 그래프, 생존/장거리 퀘스트 검증 기준.

## 변경 방식과 역할
메인 에이전트가 좌표·연결 그래프·구역 역할·인간 탐색 범위·누적 스폰 규칙을 직접 설계했다.
사용자 요청으로 gpt-5.6-sol, reasoning_effort=high 서브 에이전트를 실행하여 동일 설계를 SVG/PNG 도면으로 제작하도록 지시했다. 메인은 병행하여 규칙 명세와 연결성 검사를 작성하고 결과를 대조한다.
메인 세션의 모델 설정을 별도 도구로 변경하지는 않았으며 이 기록으로 모델 전환 완료를 주장하지 않는다.
원본 게임 코드·Unity 씬·기존 아트 에셋을 수정하지 않고 새 기획 산출물과 독립 Unity 검증 프로젝트를 추가했다. 사용자의 실배치 가능 구조 요청에 따라 Sol high 구현 담당을 병렬로 실행했다. 메인은 생성기 코드를 검토하고, 지면의 정확한 구멍과 상향 법선을 생성하는 별도 헬퍼도 작성했다.

## 기대 효과와 확인
그래프에서 12진입×3랜드마크 도달, 중앙 두 노드 회피 시 외곽 연결, 단일 지역 노드 제외 시 나머지 연결,4/8/12 후보 누적을 확인했다. P03에는 W로 가는 대체 연결도 명시했다.
최장 단순 최단경로 약556m, 중앙 회피 조건의 최장 약671m다. 이는 직선 연결합 검증이며 실제 게임 도로거리·전투시간 측정은 아니다.
메인이 최종 PNG를 직접 열어 P01~P12/E01~E07, 분산된 L1/L2/L3 및 실내 부속도, 중앙 저보상 표기, H1/H2/H3의 범위 내 분기 수색, 인간 맵 이탈 없음 문구를 확인했다. 초기 과대 글자 겹침과 M3/P08 표기 겹침은 도면 담당에게 수정을 요청하고 재렌더 결과를 검토했다.
실배치 사전 검사에서 L1/L3의 주도로 간섭, 주교량의 대각 도로 폭 부족, U1/U2의 도로-경사로 구멍 간섭을 찾아 좌표/폭을 수정했다. 최종 건물 footprint 및 경사로 구멍과 12m 도로의 평면 검사는 간섭 0건이다. 실제 보행과 층 연결은 별도 Unity 결과로 기록한다.
재실행 가능한 validate-placement.mjs에서 설계 검사 168개가 통과했다.
첫 Unity 실행에서는 지면 법선과 월드/로컬 좌표 문제를 발견했고, 그래픽 없는 실행 모드의 이미지 렌더도 실패했다. 이를 수정하고 그래픽 렌더 실행으로 전환했다. 두 번째 보행 검사에서는 167개 도달성 항목이 통과했으나, 메인이 거리값을 확인하여 U2가 의도한 경사로 대신 다른 입구로 우회한 것을 발견했다. 성공 개수만으로 완료 처리하지 않고 램프 길이 제한·지하 경로 높이 유지 검사와 접합부 수정을 추가했다.
메인은 렌더에서 L3 바닥과 공통 지면의 겹침도 발견하여 세 건물 footprint에서 공통 지면을 제거했다. 해당 영역은 건물 자체 바닥이 채우며 피트는 열린 상태를 유지한다.
후속 플레이 검증 대상: 실제 카메라 가림·보스 중첩·진입 시 피격/시야·보급 소비·부상/중량 상태의 먼 퀘스트 철수.
