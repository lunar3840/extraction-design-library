첨부한 Edel·Serin의 기존 3D 모델을 기준으로, 탑다운 익스트랙션 게임에 사용할 총기·방탄복·헬멧의 콘셉트아트와 실제 3D 장비 에셋을 제작해줘.

이번 작업은 캐릭터를 새로 디자인하는 일이 아니라 기존 캐릭터에 맞는 장비를 만드는 작업이다. 콘셉트 이미지, 장비 단독 모델, Edel 착용본, Serin 착용본, 검증 결과를 구분해서 납품해줘. Unity 프로젝트 적용과 게임 코드·밸런스·드랍 수정은 범위에서 제외한다.

1. 먼저 첨부 자료를 확인해줘.

- 두 모델의 버전·치수·비율·단위·전방축·원점·기준 포즈·본 구조·스킨 가중치·재질·텍스처를 확인해줘. 둘의 체형과 머리 크기가 같다고 가정하지 말고 실제 파일을 기준으로 해줘.
- 얼굴·눈·코·체형·팔다리 길이·원래 헤어색과 실루엣, 기존 리깅·UV·재질 연결을 보존해줘. 원본 파일을 덮어쓰지 말고 작업 사본과 별도 장비 파일을 사용해줘.
- 헬멧 아래로 보이는 옆머리·뒷머리는 캐릭터의 원래 머리색과 헤어 재질·텍스처를 사용해줘. 공통 검정 캡이나 다른 머리색으로 메우지 마. 헤어 보완 메시가 필요하면 해당 캐릭터의 원래 재질과 UV를 명시적으로 연결해줘.
- 원본에 피부 마스크용 추가 UV 채널, 버텍스 컬러, 커스텀 속성 등이 있으면 장비 제작 때문에 덮어쓰거나 제거하지 마.
- 첨부 파일을 읽거나 실제 3D를 생성·내보낼 도구가 없다면 그 범위를 정확히 밝혀줘. 가능한 콘셉트·제작 시트·모델링 지침까지 진행하되, 렌더 이미지나 파일명만으로 3D 모델 제작 완료라고 보고하지 마.

2. 게임과 장비의 디자인 기준은 다음과 같아.

- 탑다운 화면에서 읽히는 큰 실루엣과 기능적인 장비 형태를 우선해줘. 첨부된 SD 캐릭터의 비율과 기존 게임 화면의 재질감·채도·디테일 밀도에 맞춰줘. 현실 장비를 그대로 축소해 장식이 뭉개지지 않게 해줘.
- 총기에는 S급·별 개수·색상 등급 같은 명시적 티어 표시를 넣지 않아. 하지만 좋은 총과 좋지 않은 총의 성능 격차는 존재해. 모든 총을 동급으로 맞추는 전제는 아니야. 좋은 총은 성능·가격·희소성이 높고 상위 구역/진행 구간에서 획득하도록 구상하고 있어. 어느 모델이 어느 구간에 속할지는 아직 미확정이야.
- ‘회수 소총’의 최신 명칭은 ‘고철 소총’이야. 이 총은 회수 부품·보수 흔적·단순한 마감으로 저렴한 기본 총의 성격을 보여줘. 원래 존재하는 다른 ‘회수’ 무기 이름까지 일괄 변경하지 마.
- 좋은 총은 정돈된 조립·잘 관리된 부품·기능적인 완성도로 차이를 보여주고 모델별 근접/정밀/안정 성향도 유지해줘. 등급색을 칠하는 방식으로 강약을 대신하지 마.
- 방탄복과 헬멧에는 C/B/A/S 티어가 있어. C는 회수 직물·판재·보수 흔적, B는 구문명 치안·수색 규격, A는 군용 모듈 플레이트, S는 전문 복합재와 정밀한 결속 구조가 읽히게 해줘. 티어별로 같은 메시의 색만 바꾸지 마.
- 방탄복의 기동형은 얇고 간결한 구성, 균형형은 표준 구성, 중장형은 넓고 두꺼운 패널, 정비형은 교체 패널·접근하기 쉬운 결속·보수 구조가 특징이야. 정비형의 게임상 이점은 반복 수리 때 영구 마모가 적다는 것이며, 의료 도구나 자동 회복 장비로 해석하지 마.
- 같은 제품은 Edel과 Serin에게 같은 제품으로 보여야 해. 캐릭터별 피팅을 위해 크기·곡면·스트랩·스킨 가중치를 조정하되 재료·제품 정체성은 유지해줘. 세트 착용을 강제하는 디자인이나 다른 제품과 결합할 수 없는 구조는 피하고, 방탄복·헬멧·총을 독립 에셋으로 만들어줘.
- 보호판이나 바이저가 보인다는 이유로 게임의 실제 방호 범위·능력치가 변경됐다고 보고하지 마. 수치와 제품별 방호 범위는 별도의 기획/구현 사항이야.

4. 한 번에 전체54종을 만들어 품질을 놓치지 말고, 먼저 대표4종으로 제작 규격을 잡아줘.

첫 배치: A 군용 전투복, A 공병 정비헬멧, 고철 소총, M4A1.

각 장비의 콘셉트 시트 → 실제 장비 모델 → Edel·Serin 각각의 피팅 → 비교 검증 순서로 진행해줘. 이4종은 몸통 장착·머리/헤어 처리·총 파지와 기본/발전된 총의 대비를 먼저 확인하기 위한 샘플이야. 공통 규격이 맞으면 A티어의 나머지 스타일을 비교하고 다른 티어·무기군으로 배치별 확장해줘. 새 기준이 필요한 부분은 작업 가정과 이유를 적고, 원본 파일을 읽어 알 수 있는 내용을 다시 묻는 대신 먼저 확인해줘.

5. 콘셉트아트는 실제 모델링에 쓸 수 있게 만들어줘.

- 장비 하나당 정면·후면·좌측·우측의 동일 디자인 턴어라운드와 재료/결속부 상세를 제공해줘. 여러 시점에서 판 수·스트랩·파우치·개구부가 일치해야 해.
- 장비 단독 시트와 Edel/Serin 착용 시트를 분리하고, 얼굴이나 머리로 핵심 부품이 가려지지 않는 시점을 포함해줘.
- 원근을 줄인 제작용 시트와 분위기 연출용 이미지를 구별해줘. 실제 탑다운 크기의 읽힘, 인벤토리 근접 화면, 측면·후면을 함께 확인해줘.
- 총은 총구·메인 그립·보조손 파지·탄창·개머리판·부품 장착 위치를 식별할 수 있게 해줘. 장비별 시트를 각각 파일로 저장해 후속 모델링 입력으로 쓸 수 있게 해줘.

6. 실제 3D 파일은 다음 기준으로 제작·검증해줘.

- 장비를 캐릭터 몸과 합친 단일 조형물로만 납품하지 마. 장비 단독 원본과 두 캐릭터의 착용 사본/피팅 정보를 분리해줘.
- 움직이는 몸통 장비는 필요한 본에 스킨을 연결하고, 헬멧·총의 단단한 부품은 형태가 찌그러지지 않게 해줘. 원본 스켈레톤 이름·계층·바인드 포즈를 임의로 바꾸지 마.
- 헬멧·칼라·등판·스트랩·가슴/어깨·팔·머리카락의 간섭을 확인해줘. 필요한 가림 처리는 별도 마스크/분리 메시와 적용 범위로 남기고 원본 몸·헤어·의상 메시를 영구 삭제하지 마.
- 제공된 애니메이션이 있으면 대기·이동·조준·사격·재장전 등에서 확인해줘. 없으면 가능한 포즈 변형으로 검토하고 실제 애니메이션/Unity 검증은 미실시라고 밝혀줘.
- 총은 두 캐릭터 각각의 손 크기와 그립 위치를 확인해줘. 총구 방향, 방아쇠 손, 보조손, 개머리판의 위치가 맞아야 해. 필요한 캐릭터별 장착 변환과 앵커를 기록해줘.
- UV·텍스처·재질 연결, 노멀/스무딩, 숨겨진 불필요 면, 파일 누락을 점검해줘. 원본 캐릭터의 UV·텍스처를 장비 UV와 합쳐 덮어쓰지 마.
- 폴리곤 수·재질 수·텍스처 해상도·LOD 계획은 원본과 실제 화면 크기를 읽고 제안해줘. 근거 없이 고해상도만 키우거나 모두 저폴리로 깎지 마.
- 편집 가능한 원본 파일과 GLB 등 확인 가능한 교환 파일, 텍스처를 제공해줘. 가능한 도구가 지원하면 .blend와 FBX도 함께 제공하고, 실제로 내보낸 형식만 납품했다고 적어줘.
- 내보낸 파일을 다시 열어 메시·재질·텍스처·스킨 연결이 유지되는지 확인해줘. 콘셉트 이미지, 임시 블록아웃, 완성 모델, 피팅 검증 완료를 서로 구별해줘.

7. 결과는 장비별 폴더로 정리해줘.
