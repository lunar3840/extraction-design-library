# Figma 아이콘 라운드 조정

- 사용자 지시: 아이콘 전반의 모서리를 둥글게 다듬기.
- 완료 확인일: 2026-10-22 KST. 진행 중 사용하던 2026-10-21 증빙 폴더에 연속 보관.
- 대상: EXTRACTION · Modern Glass UI Kit / KUD4t84BL1S77c3cnb8co0.
- 실제 수정 위치: Figma 원본 컴포넌트와 네 개 HUD의 작은 초상 클립 프레임. Unity 수정 없음.

## 기획 의도와 변경 전 문제

승인된 열린 HUD 구조와 높은 문자 대비를 유지하면서, 번개·화살표·작은 슬롯의 각진 인상을 완화한다. 큰 패널을 다시 디자인하거나 정보 배치를 바꾸는 작업이 아니다. 기존 80px 퀵슬롯은 반경 2, 주요 흰 키캡은 반경 3이었다.

## 실제 적용

- 기존 아이콘 소스의 모서리를 완화하고 둥근 선 끝·연결부, 선 두께, 실루엣을 유지했다. 재배치와 가속의 원본 컴포넌트 ID 76:2472 / 76:2476은 그대로 남아 있다.
- HUD/QuickSlotCompact (55:1184): 80×80 크기를 유지하고 바깥 반경 10, 숫자 키캡 반경 5.
- HUD/AbilityCompact: 모든 변형의 작은 입력 키캡 반경 5.
- HUD/InteractionCompact: 모든 변형의 F 키캡 반경 6.
- 네 개 HUD 초상 클립 프레임: 반경 8, 기존 크기·자산 연결 유지.
- 내장 편집 도구는 53개 소스의 81개 아이콘 벡터를 처리했다고 보고했다. 이 수량은 도구 보고이며 메인이 81개 노드를 개별 재검사한 수량으로 제시하지 않는다.
- 편집 가능한 시계 아이콘 소스는 발견하지 못해 변경하지 않았다. 현재 확인한 HUD의 작전 시간은 텍스트로 표시된다.

## 적용 방식

공식 Figma MCP는 Professional 플랜의 View 좌석 호출 한도로 실행되지 않았다. 앱 재시작·종료·좌석 구매·결제 변경 없이, 이미 설치되어 실행 중인 Figma의 내장 Agents 편집 기능을 사용했다. 대상 파일만 열고 원본 컴포넌트를 수정하도록 범위를 제한했다. 기존 다른 탭은 유지했다.

별도로 만든 `icons/*.svg` 12종과 `proposal_round_icons.svg`는 라운드 방향의 로컬 제안 자료다. 이 SVG 파일을 Figma에 그대로 삽입한 것은 아니다. 실제 Figma 변경과 로컬 제안을 구분한다.

## 확인 결과

- Figma 속성 패널에서 55:1184 원본 컴포넌트, W80/H80, Corner radius 10을 직접 확인했다. 증빙: `after_quickslot_properties.png`, `native-properties-audit.txt`.
- Figma에서 현재 69:2948 프레임을 1x PNG로 직접 내보냈다: `after_project_backdrop.png` (1920×1080).
- 독립 시각 검토 PASS: 현재 정상 HUD에서 둥근 슬롯·키캡, 물방울·번개·스킬 실루엣, 글자 대비, 기존 배치를 확인했다. 새 겹침·잘림 없음. 상세: `figma-visual-audit.md`.
- 수분/에너지 112px 원형, 하단부터 차오르는 fill, 숫자 없는 표시, 캐릭터 위 HP/스태미너가 유지됐다.
- 화면에 없는 상태 아이콘·다른 화면·모든 변형과 모든 벡터 속성을 개별 시각 검증하지는 않았다. PNG만으로 편집 가능 구조나 정확한 반경 전체를 검증했다고 주장하지 않는다.
- 로컬 제안 SVG 12종의 별도 구조/렌더 검증은 `audit.json`에 기록했다. 실제 Figma 노드 검증과 동일하지 않다.
