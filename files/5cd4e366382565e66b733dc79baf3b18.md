# 원형 근접 시야 반경 축소

## 사용자 지시 요약

현재 5.5m 원형 시야가 너무 넓으므로, 덕코프 사례처럼 플레이어에게 실제로 근접한 유닛만 확인되도록 줄인다.

## 기획 의도와 해결하려는 문제

플레이어 주변을 전방 시야와 무관하게 확인할 수 있는 안전 영역을 작은 근접 거리로 제한한다. 몇 걸음 떨어진 후방 적까지 미리 드러나던 문제를 줄이면서, 바로 곁의 적을 알아볼 기회는 유지한다.

## 변경 전 상태 및 문제점

원형 시야 반경이 5.5m, 경계 흐림 폭이 1.1m였다. 플레이어 뒤 4m에 있는 원거리 무기 적이 원형 시야 안에 들어와 표시됐다. `before_vision.png`와 `before_result.txt`에서 확인했다.

## 실제로 바꾼 부분과 방식

- 기본 원형 시야 반경을 5.5m에서 2.5m로 축소했다.
- 화면 경계 흐림 폭도 1.1m에서 0.45m로 줄여, 반경이 작아진 시야에 맞게 경계가 번지지 않도록 했다.
- 플레이어 설정 기본값, 저장된 기본 설정 에셋, 시야 컨트롤러의 기본값을 함께 맞췄다.
- 후방 2m, 후방 4m, 근거리 벽 뒤, 원거리 전방의 적을 확인하도록 기존 시야 자동 검사를 갱신했다.

## 변경 후 기대 효과와 확인 결과

- 후방 2m 적은 보임: 통과.
- 후방 4m 적은 숨김: 통과.
- 원형 반경 안이더라도 벽 뒤 적은 숨김: 통과.
- 기존 전방 부채꼴의 먼 적 표시는 유지: 통과.
- 격리된 Unity 검증 장면에서 컴파일과 4개 시야 검사를 통과했다. `vision_checks.log`에 실행 로그가 있다.
- 동일 장면 촬영에서 후방 4m 적의 표시 상태가 `True`에서 `False`로 바뀌었다.

## 관련 스크린샷 파일명과 대응 시점

- `before_vision.png` ↔ `after_vision.png`: 같은 1600×900 화면, 카메라 위치, 플레이어 자세, 조명 및 후방 4m 적 위치. 전 화면에는 적이 보이고 후 화면에는 숨겨진다.
- `before_result.txt` ↔ `after_result.txt`: 각 화면의 실제 적 표시 판정 수치.
