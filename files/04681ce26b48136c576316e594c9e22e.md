# A맵 지면의 검은 원호 수정 v12

## 원인과 수정 범위

하나의 지면 셰이더에서 두 결함을 함께 수정했다.

1. 다중 그림자 영역의 서로 다른 좌표를 꼭짓점 사이에서 섞어 생기는 계단형 원호: 캐스케이드 선택과 그림자 좌표 계산을 픽셀 위치 기준으로 변경했다. 마지막 그림자 거리 경계에는 URP의 표준 거리 페이드를 적용했다.
2. Forward+ 조명 변형 누락: `_CLUSTER_LIGHT_LOOP`를 지원하여 이 렌더링 방식에서 제공되지 않는 per-object LightData에 의존하지 않도록 했다.

그림자 기능을 끄거나 조명 세기·그림자 거리·캐스케이드 수를 바꾸지 않았다. 지형, 도로, 건물, 콜라이더, 진입/탈출, 캐릭터와 시야 마스크도 변경 대상이 아니다.

## 재현과 검증

처음의 그림자 좌표 수정만으로는 전후 이미지가 같았다. 조명 호환성 결함 때문에 직접광이 빠져, 그 직접광에 곱해지는 잘못된 그림자도 드러나지 않았기 때문이다. 단순한 자동 PASS를 시각적 성공으로 취급하지 않고 원본 설치를 보류한 후 추가 진단했다.

조명 호환성 한 줄만 추가하고 기존 그림자 계산을 유지한 **진단 대조군**에서 제보와 같은 검은 계단형 원호를 재현했다. 동일한 조명·지형·캐릭터·카메라에서 전체 수정본은 이 원호를 제거했다. 대조군은 원본 셰이더 자체가 아니므로 원래 변경 전 사진으로 표시하지 않는다.

- 진단 대조군: `diagnostic_cluster_only_sync_b4_sync_overlay_off.png`
- 같은 위치의 전체 수정본: `after_reproduced_d3d11_sync_b4_sync_overlay_off.png`
- 시야 효과를 유지한 동일 비교: 각 파일의 `_overlay_off`를 뺀 PNG
- 원본 그대로의 기준: `before_x00/x10/x25*.png`, 추가 정확 복원 기준인 `before_reconstructed_*`

사진은 `outputs/change_records/2026-09-15/stage-a-shadow-v12/`에 있다. B4 대조군/수정본은 geometry와 light 지문, 플레이어·카메라 위치가 일치한다. 160만 픽셀 중 변경 픽셀은 60,888개이며, 실제 화면에서 원호가 사라지고 물체 그림자와 시야 틴트가 유지되는 것을 메인과 독립 담당이 확인했다. 픽셀 차이 개수만으로 통과 판정하지 않았다.

Direct3D11과 Direct3D12의 전체 수정본 모두 컴파일 오류 0, 지형·조명·카메라 보존 검사를 통과했다. 별도 `final_movement_*`는 카메라/캐릭터를 0m, 10m, 25m 위치로 옮긴 추가 검증이며, 실제 보행 입력 테스트로 과장하지 않는다.
