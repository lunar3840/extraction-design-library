## 사용자 지시와 기획 의도

- 원문: SOURCE_TRANSCRIPT.md.
- 프로젝트를 언제부터 작업했는지 찾아보기 쉽게 날짜 오름차순·내림차순 탐색을 추가한다.
- 기존 웹 기획 라이브러리의 탐색 개선이므로 같은 주제의 후속 회차로 연결한다.

## 변경 전 상태 및 문제

- 주제 목록은 가장 최근의 기록일 내림차순으로 고정되어 초기 기록으로 이동하기 어려웠다.
- 오래된 주제에 최신 후속 수정이 있으면 주제가 최근 목록으로 이동해 시작 시점을 알아보기 어려웠다.
- 데이터 편집기에는 프로젝트 시작 이력을 뜻하는 날짜가 없다. 추출 시각·수치 저장 시각을 프로젝트 시작일로 사용하는 것은 부정확하다. 담당 채팅과 읽기전용 조율 후 편집기는 수정하지 않았다.

## 실제 변경과 방식

- 날짜 정렬 선택: 최근 기록순(최신 먼저), 처음 기록순(오래된 먼저).
- 통합 주제는 전체 구성 원문의 최초/최근 유효 날짜를 계산한다. 오래된 주제의 후속 수정도 최초일이 유지된다.
- 개별 기록 모드와 모든 분야/소분류/자료 성격/출처/검색 필터에도 날짜 정렬을 적용한다.
- 명시적 사용자 지시일을 우선하고 원문 기록일을 사용한다. 파일 수정시각은 사용하지 않는다. 유효 날짜가 없는 기록은 두 정렬 모두 마지막이며 같은 날짜는 제목·ID로 안정 정렬한다. 원문 날짜와 원래 자료 순서는 덮어쓰지 않는다.
- 주제 카드와 상세에 최초/최근 기록일, 상단에 전체 수집된 기록 기간 및 가장 이른 날짜의 원문 버튼을 표시한다.
- 가장 이른 확보 날짜는 2026-09-04. 지시 원문 대조표의 사용자 지시일(한국 시간)이다. 실제 프로젝트 시작일로 확정하지 않고 이전 작업·미수집 대화의 가능성을 안내한다. 근거 목록: DATE_AUDIT.json.
- 날짜 초기화는 최근 기록순으로 돌아간다. 날짜 정렬은 검색/탭 변경 중 유지된다. 공유 헤더/메뉴/배너 크기는 변경하지 않는다.
