# A맵 v0.2 · 실제 배치용 설계

## 무엇을 보는 자료인가요?

기계가 점령한 지상의 도시 외곽을 520×400m로 구성한 레벨 블록아웃 설계입니다. 도면은 공간의 역할과 동선 판단용이고, 실제 배치 치수는 좌표 명세와 Unity 블록아웃이 기준입니다. 완성된 환경 아트나 전투 밸런스 확정본은 아닙니다.

- `StageA_Surface_Scavenger_Routes_Blueprint_v02.png`: 전체 구조와 실내 동선 부속도.
- 같은 이름의 `.svg`: 도면의 편집 가능한 원본.
- `DESIGN_v02.md`: 세계관, 자원·위험 분산, 무장 가치별 누적 진입, 탈출, 원거리 퀘스트 설계.
- `IMPLEMENTATION_SPEC.md`: 건물 크기, 출입구·층고·계단, 교량, 지하 경사로의 실제 치수.
- `placement_spec.json`: Unity 좌표 환산을 포함한 최신 배치 데이터. `layout_graph.json`은 최초 개념 연결망 검사 자료이며 최신 물리 배치의 단독 기준으로 사용하지 않습니다.
- `unity/`: 독립 Unity 검증 결과와 가져오기용 산출물. 구체 제공 파일 및 검사 결과는 해당 폴더 안내를 확인합니다.

## 핵심 구분

H1~H3는 인간 적이 자원을 찾아 **정해진 범위 안을 순찰·탐험하는 망**입니다. 인간 적에게 E01~E07 탈출구 사용이나 맵 이탈 행동을 부여하지 않습니다. E 표식은 플레이어 전용입니다.

P01~P12는 진입 후보 구역입니다. 장비 가치가 높아지면 기본 후보를 유지한 채 4→8→12로 풀을 넓힙니다. 저가 무장도 이동 중 모든 지역에 접근할 수 있습니다. 실제 장비 평가액 계산과 동적 안전 스폰 선택은 후속 게임 시스템 연결 작업입니다.

L1·L2·L3는 실내를 갖춘 분산 고가치 시설이며 외곽 통과에 실내 진입이나 보스 처치를 강요하지 않습니다. 중앙 C1·C2는 저보상 연결 공간입니다.
