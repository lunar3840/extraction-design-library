# 헬멧·방탄복 몸에 맞춤 수정

2026-09-04. 대상 `C:/UnityProject/escape`, 별도 검증 `C:/tmp/EscapeHelmetRefit`.

사용자가 지적한 납작한 측면 두상, 방탄복/옷 관통, 어깨끈 어긋남과 깨져 보이는 옷자락을 수정했다. 이전의 얼굴 범위 기준 헬멧, 단단한 Chest 소품, 의상 삼각형 제거 방식은 현재 프로필에서 사용하지 않는다.

## 변경

- 세 캐릭터의 전체 두상(얼굴+원본 두피)으로 헬멧 폭·깊이를 다시 산정. 얼굴·눈·캐릭터 뼈 크기는 변경하지 않았다. 플레이어 원래 머리 깊이 약 .51, 헬멧 약 .58. 고글은 눈높이이며 측면 안감으로 틈을 가린다. 긴 헤어는 숨기고 뒤쪽 두피와 목덜미 안감을 사용한다.
- 방탄복 6,041개 정점을 각 캐릭터의 가슴/등/허리 단면과 어깨 방향에 맞춰 재배치. 6개 본에 가중치를 주어 몸통 굽힘과 어깨 움직임을 따라가게 했다. 런타임 `SdArmorRig`와 초기화 연결 추가.
- 착용 의상 사본은 모든 삼각형, 서브메시, 원래 본 연결을 보존한다. 겹치는 몸통만 안쪽으로 정리하고 옷자락은 허리에서 끝으로 갈수록 보정 강도를 줄여 형태를 남긴다.
- UnityChan 옷의 양면 렌더링이 원래 앞뒤 면을 동시에 그려 뒤쪽에 깜빡임을 만들던 문제를 수정했다. 변경은 생성된 URP 재질의 Cull/DoubleSidedGI이며 원본 FBX는 그대로다.
- 기존 가방 장착·해제·파손 표시·로드 교체 규칙을 유지한다. 최신 인벤토리 인물 뷰도 새 방탄복 스키닝을 복사한다. 적용 프리팹은 세 캐릭터용이며 적 자동 지급은 기존처럼 하지 않는다.

## 확인

최종 Unity Play Mode **52 PASS**, 로그에 컴파일 오류/Exception/FAIL 없음. 검사 결과 `Armor-Tailored-RuntimeChecks.txt`.

- 실제 테스트 상자 → 가방 → 헬멧/방탄복 개별/동시 장착.
- 파손 장착 상태 유지, 비활성/재활성, 해제 후 원래 메시/헤어 복원, 가방 교체 추종.
- 세 캐릭터 의상 전체 삼각형·본 연결 보존, 실제 캐릭터 뼈에 방탄복 연결.
- Idle/Walk/Run 각 4시점(12시점) 양손 그립 오차 0.015 미만.
- 최신 원본 프로젝트의 InventoryPortrait를 검증 사본에 동기화하고 새 방탄복 뼈 복사 및 실제 인물 렌더 확인. UI 소스는 배포 시 수정하지 않음.

실제 Unity 렌더:

- `Tailored-Player_UnityChan.png`, `Tailored-Ranged_Misaki.png`, `Tailored-Melee_Yuko.png`: 왼쪽 원래 모습, 오른쪽 착용 정면/측면/후면.
- `Tailored-Gun-Idle.png`, `Tailored-Gun-Walk.png`, `Tailored-Gun-Run.png`: 각 동작의 정면/측면/후면.
- `Tailored-BackComparison.png`: 옷자락 비교용(왼쪽은 확인을 위해 원래 헤어만 숨김).
- `Tailored-InventoryPortrait.png`: 현재 인벤토리 미리보기 렌더.

별도 검증 에디터에서 확인했다. 사용자 원본 에디터의 실행 중인 씬을 조작한 검증은 아니다. 검증한 기본 동작 외의 모든 새 애니메이션/체형에서 관통이 전혀 없다는 보장은 아니며, 새 장비에도 자동 적용되는 범용 의상 피팅은 아니다.
