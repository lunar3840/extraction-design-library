# A맵 공장 창 근거리 깊이·반사 V22

## 사용자 지시와 기획 의도

V21의 외벽·상부 창 반복 완화 후 남았던 ‘근거리에서도 창 안쪽 깊이와 반사 변화가 읽히도록 보완’ 제안에 사용자가 “해봐”라고 승인했다. 같은 주 공장 유리 38개에 한정해 재질 표현을 조정한다. 외벽, 구조, 충돌, 조명, 캐릭터와 게임 동선은 변경하지 않는다.

## 변경 전 문제와 기록

V21은 창 반사와 가상 내부 층을 구현했지만 정면·좌우 사선의 전후 화면에서 차이가 거의 식별되지 않았다. 정면 반사 기여도가 작았고, 어두운 유리 픽셀을 창틀로 취급하는 기존 마스크가 효과를 억제할 수 있었다. 07:29부터 이번 시작 상태에서 새로 고정 21시점·실제 플레이 20시점을 촬영하고 장면/프리팹을 `backup/`에 보관했다. 이전 결과 이미지를 변경 전 증빙으로 재사용하지 않았다.

## 구현 범위와 방법

기존 V21 창 슬롯 38개(외벽24, 지붕/채광창14)에 별도 V22 재질을 적용한다. 원본 텍스처와 창별 파손 패턴·색 변주는 보존한다. 창틀과 유리 영역을 구분하고, 어두운 후벽·기둥·빔의 가상 내부와 시점 이동에 따른 제한된 UV 이동을 더한다. 기존 정적 큐브맵을 흐린 반사로 사용한다. 실제 투명 창이나 새로운 실내 메시, 실시간/창 위치별 정확한 반사가 아니다.

실제 적용 내용:

- 원본 6×4 창 패널의 경계를 이용해 창틀을 분리한다. 색이 어둡다는 이유만으로 유리를 창틀 처리하던 방식을 제거했다. 경계의 부드러움 계산은 감싸기 전 UV 미분값을 사용해 텍스처 끝의 이음 오류를 방지했다.
- 가상 후벽에 기둥·빔·선반 윤곽을 겹쳐 시차의 기준점을 만들었다. 내부 이동은 창 뒤 평면을 향하는 방향으로 교정하고, 깊이 .024/.027/.030 및 축별 이동 ±.045 UV 이내로 제한했다.
- 내부 강도 .82/.86/.90, 온전한 유리의 내부 표현 비율 .38/.40/.42, 구조 대비 .70/.725/.75를 사용한다. 후벽 색은 중성 (.30,.32,.30), 온색 (.34,.30,.26), 냉색 (.28,.31,.34)의 세 계열이다. 자체 발광은 추가하지 않았다.
- 반사 강도 .36, 거칠기용 큐브맵 mip3.1, 정면 가중치 .36과 먼지 감쇠를 적용했다. 반사는 온전한 유리에서만 섞이며 파손 부분과 창틀에서는 제외한다. V21 정적 큐브맵을 그대로 참조하므로 캡처 위치나 전역 반사 설정은 바뀌지 않았다.

첫 적용은 반사만 보이고 시차 차이가 RGB 3/255 이상인 픽셀이 세 각도 모두 0개였다. 이 결과를 통과 처리하지 않고 내부 색을 재조정했다. 최종판은 실제 화면에서 내부 구조를 식별할 수 있고, 동일 카메라에서 시차만 끈 결과와도 차이를 확인했다.

## 검증 기준과 대응 이미지

- 고정 21시점은 `before_<시점>.png` / `after_<시점>.png`로 동일 위치·시야각48도·1600×1000·기존 조명에서 대응한다. 핵심은 glass_frontal / glass_left / glass_right 이다.
- 실제 플레이 20시점은 기존 이동7경로, 정지2지점의 start/end와 차양 아래2시점이다.
- 추가 `diagnostic_<frontal|left|right>_<full|no_parallax|no_reflection>.png`는 동일 조건의 효과 분리 검사다. no_parallax는 내부 밝기가 아니라 시차 이동만 끄고, no_reflection은 큐브 반사만 끈다. 픽셀 차이 수치만으로 시각 통과 판정하지 않는다.
- 원래 메시·렌더러6,018·충돌체4,665·변환14,032·기준점46개, 모든 비대상 재질과 조명/반사·진입점 정책 보존을 확인한다.
- 메인 통합/실행과 제작·독립 검토 담당을 분리하며, 시각 검토와 저장·재열기·Play 결과를 확인한 후 완료 보고한다.
