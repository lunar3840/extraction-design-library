# A맵 V18 — 하역·보관·수리 구역의 지면 사용 흔적

## 사용자 지시와 기획 의도

- 사용자가 다음 작업 제안에 대해 “한번 해봐”로 승인했다. 우선순위로 제안한 하역구–컨테이너–수리 쉼터의 지면 작업을 수행한다.
- V17 구조물과 소품의 위치·크기는 유지하면서, 지면과 따로 놓인 인상을 완화한다. 하역구에는 평행한 타이어 자국, 컨테이너·강관 주변에는 압착 먼지, 수리 장비 발치에는 작은 오염 흔적을 배치한다.
- 이번 범위에 창문·외벽 변형, 새 소품, 전역 조명, 캐릭터·헤어, 적·스폰·이동 동선 변경은 포함하지 않는다.
- 메인이 지면 표시 방식·통합·플레이 검증을 맡고 Sol high 담당이 배치 제작, 표면 높이/셰이더 구조 조사, 독립 검증을 병렬 수행했다. 파일 소유를 분리했다.

## 변경 전 상태와 증빙

- V17 완료 상태에서 새 촬영을 실시했다. 이전 작업의 사후 이미지를 변경 전 이미지로 재사용하거나 재구성하지 않았다.
- 기존 지면은 넓게 같은 성질이 이어지고, 새 컨테이너·쉼터 주변에 작업 용도에 따른 사용 흔적이 부족했다.
- `before_*.png` 30장: 고정 카메라 10개, 7개 보행+2개 정지 관찰 지점의 시작/종료 18개, 기존 차양·쉼터 아래 2개.
- `backup/`에 수정 전 실제 장면·프리팹을 저장했다. 기존 소스 파일과 기존 재질은 수정하지 않는다.
- `BASELINE_VALIDATION.txt`: 8 PASS / 0 FAIL. 기존 충돌체 4,665개·렌더러 5,962개·앵커 46개 및 V16/V17 제어 설정의 기준 서명을 저장했다.

## 실제 변경과 방식

- 지도 바로 아래 `LookV18_SurfaceRoot`에 3개 용도 그룹을 추가했다. 기존 오브젝트는 이동·교체하지 않았다.
- 총 28개 패치: 하역구 11, 컨테이너·강관 구역 8, 수리 쉼터 9. 유형은 압착 흙/먼지 14, 작은 기름 오염 10, 타이어 분절 4다.
- 하역구의 0.36m 폭 타이어 자국 두 줄은 중심 간격 2.30m로 맞추고 문 앞에서 야드 방향으로 배치했다. 넓은 일괄 바닥판은 사용하지 않았다.
- 패치는 0.25m 이하 간격으로 분할한 메시다. 지형은 실제 지형의 삼각형 높이 샘플을, 기존 콘크리트 앞치마는 그 메시 충돌체의 직접 높이를 사용한다. 최종 높이는 표면보다 0.012~0.018m 위다.
- 새 투명 PBR 셰이더는 기존 지면 텍스처를 참조하고 불규칙한 경계·밝기·타이어 홈을 코드로 생성한다. 조명·그림자·안개를 받으며 자체 그림자와 깊이 쓰기는 하지 않는다.
- 새 충돌체는 0개다. 신규 렌더러 28개, 정점 2,227개, 신규 공용 재질 3개이며 기존 재질을 덮어쓰지 않았다.
- 최초 적용은 대비가 너무 약해 독립 시각 검토에서 보류했다. 동일한 배치와 경계 형태를 유지하면서 먼지·타이어는 2.2배, 기름 흔적은 1.8배의 실효 강도를 적용하고 최대 투명 혼합 비율은 0.62로 제한했다. 타이어에는 길이 방향의 완만한 마모·부분 끊김을 추가했다.
