# A맵 v0.8.1 — 중복 렌더 표면 정리

## 수정 범위

도로·지반·교차로·건물/핵심실 바닥·중계 공터·상부 통로 등 생성 블록의 같은 방향 공면을 정리합니다. 중복 패치에는 표면 소유자를 하나만 남기고 다른 면의 겹친 부분을 잘라냅니다. 렌더 순서 덮어쓰기나 도로 전체 높이 변경으로 가리는 방식이 아닙니다.

- 콜라이더 형상, 위치, 레이어, 활성 상태는 유지합니다.
- 진입·탈출·문·중계·건물 등 기준점과 원본 배치 데이터를 유지합니다.
- 지형과 도로 고도는 변경하지 않습니다. 지형 전체의 고저차 문제는 `TERRAIN_DIAGNOSIS.md`의 확인 결과만 제공합니다.
- 현재 A 프리팹을 대상으로 외형 메시 참조만 갱신하며 기존 씬을 재생성하지 않습니다.
- 건물 내부를 채우는 보이지 않는 구조 접합/충돌체까지 없애는 작업은 아닙니다.

## 에셋 교체 유지

기존 `Override Prefab` + `Rebuild This Visual Slot` 사용법을 유지합니다. 원본 생성 블록의 외형을 바꾸거나 복원한 뒤 주변 생성 표면의 중복을 다시 정리하고, 새 메시를 별도 에셋으로 저장합니다. 사용자 override 프리팹의 내부 메시를 잘라내거나 변형하지 않습니다. 따라서 향후 가져오는 외부 에셋 자체의 겹침·문 위치·통행 적합성은 별도로 확인해야 합니다.

새 생성 메시는 `Assets/Escape/Resources/StageMaps/Generated_v081`에 보관하고, 기존 v08 기본 재질과 메타를 보존합니다. 구조 전체를 하나의 메시로 합치지 않았습니다.
