# A맵 건축 키트 D07 — 원화·수량·비용 계획 기록

## 사용자 지시 및 범위

이전 건물 10외형군에 맞는 에셋 종류와 숫자를 먼저 정리하고 에셋 아트를 제작. Tripo 생성은 나중에 사용자 지시를 받은 뒤 수행. 크레딧 상한 2,500, 남은 잔액 고려, 품질을 조정하더라도 비용 최소화. 맵 작업 병렬 지침 적용.

## 변경 전과 목표

- 이전 콘셉트는 완성 건물 외형을 3장으로 비교했으나 창·벽·처마를 단품 입력으로 쓸 수 없는 상태였습니다.
- D05 보유 14종, MAV16 30종, FactoryV12 및 D04 구조를 읽기 전용으로 대조했습니다.
- 목표는 중복 소품 생성 없이 10외형군을 구별하는 부품만 설계하고, 문/창의 실제 구멍과 지붕 치수를 생성 모델에 무조건 맡기지 않는 것입니다.
- 기존 Unity 장면·코드·프리팹·에셋과 Blender 장면은 이번에 조작하거나 수정하지 않았습니다.

## 실제 만든 것

- T01–T14 **단품 원화 PNG 14장**. 하나의 이미지에 하나의 부품, 중립 회색 배경, 입체 깊이·접합 방향을 보여 줍니다. 배경은 투명 알파가 아닙니다.
- B1–B6 **정밀 구조 제작 작업군 비교 시트 1장**. 완성된 모델 6개가 아니라 후속 제작 묶음이며 B4 등은 여러 메시가 필요할 수 있습니다.
- 신규 Tripo 후보는 우선 12종 + 조건부 코너 2종. T01/T10은 기존 자산과 형태·두께·슬롯을 대조해 필요할 때만 생성합니다.
- ASSET_PLAN.md, ASSET_MANIFEST.json, STRUCTURAL_MANIFEST.json, ART_INDEX.md, BUDGET_PLAN.md/json, PROMPTS.md, STRUCTURAL_PROMPT.md, GENERATION_RESULTS.json을 저장했습니다.
- 기본 이미지 생성 도구 15회로 원화를 제작했습니다. 이는 Tripo 3D 생성이 아니며 Tripo 크레딧 사용 0입니다.

## 비용 확인과 최소화

- 실제 Tripo 브라우저 UI: 잔액 2,750, 로딩 완료 후 기본 생성 표시 30. 단일이미지·HD H3.1·비공개·2K·Ultra OFF·AI 강화 OFF·PBR/조명제거 ON·삼각형 목표 8,000. H3.1은 로딩 완료 접근성 표시에서 확인했고 옵션 캡처에는 아래쪽 모델 메뉴가 표시되지 않습니다.
- 초기 로딩에서 일시적으로 55가 보였으나 최종 로딩 완료 30 화면만 견적 근거로 채택했습니다.
- before_tripo_quote.png ↔ after_tripo_readonly.png: 동일 옵션 패널·잔액·가격 확인 화면. 설정을 변경하거나 파일을 업로드하거나 생성 버튼을 누르지 않았습니다. 따라서 화면의 핵심 차이는 없고, 읽기 전용 확인·무과금 유지 증빙입니다.
- 이전 실제 소비 450은 기존 CREDIT_LEDGER.json에서 확인. 2,500을 이전 소비 포함 총한도로 보수적으로 해석하면 추가 2,050 여유입니다.
- 표시 단가 유지 전제: 12종 360, 14종 420, 재시도 180 및 추가 처리 예비 100 포함 이번 신규 계획 700 이내. 목표액을 채우지 않습니다.
- 사용자 재지시 후 각 실제 실행 직전 가격·잔액 재확인이 필요합니다. 모델 면수 저하가 곧 생성비 감소라는 근거는 없습니다. 2K 기본 생성 후 Unity 1K 반입 상한 검토는 실행 성능 절감용입니다.
- 충전/구독/결제/Tripo 유료 처리/GLB 다운로드/새 Unity 배치 없음.

## 병렬 역할과 검토

- 메인: 최종 수량·예산, 브라우저 잔액/가격 읽기, 전체 15개 아트 프롬프트·이미지 생성, 통합 기록.
- GPT-6 Sol high 디자인 검토자: 기존 에셋 대조, ASSET_PLAN.md 및 T01–T07 시각 QA.
- GPT-6 Sol high 독립 검토자: 이전 소비 검산, 비용·형상 누락 검토, T08–T14 및 구조 비교 시트/견적 화면 시각 QA.
- 메인은 생성 결과 전체를 확인했습니다. T02의 서리유리는 의도된 불투명 형태입니다. T04/T05/T07/T09/T12/T14 창이 이미지상 비어 보여도 3D 관통을 보증하지 않습니다. T08 온전한 기와와 T11 노출 서까래는 구별되는 형태입니다. T01/T10은 코너 시안으로 적합하더라도 기존 에셋 비교 전 과금하지 않습니다.
- 최종 독립 결과: VISUAL_QA_A.md, VISUAL_QA_B.md, REVIEW.md를 메인이 직접 읽었습니다. 두 검토자의 직접 시각 판독 범위는 각각 T01–T07 7장, T08–T14 및 B비교 시트 8장으로 합계 15장입니다. 원화 참고로 채택 가능하며 필수 재생성 요구는 없습니다. 3D/실측/Unity 적합성은 별도로 미검증임을 유지했습니다.

## 전후 증빙과 한계

- 신규 원화 생성 전 해당 단품 파일은 없었으므로 원화의 before 이미지는 존재하지 않습니다. 완성 원화를 이전 이미지처럼 표시하지 않았습니다.
- after_clinic_window_art.png, after_control_window_art.png, after_structural_art.png는 생성 결과 원화 복사본이며 실제 게임/Unity 스크린샷이 아닙니다.
- Tripo 실제 확인 화면 before_tripo_quote.png / after_tripo_readonly.png만 UI 전후 증빙으로 구분합니다.
- PNG가 뒷면·정확한 치수·모듈 이음새·유리 분리·구멍·내부 파밍·충돌·NavMesh·지붕 컷어웨이·LOD·최종 카툰 렌더를 검증한 것은 아닙니다.
- B1의 높은 채광 지붕·포털 및 B4의 곡면 지붕·리브를 후속 구현에서 생략하면 10군 실루엣 목표를 충족하지 못합니다.
- 스폰/탈출·동선·울타리·B4/R8 문제는 이번 범위 밖이며 변경하거나 해결 완료로 처리하지 않았습니다.
