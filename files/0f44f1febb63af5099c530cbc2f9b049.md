## 사용자 지시
현재 이미지 크기는 유지한다. 반복 수정 지시를 주제로 통합하고 회차별 수정 중점을 보여 준다. 기획 문서 등 각 탭에 소규모 분류 속성을 둔다. 데이터 편집기 채팅과 조율하여 두 웹사이트의 전체 배열을 통일한다.

## 기획 의도·변경 전 문제
진행 확인 한마디도 독립 카드로 표시되어 실제 변경 흐름을 파악하기 어려웠다. 문서와 검증 자료가 섞여 있고, 두 도구는 색만 같을 뿐 브랜드·탭·좌측 메뉴·본문 시작 위치가 달랐다.

## 실제 변경·방법
- 원문 1,043건을 삭제하지 않고 305개 주제에 일대일 소속시켰다. 명시적 변경 기록 연결, 동일 작업 폴더, 동일 시나리오 Chat을 우선한다. 연결 미확인 Codex 지시는 동일 대화+분야+소분류로 묶고 통합 근거를 표시한다. 제목만 같은 무관한 문서는 합치지 않는다.
- 지시 604건을 564개 고유 지시 회차(동일 지시 1건 중복 포함)와 진행 확인 39건으로 모두 보존한다. 단순 재촉은 펼침 목록으로 분리했다. ‘주인공 캐릭터 제작’은 10건→실질 지시 3회차+확인7건이다. 텍스처/리깅, 눈꺼풀/표정, 메시/텍스처 경계가 각 회차의 중점이다.
- 회차 표시는 지시 횟수이며 구현 완료 횟수가 아니다. 상태는 기존 원문 표현을 보존한다. 원문 지시 시각 604건을 원본 CSV/Chat JSON에서 읽어 KST로 표시했다. 파일 수정 시각으로 대체하지 않았다.
- 각 탭에 분야·소분류·자료 성격(기획·설계, 검토·검증, 참고·제작, 구현 명세, 변경 결과, 지시, 진행 확인, 전후 원문) 속성 및 필터를 추가했다. 전체에서 33개 소분류가 노출된다. 분류는 탐색용이며 게임의 확정 요구나 적용 범위를 변경하지 않는다.
- 주제별/개별 기록 전환, 회차 원문 왕복, 원문·비교 이미지·검증 문서 링크, 기존 개별 기록 해시 주소를 보존했다. 필터 초기화는 현재 탭을 유지한다.
- ‘스탯 데이터 편집기 추가’ 채팅(01a1653a-5721-77b1-b7eb-5b3c5f37e829)과 사용자 승인 범위에서 직접 조율했다. 공통 브랜드, E40px, 상단76px, 도구별 액션44px, 하단12px, 메뉴236px, 간격16px, 좌우14px로 통일했다. 편집기 담당은 data-editor/data-editor-web만, 이 작업은 planning-library-web만 수정했다. 라이브러리의 긴 목록은 본문 안에서 스크롤하며 상단 탭 위치는 유지한다. 편집기의 기능상 우측 상세 패널은 유지한다.
- 원본 이미지 추가 업로드·재압축은 하지 않았다. 기존 웹 이미지 7,398장과 문서 1,358개는 R2에서 그대로 제공한다. 입력 색인은 기존 게시 스냅샷이며 이번에 프로젝트 전체 기록을 새로 수집했다는 뜻이 아니다.
