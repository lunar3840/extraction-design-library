# 비교 시안의 촬영 시점 구분

`baseline_renders/before_car/shell/roof_iso/top.png`6장은 이번 수정 전에 실제 기존03 에셋을 새로 촬영했다. 실제 변경 전 증빙이다.

최종04의 마당 조합은 이번 작업에서 새로 만든 격리 비교 fixture다. 이 조합이 작업 전 A맵에 존재했던 것처럼 표현하지 않는다. 조합의 변경 전 조건2장은 이전03에 구워 보존된 폐차·S06 외벽·지붕3개를 사용하여 최종 조합과 동일한 위치·카메라·조명으로 **수정 후 재구성**했다. 원본03 prefab/의존 해시가 그대로임을 최종04 보고서에서 대조했으며 재구성 source 경로는 이전 `a-map-surface-ivy-refinement/candidate_03/DEMO_PREFABS.txt`다.

정확한 이름으로 다음과 같이 파일을 이동했다. 이미지 픽셀은 변경하지 않았다. 실행 당시 기록인 `study_04/CAMERAS.txt`의 원래 이름은 감사 기록으로 보존하고 이 대응표로 연결한다.

| 실행 당시 이름 | 재구성 표시 최종 이름 |
|---|---|
| study_04/before_showcase_iso.png | study_04/before_reconstructed_showcase_iso.png |
| study_04/before_showcase_top.png | study_04/before_reconstructed_showcase_top.png |

`after_showcase_iso/top.png`와의2쌍은 이 격리 조합의 재구성 전후 비교다. 실제 게임 맵 배치의 전후 비교나 작업 전 존재한 장면의 직접 촬영으로 취급하지 않는다. 나머지 중간 study01/03의 같은 이름은 중간 실행 원본으로 보존하며 최종 공개 이미지에 포함하지 않는다.
