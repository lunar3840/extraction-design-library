# A맵 서측 공구 작업마당 D02 독립 검증

## 검증 범위

V33의 공구 작업마당을 보존한 상태에서 남측 P0 접근, 반입 A, W05 동측 정비 B1, W04 남측을 돌아가는 B2, 북측 서비스 C가 실제 배치·충돌·이동으로 구별되는지 확인한다. 독립 검증자는 `StageAWestD02Validation.cs`와 `StageAWestD02Play.cs`를 소유하고, 배치·Unity 적용·씬 저장은 수행하지 않는다.

## 판정 자료와 방법

- 변경 전 실제 Unity 화면은 같은 기록 폴더의 `before_*.png` 9장이다. 변경 후 화면과 짝을 맞춰 직접 판독한다.
- `D02_PLAN.json`의 네 페인트 경로를 원본 굴절점과 폭으로 읽어, 실제 지형 MeshCollider의 높이·경사와 플레이어 크기 캡슐 충돌을 중심 및 양쪽 가장자리에서 검사한다. 배치 코드의 성공 문자열은 검증 근거로 삼지 않는다.
- V33 공구 작업마당의 WC_G1(9m), WC_G2(4m) 실개구와 담장·건물 보존, 기존 설비 중 의도적으로 교체한 EW2/EW3/EW4/EW6의 비활성, 외부 EW1/EW5 유지 상태를 확인한다. 보호 구조의 전후 상세 서명은 메인 작업 기록과 대조한다.
- 새 동선은 각 지점의 실제 NavMesh 접속과 먼 우회 없는 국소 경로를 확인한다. 기본 진입점 B1–B4에서 탈출점 X1–X7까지 28쌍, 두 교량, 기존 주요 건물 내부 목표도 다시 확인한다.
- 실제 Play에서는 자동 입력을 중단하고 적을 동결한 상태에서 PlayerMotor와 활성 CharacterController를 정상 보행 속도로 실행한다. 한 렌더 프레임당 실제 `Time.deltaTime` 한 번만 움직인다. P0↔A, B1 선택 루프, B2 독립 우회, C 작업면, 북측 측문 왕복의 총 10차로를 검사하며 플레이어 카메라 화면을 저장한다. 이 검사는 적과 교전하는 실제 AI 행동 검사가 아니다.
