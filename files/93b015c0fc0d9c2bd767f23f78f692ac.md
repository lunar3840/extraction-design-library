# 대표 총기 선택과 기존32종 대응

이 표는 구상 명단의 대응표다. 실제 카탈로그·상점·드랍·저장품·아트를 변경하지 않았다. 예비 후보는 삭제 지시가 아니다.

| 분류 | 대표로 검토하는 기존ID | 신규 후보 |
| --- | --- | --- |
| 소총7 | AR_001, AR_002, AR_003, AR_004, AR_011, AR_012, AR_013 | 없음 |
| 기관단총3 | 없음 | MP5, UMP, P90 — 신규ID 미확정 |
| 권총3 | P_001, P_002, P_003 | 없음 |
| 산탄3 | SG_001, SG_003, SG_011 | 없음 |
| DMR3 | DMR_001, DMR_002, DMR_003 | 없음 |
| 저격3 | SR_002, SR_003, SR_012 | 없음 |
| 기관총2 | MG_002, MG_003 | 없음 |

기존21 + 신규3 = 대표24. 예비 기존11을 더하면 원래32개의 화기를 모두 추적할 수 있다.

| 예비 분류 | 기존ID·모델 | 보류 이유와 재검토 조건 |
| --- | --- | --- |
| 권총2 | P_004 D.Eagle / P_011 새총 | Anaconda와 중량 권총 역할이 겹치거나 별도 발사체/명중 규칙 필요. 상위 품질 권총으로 다시 배치하지 않음 |
| 산탄4 | SG_002 Winchester 1880 / SG_004 SG870 / SG_012 소드오프II / SG_013 Remington | 장전 방식·산포·취급 차이가 대표3종과 분명해질 때 재검토. II라는 이름만으로 기본 피해 상위 버전을 만들지 않음 |
| 저격4 | SR_001 회수 저격총 / SR_004 SV98 / SR_011 K-14 / SR_013 Dragunov | 저비용·기동·정밀 역할 중복. Dragunov의 DMR/저격 정체성 및 탄약 계열은 별도 검토 |
| 기관총1 | MG_001 분대 지원 기관총 | RPK의 이동 지원과 M249의 지속 사격 사이 새 선택 이유가 생길 때 재검토 |

기존 근접 KN_001~004, KN_011의5종은 이번 대표 화기 수에 포함하지 않고 보존한다. 현재 근접 카탈로그 티어도02회차의 무기 무티어 설계와 후속 정합성 검토 대상이며, 지금 필드나 성능은 바꾸지 않았다.

방탄복16/헬멧10은 기존8방탄복/8헬멧을 재해석·확장하는 제품 후보이며 기존 저장ID를 새 제품에 임의 재사용하는 결정이 아니다. ID 이관·재질·외형 교체는 구현 승인 이후 검토한다. 원래 머리색·장비 착용 지침을 보존한다.
