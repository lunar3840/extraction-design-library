## 사용자 지시와 기획 의도

다른 항목의 소수점·퍼센트도 전체 확인하고 발견한 오류를 CSV와 Unity 반영까지 고치라는 지시다. 같은 데이터 편집기의 숫자 읽기 정확성과 이동/반영을 검증하는 작업이므로 기존 주제 ID를 유지한다. 이전03회차에서75→0.75로 정정한 기록은 보존한다. 사용자 원문은 [SOURCE_TRANSCRIPT.md](SOURCE_TRANSCRIPT.md)에 별도 보관했다.

## 변경 전 상태와 문제

공개103분류12,931항목과 현재 로컬14,686항목을 조사했다. 소수점 또는 퍼센트100배 변환의 추가 오류는 없었지만, 이전 파서는 일부 문맥에서 마이너스를 숫자에 포함하지 않아 원문의 음수를 양수로 표시하고 저장했다. 총38개가 독립 C# 분석기와 불일치했다. 공개본에 포함된 사례는 `StageMapRouter.cs#L135:3` 참조값 한 개다. `d.y>=-.3f`를0.3으로 읽고 있었다. 현재 로컬 검사·계산 코드에는 추가 사례가 있었다. 빌드 지시문의 경고 번호0649도 잘못 수집되고 있었다.

## 실제 변경 및 방법

- 비교·곱셈·null 병합 등 뒤의 단항 부호를 숫자와 함께 읽고 교체한다. 뺄셈 연산자는 유지하며, 새 음수와 인접한 `-`가 `--` 연산자로 합쳐지지 않게 한다.
- 선행0 없는 소수·음수·지수·정수·16진수·2진수와 접미사를 유지한다.16진수 E/D를 실수 표기로 오인하지 않는다. 빌드 지시문은 숫자 수집에서 제외한다.
- 로컬 저장 CSV와 기준값의 부호 누락38개를 실제로 보정했다. 미저장/저장 사용자 편집은 없었으며 원본 Unity 파일은 쓰지 않았다. 경고 번호1행 제외 후 현재14,685항목이다.
- 공개 카탈로그 및 서버 저장 상태는 특정ID·필드·원문·이전 값이 일치하는0.3→-0.3 한 항목만 보정했다. 다른12,930개 값·지문·읽기 전용 상태·권한·작업 대기열을 유지한다. 보정 이력은 한 번 기록되고 두 번째 조회에서는 반복하지 않는다.
- CSV 최신 숫자 표기를v3으로 갱신했다. 안전한v2는 호환한다. 과거에 부호를 놓치던 문맥의 구형 오류 값은 가져오기를 거부한다. 최신 파일의 의도적인 양수는 자동으로 부호를 뒤집지 않는다. 비율과 퍼센트 수치는 원본 단위를 유지하며 자동100배 환산은 하지 않는다.
- 연결 도구의 숫자 원문과 결과값이 일치해야 웹에서 적용 완료로 승인한다. 실제 원본 해시·명시적 비교·백업·재추출 검사는 유지했다.
- 독립 감사 재현 도구와 회귀 검사를 추가했다. 별도 Roslyn의83,137개 리터럴과 대조했으며, 현재 로컬 코드/데이터의 값·교체 위치 불일치와 미확인 리터럴은 모두0이다.

## 검증과 적용 범위

- 공개103개 카테고리 CSV 전수:12,931개 값/숫자8,530개 일치. 로컬 전체 CSV:14,685개 값/숫자9,993개 일치.
- 공개본 이후 바뀐4개 파일의291행은 보존된 공개 원문을 별도 분석해 일치를 확인했다. 최신 로컬 값으로 공개본을 일괄 교체하지 않았다.
- 복사 프로젝트에서 C#·JSON·Settings의 일반/PC 전달 CSV 가져오기·명시 반영을 검증했다. 웹 인증→대기열→실제 연결 도구→복사 원본 쓰기→재추출→완료 응답도 검증했다. 비율0.625와 퍼센트 수치62.5, 음수-0.12 및 작은 소수0.0000025가 각각 유지됐다. 복사 C#는 반영 후 Roslyn으로도 확인했다.
- 기능 검사120개 및 설명 데이터 검사 통과. 현재 실제 Unity 원본의 모든 감사 대상 해시가 작업 전과 같으며 실제 Unity 파일 쓰기0회. 게임의 원래 수치는 이미 음수이므로 게임 밸런스 자체를 변경한 것이 아니다.
- 편집기 공개 배포v10 성공. [공개 편집기](https://extraction-balance-editor.ehojin0415.chatgpt.site/). 원본 지문은 이전과 같은 `7dae3ef2c6cfcc501fd08cdacdaba5ce0cddde4710f4ae120bdbf41d8d773f8e`다.
- 실행 중이던 로컬8890 편집기는 최신 코드로 재시작했으며 켜 둔 상태다. 다른 PC의 연결 도구도 최신 파일로 다시 실행해야 새 숫자 검사를 사용한다.
- 기존 오류 CSV는 최신 편집기에서 다시 내보내 사용한다. 관련 오류가 포함된 구형 파일은 자동 변환하여 적용하지 않고 재내보내기를 안내한다.
