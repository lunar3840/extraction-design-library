## 실제 변경과 구현 방식

- 현재값30→32px Bold, 최대치·변화량13→15px Regular/Medium.
- strip을(56,896,616,44)로 변경해76px 상향. 무기2 하단과33px 간격.
- 아이콘은 기존 Figma 원본26px와104px 로컬 PNG를 정확히 재사용했다. 원본 아이콘 아트·폰트 파일·meta/GUID를 바꾸지 않았다.
- 콘텐츠 폭159/124/155/155, 현재값 열68/57/57/57, 보조 열59/35/66/66, 시작점0/168.25/297.75/457.75.
- 아이콘 투명 여백을 고려한 그룹 간 간격은 약10px로 유지하고, 현재값 좌측/보조값 우측 정렬과 고정 열을 유지했다. 전체 오른끝672는 기존 Operator 내부이며 중앙 가방까지24px 여백을 유지한다.
- 현재값34px·보조15px 후보는628.75px가 필요해 Operator의 허용616px를 넘으므로32px를 선택했다. 실제 Noto hmtx로99.9,120,/86.3kg,+120회복 등을 확인했다.
- 드문100.0kg 이상은 기존 제한 열 내부의 자동 글자 축소를 유지한다(100.0은25px). 일반 설정 최대86.25kg와99.9까지는32px를 유지한다.
- 최대/변화량은22px씩2행. 아이콘 y9, 전체44px.
- Figma의 기존18개 Kind/Value/Flow 변형과4개Context, main/no-backpack/전체UI clone의 공유 instance를 갱신했다. wrapper는 Operator 내 고정 오버레이로 두어 자동 레이아웃에 의해 다시 아래로 밀리지 않게 했다. 관련 ID와 실제 반환 좌표는 figma_component_state.json 및 figma_screen_update_*.json 참조.
- 데이터 연동·소모/회복 표시·색·문구·백플레이트 없는 구성·체력 상세 동작을 보존했다. 기존 IMGUI 그림자는 Figma blur의 근사이며 픽셀 동일 효과라고 주장하지 않는다.
