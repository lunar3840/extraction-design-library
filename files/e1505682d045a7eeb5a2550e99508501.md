# 자료 포함 비공개 웹 기획 라이브러리

작성일 2026-10-23 KST. 사용자 요청: 노트북의 자료가 없는 PC에서도 읽도록 문서와 이미지를 함께 올린 웹 버전 구현.

변경 전에는 localhost 서버 또는 동일 폴더의 원문·이미지가 필요했다. 새 planning-library-web에서 Sites의 소유자 전용 사이트를 생성하고 문서·지시 색인·이미지·연결 자료를 배포 자산으로 묶는다. 원문은 파일로 복사하며 이미지는 내용 변경 없이 웹 열람용 WebP(최대1440px)로 변환한다. 실제 로컬 원본은 보존한다. 웹용 링크는 배포된 파일 경로로 바꾼다.

새 자료 생성은 현재 게시본을 자동 변경하지 않으며 재배포 시 갱신한다. 새 사이트가 없던 상태이므로 변경 전 웹 화면은 없다. 브라우저 제공자가 연결되지 않아 실제 전후 화면 캡처·육안 검수는 미수행이다. 배포 성공 여부는 Sites 결과, 링크·자료 검사는 planning-library-web/VERIFICATION.json에 근거한다. 완료 배포 URL·버전은 DEPLOYMENT.json에 별도로 기록한다.
