## 비용·품질 절감 방식

1. 실제 문 구멍, 곡면 지붕, 반복 철골은 Blender에서 정확한 치수로 제작합니다. 똑같은 형태의 길이·색·오염 차이에 Tripo를 반복 사용하지 않습니다.
2. 중정비 크레인·펌프·변압기·차량·파이프·차양 등 기존 설비를 재활용합니다. 기존 프리팹에서 원하는 부품이 반드시 분리된다는 뜻은 아닙니다.
3. 생성 UI에서 확인한 기본 선택지는 2K입니다. 4K/8K·Ultra·AI 강화·추가 업스케일은 기본 계획에서 제외합니다. Unity 반입 시 대부분 1K로 제한하고 큰/중요 부품만 2K를 별도 검토합니다. 반입 축소는 실행 성능 절감이며 생성비 할인이 아닙니다.
4. 반복 창틀은 약 3–6k 삼각형, 벽·처마는 약 5–8k, 관찰창/복잡한 파손 부품은 최대 약 8–12k를 후처리 목표로 검토합니다. 생성 보증값도, 프레임 성능 예측도 아닙니다. 작은 녹·균열은 텍스처에 맡기고 기본 실루엣과 개구부 두께는 유지합니다.
5. 과거 목표 4k~16k 모델들이 동일하게 30씩 과금됐으므로 폴리곤 수를 낮추면 생성비도 낮아진다고 가정하지 않습니다. 추가 리토폴로지/스마트 UV/텍스처 재생성도 필요성과 UI 가격을 확인한 경우에만 검토합니다.
6. 3종 시험 후 확대합니다. 전체 14종을 한꺼번에 과금하거나, 목표액 2,500을 채우기 위해 에셋을 늘리지 않습니다.
