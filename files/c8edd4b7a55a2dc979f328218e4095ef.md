# D13 A맵 외곽 울타리 독립 검토

## 변경 전 기준과 검토 범위

- 기준은 D12까지 반영된 현재 저장 A맵이다. 이전 D12 작업 전 스냅샷은 D13 전체 맵 보존 판정에 재사용하지 않는다. `BASELINE.txt`, `BEFORE_CAPTURE_INDEX.csv`, `before_editor.png`, 네 변의 광역·상세 화면, 네 코너, 일곱 탈출구 접근 화면과 씬·프리팹 백업을 확인한 뒤 D13 전용 읽기 전용 스냅샷을 만든다.
- 원본 `StageA_Landform_v09/BoundaryGuards`에는 North 52개, South 52개, West 40개, East 40개, 총 184개의 큐브가 있다. 원본은 10m 이하 길이로 나뉘며 각각 MeshRenderer와 BoxCollider를 갖는다. 측면 배치는 맵 경계에서 0.3m 바깥, 두께는 0.6m이다. 원래 시각 큐브는 각 면 양끝에서 0.35m씩 잘려 있으나, 충돌체는 구간 양끝보다 0.04m씩 더 뻗는다. 새 울타리의 코너 이음과 실제 물리 경계가 어긋날 위험이 있다.
- 허용 원본 변경은 이 184개 MeshRenderer의 `enabled=true` → `false`뿐이다. 원본 Transform, MeshFilter, 재질 참조, BoxCollider의 설정·위치·실제 범위, 지형, 수로, D12·V34 아트, 조명, 스폰·탈출 데이터는 모두 불변이어야 한다. 신규 객체는 시각 전용 `D13_OuterFence` 루트 아래 네 면 그룹과 46개 패널에만 추가하며 신규 Collider는 없어야 한다.
- 특히 X6 탈출 지점은 남쪽 경계에서 약 11m, X5는 동쪽 경계에서 약 13m 떨어져 있다. 원본 경계를 막는 물리면은 유지하되 실제 플레이어가 일곱 탈출 지점에 접근·활성화할 수 있어야 한다. B4와 비활성 R8의 기존 62.169m 간격과 위험 진입 정책도 유지하며, 이 작업이 두 진입 경험의 미해결 문제를 해결했다고 주장하지 않는다.

## 분리된 통과 조건

- 정적 보존: D13 직전 현재 맵 전체의 오브젝트 구조·재질·조명·전역 렌더 설정을 스냅샷과 비교한다. 원본 184개 renderer 표시만 꺼지고 물리 충돌은 정확히 남는지, 신규 루트에만 46개 패널·3개 D13 전용 재질이 있는지, 각 패널 메시가 해당 원본 네 구간의 물리 수평 범위와 최고점을 시각적으로 덮는지 검사한다.
- 기하·시각: 패널 하단이 기존 메시 지형에 접하는지, 네 코너와 10m 이음에 틈이 없는지, 울타리 막대가 원본 0.6m 물리 스트립을 벗어나 보이는 통로와 실제 통로가 달라지지 않는지 확인한다. 북·남·서·동 광역/상세, 네 코너, 수로가 외곽에 닿는 구간, 탈출구 전후 같은 시점 사진을 직접 비교한다.
- 실제 플레이: `PlayerMotor`로 네 변과 코너를 향해 밀고 원본 충돌면 밖으로 나가지 않는지, 걸림 없이 각 탈출구에 접근·활성화하는지 확인한다. 정적 검사 성공만으로 시각 완성이나 이동 안전을 통과 처리하지 않는다.
- 비용: D13 신규 메시 합계 15만 삼각형 미만을 목표로 계산하되, 이 수치는 실제 FPS·프레임 시간 측정이 아니다.

## 현재 상태

- 변경 전 증빙은 20개 대응 시점과 에디터 화면, 씬·프리팹 백업으로 확보되었다. D13 직전 저장 맵의 독립 스냅샷에는 원본 33,841개 객체, 경계 가드 184개, 원본 재질 파일 548개, 씬 조명·볼륨 16개가 포함된다.
- `VALIDATION_candidate01.txt`를 독립적으로 읽어 정적 검사 17/17 통과를 확인했다. 원본 맵 누락·구조·외형 차이 0, 원본 재질 파일 변경 0, 기존 가드 184개 렌더러만 숨김, 기존 BoxCollider 184개 보존, 신규 객체 51개는 D13 루트 아래 네 면·46개 패널에만 한정, 신규 Collider 0개다. 패널은 106,296삼각형으로 15만 예산 안에 있다.
- 20개 동일 시점 후보 화면 중 네 면 상세·광역, 네 코너, 수로 쪽 남쪽 경계와 탈출구 접근 화면을 변경 전 화면과 비교했다. 기존 단색 벽은 지형을 따라가는 낮은 기초와 높은 철살 울타리로 바뀌며, 확인한 화면에서 두드러진 이음 틈·코너 누락·지형 부유·탈출구 침범은 보이지 않는다. 사진만으로 모든 184구간의 픽셀 단위 이음이나 FPS를 보증하지 않는다.
- `after_play_01/OUTER_PLAY.txt`의 실제 `PlayerMotor` 30/30 통과를 확인했다. 네 면 대표 19지점과 코너 4곳을 밀어도 모두 맵 안에 머물렀고, 일곱 탈출 지점은 모두 실제 이동 후 `InsideExit=True`였다. 물속에서만 시작 가능한 `SouthGuard_27` 한 지점은 명시적으로 제외되었다. 추출 저장 트랜잭션 자체는 실행하지 않았다.
- 기존 연속된 BoxCollider를 정확히 보존했으므로 철살 사이가 시각적으로 열려 있어도 그 틈으로 실제 이동하거나 탄환·레이캐스트가 통과하는 울타리라고 해석하면 안 된다. 이는 사용자 요청의 시각 교체·물리 보존 범위에 따른 제약이다. 106,296삼각형 수치는 FPS 측정이 아니다.
- 저장·재로드 후 `VALIDATION_final.txt`를 다시 읽어 17/17 통과와 같은 106,296삼각형을 확인했다. `after_*.png` 20개와 `after_editor.png`, `CHANGE_RECORD.md`도 확인했다. 전후 캡처 인덱스의 카메라 위치·시선·FOV는 20/20 일치한다. 후보와 저장 후 최종 이미지의 파일 내용은 19개가 같고 남쪽 광역 한 장은 1600×1000 중 외곽의 단 1픽셀만 달라 실질적인 장면 변화가 없다. 에디터 화면에서도 단색 경계 대신 높은 울타리 둘레가 보인다.

## 독립 판정

요청 범위인 **D12 기준 A맵 외곽 단색 벽의 시각적 높은 울타리 교체**는 통과한다. 원래의 연속 충돌과 진입·탈출 정책, 맵·재질·조명 보존을 정적 비교와 실제 이동으로 확인했다. 단, 이번 판정은 철살 틈의 탄환 통과, 수중 시작 한 지점, 실제 추출 저장, 전체 경계의 연속 주행, 프레임 시간·FPS, 지도 밖 배경의 완성도를 보증하지 않는다.
