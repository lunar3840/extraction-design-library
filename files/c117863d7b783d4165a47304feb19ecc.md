# 중정비동 지붕·외벽 가시성 및 칸막이 교차 수정 V24

## 사용자 지시와 의도
- 북쪽(화면 상단) 접근에서 지붕에 가려지는 플레이어와 건물 입구를 식별할 수 있게 한다.
- 2층 외벽이 사라져 실외가 전부 열려 보이는 문제를 수정하고 벽 교차를 정리한다.
- 기존 사용자 에셋 30종, 신규 53개 배치와 기존 소품 21개 교체, V23 재질을 보존한다.
- 앞서 진단한 밝기 경계는 이 변경의 대상이 아니다.

## 변경 전 상태 및 백업
- 현재 A맵 씬이 편집 모드이고 저장되지 않은 변경이 없는 것을 확인한 후 백업했다.
- `backup/A.unity`, `backup/A.prefab`, 기존 층별 표시 코드 3개를 보존했다.
- `before_north_approach.png`, `before_2f_north.png`, `before_west_crossing.png`, `before_east_crossing.png`는 실제 수정 전 같은 프로젝트에서 촬영한 고정 카메라 증빙이다.
- 사용자 첨부 화면은 `user_report_north.png`, `user_report_2f.png`로 별도 보관했다. 재현 화면과 혼동하지 않는다.
- `before_INVENTORY.txt`에는 맵 전체 위치/회전/크기, 재질, 메시 연결, 충돌체 정보를 기록했다.

## 확인한 문제
- 실내에서는 Exterior 전체를 숨겼고, 실외에서는 Roof 전체를 표시해 건물 경계 양쪽에서 정반대의 과도한 표시가 발생했다.
- 2층 좌우 수평 칸막이의 문틈을 수직 칸막이가 가로막는다: 서쪽 x=-27,z=-2, 동쪽 x=27,z=-2.

## 진입점 간격 재검토
- B4/R8 기존 설계 기록을 확인했다. 두 지점의 약 62m 간격과 W5 합류, 초기 적 노출·엄폐·파밍 접근·탈출 위험의 기존 유사성은 이번 건물 내부 수정으로 차별화되지 않는다.
- 기본/위험 진입점, 적, 파밍 배치, 탈출점 및 초기 외부 동선은 변경하지 않는다. R8 비활성을 유지하며 독립 위험 진입점이 해결됐다고 간주하지 않는다.

## 실제 변경
- 실외 접근: 플레이어 머리/발 및 인근 외벽으로 향하는 카메라 시선에 걸리는 지붕 타일, 고창부, 상부 외벽 패널만 표시에서 제외한다. 건물 전체를 없애지 않으며 낮은 벽과 입구는 남긴다.
- 실내 층별 외벽: B1에서는 상부 외벽 제외, 1층에서는 1층 외벽 유지/2층 외벽 제외, 2층에서는 외벽과 창 패널을 유지한다. 캐노피에서 1층으로 들어갈 때 같은 층 번호 때문에 표시 갱신이 생략되던 경우도 보완했다.
- 2층 외부 시야: 높은 카메라가 외벽 너머 야외를 전부 보여주지 않도록 외부 영역만 거의 불투명한 시야 가림을 적용한다. 깊이를 쓰지 않는 지면 셰이더에 대한 대체 계산도 포함한다. 2층을 벗어나거나 맵이 비활성화되면 해제한다. 기존 전역 조명/톤매핑은 수정하지 않았다.
- 벽 가까이에서 플레이어 몸이 숨으면 가려진 몸 부분에만 청회색 실루엣을 표시한다. 원본 캐릭터/머리카락 메시·재질은 수정하지 않고 런타임 복제 표시만 사용하며, 종료 시 정리한다.
- 실루엣은 깊이 비교와 머리뼈 높이 상단 제외를 함께 적용한다. 겹쳐 있는 머리카락/헬멧 메시의 자체 가림이 원래 머리색까지 덮지 않도록 머리 부분은 표시 대상에서 제외했다.
- 서쪽 WestPlanning 및 동쪽 EastControl 2층 칸막이 각각에 기존 교차 문틈과 맞는 3.5m 통로를 만들었다. 두 벽의 해당 패널/충돌체만 분할했으며 일반 L/T자 접합부는 유지했다.
- 숨긴 지붕과 상부 외벽의 마우스 조준 판정은 실제 맞은 위치에 한해 제외한다. 실탄/물리 충돌은 유지한다.

## 전후 화면과 시행착오
- `before_*`와 `after_*`의 같은 접미사가 같은 시점이다. 고정 편집 카메라 4쌍, 실제 플레이 카메라 17쌍을 보관한다. 플레이 카메라 화면은 1600×1000, HUD 없이 게임 월드만 동일 조건으로 렌더링했다.
- 플레이 시점: north_approach_center/west/east, south_main_approach/inside, second_south/north/west/east/northeast_near_wall, first_west_stair/east_stair/northwest_near_wall/northeast_near_wall, basement_west_stair/east_stair, attached_canopy.
- 사용자 설명의 ‘상단’은 화면 기준으로 해석해야 한다. 실제 현재 카메라에서는 월드 남측 주 출입구 접근에서 지붕에 완전히 가리는 현상이 재현됐다. 북측 접근도 함께 검증했다.
- 첫 적용의 자동 검사는 통과했지만 독립 화면 검토에서 벽 옆 플레이어 몸 가림을 발견했다. `iteration1/`에 이를 보존했으며 완료로 처리하지 않고 실루엣/하체 검사 및 외부 시야 제한을 추가했다.
- 창은 기존 불투명 창 재질을 유지한다. 이번 작업은 무제한 외부 시야를 차단하는 수정이며, 실제 투명 유리를 통한 창밖 렌더링을 새로 구현한 것은 아니다.
