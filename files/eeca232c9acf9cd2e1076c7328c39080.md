# 고철 소총·체감 성능 격차·획득 구간 — 05회차 정정

2026-10-29 KST. 같은 장비·무기 주제의05회차다. **기획 원칙을 정정했으며 게임 구현은 하지 않았다.** 최신 사용자 지시가02~04회차의 충돌하는 해석보다 우선한다. 이전 원문·수치안·공개 파일은 그대로 보존한다.

## 최신 사용자 확정

1. 기존 기획의 ‘회수 소총’ 명칭을 **고철 소총**으로 바꾼다.
2. 무기에 명시적인 티어·색상 등급·등급 배지를 붙이지 않는다.
3. 좋지 않은 총과 좋은 총의 **실제로 체감되는 성능 격차**를 둔다. 표시 등급 없이도 사용자가 총의 가치를 느낄 수 있어야 한다.
4. 성능과 희소성에 따라 가격과 습득 확률이 자연스럽게 달라진다.
5. 고성능 총은 높은 티어 구역/구간에서만 획득하도록 설계할 예정이다.

탄약T와 방어구 티어를 유지하는 이전 확정도 계속 적용한다. 다른 ‘회수’ 무기의 이름까지 바꾸라는 지시로 확대하지 않는다. ‘고철 소총’은 기획상의 새 표시명이며 현재 AR_001 카탈로그/실제 UI는 수정하지 않았다.

## 기존 해석의 정정

02~04회차에서 무기 무티어를 모델 간 수직적인 우열을 배제하고 동급의 장단점 교환에 집중하는 것으로 해석한 부분은 수정한다. **등급 표시를 없애는 것과 모든 총을 같은 수준으로 만드는 것은 별개다.**

앞으로는 전반적인 실전 효율이 좋은 총이 존재할 수 있다. 고철 소총은 싼 준비와 쉬운 입수의 의미를 갖지만 화력·명중 유지·취급 등에서 발전된 총보다 한계를 느낄 수 있게 한다. 좋은 총을 얻으면 실제로 교전이 편해지는 성능상의 보상이 있어야 한다.

그 안에서도 총기별 사격 리듬·근접/정밀/안정 성향을 유지할 수 있다. 개성이 있다는 이유로 모든 총을 반드시 동급으로 보정하지 않으며, 좋은 총이라고 모든 능력치를 동시에 최고로 만들어야 한다는 뜻도 아니다. 모델별 새 순위·격차 폭과 같은 모델의 품질 변형 체계는 아직 정하지 않았다.

## 가격·획득 원칙

가격은 모델의 종합 성능, 희소성, 재입수 난도와 손실 부담을 반영하는 방향으로 재검토한다. 구체 가격은 미확정이다. 표시하지 않은 성능 차이를 설명하기 위해 기존 무기 C/B/A/S를 그대로 유지할지 같은 구현 수단도 결정하지 않았다. 기획을 숨은 고정 등급 필드의 구현 완료로 취급하지 않는다.

고성능 총을 낮은 구역에서 아주 낮은 확률로 생성하는 것은 ‘높은 구역/구간에서만 획득’이라는 사용자 원칙을 충족하지 않는다. 구역별 현장 생성 후보를 정할 때 허용되지 않은 구역에서는 해당 모델의 생성 확률을0으로 두는 방향이다. **어느 구역이 해당 구간인지, 어느 총이 제한 대상인지, 실제 확률은 아직 정하지 않았다.**

월드 상자·보스/일반NPC 장비·전리품·퀘스트/보상·상점·기존 소유품의 반입/회수 등을 함께 확인해 낮은 구역의 우회 입수가 생기는지 검토해야 한다. 이 경로들의 예외는 이번 지시로 임의 허용하거나 금지 확정하지 않는다. 기존 소유품의 삭제·압수, 판매 제한이나 구역 진입 제한도 새로 결정하지 않았다.

현재 맵을 중앙/외곽만으로 난도 분류하지 않으며 특정 건물·B/R진입점·진입가치 문턱을 이 문서로 변경하지 않는다. 높은 난도 목적지가 외곽에도 있다는 기존 원칙을 유지하고, 획득 구간과 실제 진입 조건은 후속 기획에서 조율한다.
