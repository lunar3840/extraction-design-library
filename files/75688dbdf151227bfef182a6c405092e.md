# 루팅·상점 슬롯과 정보창 티어 색상 통일

상태: 완료. 2026-10-22 (Asia/Seoul).

## 사용자 지시와 기획 의도

루팅창과 상점 아이템 슬롯에 인벤토리와 같은 티어 색상 기준을 적용하고, 마우스 오버 정보창의 색도 해당 슬롯과 일치시킨다. 좁은 슬롯에 티어 문자를 다시 추가하지 않고 배경색·외곽선으로 구분한다. 기존 캐릭터 영역과 게임 기능은 이 변경의 대상이 아니다.

작업 중 후속 지시: 정보창 밑의 `클릭 상세 · 드래그 이동` 조작 안내는 생략한다. 공용 정보창에서 조작 안내·그 구분선·불필요한 빈 높이를 제거하고 실제 클릭·드래그 동작은 유지한다. Figma와 Unity 양쪽에 적용한다.

## 변경 전 상태

- 루팅의 공개 완료 슬롯은 이미 공용 DrawSlot을 사용한다. 미수색 물품은 중립색과 물음표만 표시한다.
- 공용 정보창은 중립 배경/외곽선을 사용하며, 강조색도 가치 V 기준이라 관통 T 기준의 탄약 슬롯과 다를 수 있다.
- Unity 상점은 아이콘이 없는 텍스트 상품행이며, 상품용 hover 정보창이 연결되어 있지 않다.
- Figma 기존 상점 시안은 Tier/Item 인스턴스를 재사용한다. 실제 네이티브 상태와 수정 기록은 FIGMA_TIER_CONSISTENCY.md에 별도로 남긴다.

## 수정 전 증빙

- before_work_scene_unoccluded.jpg: 실제 원래 StageA 작업 씬. 최초 before_work_scene.jpg에는 앞에 있던 Figma 창이 겹쳐 있어 해당 이미지를 씬 비교 기준으로 사용하지 않는다.
- before_r03_supply_1920x1080.png / before_r03_loot_search_1920x1080.png / before_r03_loot_revealed_1920x1080.png: 이번 요청 후, 런타임 소스 수정 전에 기존 SystemsTest 씬의 격리 프로필에서 촬영했다. 34장 전체와 38단계 manifest를 보관한다.
- 기존 검증 도구의 컴파일된 Record 경로가 이전 작업 폴더를 가리켜 그 폴더에 before_r03 이름으로 먼저 저장되었다. 해당 원본69파일을 그대로 이 폴더에 복사했다. 재구성·화면 합성·후 이미지의 전 이미지 위장은 없다.
- source_before 및 source-before-manifest.json: 변경 대상 런타임4파일의 원본과 해시.

## 변경 범위와 방식

- 기존6색/티어 판정/가격 기준을 재사용하고, 슬롯과 정보창이 같은 색상 해석을 참조하도록 공통화한다.
- 탄약 슬롯은 관통 티어, 일반 물품은 기존 가치 티어를 사용한다. 정보창의 가치·관통·잔량 내용은 보존한다.
- 상점은 기존 상품행에 티어 아이콘 슬롯과 읽기 전용 상품 hover를 연결한다. 구매/판매/재고/해금/잔액 판정은 보존한다.
- 미수색 루팅 물품의 티어와 정보는 공개하지 않는다.
- 앱 종료·재시작, 일반 사용자 저장 변경, 씬 에셋 저장은 수행하지 않는다. 검증 종료 후 원래 StageA 씬을 복구한다.

## 실제 변경 부분

1. 공용 `ItemTierPresentation.SlotTint`를 추출해 기존 슬롯과 공용 정보창이 같은 색을 참조한다. 기존 슬롯의 RGB·혼합·선택 강조 수치는 바꾸지 않았다.
2. 정보창의 짙은 바탕에 티어색24%를 혼합하고 불투명도92%를 적용했다. 외곽선70%·상단선·내부 아이콘 슬롯도 같은 티어색을 사용한다. 작은 가치V 배지는 판매 가치의 뜻을 유지하며, 탄약의 관통T 본문도 남긴다.
3. 기존 상점 상품행에64×64 논리 크기의 공용 슬롯·큰 아이콘·우하단 구매 단위1을 추가했다. 아이콘과 상품 정보 부분에만 hover를 연결하고 구매 버튼 쪽은 제외한다.
4. 상점 스크롤을 고려해 실제 viewport와 hover 후보의 교집합만 등록한다. 상품 미리보기는 읽기 전용 `SlotView`이며 가짜 무기 장탄/의료 잔량을 만들지 않는다.
5. Editor 증빙 도구는 출력 위치와 격리된 상점·6색 루팅·실제 GameView 저장 명령만 추가했다. 정상 게임 런타임이나 저장 규칙으로 사용하지 않는다.
6. 후속 지시에 따라 공용 hover의 하단 안내 label과 구분선을 제거했다. 카드 높이는 마지막 실제 내용(아이콘/상태/설명) 아래14px까지만 잡는다. API와 실제 클릭·드래그 처리는 유지했다. 단계별 before/after 소스는 `source_before_footer/`, `source_after_footer/`, 검증은 `TOOLTIP_FOOTER_REDUCTION.md`와 `footer-preservation-audit.json`에 있다.

## Figma 최종 완료

기존 Tier/Item 12변형과 상점4색 슬롯은 이미 같은 색 변수를 사용하므로 재사용했다. 공용 정보창 패밀리112:3402에 Color tier1~6(원본2=105:2984)을 연결했고, 기존 검토 인스턴스105:3363에304×239/안내 삭제가 자동 반영됐다. 기존 토큰 값·캐릭터·열·슬롯 배치는 보존했다. 6색992×538 및 검토1920×1080의 두1×PNG를 담당자와 메인이 각각 직접 열어 통과 판정했다.
