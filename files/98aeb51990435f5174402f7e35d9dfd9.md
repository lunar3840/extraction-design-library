# 에델·세린 장비 디자인 시안

## 지시와 목적

사용자가 3D 장비 제작 plan의 색상·디자인 차이를 키우고, 먼저 시안을 승인받은 다음 Blender 피팅과 Unity 삽입을 진행하도록 지시했다. 후속 지시는 서브컬처 의상의 노출 유지, 에델/세린의 실제 비율 사용, 같은 역할의 방어구도 티어마다 다른 생김새를 가져야 한다는 것이다. 원문은 USER_REQUEST.md에 보존했다. 기존 장비 원본 인계 회차(2026-10-30/equipment-art-model-package)의 후속 디자인 목적이므로 같은 주제 ID를 유지한다.

## 변경 전

첫 16종 시안은 전신 피복과 일반 마네킹 비율이라 사용자의 노출·캐릭터 비율 요구에 맞지 않았다. 수정한 첫 캐릭터 착용 시안(draft03)은 두 캐릭터 비율을 참고했으나 C/B/A/S의 판 분할과 연결부 차이가 충분히 명확하지 않았다. 이를 최종 승인본으로 취급하지 않는다.

## 실제 시안 변경

- C는 회수 천/판재, 비대칭 판의 연결과 보수 흔적, 올리브·갈색·녹슨 주황색.
- B는 구문명 치안 장비의 연속된 둥근 보호 셸과 큰 규격 버클, 회청·크림·황토 포인트.
- A는 분할된 각진 군용 판과 정돈된 모듈 결속, 어두운 올리브·차콜·벽돌색 포인트.
- S는 얇게 겹친 복합재 셸과 매입 결속, 네이비·화이트·실버·시안 포인트.
- 최종 비교 이미지는 **동일한 균형형 역할**에 네 티어를 적용했다. C는 비대칭 회수 판, B는 한 장의 둥근 셸, A는 각진 분할판, S는 네 개의 얇은 분리 셸로 구분한다. 더 높은 티어를 무조건 더 무겁거나 더 많이 가리는 의상으로 대신하지 않는다.
- 에델과 세린은 각각의 실제 게임 기준 렌더를 이미지 참조로 사용했다. 원래 얼굴·헤어색·큰 머리와 짧은 팔다리의 비율을 유지하는 방향으로 만들었다. 팔·복부·허벅지 일부를 드러내고 가슴·골반·둔부는 불투명한 의상으로 덮는다.

## 방식과 검증

built-in image_gen으로 제작했다. IMAGE_PROMPTS.json은 실제 프롬프트와 참조 파일을 기록한다. 프로그램으로 기존 캐릭터 메시를 바꾸거나 합성한 결과가 아니다. PNG의 비율·머리색·역할/티어 레이블·발 잘림·보호판 구분을 눈으로 확인했다. 균형형 최종 이미지에는 C의 비대칭 보수판, B의 단일 둥근 판, A의 세 구획 판, S의 네 분리 판이 보인다.

**이미지 참조 기반 시안이므로 정확한 3D 치수 일치나 실제 피팅을 증명하지 않는다.** 얼굴·신체 픽셀과 형태가 원본 메시와 동일하다는 주장도 하지 않는다. 모델 제작 시에는 원본 메시·본·UV·재질을 유지하고 두 체형에 별도 피팅해야 한다. 캐릭터별 어깨/가슴/허리/골반의 곡률과 스트랩 길이, 팔 움직임과 머리카락 간섭을 Blender와 Unity에서 확인한다.

16종 마네킹 시트는 기동/균형/중장/정비의 전체 디자인 언어를 보여주는 보조 자료다. 현재 두 캐릭터로 비교한 최종 대상은 균형형 4티어이며, 16종 모두의 3D 피팅 완료나 모든 착용 시안 완료로 보고하지 않는다. 헬멧14종도 단독 디자인 초안이다. 이미지 안의 생성된 'GAME READY' 문구는 제작 상태를 뜻하지 않으며 실제 모델·방호 성능·게임 적용은 미완료다.

사용자 승인 전 **새 장비 메시 제작, Blender 피팅, Unity 장비 삽입은 하지 않았다.** 새로운 드롭·성능·방호 범위·세트 착용 규칙을 확정하지 않았다. 무기24종의 새 개별 제작 시트는 이번 비교 이미지에 포함되지 않는다. 차기 승인 범위를 구체화한 다음 제품별 정면·측면·후면 제작 시트를 작성한다.

에델 원본/애니메이션 동기화와 현행 게임 투명도 점검은 ../character-sync-equipment-concepts/CHANGE_RECORD.md에 별도 기록한다. 미확보 원격 출력 링크를 새 시안이나 구현 완료의 증빙으로 사용하지 않는다.


## 실제 라이브러리 게시 확인

2026-11-02 사용자 지시의 기존 장비 주제 후속2026-11-02-01(주제 내 작업9회차)로 문서4개·이미지4장·시안 수정 비교1쌍을 게시했다. 전투·적 AI / 무기·사격 / 기획·설계 분류, 원문4개 열람, 상세 이미지4개와 대표 썸네일3개를 실제 공개 화면에서 확인했다. 이전1127항목·69게시행·307주제와 원문/이미지 대응 및 과거 고정 검증 스냅샷을 보존했다. 최종1128항목·70게시행이다.

이 게시 확인은 승인 대기 이미지 시안의 자료 열람 확인이다. 새3D장비 제작·캐릭터 피팅·Unity 적용·무기24종 개별 제작시트는 완료로 승격하지 않았다. 공개 허용목록 밖의 대체된 전신피복 초안,3D원본·텍스처·ZIP은 업로드하지 않았다. 비교쌍은 같은2행4열 시안 수정이며 Unity 게임 화면이 아니다.

기존v19 화면을 유지하고 자료만 증분 게시했다. 현재 세션에 서버 쓰기비밀키가 없어 README의 실제 게시 복구 절차에 따라 Sites 비밀키를 갱신하고 동일v19를 환경revision13으로 배포했다. 공개범위·인증정책·게임·편집기·공통UI는 변경하지 않았다. 비밀값은 기록하지 않는다. 최종 해시와 확인 결과는 PUBLICATION_VERIFICATION.json 및 publication_snapshot에 저장한다. 게시 전후 카드 확인 화면은 publication_evidence/before_library.jpg와 after_library.jpg이며 시안 원본 전후쌍과 구별한다.
