## 사용자 지시

1. “좌측 아이콘들 탭 의미에 맞게 재디자인해서 넣어주고 박스들 모서리에 라운드처리해서 좀 둥글게 해야할 것 같음. 레트로 느낌이 아크레이더스의 중요 포인트기도 해서 너무 지금처럼 적은 숫자의 색만 쓰진 않았으면 함(그렇다고 엄청 많이 뭐 쓰라는게 아님)”
2. “그리고 백플레이트 남색 박스도 지금 너무 진함. 내가 기획서 탭에서 했던 것처럼 반투명한 스타일 유지해줘야함.”
3. “이전 테마 아예 지우진 말고, 테마를 white / black 두개로 해서 선택하는 식으로 했으면 좋겠는데. 혹시 지웠어 이전 테마? 아이콘이나 박스 라운딩 처리 같은건 기존 테마랑 공유하고.”

두 웹의 ARC 재디자인 1차 적용 뒤 받은 후속 변경이다. 동일 주제의 다음 회차로 이어지고, 1차 결과·원문은 보존한다. Figma 기획서 파일은 시각 표현만 읽었으며 비공개 포트폴리오 본문·다른 게임 규칙은 옮기지 않는다.

## 의도와 변경 전 문제

라이브러리의 문서·수정·대화·스크린샷과 기획 분야에 같은 전체 항목 아이콘이 반복되어 기능 구별이 어려웠다. 백플레이트4px 모서리와 어두운 합성이 사용자가 원하는 둥근 반투명·레트로 표현보다 딱딱하고 단조로웠다.

## 변경 방법

- 공통 24px 벡터 아이콘을 작성하고 문서/변경 이력/대화/이미지, 세계관/캐릭터/맵/전투/파밍/성장/UI/그래픽/검증에 의미별로 연결한다. 전체 항목의 기존 ARC 원본 그리드만 유지한다.
- 편집기의 기존 데이터 분류/그룹 이름을 읽어 사람·동선·체력·무기·탄약·경제·보호·도구 등의 아이콘을 붙인다. 렌더러는 라벨/ID/이벤트를 교체하지 않고 시각 속성만 부여한다.
- 공통 큰 패널18px, 모바일16px, 카드17px로 반경을 늘린다.
- 크림·모래색·적갈색·청록·회청색을 제한된 팔레트로 배정하고, 선택·검증·경고 등의 기존 의미는 보존한다.
- Figma 문서 `46:100`의 #1B2536/#090D16 배경 및 원본 백플레이트를 다시 대조. 패널은 #1B2536 /43%와 배경 흐림으로 더 밝고 투명하게 조정한다. 이는 원본 내부 수치의 재현 주장이 아닌 사용자 후속 의도에 맞춘 웹 조정값이다.
- 기존 `style.css`·이전 테마 소스·Git 및 전후 기록을 보존하고 White/Black 두 선택을 추가한다. White는 밝은 반투명 유리 표현, Black은 ARC 계열 남청색·레트로 팔레트로 구성한다. 아이콘/반경/배치를 공유하며 차이는 외형 토큰으로 둔다.
- 선택은 브라우저에 저장하고 도구 탭 이동 시 query로 전달한다. 기존 검색/카테고리/해시 원문 경로와 서버 데이터는 유지한다. 서로 다른 출처의 localStorage가 자동 공유된다고 주장하지 않는다.

## 검증·게시

실제 공개 배포 완료: 기획 라이브러리 v17, 데이터 편집기 v6. 두 웹의 White/Black 버튼, 테마 전환, 새로고침 후 선택 유지, 실제 도구 탭 이동 시 White가 이어지는 것을 확인했다. 아이콘21종이 실제 탭·분류에 연결되며 동적 목록 재렌더에도 유지된다.

두 도구 모두1280×720에서 헤더 x14/y0/1252×76, 좌측 x14/y132/236×496, 하단 x14/y640/1252×68, 제목20px/29px로 일치한다. 테마 선택을 넣은 도구 탭도 x896.53/y18/235.58×40으로 일치한다. 모바일390×844에서는 실제 내용폭383px, 헤더125px, 도구 영역 x14/y70/355.33×40, 좌측 x10/y189/363.33×250 및 제목19px로 일치하고 가로 넘침은 없다. White/Black은 같은 아이콘·라운드·배치 규칙을 사용한다.

- White 편집기의 보조 문구·필드·원본 경로·잠금 안내·표 상태·포커스 색 대비를 별도로 보완하고 실제 화면으로 확인했다.
- 라이브러리 조직/Worker 검사 통과, 편집기 임시 환경29/29 검사 통과 및 Unity 파일 열기0. 의미별 아이콘/테마 선택 JS 구문 검사 통과.
- 실제 공개 CSS·선택/아이콘 JS·SVG/PNG 총54개 조회 모두 HTTP200·로컬 SHA256과 일치.
- 공개 카탈로그103개 분류/12,931개 값 및 지문 `7dae3ef2c6cfcc501fd08cdacdaba5ce0cddde4710f4ae120bdbf41d8d773f8e` 유지. 원래 라이브러리/편집기 기본 CSS, backend·transport·app·CSV·카탈로그 파일의 이전 해시가 그대로임을 확인했다.
- 공개 편집기의 쓰기 잠금과 로그인 모달 접근 유지. 비밀번호 입력, 실제 웹 값 저장, Unity 반영 요청은 하지 않았다. 로컬 게임/Unity/Figma 원본을 편집하지 않았다.
- 배포 환경은 기존 라이브러리 revision7, 편집기 revision1을 유지했고 이번 후속에서 키나 계정 설정을 변경하지 않았다.

허용된 원문/검증 문서6개, 전후/White 증빙 PNG12개를 기존 주제의2026-10-27-02 회차에 게시했고 공개 재조회를 확인했다. UI 배포와 기록 색인 게시를 모두 확인한 뒤 published로 갱신했다. 이전 주제/원문/이미지/06·07 미완료 상태는 보존했다.
