# 사용자 원문 — 장비와 무기 종류 구상

- 채팅: 장비와 무기 종류 구상

> 이제 우리 게임에 나올 장비 종류와 무기 종류를 구현해야 할 것 같음. 우선 구현은 하지 말고 구상만 해줘보길 바람. 델타포스처럼 같은 티어 내에서도 여러 스타일의 (기동성을 중시한, 혹은 방어력을 중시한 등의) 방어구가 나오면 좋겠고, 총기류도 같은 라이플 내에서도 특색이 강한 방식으로 구현했으면 함.

이번 요청의 승인 범위는 기획 구상이다. Unity 실행·수정, 카탈로그·수치·스폰·적 방어구·총기 발사 방식 변경은 승인되지 않았다. 기획 기록 보존과 기존 기획 라이브러리 반영은 프로젝트의 상시 완료 절차에 따른다.
