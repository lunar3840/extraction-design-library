# A맵 현실감 개선 V17 — 외벽 기능 구분과 야드 중간 규모 구조물

## 사용자 지시와 범위

- 그래픽의 현실감을 개선하기 위해 앞서 제안한 외벽 반복 완화·야드 기능 구조물 작업을 시도하라는 승인에 따라 수행했다.
- 대상은 A맵 공장 홀 남측 외벽과 가까운 야드다. 전체 맵 리메이크, 새 캐릭터·적, 진입점 이동, R8 활성화는 범위에 포함하지 않는다.
- 메인이 설계·통합·플레이 검증을 맡고, Sol high 담당을 외벽 제작·야드 제작·독립 검증으로 나눴다. 제작 파일 소유를 분리하고 독립 검증 결과를 확인한 뒤 완료 처리한다.

## 기획 의도와 변경 전 문제

- V16에서 조정한 재질·조명은 유지하면서, 같은 벽·창이 이어지는 인상과 소품만 놓인 빈 야드의 형태 문제를 개선한다.
- 서측 보수 외벽, 중앙 사람 출입구, 동측 하역구의 기능이 형태로 구별되도록 한다.
- 야드에는 실규모 컨테이너·강관 보관 군집과 수리 쉼터를 추가하여 실제 작업장으로 읽히는 중간 규모 구조를 만든다.
- 사진 수준의 현실감 완성이나 전체 환경 품질 통일이 아니라, 한 구역에 한정된 형태 개선 단계다.

## 변경 전 증빙

- 수정 전에 현 상태를 저장했다. 재구성한 전 이미지가 아니다.
- 장면·프리팹 원본과 수정할 기존 런타임 파일 2개를 `backup/`에 보관했다.
- 7개 고정 카메라와 9개 실제 플레이 검사 지점의 시작/종료 18장, 합계 25장의 `before_*.png`를 확보했다.
- `BASELINE_VALIDATION.txt`: 9 PASS / 0 FAIL. 이전 충돌체 4,625개, 앵커 46개, 원격 구역 33개, V16 렌더러 457개 등의 서명을 보관했다.

## 실제 변경과 방법

### 외벽

- 홀 `Exterior` 아래 V17 전용 루트를 두고 서측 보수 패널, 중앙 출입구 테두리, 동측 골강판 하역 차양·기둥·지지재를 추가했다.
- 기존 외벽·실내·기존 충돌체는 교체하지 않았다. 신규 전용 재질을 복사해 사용하고 V16 재질 참조와 설정을 유지했다.
- 검토 중 하부 반복 창과 검은 평판 차양은 제거하고 콘크리트 보수 패널·기존 공장 자산의 골강판 지붕으로 바꿨다. 너무 어둡던 보수 패널 재질도 조정했다.

### 야드

- 서측 중심 `(-27,-55)`: 약 5.94×2.70×2.53m 컨테이너와 약 5.1m 강관 랙, 보관 상자·팔레트를 구성했다.
- 동측 중심 `(16,-70)`: 약 7.5×5.3m 지붕의 4기둥 수리 쉼터와 장비를 배치했다.
- 원안 동측 후보는 기존 문의 접근 여유 공간에 걸려 거부했다. `YARD_DIAGNOSIS.txt`의 안전 검사 결과에 따라 최종 위치를 선택했다.
- 신규 야드는 렌더러 24개·충돌체 24개·삼각형 69,425개다. 성능 수치는 별도의 빌드 벤치마크가 아니다.

### 시야와 충돌

- 새 하역 차양·수리 쉼터 밑에서 지붕 렌더러를 숨기고 밖으로 나오면 복원한다.
- 실제 결과 이미지에서 하역 차양을 숨겨도 뒤쪽 기존 공장 지붕이 캐릭터를 가리는 문제가 발견됐다. 하역 차양 아래에서는 기존 홀의 1층 가림 모드도 연동하고, 차양 기둥·발판·지지대는 계속 보이도록 했다.
- 숨겨진 지붕의 물리·탄환 충돌은 유지하며, 조준 지점 선택에 사용하는 포인터 검사만 지붕을 건너뛴다.
- 이 위치에서 함께 숨겨진 공장 상부 바닥·지붕·2층 외벽도 포인터에서만 제외한다. 하부 벽과 모든 물리·탄환 충돌은 유지한다.
- 기존 홀 지붕 가림 처리와 층별 이동 기능은 유지한다.
