# 전술 유리 HUD 스타일 개편

- 날짜: 2026-10-21
- 사용자 지시: UI의 투명도를 높이고 콜 오브 듀티·델타 포스 등 출시 게임의 HUD를 참조하여 세부 표현과 완성도를 보강.
- 후속 지시: 수분/에너지 아이콘 확대, 반투명 UI 명암 및 글자 가독성 보강. 후속 최종 기록은 readability-pass/CHANGE_RECORD.md.

## 기획과 변경 전

기존 시안은 같은 모양의 카드가 반복되고 무기 이미지·핵심 탄약·상태 변화의 구별이 약했다. 실제 게임 배경에서 판단할 수 있는 미리보기도 없었다.

## 변경 내용과 방법

Figma 네이티브 컴포넌트를 편집하여 큰 탄창 수, 밝게 보정한 실제 프로젝트 무기 썸네일, 30발 탄창 눈금, 원형 스킬 충전, 원형 미니맵과 방위 눈금, 목표 진행·탈출 표시를 구성했다. 소스 AR_001.asset의 magazineSize 30, reloadTime 2.8과 실제 WeaponThumbnails/AR_001.png를 확인했다. 본문은 Noto Sans KR, 핵심 숫자는 Barlow Condensed SemiBold를 사용했다.

첫 재질은 HUD 전용 배경 불투명도 16%, 알림 24%, 흐림 14px로 제작했다. 이는 후속 사용자 지시에 따라 글자 패널 32%, 흐림 10px, 대비 높은 테두리·글자 그림자로 보강되었다. 수분/에너지의 최초 58px도 후속 76px로 확대되었다. 최종 수치는 후속 기록을 따른다.

일반·위급·탈출 HUD(13:708,13:855,13:1423), 컴포넌트 가이드(57:1158), 생존 가이드(49:1226)를 갱신했다. 실제 프로젝트의 UI 없는 과거 캡처 after_tools_interior.png를 별도 가독성 미리보기의 배경으로만 사용했다. UI 전체를 이미지로 평면화하지 않았다. 캐릭터와 아이템은 개별 에셋이며 모든 UI 문구와 도형은 편집 가능한 레이어다. Unity 파일·게임 실행 상태는 변경하지 않았다.

## 참조와 적용 범위

- CoD 공식 How to Play / Controls: https://www.callofduty.com/guides/blackops6/training/call-of-duty-guides-black-ops-6-multiplayer-how-to-play
- Delta Force 공식 Operations Mode 101: https://deltaforce.garena.com/en/news/system/RMDWVM
- 초기 시각 자료 reference_cod_hud.jpg는 2024년 공개 자료, reference_delta_hud.jpg는 Hawk Ops 알파 자료다. 최신 출시판과 동일하다고 단정하지 않았다.
- 도입한 것은 수치 위계, 반투명 레이어, 상태 표시 등 디자인 표현이다. 다른 게임의 게임 규칙·수치·UI 동작을 현재 프로젝트의 확정 구현으로 적용하지 않았다.
- 새 방위·거리·미니맵 도식은 편집용 예시다. 실제 A맵 지형·진입점·적 배치 변경이 아니며 런타임 데이터 연결을 완료한 것이 아니다.

## 증빙과 검증

before_normal/critical/extraction.png는 실제 수정 직전 Figma 캡처이고 after_normal/critical/extraction.png는 첫 전술 스타일 적용 결과다. 해당 3개 프레임은 동일 배경·해상도·캐릭터 에셋을 유지했다. before_guide.png ↔ after_guide.png, before_survival_guide.png ↔ after_survival_guide.png는 대응하는 문서 프레임이다. after_project_backdrop.png는 새 미리보기라 대응 before가 없다. 이후 최신 최종본은 readability-pass/의 전후 캡처와 기록으로 구분한다.

최초 구조 검증에서 대상 6개 프레임의 텍스트 컨테이너 이탈 0건, 폰트 Noto Sans KR/Barlow Condensed, 원본 UI의 편집 가능한 레이어를 확인했다. 연속 충전 호와 지도 방향, 별도 미리보기 위치를 검토·보정했다. validation.json과 상태 JSON에 ID와 검사 내용을 저장했다.
