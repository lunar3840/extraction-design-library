## 사용자 지시·기획 의도
새 기획과 수정 기록을 기존 주제·소분류에 계속 반영하고 후속 수정은 새 대표 항목 대신 회차로 연결하는 지침을 추가한다. 라이브러리와 데이터 편집기는 하나의 사이트의 두 화면처럼 브랜드·문구 크기·컴포넌트·패널 배치를 맞춘다.

## 변경 전
1280×720에서 메뉴 폭236/top132는 같지만 라이브러리 높이574, 편집기496이었다. 라이브러리 브랜드는 다른 요소·줄높이·여백을 사용했고 탭 컨테이너도 더 컸다. 이전 완료 보고의 공통 위치 확인만으로 전체 크기가 같다는 뜻은 아니었다.

## 변경과 방법
- 루트 AGENTS.md에 지속 반영/주제 연속성 및 공통 웹 UI 규칙 추가. 주제 ID·분야·소분류·자료 성격·회차 요약·게시 상태를 작업 기록에 남기고, 실제 신규 색인 수집/증빙 업로드/배포/공개 검증을 완료 절차로 규정했다. 권한·원문 부족 시 pending으로 보고하며 오래된 고정 수집본 재빌드를 최신 반영으로 오인하지 않도록 명시했다.
- 편집기 담당과 조율하여 편집기 소스는 수정하지 않고 실제 CSS와 공개 DOM 치수를 기준으로 라이브러리를 맞췄다. 브랜드 DOM/폰트/줄높이/마진, 로고, 탭 컨테이너·링크, 좌측 메뉴 버튼, 패널 높이, 하단 정보바와 반응형 기준을 통일했다.
- body grid는 상단76+액션56+유동본문+하단80, 바닥12. 1700px 이상 및 1100/540px 이하 기준은 편집기 수치에 맞춘다. 본문 기능과 우측 편집 상세는 각 도구에 맞게 유지한다.
- 전후 증빙/기존 원문/이미지/주제 데이터는 삭제·재압축하지 않았다. 별도 자동감시 작업은 이 채팅에서 만들지 않았다.
