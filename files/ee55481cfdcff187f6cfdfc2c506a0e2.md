## 실제 변경 및 검증

### 최종 적용 내용

- `LandscapeV31_OrganicGuidance` 아래 A/B/C/D를 분리했다. A는 5m 안부를 사이에 둔 두 물리 메시로 나눴다. 총 주 지형 메시 5개다.
- A는 기존 지표 위 3–5m 암반 절개, B는 2.65m 작업 기단, C는 3.45m 설비 단차, D는 2–3m 제방 돌출부다. 높이는 지표 고도에 더해지는 높이다. 도로 판만 띄운 형태가 아니라 지표에 맞춘 전체 점유면·측면·매립 이음을 갖는 물리 지형이다.
- 현재 V09 지표를 재빌드하거나 기존 지형 에셋을 덮어쓰지 않았다. 5,221개 생성 표면 샘플에서 실제 MeshCollider 높이를 확인했다. 경계 누락을 위한 2.5cm 보조 ray가 필요했던 최종 샘플은 0개다.
- 새 형상의 렌더 메시와 충돌 메시가 동일하다. 숲이나 보이지 않는 거대 상자로 이동을 막지 않는다. 지표와 겹치는 하단은 의도적인 매립 이음이고, 상면을 지표와 같은 높이에 겹쳐 놓지 않았다.
- 차선 없는 Time Ghost 반복 텍스처로 독립 URP 재질 4개를 만들었다. 기존 원본 재질은 변경하지 않았다. 산업 설비 4개와 암석 7개는 교체 가능한 별도 자식으로 구성했다.
- C 남동쪽 끝을 줄여 기존 폐차를 보존하고, D 북서쪽에 열린 홈을 만들어 실제 T3 단말과 접근 공간을 보존했다. 정확한 최종 윤곽과 차이는 `AS_BUILT.json`에 기록했다. 승인 `PLAN.json` 원본은 변경하지 않았다.
- D의 홈을 만든 뒤 남았던 1m 폭 서쪽 돌출 띠는 두 꼭짓점을 제거해 정리했다. 기존 점유면 밖으로 넓히지 않았다. 이 마지막 축소 후에도 전체 기하·통행 검사를 다시 실행했다.
- 재생성 시 기존 메시의 렌더링 버퍼도 명시적으로 갱신하도록 해, 물리 형상만 새것이고 화면에는 이전 형상이 남는 문제를 바로잡았다.
