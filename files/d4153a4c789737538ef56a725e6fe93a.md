# 기계형 이동 독립 검증 (2026-10-15)

**판정: 이번 수정 범위의 순간이동·날아다님 현상은 개선 확인.** Unity 소스·씬·프리팹은 수정하지 않고, 실제 A맵 40초 기록과 변경 소스, 정적·재생 검사 결과를 별도로 읽었다.

- `before_143540` 대비 `after_195517`: 살아 있는 기계의 Animator 로컬 위치 최대 이탈 45.71917 → 0, 최대 루트 각속도 약 360.017 → 110.112도/초. 수정 후 루트 최고속도 2.421m/s, NavMesh 이탈 0, 높이 오차 0. 구르기 프레임 0이고 실제 `BeginRoll` 직접 호출도 거부됐다.
- 수정 후 살아 있는 5종 모두 Animator 로컬 위치·회전 이탈 0. 프리팹 검사에서는 5종의 root motion 비활성, 상태 연결, 애니메이션 재생 검사가 통과했다. `after_controlled_motion_02.png`에서는 보이는 SpiderLight의 몸체·다리가 연결되고 지면 근처에 있다.
- 전차는 인간식 `Reposition`을 사용하지 않는다. 다만 NavMesh 경로를 따라 선회하는 동안 작은 횡속도는 남는다. N3_Tank 40초 기록에서 최고 횡속도 0.294m/s, 0.4m/s 초과 프레임 0, 0.2m/s 초과 연속 구간의 횡이동은 각각 최대 약 0.16m였다. 따라서 **완전한 무횡이동**은 아니지만, 급격한 측면 점프는 관측되지 않았다. `Retreat`에서 목표를 바라보는 이동도 허용되므로 이 수치는 자연스러운 튜닝 한계로 남는다.
- `Stop(false)`는 유효한 현재 경로를 남긴 채 목표 속도를 0으로 줄이고, 0.05m/s 이하에서 정지·경로 해제한다. 경로 실패와 비활성 등의 `Stop()`은 즉시 정지한다. `ReuseMachinePath`는 경로 존재·비노후·0.6초·목표 차이 0.5m 이내를 확인하므로 현재 기록에서는 감속 중 경로 안정성 문제가 나타나지 않았다.

**계측 한계:** 시각 경계 중심 편차 최대 1.54962m는 수정 전후 동일하지만, 대부분 프레임에서 `visualMinY == visualMaxY == actorY`여서 카메라 가시성에 따라 렌더러가 비활성일 때 액터 위치를 경계값으로 쓰는 측정 코드의 대체값이 섞였다. 이 숫자로 몸체 내부 드리프트나 발의 지면 접촉을 판정하면 안 된다. `after_early_00.png`에는 기계가 아직 보이지 않아 해당 전 화면과 직접 외형 비교도 제한된다. 실화면 확인은 `before_controlled_motion_02.png`와 `after_controlled_motion_02.png` 같은 대응 시점에 근거한다. 다섯 종 모두의 개별 근접 화면 검증은 이번 40초 촬영에 포함되지 않았다.

## 전차 방향 보완 후 재검토

추가 소스에서는 전차의 목표 바라보기 상태를 정지 중으로 제한하고, 후퇴 시 NavMesh 경로의 역방향으로 선회하며, 경로와 앞방향 차이가 100도 이상이면 최소 이동속도를 0으로 낮췄다. 이는 전차가 적을 보면서 옆으로 이동하던 경로를 줄이는 논리다.

`after_195920` 실맵 40초 기록은 전체 검사 PASS(최대 루트속도 3.303m/s, 최대 각속도 110.082도/초, Animator 로컬 이탈 0, 구르기 0, NavMesh 이탈 0)였으나, 이번 출격에는 **Tank가 출현하지 않았다**. 기록의 종류는 SpiderLight·SpiderMedium·SpiderTransformer·SpiderHeavy뿐이다. 따라서 전차의 실제 횡속도 개선을 이 기록으로 판정할 수 없으며, 위의 전차 0.294m/s 수치는 방향 보완 전 `after_195517` 기록에만 해당한다.

`after_200330`에서는 출격별 후보 선택 정책을 유지하며 Tank와 SpiderHeavy가 포함된 출격을 골랐다. Tank의 살아 있는 3,069프레임에서 횡속도 최고 0.279m/s, 0.4m/s 초과 0프레임, 0.2m/s 초과 연속 구간 최대 횡이동 0.142m, Animator 이탈 0, NavMesh 이탈 0이었다. 이전 출격의 0.294m/s·0.156m보다 작지만 출격별 경로 차이가 있으므로 수치 감소 전부를 코드 변경의 효과로 단정하지 않는다. 이 실행은 40초 기록 후 근접 촬영 검사에서 출격 명단에 없는 SpiderTransformer를 요구하여 `RESULT FAIL`로 끝났다. 따라서 **이 실행을 전체 재생 통과로 표시하지 않는다**. 별도 모델 근접 검증 `model_validation/VALIDATION.txt`는 실패 0이며 Tank·SpiderTransformer 측면 이미지에서는 조립과 지면 높이에 이상이 보이지 않았다.
