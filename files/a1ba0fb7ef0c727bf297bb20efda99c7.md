# D07 Tripo 생성 독립 검토 — 2026-10-13

## 검토 범위와 판정

`ASSET_PLAN.md`, `ASSET_MANIFEST.json`, `REVIEW.md`, `VISUAL_QA_A.md`, `VISUAL_QA_B.md`를 대조하고, T01·T10 원화와 기존 D05 진료소 코너 프리뷰 및 D04 생활폐허 화면을 직접 열어 비교했다. **T02–T09·T11–T14의 우선 12종 선정은 타당하다.** 각 건축군에 다른 실루엣·재료·용도를 주며, 기존 설비 소품을 중복 생성하는 목록이 아니다. 이 판정은 입력 원화와 기존 기록에 대한 생성 계획 검토다. 새 Tripo 결과, GLB, 정확한 치수, Unity 적합성의 합격 판정이 아니다.

10개 외형군의 완성 판정은 별개다. 01 HALL과 06 GARAGE에는 우선 Tripo 후보가 없고 B1, B4, B5 구조 작업군이 필요하다. B1–B6은 모델 6종의 완성·생성 주문 목록이 아니다. `T08`은 07·08군에 공용인 **한 종류**이며, `T11`은 빠진 기와와 노출 서까래가 있어 온전한 `T08`의 색상 변형으로 축소할 수 없다.

## 우선 생성 순서와 중단 기준

1. **3종 시험:** `T02`(막힌 서리유리의 의료 가로창), `T04`(열린 아치 고창), `T11`(파손 처마·돌출 서까래). 유리면, 실제 개구, 불규칙한 지붕 끝이라는 서로 다른 실패 유형을 먼저 확인한다. 각 모델의 앞·사선·뒤와 회전 시 윤곽을 확인하고, 입력 원화 및 매니페스트 ID를 결과 ID와 연결한다.
2. 시험 3종이 단일 부품·형상·후면에서 목적을 유지하면 `T03`, `T05`, `T06`, `T07`, `T08`, `T09`, `T12`, `T13`, `T14`를 군별로 진행한다. 한 번에 전량 과금하지 않고 개별 결과의 실패 이유를 기록한다.
3. `T01`, `T10`은 이 12종의 자동 연속 주문에 넣지 않는다. 아래 기존 자산 대조와 건물 슬롯 확인 후 각각 생성·생략을 결정한다.

프리뷰 즉시 반려할 경우: 통짜 건물·바닥/배경판/소품 추가, 원화에 없는 창·문, 뒤를 막은 가짜 개구, 창틀·서까래의 큰 형상 소실, 두 부품으로 분리된 모델, 접합면의 큰 돌출. 회전 화면에서 합격해도 GLB 수령 뒤 메시/UV/피벗/실제 열린 공간·벽 두께·재질을 검사해야 한다. 기존 건물에 설치할 때는 실제 슬롯·출입 폭, 지붕 컷어웨이와 플레이어 가림, 충돌·LOD를 별도로 검증한다. `T03` 루버는 문이 아니며 `T02`의 8칸은 의도된 불투명 서리유리다. `T04`, `T05`, `T07`, `T09`, `T12`, `T14`의 원화상 밝은 창칸은 GLB 관통의 증거가 아니다. `T13`은 전면 경사가 보이나 후면 부착면의 평탄성은 미확인이다.
