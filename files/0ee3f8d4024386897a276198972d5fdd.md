# Rokoko Guns 모캡 SD 캐릭터 리타기팅 기록

## 사용자 지시 요약

- 다운로드한 `Guns.zip`의 Rokoko 총기 모션을 현재 프로젝트의 SD 캐릭터(Serin)에 적용해 실제 사용 가능성을 확인한다.

## 기획 의도와 해결하려는 문제

- 무료 총기 모캡을 SD 캐릭터의 전투 동작 제작에 재사용할 수 있는지 확인한다.
- 기존 플레이어용 전투 애니메이터를 바로 덮어쓰지 않고, 전체 모션을 독립된 미리보기 환경에서 안전하게 비교한다.
- 단순 임포트 성공뿐 아니라 손과 총의 접점, SD 체형에서의 자세, 실제 전투 루프로 쓸 수 있는지를 화면으로 검증한다.

## 변경 전 상태 및 문제점

- Serin은 프로젝트 전용 상체 조준/사격/재장전과 무기 손잡이 보정 방식을 사용하고 있었다.
- 기존 검증에서 조준·사격·재장전 및 걷기·달리기의 양손 그립 오차는 0으로 확인되었다.
- Rokoko 원본은 Mixamo 계열 52본 휴머노이드와 긴 전신 퍼포먼스 클립으로 구성되어 있어, SD 비율에서 그대로 사용할 수 있을지는 확인되지 않은 상태였다.
- 변경 전 화면은 `before_aim.png`, `before_aim_right_profile.png`, `before_fire.png`, `before_reload.png`에 저장했다.

## 실제로 바꾼 부분

- `Guns.zip`에 들어 있던 FBX 15개를 `Assets/Escape/Art/Rokoko/Guns/`에 추가했다.
- 15개 FBX를 모두 Unity Humanoid, 자체 Avatar 생성 방식으로 임포트했다.
- 제작용 `Serin.controller`와 분리된 `RokokoGunsPreview.controller`를 만들었다.
- 전용 미리보기 씬 `RokokoGunsPreview.unity`와 이전/재생/다음 조작 UI를 추가했다.
- 원본 모션의 양손 위치를 기준으로 기존 AR_001을 정렬해, 모션 자체의 총기 접점을 비교할 수 있게 했다.
- 원본 출처와 라이선스 확인 사항을 `Assets/Escape/Art/Rokoko/SOURCE.md`에 기록했다.
- 제작용 Serin 애니메이터와 기존 전투 모션은 변경하지 않았다.

## 변경 방식

- 원본 FBX를 편집하거나 잘라내기 전에 15개 전체를 독립된 프리뷰 컨트롤러의 상태로 등록했다.
- Unity의 Humanoid 리타기팅을 사용해 Serin Avatar에 재생했다.
- Rifle Light/Medium/Heavy와 ShotgunFight는 여러 시간 지점을 샘플링하고, 양손 높이와 간격을 기준으로 조준에 가까운 프레임도 추가 캡처했다.
- 임포트 및 컨트롤러 구성이 유효한지는 Unity 에디터 내부 검증 보고서로 확인했다.

## 변경 후 기대 효과와 확인 결과

- 임포트 결과: FBX 15개 모두 Humanoid 클립과 자체 Avatar로 정상 등록되었고, 전용 프리뷰 씬에서 재생된다.
- 안전성 결과: 제작용 `Serin.controller`는 교체하거나 수정하지 않았으며 기존 전투 시스템이 그대로 유지된다.
- 품질 결과: 원본 모션은 긴 시네마틱/퍼포먼스 성격이 강하고 SD 체형과 팔다리 비율 차이가 커서, 원본 그대로는 플레이용 조준·사격·재장전 루프로 쓰기 어렵다.
- 대표 문제: 하체가 접힌 채 떠 보이는 프레임, 팔이 총 손잡이에서 떨어지는 현상, 총이 가슴이나 얼굴을 가로지르는 현상이 확인되었다.
- 판단: 이 모션들은 폐기 대상은 아니며, 필요한 짧은 구간을 선별한 뒤 루트/하체를 정리하고 기존 `SdWeaponPose`의 양손 IK 보정을 결합하면 피격·처형·건푸 연출 또는 특수 동작의 원재료로 사용할 수 있다.
