## 저장본 확인

모델 포함 ZIP의 `native/Edel_AR_013_A_Corrected_Review.blend`를 Blender에서 열면 저장된 재장전 동작을 볼 수 있다. Space로 재생하고 카메라 보기로 확인한다. 자동 Python 실행 허용은 필요하지 않다. 수정한 동작 이름은 `GR_AR_013_A_*`다.

기존 `EF_*` 곡선은 보존 이력이다. 새 공통 보정값이 남을 수 있으므로 과거 화면의 정확한 비교는 별도로 보존한 before 이미지와 동결17 원본을 사용한다. 새 key를 포함한 현재 저장본의 검증을 과거 곡선·다른 무기까지 확대하지 않는다.

## 동작의 의미와 남은 범위

새 탄창 한 개는 시작부터 허리 파우치에 들어 있다. 왼손이 이를 잡아 꺼내고 총에 넣는다. 빈 탄창은 놓은 위치에서 떨어져 바닥에 남는다. 한 번의 탄창 교환을 보여주는 비반복 검토 동작이며 게임의 인벤토리·탄 수·재장전 시간이나 아이템 소모 로직을 구현한 것은 아니다. 검토 영상의 길이9.03초를 게임의 확정 재장전 시간으로 쓰지 않는다.

오른손 연결 피부에는 검토 사본 전용 `GR_RightGripWeb` 보정 한 개를 추가했다. 원래 기본 메시·뼈 rest·길이·가중치·UV·머리색·재질·기존 shape 좌표와 원본 Master는 보존한다. 모든 원래 데이터와 새 key 추가를 서로 구별해 검증했다.

**Unity에는 아직 적용하지 않았다.** 다른 총기·세린 등 다른 캐릭터의 파지 완료를 뜻하지 않는다. 기존 플레이어 감정·몸짓·이동 동작 전수 검증에서 발견한 별도8개 확정 결함도 이번 SCAR 사본 수정으로 해결했다고 보고하지 않는다. 실제 export 재현과 게임에서 새 보정의 연결·다른 자세와의 전환은 이후 적용 검증 범위다.

이전17 통과는 왼손 방향 오판으로 철회됐다.18은 재장전 팔/몸통,19는 조준/사격의 어깨/머리카락 추가 문제 때문에 최종본으로 승격하지 않았다. 이전 ZIP·native·영상·QA는 삭제하거나 덮어쓰지 않고 철회·실패 이력으로 보존한다.
