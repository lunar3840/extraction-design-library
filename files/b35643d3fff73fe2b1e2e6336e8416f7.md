# 전체 게임 화면 외곽선 강화

## 사용자 지시와 의도

사용자가 캐릭터뿐 아니라 전체 화면의 외곽선을 더 강하게 하여 카툰 느낌을 높이도록 요청했다. USER_REQUEST.md에 원문을 보존했다. 기존 D15 주제의 후속 구현 회차03으로 연결하며 회차01 검토와02 에델 피부 조정은 유지한다.

## 시작 상태와 범위

변경 전 PC_Renderer의 화면 외곽선은 widthPixels1.15, depthThreshold.025, normalThreshold.48, normalStrength.25, RGBA(.025,.038,.05,.72)였다. 기존 ToonOutlineFeature와 Game 카메라의 ToonOutlineCamera 마커가 활성인 게임 월드 화면에 적용된다. 캐릭터 전용 새 패스를 추가하지 않고 해당 설정의 두께와 농도를 조정했다.

맵/에델/UI 담당 세 채팅이 Unity/Assets/공유 요청 사용·예약 없음과 명시 반환을 확인했다. 메인이 단독으로 실행·적용·검증한다. 후보 설정 설계, 촬영 도구, 독립 검토를 GPT-6 Sol high에 분담하며 각 staging 하위 폴더만 수정하도록 분리했다.

## 실제 변경과 방식

| 설정 | 변경 전 | 채택 후 | 목적 |
| --- | --- | --- | --- |
| 폭 | 1.15px | 1.7px | 캐릭터와 구조물의 바깥 경계를 더 또렷하게 읽히게 함 |
| 깊이 경계 문턱 | .025 | .02 | 건물·차량·잔해의 실루엣을 조금 더 포착 |
| 법선 경계 문턱 | .48 | .46 | 단단한 표면의 모서리 구분 강화 |
| 법선 기여 | .25 | .38 | 창틀·칸막이·소품의 내부 모서리 농도 강화 |
| 잉크 alpha | .72 | .88 | 선의 농도 강화. RGB(.025,.038,.05)는 유지 |

`Assets/Settings/PC_Renderer.asset`의 기존 feature 설정5줄만 바꿨다. 재생성 메뉴가 이전 값으로 덮어쓰지 않도록 `Assets/Escape/Editor/ToonArtBuild.cs`의 같은 설정도 동기화하고 normalThreshold 대입을 명시했다. **그 메뉴의 Apply는 실행하지 않았다.** 해당 함수에는 원래 여러 재질을 다시 설정하는 동작이 있으므로 이번에는 값 동기화와 컴파일만 수행했다.

외곽선 셰이더·RendererFeature·카메라 marker 코드는 바꾸지 않았다. 중앙+4방향의 기존 깊이/법선 검출과 위를 향한 바닥의 세부선 억제를 유지했다. 추가 pass, 새 텍스처 샘플, SDF, 원본 모델/텍스처/UV, 피부·헤어 재질, 조명·Volume·카메라 조작·동선 변경은 없다. 화면이 완전히 새 카툰 재질로 바뀐 결과가 아니라 기존 표현에 윤곽을 더하는 조정이다.

## 변경 전후 확보와 실행 검증

제작 담당이 staging/design에서 설정 후보와5줄 diff를 작성했고, 도구 담당이 staging/probe에 별도 촬영 도구를 작성했다. 메인은 현재 Editor 창을 저장하고 원래 설정으로 실제 Play를 먼저 실행했다. before 로그의 RESULT PASS, 실제 카메라 marker/Renderer 참조,14보호 파일의 원본 해시를 확인한 뒤 두 프로덕션 파일만 적용했다. 원본은 backup/에 보존했다.

StageScenePreview의 격리 임시 저장 프로필만 사용했다. 캐릭터는 현재 에델로 고정하고 시간·입력·적 틱을 촬영 중 정지했다. 변경 전 POSE_PLAN.json을 변경 후에 재사용했다. A맵9시점과 B맵1시점, 총10개 실제 게임 카메라 렌더는1600×1000이고 위치·회전·FOV 로그가 전후 일치한다. 근접3뷰와 환경 조감/폐차 구도는 비교를 위한 진단 구도이며 실제 기본 전투 거리와 구별한다. 인벤토리는 열지 않았다. UI 없는 렌더 캡처를 HUD 전체 검증으로 취급하지 않는다.

- Before/After 모두 RESULT PASS. 실제 Player Camera의 marker 활성, PC_Renderer의 활성 outline feature1개와 runtime UniversalRenderer의 동일 참조를 확인했다.
- 실제 설정은 표의 변경 전후 값과 일치했다. 적용 후 설정을 다음 Play에서 다시 읽었으므로 메모리에서만 바뀐 시험값이 아니다.
- `game_front`에서 marker를 일시적으로 껐다 다시 켠 통제 촬영도 했다. 활성/비활성 사진의 차이 픽셀은59,961→170,946, 평균 RGB8 절대차는.4716→1.1419였다. 패스 실동작과 효과 증가의 근거이며 화질 점수·FPS·단순 선 면적 배수로 해석하지 않는다.
- 실제1층/2층 가림 값은0/1이다. A→B에서 기본 Hybrid Toon31재질로 전환하고 B→A에서 D15 및 원래 재질 바인딩으로 돌아왔다.
- 에델의 피부값은 전후 모두.65이며 활성 피부 재질3개가 같다. 읽은13개 메시 행의 정점 수와 UV0 해시도 동일했다. 에델 피부1차 소스3개, 헤어C15b, 맵 prefab/scene, Mobile Renderer, outline 셰이더·feature·marker, 조명 설정 소스는 기준 해시와 같다.
- 14보호 파일 중 PC_Renderer.asset과 ToonArtBuild.cs만 의도대로 바뀌었다. VALIDATION_SUMMARY.json과 FINAL_SOURCE_HASHES.json에 근거를 저장했다.

## 시각 검토 결과

메인이 실제 전후 사진을 보고 건물 지붕·파손 벽·창틀·실내 칸막이, 폐차·차량·드럼과 캐릭터의 윤곽이 더 진하고 또렷해진 것을 확인했다. 바닥의 작은 표면 요철까지 검은 잉크 덩어리로 변하는 현상이나 큰 이중 halo는 확인한 정지 화면에서 보이지 않았다. RGB와 배경 조명·재질은 그대로여서 건물별 색과 에델 원래 머리색/피부 표현이 유지된다.

독립 검토자가10쌍을 원본 크기로 직접 열고 실행 로그를 대조했다. 메인이 staging/review/FINAL_REVIEW.md를 직접 읽었다. 판정은 **확인한 PC 게임 카메라 A/B 장면의 점진적 외곽선 강화 통과**다. 실내1층 화면 상단의 NPC 한 개는 두 촬영 사이에 이동했으므로 그 부분은 품질 비교 근거에서 제외했다.

기존 game_front의 회색 가로띠와 indoor_2f 밖의 어두운 시야 덮개는 변경 전에도 있다. 강화 후 시야 덮개 아래 멀리 있는 **정적 배경의 잔윤곽이 소폭 더 읽힌다.** 이 한계를 남긴다. 시야 밖 적은 PlayerVisionController/EnemyController가 해당 Renderer를 끄므로 outline만으로 숨긴 적의 깊이 실루엣을 직접 되살리는 구조는 아니다. 이 판단은 소스 근거이며 시야 밖 적을 배치한 전용 동적 시험을 대신하지 않는다. 해당 시야 코드는 변경하지 않았다.

## 적용 범위와 한계

PC Renderer와 활성 marker를 사용하는 게임 월드의 캐릭터·불투명 건물/소품·깊이/법선에 참여하는 표면이 대상이다. Mobile Renderer에는 이 feature가 없고 이번에 추가하지 않았다. 투명 물/유리/비, 색상 텍스처 경계만 있는 무늬, HUD 전체에 같은 외곽선을 새로 보장하는 작업이 아니다. 위쪽 바닥·풀의 상면에는 기존 억제가 남는다.

정지 Editor 시험이며 HUD·모바일·움직일 때의 선 떨림·Player 빌드·GPU/FPS·장시간 전투는 확인하지 않았다. 기존 pass와 샘플 수가 같다는 사실을 성능 무영향이나 최적화 완료로 확대하지 않는다. 에델의 기존 헤어·파지·동적 충돌 미완료 상태도 이 외곽선 조정으로 해결되지 않는다.
