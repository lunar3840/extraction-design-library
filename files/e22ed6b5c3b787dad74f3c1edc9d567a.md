# 시나리오 Chat 대화·작업 내역 추가

작성일: 2026-10-23 KST.

## 사용자 지시 요약과 기획 의도

Work/Codex 외에 익스트랙션 시나리오에서 Chat으로 작업한 대화 내역·작업 내역도 로컬 프로젝트 기록에 추가한다. 지시와 응답·버전·실물 확보 여부를 함께 찾을 수 있게 한다.

## 변경 전 상태와 문제

10월21일 감사는 관련 Chat 대화 7개·사용자 메시지 34건을 보존했지만 최근 후속 메시지와 새 리브 모델 대화는 포함하지 못했다. 이전 보존본은 그대로 남긴다.

## 실제 변경과 방식

시나리오 섹션에 속한 Chat 대화 8개를 읽고 과거 보존본과 메시지 ID로 중복 제거했다. 54개 사용자 메시지의 지시별 CSV, 날짜순 원문 Markdown, 원문 JSON, 대화별 CHANGE_RECORD 8개, 파일 참조 및 로컬 후보 인덱스를 추가했다. 참조만 있는 응답이나 응답 미반환을 임의로 복원하지 않았다.

## 확인 결과와 기대 효과

본문 보존 29건, 참조 표시만 7건, 응답 미반환 18건. 응답 파일명 42종 중 동일 이름 로컬 후보 8종을 확인했다. 이는 실제 작업 54개 완성 또는 파일 42종 복구를 뜻하지 않는다. 조회 가능한 출처를 한 폴더에서 다시 찾을 수 있게 됐다. 최종 검증은 VERIFICATION.json에 기록한다.

## 스크린샷 및 비교 시점

대화 보존은 텍스트·출처 데이터 추가이며 실제 게임/모델/UI를 수정하지 않았다. 읽기 도구에 화면 촬영 기능이 없어 이번 수집의 전후 스크린샷은 확보하지 못했다. 10월21일 원본 스냅샷이 전 상태, 최신 page-001.json과 merged.json이 후 상태의 텍스트 증거다. 텍스트 파일을 실제 스크린샷으로 표시하거나 과거 작업의 전 이미지를 새로 만들지 않았다. Chat 원본 생성 이미지·영상이 미확보인 항목은 파일 참조표에 남겼다.

## 주요 파일과 상태

README.md, INSTRUCTION_LEDGER.csv, SUMMARY.json, ARTIFACT_REFERENCES.json, LOCAL_FILE_CANDIDATES.json, sources/<대화ID>/{page-001.json,snapshot-2026-10-21.json,merged.json,TRANSCRIPT.md,CHANGE_RECORD.md}. 실제 Unity와 캐릭터 모델은 변경하지 않았다. 이번 보존은 자동 동기화 설치나 미래 결과 수집 예약이 아니다.
