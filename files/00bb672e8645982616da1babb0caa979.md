## 사용자 지시와 기획 의도
- 인벤토리와 로비에서 좌우로 돌려도 화면상의 크기와 기준 위치 유지.
- 대기 동작 중 발에 따라 캐릭터 전체가 밀리는 느낌 제거.
- 클릭 시 무작위 표정과 이에 맞는 고개/상체 몸짓. 직접 캐릭터 입력이 없으면 주기적 자동 재생. 인벤토리 정리·파밍 아이템 이동은 대기 시간 초기화 대상에서 제외.
- 후속 지시: 인벤토리 캐릭터를 크게 표시하고 무기 슬롯에 몸이 가려지지 않도록 조정. 최종 지시는 발끝을 무기 2 슬롯의 하단 끝에 맞추기(슬롯 아래까지 내리는 중간 지시는 철회됨).
- Tab으로 여는 로비 출격 화면의 캐릭터도 확대.

## 실제 변경
- 미리보기 재구성 시 중립 자세의 골반 수평 위치와 발바닥 높이를 회전축으로 고정. 카메라 위치/배율은 회전이나 대기 자세로 다시 맞추지 않음.
- 미리보기의 골반·양쪽 다리·발과 상위 이동 뼈를 중립 자세에 고정. 상체 호흡·표정 몸짓은 유지. 실제 플레이어 루트와 이동 스켈레톤은 변경하지 않음.
- Joy/Surprise/Shy/Curious/Determined 표정에 고개 기울임·상체 움직임을 연결. 원본 FBX의 의미 있는 표정 채널을 사용하고 새 절차적 몸짓을 보강했음. 원본 패키지 CBG 액션 전체를 Unity에 가져와 재생한 것은 아님.
- 클릭과 드래그를 분리하고 슬롯 클릭을 제외. 직전과 같은 표정 연속 선택 방지. 대기 중 8~14초마다 다음 자동 반응 예약(다른 대기 몸짓이 진행 중이면 종료 후 시작).
- 이동·조준·구르기·피격·발사·재장전 등 실제 캐릭터 조작/전투는 반응과 대기를 초기화. 아이템 조작과 UI 열기/닫기는 초기화하지 않음. 게임 시뮬레이션 정지 상태는 그대로 유지.
