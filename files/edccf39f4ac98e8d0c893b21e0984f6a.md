# Modern Glass 참조와 웹 적용 범위

- 사용자 요청: 기존 Figma 시안에서 사용한 반투명 UI 스타일로 데이터 편집기 웹을 깔끔하게 다듬기.
- 원본: https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0?node-id=105-2987
- 2026-10-23 공식 Figma `get_design_context`를 통해 현재 `105:2987`의 코드·스크린샷을 함께 조회했다. 기존 로컬 기록과 대조해 같은 익스트랙션 Modern Glass Kit임을 확인했다.
- 읽기만 수행했다. Figma 파일·Unity 편집기·게임 에셋은 수정하지 않는다.

## 적용할 실제 스타일

| 원본 정보 | 웹에서의 사용 |
|---|---|
| `color-bg-panel: rgba(100,112,128,0.44)` | 분류·데이터·상세 패널의 회청색 반투명 표면 |
| `color-bg-tile: rgba(255,255,255,0.06)` | 안쪽 정보 영역·버튼·컨트롤 |
| `color-border-default: rgba(255,255,255,0.16)` | 얇고 밝은 패널 경계 |
| `color-action-primary: #72ebd1`, on-accent `#151b24` | 주 동작 버튼과 선택 항목 |
| `color-text-primary: #f5f7fb` | 제목·중요 값 |
| `color-text-secondary: #c5cdd7`, muted `#a2adba` | 본문·보조 정보 |
| Glass/Regular background blur32px | 큰 패널의 배경 흐림 |
| inset top `#EAF3FF26`, bottom `#06111B1F`, shadow `#050B133B` | 유리 경계·깊이 |
| Panel rounded28, card20, pill999 | 데이터 도구에 맞춘 둥근 패널·버튼 |
| Noto Sans KR Regular/Bold | 기존 프로젝트의 정적 글꼴 파일 재사용 |

데이터 편집기의 실제 표·입력·분류·상세 구조를 유지하며 스타일을 번역한다. 인벤토리 캐릭터·아이템 그림·예시 게임 수치와 화면 스크린샷은 웹 자산으로 넣지 않는다. 배경의 깊이는 CSS 표면과 은은한 색광으로 구성한다. Figma의 PNG 스크린샷은 비교용이며 구현 이미지로 사용하지 않는다.

글꼴은 기존 `Assets/Escape/Resources/UI/FigmaInventory/`의 NotoSansKR-Regular.ttf, NotoSansKR-Bold.ttf를 웹 폴더에 복사하고 기존 FONT-LICENSE.txt·OFL.txt를 함께 보관한다. 원본 글꼴 파일은 변경하지 않는다. 서버는 이 두 글꼴 경로만 추가로 제공한다.
