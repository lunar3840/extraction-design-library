## 작업 환경 및 변경 전 증빙

- 전체 화면 `before_<id>_<yaw>.png`; 원래 투명 배경 portrait 렌더 `before_<id>_<yaw>_portrait.png`. 모델 ID prototype은 에델.
- 원본 자료의 설명은 분석 자료로만 사용했고, 그 안의 작업 제안/스크립트를 사용자 지시로 간주하거나 실행하지 않음.

## 확인한 원인
- 세린과 리브의 몸체/기본 상의를 함께 검사하고 유이의 공통 몸체도 검사한 결과, 후면 상의 위아래에 같은 열린 경계 2곳(42점, 58점)이 존재함.
- 실제 Unity 후면에서 삼각 틈이 재현됨. 검은 영역 일부는 틈 너머 총이 보이는 것이므로 알파가 255라는 이유만으로 정상 표면으로 판단할 수 없음.
- 서로 정확히 같은 위치인 세린 몸체/상의 경계 76점의 현재 자세 위치 차이는 0. 단순히 분리 경계점의 서로 다른 웨이트 때문으로 결론 내리지 않음.
- 에델 피부 텍스처와 전후 렌더를 비교해 큰 띠 모양의 음영을 별도로 검토. 원본 피부 텍스처를 덮어 칠하지 않고 피부 재질에만 Toon 음영 경계 완화를 적용함.

## 변경 방식
- 원본 FBX와 기존 메시·UV·웨이트는 유지. 열린 후면 경계 두 곳을 연결하는 작은 스킨 메시를 별도 에셋으로 추가하고 세린·리브·유이 프리팹에 연결.
- 경계점 위치와 웨이트는 원래 모델의 경계점에서 직접 가져오고, 같은 스켈레톤/바인드포즈를 사용. 인접 피부 UV와 노멀을 사용하며 의상이나 머리카락의 UV/재질은 변경하지 않음.
- 각 캐릭터에 100점, 96삼각면 추가. 설치 결과와 최종 메시 검사에서 수치를 확인함.
- 에델 `Body_Skin_Clean` 재질만 음영 경계 폭 .18 / Toon 혼합 .6 적용. 헤어·얼굴·의상·무기의 Toon 설정은 유지.
