# 세린 S4 리핏 시험 결과

**종료된 피팅 시험이며 게임 적용 완료가 아니다.** 에델 S4 디자인을 재사용한 세린 전용 DCC/FBX 시험본을 만들었지만 Unity 실제 측·후면에서 겨드랑이·허리·쇼츠 경계의 파편과 피부 노출이 남았다. 게임 자동 착용 연결을 원래 상태로 복구하고 새 자산·임시 검사 도구는 Assets 밖에 보존했다.

전체 의상을 새로 생성하지 않고 기존 50개 부품·디자인·텍스처·재질을 재사용할 수 있었다. 세린 원래 몸 비율·81본 골격·갈색 헤어를 기준으로 몸통과 팔다리의 부위별 크기, 웨이트, 부츠 폭을 조절했다. 긴 겨드랑이 삼각형을 정리하고 소매 및 부츠·쇼츠 안감을 보완했으며 장갑의 노출 손가락을 유지했다.

하지만 전체 배율과 자동 표면 피팅만으로 완성할 수는 없었다. 다음 제작에서는 실제 Unity 측·후면을 기준으로 겨드랑이 봉제선, 옆구리·허리 절개, 쇼츠 윗단의 메시와 경계 루프를 국소적으로 다시 제작해야 한다. 몸 가림 면만 조정하는 방법은 R10에서 해결책이 아니었다. 새 전체 의상 생성보다 이 국소 재제작을 우선할 근거가 생겼다.

## 검증 구분

- DCC/FBX: 50부품·81본·84,562정점. 독립 왕복 검사에서 부품·웨이트·UV 전달 일치, 기본·조준·무릎·회전의 수치적 변형 무결성 확인.
- Unity: 동일 카메라 T 자세 3면 및 실제 Humanoid 클립 idle/aim/walk/run 정·측면 검사. 기존 메시 갱신의 GPU 오류는 새 메시 자산으로 해결했으나 시각적 관통·거친 경계가 남아 불합격.
- 에델 회귀: 기존 S4 ON/OFF/파괴 시 원본 몸 복원, 헤어 메시·재질 불변 통과. 첫 검사의 복제 이름 `(Clone)` 오류를 보조 도구에서 수정한 뒤 재검사했다.
- 복구: 원래 선택기와 보호 자산 해시 일치. 복구 후 새로 촬영한 세린 3면 PNG가 작업 전 PNG와 바이트 단위 동일하다. 이전 이미지를 복제한 것이 아니다.
- 이번 시험에서 Play는 시작하지 않았다. 실제 인벤토리 착탈·전투·헤어 물리·성능·빌드 검증을 통과했다고 주장하지 않는다.

## 보존 위치와 이미지 의미

최신 DCC/FBX는 `outputs/handoffs/2026-11-03/Serin_S4_Refit/r9/`다. R10은 같은 형상에서 몸 가림만 복원한 `staging/coverage_r10.json`이다. Unity 시험 자산·연결·임시 도구는 이 기록의 `integration_snapshot/Assets/Escape/`에 보존했으며 현재 Unity Assets에서 자동 적용하지 않는다.

`after_unity_*`는 **불합격 시험 화면**, `after_restored_unity_*`는 **원래 외형 복구 확인 화면**, `after_r9_*`는 **DCC 시험 렌더**다. DCC 렌더를 게임 완성 화면으로 대체하지 않는다. 독립 판정은 `staging/review/R10_FINAL_DISPOSITION_REVIEW.md`다.
