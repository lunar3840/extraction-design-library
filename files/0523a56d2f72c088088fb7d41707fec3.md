## 4. 발견한 Editor 증빙 시계 문제

최종 제한 로그 조회에서 ArgumentOutOfRangeException(now)을 발견해 root에 알렸다. 마지막64KiB에서 해당 예외101건을 관찰했고 stack은 LootState.Advance:111 ← LootInteractor.Update:121이다.

소스에서 원인도 교차 확인했다. 기존 route의 loot_revealed 및 새 RevealInteractiveLoot가 State.Advance(Time.timeAsDouble+120)로 테스트 시계를 미래로 보낸다. 이후 production LootInteractor.Update는 실제 now를 전달하므로 now<clock 보호 규칙에 걸린다. 이번 색상4파일이나 production clock 규칙의 회귀가 아닌 **Editor 증빙 helper의 시간 전진 방식 문제**다. 미수색 분기/거래 로직 보존과 구별한다.

기존 이미지는 실제 표시 증빙으로 보존하지만, 이를 오류 없는 실행이라고 주장하지 않는다. root가 Editor helper만 자연 수색 대기+현재 시각 Advance로 보완했으며 최종 focused 결과는6절에 기록한다. production 시간 규칙 완화나 앱 재시작으로 우회하지 않았다.

## 6. 최종 footer 제거·자연 수색 focused 재검증

사용자의 후속 지시에 따라 공용 hover의 클릭/드래그 안내 footer를 제거했다. source_before_footer/source_after_footer diff를 직접 읽었고, 안내 label·구분선·높이 계산3부분만 바뀌었다. 카드 높이는 마지막 실제 본문/아이콘/상태 하단+14logical padding으로 계산한다. hint 등록·실제 click/drag·가격·상태·본문·티어 색은 유지된다. footer-preservation-audit도 다른3파일 및 입력 등록 보존을 기록한다. footer_runtime_compile.txt는 오류0/기존경고21이다.

다음 최종 실제 PNG3장을 직접 확인했다.

- `after_footer_shop_food_hover_1920x1080.png`: 녹색 식품 카드에서 안내/구분선/하단 빈 공간이 함께 없어져 높이가 줄었다. 가치V2·판매가100·수량1·설명과 녹색 body는 유지된다.
- `after_natural_loot_t6_hover_1920x1080.png`: 적색T6 카드에 가치V1·판매가90·20개·관통T6·설명은 남고 footer가 없다. 카드 밖 잘림이나 새 텍스트 중첩이 없다.
- `after_natural_loot_t3_hover_1920x1080.png`: 청색T3로 올바르게 바뀌며 가치V1·판매가12·20개·관통T3·본문이 남고 footer는 없다. 같은 시각의 원본 interactive_20261021T232734556 PNG로도 확인했다.

새 임시 프로필 `input-5fd6952482d646679c392d5c9575947f`의 두 loot state는8항목 모두 Completed이고 탄약6종은각20개, 의료/배낭각1개다. 각각 실제 T6/T3 후보 UID와 화면이 맞으며 simulatedInputActive=False다. Editor helper 소스에서도 미래+120 호출이 사라졌고 실제 현재 시각 Advance 및 자연 PlayerLoop 대기로 바뀐 것을 확인했다. Production LootState의 단조 증가 보호 규칙은 그대로다.

자연 수색 focused 로그는 `natural-loot-focused-log-audit.json`의 정확한 원본 byte 범위1119404030~1120249634, 총845604bytes를 근거로 한다. 저장된 원본 slice의 실제 크기845604와 SHA256이 audit의 savedExactBytes/savedExactSha256과 일치함을 독립 확인했다. 처음의 개행 정규화 사본은 `_normalized.txt`로 따로 보존했으며 최종 원본 slice와 혼동하지 않았다.

- 전체 focused 구간 audit: truncated=False, argumentOutOfRangeNow0, compilerErrors0, thrownExceptionHeaders[].
- Exception 문자열34회는 System.Exception& 같은 메서드 매개변수 텍스트이며 throw된 예외 header와 구분했다.
- 검토자가 제한해 읽은 저장 로그 마지막64KiB에서도 now/일반 throw header/컴파일 문제 줄0이다.
- 기존 Particle Velocity 문구14287회는 남아 있다. 따라서 전체 게임 로그가 깨끗하다고 주장하지 않으며, 새로 발견한 증빙 시계 예외가 재현되지 않은 것으로 판정한다.

기존 전후34장 route는 최초색상 작업 증빙이며, 최종 footer/시계 보완은 위 focused3장과 새 로그로 확인했다. 최종 source 상태에서34장 전체를 다시 수집했다고 확대하지 않았다.
