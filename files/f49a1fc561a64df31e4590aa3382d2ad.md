# Stage A v0.2 Unity blockout

Unity 6000.1.0f1에서 생성 및 컴파일한 1m 실척 블록아웃입니다.

- `StageAMapV02_Blockout.unitypackage`: Unity 프로젝트에 Import Package로 가져옵니다.
- `StageA_SurfaceScavenger_Blockout_v02.unity`: 생성된 씬 원본입니다. 패키지 사용을 권장합니다.
- `StageAMapGenerator.cs`: 메뉴 `Extraction > Stage A v0.2 > Generate, Validate and Export`에서 전체를 재생성합니다.
- `StageA_Placement_v02.json`: 스폰·탈출·순찰·랜드마크·지하 좌표의 엔진 배치 데이터입니다.
- `NAVMESH_VALIDATION.*`: 실제 생성 지오메트리에 대한 경로 계산 결과입니다.

좌표는 Unity `(X,Y,Z)=(mapX-260,height,200-mapY)`이며 북쪽은 +Z, 1 unit=1m입니다. 인간형 H1~H3 메타데이터의 `exitsMap`은 모두 false입니다. 인간 유닛은 범위 안을 수색/순찰하며 플레이어 탈출구를 이용하지 않습니다.

이 자료는 지오메트리와 보행 가능성 검증용 블록아웃입니다. 실제 적 AI, 전투, 스폰 경제, 보스 회전반경, 루팅 시간은 구현하거나 플레이테스트한 결과가 아닙니다.
