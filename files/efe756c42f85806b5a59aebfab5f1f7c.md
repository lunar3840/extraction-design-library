# 비건물 환경 후보 전달

## 적용 입력

- 원본 현재 프리팹 SHA-256: `5fc764297b5d8b6fe470f984d2e9da26c546253ad35564bf4a2daaff99275aff`
- 현재 Unity 읽기 전용 스냅샷: `OUTDOOR_LIVE_002.json` (8,588 활성 renderer, 1,925 collider, 2,710 unique mesh)
- 최종 Blender 원본과 7 FBX: `export/live_004/StageA_Outdoor_Authored.blend`, 같은 폴더의 root별 FBX
- 제작 계약: `export/live_004/OUTDOOR_EXPORT_MANIFEST.json`
- 독립 재반입·전수 coverage·국소 돌출 검증: 같은 폴더의 `ROUNDTRIP_VALIDATION.json`, `COVERAGE_VALIDATION.json`, `DETAIL_MARGIN_VALIDATION.json` (각 PASS)
- Unity 후보 배치 staging: `StageAOutdoorApply.cs`, 공개 `Escape.EditorTools.StageAOutdoorApply.ApplyCandidate()`

## 적용 경계

후보 적용은 현재 활성 비건물 visual 571개 중 563개를 동일한 material asset GUID/local file ID로 재배치하고, 외부 제작 차량 8개를 원래 renderer 상태로 유지하도록 설계했다. 7개 기존 root의 GameObject·Collider·LOD·스크립트·원본 자산은 보존한다. 신규 root는 맵 직계 `BlenderExpansion_Outdoor_{sourceRootName}`이고, 기존 563개 `MeshRenderer.enabled`만 exact `rendererKey` allowlist로 끈다. 새 FBX는 시각 전용이며 신규 collider는 0개여야 한다. 현재 571개 원본 renderer의 LODGroup 소속은 모두 비어 있다.

신규 detail 237 renderer/577 feature 중 12개가 대응 원본 renderer AABB에서 0.005m 이상 돌출한다. 최대값은 0.050000012m이며 도로 턱·배수·야드 apron trim의 두께를 유지하는 시각 영역이다. 적용 helper는 manifest SHA가 일치하는 별도 margin PASS 보고서를 요구하고 Unity import 뒤 실제 detail bounds도 0.055m 허용값 이내로 확인한다. 충돌 판정은 원본 collider를 유지하므로 신규 detail에 물리를 붙이지 않는다. 실제 출입문·전리품·스폰·엄폐·시야 동선은 건물과 통합한 Unity 후보 검증에서 확인해야 한다.

`ApplyCandidate()`는 원본 씬과 프리팹을 저장하지 않고 `candidate_outdoor.unity`와 `APPLY.json`을 별도로 만든다. 시작 전 스크린샷 완료 표식·원본 저장 파일 SHA·Blender 출력 SHA를 확인하며, 실패하면 자신이 만든 root·asset·renderer flag만 되돌린다. 기존 건물 후보 상태는 변경하지 않는다. 첫 Unity 적용 시도는 회전된 원본 mesh의 저장 AABB 모서리 변환이 실제 정점 AABB보다 약 6cm 넓게 나오는 비교 방식 때문에 중단되고 rollback되었다. 정점 전체를 읽는 정확 bounds 검사로 교정한 두 번째 시도는 Unity에서 완료되어 7 root/800 새 renderer와 기존 563 renderer 억제가 확인됐다.

이후 FBX importer의 material slot 순서가 실제 submesh 순서와 다를 수 있어 공개 `RebindMaterials()` staging을 추가했다. 원본 FBX/manifest는 유지하고 새 FBX importer의 재질 이름을 원본 GUID/local ID 또는 기존 DETAIL 재질에 remap한 뒤, imported model prefab의 실제 슬롯 순서를 후보 800 renderer에 적용한다. Unity 실제 실행은 **COMPLETE**였으며 7 FBX의 55개 material name remap, 800 후보 renderer, 원래 563 disabled/8 preserved flag·충돌·GameObject 및 원본 scene/prefab SHA 불변을 [`MATERIAL_REBIND_REPORT.json`](MATERIAL_REBIND_REPORT.json)에 기록했다. [`candidate_outdoor_rebound.unity`](candidate_outdoor_rebound.unity)는 이전 후보를 덮지 않는 별도 사본이다. 새 시각 결과 촬영과 Play 검증은 계속 진행 중이다.
