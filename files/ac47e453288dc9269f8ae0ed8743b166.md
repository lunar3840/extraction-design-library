# A맵 v0.3 중앙 중정비동 이미지 도면

상태: 1차 이미지 도면 제작 및 육안 확인 완료. 날짜: 2026-09-11.

## 사용자 지시 요약
중앙에 대표 랜드마크가 필요하다. 환승역의 컨셉 적합성을 재검토하고 중정비동의 원래 용도 설명 후, 먼저 이미지 도면으로 보여 달라고 요청했다. 이번 턴에는 Unity 테스트를 하지 않는다.

## 기획 의도와 변경 전 문제
v0.2는 중앙 고가치 집중을 피하려다 중앙의 대표 랜드마크 자체가 사라졌다. 환승역 제안은 맵의 기능적 배경과 연결 근거가 약했다. v0.3에서는 도시 기반시설 작업장비의 옛 정비소라는 일관된 산업 외곽 컨셉을 검토한다.

## 변경 내용과 방식
중앙에 높은 크레인 정비 홀을 가진 중정비동을 배치하고 실내 확대도를 제공한다. 외곽에는 의료/전력/정밀부품 목적지를 나눠 중앙이 모든 보상과 이동을 독점하지 않게 한다. 중앙 북·남측 우회와 외곽 순환을 유지한다. 인간은 상주하거나 철수하지 않고 제한 범위 안에서 탐험·수색한다. 플레이어 진입12/탈출7과 누적 진입풀을 유지한다.

메인이 IMAGE_BRIEF.md의 공간·동선 설계를 작성하고 기존 Sol high 도면 담당에게 built-in image generation을 맡긴다. 메인이 최종 생성 이미지를 직접 확인한다. 새 이미지 산출물만 추가하며 기존 Unity/Blender/게임 씬은 변경하거나 테스트하지 않는다. 모델 설정을 전환했다는 주장은 하지 않는다.

## 전후 증빙
- before_overview.png: 작업 착수 전 v0.2 원본 PNG를 복사해 보존. 실제 기존 도면 이미지이며 게임 화면 캡처가 아니다.
- after_overview.png: 메인이 열어 확인한 최종 PNG를 복사하여 보존했다. 1536×1024.
두 이미지는 북쪽 위 전체 구조의 기획 비교용이다. 새 컨셉 이미지이므로 같은 카메라/같은 배율의 게임 스크린샷 비교가 아니다. 사후 이미지를 전 이미지로 가장하지 않는다.

## 검증 범위와 기대 효과
중앙 랜드마크와 실내, 우회길, 외곽 보상 목적지, 인간 순찰/플레이어 탈출의 구분을 육안 확인한다. 정밀 치수·실제 충돌·보행·전투를 검증한 도면이라고 주장하지 않는다. 설계 검토를 받은 후 필요한 물리 배치와 동선 검증을 진행할 자료다.

## 최종 이미지 확인 결과
메인이 PNG를 직접 열어 중앙 중정비동, 크레인/피트/부품실/전장실 및 상부통로 확대도, 중앙 북남측 우회, 주변 목적지와 H1/H2/H3 내부 수색선, M1/M2/M3를 확인했다. P01~P12/E01~E07는 각 한 번씩 표시되며 인간 수색선이 플레이어 탈출구로 연결되지 않는다. 생성 담당은 최초 이미지의 P/E 번호 중복을 한 차례 이미지 수정으로 바로잡았다.

한계: 진입 번호의 실제 지리 배치는 이전 저위험 서남부 중심 등급 배치와 동일하지 않으며, 장비 등급에 따른 상세 위치는 다음 설계에서 재배치해야 한다. 이미지의 80×56m는 가정 치수이며 픽셀 비율을 실측 치수로 환산하지 않는다. 이 결과는 중앙 랜드마크 컨셉과 전체 공간 구성을 먼저 논의할 시각 초안이며 누적 스폰 시스템을 구현하거나 난이도별 안전 진입을 검증한 결과가 아니다. 새로운 Unity/Blender 테스트는 수행하지 않았다.
