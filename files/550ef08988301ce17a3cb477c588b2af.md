# 동료 칩 슬롯 가로 폭 축소

## 사용자 지시와 의도
- 칩 슬롯이 캐릭터를 가리므로 가로 폭을 줄인다.
- 기존 장착·해제 및 출격 중 잠금 규칙은 유지한다. 캐릭터 모델과 다른 장비 UI는 변경하지 않는다.

## 변경 전 상태와 증빙 출처
- 기존 슬롯은 가상 화면 좌표 `(330,114,238,70)`이며 캐릭터 초상화 영역의 오른쪽 100px와 겹쳤다.
- 변경 직전에 직전 작업의 실제 게임 캡처 `companion-chip-equipment/after_inventory_serin.png`, `after_inventory_prototype.png`를 이 폴더의 `before_inventory_serin.png`, `before_inventory_prototype.png`로 보관했다.
- 해당 캡처 이후 이 변경 전까지 슬롯 소스는 동일했으며, 사후 이미지를 전 이미지로 재구성하지 않았다.
- 변경 전 소스: `InventoryCompanionChips.before.cs.txt`.

## 실제 변경
- 슬롯을 오른쪽 방어구 열의 위치·너비에 맞춘 `(446,114,122,70)`으로 변경했다. 오른쪽 끝 568과 높이는 유지했다.
- 초상화 오른쪽 끝 430과 슬롯 사이에 16px 간격을 확보했다.
- 표시 문구를 `동료 칩`, 동료 이름/`미장착`, `선택 / 해제` 또는 `출격 중 잠금`으로 줄였다.
- 선택창 크기와 장착·해제 로직은 유지한다. 선택창은 새 슬롯의 왼쪽에 정렬되므로 캐릭터가 아닌 물자 패널 일부 위에 열린다.

## 주요 수정 파일
- `C:/UnityProject/escape/Assets/Escape/Runtime/Inventory/InventoryCompanionChips.cs`
- 검증용 복사본의 동일 소스 및 캡처 경로만 갱신했다. 사용자 저장 슬롯과 실행 중인 메인 씬을 조작하지 않는다.

## 검증 상태
- 독립 레이아웃 검토: 캐릭터와 16px 간격, 헬멧과 14px 간격, 102px 내부 폭에 현재 이름과 짧은 문구가 들어감을 확인.
- Unity 6000.1.0f1의 별도 검증 프로젝트 Windows 빌드 성공: `build.log`의 `Build Finished, Result: Success.`.
- 기존 동료 칩 검사 42개 통과: `chip_checks.txt`. 이번 작업에서는 전체 인벤토리·모델 검사를 다시 실행한 것으로 주장하지 않는다.
- 실제 게임 화면에서 세린·테스트 동료·미장착 모두 슬롯 글자가 잘리지 않고 캐릭터와 겹치지 않음을 확인했다.
- 자동 실행 확인: 장착·해제, 미장착 출격 차단, 지상에서 UI/월드/세션 경로의 교체·해제 차단 통과: `runtime_complete.txt`. 실행 오류 파일은 생성되지 않았다.
- 실제 마우스로 축소된 슬롯을 열고 선택창 오른쪽의 세린 행을 눌러 외형 변경을 확인했다. 다시 열어 가방 탄약 슬롯 바로 위의 해제 버튼을 눌러 미장착 전환을 확인했다. 뒤쪽 아이템의 선택/드래그나 상세 창 열림은 발생하지 않았다.
- 검증본과 메인 프로젝트의 수정 소스 SHA-256 일치: `144C6569CF640C92D1C6BEEC1D6805C7D96435AE55C9CA7BCD49CFBB4AA179D9`.
- 실행 중인 메인 Unity 씬/Play 상태 및 사용자 저장 데이터는 변경하지 않았다. 자체 검증 실행본은 확인 후 종료했다.
