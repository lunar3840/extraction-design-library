# 익스트랙션 프로젝트 지침 동기화

- 작업 일시: 2026-09-11
- 사용자 지시 요약: 실제 Unity 프로젝트와 기존 작업 탭에도 작업 전후 스크린샷 및 기획 기록 지침이 확실히 적용되도록 동기화한다.
- 기획 의도: 관리 폴더에만 존재하던 규칙을 실제 Unity 소스 경로에도 배포하고, 기존에 열린 작업 탭이 이전 지침 상태를 유지하는 문제를 줄인다.
- 변경 전 상태 및 문제점:
  - `C:\UnityProject\escape\AGENTS.md`가 존재하지 않았다.
  - `C:\UnityProject\escape\Assets\Escape\AGENTS.md`에는 캐릭터 헤어·헬멧 지침만 있고 작업 기록 지침은 없었다.
  - Unity 프로젝트는 Git 저장소로 인식되지 않아, 하위 폴더에서 시작한 작업이 상위 경로의 지침을 자동으로 탐색한다고 보장할 수 없었다.
  - 최근 작업이 있었던 기존 탭 중 일부는 관리 폴더의 갱신된 `AGENTS.md`를 읽지 못한 상태였다.
- 변경한 부분:
  - Unity 프로젝트 루트에 공통 `AGENTS.md`를 생성했다.
  - `Assets/Escape/AGENTS.md`에도 동일한 작업 전후 증빙 규칙과 절대 저장 경로를 추가했다.
  - 최근 변경과 관련된 UI, 캐릭터, 의료, 커서 작업 탭 네 곳에 최신 지침을 직접 다시 읽도록 동기화 메시지를 전달했다.
- 변경 방식:
  - 루트와 하위 경로 어느 위치에서 작업을 시작하더라도 규칙을 확인할 수 있도록 두 위치에 명시했다.
  - 모든 결과가 한곳에 모이도록 기록 경로를 `C:\Users\ehoji\OneDrive\문서\ChatGPT\익스트랙션\outputs\change_records\YYYY-MM-DD\<작업명>\`의 절대 경로로 고정했다.
  - 기존 탭에는 이번 동기화 과정에서 프로젝트 파일을 수정하지 말고, 다음 변경부터 새 지침을 적용하도록 전달했다.
- 기대 효과:
  - 앞으로 관리 폴더 또는 실제 Unity 프로젝트에서 시작하는 변경 작업 모두 전후 스크린샷과 기획 기록을 같은 위치에 남긴다.
  - 오래 열린 주요 작업 탭도 다음 변경 지시 전에 최신 규칙을 다시 확인한다.
- 확인 결과:
  - 두 Unity 지침 파일을 다시 읽어 기록 규칙과 저장 경로가 포함된 것을 확인했다.
  - UI, 캐릭터, 의료, 커서 작업 탭 네 곳의 동기화 전송 및 완료 상태를 확인했다.
  - `before_configuration.png`와 `after_configuration.png`를 열어 내용과 가독성을 확인했다.
- 수정한 주요 파일/에셋:
  - `C:\UnityProject\escape\AGENTS.md`
  - `C:\UnityProject\escape\Assets\Escape\AGENTS.md`
  - 이 작업 기록 폴더의 PNG 증빙 및 `CHANGE_RECORD.md`
