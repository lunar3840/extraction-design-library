# V34 HALL 독립 검증 기록

## 검증 범위와 기준

- 현행 D10 건물·D11 야외가 반영된 A맵을 기준으로, 변경 전 HALL 남측·서측·실내·계단 화면과 실제 Play 화면 및 scene/prefab 백업을 확인했다.
- `V34_D11_ORIGINAL_SNAPSHOT.json`에는 변경 전 원본 32,381개 오브젝트의 구조·컴포넌트·메시·충돌·직렬화 설정·재질 결합, 원본 재질 파일 544개, 기존 Light/Volume 4개와 전역 렌더 설정 서명이 있다.
- 허용 범위는 HALL 1F FactorySurface 45개의 새 전용 재질 연결, D11 SurfaceTiles 16개의 새 전용 도로 재질 연결, HALL 남·서 출입구의 무충돌 시각 디테일, `V34_Lighting`의 원본 지붕·2F 바닥 일치 그림자 전용 복제본과 국소 조명이다. 원본 지형·도로·건물 구조·충돌·출입·스폰·탈출·가시성 설정 변경은 허용하지 않는다.
- 시각 품질 판정과 기술적 보존 판정은 별개다. 기술 검사가 통과해도 대응 화면에서 깊이·가독성·주변 영향이 확인되지 않으면 승인하지 않는다.

## 후보 01 직접 검토: 불합격

- `candidate01_hall_south.png`, `candidate01_hall_west.png`, `candidate01_hall_inside.png`, `candidate01_hall_stairs.png`를 동일 시점의 `before_hall_*.png`와 비교했다.
- 남·서 접근 지면뿐 아니라 화면에 보이는 주변 도로 전체가 선명한 마젠타로 렌더링된다. 현재 후보는 사용자에게 제시하거나 저장할 수 있는 시각 품질이 아니다.
- Unity Editor.log에는 `V34HallApproachPavement.shader`의 `V34RectWeight(float2 point, ...)` 인근에서 HLSL `point` 토큰 구문 오류와 후속 `min` 오류가 기록돼 있다. 표면 담당과 메인 에이전트에 정확한 위치를 전달했다.
- 실내에 국소 그림자 깊이는 생겼으나 계단과 작업 장비의 명암이 변경 전보다 크게 어둡다. 셰이더 복구 후 실제 게임 카메라에서 출입구·계단·작업 구역 가독성을 다시 평가해야 한다.
- 본 후보 단계에서는 독립 기술 검증·실제 Play·저장 후 재로드 결과가 없었으므로 최종 판정으로 대체하지 않았다.

## 후보 비교 시 확인 기준

- 동일 실제 게임 카메라 전후 8쌍에서 마젠타 0, HALL 외 지역 원래 색 유지, 실내 동선과 장비 가독성, 남·서 문폭과 계단 시야 유지.
- `StageAReferenceV34Validation.Validate` 결과의 원본 보존·허용 신규 범위·무충돌·shadow-only 정확 일치·원본 재질 불변·V34 셰이더 오류 0.
- 실제 PlayerMotor Play의 HALL 출입·cutaway/복원, 전체 원래 102개 문과 204개 방향 차선, 저장 후 재로드 상태. 기존 D09 검사에는 계단 횡단이 포함되지 않으므로 별도 실행 없이는 이를 통과했다고 주장하지 않는다.
- B4/R8은 기존 간격 약 62m와 R8 비활성을 유지했는지 확인한다. 이 시각 작업으로 독립 위험 진입 경험이 해결됐다고 판정하지 않는다.

## 후보 02 실제 게임 카메라 비교: 추가 보정 요청

- `candidate02_play_south_yard.png`와 `before_play_south_yard.png`의 동일 시점에서 마젠타는 해소됐다. 그러나 HALL 접근 도로는 원래 D11의 깨진 블록·흙 가장자리 대비가 크게 줄고 회색 판처럼 읽힌다. 범위 외 도로 색은 수학적으로 원본 shader 결과가 유지되어야 하며, HALL 국소 보정은 더 약하게 해야 한다.
- `candidate02_play_hall_1f.png`, `candidate02_play_stairs.png`, `candidate02_play_hall_2f.png`에서는 지붕/창의 그림자로 구조 깊이가 생겼다. 동시에 바닥과 계단의 명암이 전보다 상당히 낮아져 기존 장비·문선·계단이 덜 읽힌다. 국소 조명과 shadow-only 복제본 균형을 재조정한 뒤 재촬영이 필요하다.
- 새 금속 프레임은 기존 출입구 윤곽에 붙으며 위 화면만으로 문폭/이동 가능성을 침해했다고 보이지 않는다. 통과 판정은 실제 PlayerMotor 동선 확인 뒤 내린다.

## 후보 04 기술 검증과 Play 대응화면

- `VALIDATION_candidate04.txt`를 직접 읽었다. 15개 항목 통과, 실패 0이다. 현재 D11 원본 오브젝트 32,381개의 구조·메시·충돌·직렬화 필드 변경 0, HALL 바닥 45개와 D11 SurfaceTiles 16개 외 재질 재할당 0, 신규 V34 오브젝트 109개·신규 콜라이더 0, 원본 재질 파일 544개 변경 0, 기존 Light/Volume 및 전역 렌더 설정 변경 0이다.
- `V34_Lighting`에는 신규 renderer 94개와 Light 12개가 있다. 지붕/2F 구조 원본 81개에 대한 shadow-only 복제본 81개가 메시·재질·월드 행렬에서 1:1 일치한다. V34 전용 재질 5개의 shader 오류는 0이다.
- 실제 게임 카메라 `candidate04_play_south_yard.png`에서는 후보02의 회색 판 느낌이 줄고 원래 D11의 깨진 블록·흙/포장 대비가 상당히 회복됐다. 동일 카메라의 `before_play_south_yard.png`와 비교했다.
- `candidate04_play_hall_1f.png`, `candidate04_play_stairs.png`, `candidate04_play_work_area.png`, `candidate04_play_hall_2f.png`는 각 `before_play_*.png`와 비교했다. 창·상층 슬랩 그림자로 깊이가 늘고 1F 작업 구역의 기계/통로는 다시 읽힌다. 2F는 이전보다 어두운 분위기지만 창 그림자 패턴과 바닥 이동 영역은 보인다.
- 실제 게임 카메라의 8개 동일 위치 전후 화면을 기준으로 후보04의 대표 HALL 시각 결과를 합격 판정한다. 1F 출입·작업 장비·계단과 2F 창/바닥 이동 영역이 읽히며, 국소 그림자가 기존의 균일한 바닥보다 구조 깊이를 준다. 2F는 이전보다 어둡지만 동선 가독성을 잃은 수준은 아니다.
- Editor 남·서·실내·계단 화면은 Preview 상태의 차이가 있어서 정확한 1:1 시각 수락 근거로 사용하지 않는다. 동일 카메라의 `before_play_*.png`와 `candidate04_play_*.png` 8쌍을 주근거로 삼는다.
- `west_entry` Play 화면은 서측 포털보다 포털 앞 풀밭·램프 상단을 보여 주어 서측 새 금속 프레임 자체의 외관 품질을 직접 판정하지 못한다. `remote_control` 전후는 사실상 동일해 작업 범위 밖 보존 근거다. 서측 프레임을 독립된 시각 성과로 주장하려면 근접 대응 화면을 별도로 남긴다.
- 기술·시각 합격과 별도로 전체 문 PlayerMotor 통과와 층별 초기 위치/가시성 검사, 저장 후 재로드 검사를 읽은 뒤 통합 최종 승인한다.

## 저장 후 재로드 확인

- 메인이 후보04를 scene/prefab으로 저장하고 A scene을 다시 연 뒤 생성한 `VALIDATION_reloaded.txt`를 직접 읽었다. 15 PASS, 0 FAIL로 저장 전 후보04와 동일하다.
- 원본 32,381개 구조·게임플레이 필드 불변, 허용 재질 61개, V34 신규 109개·신규 Collider 0, shadow-only 81/81 정확 일치, V34 shader 오류 0, 기존 재질 파일·기존 Light/Volume·전역 렌더 설정 불변이 재로드 후에도 유지된다.
- 저장·재로드 후 `after_PLAY.txt`와 실제 게임 카메라 `after_play_*.png` 8장을 확인했다. 동일 위치의 후보04 화면과 일치하고, 층별 표시 및 지역 톤매핑 연속성 검사도 PASS다.

## 저장 후 실제 문 동선 및 최종 독립 판정

- `play_attempt_01/D09_PLAY_VALIDATION.txt` 최종 결과는 `passed=204 failed=0 originalDoorLanes=204 buildings=69`, `RESULT PASS`다. 변경 전부터 있던 문 102개의 안팎 양방향을 켜진 `CharacterController`와 `PlayerMotor.Simulate`로 이동했다. 전투만 결정적인 동선 검사를 위해 중단했으며 물리 키보드·마우스 조작 시험은 아니다.
- HALL 외부 남·북과 내부 1F·2F 세 위치의 지붕/가시성 전환, B1–B4 기본 스폰 중 B3 선택 및 R8 등 위험 진입점의 계속된 제외를 확인했다. HALL 서측 문을 포함한 원래 문 양방향 동선도 204개 결과에 포함된다.
- D09 테스트의 층별 HALL 가시성은 각 층의 **초기 위치에 캐릭터를 배치**하여 확인한 것이다. 실제 계단을 따라 1F↔2F를 횡단하는 테스트는 이번 결과에 없다. 새 충돌체 0개와 원본 충돌/구조 서명 불변은 계단을 막는 신규 변경이 없다는 기술적 근거이지, 실제 층간 횡단 완료 증거는 아니다.
- 독립 판정: **기술 보존 및 이번 HALL 대표 구역의 시각 개선은 합격.** 원본 32,381개 상태의 무단 변화 0, 저장 후 검증 15/15, 실제 원래 문 204방향 204/204 통과, 8쌍 Play 화면의 개선과 비대상 지역 보존을 함께 근거로 한다.
- 품질 한계: 2F는 변경 전보다 어두워졌고 바닥·창 그림자는 읽히지만 밝은 작업 시인성까지 완성한 상태는 아니다. 서측 금속 프레임은 Play 대응 화면에서 크기가 작고 카메라가 주로 램프/풀밭을 비춰, 근접 외관 품질을 독립 판정할 증빙이 부족하다. 전체 A맵을 GF2급으로 완성했다는 판정이 아니라 **HALL과 연결된 접근부에 대한 작은 시범 개선**만 수락한 것이다. 계단 실제 층간 횡단 및 성능 벤치마크도 이번 판정 범위 밖이다.
