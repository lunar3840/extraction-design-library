# D10 국소 표면 손상 제작 계획

2026-10-14. 소유 범위: `blender/build_surface_details.py` 및 이 문서. Unity 프로젝트·씬·충돌·내비게이션·원본 D09 에셋은 이 제작 작업에서 수정하지 않는다. 메인이 이미 확보한 작업 전 화면을 기준으로 통합 전후 증빙을 관리한다.

## 의도와 근거

승인된 `outputs/concept_art/2026-10-12/a-map-building-identities-v01/BUILDING_DESIGN.md` 및 비교 시트 3장의 v02를 읽고 확인했다. D09는 용도별 부피를 구분했지만 벽 박락이 얇은 단색 다각형이고 같은 위치·크기의 표식이 반복된다. D10은 마모가 생기는 접합부와 재료층을 실제 작은 입체 메시로 읽히게 한다. 전체를 균등하게 오염시키거나 지면 소품을 추가하는 작업이 아니다.

## 실측·안전 제한

- `all_r04/D09_ARCHITECTURE.json`의 실제 외측 Shell 삼각형 평면과 실제 Window 메시 범위를 읽는다. 명목상 풋프린트만으로 떠 있는 표면을 만들지 않는다.
- 벽면 효과는 원래 닫힌 외측 면이 확인되는 위치에만 배치한다. 실제 문과 창 범위에 여유를 두고 피해 가며 지면 잔해나 장애물은 추가하지 않는다.
- 새 표면 메시의 충돌은 모두 끈다. 벽 외측 돌출은 0.12m 안으로 제한하며 건물당 재료/효과별로 묶는다.
- HALL 원본 V13 외벽은 조사 자료에 renderer bounds만 있어서 닫힌 실제 면을 보증하기 어렵다. 이 경우 원본 외벽 박락을 추정 생성하지 않고 실제 D09 포털/레일 면의 작은 국소 부속만 만든다.
- 기존 `D09_FacadePart_Detail_LocalizedPlasterScarsAndRainRuns`는 exact-name replacement로 교체한다. 수문군의 기존 `D09_FacadePart_Detail_Waterworks_InterruptedHistoricWaterline`도 exact-name replacement로 갱신한다. 나머지는 additive다.
- A 담당의 생활 폐허 주벽 상단·지붕과 차고 지붕을 수정하지 않는다. B4/R8 진입점·스폰·동선과 출입구 유효폭은 변경하지 않는다.

## 전달·확인

Blender Python으로도 실행할 수 있는 메시 제작 스크립트가 Unity-local Y-up JSON 패치를 출력한다. `--check-only`는 파일을 쓰지 않고 69동 범위, 삼각형·UV 유효성, no-collider, exact replacement 대상, 실측 문/창 회피 및 입체 깊이 제한을 검사한다. 실제 Unity 적용·전후 화면·플레이 확인은 메인의 통합 검증 대상이며 이 문서만으로 런타임 통과를 주장하지 않는다.

2026-10-14 드라이 생성 검사 통과: 69/69동, 298개 묶음 메시, 163,360삼각형, 충돌 메시 0, 추가 재질 0. HALL은 실제 금속 면에만 156삼각형/3개 접합부를 더하며, 나머지 68동은 실측 Shell 위의 입체 손상 패치가 모두 있다. 건물군별 삼각형 수는 HALL 156, 의료 9,072, 전력 17,772, 물류 12,254, 공방 29,470, 차고 9,262, 관리 19,636, 폐허 43,390, 제어 7,304, 수문 15,044다.

메인 실행 예시(Blender 실행은 메인 소유):

```text
Blender --background --python R/blender/build_surface_details.py -- --out R/blender/surfaces_v01/D10_SURFACE_DETAILS.json --blend R/blender/surfaces_v01/D10_SurfaceDetails.blend
```

여기서 `R`은 이 문서가 있는 D10 기록 폴더다. 출력 JSON의 REPORT에는 건물별 손상 개수와 실제 원본 면 이름·외측 평면·손상 범위·돌출 깊이 메타데이터를 기록한다. `.blend`는 실제 조사된 프레임 위치와 회전을 적용한 편집 가능한 디테일 전용 메시이므로, 외관 비교 시 D09 본체와 함께 열어야 한다.

## 후보 01 시각 검토와 수정 02

메인 및 독립 검토자가 후보 01을 시각적으로 반려했다. 담당자는 실제 `unity_attempt_01_detail_TOOLS.png`, `unity_attempt_01_detail_F01.png`, `unity_attempt_01_detail_CLINIC.png`를 읽고 문제를 확인했다. 당시 TOOLS의 박락 두 개는 L/B에 있고 문이 있는 R에는 없었으며, F01도 문이 있는 L이 비었다. S07은 다섯 개 중 네 개가 L에 몰렸다. 삼각형·동수 충족이 실제 카메라의 가독성 충족을 뜻하지 않는다는 근거다.

수정 02는 실제 `measuredDoors[0].side`의 주진입 면에 1.3–2.1m 크기의 비대칭 세로/대각 박락을 먼저 배치하고 검증에서 이를 필수로 삼는다. CLINIC은 실제 촬영에서 크게 보이는 앞 왼쪽 날개 벽에 주 박락, 뒤로 들어간 진입 중정 벽에 보조 박락을 만든다. TOOLS 등 공방은 실제 D09 `HighEaveClosure`에서 주진입 측의 외곽 닫힌 고벽을 확인할 수 있을 때만 추가 박락을 만들며, 이 부분은 원본과 동일한 Roof 분류를 써 컷어웨이를 상속한다.

여러 비슷한 크기의 임의 표식을 주 박락 하나와 종속 측면 하나(폐허는 세 군데)로 줄였다. 깨진 회반죽의 폭은 0.075–0.14m, 입술 앞쪽 깊이는 최대 0.106m로 키웠으며 줄눈·벽돌층 위의 연속된 경계가 비대칭으로 갈라진다. 창턱과 홈통의 실제 접속부에서 출발하는 물자국은 0.12–0.20m 폭의 불규칙한 부채꼴·분기 흔적으로 바꿨다. 벽에 가려지는 장식용 masonry 뒷면 삼각형만 생략해 앞면·두께 측면을 유지하면서 비용을 줄였다.

수정 02 드라이 검사: 69/69동, 298개 묶음 메시, 161,602삼각형, 충돌 0, 새 재질 0. HALL을 제외한 68동 전부 `primaryHero=true`이며 주진입 면 누락 검사가 통과했다. 실제 Unity 동일 카메라 가독성은 메인의 후속 캡처로 다시 판단한다.

## 후보 02 시각 검토와 수정 03

후보 02의 TOOLS/F01/CLINIC 상세샷에서는 손상이 읽혔지만, 각 벽돌 코스를 밝고 두꺼운 회색 테두리로 둘러 벽에 붙인 표지판처럼 보였다. 물자국도 분절된 불투명한 조각처럼 읽혔다. 메인과 독립 검토에 이를 그대로 보고하고 후보 02를 완성 통과로 처리하지 않았다.

메인 지시에 따른 수정 03은 주 박락 위치·크기를 유지하면서 전체 둘레 테두리를 없앤다. 서로 떨어진 3–5개의 짧은 깨진 모서리에만 원래 벽색의 회반죽 입술을 남겨 노출 깊이를 0.015–0.035m로 낮추고 개별 벽돌 앞면도 0.012–0.035m로 낮춘다. 밝은 회색 베젤과 깊은 벽돌 패널의 인상을 줄이는 목적이다.

물자국은 메인이 제공하는 D10 전용 `DampStain`, `RustStain` 두 재질을 쓴다. 기존 D09 재질이나 D09 코드의 재질 목록은 수정하지 않고 이 스크립트의 로컬 `Part` 서브클래스에서만 추가한다. 전용 메시 `Detail_D10_AttachmentMoistureAndOxidation`, `Detail_D10_DiscontinuousHistoricWaterline`은 두 스테인 재질만 포함한다. 불투명 재료가 섞이면 제작 검증에서 실패시킨다. 실제 Unity 통합은 전용 스테인 메시의 그림자를 끄고 새 셰이더의 부드러운 알파 가장자리·하단 페이드, ZWrite Off를 사용해야 한다.

각 누수는 연결된 하나의 얇은 리본이며 두께·불투명 중앙 띠가 없다. UV.x는 폭 방향 0–1, UV.y는 분절마다 재시작하지 않고 전체 흐름의 위 0–아래 1이다. 수문 기단의 불연속 수위 흔적도 같은 전용 스테인 메시에서 출력한다. 별도 골재·기단 칩·홈통 등 고체 메시에는 기존 13개 재료만 쓴다.

수정 03 드라이 검사: 69/69동, 298개 묶음 메시, 96,780삼각형, 충돌 0, 새 D10 전용 재질 2. HALL 제외 68동의 주진입 면 주 박락 검사와 스테인 UV 범위·재질 전용성 검사가 통과했다. Unity 렌더 시각 검토는 메인의 다음 후보를 확인한 뒤 별도로 기록한다.

## 후보 04 실제 화면 확인

표면 담당은 메인이 생성한 `unity_attempt_04_detail_TOOLS.png`, `unity_attempt_04_detail_F01.png`, `unity_attempt_04_detail_CLINIC.png`, `unity_attempt_04_S07_front.png`를 직접 확인했다. 동일 카메라의 후보 02와 비교해 두꺼운 회색 액자 및 표지판처럼 뜨는 립, 물자국의 분절된 불투명 금속 조각 인상은 제거됐다. TOOLS는 캐노피 아래 일부 하부 박락이 가려져도 상부의 실제 Roof 고벽 노출층이 화면 안에 보여 손상이 읽힌다. CLINIC의 창 아래 물때는 부드럽고 낮은 대비로 붙어 있으며, S07은 주진입 정면과 측면에 손상이 분산된다. 이 네 화면에서 새 출입구 침범이나 뜬 액자·스테인 그림자 같은 특정 퇴행은 발견하지 못했다.

아직 벽돌 코스의 규칙적인 계단식 외곽과 넓은 벽면의 단순함은 남아 있다. 따라서 이 결과는 **D09 대비 국소 손상 디테일 개선**이며 승인 콘셉트의 완전한 재현을 의미하지 않는다. 전체 69동·충돌·내비게이션·컷어웨이 검증 및 완료 전후 증빙 확인은 메인의 통합 보고를 따른다. 이 담당의 실제 시각 확인 범위는 위 네 저장 화면이다.
