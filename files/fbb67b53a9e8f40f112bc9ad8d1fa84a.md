# D15 — 반실사 서브컬처 셰이더 대표 구간 시험

## 사용자 지시와 기획

사용자는 니케·니어 오토마타를 참고하여 아포칼립스 배경과 서브컬처 캐릭터가 어울리는 셰이더 방향을 요청했고, 제안 후 “한번 시도해볼래 그럼?”으로 시험 구현을 승인했다. 두 게임의 비공개 내부 셰이더를 복제하는 작업이 아니라 표현 원칙을 참고한 독립 구현이다.

캐릭터의 원래 머리색·피부색·텍스처·UV를 보존하며 피부/헤어/의상/장비의 명암과 광택을 구분한다. 환경은 큰 면의 가독성과 재질 구분을 강화하고, 식생에는 과한 검은 외곽선이나 고비용 캐릭터 셰이딩을 적용하지 않는다. 우선 A맵 서남부 대표 구간과 플레이어에 한정하여 시험한다.

## 병렬 수행과 조율

GPT-6 Sol high에 캐릭터 표현, 환경 표현, 독립 검증/Play 촬영 도구를 분리 배정했다. 메인이 Unity 단일 조작·기준 화면 확보·통합·시각 판단을 맡는다. `현실적 그래픽 개선 요소 분석` 대화와 조율했고, 해당 대화는 이번 작업 동안 Unity 및 파일을 변경하지 않는다고 회신했다. 그 대화가 짚은 V33 가림용 셰이더의 D09 식별, V34 그림자 복제 81개, V35 실내 조명 4개, 원본 헤어 텍스처 유지 기준을 반영했다. 전역 조명/렌더러 변경은 하지 않았다.

## 실제 적용 방식과 후보 검토

- A맵 서남부 중심 (-165, -98), 반경 60m 안에서 실제 활성 렌더러 경계를 조사하여 대표 대상만 선택했다. 두 건물의 벽면 108슬롯, 풀 3개 청크에 걸친 15슬롯, 나무 6슬롯, `SW_W_SalvageCar`의 불투명 재질 1슬롯, 총 130슬롯/61렌더러다. 범위 밖 다른 건물·바닥·식생은 그대로다.
- 건물은 D09 셰이더 식별을 보존한 복제 재질에서 얼룩·빗물·거칠기 강도를 조정했다. 새 건물 형상이나 신규 노후화 텍스처를 만든 작업은 아니다. 차량은 기존 URP Lit 조명 패스를 사용하는 D15 재질로 복제하고 제한된 금속 광택을 적용했다.
- 식생은 D14의 거의 무채색에 가까운 변환 대신 절제된 원래 색을 살리는 D15 표면 처리를 적용했다. 1차 `candidate_*`의 민트색 과장은 메인/독립 검토에서 보류했다. D15 식생 복제본 21개를 따뜻한 올리브로 다시 조정해 `retuned_*`를 촬영했다. 이 한정 시험 영역과 나머지 원본 구역의 색 차이는 남는다.
- 캐릭터는 A맵 프로파일로만 활성화하며 실제 플레이어에 피부/머리/의상/장비별 부드러운 단계 명암, 광택, 빛을 받는 방향의 얇은 테두리광을 구분한다. 원본 알베도·헤어색·UV·노멀·알파 설정을 유지한다. 적에게 일괄 적용하지 않는다. 얼굴 SDF·별도 헤어 이방성 모델·바람 변형·화면 전체 외곽선은 이번에 추가하지 않았다.
- 원본 재질 자산은 수정하지 않았다. `D15_MATERIAL_REPLACEMENTS.csv`에 원본/복제 GUID, 경로, 슬롯, 원본 의존성 해시를 기록했다. 캐릭터 기존 코드 `ToonCharacterStyle.cs`만 옵트인 분기를 추가했고 기존 파일의 백업을 보관했다.

## 제한과 다음 검토 사항

- 풀 시험 청크와 원본 청크의 색 차이가 남고 실제 탑뷰에서 시험 풀이 더 밝고 차갑게 읽힌다. 맵 전체로 확장하기 전 팔레트와 경계 연결을 추가 조정해야 한다. 이 점은 미해결로 유지한다.
- 바닥 혼합 경계, 건물 형태/밀도, 모델 자체의 저폴리 표현은 이번 셰이더 시험으로 해결했다고 하지 않는다.
- 적 외형 표본은 이번 미리보기에서 0이었다. `enemyD15=0`은 실제 적 모델을 충분히 표집한 시험이 아니다. 플레이어 전용 코드 게이트만 확인했다.
- A→B→A 직후 추가 후면 컷은 첫 A 후면 컷보다 배경이 어둡고 풀의 원형 명암 차이가 보인다. 프로파일/텍스처 복귀는 확인했지만 전환 후 대기·조명까지 시각적으로 동일하게 복구된다고 주장하지 않는다. 원인이 기존 전환/정지 진단의 타이밍인지 별도 회귀인지 이 시험만으로 확정하지 않았고, 전환 시 조명 안정화는 추가 검토 항목으로 둔다.
- 프레임 시간/실기기 FPS를 측정하지 않았다. 기능 검사 PASS는 성능 보장이나 아트 방향의 사용자 승인을 의미하지 않는다.
- 니케·니어 오토마타의 비공개 셰이더를 복제한 것이 아니며, 두 게임 수준의 완성도에 도달했다고 주장하지 않는다.
