# 날짜 표시 정정 — 2026-10-23

INSTRUCTION_LEDGER.csv의 timeUTC 54행과 sources 아래 8개 TRANSCRIPT.md의 날짜 표시를 정정했다. startedAt의 초 값을 밀리초로 해석한 문제이며, 원본 JSON의 숫자 시각은 정상이다. 초 값에 1000을 곱한 UTC ISO 시각으로 바꿨다. 예: 1788521696.248 → 2026-09-04T11:34:56.248Z. 라이브러리 화면은 한국 시간의 날짜로 표시한다.

원본 숫자 시각은 수정하지 않았다. 수정 전 표시 파일은 ../local-planning-library/source_before/에 보존했다. 54개 시각을 원본과 일대일 대조했고 1970년 표시가 제거됨을 확인했다. 상세 변경 및 검증은 ../local-planning-library/CHANGE_RECORD.md와 VERIFICATION.json을 참조한다.
