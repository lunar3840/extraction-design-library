# 의료동 현실감 시범 개선 V32

## 사용자 지시와 범위

- 현실적인 그래픽 개선 분석 후 사용자가 “한번 시도해볼래?”라고 적용을 승인했다.
- 의료동(`CLINIC`)과 내부 `CORE_G1`을 대표 구역으로 선택했다. 전체 맵 확장은 이번 범위가 아니다.
- 메인이 기획·Unity 실행·통합을 맡고 GPT-6 Sol high 제작 2명(표면/조명), 독립 검증 1명으로 병렬 분담했다.
- 최신 D04 배치와 구조를 기준으로 진행했으며 다른 건물, 소품, 충돌, 진입·탈출점, 캐릭터 외형은 바꾸지 않았다.

## 변경 전 상태와 기획 의도

- 의료동 전체 바닥에 건물 크기로 확대된 콘크리트 균열·오염이 반복되고, 중앙 코어 벽은 단색 평면이었다.
- 지붕 가림은 렌더러를 끄므로 태양 그림자도 함께 사라졌다. 등기구 모델 두 개는 있지만 실제 실내 광원은 없었다.
- 인간 크기에 맞는 낡은 바닥 마감, 회벽/하부 도장 구분, 지붕이 가려져도 유지되는 음영과 기존 등기구의 국소 빛으로 공간의 용도와 깊이를 강화한다.

## 실제 변경

- `CLINIC/FactoryFloor` 1개와 `CORE_G1/Generated/Floor` 1개에 전용 바닥 재질을 연결했다. 65cm 단위 마감, 기존 에셋의 미세 표면, 작은 색·마모·거칠기 변화를 사용한다.
- `CORE_G1/Generated`의 North, South_A, South_B, East, West 5개 벽에 전용 도장 재질을 연결했다. 약 1.16m 하부 청회색 도장과 상부 회벽, 밑단 사용감을 표현한다.
- 바닥/벽은 비금속이며 원본 텍스처·재질 파일을 수정하지 않고 전용 복제 재질을 사용한다.
- 의료동 지붕 표면 2개의 그림자 전용 복사본을 `ClinicV32_RoofShadowOnly` 아래에 추가했다. 지붕 가림 계층 밖에 두어 카메라에서는 숨겨져도 햇빛 차폐는 유지된다. 새 충돌은 없다.
- 기존 CeilingLamp_A/B 아래에 하향 스포트라이트 2개를 추가했다. 강도 8, 범위 11m, 조사각 105°, 부드러운 그림자. 빛의 위치는 등기구 메시의 하단에서 8cm 아래다.
- 전역 태양·환경광·안개·노출 설정과 A/B 전환 코드는 수정하지 않았다.

## 전후 증빙과 백업

- `backup/A_saved.unity`, `backup/A.prefab`: 적용 전 저장본. `BASELINE.txt`에 해시 기록.
- `backup/materials/`: 기존 참조 재질 백업. 추가 재질 해시는 장면/프리팹이 원본과 동일하고 V32 적용 전임을 재확인한 뒤 보충했다.
- 실제 변경 전 직접 촬영했으며 재구성 전 이미지는 사용하지 않았다.
- 편집 화면 비교: `before_` / `after_` + `clinic_entrance.png`, `clinic_roof_exterior.png`, `clinic_interior.png`, `clinic_detail.png`.
- 실제 플레이 비교: `before_play_` / `after_play_` + 위 4개 시점, `clinic_game_camera.png`. 카메라/플레이어 위치는 플레이 검증 로그에 기록.
- 최초 before 게임 카메라의 청록색 플레이어 가림 표시에는 카메라 이동 직후 표시 갱신 지연이 있었다. after 촬영 도구는 기존 Refresh()를 호출하여 실제 카메라 기준으로 갱신한다. 캐릭터 재질이나 런타임 로직 변경은 아니다.

## 중간 실패와 보완

- 최초 조명 사전 검사는 지붕 가림 구역이 중첩 RoofCutaway 자체를 참조한다고 가정해 중단됐다. 실제 저장본은 상위 ROOF_CLINIC__Visual을 참조하므로 정확한 조상 관계 검사로 수정했다. 이때 조명 노드 생성 전 중단됐으며 원본 저장본은 유지됐다.
- `iteration01_shader_failure/`: 새 셰이더의 HLSL 예약어 `texture`를 지역 변수로 사용해 분홍색으로 출력됐다. 변수명을 수정하고 컴파일 오류 검사를 추가했다. 실패 화면은 삭제하거나 정상 결과로 제시하지 않는다.
- `iteration02_flat_lighting/`: 오류 수정 후에도 어둡고 균일했다. 설치된 URP의 `_CLUSTER_LIGHT_LOOP` 지원을 추가하고 재질의 미세 마모/거칠기 변화를 보강했다.
- `iteration03_low_light/`: 추가 광원 처리 후에도 빛이 약해 국소 광원 강도를 1.45에서 8로 높였다. 실측 광원 높이는 8.31m, 바닥은 4.02m였다. 등기구 차폐가 원인이라는 초기 추정은 실제 경계 측정으로 배제했다.
- 최초 before 동쪽 경계의 저해상도 첫 렌더 차이 0.045267은 baseline 결함으로 로그에 남겼다. 같은 화면의 저장된 전후 캡처는 유사했고, 준비 렌더를 거친 after 검사에서는 네 방향 모두 약 0.000001~0.000002였다. 이 검사는 확인한 네 위치에 한정되며 모든 맵 경계의 무결성을 뜻하지 않는다.

## 최종 검증

- `GEOMETRY_VALIDATION.txt`: 기존 계층·위치·크기·메시·충돌 보존, 신규 충돌 0, 대상 외 재질 변경 0, 원본 재질 변경 0 — PASS. 새 그림자 계층만 비교 예외로 허용했다.
- `after_PLAY_VALIDATION.txt`: 실제 플레이에서 7개 대상 재질 유지, PlayerMotor/CharacterController로 입구→내부 이동 180단계 통과, 동·서·남·북 검사 위치의 밝기 연속성 통과, B 복귀 시 A맵과 새 광원 비활성화 — 실패 0.
- 최종 실제 플레이 화면에서 바닥의 큰 균열 반복이 사라지고, 작은 마감 패턴과 두 톤 벽, 천장등의 국소 광량이 확인됐다. 지붕 외부 시점은 변경 전 이미지와 동일하다.
- `PERSISTENCE_VALIDATION.txt`: 저장·다시 열기 후 7개 재질 연결, 전용 셰이더, 그림자 루트 1개와 광원 2개 유지, 원본 재질 파일 동일 — 실패 0, 셰이더 오류 0.
- `RELOADED_GEOMETRY.txt`: 저장 후 구조가 실제 시험한 after 구조와 정확히 일치 — PASS.
- `SAVED_STATE.txt`, `FINAL_STATE.txt`: A 장면과 맵 프리팹 저장 완료, 플레이 종료, sceneDirty=False.
- 독립 GPT-6 Sol high 검토자가 최종 이미지와 위 검증 기록을 읽고 의료동 V32 범위 내 PASS로 승인했다. 남은 차단 결함은 없으며 전체 맵/베이크 GI 검증을 의미하지 않는다.
- 원본 4개 편집 시점 + 5개 플레이 시점의 전후 PNG를 모두 보관했다. 경계 검사 이미지는 별도 추가 증빙이며, 카메라 캡처에는 화면 오버레이 HUD가 포함되지 않는다.
- 이번 변경은 동선·장애물·스폰을 바꾸지 않았으므로 B4/R8 경험 재설계는 하지 않았다. R8 활성화도 하지 않았다.
