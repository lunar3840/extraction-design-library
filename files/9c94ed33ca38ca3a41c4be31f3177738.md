# 인벤토리 실시간 인물 및 임시 아이템 변경

## 사용자 요청 반영

- 전체 아이템 목록은 최종 콘텐츠가 아니다. 일반 상점은 시스템별 샘플 10종, 신규 저장 슬롯의 시작 아이템은 소총·탄약·물·식량·헬멧·방탄복 6종으로 축소했다.
- 기존 아이템 정의는 저장 호환 및 시스템 회귀 시험을 위해 보존했다. 기존 슬롯의 가방/창고/유품 아이템을 삭제하거나 숨기지 않으며, 로드 시 새 장비를 강제 지급하지 않는다. 퀘스트/감염 개발용 지급 및 개별 시스템 시험 씬의 추가 샘플은 유지한다.
- 왼쪽 인물 칸은 정적 실루엣 대신 실제 현재 플레이어의 3D 모델을 보여준다. 장착 헬멧·방탄복·총, 현재 자세, 장비에 따른 헤어/옷 가림을 따라가며 해제 및 저장 불러오기에도 갱신된다.
- 장비 외형 on/off 버튼은 이번 범위에 포함하지 않았다.

## 구현 및 보호 범위

- InventoryPortrait: actor 전체 Transform 계층과 MeshRenderer/SkinnedMeshRenderer만 별도 공간에 구성. 원본 sharedMesh·bindpose·bones 순서·rootBone·blendshape·재질 속성을 유지한다. Animator/게임 로직/물리/충돌을 복제하지 않는다.
- 렌더링은 최종 캐릭터/장비 처리 후 LateUpdate에서 동기화한다. 별도 카메라와 투명 RenderTexture를 사용한다. 가방 닫기 및 소유 UI 비활성화 시 정지, UI 파괴 시 카메라·RT·사본 정리.
- InventoryGlassView의 인물 칸 연결, 무기 명패를 모델 아래로 이동. GlassIcons의 정적 실루엣 경로 제거.
- PrototypeItems.json으로 상점 노출 품목 편집. SessionTestWorld의 신규 슬롯 시작 구성만 조정했다. 기존 거래·스택·중량·장비·저장 규칙은 유지했다.
- Roblox 원본, SD 캐릭터/총/방어구 자산 및 Sd* 코드, 사용자 실제 저장은 수정하지 않았다. 검증은 별도 프로젝트/실행본 및 고유 임시 저장 경로에서 수행했다.

## 최종 검증

- 실제 URP 별도 Windows 빌드 및 실행 모두 exit 0. Portrait-Checks.txt: 439 PASS, Errors=0.
- 화면 확인: Portrait-01-Original / 02-Helmet / 03-Equipped / 04-Removed / 05-WeaponSwap / 06-Shop. 각 -Model.png는 실제 미리보기 RT 원본이다.
- 렌더러 표시/메시/재질, 뼈 순서·현재 좌표·rootBone, 장비 해제/저장복원/무기교체, UI 닫기/비활성화/파괴, 상점10종 및 레거시 정의 보존을 검사했다.
- 최종 소스로 headless 회귀 4배치 exit 0: GlassLayout57 + FrontEnd44 + Equipment63 + Systems18 + Session42 + Basecamp50 = 274 PASS. headless 결과는 그래픽 확인과 구분한다.
- 변경 런타임/데이터 7파일은 실제 URP 검증 사본과 SHA256 일치 확인. README는 검증 후 문서 설명만 보완했다.
- 최초 BakeMesh 구현은 데이터 검사를 통과했지만 시각적으로 체형이 틀어져 폐기했다. 전체 Transform/스킨 뼈대 동기화로 대체한 최종 이미지에서 정상 체형·장비 위치를 직접 확인했다.
- 별도 검증 에이전트 보고서: work/review/PORTRAIT_REVIEW.md.

## 현재 한계 / 이후 확장

- 현재 SD 모델과 장비 연결 경로를 검증했다. 향후 다른 모델의 LOD, actor 외부 뼈, 같은 Transform에서 Renderer component 자체 또는 bones/rootBone만 교체하는 경로는 추가 연결/검사가 필요하다. 현재 장비 메시 교체 및 새 총 GameObject는 반영된다.
- 별도 렌더 공간은 현재 시험장 밖의 좌표와 layer31을 사용한다. 향후 대규모 월드/레이어 정책을 정할 때 전용 preview scene 격리를 검토해야 한다.
- 인벤토리 미리보기는 게임 내 현재 모습의 표시이며 새 장비 모델 제작/피팅 수정이나 모든 향후 아트 품질 보장은 아니다.

## 사용자 확인

Unity가 컴파일을 마친 뒤 Play를 다시 시작하고 Tab으로 가방을 연다. 기존 슬롯은 원래 아이템을 유지한다. 기본 헬멧/방탄복은 상점에서 구매하거나 빈 슬롯의 새 게임에서 확인할 수 있다. 기존 저장을 지울 필요는 없다.
