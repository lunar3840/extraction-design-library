# 에델·세린 체형을 기준으로 방어구 디자인 다시 구성

## 사용자 지시와 기획 의도

사용자는 이전 에델·세린 착용 시안에서도 등급에 따른 차이가 잘 보이지 않으므로 남성형 마네킹에서 가져온 형태를 벗어나 두 캐릭터에 맞춘 새 시안을 요청했다. USER_REQUEST.md에 원문을 보존했다. 같은 방어구 역할 안에서도 C/B/A/S가 다른 생김새를 가져야 하며, 앞서 요청한 서브컬처 의상의 노출 방향도 유지한다. 기존 장비 주제의 11-02-01 시안에 대한 명시적인 후속 수정이므로 주제 ID를 유지하고 11-02-02로 연결한다. 새 목적의 대표 주제를 만들지 않는다.

## 변경 전 문제

기존 시안은 네 티어가 대체로 작은 보호판 상의와 비슷한 반바지·벨트 조합이었다. 보호판 분할과 색에는 차이가 있었으나, 두 캐릭터의 작은 몸에서 보이는 옷의 외곽선·목선·허리 구조는 비슷했다. 남성형 마네킹 시안의 장비 형태를 두 캐릭터에 얹은 인상이 남았다는 사용자 평가를 반영한다.

before_character_design.png는 이미 게시된 11-02-01의 after_tier_structure.png를 수정 착수 전에 복사한 정확한 이전 시안이다. 이전 회차 원문·파일·게시 증빙은 수정하거나 덮어쓰지 않았다.

## 실제 바꾼 시안

새 이미지의 생성 참조에는 **실제 에델·세린 게임 렌더 두 장만** 사용했다. 이전 마네킹 이미지나 이전 방어구 시안을 새 이미지의 형태 참조로 넣지 않았다. 에델의 연보라색 머리와 땋은 머리, 세린의 갈색 머리와 포니테일, 큰 머리와 짧은 팔다리의 비율을 각각 참고했다. 동일 제품의 등급별 디자인 정체성은 두 캐릭터 행에서 연결한다.

| 등급 | 새 의상 구조와 눈에 보이는 구분 |
|---|---|
| C | 해진 비대칭 짧은 조끼, 사선 결속, 한쪽 회수 금속판, 불균형한 허리 파우치·작업 천과 한쪽 무릎 보호대. 갈색·올리브·녹슨 주황색. |
| B | 둥근 칼라와 짧은 소매를 가진 순찰복 볼레로형 재킷, 크림색 곡면 전면, 가로 버클, 둥근 분할 허리 덧단. 회청·크림·황토 계열. |
| A | 목이 올라오는 짧은 군용 전투 재킷, 각진 쇄골·가슴 보호판, 중앙 해제 손잡이, 벨트에서 별도로 내려오는 각진 허리 보호판. 차콜·어두운 올리브·벽돌색 표식. |
| S | 한쪽 어깨를 개방한 비대칭 짧은 테크 의상, 얇은 곡면 셸, 몸통의 비대칭 절개와 한쪽으로 내려오는 짧은 코트 꼬리, 매끈한 분리형 정강이 판. 네이비·화이트·실버·절제된 시안. |

단일 사각 보호판의 색 교체에 머물지 않도록 상의의 재단·목선·소매·결속부·허리 덧단·다리 장비를 함께 바꿨다. 팔·복부·허벅지 일부의 노출은 유지하며 가슴과 골반/둔부는 불투명한 상의·반바지로 덮는다. 현재 비교는 같은 **균형형 역할**의 네 티어이며, 등급이 높아졌다는 이유로 무조건 전신을 덮는 중장형으로 바꾼 것이 아니다. 시각적 보호판 크기가 실제 방호 범위나 성능을 확정하지 않는다.

## 제작 방식과 확인 결과

built-in image_gen으로 새 승인용 이미지 시안을 생성했다. IMAGE_PROMPT.json에 실제 프롬프트와 두 참조 파일 경로·역할을 보존했다. PNG를 열어 두 캐릭터가 에델/세린 행에 맞게 배치되었는지, 네 등급 표기와 발끝이 포함되는지, 각 원래 머리색과 헤어 실루엣이 유지되는 방향인지, 조끼/순찰복 재킷/각진 군용 재킷/비대칭 테크 의상이 서로 다른 외곽선을 가지는지 확인했다.

원본 게임 렌더를 참고한 **이미지 시안**이지 원본 메시 위에 실제 3D 장비를 피팅한 렌더가 아니다. 정확한 체형 치수·본·관절·얼굴 픽셀 보존을 검증한 것으로 주장하지 않는다. 두 캐릭터의 체형을 보존한 실제 제작은 별도 Blender 작업이 필요하다. 어깨 가동부와 칼라/헤어, 가슴/상의 곡면, 허리 보호판과 허벅지, S 의상의 코트 꼬리와 팔·총기 간섭은 제작 단계에서 확인할 항목이다.

이번에는 Unity·Blender를 조작하거나 생산 Assets·캐릭터 모델·애니메이션·장비 성능·드롭을 변경하지 않았다. 사용자 승인을 받기 전 새 장비 제작·피팅·삽입도 하지 않았다. 이전 원본 패키지 다운로드 문제로 보류된 캐릭터 동기화 상태와 이번 디자인 이미지 완료 상태는 구분한다.

## 전후 증빙

- before_character_design.png: 11-02-01의 이전 두 캐릭터/네 등급 이미지 시안.
- after_character_design.png: 이번에 실제 에델·세린 렌더만 참조하여 의상 전체의 재단과 실루엣을 다시 구성한 시안.
- 두 이미지 모두 에델 상단·세린 하단, C/B/A/S 네 열로 비교한다. AI 생성 이미지이므로 조명·카메라·포즈·비율이 픽셀 단위로 동일한 재촬영본은 아니다. 비교 대상은 의상의 디자인 변화이며 실제 게임 화면의 전후쌍으로 사용하지 않는다.
- FILE_CHECK.json: 이미지 해상도·해시 및 이전 시안과의 원본 일치 확인.

## 다음 단계와 승인 상태

새 시안은 사용자 검토 대기다. 의상 전체의 차별화가 충분한지 확인한 다음 승인된 디자인부터 제품별 정면·측면·후면을 정리하고, 두 원본 체형에 맞춘 실제 모델 제작과 움직임 검증을 수행한다. 이미지 시안의 완성을 16종 전체 방어구의 제작·피팅 완료로 확대하지 않는다.
