# A맵 Time Ghost 환경 에셋 적용 기록

작업일: 2026-09-15, 한국 시간

## 사용자 지시와 기획 의도

사용자가 다운로드한 `Time Ghost Environment | 3D Sample (2024)`를 활용해 너무 단순했던 임시 환경 외형을 교체한다. 기존 지형·동선·충돌·건물 실내·진입·탈출 구조와 추후 에셋 교체 가능성을 유지한다. 메인이 선별·통합·나무 URP 어댑터·Unity 실행·시각 검토를 맡고, Sol high 담당들이 패키지 분석, 지표·바위·식생 제작, 독립 검증을 병렬 수행했다.

## 변경 전 상태

기존 v0.9는 연속 지형과 기본 탐험 공간이 구현되어 있었지만, 땅은 단색이고 나무는 원기둥, 바위는 구, 풀·덤불은 단순 메시였다. 원본과 검증본 A 프리팹의 동일 SHA256 `BC8C305BA0DAAB04833B72F63278418C532DA1659DE7F1DCE8F2C290547490C3`을 확인하고, 실제 수정 전에 기존 6개 카메라의 화면을 새로 촬영했다. 이전 작업 사진을 이번 before로 대신 사용하거나 사후 재구성하지 않았다.

## 실제로 바꾼 부분과 방식

- 로컬 Unity Asset Store 캐시의 5,708,218,029-byte 패키지를 분석해 필요한 아트만 선별했다. 샘플 씬, HDRP 프로젝트 설정, DOTS/ECS 패키지나 게임 코드는 병합하지 않았다. 원본 게임은 Unity 6000.1.0f1 / URP 17.1.0을 유지한다.
- 지표를 grass ground와 방향성 없는 rubble 텍스처로 교체했다. 기존 도로 삼각형의 UV 영역을 1024×1024 R8 마스크로 만들고 약 1m 경계를 혼합해, 겹친 도로판을 추가하지 않고 부드러운 길 가장자리를 표현한다. 지형의 정점·삼각형·UV·충돌은 변경하지 않았다.
- 암석 80곳을 Kullaberg 모델 2종으로 교체하고 기존 외형 범위에 맞췄다. object-space normal은 URP의 tangent-space normal 슬롯에 넣지 않았다.
- 잔디 위치 640개와 덤불 위치 192개에 Standard Grass 3종 및 높은 Meadow Grass 3종을 배치했다. 기존 20개 구역의 위치·폭·높이를 유지했고 80개 재질별 결합 메시로 묶었다. 여기서 192개는 관목 모델이 아니라 기존 덤불 위치를 높은 풀로 대체한 수량이다.
- 나무 128곳에는 Cedar/Dogwood의 12×12 반구형 이미지 아틀라스를 사용하는 URP 어댑터를 적용했다. 샘플에 일반 입체 나무 모델이 없으므로 실제 3D 나무 FBX를 가져온 것으로 표현하지 않는다. 원본 투영·프레임 매핑 보조 코드를 사용하고 URP용 표시·그림자 처리를 구성했다.
- 228개 환경 슬롯에 교체 프리팹을 연결했다. 기존 CollisionRoot와 외형을 분리하고, 교체 프리팹 안에는 새 물리 충돌을 추가하지 않았다. 텍스처 가져오기 상한은 2048이다.

건물 15곳, 차량 16개, 산업 소품 39개, 수면, B맵, 캐릭터·무기 및 진행도/해금 로직은 기존 상태를 유지했다. 패키지 전체의 완성된 샘플 장면을 현재 맵에 이식한 작업은 아니다.

## 중간 검토에서 발견하고 수정한 사항

1. FBX 안의 여러 LOD가 같은 위치에 존재하는 것을 확인했다. LOD1 하나만 남겨 중복 표시를 방지했다.
2. 첫 방향성 도로 텍스처는 길 방향과 무관한 줄무늬를 만들고 2m 지형 분류의 톱니 경계를 강조했다. 무방향 rubble와 부드러운 마스크 혼합으로 대체했다.
3. 나무가 지나치게 가늘고 어둡게 표현되어 폭과 재질 밝기를 보정했다.
4. 원본 HDRP의 픽셀 깊이 보정이 없는 상태에서 나무의 빛 방향 그림자판과 카메라 방향 표시판이 달라 수관에 직선 자기 그림자가 생겼다. 나무의 그림자 수신을 생략하고 지표로 드리우는 그림자는 유지했다.
5. 지표 전용 셰이더에서 텍스처가 과암부에 묻혀 환경광 하한을 보정했다. 카메라·씬 조명 설정 자체는 전후 동일하게 유지했다.

초기 적용 화면 및 검사 결과는 작업공간 `work/timeghost-v10/Build01_preview/`에 보관했다. 본 폴더의 after는 최종 보정 결과다.

## 확인 결과

검증은 분리 프로젝트 `work/stage-a-v03-validation`에서 실행했다. 원본 에디터의 열린 씬을 강제로 전환·저장하거나 원본 Play를 실행하지 않았다.

- 최종 정적 검사: PASS, 3,577개 확인, 실패 0, Unity 오류/예외 0.
- 활성 충돌체 945개 전수의 위치·형상 지문이 변경 전과 동일하다. 지형 메시와 주요 기준점 지문도 동일하다.
- 진입 12곳, 탈출 7곳, 중계 3곳, 주요 건물 5곳 및 보조 건물 10곳 유지.
- 동일 메시·동일 위치·회전·크기의 새 완전 중복 외형 0그룹.
- 활성 재질의 셰이더 지원, URP 호환, 필요한 텍스처 참조와 역할, 절차 마스크의 R8/크기, 지표 16개 렌더러의 혼합 재질 계약 통과.
- Play 검사: PASS. 경로 233건, 실제 캐릭터 이동 39건, 호안 밀기·구르기 차단 17건. 외형 교체 후 2프레임이 지난 시점에도 충돌 보존.
- 원본 에셋 GUID와 새 아트 GUID 충돌 0건.
- 진단값: 활성 렌더러 1,319개, 고유 재질 32개, 실제 참조 Time Ghost 텍스처 17개, 인스턴스 삼각형 합계 556,258개, 고유 메시 런타임 메모리 약 57.3MiB. 이는 FPS/전체 GPU 메모리 측정 결과가 아니다.

정적 검사와 별도로 동일 6개 시점, 나무 측면·반대편·고각, 풀 근접 및 실제 Play 진입 화면을 확인했다. 새 재질은 정상 표시되며 도로 줄무늬·거친 경계와 나무의 직선 자기 그림자 문제는 최종 화면에서 해소됐다.

## 남아 있는 표현 한계

나무는 다방향 이미지 기반이므로 가까이 확대하면 흐릿하고 깊이감이 제한된다. 원본 HDRP의 전체 깊이 보정, 바람, 투과광과 ECS 최적화까지 재현하지 않았고 나무가 다른 물체의 그림자를 받는 표현도 생략했다. 정지 시점 검사만으로 모든 움직임에서 팝핑이 전혀 없다고 보증하지 않는다.

기존 배치 밀도를 유지해 넓은 공터가 남고 일부 풀은 성긴 마른 풀처럼 보인다. 회색 건물·차량·수면의 임시 외형도 그대로다. 새 건축 에셋, 식생 밀도 재설계, 최종 조명/성능 튜닝은 별도 단계다. 높은 폴리곤의 모든 삼각형 교차를 전수 검사한 것은 아니며, 최종 에셋 교체나 양면·투명 재질 변경 시 다시 검증해야 한다.
