# 시야각 바깥 밝기 조정

플레이어 시야각 바깥의 전용 어둠 오버레이 강도를 `0.72`에서 `0.56`으로 낮췄다.

시야각 115도, 시야 경계 흐림, 근접 위협 표시, 적 가시성 판정, 조명 색과 강도, 그림자, 반사, 젖은 바닥, 카툰 셰이더와 외곽선은 변경하지 않았다. 코드 기본값과 실제 `PlayerDefaults` 설정에서 같은 값 한 항목만 수정했다.

별도 검증 프로젝트에서 실제 출격·이동·사격과 그래픽 통합 검사 37개가 통과했다. 기존 맵 2개와 SD 캐릭터 원본 292개의 해시도 유지됐다. `Comparison.png`는 왼쪽이 이전, 오른쪽이 조정 후 실제 플레이 화면이다.

이전 값은 `work/peripheral-brightness-backup`에 보관했다. Unity의 파일 가져오기가 끝난 뒤 Play를 다시 시작하면 적용된다.
