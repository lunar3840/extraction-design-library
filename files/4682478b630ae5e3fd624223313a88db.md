# D05 2차 연결·외벽 에셋 4종 제작 기록

날짜: 2026-10-12. 상태: Tripo 생성 및 프리뷰 검사 완료, 사용자 다운로드 대기, Unity 미변경.

## 사용자 지시와 적용 범위

사용자 원문: “더 만들어 그럼. 배치하는데 또 크레딧 쓰잖아.”
부족하다고 검토한 연결 부품과 외벽 차별화 소재의 추가 생성을 진행했다. 기존 지시상 다운로드는 사용자가 담당한다. 이 턴은 Unity 배치 작업이 아니며 씬·프리팹·코드 수정, 다운로드, 유료 내보내기, 유료 후처리, 구독 변경을 하지 않았다.
Tripo 모델 생성·재가공에는 크레딧이 들지만 다운로드한 모델을 Unity에 배치하는 행위 자체에는 Tripo 크레딧이 들지 않는다고 안내했다. 다른 서비스 사용량까지 무료라는 의미는 아니다.

## 기획 의도와 변경 전 상태

- 기존 D05 10종은 산업 설비·부착물·독립 시설 중심이다. 건물 벽 재질 반복과 연결 경계 끝단 표현의 공백이 남아 있다.
- 저장된 D04 공구정비점·진료소·전체 캡처를 선행 검토했으며, 이는 현재 실시간 Unity 화면이 아니라 2026-10-07 기록이다.
- 작업 전 Tripo 모델 목록과 잔액 2,870을 before_asset_library.png로 저장했다.
- 기존 10종을 지우거나 재생성하지 않았다.

## 병렬 검토로 바꾼 설계

메인이 디자인·이미지 생성·Tripo 제출·시각 검사·통합을 수행하고, GPT-6 Sol high 서브가 기존 맵 코드와 에셋 중복·각도·12개 프리뷰를 독립 검토했다.
처음 만든 90° YardCorner 시안은 모델링 전에 제외했다. V33 실측에서 직각 연결은 한 곳뿐이고 대부분 29~83°이므로 긴 L형을 범용 키트라고 부를 수 없다. 벽날개 없는 BoundaryJunctionPier로 교체했다.
추가 낮은 폐허벽은 D04의 기존 재고와 중복되어 제외했고, 철망 게이트 어깨는 기존 V16 대체 여부가 미검증이므로 과금 보류했다. 최종 4종만 생성했다.

## 검증과 남은 제한

메인은 4종 각각 정면·사선·후면을 직접 회전하여 확인했다. 서브도 저장된 12장과 원화를 별도 열어 검사했다. 시각 후보로서 통과하며, 배치 완료나 범용 정합 완료를 뜻하지 않는다.

- 진료소: L형 코너와 미장/노출벽돌/청록 타일·창턱 보존. 안쪽도 창과 마감이 있는 양면 코너벽이다. 얇은 스킨이 아니므로 기존 벽을 분할·교체하는 작업이 필요하다. 닫힌 불투명 창이며 통행구가 아니다.
- 끝단: 한쪽 경계와 큰 기둥만 있고 빈 쪽에 문짝/가로빔이 없다. 실제 벽 길이를 재서 필요하면 기존 벽 방향으로 줄인다. 출입구 폭을 줄이지 않는다. 불투명용으로 철망 구역의 시야를 바꾸지 않는다.
- 접합기둥: 단일 기둥으로 벽날개 없음. 받침이 둥글게 다듬어졌고 볼트/띠가 조금 돌출되므로 접합면을 정리할 필요가 있을 수 있다. 다양한 각도를 자동 연결하는 부품이라고 주장하지 않는다.
- 산업 외벽: 무창 벽돌면과 콘크리트 프레임 깊이 보존. 뒤도 마감된 두꺼운 벽이므로 기존 외벽을 대체/분할해야 한다. 도로 위 독립 장벽이나 기존 창/문 위 덧댐으로 사용하지 않는다.
- 실제 GLB 파일은 아직 받지 않았다. 실측 크기·피벗·UV·면 연결/양면·내보내기 성공·충돌체·플레이어 가림·성능·기존 벽 접속은 미검증이다.
- 새로운 모든 구조물을 복제해 넓은 초지를 채우는 것이 목표가 아니다. 기존 건물/연결 경계와 작업마당의 역할 안에서 선택 적용해야 한다. B4/R8/W5와 게이트·교량·출입 동선을 변경한 적 없다.
- 상세 독립 판정은 ../BATCH2_REVIEW.md. 제작 프롬프트는 SOURCE_PROMPTS.json 및 REFINED_PROMPTS.json. 전자는 제외된 직각 코너 시안도 포함한다.
