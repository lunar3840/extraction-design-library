# S4 일러스트 노출부 수정 시안

## 사용자 지시·출처·연결

원문은 [SOURCE_REQUEST.md](SOURCE_REQUEST.md). 사용자는 기존 시안에서 실제로 맨살이 드러나는 왼다리와 허리까지 옷으로 채워진 문제를 지적했다. 같은 장비의 실제 형태와 식별성을 보완하는 후속이므로 기존 주제의 2026-11-03-03 기획 회차로 연결한다. 기존02 시안/01 구현 원문·이미지·검증 자료는 보존한다.

사용자 직접 지적은 왼다리와 허리다. 왼 윗팔은 실제 착용 참고 화면에서 함께 확인한 추가 정합성 보완이며, 사용자가 직접 별도 지시한 항목으로 기록하지 않는다. 캐릭터의 왼쪽은 정면에서 화면 오른쪽이다.

## 변경 전·실제 참조

before_icon.png는 이전02 일러스트 after_icon.png의 바이트 동일 사본을 수정 전에 저장했다. 이전 시안은 허리 양옆을 닫힌 재킷처럼 채우고, 왼 허벅지와 무릎에도 피복·보호대를 추가했다.

reference_actual_equipment.png는 기존 s4-edel-unity-armor/after_inventory_on.png의 실제 S4 에델 착용 검증 화면을 그대로 복사했다. 이번 작업에서 새로 실행/촬영한 Unity 화면이 아니다. 맨살의 위치와 장비 경계를 확인하는 구조 참조로 사용하며 UI·캐릭터 얼굴·무기 등을 새 아이콘에 삽입하지 않는다.

## 실제 시안 변경

내장 image_gen 편집 도구를 사용했다. 기존 일러스트가 편집 대상, 실제 착용 화면은 노출 구조 참조다. [GENERATION_PROMPT.txt](GENERATION_PROMPT.txt)에 전체 지시를 보존했다.

- 허리: 옆구리를 덮던 어두운 피복과 주황 장식을 제거하고 양옆 피부를 단순한 셀 명암으로 표현했다. 실제 장비의 중앙 검정 복부 패널과 허리 벨트는 유지한다.
- 왼다리(화면 오른쪽): 짧은 하의 아래의 허벅지·무릎을 피부로 표현하고, 허벅지 위쪽의 두 줄 고정 밴드와 작은 버클만 유지했다. 추가했던 긴 피복과 해당 무릎 보호대는 제거했다.
- 왼 윗팔(화면 오른쪽): 실제 참조에 맞춰 어두운 소매를 제거하고 팔꿈치까지의 피부를 표현했다.
- 반대편 주황 소매·장갑판이 있는 다리와 무릎 보호대, 가슴판·벨트·파우치, SD풍 굵은 외곽선과 단순 명암, 팔꿈치·무릎 프레이밍은 유지했다. 이전에 제거한 대각선 끈은 다시 넣지 않았다.

피부는 실제 피복 범위를 전달하는 단순한 도형/색면으로 표현한다. 머리·손·발 등 원래 프레이밍 밖의 신체는 추가하지 않았다. 이번은 PNG 시안만의 수정이며 Unity/실제 착용 모델/생산 아이콘/공통 UI 코드 변경을 포함하지 않는다.

## 검증과 한계

생성 결과를 직접 열람해 좌우 방향, 허리 양옆의 피부, 왼 허벅지의 두 줄 밴드와 맨무릎, 왼 윗팔 노출, 반대편 주황 장비와 기존 2D 스타일 유지를 대조했다. 실제 게임 슬롯에 적용한 검증 또는 픽셀 단위의 동일 원본 추적 결과라고 주장하지 않는다. 시안 검토 전이며 Unity 내 작은 아이콘 가독성/성능은 측정하지 않았다.

원본 PNG를 재인코딩/보정하지 않고 그대로 복사했다. IMAGE_VALIDATION.json에 RGBA8/1254×1254/891736bytes/SHA를 기록했다. 알파24 초과 가시 범위는187,57~1027,1218이고 사방 여백이 있다. 원시 알파0 초과 범위는0,19~1205,1221로 별도 기록했으며 가장자리에 알파1 픽셀4개가 있어 테두리 전체가 완전 투명하다고 주장하지 않는다. 모서리4개는 알파0이며 완전 투명 픽셀915616개다.
