# A맵 V32 건물군·마당 기반 동선 도면 재설계

## 사용자 지시와 작업 범위

기존 V31 토사 덩어리가 도로만 막고 주변 평지의 자유 횡단은 그대로 남기는 문제를 지적받았다. 덕코프 참고 지도처럼 열려 있으면서도 건물·시설이 오밀조밀하게 이어져 동선을 유도하도록 **도면부터** 재설계한다. Unity 실행·수정·배치는 하지 않는다. 다른 게임의 시스템을 현재 프로젝트 규칙으로 가져오는 작업도 아니다.

## 변경 전 상태와 증빙

- 작업 시작 전에 기존 V31 총괄도 원본을 `before_overview.png`로 복사했다. 이전 제안 도면의 보존본이며 현재 Unity 사진으로 가장하지 않는다.
- 사용자가 직접 제공한 실제 Unity 문제 화면을 `before_user_unity_reference.png`로 보관했다. 기존 도로를 가로막는 긴 평평한 토사와 주위 넓은 빈 잔디를 확인할 수 있다.
- 기존 V31 도면/구현 파일을 덮어쓰지 않았다. 이번에는 Unity를 켜거나 조작하지 않았으므로 게임 전후 캡처를 새로 만들지 않았다. 사후 도면을 변경 전 게임 화면으로 위장하지 않는다.
- `before_overview.png`와 `after_overview.png`는 동일한 520×400m 북서 원점·북쪽 상단 기준의 총괄도지만, 범례와 여백 구성은 다르다. 픽셀 단위 게임 화면 비교용은 아니다.

## 기획 의도

길에 장애물을 놓고 돌아가게 하는 대신, 건물과 마당의 실제 점유면이 통로를 형성하게 한다. 중앙 중정비동과 진료소·전력시설·정밀부품 창고·공구 정비점은 기준점으로 남긴다. 소형 건물 보존에 얽매이지 않고 재배치·증설 후보로 다룬다. 전체를 균일하게 채우거나 9개의 닫힌 방으로 나누지 않는다. 남측 하역대로 같은 열린 직행축은 빠른 이동 선택지로 유지한다.

## 실제 변경한 도면 내용

- 기존 주요 시설 5곳 + 소형 시설 재배치·증설 후보 64곳으로 총 69개 건물 점유면을 배치했다. 69개를 새로 추가한다는 뜻이 아니며 기존 49개 소형 건물을 이 도면 위에 중복해서 얹지 않는다.
- 설비 점유면 29개, 부분 담장 21개, 소규모 암반 10개와 열린 작업마당을 조합했다. 마당과 식생은 통과 가능하며 보이지 않는 식생 장벽을 두지 않는다.
- V31 토사 A–D를 고정 제약으로 사용하지 않는다. 이번 제안은 기존 큰 토사를 그대로 꾸미는 안이 아니라 주변 시설을 포함한 재구성안이다. 실제 Unity의 토사는 아직 그대로 있다.
- 서측 상세에서 8m 반입길, 4m 뒤뜰 접근, 3.5m 남측 샛길을 다른 건물 면과 마당을 지나도록 구성했다. 폭은 설계 목표이며 실제 게임의 측정값이 아니다.
- 북측 N17 및 동측 E04 부속동으로 기존 광폭 직행 띠를 나누었다. 남측 하역대로는 의도된 열린 축으로 유지했다. 모든 직선 이동을 금지하려는 안은 아니다.
- B/X/T1–T3과 수로·두 교량 좌표는 유지했다. R1–R8은 비활성이며 위험 구역이나 적 위치가 아니다. B4/R8 경험 차이는 미검증이라 위험 전용 경로선을 최종안에서 제외했다.
- 건물 다각형은 실내 출입이 미설계된 보수적 외곽 점유면이다. 실내 구조·문·지붕 가림·높이·AI·보상 배치를 완성한 도면이라고 주장하지 않는다. 인간형 적은 기존 설정대로 제한 구역 내 수색·순찰이며 거주·철수 거점을 만들지 않았다.

## 제작과 검증 과정

메인이 배치 데이터·통로 폭·점유 형상과 검증 도구를 작성했다. GPT-6 Sol high 제작 담당은 PNG/SVG 총괄도와 서측 상세도를 제작했고, 별도의 GPT-6 Sol high 검토 담당은 점유·연결·경로 위상을 독립 검토했다. 메인이 최종 `REVIEW.md` 전문과 실제 렌더 결과를 읽고 확인했다.

초안의 건물/장비 겹침과 경로 관통은 반려했다. 중간 자동 경로 보정안은 사각형 여유폭 때문에 불필요한 대우회·왕복·반복 교차를 만들어 다시 반려했다. 설비를 마당 안쪽으로 옮기고, C04/E04/S12와 일부 담장을 조정했으며, 생활 폐허 경로 P2를 B3–B4 내부 연결로 정리했다. 실제 표시 선과 검사 선을 따로 만드는 방식으로 문제를 숨기지 않았다.

### 확인 결과와 한계

- 메인 정밀 2D 검사: 표시 경로 28개의 중심선/계획 폭과 건물·설비·암반·부분 담장 간 충돌 0, 고체 점유면끼리 중복 0.
- 독립 0.5m 경로/폭 샘플 검사: 충돌 0, 경로 자기교차 0, 경로 쌍별 반복 교차 0. 갈림길·합류점의 서로 다른 경로 교차 자체는 허용한다.
- 보수적인 1m 확장 평면 격자에서 기본 진입 4곳·탈출 7곳·중계기 3곳이 같은 연결 영역에 있다. 도면의 2D 연결성 확인일 뿐 Unity/NavMesh/캐릭터 이동 결과가 아니다.
- 폭 표기 위치가 최종 경로 띠 안에 있음을 제작 담당이 확인했다.
- 총괄도·상세도 PNG와 SVG를 직접 열어 가독성과 파일 형식을 확인했다. 총괄 2510×1770, 상세 2510×1690.
- 대화 내 확대 도면은 전체/서측 선택 동작과 360px 화면을 확인했다. 브라우저 오류 0, 가로 넘침 없음. 상세 우측 중정비동 이름이 잘리던 부분을 수정했다.
- 실제 플레이 선택, 시야, 적 노출, 엄폐, 파밍 유인, 전투 위험은 미검증이다. 외곽 지름길과 열린 마당이 남으므로 플레이어가 모든 도로 굴곡을 따른다고 보증하지 않는다.
