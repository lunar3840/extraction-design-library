# 인벤토리 UX 분석서 수정 — 40쪽 → 42쪽 (설문 재집계·영상 추측 비교)

## 사용자 지시 요약

- 강사 피드백을 반영해 분석서를 고친다. 문서 디자인은 유지하고 글자·숫자·캡처만 수정한다.

## 기획 의도와 해결하려는 문제

- 영상 사례 분석에 설문 수치가 섞여 있어 "관찰로 세운 추측"과 "설문으로 확인한 결과"가 구별되지 않았다. 두 단계를 나눠야 결론의 근거가 드러난다.

## 진행 회차

- **설문**: 조건 불일치 5건과 바로 장착 1건을 빼 83건 → 78건으로 다시 집계하고 관련 수치·도넛 차트 갱신.
- **영상 사례**: 16~18쪽을 설문 수치 없이 영상 추측만으로 정리하고, 35쪽에서 추측과 설문 결과를 비교(일부 맞음 / 대체로 맞음).
- **구성**: 9~14쪽 재구성 — 화면 구성 통합, 시각 단서 4종, 익스트랙션 루프, 보호 공간·BM(2026-11 공개 자료 기준).

## 결과

- 42쪽 PDF, 포트폴리오 사이트 DESIGN 영역에 게시.
- 결론: 격자형이 담기 더 어렵다는 추측은 세 상황 모두 설문과 같은 방향. 원인·포기 방식의 차이는 미확인.

## 한계 / 확인하지 못한 것

- 보호 공간 수치는 게임 시즌 변경 시 다시 확인 필요.
