# 게임 성능 집중 점검 — 진행 중

사용자 원문은 USER_REQUEST.md에 보존한다. 같은 이동·전투 지연 개선의 후속이므로 10/26 분석·1차·2차와 동일 대표 주제를 유지한다. 환경 비용 감사는 이번 원인 분리의 일부다. 구현 또는 성능 합격으로 승격하지 않는다.

## 목적과 확인된 환경

사용자는 RTX4050 노트북의 Unity Editor Game에서 플레이가 어렵다고 보고했다. 사용자는 빌드를 아직 시험하지 않았다. 현 컴퓨터는 i7-13700H/RTX4050 Laptop/물리메모리 약32GB이며 Editor.log에서 실제 Direct3D12 RTX4050 선택을 확인했다. 내장 GPU 오선택을 원인으로 지정하지 않는다. 실행 당시 여유 디스크·메모리와 현재 Unity 프로세스는 별도 기록한다.

## 조율과 수정 전 증빙

맵/UI 담당의 무예약 회신 및 에델 S4 담당의 05:06:53 KST 명시 반환 이후 이 채팅이 Unity 검증 순서를 인수했다. 최신 S4 기본 지급/ON·OFF/몸 복원, InventoryPortrait 재바인드 수정과 전맵 덩굴을 현재 기준으로 보존한다. 과거 scene/prefab 백업을 최신 파일 위에 복원하지 않는다.

before_editor_native.jpg는 실제 인수 직후 StageA_Relay_Blockout_v08 clean Edit/Game 탭의 native 화면이다. Game 기준값은 프로덕션 최적화 적용 전에 별도 저장한다. 서브 에이전트는 GPT-6 Sol high로 월드·렌더링·헤어 범위를 분리하여 staging에만 작성했다. Unity 실행·프로덕션 통합은 메인 단독이다.

## 현재 상태

정적 감사 후보와 실제 측정 결과를 구별한다. staging/hair/HAIR_STATIC_AUDIT.md, staging/world/AUDIT.md, staging/render/RENDER_STATIC_AUDIT.md가 초기 읽기 전용 결과다. 초기 제안 중 기존 반려 score skin cache의 중복 제안은 철회했다. 실제 변경·전후 수치·시각 회귀·공유 Unity 반환·게시 결과는 실행 후 추가한다.
