## 판정과 범위

**PASS_FOR_SAVED_GAME_SAMPLE_WITH_LIMITS.** 최종 저장본의 `rounds/fin06b_saved/after_<id>.png` 36장과 `rounds/fin06b_extra/after_<id>.png` 21장을 모두 직접 열었다. 진짜 변경 전 `before_<id>.png` 36장과 `rounds/extra_before02/before_<id>.png` 21장을 기준으로 삼고, HALL·C01·작은 건물·폐차·컨테이너·수변·다리·발전기·처마의 대표 쌍은 원본 크기로 다시 대조했다. 두 `PLAY_REPORT.json`은 각각 36/36·21/21, 실제 플레이어 이동 PASS, 씬 clean, 원상 복원 및 덩굴 강제 표시 없음이다. 이 판정은 **57개 촬영 시점의 실제 Game 미감**에 한정한다. 57개는 57개 개별 수정 그룹을 뜻하지 않으며, 추가 21장에는 이미 포함된 건물·컨테이너의 근접 재촬영과 제작 제외 R_RACK_06도 있다. 226 기존 그룹과 추가 17그룹 전수의 개별 Game 미감 합격이나 최종 보존 게이트는 별도 진단 결과와 구분한다.

## 잔여 한계와 인계

- HALL, C01, 파란 컨테이너에는 변경 전보다 덩굴이 성기고 맨줄기 또는 빈 면이 크게 남는다. 연결된 성장과 입체 잎 군집은 개선됐지만 **전맵이 풍성하게 뒤덮인 상태**로 표현하면 과장이다. 사진 참조와 완전히 동일한 잎종·재질·밀도를 달성했다는 판정도 아니다.
- 수변 일부와 난간의 Game 시점은 대상면이 작거나 반대편이므로 추가 17그룹의 위치·생성·원본 보존 여부는 별도 source/진단 검증에 맡긴다. 이 문서는 보이지 않은 접점까지 시각 PASS로 승격하지 않는다.
- 이 57장에서는 사용자 요구에 반하는 큰 부유 잎, 반복된 검은 뒷면 카드 띠, 출입·통행 가림, 건물·폐차·장비 재질 콘셉트 파괴를 발견하지 못했다. Pilot11 대표 미감 통과를 실제 저장본의 다양한 시야에서도 유지한다. 이전 실패 Pilot 기록과 전후 원본 이미지는 그대로 보존한다.

## 226+17 진단 화면 보조 확인

`rounds/fin06b_base/after_group_000.png`~`225.png` 및 `rounds/fin06b_xdiag/after_extra_*.png` 17장을 원본 무수정 파생 모음 12장(`staging/review/contact_sheets/derived_final_*`)으로 모두 훑었다. `BASE_AFTER_DIAGNOSTIC_REPORT.json`은 226/226, `EXTRA_AFTER_DIAGNOSTIC_REPORT.json`은 승인 17/17과 씬 clean을 기록한다. `026`, `183`, `198`, `205`, `224` 및 추가 `R_BANK_04`, `R_D12_RAIL_E`, `R_GENERATOR_04`, `R_YARD_SHELTER_EAVES`는 진단 원본 PNG를 별도로 확대했다. 파생 모음은 분석용이며 전후 Game 원본을 대체하지 않는다.

진단 전수 축소 화면에서도 새로운 대형 부유 형상·검은 카드 띠·건물 외형 파괴는 보이지 않았다. 다만 `183` 배관, `198` 설비, `205` 파란 컨테이너 및 일부 수변·다리 진단은 초점 대상의 덩굴이 매우 작거나 보이는 면에 없으므로 **그룹마다 잎이 잘 보인다는 시각적 전수 합격은 선언할 수 없다.** 생성·참조·원본 보존의 전수 기술 판정은 validator 결과에 따른다.
