# A맵 기계형 몬스터 이동 수정

- 작업일: 2026-10-15
- 사용자 지시: 기계형 몬스터가 좌우로 순간이동하거나 날아다니는 것처럼 보이는 이동을 고치고, 구매한 애니메이션 팩에 맞게 자연스럽게 다듬는다.
- 범위: 기계형 5종의 이동·애니메이션 연결. 맵 지형, 진입점, 몹 배치·수량, 인간형의 기계 회피 및 적대행동 인지 규칙은 유지한다.

## 기획 의도와 변경 전 문제

거미형 4종의 복제 프리팹은 원본 하체의 Animator root motion 활성 상태를 상속했다. NavMeshAgent가 부모 액터를 움직이는 동시에 자식 애니메이터도 이동하여 몸체가 기준점에서 누적 이탈했다. 탱크는 기존에도 root motion이 꺼져 있었다.

또한 모든 적에게 적용되던 인간형 회피 구르기는 0.3초에 4.5m를 Agent.Move로 직접 이동시켰다. 기계형에는 이에 맞는 구르기 모션 연결이 없었다. 정지 중 방향 전환은 0.2초 AI 판단마다 크게 꺾였고 후진·횡이동·회전에도 전진 모션만 재생됐다.

수정 전 실제 A맵 40초의 2,453개 관측 프레임을 저장했다. 부모 루트 최대속도는 2.238m/s였지만 Animator 자식의 localPosition은 초기 대비 최대 45.71917 단위까지 누적되었다. 이는 모델 부모의 축척이 적용되기 전 **로컬 좌표 수치**이며 월드 거리 45.7m라는 뜻이 아니다. 별도 렌더러 중심 편차 수치에는 비가시 렌더러의 대체값이 섞이므로 몸체 이동의 유효한 계측값으로 사용하지 않는다.

수정 전 재현용 직접 BeginRoll 호출은 성공했으나 동기 스크린샷 촬영 사이에 구르기 프레임을 놓쳐 rollFrames는 0이었다. 이를 실제 속도 15m/s를 촬영했다고 해석하지 않는다. 구르기 금지는 별도 직접 호출 검사로 검증한다.

## 실제 변경

- 복제 기계 프리팹 및 실행 시 바인딩에서 root motion을 끄고 위치 이동을 NavMeshAgent 한 곳에서 담당하도록 했다. 구매한 패키지 원본은 수정하지 않는다.
- 기계는 AI의 구르기 판단과 실제 구르기 실행을 모두 차단한다. 인간형과 기존 시험용 적의 구르기는 유지한다.
- 기계의 가속·감속, 프레임별 선회, 방향 전환 시 감속, 짧은 경로 재사용을 추가한다. 안전상 정지가 필요한 경로 실패·비활성·사망은 즉시 정지한다.
- 거미의 전진·후진·횡이동·제자리 회전·이동 중 회전과 전차의 전진·후진·선회 모션을 실제 속도·방향에 따라 연결한다. 전차의 인간식 측면 재배치는 끈다.
- 전차 후퇴는 경로의 반대 방향으로 차체를 정렬한 뒤 후진한다. 적을 바라보는 방향에 차체를 고정한 채 대각선으로 미는 동작을 피하고, 큰 선회 각도에서는 이동 목표 속도를 0까지 낮춘다.
- 이동속도에 맞춰 보행 재생속도를 조절하고 모션 전환을 혼합한다. 공격 모션이 없는 기계가 발사 시 보행 갱신을 잠시 멈추던 처리를 제거한다.
- 기계 사망 시 각 부품을 개별 단위 축척으로 바꾸던 처리를 시각 루트 전체의 원래 축척 기반 축소로 바꿔 조립 부품의 상대 크기와 위치를 보존한다.

### 검증 해석과 유지 범위

- 실제 재생의 NavMesh 높이/이탈 검사는 **액터 이동 기준점**을 검사한다. 비가시 렌더러의 bounds 대체값으로 모든 기계의 발 접지까지 검증됐다고 주장하지 않는다. 근접 이미지와 애니메이션 검사를 별도로 읽는다.
- Unity 종료 전 작성된 소스·프리팹·검사는 보존되어 있었고, 사용자 복귀 요청 후 편집기를 다시 연 상태에서 실제 A맵 재생을 이어 진행했다.
- A맵 Resources prefab SHA256은 변경 전후 `B598C2581070876D98F0A1A67F441A8D0373FDD0F9A07DBF9793F31721CE4B56`로 동일하다. B4/R8 약 62m와 W5 합류 문제를 재검토했으며 진입 경험을 새로 구분한 것으로 주장하지 않는다. R8을 포함한 위험 진입점은 계속 비활성이다. 진입부로의 순찰·추격 범위 확대, 반입가치 문턱·보상·건물·엄폐·탈출 동선 변경은 없다.
