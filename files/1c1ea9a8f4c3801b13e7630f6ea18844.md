# 소모품 우측 배치와 스킬 확대

- 작업일: 2026-10-22
- 사용자 지시: 무기 밑 소모품 때문에 무기 슬롯이 높아 보이므로 소모품을 오른쪽으로 이동하고, 스킬 슬롯을 더 크게 제작.
- 대상: Figma `KUD4t84BL1S77c3cnb8co0`, 페이지 `11:711`, 비교 프레임 `103:2538`.
- 링크: https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0?node-id=103-2538

## 기획 의도와 변경 전 문제

무기 480×104 아래에 소모품 네 개가 338×80 한 줄로 쌓여 무기가 y836부터 시작하고 있었다. 소모품을 오른쪽으로 빼 무기를 중앙 하단에 낮게 놓고, 작게 보이던 스킬 링·아이콘·키·문구를 함께 확대한다. 소모품 자체를 줄여 식별성을 희생하지 않도록 80×80 슬롯은 유지하고 2×2로 묶었다.

## 실제 변경과 방법

Figma 일반 편집 기능으로 기존 프레임의 Auto Layout과 위치를 변경하고, 스킬 묶음은 Scale 도구로 1.25배 확대했다.

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 무기/소모품 부모 | 480×196, x720/y836, 세로 배치 | 670×166, x720/y866, 가로 배치·하단 정렬 |
| 무기 슬롯 | 480×104, x720/y836 | 480×104, x720/y928 — 92px 아래로 이동 |
| 소모품 묶음 | 338×80, x791/y952, 4개 한 줄 | 166×166, x1224/y866, 2×2 |
| 소모품 슬롯 | 각각 80×80 | 동일, 가로·세로 간격 6px |
| 무기와 소모품 간격 | 세로 12px | 가로 24px, 기존 `spacing/24` 변수 적용 |
| 스킬 묶음 | 300×128, x1572/y904 | 375×160, x1497/y872 — 전체 125% |

스킬의 링·아이콘·키캡·문구·간격을 균일하게 확대했다. 링 64→80px, 키캡 24→30px에 해당한다. 두 스킬 사이 간격도 12→15px가 됐다. 확대 후 위치를 다시 조정해 오른쪽 48px, 하단 48px 여백을 유지했다.

무기 묶음의 중심 x960은 계속 1920 화면 중앙에 맞는다. 무기·소모품·스킬의 하단은 y1032로 일치한다. 소모품 오른쪽 x1390과 스킬 왼쪽 x1497 사이에는 107px 간격이 있다.

## 변경 후 확인

실제 1920×1080 Figma PNG에서 무기가 내려갔고, 소모품 네 개가 오른쪽 2×2로 표시되며, 확대된 스킬 이름·충전 링·준비/72%가 읽히는 것을 확인했다. 주 탄수 24/120, 보조 탄수 12/48, T3 관통, 아이템과 3~6키·×1 수량도 보존했다. 현재 장면에서 새 겹침이나 잘림은 보이지 않는다. 독립 시각 검토는 `visual-audit.md`에 별도 기록한다.

수분·에너지와 캐릭터 위 체력·스태미너, 목표·미니맵·탈출·상호작용은 변경하지 않았다. 새 인스턴스 분리나 UI 평면화 없이 편집 가능한 레이어를 유지했다. 이 비교 프레임 외의 컴포넌트 마스터와 다른 화면은 수정하지 않았다. 모든 런타임 상태·화면비 검증이나 Unity 적용 완료를 의미하지 않는다. 앱과 작업 탭을 종료·재시작하지 않았고 Unity도 수정하지 않았다.
