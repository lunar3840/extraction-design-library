첨부한 Edel·Serin 원본 모델과 CHAT_PRO_HANDOFF_PROMPT.md를 기준으로, 우리 탑다운 익스트랙션 게임용 장비의 콘셉트아트와 실제3D 모델을 제작해줘. 전달문에 전체 후보 목록과 제작 기준이 들어 있어.

먼저 두 캐릭터 파일을 직접 읽고 크기·비율·기준 포즈·본/스킨·UV·재질·텍스처를 확인해줘. 두 모델이 같은 체형이라고 가정하지 말고, 캐릭터의 얼굴·체형·리깅·원래 헤어색을 유지하면서 장비를 각각 맞춰줘. 헬멧 아래 옆머리·뒷머리도 해당 캐릭터의 원래 헤어 재질/텍스처를 사용해줘. 원본은 보존하고 사본에서 작업해줘.

최신 기획은 무기에 가시적인 티어 표시를 두지 않지만 성능 좋은 총과 좋지 않은 총의 격차는 있다는 것이야. 기본 총의 이름은 고철 소총이고, 방탄복16종·정비형을 포함한 헬멧14종·총기24종이 후보야. 모든 총을 같은 성능으로 맞추거나 무기마다 등급색을 붙이지 마. 방어구는 C/B/A/S의 소재·형태와 기동/균형/중장/정비의 특성이 읽히게 해줘.

첫 배치는 A 군용 전투복, A 공병 정비헬멧, 고철 소총, M4A1의4종으로 시작해줘. 장비 단독 콘셉트 → 실제3D 장비 → Edel/Serin 각각의 착용·파지 → 검증 순서로 진행하고, 공통 규격이 맞으면 전달문의 나머지 목록으로 배치별 확장해줘.

각 장비에 정면·후면·양측면 제작 시트와 두 캐릭터 착용 시트를 제공해줘. 실제 모델은 장비 단독 파일과 캐릭터별 피팅을 구분하고, 움직임에 필요한 스킨/장착 앵커를 연결해줘. 헬멧·머리카락·목·어깨·팔·스트랩과 총의 양손 파지 간섭을 확인해줘. 가림 처리가 필요하면 원본을 삭제하지 말고 별도 마스크/분리 메시와 범위를 남겨줘.

편집 원본, GLB 등 실제로 내보낸 교환 파일, 텍스처, 피팅 정보와 README를 장비별 폴더로 납품해줘. 내보낸 파일은 다시 열어 메시·재질·텍스처·본 연결을 확인하고, 제공된 애니메이션/포즈에서 검토한 화면과 미해결 문제를 남겨줘. 실제 탑다운 크기와 인벤토리 근접 화면 양쪽에서 읽히는지 비교해줘.

이미지·블록아웃·실제3D 파일·피팅 검증·엔진 적용의 완료 단계를 구별해줘. 사용 가능한3D 제작 도구가 없다면 그 범위를 밝히고 가능한 콘셉트/모델링용 시트와 지침까지 진행해줘. 이미지나 파일명만으로 실제 모델 제작 완료라고 말하지 마.

이번 범위는 장비 아트와 별도3D 에셋 납품까지야. Unity 프로젝트 반영이나 게임 코드·밸런스·드랍은 수정하지 마. 우선 첨부 원본 확인 결과와 첫4종의 제작 가정을 짧게 밝힌 뒤 제작을 진행해줘.
