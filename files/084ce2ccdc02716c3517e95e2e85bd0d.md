# 장비와 무기 선택의 개성 — 1차 구상

2026-10-29 KST. **사용자 검토 전 제안이며 게임 구현은 하지 않았다.** 이름·종수·성능 방향은 기획 후보다. 수치 확정이나 실제 플레이 밸런스 검증 완료를 뜻하지 않는다.

## 1. 설계의 중심

방어구는 **어떤 위험을 얼마나 오래 감수할지**, 총은 **어떤 거리와 사격 습관으로 싸울지**를 고르게 한다. 동일 티어의 차이가 단순한 성능 서열로 수렴하지 않게 한다. 높은 등급에도 명확한 성능 향상은 남기되, 무게·유지비·운용 비용까지 모두 개선되는 구조는 피한다.

델타포스처럼 동일 등급에서도 여러 선택지를 원하는 것은 이번 사용자 지시다. 델타포스의 실제 수치·방호 공식·아이템 구성을 우리 게임의 확정 규칙으로 가져오지는 않는다. 공식 운영 자료에서도 부품의 반동·취급·정확도 교환 관계를 확인할 수 있으나, 아래 제품군과 역할은 우리 게임을 위한 자체 제안이다. 참고: [Garena Delta Force 공식 업데이트](https://deltaforce.garena.com/en/news/all/MW4ZYF) (2026-10-29 열람).

## 3. 장비 분류

처음 선택 구조는 **방탄복·헬멧·배낭**을 중심으로 잡는 편이 좋다. 기존 체스트리그는 사용자가 확정한 항상 주어지는 기본 준비 공간이며 교체형 장비로 바꾸지 않는다. 현재 기본12칸과 V 자동 치료의 리그 접근 규칙을 기준으로 유지한다. 헤드셋은 별도 청각 체계가 필요한 후속 후보이며, 장갑·신발·각 부위 방어구까지 한꺼번에 늘리는 안은 보류한다.

| 장비 | 스타일 후보 | 선택의 대가 |
| --- | --- | --- |
| 방탄복 | 기동 / 균형 / 중장 / 야전정비 | 기동성, 보호 범위, 연속 피격에 버티는 내구, 반복 출격 유지비의 교환 |
| 헬멧 | 경량 개방형 / 표준형 / 안면 보호형 | 낮은 부담과 얼굴 보호 범위의 교환. 청각 차이는 실제 청각 체계를 만들 때만 추가 |
| 배낭 | 소형 기동 / 중형 탐색 / 대형 회수 | 적재 공간과 빈 가방 자체 무게, 가득 채운 귀환 부담의 교환 |
| 체스트리그, 현행 유지 | 기본 준비 공간과 V 자동 치료 접근 | 교체형 리그·탄창 접근속도 보너스는 이번 제안에서 제외 |
| 투척·도구, 후속 | 파편 / 연막 / 섬광, 제한적 기계 대응 도구 | 살상·시야 차단·순간 진입의 교환. EMP 등은 기계 전체를 무력화하는 기본 필수품으로 두지 않음 |

방탄복과 헬멧은 개별 선택을 허용하는 방향이다. 경량 헬멧+중장 방탄복처럼 혼합할 이유를 남기며, 같은 세트를 강제하는 공격력 보너스는 제안하지 않는다. 배낭은 보호등급을 붙이기보다 적재량·중량·가격으로 읽히게 한다.

## 4. 동일 보호등급 방탄복의 네 스타일

여기서 같은 등급이란 **동일 ProtectionClass**를 뜻한다. 중장형이 같은 등급의 기동형보다 더 오래 버티는 이유는 내구·보호 범위에 두며, 중량형에만 숨은 상위 관통저항을 주지 않는다.

| 스타일·가칭 | 분명한 이점 | 감수할 약점 | 선택할 출격 |
| --- | --- | --- | --- |
| 기동형 ‘러너’ | 가볍고 이동·조준 전환 부담이 낮음 | 낮은 내구, 좁은 보호 범위 후보, 전문 경량 소재의 정비 비용 | 짧은 수색, 측면 이동, 위험 시 빠른 이탈 |
| 균형형 ‘패트롤’ | 중간 내구와 부담, 폭넓은 상황 대응 | 기동·연속 피격 어느 한쪽 최고는 아님 | 목적이 여러 개인 일반 탐색 |
| 중장형 ‘벌워크’ | 높은 내구와 넓은 보호 범위 후보 | 큰 자체 중량, 느린 취급·이동, 긴 이동/전리품 운반 부담 | 좁은 진입부, 위험 시설의 짧고 강한 교전 |
| 야전정비형 ‘워크호스’ | 수리 효율과 낮은 영구 마모, 저렴한 유지 | 순간 내구는 균형형보다 낮고, 기동형만큼 가볍지 않음 | 저비용 반복 출격, 긴 수색 |

예: A티어/보호등급4 안에서도 ‘기동형을 입고 교전을 짧게 끝낼지’, ‘중장형으로 두 번째 피격을 감수할지’, ‘정비형으로 여러 출격을 싸게 돌지’가 갈려야 한다. 이동속도+방어력+내구+수리비가 동시에 좋은 고가 제품은 만들지 않는다.

수치보다 먼저 보호 부위를 정한다. 첫 확장은 가슴/복부 같은 기존 큰 신체 구역에서 시작하고, 정밀한 플레이트 틈·탄도 각도까지 기본 요구로 확대하지 않는다. 전후·측면 분리는 현재 피격 체계가 지원하는지 별도 확인 후 정한다. 파편·폭발·충격 저항은 탄 방호와 분리된 후속 설계다.

헬멧의 안면 보호형도 같은 보호등급에서 적용 범위와 무게의 교환을 기본으로 한다. 탑다운 게임의 화면을 크게 가리거나 발소리만 일률적으로 줄이는 강한 불편은 우선 사용하지 않는다. 실제 아트 제작 시 캐릭터별 원래 헤어 재질·색과 뒷머리 실루엣을 유지한다.

## 6. 같은 라이플 안에서 다른 총을 고르는 이유

실총의 모든 성능을 재현한다는 의미가 아니라 현재 명칭과 모델 후보를 활용한 게임 역할 배정이다. 총기 고유 역할은 기본 반동 형태·연사 리듬·조준 전환·지속 사격 산포·회복·탄창/장전 공백의 묶음으로 만든다.

| 기존 총기/가칭 역할 | 잘하는 방식 | 약점 | 플레이어가 느낄 차이 |
| --- | --- | --- | --- |
| M4A1·범용형 | 적당한 거리와 짧은 연사를 오가며 다양한 부품 조합 | 화력·원거리·기동 어느 축도 특화형 최고치를 못 가짐 | 상황을 덜 가리고 총 한 자루로 다니기 편함 |
| K-2·안정 연사형 | 예측 가능한 반동과 짧은 연속 사격, 초반 명중 유지 | M4보다 느린 조준·표적 전환 후보, 낮은 순간 탄 밀도 | 급하게 난사하기보다 일정 리듬으로 맞히기 쉬움 |
| AK47·중량 타격형 | 낮은 발사 빈도로 한 발을 크게 맞히는 근중거리 교전 | 큰 반동·조준 회복, 빗나간 탄의 대가 | 오래 누르기보다 제어한 몇 발이 중요함 |
| FAMAS·근접 고연사형 | 모서리 진입 후 짧은 노출에 탄을 집중 | 탄창 소진과 재장전 공백, 중거리 지속 사격 산포, 탄약비 | 먼저 잡으면 빠르지만 빗나가면 곧 빈틈이 생김 |
| M16·점사/절제형 후보 | 정해진 짧은 점사와 회복 간격으로 중거리 노출 제어 | 점사 사이 근접 대응 공백, 계속 누르는 화력 부족 | 쏘고 숨고 다시 쏘는 리듬. **현재는 자동이며 점사 기능은 새 후보** |
| SCAR·정밀 중량형 | 낮은 발사 빈도, 첫 탄 정확도·거리 유지, 엄폐 사이 사격 | 무거운 취급·탄창/장전 공백·근접 연속 대응 | 서서 차분하게 맞힐수록 좋고 이동 중 급사격은 불리함 |
| 회수 소총·저비용형 | 싼 보급·정비와 반복 출격 | 전문 총기의 강점을 흉내 내기 어려운 상한 | 잃어도 다시 준비하기 쉬움. 무작위 고장으로만 약점을 만들지 않음 |

AK와 SCAR의 중복을 막는다. AK는 근중거리 반동 제어와 한 발 교환, SCAR는 중거리 첫 탄 정확도와 느린 취급에 무게를 둔다. K-2는 사격 안정성, M4는 호환·유연성이 선택 이유다. 초기 두 모델의 차이가 약하면 부품 몇 개와 새 이름으로 감추지 말고 역할을 합치거나 조정한다.

SCAR에는 필요할 때 자동사격으로 대응할 여지를 남긴다. DMR은 그보다 먼 거리에서 반자동 반복 명중에 더 특화하고, 근거리 연속 대응은 더 양보하는 방향으로 경계를 둔다.

부품을 끝까지 맞춰도 FAMAS의 탄 소비·연사 리듬이 SCAR처럼 되거나 SCAR의 근접 취급이 FAMAS처럼 되는 조합은 피한다. 소음기형은 기계의 시야·탄착·피격 인식을 없애지 않으며 ‘은밀 대기→발사→위치 이동’이 편해지는 정도의 역할로 다룬다. 캐릭터 속성과의 궁합은 후속 후보로 남기고 특정 캐릭터가 없으면 총의 핵심 기능을 못 쓰게 하지는 않는다.

## 7. 우리 게임의 인간·기계 적과 연결

우리 게임은 기계가 맵 전역의 주적이고 인간은 소수 수색조라는 최신 기획을 따른다. 중앙 기계/외곽 인간으로 나누거나 외곽을 저난도로 일괄 취급하지 않는다.

- 작은 고기동 기계: 짧은 조준 전환과 추적 명중이 중요할 후보.
- 느린 중장 기계: 장갑과 노출 약점이 실제 도입될 때 관통·정밀 사격이 유리하도록 검토할 후보.
- 인간 수색조: 엄폐, 선제 발견, 짧은 노출과 이탈이 중요한 상대.
- 인간·기계의 삼자 교전: 큰 총성·긴 교전이 추가 위험을 부르는 환경에서 신속 종료/은밀 이동/지속 사격 중 무엇을 택할지 갈리게 함.

위는 설계 목표다. **현재 고급 관통탄이 기계 추가 피해를 주거나 EMP가 실제로 작동한다고 말하지 않는다.** 우선 기존 공격 전조·회피·재배치·재장전 공백으로 무기별 선택을 살린다. 기계 특효 배율 하나로 정답 무기를 고정하지 않고, 장갑 유무·부위·속도·거리·노출 시간으로 선택이 갈리도록 후속 적 방호 설계를 함께 확인해야 한다. 인간에게 기계의 숨은 표적 지정 정보를 직접 알려주는 방식은 채택하지 않는다.

## 8. 출격 조합 예시

| 조합 | 좋은 목적 | 취약점 |
| --- | --- | --- |
| 기동 방탄복+경량 헬멧+FAMAS+소형 배낭 | 짧은 수색과 근접 한 번의 교전 후 이탈 | 장기 교전·재장전 공백·많은 전리품 |
| 균형 방탄복+표준 헬멧+M4/K-2+중형 배낭 | 목적이 여럿인 탐색과 적응 | 한 가지 특화 상황의 최고 효율 |
| 중장 방탄복+표준/안면 헬멧+AK/MG | 위험 시설의 짧은 진입과 연속 교전 | 탄약·장비 중량, 추격 회피, 가득 찬 귀환 |
| 야전정비 방탄복+경량 헬멧+회수 소총/M16+중형 배낭 | 유지비를 아끼는 반복 출격 | 갑작스러운 근접 집중 화력 |
| 기동/균형 방탄복+SCAR/DMR | 사선을 확보하고 선제타 후 이동 | 근접 급습, 큰 탄약 소모보다 명중 의존 |

조합은 추천 예시이며 세트 제한이 아니다. 중장 방어구를 샀다고 위험 진입점이나 고난도 적 출현이 자동 활성화되는 규칙을 이번 구상에 추가하지 않는다. 현재 진입 후보/반입가치 문턱은 변경하지 않는다.

## 9. 앞으로 구현 승인을 받는다면 확인할 기준

첫 비교 대상으로 같은 보호등급의 기동/균형/중장/야전정비4스타일과 기존 라이플의 대표5역할(범용·안정·중량·근접고연사·정밀)을 선정할 수 있다. M16 점사·기관단총·안면별 보호·EMP는 별도 확장 후보다. 교체형 리그는 제안에서 제외한다. 전 티어에 같은 개수의 제품을 복제할 필요는 없다.

검토할 항목은 다음과 같다.

1. 같은 탄·같은 부위·같은 거리에서 기본 성능과 명중 난도를 비교하고, 움직이는 표적·다수 표적·엄폐 노출을 나눠 본다. 평균 DPS 하나로 결정하지 않는다.
2. 같은 보호등급의 동일 보호 부위에서 관통 기준을 유지한다. 빈 상태와 전리품을 가득 채운 상태의 이동·취급, 연속 피격, 수리 뒤 다음 출격을 별도로 비교한다.
3. 비슷한 준비 예산에서 실제 유지비까지 함께 비교한다. 구매가뿐 아니라 탄약 소비·수리·소모품·탈출 생존을 함께 보며, 정비형은 반복 출격에서 실제 장점이 있는지 확인한다.
4. 무부품 기본 총과 합리적인 가격의 부품 총을 구분해 비교한다. 희귀 개체 옵션의 좋은 추첨만으로 모델의 약점이 사라지지 않게 한다.
5. 전투 조건이 바뀌었을 때 우위가 뒤집히는지 확인한다. 서로 다른 두 역할이 항상 같은 총/방어구에 지면 역할 또는 수치를 다시 정한다.
6. 탑다운 실제 카메라에서 총성·발사 리듬·피격·실루엣만으로 차이가 읽히는지, 헬멧의 원래 헤어색과 건물/환경의 가독성을 해치지 않는지 본다.

현재는 위 기준을 **실행하지 않았으며** 수치 밸런스·실전 재미·새로운 방호 체계는 미검증이다. 이번 완료 범위는 원문 보존, 기존 구현 대조, 역할 구상과 독립 문서 검토다.
