# 실제 입력 확인

2026-10-19, 최종 CinematicAfter 실행본의 격리 저장에서 직접 키보드/마우스를 입력하고 매 단계 실제 창 화면을 확인했다.

- PASS Space 1회 입력으로 A맵 진입 대사 1/2 → 2/2, 넓은 장면 → 근접 장면 전환.
- PASS 대화 기록 버튼으로 화자 이름과 현재까지의 두 대사 표시.
- PASS 기록 창에서 Space를 눌러도 마지막 대사를 마치거나 게임으로 빠져나가지 않음.
- PASS Escape로 기록 창만 닫고 같은 대사 유지.
- PASS Escape로 건너뛰기 확인 창 표시.
- PASS 계속 보기로 건너뛰기를 취소하고 같은 대사 유지.
- PASS 다시 확인 창을 열어 건너뛰기 확정 후 원래 게임 카메라와 HUD로 복귀.

증빙: after_manual_history.png, after_manual_skip.png, after_manual_return.png.
자동 검증 드라이버가 남긴 원래 Frozen 상태는 그대로 보존되어 있으므로, 이 수동 확인을 이동 재개 실험으로 주장하지 않는다. 시간/입력/공격/재장전/적 상태의 복원은 runtime_checks.txt의 별도 실측 결과로 확인했다.
