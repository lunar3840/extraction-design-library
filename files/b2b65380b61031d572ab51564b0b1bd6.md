# 연결 거부 재발 — 서버 없이 여는 로컬 HTML 제공

2026-10-23 KST. 사용자 화면에서 연결 거부 재발. 진단 환경에서는 PID65728이 포트8878에 계속 연결돼 있어 서버 종료라고 확정할 수 없다. 사용자 브라우저와 실행 호스트의 localhost 연결 경로 차이 여부도 미확정이다.

사용자 목적은 라이브러리 열람이다. HTML에 CSS·스크립트·검색 색인을 포함해 파일을 직접 열 때 서버 요청 없이 탐색할 수 있도록 보완했다. 이미지와 원문은 프로젝트 안의 실제 상대 경로로 연결한다. 라이브러리 열기.cmd는 색인을 재생성한 뒤 HTML을 연다. Node가 없는 PC에서도 이미 생성된 HTML은 직접 열 수 있다. 새 기록 반영에는 생성기 실행이 필요하다.

변경 전 app.js/index.html/실행기는 source_before에 보존했다. 이번 사용자 오류 이미지는 메시지에 있지만 로컬 첨부 경로가 제공되지 않았고, 브라우저 제어 도구도 없어 실제 전후 캡처는 미확보다. HTTP 정상 응답을 사용자 화면 성공으로 간주하지 않는다.
