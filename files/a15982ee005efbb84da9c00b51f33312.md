# 기존 Figma 인벤토리 키트 Unity 적용 및 오퍼레이터 영역 정리

작업일: 2026-10-23 (Asia/Seoul)

## 사용자 지시와 기획 의도

중단했던 기존 Figma 인벤토리 UI Kit의 Unity 적용을 재개했다. Unity에서 별도로 만든 외형 대신 승인된 키트의 배치, 서체, 명암, 슬롯 간격, 티어 색, 마우스 정보창을 사용한다. 후속 지시에 따라 왼쪽 오퍼레이터의 큰 배경판은 없애고, 헬멧·방탄복·배낭의 빈 슬롯 안내 아이콘은 옅은 무채색 자국처럼 표현한다. 캐릭터와 장비 영역 크기는 유지한다.

## 변경 전 상태와 문제점

- 기존 Unity 화면은 Figma와 열 너비, 서체, 퀵슬롯 위치 및 표면 표현이 달랐다.
- 작은 슬롯의 부가 정보는 앞선 요구대로 슬롯 색과 외곽선, 큰 아이콘, 우하단 수량 중심으로 정리한다.
- 오퍼레이터 뒤의 큰 반투명 패널과 색 있는 빈 장비 아이콘은 캐릭터보다 무겁게 보였다.

실제 코드 수정 전에 before_inventory/storage/loot.png를 저장했다. 후속 지시의 변경 전 화면은 실제 중간 결과 after_r03_inventory.png를 before_operator_backplate.png로 복사해 보존했다. 재구성 이미지가 아니다. 애니메이션 프레임과 별도 검증 프로필의 항목 식별자는 달라질 수 있으나 해상도, UI 배율, 씬과 기본 카메라 구도를 유지했다.

## 적용한 디자인과 구현 방식

원본: [EXTRACTION · Modern Glass UI Kit / Inventory](https://www.figma.com/design/KUD4t84BL1S77c3cnb8co0?node-id=105-2987)

- 현재 프로젝트는 IMGUI다. 기존 편집 가능한 Figma 노드의 수치와 에셋을 로컬 네이티브 UI로 옮겼으며, UXML/USS 커넥터를 적용했다고 주장하지 않는다.
- 1920×1080 기준640/640/528px 열과24px 간격,92px 슬롯과8px 간격, 가방 아래 퀵슬롯, Noto Sans KR 서체를 적용했다. 무기·동료 칩 등 실제 게임에만 존재하는 조작은 같은 장비 카드 계열에 배치했다.
- 6단계 파스텔 토큰을 슬롯 바탕과 외곽선, 마우스 정보창에 연결했다. 슬롯은 큰 아이콘과 우하단 수량으로 정리하고 의료 소모량 등은 정보창에서 실제 데이터로 제공한다.
- 장면 카메라만 별도 저해상도로 렌더링하여 블러 배경을 만들었다. HUD를 다시 캡처하지 않으며, 인벤토리를 닫으면 추가 캡처를 중지한다.
- 원본 Figma의105:3012는 자식과 위치를 보존한 채 채움·외곽선·효과만 제거했다.105:3018/3019/3020의 Image 인스턴스는 원본 컴포넌트 연결을 유지하고 무채색 및30% 불투명도로 수정했다. 다른 아이템의 원본 에셋과 티어 토큰은 변경하지 않았다.
- Unity에서도 큰 오퍼레이터 패널만 그리지 않으며, 동일한 SVG 윤곽에서 만든 별도 무채색 안내 에셋을 빈 슬롯에만30% 불투명도로 사용한다. 실제 장착 아이템의 이미지와 티어 표현은 유지한다.
- 검증 중 드러난 소스 창의 그리기 순서, 버튼 중앙 이음선, 상세창 병행 시 루팅창의 불필요한 가로 스크롤을 수정했다. 실제6×6 수납 용량 및 이동·장착 규칙을 변경하지 않았다.

## 확인 결과

- 실제 Windows Unity Editor Play1920×1080에서 인벤토리, 보관함, 상점 연동,6단계 티어 루팅창, 마우스 정보창과 상세창을 확인했다.
- 실제 OS 마우스 드래그로 응급 주사기를2,0에서5,5로 이동했다. 같은 아이템 식별자661e38a26f3743ac969041d516064374 및 수량1을 유지했다.
- 최종 수정 후13개 배치·서체 확인과 블러 준비 상태를 다시 통과했다. 기존 hover 계약33개도 통과했다.
- 컴파일 오류0개, 기존 경고21개. 최종 검증 로그의 연속 전체 범위에서 컴파일 오류 및 예외 헤더0개. 기존 파티클 곡선 경고는 남아 있으며 별도 기록했다.
- 칩 장착/해제 제한, 보관함·사망·입력 잠금, 루팅 전송/장착/수색 시계, hover/drag 연결, 공용 HUD 배율 보존을 코드 비교로 확인했다. 최신 칩 테스트 설정도 보존했다.
- 8개 해상도는 수학적 배치 검사이며8개의 실제 렌더 검사를 의미하지 않는다. 별도 실행 빌드 및 모든 플랫폼 성능 검증은 이번 범위에 포함하지 않는다.
