# A맵 v0.8 중복 표면 수정 / 지형 높낮이 조사

## 사용자 지시와 범위

1. 첨부 화면처럼 객체 표면이 겹쳐 깜빡이는 현상을 확인하고 수정합니다.
2. 도로만 높아진 것인지 지형 전체가 높아진 것인지 확인해서 답합니다. **지형과 도로의 고저차 설계는 이번에 수정하지 않습니다.**
3. 메인이 범위·원본 보존·Unity 실행·통합 검토, Sol high가 수정 제작, 별도 Sol high가 독립 검증을 담당합니다.

## 변경 전 상태 / 원인

- `GROUND_BASE`는 상면 Y=0의 평면 지반이며, 도로는 노드 높이 0~12m를 잇는 독립 경사판입니다. 그 아래를 수직 기초로 채웠을 뿐 빈 구역까지 연결된 자연 지형은 아닙니다.
- Y=0 도로와 지반의 상면, 노드에서 만나는 도로, 건물·중계 공터의 바닥과 접근 도로에 같은 평면의 중복 표면이 있습니다.
- 기존 검사에서는 이동 경로와 에셋 교체 후 충돌/기준점 보존을 확인했지만 렌더링 표면의 겹침을 별도로 검출하지 못했습니다.

## 변경 전 증빙

- 사용자의 원본 첨부 이미지를 `before_user_report.png`로 보관했습니다. 이후 촬영한 다른 시점과 동일 화면이라고 주장하지 않습니다.
- 원본 저장 A v0.8 씬/프리팹을 해시가 같은 검증 프로젝트 사본으로 복사해 실제 수정 전에 Unity 렌더 6장을 저장했습니다.
- `before_overview.png`, `before_south_ground.png`, `before_south_ground_shift.png`, `before_junction.png`, `before_north_elevation.png`, `before_hall.png`.
- 두 south_ground 시점은 카메라를 0.3m 옮긴 대응 시점으로, 각 시점별 before/after 카메라는 동일합니다. 전체 해상도 1600×1000, 동일 조명입니다.
- 원본 Assets/Escape·Packages·ProjectSettings 960개 파일 SHA-256은 `original_manifest.json`, 주요 수정 후보의 원본은 `work/stage-a-overlap-v081/Backup/`에 보관했습니다.
- 사용자가 열어둔 원본 에디터의 미저장 상태는 덮어쓰거나 전환하지 않습니다.

## 수정 계획 / 기대 효과

충돌체·논리 기준점·지형/도로 높이를 유지하면서 생성 블록의 중복 렌더 표면을 정리합니다. 임의로 도로를 띄우거나 렌더 순서만 덮어쓰는 방식은 사용하지 않습니다. 개별 에셋 교체 구조와 사용자 override를 보존합니다.

## 최종 변경 / 검증

### 실제 변경

- `StageABlockoutVisualOverlapFixV081.cs`: 생성 박스의 여섯 방향 면을 검사해 같은 방향의 공면 중복을 다각형 차집합으로 잘라냈습니다. 사용자 override 프리팹은 건드리지 않습니다.
- `StageABlockoutStructureV08.cs`: 최초 생성과 전체 외형 재생성 완료 후 정리를 한 번만 실행하도록 연결했습니다. 원래 도면 좌표, 생성 파라미터, 충돌체 배치 코드는 바꾸지 않았습니다.
- `StageABlockoutSemanticAnchorEditor.cs` / `StageV081VisualEditing.cs`: 슬롯 교체 후 주변 생성 표면을 다시 정리하고 새 메시를 별도 에셋으로 저장합니다. 원래 외형으로 복원할 때 잘린 바닥 구멍이 남지 않도록 재계산합니다.
- 기존 A v0.8 프리팹의 메시 참조를 갱신했습니다. 2,163개 생성 메시를 `Generated_v081`에 따로 저장하며 맵을 하나의 메시로 합치지 않았습니다. 객체/기준점/충돌 구조는 유지합니다.
