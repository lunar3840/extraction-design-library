작업일: 2026-10-23. 범위: 기존 인벤토리 Figma 시안의 좌하단 상태 영역과 재사용 컴포넌트.

사용자 지시: 첨부한 타르코프 예시를 참고해 무게·체력·수분·에너지 아이콘과 현재/최대 수치를 배치한다. 현재값을 크게 강조하고 수분·에너지 증감을 파스텔 빨강·파랑과 +/−로 구분한다. 예시의 개별 게임 수치·규칙은 이 게임의 규칙으로 옮기지 않는다.

현재 문제: 체력 막대와 별도 작은 중량 문구만 있어 네 상태를 함께 읽기 어렵다. 변경 전 공식 Figma 전체 화면을 `before_figma.png`에 저장했다.

수용 기준: 좌측 캐릭터·장비 배치를 유지한다. 4열 상태 패널에서 현재값이 최대값보다 크다. 아이콘은 수정 가능한 벡터/컴포넌트이고 수치·문구도 편집 가능하다. 자연 소모, 즉시 회복, 거점의 변화 없음, 부족 경고 상태를 준비한다. 기존 Noto Sans KR·색/간격/유리 효과 토큰을 우선 재사용한다.

실제 게임 값 확인: 무게=Bag.Weight/MaxWeight(kg, 최대는 기준 하중), 체력=Health/EffectiveMaxHealth, 수분=Thirst/MaxThirst, 에너지=Hunger/MaxHunger. 외상·성장으로 최대치가 달라질 수 있다. StageA 기본 정지 소모 예시는 수분−9.0/분, 에너지−3.0/분. 음식/물은 즉시 회복하므로 +회복량에 /분을 붙이지 않는다. 거점은 자동 소모0이다.

후속 지시: 상태명은 아이콘으로 대체하고 숫자를 아이콘 오른쪽에 놓는다. 증감을 아래 별도 행에 두지 말고 첨부한 타르코프의 우측 작은 수치 묶음 배치를 따른다. 해당 상태 부분의 백플레이트도 제거한다.

제작 방식: 기존 하트·수분·번개 벡터를 재사용하고 무게 아이콘만 새 SVG 벡터로 만들었다. 4개 아이콘 컴포넌트, 6개 지표 변형(일반/부족 × 감소/회복/변화 없음), 4개 상태 패널(출격/거점/섭취 직후/부족)을 구성했다. 색·간격·서체 토큰과 원본 컴포넌트 연결을 유지한다. 수치와 아이콘은 각각 텍스트 속성·아이콘 교체 속성으로 편집할 수 있다.

최종 배치: `아이콘(20px) → 현재값(26px) → 작은 우측 묶음`이다. 우측 묶음 위쪽은 최대값, 아래쪽은 증감치이며 모두12px이다. 증감치가 현재값 아래로 내려가지 않는다. 소모는 파스텔 빨강과 −기호, 즉시 회복은 파스텔 파랑과 +기호를 함께 쓴다. 무게·체력의 불필요한 보조 문구는 없앴다. 각 지표136×32px, 전체592×32px이며 좌측 하단 기존 footer 기준선에 맞췄다. 캐릭터와 장비 영역의 크기·위치는 유지한다.

백플레이트: 패널 바탕·테두리·배경 흐림·패널 그림자를 모두 제거했다. 글자와 아이콘에만 기존 가독성 그림자를 재사용하여 게임 배경 위에서 읽히도록 했다. 검토 보드의 회색 캔버스는 화면 배경을 대신하는 검토용이며 게임에 들어가는 패널 바탕이 아니다.

증빙: before_figma.png는 변경 전 공식 스크린샷, after_figma_initial.png/after_states_initial.png는 첫 상하 배치다. before_inline_refinement.png는 그 실제 첫 시안 캡처 복사, before_reference_alignment.png/before_reference_states.png는 하단 증감 행을 쓰던 실제 중간 시안 캡처 복사다. 각 단계의 원본·생성 ID와 검증은 component-build.json, composition.json, inline-*.json, reference-*.json에 남긴다. 최종 after_figma.png/after_states.png는 실제 공식 Figma 캡처로 확인한다. 이미지 전체를 UI 레이어로 삽입하지 않았고, 기존 캐릭터·아이템의 개별 래스터 에셋만 유지했다.

범위: 이번 요청의 Figma 시안과 UI 키트만 수정했다. Unity 편집기·코드·사용자 세이브는 조작하지 않았으며 게임 반영 또는 Play 검증 완료로 주장하지 않는다.


검증 완료: 최종 공식 캡처에서 아이콘·현재값의 좌우 정렬, 우측 최대값/증감치 묶음, 백플레이트 제거를 확인했다. 6개 지표 변형과4개 상태 패널은 구조 검사PASS이며, 숫자·메타정보 폭 초과0개다. 서체는 Noto Sans KR이고 현재값26px가 최대값12px보다 크다. 최종 화면의 현재값·최대값·증감치에 잘림이나 겹침이 없다. 위아래 배치와 하단 변화율을 사용하던 중간 시안은 최종 시안으로 사용하지 않는다. 전후 PNG와 이 변경 기록 저장까지 완료했다.
