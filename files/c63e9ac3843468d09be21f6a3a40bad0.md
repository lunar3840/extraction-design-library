# 착용 외형 재진단

사용자 지적: 헬멧 측면이 납작하고 방탄복의 여러 부분이 어긋나 보임. 이전 기능 검사 통과를 외형 완성으로 해석하면 안 됩니다. 현재 적용된 방어구 외형은 추가 작업이 필요한 상태입니다.

## 머리 비교

`Helmet-Side-Diagnostic.png`는 같은 각도·크기로 **원래 캐릭터 / 머리카락만 숨긴 캐릭터 / 현재 헬멧 착용**을 렌더링한 비교입니다. 진단용 그림에서는 방탄복과 옷 가림을 적용하지 않았습니다.

`Face_BlendShapes`는 전체 두상이 아니라 뒤가 열린 얼굴 부분입니다. 원래 헤어 메시가 두피와 옆·뒷머리 볼륨도 담당합니다. 얼굴 부분의 깊이를 기준으로 헬멧·덮개를 맞추면서 원래 머리 깊이를 충분히 반영하지 못했습니다.

UnityChan 동일 자세의 실제 메시 측정(모델 좌표, 긴 꼬리머리와 머리 장식 제외):

| 범위 | 너비 | 높이 | 앞뒤 깊이 |
|---|---:|---:|---:|
| 얼굴 메시만 | 0.45 | 0.45 | 0.24 |
| 얼굴 + 머리 본에 연결된 원본 두피 헤어 | 0.57 | 0.62 | 0.51 |
| 현재 헬멧·덮개·패딩 전체 | 0.53 | 0.56 | 0.43 |

머리 본의 크기를 바꾸지 않았다는 사실만으로 원래 두상 윤곽을 보존했다고 말할 수 없습니다. 원래 볼륨을 담당하던 헤어를 숨기고 대체 메시를 축약한 영향이 있습니다. 다음 피팅은 얼굴만의 범위가 아닌 원래 전체 두상과 귀·목 위치를 기준으로 해야 합니다.

## 방탄복

착용 프리뷰에서 옆구리·허리의 원래 옷이 방탄복 밖으로 튀어나오고 어깨끈이 체형과 맞지 않습니다. 기존 가림 처리는 몸통 본 가중치/높이/면 방향을 기준으로 삼각형 일부만 없애므로 옷의 경계가 거칠게 남습니다. Chest에 붙인 소품의 단순 크기 조정만으로 SD 캐릭터의 넓은 옷과 변형을 따라갈 수 없습니다.

몸통의 실제 표면과 어깨 위치에 맞춰 방탄복 형태를 수정하고, 옷 가림 영역도 방탄복이 실제 덮는 영역에 맞춰 다시 설계해야 합니다. 이 진단에서는 추가로 원본 프로젝트 외형을 수정하지 않았습니다.
