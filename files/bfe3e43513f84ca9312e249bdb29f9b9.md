## 사용자 지시 및 기획 의도
다른 탭 완료 작업도 지침 저장에 그치지 않고 기존 주제의 후속 회차로 반영한다. 원문·전후 이미지·실제 게시 확인을 포함한다. 메뉴의 '디자/인', '경/제' 같은 단어 중간 줄바꿈을 없앤다. 후속 지시로 메인 목록에 가벼운 대표 썸네일 몇 장을 자연스럽게 삽입하고 이름 없는 예약 작업을 명확히 표시한다.

## 변경 전
수집/조직 빌드가 과거1043건 색인에 고정되어 새 작업을 읽지 않았다. library_topic_id 메타데이터가 그룹화에 반영되지 않았다. 대표 이미지는 전후 스크린샷 탭에만 있었으며, 메뉴의 직접 텍스트 노드가 한글 음절 중간에서 줄바꿈됐다. 변경 전 실제 게시 화면은 before_library.png.

## 실제 변경과 방법
- 최신 증분 데이터 경로와 기존 이관 fallback을 분리했다. 준비된 CHANGE_RECORD를 수집하고 미확인 작업은 CANDIDATES.json의 pending에 둔다. library_ready는 작업 완료 검토 표시이며 게시 성공 표시는 아니다.
- 기존 주제 ID/분야/소분류/자료 성격/회차 요약을 읽으며 '지시 회차'와 '완료 작업 후속 회차'를 구분한다. 기존 지시604건과 주제305개를 보존한 채 완료 기록을 연결했다.
- 누락된 인벤토리 상태 패널 Figma, Unity 적용, 간격 조정3건을 기존 inventory-figma-kit-alignment 주제로 연결했다. 라이브러리 최근3건도 hosted-planning-library 주제로 이어 붙였다. 진행 중인 raised/전체UI 작업은 이번 완료 대상에서 제외했다.
- 새 자산 업로드·해시검증 및 원문/짝이미지 공개 재조회 이후에만 색인을 마지막에 교체한다. 게시 ledger에 시각·해시·기록·검증 경로를 저장한다. 쓰기 인증은 유지하며 비밀값을 소스/기록/예약 프롬프트에 저장하지 않는다.
- 대표 전후 이미지 우선 최대3장을 400×225 이내/품질55 WebP 썸네일로 생성하고 지연 로딩한다. 상세1440px/품질78 및 로컬 원본은 유지한다. 이미지를 누르면 주제·회차·원문이 열린다. 자료가 없는 카드에 허위 이미지를 붙이지 않는다.
- 메뉴는 단어별 nowrap과 단어/중점 경계의 줄바꿈 기회로 구성하고 숫자 영역 폭은 유지한다.
- 기존 automation-2를 중복 없이 하루1회 유지하고 이름을 '익스트랙션 기획 라이브러리 — 새 작업 수집·게시 확인 (매일)'로 갱신했다. MD파일 탭이 실행 대상이다. 로컬 자료 접근/앱 실행 상태에 따라 작업이 보류될 수 있으며 등록 자체를 게시 성공으로 간주하지 않는다.
