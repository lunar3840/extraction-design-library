# DMZ 참고 반투명 HUD 독립 시각 검토

- 검토일: 2026-10-22
- 대상: Figma `KUD4t84BL1S77c3cnb8co0`, 페이지 `11:711`, 비교 프레임 `103:2538`의 1920×1080 내보내기
- 비교: `before_project_export.png` → `after_project_export.png`
- 결과: **현재 비교 화면에서 통과**

## 확인 결과

1. 지역명, 작전 시간, 무게, 목표·탈출 안내의 배경이 이전보다 옅어져 게임 배경이 더 잘 비친다. 흰 글자와 아이콘의 대비는 유지되어, 패널의 검은 덩어리감이 줄었다.
2. 상호작용 안내는 배경의 투명도가 높아졌지만, 현재 화면의 밝은 바닥 위에서도 키와 문구를 구별할 수 있다. 글자 크기나 간격이 줄어든 흔적은 없다.
3. 스킬의 원형 배경과 하단 설명 배경도 옅어졌다. 링, 아이콘, 키 표시는 여전히 선명하며 슬롯 확대 상태가 유지되어 있다.
4. 무기 중앙 하단, 소모품 우측 2×2, 스킬 우측 하단의 배치가 보존됐다. 무기 탄약, 소모품 키 3·4·5·6 및 수량, 스킬의 키와 설명에서 정보 소실이나 새 겹침·잘림은 보이지 않는다.
5. 112px 수분·에너지, 캐릭터 위 체력·스태미너, 기존 라운드와 글자 형태는 시각적으로 동일하다. 전투 화면의 중앙 공간도 추가로 침범하지 않는다.

## 검토 범위와 한계

- 이 평가는 실제 Figma 전후 PNG의 독립 시각 비교다. 내부 속성의 정확한 수치는 작업 담당자의 변경 내역과 구분해 `design-system-state.json`에 기록한다.
- 현재 주간 배경, 1920×1080, 표시된 정상 상태에서 확인했다. 야간·역광·눈밭·강한 광원, 다른 해상도, 긴 문구, 경고 상태와 실제 Unity 런타임까지 검증한 결과는 아니다.
- 현재 화면에서 추가 수정을 요구할 결함은 발견하지 않았다.
