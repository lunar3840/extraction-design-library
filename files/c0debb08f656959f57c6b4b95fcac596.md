# 기지 확장 — 미래 하우징·동료 생활 공간 확보

## 사용자 지시

이전 16×14m 기지를 나중에 하우징과 현현 동료들의 생활 공간을 넣을 수 있도록 확대한다. 이번에는 공간 확보만 하며 하우징·가구 배치·동료 NPC/생활 AI는 구현하지 않는다.

## 기획 의도 / 변경 전 문제

- 이전 기지는 출격·보관·보급·의뢰·작업대만 들어가는 224㎡ 규모였다.
- 시설 크기나 캐릭터 비율을 전체 스케일로 키우면 생활 공간 확보가 아니라 모든 물체가 거대해지므로 그렇게 하지 않는다.
- 출격 준비가 불필요하게 멀어지지 않도록 중앙 시설과 도착 위치는 유지하고 외곽을 확장한다.

## 실제 변경

- 바닥 16×14m → **32×28m**, 면적 **224㎡ → 896㎡(4배)**. 이번 첫 확장값이며 향후 주거 배치에 따라 조정할 수 있다.
- 바닥 상면 y=0, 기지 Root 배율 1 유지.
- Spawn `(0,.05,-2.6)` 및 다섯 접근점·기존 시설의 크기와 위치 유지.
- 양옆 각각 7.1×18.8m, 남·북 각각 14.8×5.3m의 빈 바닥 구역을 톤과 얇은 선으로 구분했다. 주거 시스템의 확정 토지/방 규칙이 아닌 임시 공간 구획이다.
- 기존 내부 경계가 새 공간 진입을 막지 않도록 외곽 벽·난간·캡·기둥·벽부착 조명/배관/배수 디테일을 새 경계로 이동했다.
- 북/동 카메라 쪽은 0.78m 난간, 남/서 배경 쪽은 2.08m 벽을 유지했다. 재질의 역할과 기존 기지 콘셉트는 유지했다.
- 새 바닥 구획은 비충돌 장식이다. 중앙/양옆/뒤쪽/북쪽을 걸어서 오갈 수 있도록 내부 벽을 만들지 않았다.
- HUD의 `크래들 · 소형 기지`를 `크래들 · 기지`로 변경했다.
- 기존 TAB/F, 출격 UI, 저장, 동료 칩, 맵/적 배치 및 캐릭터 외형은 변경하지 않는다.

## 검증 및 원본 통합

- **독립 확장 검사 103개 PASS / RESULT PASS**: `EXPANSION_CHECKS.txt`. 실제 PlayerMotor와 CharacterController로 네 예약 구역·네 모서리 왕복, 추락 없음, 사방 외곽 이탈 차단, 17개 기존 solid 시설과 접근점 보존을 확인했다. Unity batch exit 0 (`geometry_checks.log`).
- **기존 기지 흐름 검사 60개 PASS**: `BASE_FLOW_CHECKS.txt`. 새 슬롯/불러오기, 기본 기지 진입, TAB 전환과 위치 보존, 각 시설 접근, 출격 준비, 저장 실패/재시도, B맵 출격 및 추출/사망 후 귀환을 확인했다. Unity batch exit 0 (`base_flow_regression.log`). **B 전용 회귀 검사이며 A맵 출격을 검증한 결과가 아니다.** 이번 변경은 A맵·진입점·AI·동료 칩 로직을 수정하지 않았다.
- 메인이 전후 도착점·전경 및 추가 구역 5개 렌더를 직접 확인했다. 기존 중앙 구역의 크기는 유지되고 빈 주변 공간이 확대되었으며, 카메라 쪽 낮은 난간과 플레이어 식별을 확인했다. 실제 전체 HUD 화면의 검수로 확대 해석하지 않는다.
- 수정 직전 원본 두 런타임 파일의 SHA-256을 `source_before/`와 다시 대조해 동일함을 확인한 후, 검증한 두 런타임 파일과 신규 Editor 검사/.meta만 원본에 반영했다. 통합 후 세 C# 파일이 staging과 일치하고 신규 .meta가 검증 프로젝트와 동일함을 재확인했다.
- 원본 Unity 자동 컴파일 및 assembly reload 완료를 확인했다. `Assembly-CSharp.dll` 2026-10-16 14:07:46, `Assembly-CSharp-Editor.dll` 14:07:51(KST) 갱신 및 해당 컴파일 구간 C# 오류 없음. `INTEGRATION_CHECKS.txt` 참조.
- 원본 Unity의 재생을 중단하거나 씬을 열고 저장하지 않았고, 사용자 프로필/세이브를 변경하지 않았다. 기지는 실행 중 생성되는 구조이므로 이미 생성된 기지는 다음 재생 시작 때 새 크기로 생성된다.
- 처음 증빙 도구를 컴파일할 때 `PlayerSettings` 타입명 중복을 발견해 검증용 도구에서 정규화된 타입명으로 수정하고, 재실행에 성공한 뒤 before를 촬영했다. 제품의 변경 전 이미지는 제품 수정 전에 확보했으며 재구성본이 아니다.
- 하우징·방/가구 배치·동료 현현/생활 AI는 아직 없다. 빈 공간은 후속 배치에 활용할 준비 영역이며, 특정 생활 인원이나 향후 하우징 규칙이 확정되었다는 의미가 아니다.
