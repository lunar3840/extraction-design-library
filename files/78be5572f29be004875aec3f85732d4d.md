# D05 2차 경계·입면 4종 — 독립 설계·Tripo 프리뷰 검토

2026-10-12. 사용자 추가 생성 승인 뒤, 기존 10종과 현행 V33/D04를 대조해 후보를 선별하고, 최종 **A′·B·C·E′ 4종**의 저장된 Tripo 앞·측면·뒷면 프리뷰를 독립 검토했다. 이 문서는 원화 및 UI 프리뷰에서 보이는 형태의 검토일 뿐 원본 GLB 검수나 Unity 배치·충돌 검증 기록이 아니다. 본인은 이 문서만 수정했고 브라우저·크레딧·Unity 상태를 변경하지 않았다.

## 왜 연결·입면 기능군을 나누는가

- 현행 V33 `StageAEnclosuresV33Placement.cs`는 각 긴 경계를 3.5m 이하의 단순 Box 조각으로 분할하고, **12개 항상 열린 게이트에는 표식 anchor만** 만든다. D05 YardWall은 불투명 일자 3m 한 칸이므로 꺾임·건물 접속·열린 입구의 구조 언어가 부족하다.
- CN/WC/SC의 불투명 콘크리트 벽은 높이 2.2m, 두께 0.28m이다. PC/YC는 별도 충돌체를 가진 투시형 철망(높이 1.8m)이다. 같은 불투명 기둥을 PC/YC까지 붙이면 시야를 바꿀 수 있다. CN/WC/SC 게이트 6곳과 PC/YC 6곳(그중 `PC_G3`,`YC_G3`은 파손 틈)은 시각적·기능적으로 같은 부품으로 다루지 않는다.
- D04는 68동 지붕과 얕은 처마·기둥을 다양화했으나 공용 벽 재질/창 반복이 남는다. 단독으로 길을 막는 또 다른 벽 대신 **기존 건물의 코너/기초에 붙는 두 가지 다른 입면 언어**를 만든다. 진료소 권역의 회반죽·노출벽돌과 산업동의 콘크리트·벽돌은 형태·사용 구역을 분리하면 중복이 아니다.
- **고정 직각 코너의 범용성은 낮다.** 실제 불투명 V33의 연속 벽-벽 꺾임은 CN_W4/W5 약 83.4°, WC_W3/W4 약 64.3°, WC_W6/W7 정확히 90°, WC_W7/W8 약 29.3°, SC_W5/W6 약 58.6°다. 정확한 직각은 TOOLS 문 여유 때문에 x=106으로 보정된 WC_W6/W7 `(106,204)` 한 곳뿐이다. `batch2/concepts/YardCorner_2m.png`는 시안으로만 보관하고 Tripo 생성에서 제외한다. A는 **벽날개 없는 사각 단일 접합기둥**으로 바꾼다. 이 형상도 임의각 벽과 자동 정합되지 않으며 끝단 절단/캡·실측이 필요하다.

## 이미지 생성용 공통 제약과 개별 프롬프트

각 항목을 **한 장에 하나의 독립 물체**로 만들고 3/4 약간 위 시점, 중성 회색 배경, 고른 빛, 바닥/건물/도로/캐릭터/글씨/브랜드/배경 소품 없음. 재질은 침수된 오래된 공공 정비지구: 낡은 콘크리트·회녹 철재·바랜 회반죽·일부 붉은 벽돌, 녹과 물때는 하단·접합부에 국소적으로. 실제 사진 같은 작은 볼트보다 탑뷰에서 보이는 기둥·띠·경계 면을 우선한다. 콘셉트 이미지를 Tripo에 넣기 전에 앞/옆/후 실루엣을 육안 검사한다. 치수는 **설계 목표**이며 Tripo가 자동으로 실측 보증하지 않는다.

## 저장된 원화의 독립 시각 점검

- `batch2/concepts/YardCorner_2m.png`: 골강판/기단/중심기둥의 재질 연결은 좋으나 정직한 90° 양쪽 긴 벽이다. 위 실측 각도와 달라 **3D 제작 제외**가 적절하다.
- `batch2/concepts/YardGateShoulder_2m.png`: 회녹 강판·콘크리트 기단이 YardWall과 이어지고 열린 쪽 힌지가 보인다. 그러나 복귀벽이 그림에서 꽤 길고 끝기둥도 두꺼워 보인다. Tripo 결과가 실제 1.0~1.3m 짧은 복귀인지 검증 전에는 통로 폭 보존을 주장할 수 없다. 필요하면 기존 벽 방향으로만 끝단을 trim하여 접속하고 열린 공간으로 기둥이 튀어나오지 않게 한다.
- `batch2/concepts/ClinicPlasterCorner_3m.png`: 갈라진 회반죽·노출 적벽돌·청록 기단의 의료권 재료 구별은 뚜렷하다. 다만 그림의 L 형상은 얇은 덧댐보다 깊이 있는 완전 벽 같고 창도 명백하게 그려져 있다. 실제 기존 직사각형 진료소 코너의 벽/창을 계측한 뒤 메시 일부를 **대체 또는 접속**할 수 있을 때만 후보가 된다. 기존 벽에 통째로 겹쳐 붙이는 방식은 불허한다.

이 절까지는 원화만으로 계획한 사전 단계의 판정이었다. 이어지는 12장 Tripo 프리뷰로 대략적인 후면 실루엣을 추가 확인했지만, 실제 치수·두께, UV, Unity 적용 가능성은 여전히 미확인이다.
