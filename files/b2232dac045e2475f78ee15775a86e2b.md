# 지침 적용 범위 정리

## 사용자 지시 요약

현재 게임에 해당하지 않는 다른 프로젝트 전용 지침을 이 작업 공간에 보관하지 않는다. 어느 프로젝트에 적용되는지 모호한 지침은 사용자에게 알리고 확인 전까지 보류한다.

## 기획 의도와 해결하려는 문제

다른 프로젝트의 세부 규칙이 현재 게임의 지속 지침으로 남는 일을 막되, 적용 범위가 불명확한 새 자료는 임의로 판단하지 않도록 한다.

## 변경 전 상태 및 문제점

이전 응답에서 현재 게임에 필요하지 않은 별도 프로젝트 관련 세부 지침과 증빙 사본을 이 작업 공간에 추가했다. 이 기록의 `before_AGENTS_reconstructed.md`는 그 세부 지침을 제거한 직후, 일반 보류 기준을 추가하기 전 상태의 정확한 원문이다. 앞선 기록에 보존된 원문과 일치하는 파일에서 복사했으며 화면 캡처가 아니다.

## 실제 변경 및 방법

- `AGENTS.md`에서 앞서 추가한 별도 프로젝트 관련 세부 지침을 제거했다.
- 해당 세부 지침을 위해 만든 기록 폴더의 문서와 이 작업 공간 내 화면 사본을 제거했다. 사용자가 제공한 원본 자료와 다른 프로젝트 파일은 수정하지 않았다.
- `AGENTS.md`에는 출처가 모호한 지침을 사용자에게 확인하고 적용을 보류한다는 일반 절차만 추가했다.
- Unity 씬·코드·에셋은 변경하지 않았다.

## 기대 효과와 확인 결과

현재 게임에 무관한 세부 규칙을 작업 지침으로 재사용하지 않는다. 앞으로 적용 범위가 모호한 지침은 확인 전까지 보류한다. 변경 후 원문은 `after_AGENTS.md`에 보관했다.

## 화면 자료와 한계

이번 변경은 문서 지침 정리로 게임 화면 변화가 없다. 문서 편집기를 지정한 캡처 도구가 다른 창을 반환하여 전후 스크린샷을 신뢰성 있게 확보하지 못했다. 따라서 화면을 재구성해 전후 스크린샷으로 표기하지 않았다. 전후 문서 원문 사본으로 변경 내용을 검증한다.

## 수정한 주요 파일

- 이 폴더의 `before_AGENTS_reconstructed.md`, `after_AGENTS.md`, `CHANGE_RECORD.md`
