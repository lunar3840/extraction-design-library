# A맵 야외 포장·식생 D11 독립 검토

검토자는 도로와 식생 제작 파일을 수정하지 않았고, 저장된 실제 Unity 화면과 독립 검증 출력을 직접 읽어 판단한다. 최종 합격 여부는 아래 후보별 기록과 최종 결과를 구분한다.

## 기준과 보존 범위

- 변경 전 Unity 화면 25시점과 `before_editor.png`, 씬·Resources 프리팹 백업이 D11 적용 전에 저장됐다. 동일 카메라의 후속 화면과 비교한다.
- `D11_ORIGINAL_SNAPSHOT.json`은 적용 전 원본 31,150개 오브젝트의 계층 경로, 주요 직렬화 속성, 메시·재질·콜라이더 상태를 고정한다. D11 소유 루트 둘만 새로 허용한다.
- 기존 69동, 102개 실제 문, 204방향 PlayerMotor 보행, 기본 진입 B1–B4에서 7개 탈출점까지의 28개 동선, 지형·건물 충돌과 컷어웨이를 보존해야 한다.
- B4 `(141,329)`와 R8 `(202,341)`은 약 62.169m 떨어져 있고 둘 다 W5로 연결된다. R8은 위험 진입 후보이나 tier3 비활성이며, 새 식생이나 포장으로 독립 위험 진입 경험이 완성됐다고 주장하지 않는다.

## 검증 기준

- 도로: 실제 메시·마스크의 4사분면 분포, 지형 높이 추종, 중복 삼각형·뒤집힌 면·새 충돌체 여부, 문 앞과 턱의 화면 품질을 확인한다.
- 식생: CSV 위치와 실제 청크·렌더러·삼각형, 4사분면/25m 청크 분포, 지형 접지, 포장 침범, 신규 콜라이더 및 화면의 색·밀도를 확인한다. 오브젝트 수만으로 시각 합격 처리하지 않는다.
- 변경 후 실제 Play의 102문 양방향 204 lane과 야외 대표 동선, 출입·도로 접점 화면을 확인한다. 렌더링 비용은 기록하되 지정된 하드웨어 FPS 목표는 없다.

## 후보 기록

### candidate01 — 제작 내부 밀도 조건에서 중단

`COMMAND_apply_candidate01.txt`를 확인했다. 식생 생성 중 `low=65001`, `shrubs=907`, `trees=165`로 제작 내부 최소 밀도 조건을 통과하지 못했다. 결과는 완료 후보로 판단하지 않는다. `COMMAND_recover-owned.txt`는 원본 31,150개가 모두 D11 변경 전 서명과 같음을 확인한 뒤 실패한 D11 소유 후보만 버렸다고 기록한다.

### candidate02 — 기술 검사 부분 통과, 시각 보류

`VALIDATION_candidate02.txt`를 직접 읽었다. 원본 31,150개 변경 0, 도로 104,000삼각형의 지형 접지 오차·중복·뒤집힘 0, 4사분면 포장 마스크 분포, 새 콜라이더 0, 식생 109,542건/298청크/612렌더러/443,574삼각형, 지형 접지 및 예약 포장 침범 0이 확인됐다. CSV 좌표를 소수 셋째 자리로 저장해 25m 청크 경계에서 6건의 반올림 불일치가 있었다. 기존 D09 검증기는 새 D11 루트가 전체 맵에 더해진 것을 레거시 루트 범위 오류로 보고, 그 실패가 D10 요약 실패로 이어졌다. 원본 전체 서명은 별도로 일치했고 다른 레거시 실패는 없으므로 검증기는 그 정확한 두 오류만 좁혀 판정하도록 수정했다. 이 예외는 D11 실제 플레이 검사를 대체하지 않는다.

동일 시점 `before_street_west.png`/`candidate02_street_west.png`, `before_green_north.png`/`candidate02_green_north.png`, `before_entry_B4.png`/`candidate02_entry_B4.png`를 열어 비교했다. 흙길이 블록 포장으로 바뀐 효과는 분명하지만 서부·동부 보도블록이 지나치게 흰색이며, 북부·남부 아스팔트는 넓은 검은 평행 줄무늬가 반복된다. 새 식생은 수량 증가에도 녹색 풀보다 검정·남색 카드 얼룩으로 읽힌다. `candidate02_street_north.png`, `candidate02_street_south.png`, `candidate02_green_east.png`, `candidate02_green_south.png`에서도 같은 현상이 반복돼 시각 합격은 보류했다. 제작 담당에게 재질·UV·색·포장 전환 수정을 요청했다.

### candidate03 — 이전 결함은 교체됐지만 화면 품질 보류

`candidate03_overview.png`, `candidate03_street_west.png`, `candidate03_street_north.png`, `candidate03_green_north.png`, `candidate03_entry_B4.png`를 같은 `before_` 화면 및 candidate02와 직접 대조했다. 식생의 검남색은 사라졌지만 절차형 잎이 조명과 분리된 형광 연두·흰색으로 보이고, 맵 전역에 균일한 밝은 점무늬가 생겼다. 포장 베이스 텍스처에는 파손 블록이 있으나, 실제 많은 길은 거의 상수 회색 아스팔트로 출력되어 화면에서 무늬 없는 평면 띠로 읽힌다. 이것은 식생 수량과 노면 마스크 검사만으로 수용할 수 없는 시각적 결함이다. 제작 담당에게 식생의 조명·색 반응과 주 도로의 텍스처 기여를 수정 요청했다. `COMMAND_apply_candidate03.txt`는 완료지만 시각 합격은 보류한다.

### candidate04 — 독립 기술 검사 통과, 북부 길 연결 시각 결함

`VALIDATION_candidate04.txt`를 직접 읽었다. 당시 30항목 통과·실패 0으로 기록됐고 원본 31,150개 누락·추가·변경 0, 새 충돌체 0, 도로 104,000삼각형의 중복·뒤집힘 오류 0, 식생 CSV 116,885행의 청크·포장 침범 오류 0이었다. 식생은 629렌더러·1,188,864삼각형이고 4사분면에 분포했다. 다만 당시의 도로·식생 '지형 접지' 검사는 `SampleMapHeight` 함수만 참조했다. 이후 원본 `LandSurfaceFilters` 실제 메시와 그 함수가 북쪽 `(264,130)`에서 5.118m 다르다는 별도 실측이 발견됐으므로, 후보04의 접지 합격 해석은 철회한다. 검증기를 실제 원본 메시 정점·삼각형 보간 기준으로 갱신했다. 기존 D09 전체 맵 서명은 새 D11 루트 두 개를 허용하지 않으므로 `NONINHERIT_FULL_LEGACY`로 분리했고, 실제 69동·102문·28개 기본 진입–탈출 동선 등 레거시 실질 항목은 통과했다. R8의 비활성 상태와 B4 간 62.169m도 유지됐다. 이 편집 모드 검사는 신규 204문 방향 및 야외 Play 보행 검사를 대신하지 않는다.

동일 시점 25장씩의 `before_*.png`와 `candidate04_*.png`를 대조했다. `green_west`, `green_south`, `green_ruins`, `street_west`, `street_south`, `entry_B4` 등에서 후보02의 검남색 풀과 후보03의 형광 연두 풀이 해소됐고, 녹지 밀도와 노면의 노후 질감이 확실히 나아졌다. `before_green_west.png`에도 이미 있던 도로 위 검은 잡초는 새 D11 침범으로 분류하지 않는다. 건물·출입문 보호 간격 탓에 `green_north`·`green_east`에는 넓은 맨바닥 띠가 남는다.

다만 `candidate04_street_north.png`는 기존 갈색 연결길 중앙 약 6–10m가 노출되고 새 석재 포장이 양옆에서 끊긴 패치로 걸쳐 있다. `before_street_north.png`에는 하나의 연속 흙길이었으며 `candidate04_north_ridge.png`에도 부분 포장 단절이 보인다. 이는 의도적 파손보다 포장 마스크 누락으로 읽혀 화면 합격을 보류했다. 서부와 중앙의 일부 보도 외곽도 연속된 매끈한 띠여서 깨진 블록·결손 표현이 충분히 읽히지 않는다. 강 건너 `candidate04_waterworks.png`의 흙길은 전원길로 남아 있어 이 결함과 구분한다.

사용자 참조 이미지는 따뜻한 방향광, 접촉 그림자, 토양·먼지·자갈의 미세 명암, 폐허·울타리·잡초의 재질 통일감이 뚜렷하다. candidate04는 초지의 규칙적 청록 점무늬와 평탄한 녹색 지면, 반복적 블록 포장 및 기존 건물 표면 때문에 참조 품질에 도달했다고 보기 어렵다. 다만 이번 작업 범위는 침수지구의 물·교량·폐허를 유지한 야외 포장·식생 교정이며, 전 맵 재건축이나 조명 개편으로 확대해 판단하지 않는다.

### candidate05–06 — 원본 지형 높이 가정 오류를 분리

`candidate05_street_north.png`에는 갈색 원래 길의 중앙 단절이 남고, 추측성 포장 마스크 확장으로 불필요한 가로 길까지 생겼다. 이를 화면 합격으로 보지 않았다. 실제 `LandSurfaceFilters`의 삼각형을 조사한 `NORTH_ACTUAL_LAND_TRIANGLES.csv`에서 `(264,130)` 부근 원본 메시와 `SampleMapHeight`의 높이 차이가 최대 5.118m임을 확인했다. 따라서 높이 함수에만 접지한 후보04–05 도로는 실제 지형 접지를 입증하지 못하며, 함수 기반 검사 결과를 합격 근거에서 제외했다.

후보06은 실제 메시를 2m 정규 격자 하나로 합쳐 읽으려 했지만, 원본 타일 이음부의 서로 다른 높이 때문에 적용 중 중단됐다. 후보06은 완성된 씬·화면 후보로 취급하지 않는다. 원본 데이터를 임의의 공통 격자로 재구성하지 않고, 각 타일의 보존된 정점·삼각형을 직접 복제·조회하는 방식으로 후보07을 제작했다.

### candidate07 — 범위 내 화면 개선 및 최종 기술·Play 검증

아래 중간 문단의 보류·미완료 표현은 당시 검토 시점의 기록이다. 현재 최종 상태는 뒤의 최종 보완 검사와 마지막 합격 판정 문단을 기준으로 한다.

동일한 25개 `before_*.png`와 `candidate07_*.png`를 직접 비교했다. `street_north`·`north_ridge`의 갈색 길 가운데 단절은 사라지고 낡은 포장이 이어진다. 북쪽 가로 검은 이음선은 `before_`에도 있어 D11에서 새로 생긴 결함으로 분류하지 않는다. `green_west`·`green_south`·`green_ruins`, 남서 잔해, 동부 물류, B4·R8 진입, 물가와 홀 접근을 포함해 야외 대부분에 더 촘촘한 낮은 식생과 읽히는 흙길·포장이 생겼다. 새 나무가 지붕을 가리거나 문을 막는 장면, 수면 식생 침범은 이 25개 화면에서 보이지 않았다. 다만 북부·동부 건물 보호구간의 넓고 평평한 녹색 면, 일부 반복적인 포장 테두리, 기존 지형 이음선은 남는다. 사용자 고품질 참조 이미지의 조명·접촉 그림자·지면 미세재질·전체 미술 밀도에 도달했다는 뜻은 아니다.

첫 후보07 `VALIDATION_final_retained.txt`는 원본 31,150개 변경 0 등 30항목 통과, 4항목 실패였다. 실패 네 항목은 검증기가 보존된 원본 타일을 모두 66×51 정규 격자와 동일한 정점 순서로 잘못 가정한 결과였다. 실제 원본의 4개 타일은 그 가정과 다른 임의 정점 수·구성을 갖고 있었다. 대응하는 정점에서 높이 불일치 0이었어도 나머지를 `missingLand=71494`와 식생 지면 `missingTerrain=15254`로 잘못 셌다. 이를 무시하고 합격 처리하지 않았다. 검증기를 원본 각 타일의 실제 정점 배열과 첫 두 submesh 삼각형 인덱스를 정확 대조하고, 삼각형 bounding-box 인덱스와 평면 보간으로 식생 지면을 독립 확인하도록 교정했다. 높이 오차 허용치는 포장 0.005m, 식생 0.025m로 유지한다. 교정 후 재실행 결과와 실제 PlayerMotor 보행 결과를 확인하기 전에는 기술 최종 합격을 선언하지 않는다.

교정 후 재실행한 `VALIDATION_final_retained_v2.txt`를 직접 읽었다. 35항목 통과·실패 0이다. 원본 31,150개 오브젝트 누락·추가·변경 0, 포장 16타일의 원본 실제 메시 정점 대비 +0.024m 오차 0(허용 0.005m), 원본 첫 두 submesh 삼각형 인덱스·순서 불일치 0, 포장 중복·뒤집힌 삼각형 0이다. 원래 지형 타일 사이에 이미 존재하던 이음 높이 차이 비교 252건은 보존됐으며 D11이 새로 만든 이음 높이 차이는 0이다. 식생 CSV 116,860점은 원본 실제 삼각형 보간값 대비 누락·불일치 0(허용 0.025m), 포장 예약면 중심 침범 0, 전 맵 301개 25m 셀에 분포한다. 631렌더러·1,188,640삼각형, D11 재질 8개 셰이더 지원/컴파일 오류 0이고 신규 충돌체가 없다. `SampleMapHeight` 불일치 21,029개 포장 정점과 3,657개 식생 지점은 이제 실제 원본 표면의 오류로 오판하지 않고 별도 참고 수치로 기록했다. B4/R8 62.169m·R8 비활성, 69건물·102문·28기본 동선의 정적 보존 검사는 통과했다. 실제 Play 이동 검증은 별도 미완료이므로 이 결과만으로 최종 합격 처리하지 않는다.

## 최종 판정

`outdoor_play_01/OUTDOOR_PLAY.txt`와 시작·종료 화면 40장을 확인했다. 20개 진입·도로·녹지 이름의 검사에서 실제 활성 `CharacterController`와 `PlayerMotor.Simulate`로 모두 이동 성공했고, 실행 시 선택된 기본 진입은 B4였으며 R8은 무작위 스폰 후보에서 제외됐다. R8 보행은 진단 목적으로 수동 위치 지정한 경우다. 다만 검사 지점 이름 중 `power`, `workshop`, `logistics`, `waterworks`, `green_north`, `green_east`, `green_south` 등은 시작 화면에서 건물 안·벽/지붕 경계였고 `green_west`는 녹지가 아닌 포장 위다. 따라서 이 20/20을 ‘야외 녹지 20곳의 온전한 보행’으로 과장하지 않는다. 실제 열린 녹지 위치를 다시 선택한 보완 Play와 204문 방향 결과를 확인한 뒤 최종 판정을 적는다.

`play_attempt_01/D09_PLAY_VALIDATION.txt`를 직접 읽고 204개 실제 문 양방향 lane 각각의 `PlayerMotor.Simulate` 성공행을 세어 204건, 실패행 0, 최종 `originalDoorLanes=204 buildings=69`을 확인했다. `CharacterController`는 활성 상태였고 전투만 결정론적 시험을 위해 멈췄다. 기본 스폰 B2가 선택됐으며 R8 등 위험 후보는 제외됐다. 이 검사는 D11이 기존 69동·102문 출입 가능성을 막지 않았음을 뒷받침한다. 열린 초지 위를 대표하는 야외 보완 Play는 여전히 별도로 확인해야 한다.

최종 보완 `outdoor_play_02/OUTDOOR_PLAY.txt`와 대응 시작·종료 화면 40장을 직접 확인했다. 20경로 모두 실제 PlayerMotor/활성 CharacterController로 9–20m 안팎 이동에 성공했다. 진단 경로는 69개 원본 건물 footprint에서 2m 이상 떨어진 곳을 1m 간격으로 확인하도록 재선정했으며, `green_north`, `green_west`, `green_east`, `green_south` 네 경로는 실제 저초본 CSV 점 인근에서 시작하고 전 구간 포장 예약면 밖이다. 네 방향 초지의 시작·종료 8화면은 이번에는 실제 야외 지면을 보여 준다. B1–B4와 비활성 R8의 이동은 기능 점검으로 유효하나, R8은 런타임 무작위 진입으로 활성화한 것이 아니라 수동 진단 위치다. `power`, `workshop`, `logistics`의 일부 화면은 기존 지붕이 큰 면적을 차지하고 국소 투명 컷어웨이로 캐릭터가 보인다. 이 장면들의 야외 지면 시각 가독성은 제한적이지만, 검사 경로가 원본 건물 외부임을 뒤집지는 않는다. 후보 탐색 중 실제 지형 높이 조회 fallback 경고 3곳은 최종 선택 경로·배치에 쓰이지 않았으며, 맵 전역 어디에도 fallback이 없다고 주장하지 않는다.

최종 `after_*.png` 25시점과 `after_editor.png`가 저장된 것을 확인했다. 보존 후보07의 동일 시점 비교에서 북부 포장 연결, 서·남부 녹지 밀도, B4 진입로와 침수 지구·폐허의 기존 윤곽이 유지된다. 기술·Play 검사 결과와 합쳐 이번 요청 범위인 야외 빈 땅 감소와 평평한 노후 포장길의 가시적 개선은 **합격**으로 판정한다. 단, 북부·동부 건물 이격지에는 넓은 평평한 녹색 면이 남고, 보도 외곽은 아직 반복적이며, 원본 북부 타일 이음의 검은 선과 기존 도로 위 어두운 잡초가 보인다. 추가 참조 이미지 수준의 조명·접촉 그림자·재질 세부·환경 미술 통일감에 도달했다는 판정은 아니다. FPS 등 하드웨어 성능 목표는 지정되지 않았고, 631개 식생 렌더러/약 119만 식생 삼각형의 실제 기기별 비용도 별도 측정되지 않았다. B4와 R8의 독립 위험 진입 경험 역시 해결되지 않았으므로 R8은 계속 비활성으로 보존한다.
