# A맵 B4·R8 진입점 간격 — 향후 배치 기준

2026-09-17 사용자 요청: 이번 대화의 판단을 이후 A맵 배치와 수정 때 기억하고 반영한다. 지금은 설계 기록만 남기며 Unity 지형·건물·스폰 로직을 변경하지 않는다.

## 현재 상태

- A맵 전체 크기: 520m × 400m. 실제 보행 가능 면적은 건물·수로·경계벽 때문에 더 작다.
- B는 기본 진입점, R은 위험 진입점 후보, X는 탈출 지점이다. 빨간 R 표식은 위험 구역의 범위나 적·보스 위치를 뜻하지 않는다.
- 현재 출격 시 B1~B4에서만 무작위 스폰된다. R1~R8은 배치돼 있지만 선택되지 않는 자리표시자다. R 진입 해금·위험도 선택은 아직 구현 상태로 취급하지 않는다.
- B4 지도 좌표 (141,329), R8 (202,341). 직선거리 약 62m. 둘 다 W5 (168,293) 길목으로 연결되며 주요 목적지로 가는 동선이 합쳐진다. 검증된 공통 목적지 경로에서 R8은 B4보다 약 14m 더 길다.
- R8이 일부 적 배치에 더 가까운 의도는 있으나, 실제 플레이에서 별개의 위험으로 체감되는지는 아직 검증되지 않았다. 현 배치만으로는 독립 위험 진입점의 효용이 약하다.

## 이후 배치·도면 수정 시 점검

1. B4와 R8에서 출발한 플레이어가 초반에 서로 다른 길·엄폐·조우를 경험하는지 확인한다. 같은 W5 길목으로 바로 합류한다면 단순 거리 차이를 설계 차별성으로 계산하지 않는다.
2. 적 기계와 자원 탐색 중인 인간 무리의 실제 동선, 위험 노출 시간, 접근 가능한 파밍 장소·랜드마크, 탈출 선택지를 각 출발점에서 비교한다. 인간형 적은 지상에 상주하거나 철수하기보다 무리 지어 순찰·탐색한다는 시나리오를 유지한다.
3. 위험 진입점이 더 높은 위험을 주는 경우에도 그에 상응하는 접근 이점이나 보상을 명확히 설계한다. 기본 진입점에서도 무리하면 먼 퀘스트 지점에 도달할 수 있어야 한다.
4. 건물·차량·잔해·나무·엄폐물을 추가할 때 의도한 접근 차이가 사라지거나 우연히 한쪽만 불합리하게 막히지 않는지 실제 이동·시야로 확인한다. 이후 에셋 교체가 가능하도록 기존 배치 원칙을 유지한다.
5. 독립적인 초반 경험을 만들기 어렵다면 R8을 별도 진입 동선으로 재배치하거나 비활성으로 유지하는 결정을 도면 단계에서 다시 검토한다. 좌표만 멀리 옮기는 것으로 완료 처리하지 않는다.
