# A맵 V19 남측 외벽 독립 검토

## 판정

**남측 외벽의 한정된 반복 완화 작업으로 승인.** 일부 상부 창의 부분 금속 보수와 서측 하부 보수판의 높이·폭 차이가 동일 패턴의 연속감을 줄인다. 기존 창·벽 전체를 교체한 수준의 현실감 개선은 아니다.

## 화면을 직접 대조한 결과

- `before_south_front.png`/`after_south_front.png`, `before_west_windows.png`/`after_west_windows.png`, `before_east_windows.png`/`after_east_windows.png`, `before_hall_close.png`/`after_hall_close.png`를 동일 시점으로 대조했다. 상부 14개 창 중 선택한 4개에 서로 떨어진 부분 보수판이 보이고, 원래 유리는 일부 남아 있다. 서측 하부 3개 패널은 동일 폭·높이에서 불균등한 크기로 바뀌었다.
- 중앙 사람 출입구, 동측 하역문, 환기팬과 차양은 외부 화면에서 계속 읽힌다. `after_under_LoadingCanopy.png`, `after_under_RepairShelter.png`, `after_game_main_entrance_end.png`에서도 플레이어 식별과 기존 시야 확보를 직접 확인했다. 새 외벽 요소가 실내 진입이나 차양 아래의 카메라를 가리는 중대 시각 결함은 보이지 않는다.
- 빗물 흘러내림·흙 튐은 기존 벽의 강한 얼룩 무늬 위에서 매우 미묘하다. 최종 강도 조정 후에도 독립된 주요 개선으로 읽히지는 않으며, 보수판 가까이에서는 단순한 평판의 인상이 남는다. 원경에서는 차이를 크게 주장할 수 없다.

## 보존·기능 근거

- 변경 전 `BASELINE_VALIDATION.txt`가 기존 충돌체 **4,665개**, 렌더러 **5,990개**(V18 지면 포함), 게임플레이 앵커 **46개**와 V16/V17 제어 설정을 캡처했다. 최종 `VALIDATION.txt`는 **18 PASS / 0 FAIL**이다. 모든 기존 충돌체, 앵커와 위험 진입 정책, V16/V17 설정, 기존 렌더러의 메시·재질·상태 및 명시된 V17 서측 판재 11개 이외의 위치가 유지됐다. 허용된 11개는 위치·크기만 바뀌고 메시·재질·렌더 상태는 보존됐다.
- 새 외벽·물때 그룹은 렌더러 28개, 정점 352개, 충돌체 0개다. 새 메시와 조정된 판재는 남측 외벽 한정 범위 안에 있으며 메인·하역 개구부의 시각 영역을 침범하지 않았다. `SHADERS.txt`는 새 재질의 셰이더 오류 0개를 기록한다. V14 충돌 및 V15 겹침 회귀 검사를 통과했다. V17/V18 전체 검사는 이번에 허용된 기존 11개 transform 변경 때문에 직접 성공 기준으로 쓰지 않고, V19의 별도 보존 서명으로 검사했다.
- `SAVED.txt`, `RELOAD.txt`, `INSPECT.txt`는 장면·프리팹 저장, 저장 장면 재열기 후 재검증, 렌더러 6,018개·충돌체 4,665개·`sceneDirty=False`를 확인한다. 최종 `after_PLAY_VALIDATION.txt`는 **RESULT PASS**로 주요 이동 경로, V19 외벽 그룹의 표시·숨김, 두 차양 아래 카메라→캐릭터 시야와 지붕 물리/복원, A맵 이탈 시 환경 복원을 기록한다. 대응되는 전후 이미지 33쌍은 모두 존재한다.

## 해석의 경계와 남은 과제

- `west_work`와 `east_service` 플레이 항목은 각각 `steps=0`인 정지 관찰 지점이다. 이를 새 외벽 주변의 이동 성공으로 계산하지 않는다. 실제 이동 검사는 로그의 나머지 7개 경로에 한정한다.
- 저장된 `HumanRoutes` 배열은 기존부터 비어 있다. 과거 V17의 H3 검사는 원본 코드의 계획 경로 대조이지, 살아 움직이는 H3 순찰의 플레이 검사가 아니다.
- B4와 비활성 위험 진입점 R8은 약 62m 거리와 W5 합류 문제를 그대로 가진다. 이번 외벽 표면 작업은 초기 접근·엄폐·위험·보상이나 스폰 정책을 바꾸지 않았으며 R8을 독립 위험 진입점으로 만든 것으로 볼 수 없다.
- 상부 창의 동일 텍스처, 하부 판재의 공통 표면, 기존 벽 얼룩, 원경 건물 반복은 남아 있다. 에디터 렌더링 카운터는 독립 실행 빌드의 FPS 보증이 아니다.
