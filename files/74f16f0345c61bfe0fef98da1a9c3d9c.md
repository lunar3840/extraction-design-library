# 캐릭터 상단 체력·스태미너 / 원형 수분·에너지 시안

사용자 지시: 수분·에너지는 덕코프에서 참고한 원형 반투명 아이콘과 fill 방식으로 표시하고 숫자 카드를 제거한다. 체력·스태미너는 로블록스 때처럼 캐릭터 위에 표시하는 방향을 검토한다.

## 범위와 기획 의도
이번 산출물은 별도 편집 가능한 SVG와 미리보기 PNG 시안이다. Figma MCP Starter 호출 한도가 계속 차단되어 Figma 파일이나 Unity는 수정하지 않았다. 완료되지 않은 Figma 변경을 완료로 보고하지 않는다.
캐릭터 상단 배치와 원형 fill 방식만 이번 사용자 지시를 현재 익스트랙션 UI에 적용한다. 로블록스 폴더의 Stage D 보고서는 관련 자료를 확인했으나 정확한 과거 플레이어 머리 위 UI 규격은 찾지 못했다. 다른 게임의 보스 수치·표현·동작은 적용하지 않는다. 과거 레이아웃과 픽셀 단위로 같다고 주장하지 않는다.

## 변경 전 증빙
reference_previous_hud.png는 직전 작업에서 저장한 실제 Figma 렌더의 복사본이다. 이번 턴의 현재 Figma 캡처가 아니므로 before 파일로 위장하지 않았다. 라이브 Figma 변경 전 캡처는 MCP 제한으로 확보하지 못했다. 새로 만드는 로컬 시안 파일에는 기존 수정 전 상태가 없다.

## 실제 제작
- 하단의 체력·스태미너·수분·에너지 숫자 카드 4개를 제거한 배치.
- 수분·에너지: 58px 반투명 원형, 색을 28% 농도로 아래에서 위로 채움. 물방울/번개 심볼로 구분하고 고정 숫자·항목명은 숨김.
- 잔량 부족은 작은 로즈 표시로 보조. 점멸이나 마우스 오버 상세는 동작 제안이며 구현 완료가 아니다.
- 체력 124×8px, 스태미너 124×4px의 2줄 바를 캐릭터 머리 위에 배치. 숫자와 카드 배경 제거. 실제 Unity 구현에서는 월드 좌표를 화면 좌표로 투영해 캐릭터를 따라가야 하며 이 시안은 정지 화면이다.
- 스태미너 완충 후 숨김은 권장 선택안이며 확정 사용자 요구가 아니다.
- 기하학적 바닥·상자는 UI 시안의 배경 맥락만 제공한다. A맵 설계/배치 변경이 아니다.

## 산출물 및 검증
after_hud_proposal.png / .svg: 전체 HUD 제안.
after_component_states.png / .svg: 충분/소모/부족 상태와 캐릭터 상단 바 확대.
SVG의 도형·텍스트는 분리되어 편집할 수 있고 캐릭터만 이미지로 포함한다. 새 Figma 컴포넌트나 Variant가 만들어진 것은 아니다.
PNG는 동일한 작성 데이터에서 2배 크기로 그린 뒤 축소해 만든 미리보기다. Figma 캡처나 Unity 게임 화면으로 제시하지 않는다.
생존 아이콘 안의 숫자 없음, 원형 안으로 fill 제한, 바가 머리 및 주변 HUD와 겹치지 않는지 시각 확인한다. 게임 내 가독성·카메라 추적·전투 중 성능 검증은 아직 수행하지 않았다.
