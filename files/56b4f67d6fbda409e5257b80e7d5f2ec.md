# S4 방어구 2D 일러스트 아이콘 시안

## 사용자 지시와 의도

[SOURCE_REQUEST.md](SOURCE_REQUEST.md)에 원문을 보존했다. 사용자는 사실적인 모델 캡처 아이콘이 현재 게임의 심미적 방향과 어울리지 않는다고 평가하고 직접 그린 비사실적 아이콘을 요청했다. 같은 S4 방어구의 인벤토리 식별성이라는 기존 의도의 후속이므로 기존 무기/장비 썸네일 주제의 2026-11-03-02 기획·설계 회차로 연결한다. 앞선 구현 완료 회차는 보존한다. 이번 이미지 시안 제작 완료를 Unity 구현 완료로 집계하지 않는다.

## 변경 전 상태와 증빙

before_icon.png는 이전 회차 after_strap_thumbnail.png의 실제 모델 촬영 결과를 수정 전에 바이트 그대로 복사했다. reference_inventory_user.png는 이번 사용자가 제공한 실제 인벤토리 화면이며 이 작업에서 새로 촬영한 화면으로 취급하지 않는다. 이전 아이콘은 몸통·허리 장비의 검정 면이 어둡고 재질 명암이 복잡해, 작은 슬롯과 간단한 주변 소모품 아이콘에서 이질감이 있었다.

## 만든 시안과 방식

내장 image_gen 도구의 style-transfer 방식으로 S4 아이콘을 새로 그렸다. before_icon.png에 해당하는 원래 장비 촬영 결과는 아이템 식별 참조, 사용자 인벤토리 화면은 SD 캐릭터와 주변 아이콘의 스타일 맥락 참조로 사용했다. 생성 프롬프트 전체는 [GENERATION_PROMPT.txt](GENERATION_PROMPT.txt)다. CLI나 외부 API 키는 사용하지 않았다.

after_icon.png 한 종은 굵은 회청색 외곽선, 간단한 셀 명암, 넓고 밝은 회청 면과 주황 포인트로 구성한다. 작은 형태로 식별하기 쉽게 버클·파우치·가슴 보호판을 단순화하고 소매는 몸통 가까이 내려 compact한 형태로 그렸다. 목 아래부터 팔꿈치·무릎까지의 장비만 표시하며 손·발·사람의 피부와 제거했던 대각선 끈은 넣지 않았다. 새 그림은 원래 메시를 그대로 추적한 렌더가 아니라 디자인을 단순화한 스타일 시안이다.

생성 원본은 C:/Users/ehoji/.codex/generated_images/01a07c84-280a-71d3-8895-0af268af1ec9/exec-1d1717d6-3394-4737-a16c-3e1f828deb99.png 에 보존하고, 작업 폴더의 after_icon.png로 복사했다. 원본을 후처리·알파 제거·재인코딩하지 않았다. 실제 Unity 프로젝트/아이콘 PNG/3D 착용 모델/공통 UI 코드는 이번 작업에서 변경하지 않았다. 성능 검증 중인 Unity와 공유 요청 파일도 조작하지 않았다.

## 확인 결과와 한계

생성 결과와 저장한 실제 파일을 열어 장비만 있는 2D 일러스트, 검정·주황 정체성, 팔꿈치·무릎 범위, 끈·문자·UI 패널 제외를 확인했다. PNG를 직접 읽어 RGBA8,1254×1254,모서리 알파0,완전 투명 픽셀902,588개 및 알파24 초과의 가시 피사체를 기준으로 사방 여백을 확인했다. 원시 알파0 초과의 범위에는 하단 가장자리의 알파1 픽셀8개가 포함되므로 테두리 전체가 완전 투명하다는 의미로 해석하지 않는다. 가시 경계(187,58~1055,1220)와 원시 경계(33,19~1231,1253)를 통계에 구분했다. 상세 값·SHA는 IMAGE_VALIDATION.json에 보존했다.

실제 슬롯 축소 상태의 게임 내 적합성·프레임 비용은 이번 이미지 제작에서 측정하지 않았다. 작은 슬롯 가독성은 제작 목표이며 Unity 실측 통과로 표현하지 않는다. 사용자 시안 검토·승인 전이며 Unity에 적용하지 않았다.
