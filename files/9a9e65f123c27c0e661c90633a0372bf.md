# 중간 시안·검증의 판정 정정

기록은 실제 실행 결과를 보존한다. 아래 중간 PASS는 최종 판정에 사용하지 않는다.

- `WEATHERING_193207.txt`: 첫 검증은 새 재질이 저장된다는 점만 확인했고 저장된 모든 노후화 매개변수까지 대조하지 못했다. 후속 실제 프리팹에서 설정 초기화가 발견되어 해당 PASS만으로 도구 완료를 판단할 수 없다.
- `study_01/STUDY_REPORT.txt`: `RESULT PASS`는 당시의 제한된 검사 결과다. 폐차의 `variant_a_car_iso.png`와 `after_car_iso.png`가 같은 해시였고, 실제 재열기에서 강도 0이 확인되었다. 첫 합성 시안을 최종 결과로 채택하지 않는다. 회반죽·벽돌이 금속으로 잘못 분류된 기록도 이 시안에 남아 있다.
- `PERSIST_DIAGNOSTIC_194009.txt`와 후속 19:48 진단: 실제 저장 후 강도 .65가 0, 녹 .55가 .3 등 기본값으로 변했다. 화면상 Preview 성공과 저장 성공을 구분한다.
- `COMMAND_persist-diagnostic_195018.txt`: 강화된 저장 게이트가 실제 불일치를 감지하여 실패했다. 조용히 기본값 프리팹을 성공으로 반환하지 않았다.
- `WEATHERING_195001.txt`: 새 shader에 선언된 D09 속성이 실제 Preview 재질에서 사라지는 문제를 감지했다. 이를 원본 URP 재질이라서 검사하지 않아도 된다는 식으로 완화하지 않았다.
- `SHADER_DIAGNOSTIC_195*.txt`: 새 shader 자체는 정확한 경로·70개 속성이고 fresh material은 D09 속성을 가진다. 그러나 `CopyPropertiesFromMaterial(source)` 직후 새 shader 이름을 유지한 채 D09 `HasProperty`가 false가 되고, CreateAsset 시 새 설정이 기본값으로 돌아간다. CreateAsset 후 직접 SetFloat/SetDirty/SaveAssets한 대조군은 유지되었다. 복사·shader 전환 순서를 수정하는 근거다.
- `PROBES_194123.txt`: DepthOnly 원본 URP 대조군부터 빈 회색이었다. 깊이 텍스처 읽기 진단 실패이며 새 shader의 깊이 실패로 확정하지 않는다.
- `PROBES_195425.txt`: 첫 깊이 차폐 검사에 PASS가 출력되었으나 화면 바깥 magenta 배경도 coverage에 포함되었다. 독립 검토에서 발견되어 최종 증거로 채택하지 않는다. 기하를 그리지 않은 대조군과 픽셀 변화만 비교하도록 보완한다.
- 검증기 `TestRealShellWeathering` 호출만 반입되고 함수 본문이 누락된 중간 상태에서 컴파일 오류가 발생했다. 최신 스테이징 전체를 다시 반입하여 해결했으며, 이전 어셈블리로 실행된 중간 로그를 최신 수정 성공으로 오인하지 않는다.

- `WEATHERING_195637.txt`: 저장 복구 뒤 실제 폐차·S06 저장 검사는 통과했으나 원본 발광 keyword 소실을 감지했다. shader 전환 후 원본 keyword/GI 설정을 복원하고 `WEATHERING_195852.txt`에서 모든 그룹을 통과했다.
- `study_02/STUDY_REPORT.txt`: 강화된 합성 프리팹 검사에서 기존 덩굴을 지운 뒤 Weathering marker가 삭제된 Stems/Leaves renderer를 계속 참조하는 문제를 발견하여 실패했다. 생성 덩굴은 노후화 복원 대상 renderer 목록에서도 제외하는 수정 후 새 시안을 실행한다.

최종 검증 파일과 채택 시안은 CHANGE_RECORD.md의 최종 판정을 따른다. 원본·중간 실패 기록은 삭제하지 않는다.
