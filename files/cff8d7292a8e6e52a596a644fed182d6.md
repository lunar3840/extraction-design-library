## 사용자 지시 및 범위

- 공유 대화의 중정비동 도면을 현재 A맵에 적용.
- 보유 Time Ghost 식생을 사용하여 수풀·풀을 개선.
- 사용자 첨부 `rusted+phone+booth+3d+model.zip`의 환경 소품 배치.
- 카툰 렌더링을 유지하면서 환경의 형태·재질·밀도를 더 현실적으로 개선.
- 메인이 설계·통합·검증, Sol high 에이전트가 중정비동/식생/첨부 소품을 각각 제작. 씬 실행과 저장은 메인이 수행.
- 공유 대화에 포함된 메인 미션 전체, 보상/퀘스트 상태, 위험 스폰 활성화는 이번 구현 범위가 아님. 타 게임 지침 적용 없음.

## 변경 전 상태와 문제

- V12 중정비동은 넓은 단일 상자와 낮게 압축한 지붕으로 깊이와 실루엣 변화가 부족.
- 기존 상층 보행로/핵심실은 새 도면의 3개 층 구조와 다름.
- 지하 공간을 내려갈 때 지상 지형과 슬래브가 통로를 막지 않도록 별도 개구부 필요.
- 기존 Time Ghost 부분 추출 자산은 존재하나 넓은 빈 공간과 낮은 수풀 가시성으로 풍성한 식생 인상이 약함.
- ZIP에는 이름과 달리 전화부스 포함 총 20종 GLB 환경 소품이 들어 있음. 로컬 사용자가 제공한 자료이며 라이선스 문서는 포함되지 않음.

## 변경 전 증빙 및 복구

- 실제 수정 전 A씬이 저장된 상태에서 원본 씬·프리팹을 `backup/`에 보관.
- `before_overview.png`, `before_hall_exterior.png`, `before_west_vegetation.png`, `before_south_approach.png`, `before_hall_close.png`, `before_hall_interior.png` 실제 캡처.
- 비교 카메라 위치/조명/1600×1000 해상도를 동일하게 유지하는 캡처 도구 사용.
- 원본 모델/텍스처는 수정하지 않고 `Assets/Escape/Art/RealismV13/`에 파생 자산 생성.

## 구현 방식

- 중정비동: B1=-4m, 1F=2m, 2F=8m. 동서 독립 계단, 중앙 높은 정비홀, 낮은 관리동, 외부 비밀 진입 램프.
- 지형: 기존 지형 메시의 삼각형을 정확한 직사각형 경계로 절단하여 건물 지하/비밀 통로의 지면 개구부 생성. 원본 메시 복사본 유지. 주변 맵 고도와 도로 재설계는 하지 않음.
- 가림: 건물 외부에서는 지붕/외벽 유지. 내부에서는 해당 층보다 높은 층과 지붕 렌더러만 숨김. 실제 충돌체는 유지.
- 지하 카메라: 물리 지형 개구부와 별도로 지하에서만 사용하는 렌더 전용 지형 메시를 만들고, 카메라와 캐릭터 사이를 가리는 해당 홀 벽의 외형만 숨김. 지형·벽 충돌은 변경하지 않으며 외부로 나가면 복원.
- 조준: 마우스 포인터의 카메라 레이만 숨겨진 위층을 제외. 실제 총탄 레이의 물리 충돌은 기존대로 유지.
- 식생과 소품은 서로 다른 제작 루트 및 교체 가능한 자산으로 분리.
- B4/R8은 진입 경험 차별화 검토 대상 유지. 위험 진입점 활성화/스폰 규칙 변경 없음.

- 기본 진입점 B1(지하 층 이름과 다른 스폰 ID)→X6 장거리 NavMesh 질의는 기본 검색 예산에서 Partial. 16K 노드 질의는 Complete이므로 물리적 단절과 구별되지만, 기본 질의를 사용하는 장거리 AI 추적의 제한은 남음. `LONG_ROUTE_DIAGNOSIS.txt`, `INTEGRATION_VALIDATION.txt`에 명시. 이번 환경 작업에서 전역 AI 경로 시스템을 임의 재설계하지 않음.
