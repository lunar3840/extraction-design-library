# 독립 검토 결과

검토일 2026-10-29 KST. 메인이 GPT-6 Sol high 두 서브 에이전트의 회신을 읽고 아래에 정리했다. 소스 감사와 저장 이미지 평가는 읽기 전용으로 수행했으며 Unity 실행이나 게임 파일 수정은 없다.

## 소스 감사

담당 `character_shading_audit`는 기존 HybridToon/CharacterHybridD15, ToonCharacterStyle/SubcultureD15Profile, EdelSkinShadingMask, ToonOutlineFeature, PC_Renderer 설정을 대조했다.

- 전용 단계 음영과 화면 외곽선은 이미 구현돼 있다. 몸통/다리의 독립 음영 그룹 및 얼굴 SDF는 없다.
- 에델의 기본 셰이더는 확인된 UV4 피부 표식을 사용한다. 기존 피부 수정은 보존해야 한다.
- 추가 독립 확인에서 D15에는 `_LimbSkinShading` 속성/정점 입력/음영 적용이 없음을 확인했다. `ToonCharacterStyle.Set`은 HasProperty 조건부여서 D15에서 이 값을 설정하려 해도 적용되지 않는다.
- A맵 프리팹은 D15 실험 플래그가 켜져 있지만 실제 활성화에는 올바른 맵·참조·라우터·세션 플레이어 조건도 필요하다. 따라서 D15 선택 시 마스크 미작동은 코드상 확인되나 현재 Play의 선택 상태나 팔 얼룩 재발은 확인하지 않았다.
- PC 외곽선 설정 폭은 1.15px다. 화면 depth/normal 방식이며 캐릭터 전용 선택 마스크가 아니다. 추가 패스와 작은 내부선 과검출을 확인해야 한다.

## 저장 이미지와 성능 근거 검토

담당 `character_feedback_review`는 10/26 에델의 before_front/back 및 after_front/after_skin_back 4개 이미지를 직접 비교했다.

- 큰 팔·어깨 밝은 얼룩은 줄었지만 몸통에서 허벅지·종아리로 이어지는 회색 대비와 무릎 경계는 남아 있다.
- 얼굴은 근접 화면에서 읽히지만 실제 게임 크기의 가독성은 이 사진으로 판단할 수 없다.
- 사진은 10/26 당시 격리 인벤토리 진단이다. 오늘의 런타임 증빙이나 머리 결과의 사용자 승인으로 취급하지 않는다.
- SDF는 얼굴의 국소적인 그림자 제어 후보이며 몸/다리 재질 경계·텍스처·노멀·조명 문제 전체의 해결책이 아니다.
- 10/26 동일 입력 헤어 CPU 평균은 약53.10ms였다. 당시 GPU/Render 시간은 유효하지 않아 렌더링 패스 추가 비용을 보장할 수 없다.

## 통합 판정

피부 보정 경로 통일 → 부위별 조명 합산·음영 정리 → 기존 외곽선의 캐릭터 가독성 평가 → 얼굴 SDF 순서가 타당하다. 실제 기본/A맵 게임 화면과 근접 화면의 동조건 검증이 다음 구현 단계의 선행 조건이다. 본 문서는 독립 분석 결과이며 게임 변경의 기능/성능 통과 판정이 아니다.

같은 독립 검토자에게 최종 두 문서를 다시 읽도록 했고 분석/구현 구분, D15 코드 판정과 Play 미확인 구분, SDF 설명, 과거 화면·반려 상태, 외곽선·GPU 한계의 5항목에 막는 문구 오류가 없다는 회신을 받았다. 제안에 따라 D15의 누락 범위를 ‘혼합 atlas의 UV4 팔 마스크 보정’으로 좁혀 몸통 전용 재질의 완화까지 없어지는 것으로 오해하지 않도록 했다.
