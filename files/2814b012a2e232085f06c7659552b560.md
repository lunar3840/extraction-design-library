## 실제 변경과 방식

- `data-editor/app.js`: 메뉴 이름 출력에서 중간점·선택적 공백·뒤 단어를 하나의 span으로 묶는다. 모든 원문 텍스트는 기존 HTML escape를 통과하며, 문자열·공백·ID·아이콘·건수·클릭 동작은 유지한다. 분류 제목에도 같은 규칙을 적용했다.
- `data-editor/style.css`: 중간점 묶음은 inline-block/nowrap, 일반 라벨은 keep-all로 단어 경계를 유지한다. 긴 영문 코드 이름은 overflow-wrap:anywhere로 메뉴 밖으로 넘지 않도록 유지한다. 분류 숫자 색 규칙을 별도로 좁혀 중첩 레이블 색을 보존했다.
- `data-editor-web/shared/app.js`, `shared/style.css`에 동일 화면을 반영한다. 이 작업의 웹 빌드는 기존 게시 카탈로그를 그대로 사용한다. 게임 원본·수집 수치·CSV·서버 인증·반영 로직은 수정하지 않는다.
