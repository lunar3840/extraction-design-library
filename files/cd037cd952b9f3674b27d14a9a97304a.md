# 사용자 원문 — 소수점 오류의 실제 수정

사용자 지시일: 2026-10-27 KST.

> 원문 0.75가 75로 표시되는 오류도 표시만 하지 말고 실제로 수정 부탁함. CSV로 내보내거나 유니티에 반영할 때도 올바른 수치로 처리되게 해줘.

이전02회차에서 발견·표시했던 오류를 실제 추출·저장·CSV·반영 경로에서 고치라는 후속 승인이다. 원본 게임 코드의 기준값은 이미0.75이므로 불필요하게 Unity를 실행하거나 게임 밸런스를 변경하지 않고 편집기 처리 경로를 수정했다. 원문0.75와 기존75 표기를 보존한 이전 회차는 덮어쓰지 않는다.
