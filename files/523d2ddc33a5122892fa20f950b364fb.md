# Tripo GLB 내려받기 차단 기록

후속 상태: 사용자가 브라우저에서 직접 GLB를 내려받아 요청 32개와 보류 5개를 로컬에서 확인했다. 이 문서는 자동 내보내기 실패 당시의 기록이며 현재 수령·검증 상태는 `RECEIVED_MANIFEST.json`과 `IMPORT_AUDIT.md`를 따른다.

- 사용자 지시: 기존 T01–T14와 지정된 Z 모델 18개의 GLB를 무료 내보내기로 내려받아 Unity 반입에 사용한다. 추가 생성과 크레딧 사용은 금지한다.
- 의도: 클라우드 미리보기만 존재하던 모델을 원본 파일로 확보하고, 실제 GLB 헤더·길이·메시를 확인한다.
- 변경 전: T01 결과는 Tripo 계정에 있고, 7,211면으로 표시되었으나 해당 작업의 로컬 GLB는 없었다. 계정 잔액은 1,640이었다. `before_tripo_export_T01.png`는 T01 GLB/2K 내보내기 대화상자를 보여 준다.
- 수행: T01 작업 페이지에서 GLB/2K로 `T01_clinic_tile_corner` 내보내기를 실행했다. Tripo는 완료 토스트를 표시했으나 브라우저 다운로드 이벤트가 120초 내에 없고 사용자 Downloads 폴더에도 새 파일이 없었다. 같은 작업의 GLB/1K `T01_clinic_tile_corner_1k`를 다시 시도했으나 20초 동안 다운로드 이벤트가 없고 로컬 파일도 없었다. 에셋 목록의 메뉴에는 수집·추천·삭제만 있었고, 페이지에 보이는 GLB 파일 링크는 없었다. 이 시도에서 잔액 1,640은 유지되었다.
- 다른 브라우저 경로: CUA에서 Chrome/Edge 브라우저 연결은 제공되지 않았다. Windows Computer Use에서 열린 Chrome 창과 기존 Tripo 탭은 확인했으나, Tripo 탭을 선택하려는 순간 도구가 현재 브라우저 URL을 정책에 필요한 수준으로 확인할 수 없다며 이 턴의 Computer Use를 중단했다. 명시된 중단 지침에 따라 이후 Windows UI 입력은 하지 않았다.
- 변경 후 및 검증: `downloads/` 폴더에 확인된 GLB는 0개다. GLB 헤더·길이·메시 검증은 파일이 없어 수행할 수 없다. T02–T14와 Z 18개는 이 차단 상태에서 추가 내보내기를 반복하지 않았다. `DOWNLOAD_MANIFEST.json`에 정확한 범위를 남겼다. `after_tripo_export_T01.png` 및 `after_tripo_export_T01_1k.png`는 각 시도 후의 동일 Tripo 내보내기 화면이다. 완료 토스트를 로컬 다운로드 성공으로 해석하지 않는다.
