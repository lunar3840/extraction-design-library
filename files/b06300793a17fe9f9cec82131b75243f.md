# 메인 전후 시각 검토

2026-10-28. 최종 색 연결 교정 후 메인이 BUILDINGS_01–06 시트의 36동을 4열(변경 전 외부/후 외부/전 실내/후 실내)로 대조했다. C01 실제 단독 실내, HALL 전후 단독 실내, CLINIC 실제 Play 전후 외관도 원본 해상도로 확인했다. 다른 33동/야외28쌍은 survey 독립검토, 새 방10동과 건물군10 대표는 blender 독립검토, 검증 담당도 시트12장 전체를 읽었다.

- 건물별 아이보리/벽돌/공업재/녹회색 판금 팔레트와 주요 윤곽 유지. C01/C04/E02/E04/E07/N02/N04/N07/N17 새 방이 보이며 원경에서 보이는 명백한 가구 관통이나 문 개구 소실은 발견하지 않았다. 가까운 가구 간격은 실제 캐릭터 통행 검증으로 판단한다.
- HALL 첫 Editor 후촬영의 상층 창띠는 원본 visibility 캐시가 새 모델 sibling을 인지하지 못한 도구 상태였다. RebuildCache 후 두 고정 시점을 재촬영했고, fresh Play의 after_building_HALL_interior.png에서도 정상 낮은 벽/노출 설비 구도를 확인했다. 캐시가 남은 두 사진은 after_editor_attempt_02_hall_cache에 보존했으며 after_editor의 최종 HALL쌍은 실제 재촬영 파일이다.
- 일부 Editor 얼룩 농도 차이는 실제 Unity source→imported 위치·UV0·재질·삼각형 방향67동/3394tri가 전부 일치했다. 동일 Play 조건의 CLINIC 전후 전체 화면에서 과도한 색 변화나 큰 새 회색 패치는 확인되지 않아 원본 material/shader 변경 없이 수용한다.
- E04 주변 청색 사각 바닥, 일부 건물 내부 잔디·나무, N17 수직 구조는 before에도 존재한다. 이번 반입으로 새로 생긴 파손으로 보고하지 않았다. 전체 그래픽 완성도와 모든 기존 장식의 자연스러움을 보증하는 검토는 아니다.

최종 저장 승인은 독립 Editor·실제 PlayerMotor/LootInteractor·성능 비교·원본 저장/재로드 검증까지 완료한 뒤 별도 VISUAL_APPROVAL.json으로 고정한다. 이 문서만으로 완료나 게시 준비를 뜻하지 않는다.
