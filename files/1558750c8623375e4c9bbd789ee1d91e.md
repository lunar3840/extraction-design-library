# CLINIC 분위기 시범 후보02 독립 시각 검토

판정: **국소 시범 적용·시각 개선 확인, 완성 품질 PASS 및 전맵 확대 보류.** 2026-10-30 KST의 post-UI 재구성 전 10개 Game 화면과 후보02 적용 후 10개 Game 화면을 모두 직접 열어 같은 구도끼리 비교했다. Unity 편집기·Assets·Library·request는 조작하지 않았다. `before_reconstructed_`는 현재 UI 코드에서 후보01 전용 root만 임시로 숨긴 **재구성본**이며 원회차의 진짜 수정 전 촬영물이 아니다.

## 실제 적용·보존 근거와 한계

- `COMMAND_apply_candidate02_002.txt`와 `COMMAND_save_candidate02_001.txt`: 새 root 1개, renderer 6개, vertex 5,724개, triangle 4,735개, Collider/Light 0개, 원형 잎 160개, 잎 원본 색·texture 참조 일치, 저장 후 reload Audit PASS.
- `PRE_SAVE_PRESERVATION_reloaded_save_candidate02_001.txt`: 기존 씬 inventory 46,684행 유지, 8,497개 참조 asset과 보호 소스 4개 byte 보존, 원본 shell의 reveal source binding 유지. 이 정적 결과는 실제 Game 가림 동작이나 시각 품질 판정이 아니다.
- `PLAY_PAIR_COMPARISON_candidate02.txt`: 10개 기대 시점·pose·seed·해상도·각 90 sample·문 PlayerMotor 통행은 일치하며 결과는 `MATCHED_REVIEW_REQUIRED`다. Editor Play 수치는 독립 성능 PASS가 아니다.

## 최초 10쌍 검토 시 발견한 한계와 미감 문제

1. **최초 10뷰의 CLINIC V33 가림 미노출.** `PLAY_PAIR_COMPARISON_candidate02.txt`의 모든 CLINIC 시점이 `reveal=False->False`다. W05 통제만 `True->True`다. 원본 shell을 source로 묶은 정적 검사만으로 북벽 가림 연동을 판정할 수 없었다. 아래 고유 short phase 재촬영에서 이 국소 가림 진입·복귀를 별도 확인했다.
2. **최초 후 화면의 전후 플레이 상태 불일치.** 모든 전 화면 HUD는 탄약 `30/70`, 중량 `19.8/50.0 kg`, 시간 `29:57`인데 최초 후 화면은 `0/100`, `20.3/50.0 kg`, `29:58`이다. 이는 이미지 자체로 확인된다. 아래 별도 HUD 일치 재촬영에서 같은 loadout·시간을 확보했으며 최초 회차의 한계 기록은 보존한다.
3. **핵심 미감 미달.** 후보01의 민트 패널·긴 줄기는 해결됐지만 후보02의 북벽 덩어리는 여전히 단일 수직 패치로 보이고, 줄기와 지면의 연결은 빈 검은 틈/파편으로 읽힌다. "벽과 진입로 한 화면"의 뿌리·큰 식생 군집·국소 젖음이 명확한 개선으로 보이려면 해당 접합을 실제 Game 구도에서 다듬고 재촬영해야 한다. 현재 자료만으로 완성 시범 PASS를 줄 수 없다.

후보02의 **원본 보호와 국소 시범 적용은 확인**했으며, 잎 형태·색은 후보01보다 개선됐다. 창 보존도 실제 화면에서 확인했다. 이 결과는 실제 제작된 **검토용 시범**으로 제시할 수 있다. 뿌리·지면·젖음의 시각 접합과 큰 군집 목표는 미달이므로 이를 완성안이나 전맵 확대 승인 근거로 쓰면 안 된다. CLINIC 가림 연동과 HUD 비교 조건의 후속 판정은 아래 별도 촬영 근거에 기록한다.

비교 원본: `rounds/post_ui_checkpoint/before_reconstructed_*.png`, `rounds/post_ui_checkpoint/after_candidate02_*.png`, `rounds/post_ui_checkpoint/staging/validation_tool/play_before_reconstructed/PLAY_REPORT.json`, `rounds/post_ui_checkpoint/staging/validation_tool/play_after_candidate02/PLAY_REPORT.json`.

## 후속 증빙: HUD를 맞춘 후보02 재촬영

기존 `after_candidate02_*.png` 10장과 그 HUD 불일치 관찰은 그대로 보존한다. 별도 `after_candidate02_hudmatched_*.png` **10개 Game 화면을 모두 직접 열었다.** 원시 `play_after_candidate02_hudmatched/PLAY_REPORT.json`은 완료 상태 `CAPTURED_STATIC_AND_MOVEMENT_REVIEW_REQUIRED`, 10/10 `CAPTURED_REVIEW_REQUIRED`, 1920×1080, 각 90 sample, PlayerMotor 21걸음 PASS를 기록한다. `loadoutBeforeFixture`와 모든 view fingerprint는 `AR_001`, 탄창 30/예비 70, 중량 19.8 kg, reloading false이며 시간은 전부 `29:57`이다. 실제 화면에서도 재구성 전 HUD와 일치한다. 이 회차는 기존 RifleController의 Play 한정 준비 상태이며 production 저장 변화 근거는 없다.

HUD 일치 화면에서는 북벽 잎 색·형상, 창, 지면 패치, 출입구, W05·다리·HALL1 형상이 앞선 후보02 화면과 같은 것으로 보인다. HALL1의 적 체력 막대도 재구성 전과 같이 보인다. 따라서 **HUD fixture 불일치와 HALL1 막대 차이는 별도 재촬영으로 보강**되었다. 이 보강은 핵심 미감 미달 판정을 바꾸지 않는다.

## 후속 증빙: 첫 자연 가림 화면과 두 번째 촬영 실패

`supplement_candidate02_reveal_clinic_north_reveal.png`를 직접 열었다. CLINIC 북벽의 원본 shell이 실제로 국소 가림되어 내부가 보이고, 그 가림 영역에 새 벽 식생의 고립된 잎 덩어리는 남지 않으며 지면 패치는 남는다. 원시 `play_supplement_candidate02_reveal/PLAY_REPORT.json` 첫 view는 `CAPTURED_REVIEW_REQUIRED`, `revealActive=true`, `revealBlockingSurface=CLINIC_Shell_renderOpaque`, source shader `Hidden/Escape/BuildingV33LocalReveal`, Growth 활성 renderer 0·Ground 활성 renderer 3으로 기록한다. 따라서 **가림 진입의 한 순간은 실제 화면과 renderer 상태가 일치**한다.

같은 report 전체 상태는 **`INCOMPLETE_OR_FAILED`**다. 두 번째 `clinic_north_reveal_restored`는 가림이 꺼지고 Growth 3·Ground 3으로 돌아온 상태 값은 기록했으나 `status=PENDING`, `gameExists=false`다. 두 번째 camera PNG를 쓰는 도중 `DirectoryNotFoundException`이 나서 복귀 Game 화면이 생성되지 않았다. 이 때문에 report의 `revealSupplementStatus=PASS_LOCAL_REVEAL_AND_RESTORE`는 두 view의 상태 값만으로 계산된 **완료 판정으로 사용할 수 없는 값**이다. 첫 가림 시점은 검증됐지만 시각적 복귀·전환 2단계 전체는 미검증이며 앞선 최종 시각 PASS 보류는 유지한다. 실패 기록과 첫 PNG는 삭제하거나 성공 기록으로 덮어쓰면 안 된다.

## 후속 증빙: 고유 short phase 자연 가림 재촬영

실패 회차는 보존된 상태로, 경로 길이를 줄인 별도 `sr_candidate02_reveal` 회차에서 두 Game PNG와 두 camera PNG가 모두 생성됐다. `play_sr_candidate02_reveal/PLAY_REPORT.json` 전체 상태는 `CAPTURED_STATIC_AND_MOVEMENT_REVIEW_REQUIRED`, `error` 공백, `revealSupplementStatus=PASS_LOCAL_REVEAL_AND_RESTORE`, view 2/2 `CAPTURED_REVIEW_REQUIRED`, 각 90 sample, 1920×1080, PlayerMotor PASS, 원래 상태 복원 true다. 두 view 모두 HUD 30/70·19.8 kg·29:57이다.

- `sr_candidate02_reveal_clinic_north_reveal.png`를 직접 열었다. 북벽의 원본 CLINIC shell이 국소 가림되어 실내가 보이고, 가려진 원벽 자리에 새 식생 잎·줄기 패널이 홀로 떠 있지 않다. 지면 패치는 남는다. raw는 `revealActive=true`, 차단 표면 `CLINIC_Shell_renderOpaque`, source shader `Hidden/Escape/BuildingV33LocalReveal`, Growth 활성 0·Ground 활성 3을 기록한다.
- `sr_candidate02_reveal_clinic_north_reveal_restored.png`를 직접 열었다. 원벽·창과 후보02 짙은 잎 덩어리가 다시 보이고 지면 패치도 유지된다. raw는 `revealActive=false`, 원래 `Escape/BuildingD09/WeatheredLit` 및 `Escape/Environment/Weathered Lit` source shader, Growth 활성 3·Ground 활성 3을 기록한다.

따라서 **CLINIC 북벽의 자연 V33 가림 진입과 복귀, 원벽과 새 벽 식생의 동시 처리, 지면 장식 잔류는 이 두 시점에서 실제 Game 화면으로 확인**됐다. 이 판정은 실패한 첫 회차를 성공으로 바꾸지 않으며, 다른 카메라 거리·모든 실내 위치의 가림까지 보증하지 않는다. HUD fixture 보강과 이 국소 가림 확인에도 불구하고, 큰 식생 군집과 벽·뿌리·지면·젖음 접합의 미감 미달 때문에 **완성 품질 PASS 및 전맵 확대 보류**는 유지한다.
