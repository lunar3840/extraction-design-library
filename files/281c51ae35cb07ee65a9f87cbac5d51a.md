# 인간형 적 3종 T포즈 4면도 준비

- 사용자 지시: Tripo 직접 생성 시도는 종료하고, 사용자가 직접 업로드할 수 있도록 적 종류별 4면도만 준비한다.
- 작업 범위: 기존 라인업의 수색병(SCAVENGER), 돌파병(BREACHER), 중화기병(SUPPRESSOR) 3종. 각각 정면·후면·인물 기준 왼쪽·오른쪽의 개별 PNG를 제공한다. 기본 자세는 T포즈, 손은 비우고 무기는 제외한다.
- 기획 의도: 캐릭터 몸과 총기가 붙어 생성되는 일을 줄이고, 방향별 실루엣과 장비를 확인하며 사용자가 직접 다중 이미지 생성에 넣도록 한다.
- 변경 전: 수색병 4면도만 존재했고 돌파병·중화기병은 무기를 든 3/4 정면 라인업만 있었다.
- 변경 전 증빙: before_reference_lineup.png는 기존 콘셉트 원본의 무손실 복사본이며 스크린샷이 아니다. 이전 작업에서 브라우저 화면 접근이 차단되었고 이번 작업은 기존 게임/도구 화면을 수정하는 작업이 아니므로, 화면 캡처를 확보했다고 주장하지 않는다. 기존 원화와 새 이미지 자체를 비교 자료로 보관한다.
- 제작 방식: 내장 image_gen을 사용하고 기존 라인업과 수색병 정면을 각각 캐릭터 디자인·출력 형식 참조로 사용한다. 각 신규 캐릭터 정면을 먼저 확정하고 그 결과로 후면·측면을 만든다. 최종 이미지는 프로젝트 폴더에 보관한다.
- 수색병은 검토된 기존 PNG 네 장을 복사하여 재사용한다. Tripo 계정 조회·이미지 업로드·모델 생성·결제는 수행하지 않는다.
- 작업 상태: 3종 × 4방향 = 12장 준비 완료. 수색병 기존 4장과 돌파병·중화기병 신규 8장이다.

## 실제 추가 및 확인 결과

- 돌파병: 회백색 헬멧, 주황빛 갈색 재킷, 왼쪽의 큰 회백색 어깨판과 오른쪽의 작은 짙은 어깨 패드, 오른쪽 앞 허리의 산탄 3발을 방향에 맞게 유지했다.
- 중화기병: 청회색 후드, 넓은 회백색 흉갑, 두꺼운 목 보호대, 양쪽 어깨 보호대, 더 큰 사각 배낭을 유지했다.
- 모든 신규 이미지를 생성 결과에서 직접 열람했다. 정면·후면의 양팔과 손끝, 머리와 발이 프레임 안에 있고 무기가 없다. 후면에는 마스크 전면이나 흉갑을 그리지 않았다. 왼쪽/오른쪽 측면은 서로 반대 방향을 바라보고 T포즈의 팔을 카메라 방향으로 단축 투영했다.
- 측면은 좌우 반전 복사가 아니라 각각 생성했다. 특히 돌파병 오른쪽 측면의 작은 어깨 패드와 산탄 띠를 확인했다.
- PNG 12장 모두 1254×1254임을 파일에서 확인했다. 방향별 파일명과 각 캐릭터 폴더를 분리했고 MANIFEST.json에 경로, 해상도, 바이트 크기, SHA-256을 기록했다.
- 변화 후 자료: after_scavenger_tpose_front/back/left/right.png, after_breacher_tpose_front/back/left/right.png, after_suppressor_tpose_front/back/left/right.png. 이들은 각각 원본 PNG의 복사본이며 스크린샷은 아니다.
- 비교 방법: before_reference_lineup.png의 왼쪽/중앙/오른쪽 인물과 각 캐릭터의 after_*_front.png를 외형 비교한다. 원화가 3/4 시점에 총기를 든 자세이므로 같은 시점·자세의 전후 비교라고 주장하지 않는다. 후면과 측면은 이번에 추가한 제작 참조다.
- 한계: 생성 이미지의 주름, 손가락 모양, 세부 장비 배치와 화면 내 높이에 작은 시점 간 차이가 남아 있다. 실제 3D 모델에서 렌더한 정확한 정투상 도면이 아니며 메시·리깅 검증은 수행하지 않았다.
- 기대 효과: 사용자 본인이 적 종류별 네 장을 방향에 맞춰 Tripo에 입력할 수 있다. 캐릭터와 총기가 결합된 생성 결과를 피하도록 빈손으로 준비했다.
