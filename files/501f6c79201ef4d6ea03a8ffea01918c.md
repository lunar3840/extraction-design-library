## 지시·기획 의도와 주제 연속성

사용자는 이전 회차에서 남은 ‘세부 영향 확인 필요’ 항목을 실제 코드에서 조사해 영향 요소·스탯 설명을 최대한 채워 달라고 요청했다. SOURCE_TRANSCRIPT.md에 원문을 보존했다. 기존 편집기 영향 설명의 후속 목적이므로 같은 주제의 2026-10-27-02 회차로 연결한다. 날짜·새 폴더를 이유로 새 대표 주제를 만들지 않는다.

## 변경 전 상태·증빙

v7의 12,931행 중3,155행은 기능 분야와 원문 코드만 표시하고 개별 영향은 확인 필요로 남겼다. 전리품 추첨의 weight를 ‘무게’로 읽거나 출혈 문턱을 남은 체력 비율로 오인할 수 있었다. 수정 전에 실제 공개 v7에서 같은1280×720·White의 출혈 발생 문턱과 첫 전리품 가중치, Black의 같은 출혈 문턱을 각각 before_injury.png, before_loot.png, before_injury_black.png로 저장했다. 사후 재구성하지 않았다.

## 조사·구현 방법

- Unity를 실행하거나 게임 파일을 수정하지 않았다. 현재 Assets/Escape/Runtime의255개 C# 파일을 읽기 전용 Roslyn 구문 트리/의미 모델로 읽고, 대상90개 원본에서3,155개 기존 행을 조사했다. 같은 행 문장·리터럴 순서·실제 수치/불리언을 대조하고, 생성자/함수의 형식 인수·대입 대상·주변 조건·소속 메서드를 연결했다. Unity 참조가 없는 도구에서 게임을 컴파일·실행한 것은 아니다.
- 3,146행은 원문·리터럴 대응을 확인했다. 구문 매칭이 모호한7개 C# 행 및2개 에셋 필드는 현재 원문·선언·동일 문장·직접 참조 검색으로 수동 대조했다. 원래 행 번호와 현재 위치가 다르거나 같은 문장이 복수인 경우 그 한계를 설명에 남겼다.
- 그중 구체적인 설정 의미·효과를 해석한943행과 구문·호출 연결에서의 역할을 설명한2,212행은 근거 수준을 구분한다. 후자는 모든 숫자의 최종 게임 변화량이나 상향/하향 효과까지 실측했다는 뜻이 아니다. 실제 스탯이 아닌 검사 기준·저장 상태·화면 표시·난수 내부값도 구분하고, 실제 계산식·함수 서명·주변 조건을 사용 맥락에 제공한다.
- 출혈·외상 누적 문턱과 감쇠, 팔·다리 외상 페널티, 적 회복·회피·성향·점사, 역할별 공격 패턴, 무기 종류별 탄퍼짐·반동, 부착물 배율·가격·격자, 전리품 가중치·수량·품질·최소 등급·수색 시간, 연구 가격·재료·보정, 칩 보상 확률, 동료 스킬·충전 등을 해석했다. 예를 들어 전리품 weight는 kg/퍼센트가 아닌 상대 추첨 가중치이고, 부착물 reloadTime 배율은 높일수록 재장전이 느려진다.
- turnSmoothness·aimAssistRadius와 일부 감염 회복 배율은 선언은 있지만 현재 Runtime에서 직접 소비 참조를 발견하지 못했다고 명시했다. 선언식을 확인한 것과 실제 스탯 적용 완료를 혼동하지 않는다.
- 원본 `choices[2]==0?.75f:.65f`의0.75가 기존 게시 카탈로그에75로 잘못 분리된1행을 발견했다. 해당 행은 ‘수치 불일치 확인’과 별도 강조, 원문0.75/0.65 및 실제 탄퍼짐 의미를 표시했다. 이번에는 카탈로그 값·원본·CSV 변환을 수정하지 않았다. 수치 해석이 일치한다고 거짓 통과하지 않았다.
- 표시 자료 impact-code-data.js는 source/field/note 가드를 사용한다. 행 번호만 이동한 경우에도 동일 문장·필드·리터럴 순서가 유일할 때만 연결하며, 모호하거나 문장이 달라지면 이전 설명을 무조건 재사용하지 않는다. 설명은 CSV·값·권한·게임 적용 계산에 들어가지 않는다. 현재 카탈로그의 ‘세부 영향 확인 필요’ 일반 문구는0행이지만, 구문 연결 확인 수준과 실행 참조 미발견·값 대조 필요 표시는 별도로 남아 있다.
