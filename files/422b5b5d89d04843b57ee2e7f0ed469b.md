# 캐릭터 바·소모품 가로 정렬·작전 시간 가독성

## 사용자 지시와 의도

- 머리 위 체력/스태미너의 공통 박스를 없애고 HP 아래에 스태미너 fill을 직접 붙인다.
- 소모품 3칸은 무기처럼 가로 한 줄로 표시한다.
- 시간 UI의 큰 글자와 부족한 여백을 조정한다.
- 사용자가 지정한 `Figma와 Unity UI 연동 검토` 탭과 조율한다.

## 변경 전 증빙

- `before_combat_hud_1920x1080.png`: 연동 검토 탭에서 2026-10-22 06:14:03 KST에 캡처한 실제 SystemsTest Game View 원본 `ui-kit-completion-unity/after_r02_combat_hud_1920x1080.png`를 수정 전에 복사했다. 재구성 이미지가 아니다. 상태 원본도 함께 복사했다.
- 이 화면에서 공통 외곽 안에 떨어져 있는 두 상태 바, 2행 소모품, 박스 대비 큰 시간이 확인됐다. 해당 HUD 소스의 변경 전 좌표와 일치한다.

## 실제 변경

- `InventoryHudLayout.cs`: 소모품 3칸을 같은 y에 배치하고 무기 카드 하단과 맞췄다. 1920×1080 기준 80×80px 카드, x=1224/1310/1396, y=952. 통합 행 경계와 실제 클릭 차단 좌표를 함께 갱신했다.
- 같은 파일에 머리 위 HP 112×7 / 스태미너 112×3 논리 좌표를 두고 위아래가 직접 맞닿도록 했다.
- `InventoryHudView.cs`: 공통 외곽 Pill을 제거했다. 바 전용 렌더러도 카드용 Pill 대신 그림자 없는 Fill을 사용해 3px 아래로 늘어나는 카드 그림자가 잔여 외곽처럼 보이지 않도록 했다. 개별 바의 잔량 트랙과 실제 HP·스태미너 비율, 머리 추적은 유지했다.
- `SessionGlassView.cs`: 작전 시간에만 28 논리 글자, 보조 문구 12, 일반 라벨 14 전용 스타일을 사용한다. 전역 Clock 및 다른 메뉴/로비 디자인은 바꾸지 않았다. 미니맵 하단 212×60 패널은 유지하며 글자 영역과 여백을 정리했다. 미니맵이 없는 대체 패널에도 같은 타이포 비율을 적용했다.

## 협업 범위

- 연동 검토 탭에서 위 소스 범위 소유권을 인계받았다. 해당 탭은 Figma 반영과 공유 Unity 조작 및 최종 실화면 수집을 맡는다.
- 이 탭에서는 공유 Unity의 Play/씬/native 조작이나 새 Unity batch 실행을 하지 않는다. 기존 UiTheme·캐릭터·인벤토리 간격 변경을 보존한다.

## 확인 상태

- 전체 런타임 정적 컴파일: 오류 0, 기존 경고 21, exit 0 (`validation/runtime_compile.txt`). Unity batch 실행 없이 기존 Roslyn 참조 구성으로 검사했다.
- 실제 C# 좌표 계약 검사: **207 PASS** (`validation/hud_contract_checks.txt`). 800×600, 960×600, 1280×720, 1280×800, 1600×900, 1920×1080, 2400×1440, 2560×1080에서 1행 정렬/화면 경계/주변 HUD 비중첩/빈 공간 pointer 통과 및 머리 위 바 직접 접합을 확인했다.
- 1920×1080에서 마지막 소모품 카드 오른쪽 1476px, 스킬 영역 왼쪽 1497px로 21px 간격이다.
- 연동 검토 탭의 실제 Game View 재수집 `after_r03` 완료(2026-10-22 06:46:47 KST 전투 캡처). `after_combat_hud_1920x1080.png`와 상태, `after_camp_hud_1920x1080.png`, 원본 캡처 manifest를 이 폴더로 복사했다. 전체 캡처에서 bounds failures=0, 임시 프로필 정리 완료를 확인했다.
- 전투 실화면을 직접 확인해 공통 박스/그림자 제거, HP 하단 스태미너 접합, 소모품 가로 3칸과 스킬 간 여백, 축소된 시간의 여백 및 한글 라벨 가독성을 확인했다. 거점 실화면에서도 동일 HUD 배치가 반영됐다.
- 전후 전투 화면은 동일 해상도·시험 경로·맵 위치를 사용하지만 런타임 포즈/카메라 정착에 미세한 차이가 있다. 픽셀 단위 동일 장면으로 주장하지 않는다.
- 거점 안내 띠와 무기 카드 상단의 기존 겹침은 인계받은 소스 범위 밖이므로 연동 검토 탭에 별도 전달했다. 수정 여부는 후속 자료로 구별한다.
- 잔량을 달리한 상태와 최종 입력/텍스트 치수 검증의 추가 자료를 협업 탭에 요청했다. 207개 좌표 검사를 실마우스 클릭 통과로 대체해 주장하지 않는다.

## 결과와 범위

- 요청한 HUD 3개 변경의 코드 적용·정적 검사·실제 전투/기지 화면 검토를 완료했다. 단축키 및 아이템 사용 처리 자체는 변경하지 않았다.
- Figma의 최종 동기화와 다른 메뉴 전체 검증은 `Figma와 Unity UI 연동 검토` 탭에서 이어서 관리한다. 그 전체 작업까지 완료됐다는 의미는 아니다.
- 전후 이미지와 이 기록이 모두 보관됐음을 확인했다.
