# 변경 기록 — A맵 v0.8 기본 구조 Unity 구현

## 사용자 지시

v0.8 도면을 Unity에 블록 형태로 구현하고, 엄폐물/배경 오브젝트는 다음 단계로 미루며 모든 에셋을 나중에 교체할 수 있게 구성하도록 요청하셨습니다. 모든 맵 작업을 병렬 진행한다는 지속 지침을 적용했습니다.

## 기획 의도 / 변경 전 상태

기존 A는 v0.3 사각형 동선·건물 블록에 v0.4 엄폐물이 추가된 상태이며, v0.8의 비정형 동선, 중계 장치와 새 B/R 진입 위치는 적용되지 않았습니다. 구형 A 및 보존 B를 덮어쓰지 않고 새로운 A 버전으로 만들며, 기본 구조와 외형을 분리해 다음 단계의 에셋 교체를 지원합니다.

## 변경 방식

- 메인이 설계·원본 보호·Unity 실행·통합을 담당했습니다. Sol high 제작자는 구조/슬롯, 별도 Sol high는 독립 검증, 추가 Sol high는 기초 구조 helper를 병렬 작성했습니다.
- 원본 에디터가 열려 있어 별도 검증 프로젝트에서 생성·시험했습니다. 원본의 저장된 A 씬과 동일한 해시의 사본을 변경 전에 렌더했습니다. 원본 에디터의 미저장 화면을 촬영한 것으로 주장하지 않습니다.
- 구형 A/B를 보존하고 새 `StageA_Relay_Blockout_v08` 씬/프리팹을 생성했습니다. 기존 `StageABlockoutMap`는 덮어쓰지 않고 새 구조 컴포넌트와 조합했습니다.
- 건물 5곳, 내부 개방형 핵심실, 중앙 계단/상부, 수로/교량, 중계 공터와 진입/탈출 기준점을 배치했습니다. 기존 엄폐물/배경은 새 버전에 복사하지 않았습니다.
- 논리 기준점 / 충돌 / 외형을 분리하고 슬롯별 외형 프리팹, 로컬 위치·회전·크기 보정과 편집 버튼을 제공했습니다. 콜라이더와 Rigidbody는 외형 교체물에서 제거합니다.
- 정상 A 출격은 새 프리팹에 연결하며 이번 구조 단계에서는 장비 가치와 무관하게 B만 사용합니다. 중계 해금·지도 공개·위험 진입 옵션·영구 저장은 미구현으로 남깁니다.

## 검사 중 수정

- 조작 공터의 사각형 좌상단을 본체 중심으로 잘못 사용할 수 있는 문제를 수정했습니다.
- 고도가 있는 B/R/X 기준점에 실제 연결 경사면과 받침 바닥을 추가했습니다.
- 외형 교체 시 Unity의 지연 삭제 때문에 새 외형이 삭제 예정 루트에 붙는 문제를 수정했습니다.
- 첫 실제 구조 검사는 180개 진입→목적 경로 통과 후 계단에서 실패했습니다. 24단 외형과 연속 충돌 경사면을 분리하고, 계단 뒤를 덮던 상부 발판을 앞쪽으로 이동하여 재검사한 결과 정적 검사와 실제 PlayerMotor 상·하행 모두 통과했습니다.
- 수로 남단을 y397→400으로 3m 연장한 것은 맵 가장자리 우회를 막기 위한 도면 대비 구현 보정입니다. 원본 도면 파일은 보존합니다.
