# 덩굴 랜덤화와 자연 잠식 폐허 노후화 도구

## 사용자 원문

> 좋은데? 잎을 조금만 더 풍성하게 넣어주고 같은 에셋을 넣더라도 매번 다른 형태로 랜덤하게 잎이 붙게끔 해주면 충분할 것 같네. 그리고 이거 일단 전 맵에 적용하기 전에, 동시에 낡고 오래되서 버려진 느낌을 주는 텍스쳐? 셰이더? 뭐가 됐던 그런 느낌을 주는 툴을 좀 제작해야할 것 같은데. 그것도 동시에 시안 적용해보고 같이 적용해야 할 것 같아. 다시 말하지만, 내가 초기에 기획했던 아트 분위기는 이런 느낌이야.

사용자 제공 폐도시·낡은 건물·자연 잠식 참고 이미지를 따른다. 현재는 도구와 별도 시안의 병행 적용 범위이며 전맵 적용 승인이 아니다. 같은 D09 주제의 당일04회차로 연결한다.

## 기획 의도

기존03 덩굴의 군집/여백을 유지하며 잎을 소폭 풍성하게 하고, 매 생성의 무늬를 달리하되 결과 씨앗을 저장해 재현한다. 게임 실행 중 계속 모양을 바꾸거나 씬을 열 때마다 바꾸는 요구로 확대하지 않는다.

노후화는 금속의 녹/벗겨진 도장, 벽의 누수/먼지/퇴색, 낮고 습한 부분의 이끼를 구분하는 도구로 구체화한다. 원래 건물별 색·용도·재료 및 차량의 유리·타이어·차체를 보존한다. 기존 셰이더/재질 원본·전역 조명·가림·캐릭터·A맵 씬/프리팹은 보호하고 별도 작업 사본에만 시안을 만든다.

## 실제 변경과 병렬 분담

메인이 설계·통합·공유 Unity 실행·이미지 검토를 맡고 GPT-6 Sol high 서브 3개가 덩굴 생성/UI, 노후화 도구/shader, 독립 검증을 분리했다. 각자 staging 파일만 수정하고 실제 Assets 반입·Unity 실행은 메인만 수행했다. `A맵 적 배치와 동선 계획` 채팅에서 명시 인계받았고 `현실적 그래픽 개선 요소 분석`과 보호 범위를 조율했다.

- 덩굴: 잎 군집의 연속 잎 상한을 4에서 5로 소폭 늘렸다. 잎 스타일 난수와 기존 줄기 성장 난수는 분리되어 있다. 고정731 대조에서 폐차412→448개, 외벽1414→1534개, 지붕1458→1574개다. 다른 씨앗까지 항상 같은 비율로 늘어난다는 뜻은 아니다.
- 매회 새 무늬: 명시 생성 시 새 씨앗을 뽑고 실제 사용값을 표시·저장한다. 이전 씨앗과 같은 값은 피하며 Unity 게임 난수 상태를 소비하지 않는다. 씨앗 고정으로 동일 원본/설정/시작점/제외 영역의 형상을 재생성한다. 씬 열기·게임 실행 때 자동 변경하지 않는다.
- 노후화 도구: 별도 PreviewScene 사본, 원본/생성 재질 슬롯 기록, 차량·석재/벽돌·도장면 사전 설정, 강도/녹/오염/빗물/낮은 이끼/퇴색/무늬 크기/씨앗 조절, 실제 미리보기와 고유 폴더의 새 프리팹 저장을 구현했다.
- 재료 반응: 금속은 녹·도장 손실과 해당 부분의 금속성/거칠기 변화, 벽은 불규칙 빗물·먼지·퇴색과 하부 습기/이끼로 구별한다. 원본 URP PBR와 정확한 D09 노후화를 유지한다. 유리·목재·타이어·덩굴·overlay·비활성/충돌/그림자 전용·미지원 shader는 이유를 기록하고 건너뛴다.
- 실제 조합: 폐차·S06 외벽·S06 파손 지붕을 노후화한 사본에 새 무늬 덩굴을 결합했다. 최종 채택은 `study_04/`이고 세 조합 프리팹과 마당 조합 사본을 저장했다. 기존 A맵 씬/맵 프리팹에 배치하지 않았다.

## 변경 전 문제와 수정 과정

기존03 덩굴은 군집·여백을 갖지만 잎을 조금 더 늘릴 여지가 있고 같은 설정은 같은 모양만 만든다. 원본 재료별 노후화 효과를 추가·조절하여 덩굴과 함께 저장할 수 있는 독립 도구도 없었다.

실제 검사에서 초기 재료 분류, 저장값 초기화, 발광 keyword 소실, 이전 덩굴 제거 후 renderer 참조 수명 문제를 발견해 수정했다. 핵심은 원본 shader 상태에서 속성을 복사한 뒤 새 shader로 전환하고 원본 keyword/GI를 복원하는 순서, 별도 재질 snapshot의 저장/재읽기 검증, 덩굴 renderer를 노후화 복원 대상에서 제외하는 것이다. 실패·제한된 중간 PASS를 보존하고 `ITERATION_AUDIT.md`에서 정정했다. 검증을 약화하여 통과시키지 않았다.

03 기능 시안 뒤 추가 노후화가 정상 거리에서 너무 은은하다고 메인/독립 검토가 판단하여 벽 빗물과 하부 이끼의 불규칙 포켓을 조금 더 분명하게 했다. 최종04는 원래 재료색을 남기면서 하부 오염과 수직 얼룩이 읽히는 도구 시안이다. 지붕 덩굴 일부가 먼 거리에서 가는 선으로 보이는 점은 후속 미술 조정 여지다.
