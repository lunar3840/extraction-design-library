# A맵 건물별 외형 콘셉트 v01 — 작업 기록

상태: 대표 외형 10종을 비교 시트 3장으로 생성하고 메인·GPT-6 Sol high 독립 시각 검토 완료. 메인은 최종 VISUAL_REVIEW.md를 읽고 검토 범위와 미검증 사항을 통합했습니다. 판정은 외형 콘셉트 채택 가능이며 구현 완료가 아닙니다. 기존 Unity 씬·프리팹·코드·에셋은 이 작업에서 수정하지 않았습니다.

## 사용자 지시

“건물들의 생김새와 컨셉이 너무 획일적이고 동일해보이는 느낌이 있음. tripo를 사용해 창문이나 벽, 기타 에셋들을 생성하여 좀 다양한 외형의 건물들을 생성하고 싶은데 건물마다 좀 다른 컨셉에 맞게끔 다른 외형을 우선 컨셉아트 느낌으로 제작 부탁함.”

## 기획 의도와 범위

- 소품 몇 개나 색만 달리하는 대신 지붕 윤곽, 입면 깊이, 창 비율, 주재료, 돌출 부속 구조를 건물 용도별로 구분합니다.
- 현행 69동을 10개 외형군으로 분류하고 대표 외형을 3장에 비교합니다. 69동 각각의 완성 설계도나 개별 이미지 69장이 아닙니다.
- 침수 정비지구라는 동일한 역사·노후화·재료 분위기 안에서 차별화합니다. 기계가 점유한 지상이며, 인간은 상주 주민이나 고정 캠프가 아닌 수색·파밍 집단입니다.
- 중정비동은 중앙 랜드마크를 유지하되 다른 시설도 각각 가치와 외형상 정체성을 갖습니다.
- 생성 결과는 외관 기획안이며 현행 평면·출입구 치수·지붕 가림·충돌에 맞춘 도면 및 구현 검증 이전 단계입니다.
- Tripo는 후속 모듈 제작 수단입니다. 이번에는 이미지 생성만 하며 Tripo 작업·크레딧 사용은 없습니다. 기존 모듈을 재활용하고 부족한 건축 부품부터 만들 계획입니다.
- 기존 스폰/탈출/연결 울타리/동선, B4와 R8 검토 및 위험 진입점 비활성 상태는 변경하지 않습니다.

## 변경 전 상태와 증빙

- 기존 D04에 이미 여러 지붕 유형이 적용되어 있으므로 “지붕 다양화가 전혀 없었다”고 평가하지 않습니다. 외벽·창·입구 등 공통 공장 템플릿이 건물 역할보다 강하게 반복되는 것이 검토 대상입니다.
- 직전 D06의 실제 Unity 캡처 두 장을 참조용으로 복사했습니다:
  - reference_prior_unity_loading_dock.png ← ../a-map-tripo-assembly-d06/after_spacing_loading_dock_close.png
  - reference_prior_unity_power_yard.png ← ../a-map-tripo-assembly-d06/after_spacing_power_coupler_yard.png
- 위 이미지는 **직전 작업의 기존 캡처**이지 이번 작업 시작 시 새로 촬영한 화면이나 새 설계의 변경 전후 동일 시점 비교가 아닙니다.
- 이번에는 Unity를 조작하지 않는 신규 이미지 제작이므로 실제 씬의 before/after 스크린샷 쌍은 없습니다. 결과 콘셉트를 구현 후 화면처럼 표시하지 않습니다.

## 실제 변경 및 방식

- 프로젝트 outputs 폴더에 생성 프롬프트, 새 콘셉트아트, 건물별 매핑·설계 문서와 검토 기록만 추가합니다.
- 메인 에이전트가 건축 방향·이미지 프롬프트·최종 통합 검토를 담당합니다.
- GPT-6 Sol high 서브 에이전트가 현행 건물 목록 분석/매핑 문서와 기존 에셋 재사용·독립 검토를 나눠 담당합니다.
- 이미지 생성 방식: OpenAI 기본 이미지 생성 도구. 기존 Unity 화면을 재질만 바꾸는 편집이 아닌 새로운 건축 콘셉트입니다.
- 프롬프트 원문: ../../../concept_art/2026-10-12/a-map-building-identities-v01/PROMPTS.md

### 시각 검토 및 범위 구분

- 메인이 이미지 실제 내용을 확인했습니다. 높은 포털/크레인 정비동, 낮은 회반죽·타일 진료소, 콘크리트 환기탑 전력동, 아치창 벽돌창고, 불규칙 편경사 공방, 곡면 차고, 기와 관리동, 파손 주거군, 다각 관찰실, 석재 부벽 배수동의 외형이 구별됩니다.
- 창·벽·지붕 접합부의 깊이와 재료가 공통 백색 공장 템플릿에서 분리되었습니다. 하단의 상세 그림은 참고도입니다. 특히 01/02는 입면 확대에 가까우므로 그대로 Tripo에 넣을 독립 제작 부품이 아닙니다.
- GPT-6 Sol high의 독립 시각 검토로 큰 수변과 배수동 접근 문제를 다시 확인하고 위 교정에 반영했습니다. 최종 판정은 VISUAL_REVIEW.md 참조.
- BUILDING_DESIGN.md의 실제 ID 행을 V33 PLAN.json과 메인이 재검산했습니다: 10군, 69개 항목, 고유 ID 69, 누락 0, 목록 밖 0. 군별 수는 1/4/8/10/12/5/9/11/4/5입니다.
- 이는 외형 콘셉트 검토 통과이며 69동 Unity 교체 완료나 3D 제작 준비 완료를 뜻하지 않습니다. 출입구 치수, 상층/발코니 통행, 실내 파밍, 플레이어 가림, 동선/충돌, NavMesh 및 성능은 이번 작업에서 실행·검증하지 않았습니다.
- 세밀한 반실사 콘셉트는 재료·구축감 전달용입니다. 최종 게임 카툰 셰이더·탑뷰에서의 디테일 간소화는 별도 단계입니다. 그림의 레일·원거리 건물·상층은 맵에 새 철도·건물·플레이 가능한 2층을 추가하는 승인으로 취급하지 않습니다.
