# A맵 건물군 밀도 보강 — 작업 기록

## 사용자 지시

첨부한 침수 정비지구 콘셉트 지도에 비해 현재 구현된 건물 수와 공간 구성이 부족하므로, 설명한 건물군 보강을 실제 Unity A맵에 시행한다. 기존 요청에 따라 병렬로 기획·제작·검증하고, 외형을 나중에 교체할 수 있게 유지한다.

## 기획 의도와 변경 전 문제

변경 전 A맵에는 주요 시설 5동과 보조 건물 10동만 있었다. 주요 거점의 위치는 있지만, 서부 정비 골목·남서 생활 폐허·남부 작업 마당·동부 부속 시설의 밀도가 부족했다. TimeGhost 자연 에셋 적용은 건물군 보강을 대체하지 않는다.

이번 작업은 기존 중심 시설과 연결 동선을 보존하면서 주변에 탐험 가능한 건물군을 추가한다. 전역에 균등하게 건물을 뿌리지 않고, 지역별 군집 중심·크기·방향·건물 유형을 다르게 구성한다. 현재 살아 있는 인간 정착지가 아니라 방치된 시설과 생활 흔적이라는 설정을 유지한다.

## 변경 전 증빙

원본 A 프리팹 SHA-256: `75D433A7B4F905E0197C3B0F96E532FB6EF302FD105BCFB16AD57F01EDA87600`.

원본과 일치하는 프리팹을 격리 Unity 프로젝트에서 열어, 실제 변경 적용 전에 `before_*.png` 9장을 새로 촬영했다. 이전 작업의 이미지를 이름만 바꾸어 사용하지 않았다. 원본 프리팹과 메타는 `work/stage-a-district-v11/Backup/`에 보관했다. 원본의 관련 파일 5,000개를 해시로 기록했다.

## 실제 변경 / 확인 결과

기존 15동을 유지하고 39동을 추가해 총 54동으로 보강했다. 새 건물 footprint 합계는 4,369.38㎡다.

| 추가 구역 | 새 건물 수 |
|---|---:|
| 북서 진료소 부속 | 4 |
| 서부 정비 골목 | 9 |
| 남서 생활 폐허 | 14 |
| 남부 야적장 | 6 |
| 동부 전력·창고 부속 | 6 |

지역별 seed에서 결정적인 후보 탐색을 수행하고, 기존 지형·도로·물·시설·출입 지점을 침범하는 후보를 제외했다. 첫 33동, 두 번째 35동에서 부족했던 동부 후보는 전력/창고 시설 25~60m 주변의 작은 평탄 부지를 조사하여 마지막 4동을 보충했다. 기존 성공 배치는 재추첨하지 않았다. 새 건물은 지형 바닥을 공유하고, 충돌 구조와 외형·지붕·장식을 분리했다. 양문과 내부 통로, 개방 작업장, 파손 벽·지붕 형태를 배치했다.

중간 검토에서 발견한 내부 칸막이 부유, 벽 속에 묻힌 창문 장식, 박공지붕 연결, 폐허 지붕 지지 위치를 수정했다. 첫 이동 검사에서 경사 높은 문 쪽의 상부 여유가 부족한 문제를 찾아 외부 문 높이를 보강하고 내부 칸막이 상부 문보를 제거했다. 최초 촬영 중 제작 중인 새 스크립트 의존 관계가 아직 완성되지 않아 해당 실행의 종료 코드는 1이었으나, 기존 정상 컴파일된 A맵에서 변경 전 9장 촬영은 실제 완료됐다. 이후 전체 파일이 완성된 최종 빌드·검사에서는 컴파일 오류 없이 통과했다.

최종 확인 결과:

- 정적 기술 검사 2,185건 / 실패 0, 구역 수량·면적 검사 21건 / 실패 0, Unity 오류 0.
- 기존 활성 충돌체 945개, 지형, 기존 의미 지점 143개의 fingerprint 유지. 기존 진입→탈출/중계 경로 120/120 유지.
- 새 39동의 78개 문에 대한 양방향 근거리 경로 156/156, 기본 진입점에서 각 건물 내부 접근 39/39 통과.
- 새 충돌체 362개. 새 건물 사이/기존 구조와의 관통 및 서로 다른 구조의 겹치는 공면 검사 0건. 새 바닥판·바닥 충돌체 0개. 접지·문 여유·누락 참조 문제 0건.
- 실제 Play 경로 467건, 실제 캐릭터 이동 273건 통과. 이 중 신규 문 안팎 양방향 156건 + 건물 내부 관통 양방향 78건 = 신규 234건이다. 호안 차단 17건도 통과했다.
- 39동의 외형을 실제로 교체하고 두 프레임 뒤 충돌·논리 지점이 유지되는지 확인했다.
- 메인과 독립 담당이 최종 정사영/지역/실내/폐허 보충 화면을 직접 확인했다. 수량 목표의 통과와 원래 콘셉트 최종 아트의 완성도를 구분했다.

원본 `C:/UnityProject/escape` 반영 완료: 새 파일 21개, 백업한 A 프리팹 1개 갱신, 기존 관련 파일 4,999개 해시 보존. 설치 후 A 프리팹 SHA-256은 `D82B2E0CE7C68DE73971DEA990BAD96097C02E43BA141D55B972601F58615E63`이며 검증한 프리팹과 일치한다. 원본 편집기의 씬 저장·Play 전환은 강제하지 않았다. 검증 화면은 격리 프로젝트에서 촬영했고 동일한 검증 산출물을 해시 대조 후 원본에 반영했다.

## 주요 파일 / 적용 방식

격리 복사본에서 새 `StageADistrictV11.cs`·`StageADistrictSlotV11.cs`와 `Generated_v11` 재질 8개를 생성했다. 검증을 통과한 파일과 메타, 기존 연결을 유지한 A 프리팹만 원본 프로젝트에 복사했다. B맵, 캐릭터, 스폰·퀘스트 규칙, 원본 에디터의 활성 씬/Play 상태는 변경하지 않았다.

추가 보충 화면은 `after_repair_alley_supplement.png`, `after_workshop_interior_supplement.png`, `after_residential_supplement.png`, `after_play_entry_district_supplement.png`다. 대응 before 없는 추가 관찰 자료이며 전후 비교 쌍으로 취급하지 않는다.

## 한계

건물은 교체 가능한 구조 검증용 모듈이며 최종 건축 아트가 아니다. 콘셉트보다 넓은 공터와 성긴 구간이 남고, 도로 위계·산업 장식·가구·실제 파밍 보상은 이번에 추가하지 않았다. 원래 이미지의 숲·산세·수로 윤곽을 픽셀 단위로 재현한 것도 아니다. 신규 활성 renderer는 495개이며 FPS/GPU 성능은 별도 실기기 측정 없이 통과로 주장하지 않는다.

Play 보충 화면에는 큰 직선 형태의 명암 경계가 보인다. 이전 TimeGhost v1.0의 Play 보충 화면에도 같은 유형이 관찰되어 이번 새 건물 겹침 검사의 통과와 별개인 기존 렌더링 잔여 문제로 기록한다. 원인은 이 작업에서 확정하지 않았고 셰이더는 변경하지 않았다. 정적 공면 0건을 화면 전체의 모든 명암 문제 해결로 확대 해석하지 않는다.
