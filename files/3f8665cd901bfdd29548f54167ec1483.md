## 사용자 지시 원문
“이거 옛날 캐릭터 모델링 계속 뜨는데 이거 이제 폐기해도 될듯. 여기는 현재 존재하는 4개의 캐릭터 (만약 캐릭터가 추가된다면 해당 캐릭터들도 추가) 를 출력해주면 될 것 같은데.”
후속: “아스트라 아까워서 솔 6.1로 다시 작업요청한다.”

## 기획 의도·기존 주제 연결
현재 구현된 세린·에델·리브·유이 모델이 타이틀에 표시되고 이후 등록되는 모델도 같은 목록을 사용하도록 함. 기존 네 캐릭터 모델/칩/표현 작업의 같은 대상·목적 후속이며 별도 대표 주제를 만들지 않음. 실제 모델 파일 삭제를 동료/NPC/미장착 신체 기획 변경까지 확대하지 않음.

## 변경 전 상태와 원인
- before_title_return_1920x1080.png 및 before_title_return_1600x900.png: 전체 UI 담당의 실제 저장 후 타이틀 복귀 캡처를 변경 전에 추가 확보. 직접 픽셀 확인하여 사용자 첨부와 같은 구형 기본신체가 나오는 것을 확인. 원출처 after_r02_title_return_1920x1080.png / after_title_return_1600x900.png.
- before_title_1920x1080.png: 전체 UI 담당 채팅의 실제 1920×1080 타이틀 캡처(직접 픽셀 확인 결과 초기 세린 표시)(after_title_1920x1080.png)를 수정 전에 보관. 원출처 outputs/change_records/2026-10-23/unified-figma-ui/.
- before_user_title_legacy.png: 사용자가 첨부한 실제 변경 전 구형 모델 화면. 전체 UI/카메라 조건은 알 수 없어 같은 조건으로 새로 촬영한 화면으로 주장하지 않음.
- 타이틀 UI는 현재 플레이어 외형을 미리보기로 공유. 구형 모델이 보이는 경로는 세션 종료 후 Session=null 및 BindCompanionChip→ApplyCompanion(null)로 미장착 기본신체가 적용된 뒤 타이틀이 그 플레이어를 재사용하는 것. 초기 타이틀에서는 세린이 보일 수 있으며 항상 구형 모델이 뜨는 것은 아님. 스타일 변경 전에도 존재한 미장착 기본신체의 표시이며 최근 UI 스타일의 외형 회귀로 취급하지 않음.
- SdCharacterVisual은 에델/리브/유이 ID와 모델 경로를 분기로 고정. 미래 캐릭터가 chip catalog에 등록되어도 이 외형 분기에는 자동으로 연결되지 않았음.

- FrontEndController: 초기화 연결 및 캐릭터 클릭/회전 입력에서 전환 버튼 영역만 제외. 기존 클릭/드래그/표정 연결 보존.

## 실제 최종 변경·확인 결과
- 타이틀 전용 미리보기는 LateUpdate(100)에서 페이지 변경 이후, 실제 미리보기 렌더 이전에 반영하여 복귀 직후 구형 모델이 한 프레임 남는 경로도 피함.
- 캐릭터 무작위 선택은 별도 System.Random을 사용해 전투/드롭 등 Unity 전역 난수 상태에 영향을 주지 않음.
- 실제 첫 실행에서 4모델/복원 로직은 통과했으나 분리된 OnGUI의 전환 버튼이 메인 메뉴 뒤에 가려지는 것을 발견. diagnostics/controls-hidden에 해당 원래 사진/검증 결과 보존. DrawControls를 FrontEnd.DrawTitle에서 호출하도록 수정한 뒤 전부 재검증하고 실제 버튼 입력까지 확인. 첫 실행을 완전 성공으로 주장하지 않음.
- OnDisable 중 이미 비활성인 actor에는 복원 모델을 만들지 않도록 검사하여 장면 종료 과정의 불필요한 Animator.Update 경고를 피함.
- 최종 after_title_<serin|prototype|liv|yui>.png는 실제 네 캐릭터 렌더. prototype은 저장 호환 ID이며 화면 이름은 에델. after_title_return_from_unbound.png는 세션 종료와 같은 미장착 외형 상태를 API로 재현한 뒤 타이틀로 돌아온 결과이며, 실제 저장/불러오기 전체 경로를 새로 실행한 것으로 주장하지 않음.
- before_title_return_1920x1080.png와 after_title_return_from_unbound.png는 같은 타이틀 배치/해상도/정면 조건으로 비교. 캐릭터 모델과 포즈 차이는 교체의 결과이며, 저장 완료 문구 유무는 서로 다름. 변경 전 캡처는 별도 UI 채팅 원본을 수정 전에 확보한 것으로 출처 명시.
- 원본 모델/재질/헤어/NPC 자산은 삭제하지 않았고 타이틀의 구형 모델 표시 연결을 퇴역시켰음. 게임 내 칩 미장착 신체 기획·칩 선택·세이브·실제 캐릭터 크기는 이번에 변경하지 않음.
- FrontEnd 최종 연결은 초기화, DrawControls 호출, 기존 드래그 입력에서 전환 영역 제외의 세 군데. 다른 채팅의 최신 타이틀 스타일/클릭 표정/드래그 회전과 footer y912 등은 보존.
- 원본 v08 장면 복원 후 테스트 코드3개+meta3개만 제거, 요청 파일 없음. after_editor_restored.png / scene_restored.txt / final_files.json / final_unity_compile_log.txt 참조.
- 라이브러리는 기존 네 캐릭터 주제의 후속 회차로 연결. 현 게시 소유권은 MD 파일 채팅(01a08af2)이 보유하여 원문/증빙/메타데이터를 인계함. 게시 결과를 확인하기 전까지 pending을 유지함.
