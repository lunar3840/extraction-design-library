# V31 재질 제작·정적 점검

## 수정 범위와 이유

- V16/V23의 콘크리트 바닥·공장 외벽·앞마당 재질에는 원본 노멀 텍스처가 연결돼 있었으나 `_UseNormalMap=0`이고 `_NORMALMAP` 셰이더 키워드가 없어 실제 PBR 조명에는 반영되지 않았다.
- 기존 텍스처가 있는 14개 재질에서만 노멀을 활성화했다. 원본 UV 방향을 유지했으며, 색상에 월드 플래너 샘플을 혼합하는 바닥·앞마당은 혼합 비율만큼 노멀 세기를 줄인다. 월드 XZ 노멀을 메시의 탄젠트 좌표계로 잘못 취급하지 않는다.
- V23 강철 계단·안전벽·작업대는 기존 색/경계/논슬립 무늬를 유지하면서 smoothness의 작은 공간 편차만 추가했다. 새 텍스처·메시·오브젝트는 추가하지 않았다.
- V16/V23 생성 코드를 다시 실행할 때 재질의 노멀 활성화 상태가 사라지지 않도록 해당 코드도 함께 변경했다.
