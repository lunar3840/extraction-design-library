# HUD 큰 라운드 · 캡슐 형태 보강

작업일: 2026-10-22

## 사용자 지시

“라운드 지금보다 많이 크게 줘.. 아크레이더스의 ui 참조해줘.”

기존의 작은 모서리 변경보다 확실히 둥근 인상을 원한다는 후속 지시다. 현재 HUD를 대상으로 수정했으며 다른 게임의 규칙이나 맵 지침을 UI 공통 규칙으로 확대 적용하지 않았다.

## 기획 의도와 변경 전 문제

기존 퀵슬롯 radius 18, 키캡 8~9, 상호작용 14는 작은 변화에 그쳤다. 무기·목표·중량·스킬 설명 배경에는 radius 2~3의 직각 인상이 남아, 원형 생존 게이지와 모양이 일관되지 않았다. 폰트를 줄이지 않고 큰 곡선과 기존 컴팩트한 배치를 함께 유지하는 것이 목적이다.

ARC의 실제 퀵유즈 화면에서 원형 반투명 레이어와 정보 밀도를 참고했다. 이번 수치는 현재 HUD 크기에 맞춘 프로젝트의 디자인 선택이며 ARC의 공식 radius를 계측·복제한 값이 아니다. 복고 색·장식은 추가하지 않았다. 조사 제안과 실제 적용값은 구별한다: `reference-note.md`.

## 실제 수정

| 대상 | 전 → 후 |
| --- | --- |
| 80×80 퀵슬롯 원본 | radius 18 → **32** |
| 24×24 퀵슬롯 숫자 키 | 8 → **12**, 원형 |
| 무기 카드 4개 상태 | 3 → **32**, 원래 크기 유지 |
| 선택 무기 상단 강조선 | x12 → **x32**, 둥근 모서리 밖에 뜨지 않도록 이동 |
| 296×80 상호작용 3개 상태 | 14 → **40**, 캡슐 |
| 상호작용 내부 배치 | 좌우 여백 12 → **20**, 제목·액션 행 및 구분선 폭 272 → **256** |
| 28×28 F 키 3개 | 9 → **14**, 원형 |
| 112×40 상태 배지 3개 | 2 → **20**, 캡슐 |
| 목표 본문·탈출 배경 | 3 → **32**; 높이 44의 탈출 배경은 화면에서 22로 제한되어 캡슐로 보임 |
| 지역명 배경 | 3 → **16**, 지역명 텍스트 중앙 정렬 |
| 작전 시계 | 3 → **22**, 최종 양끝 정렬(Auto) |
| 128×48 스킬 설명 배경 4개 | 3 → **24** |
| 중량 배경 4개 화면 | 3 → **16**, 캡슐 |
| 동료 헤더 4개 화면 | 3 → **28**, 캡슐 |

스킬 설명 배경과 함께 선택한 채움 없는 스킬 컨테이너 4개의 radius도 24로 설정되었다. 컨테이너는 채움·잘라내기가 없으므로 원형 충전 링과 내부 아이콘은 유지된다. 상세 상태는 `design-system-state.json`에 기록했다.

## 변경 방식과 주요 에셋

Figma의 기존 네이티브 편집기에서 원본 컴포넌트/변형과 기존 화면의 배경 레이어 속성을 수정했다. 새로운 플러그인이나 앱을 설치하지 않았다. 알려진 MCP/내장 AI 한도 상태에서 같은 요청을 반복하지 않고 일반 편집기를 사용했다. 입력값은 포커스를 이동해 확정한 뒤 속성과 실제 내보내기로 확인했다.

- 파일: `KUD4t84BL1S77c3cnb8co0`, 페이지: `11:711 Gameplay · HUD & Overlays`
- 최종 미리보기: `69:2948`
- 원본: `HUD/QuickSlotCompact 55:1184`, `HUD/WeaponCompact 55:1139`, `HUD/InteractionCompact 55:1217`, `HUD/ConditionCompact 55:1230`, `HUD/AbilityCompact 55:1183`, `HUD/TacticalNavigation 64:1577`, `HUD/TacticalObjective 64:1713`
- 중량·동료 배경: Normal `13:708`, Critical `13:855`, Extraction `13:1423`, Project backdrop `69:2948`
- 로컬 수정: 본 기록, `design-system-state.json`, 전후 증빙 PNG, 검토 기록 및 전체 UI 상태 기록의 latestRevision 링크

모든 UI 텍스트·벡터·컴포넌트는 편집 가능한 구조를 유지했다. 수분/에너지 112px와 숫자 없는 아래에서 차오르는 fill, 캐릭터 위 HP/스태미너, 글자 크기·대비, 퀵슬롯 간격 6은 유지했다. E/X 키 radius 8, 초상 radius 8, 물방울·번개 등의 이전 벡터 곡률은 이번에 추가 변경하지 않았다. Unity와 게임 파일은 수정하지 않았으며 앱·기존 탭을 종료하거나 재시작하지 않았다.

## 확인 결과

1920×1080 실제 Figma PNG를 전후 비교했다. 큰 라운드가 확실히 구별되며, 퀵슬롯 키·수량, 상호작용 제목·거리·F 키, 무기 탄수, 목표 문구가 곡선 안에서 읽힌다. 스킬 설명·중량 문구·동료 얼굴에도 새 잘림이나 겹침이 발견되지 않았다.

중간 검토에서 시계 숫자가 52px 왼쪽으로 치우친 것이 발견되어, 원본 시계의 간격을 Auto(양끝 정렬)로 설정했다. 최종 비교에서 숫자 픽셀 범위는 전후 모두 x209~262, y365~384로 동일하다. 원인은 추정하지 않고 관찰 차이와 수정 결과를 기록했다.

독립 최종 시각 검토 **PASS**: `visual-audit.md`. 이 판정은 제공된 정상 HUD 화면의 가독성·클리핑 검토다. 다른 모든 상태의 전체 화면이나 Unity 런타임 구현, 인벤토리 전면 재설계를 완료했다는 의미가 아니다.
