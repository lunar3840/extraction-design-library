# 사용자 지시 — 2026-10-24 KST

1. 해당 캐릭터들 상체 이너웨어의 경계를 일직선으로 만들어줄 수 있겠어? 그 부분을 이너웨어로 채웠던데 피부로 채우는게 맞지 싶어.
2. 리브나 유이의 경우 하체 이너웨어와 피부 텍스처의 경계가 완전히 명확하지는 않은 경우가 있던데 (특히 리브는 삽입 이미지와 같이 이너웨어의 경계가 피부에 검은 선 형태로 남아있음) 이거 피부 텍스처로 깔끔하게 정리해줄 수 있나?

별도 추가: 에델의 경우 총을 들때 총 후반부가 가슴에 묻히는 경우가 발생하는데 혹시 이거 해결가능한지 확인 부탁하고 가능할 것 같으면 수정 부탁함.

후속 확인: 아직 경계가 명확하고 깔끔하게 정리되지 못했음. 리브 엉덩이 검은 선, 세린 상체 피부/이너웨어 및 하체 경계, 유이도 동일. 리브 등에 짧은 검은 선 제거. 에델 가슴 총 접촉은 해결됐으나 왼팔이 이상해져 확인·수정 요청.
