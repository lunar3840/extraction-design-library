# 서브컬쳐 익스트랙션 슈터 프로젝트 중간보고 자료 제작

## 사용자 지시 요약

- 지금까지 구현한 내용을 짧은 중간보고용 Word와 PPT로 정리한다.
- 앞부분에 게임의 기초 기획을 넣고, 각 시스템의 의도와 구현 방식을 설명한다.
- Tripo 모델링·리깅과 직접 수행한 UV·텍스처링을 포함하되, 미완성 세린보다 에델 파일에 중점을 둔다.
- 세린 바디는 소녀형, 에델 바디는 성인형의 재사용 체형으로 운영할 계획을 설명한다.
- 기존 Markdown 기록과 구현 화면 캡처를 참조한다.
- 표제는 가제 대신 `서브컬쳐 익스트랙션 슈터 프로젝트`를 사용한다.

## 기획 의도와 해결하려는 문제

흩어져 있는 시스템 구현 기록과 캐릭터 제작 자료를 중간보고에 바로 쓸 수 있는 길이로 묶는다. 실제 구현 결과와 앞으로의 체형 재사용·아트 적용 계획을 구분해, 보고 시 진행 상태가 과장되지 않도록 한다.

## 변경 전 상태 및 문제점

- 이 작업의 Word·PPT 중간보고 파일은 존재하지 않았다. 따라서 새 문서의 `before` 페이지는 촬영할 수 없다.
- 게임 화면, 검증 기록, 에델 Blender·UV·텍스처 자료가 여러 폴더에 분산되어 있었다.
- 작업 전 프로젝트 화면 근거로 2026-09-15 A맵 캡처를 `before_project_map.png`에 보존했다. 이는 보고서 작성 전 이미 존재한 파일의 복사본이며 새로 촬영한 게임 화면으로 가장하지 않는다.

## 실제로 바꾼 부분

- `outputs/interim_report_2026-09-17/서브컬쳐_익스트랙션_슈터_개발_중간보고_20260917.docx`를 만들었다. 기본 기획, 플레이 흐름, 시스템별 의도·구현 방식, 에델 제작과 체형 운영 계획, 현재 단계, 화면 자료를 담았다.
- 같은 이름의 `.pptx`를 9장으로 만들었다. 기획·시스템·전투·거점·에델 제작·A맵·다음 작업을 실제 이미지와 함께 요약했다.
- 게임 프로젝트의 코드·씬·에셋은 수정하지 않았다.

## 변경 방식

- `MIGRATION_CHECKPOINT.md`, `outputs/SYSTEM_MIGRATION_REPORT.md`, 전투·의료·UI·캐릭터·맵의 Markdown 보고 및 변경 기록을 대조했다.
- 에델은 `Downloads/edel_tripo_uv_20260908`, `edel_texture_cleanup_20260908`, `edel_eyebrow_face_separation_upload_20260915`의 Blender 결과·UV 레이아웃·텍스처 미리보기·README를 사용했다.
- 플레이/거점/성장/의뢰/의료/무기/방어구/A맵/환경의 기존 스크린샷을 문서에 삽입했다. 기능 검사 이미지를 완성된 게임 장면으로 표시하지 않았다.
- 사용자 수정에 맞춰 최종 표제에서 가제를 제거하고 `서브컬쳐 익스트랙션 슈터 프로젝트`로 통일했다.

## 변경 후 기대 효과와 확인 결과

- Word는 5쪽, PPT는 9장이다. Word 전 페이지를 Microsoft Word에서 PDF로 내보내 이미지로 확인했고, PPT 최종 파일은 Microsoft PowerPoint에서 열어 PDF로 내보낸 후 전 슬라이드를 확인했다. 글자 잘림·겹침·누락된 이미지가 보이지 않는다.
- PPT 패키지 무결성, 슬라이드 크기, 글꼴 정책, Artifact Tool 재가져오기 검사를 통과했다.
- 보고서 본문은 현재 동작하는 핵심 시스템과 미구현 시나리오·보스 패턴·에델 게임 적용 상태를 구분한다.

## 관련 스크린샷과 대응 시점

- `before_project_map.png` ↔ `after_project_map.png`: 같은 기존 A맵 캡처를 작업 전후에 보존했다. 두 이미지는 동일하며 보고서 작성으로 게임 화면이 바뀌지 않았음을 나타낸다.
- `after_report_document.png`: 새 Word 첫 페이지의 결과 화면. 기존 문서가 없어서 대응하는 `before` 문서 화면은 없다.
- `after_report_presentation.png`: 새 PPT 표지의 PowerPoint 결과 화면. 기존 슬라이드가 없어서 대응하는 `before` 슬라이드 화면은 없다.
